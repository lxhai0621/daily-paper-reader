## 摘要
LLM 通过预测人类文本中的词汇来获取能力，而这些文本往往反映了人类执行任务的方式。因此，将 LLM 与工程化的运行时（runtime）耦合，可以将预测转化为控制：输出触发干预，进而实现目标导向的行为。我们认为，这些系统中的一个核心设计杠杆在于控制权在系统中的位置。大脑将预测嵌入在由行动后果校准的分层反馈控制器中。相比之下，LLM 智能体实现了“笛卡尔代理”（Cartesian agency）：一个学习核心通过符号接口与工程化运行时耦合，从而将控制状态和策略外部化。这种切分实现了自举、模块化和治理，但也可能引发敏感性和瓶颈。我们概述了受限服务、笛卡尔智能体和集成智能体，作为在自主性、鲁棒性和监管之间进行权衡的对比性控制方法。

## Abstract
LLMs gain competence by predicting words in human text, which often reflects how people perform tasks. Consequently, coupling an LLM to an engineered runtime turns prediction into control: outputs trigger interventions that enact goal-oriented behavior. We argue that a central design lever is where control resides in these systems. Brains embed prediction within layered feedback controllers calibrated by the consequences of action. By contrast, LLM agents implement Cartesian agency: a learned core coupled to an engineered runtime via a symbolic interface that externalizes control state and policies. The split enables bootstrapping, modularity, and governance, but can induce sensitivity and bottlenecks. We outline bounded services, Cartesian agents, and integrated agents as contrasting approaches to control that trade off autonomy, robustness, and oversight.

*   **核心概念：** 论文提出了**“笛卡尔切分”（Cartesian Cut）**的概念。这是一种类比笛卡尔“心物二元论”的架构描述，指将“学习核心”（负责预测的 LLM）与“工程化运行时”（负责执行、工具管理和策略的外部代码）进行分离的设计模式。

### 2. 论文提出的方法论
论文通过对比生物系统与 AI 系统，定义了“笛卡尔代理”的解剖结构，并提出了三种演进路径：
*   **笛卡尔代理架构（Cartesian Agency）：**
    *   **学习核心（Learned Core）：** 预训练模型，通过预测生成符号轨迹（如计划、推理、工具调用）。
    *   **编排层/运行时（Orchestration/Runtime）：** 外部代码，负责维护状态、内存序列化、重试逻辑、权限控制和工具执行。
    *   **符号瓶颈（Symbol Bottleneck）：** 核心与运行时之间仅通过低带宽的符号协议（如 JSON、文本、函数调用）通信。
*   **三种控制路径：**
    1.  **受限服务（Bounded Services）：** 控制权主要在外部（人类或机构手中），AI 仅作为非自主的咨询或规划工具。
    2.  **笛卡尔智能体（Cartesian Agents）：** 混合控制，利用符号接口实现模块化工具使用，是目前的主流模式（如 ReAct 框架）。
    3.  **集成智能体（Integrated Agents）：** 试图消除切分，将仲裁、记忆更新和适应性逻辑直接学习进模型内部（如端到端的视觉-语言-动作模型 VLA）。
