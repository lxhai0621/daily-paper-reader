## 摘要
个性化大语言模型 (PLLMs) 因其能够使输出对齐个人需求和偏好而备受关注。然而，它们在处理长周期任务（例如追踪用户大量的对话或活动历史）时仍面临困难。现有的记忆机制往往难以捕捉演化的行为，而检索增强生成 (RAG) 范式则受困于质量与效率之间的权衡。同时，由于标注数据的稀缺，参数化适配也因训练与推理之间的差距而面临瓶颈。为了增强 PLLMs 的长周期能力，我们提出了 TSUBASA，这是一种双管齐下的方法，旨在通过动态记忆演化改进“记忆写入”，并通过带有上下文蒸馏目标的自学习来改进“记忆读取”，从而内化用户体验。在 Qwen-3 模型系列（4B 到 32B）上进行的大规模长周期基准测试验证了 TSUBASA 的有效性，其表现超越了 Mem0 和 Memory-R1 等主要依赖记忆写入的竞争性记忆增强系统。我们的分析进一步证实，TSUBASA 打破了质量与效率的壁垒，实现了帕累托改进，在减少 Token 预算的同时提供了稳健、高保真的个性化体验。

## Abstract
Personalized large language models (PLLMs) have garnered significant attention for their ability to align outputs with individual's needs and preferences. However, they still struggle with long-horizon tasks, such as tracking a user's extensive history of conversations or activities. Existing memory mechanisms often fail to capture evolving behaviors, and RAG paradigms are trapped by a quality-efficiency tradeoff. Meanwhile, parametric adaptation is bottlenecked by train-inference gap due to the scarcity of labeled data. To enhance the long-horizon capabilities of PLLMs, we introduce TSUBASA, a two-pronged approach designed to improve memory writing via dynamic memory evolution, and memory reading via self-learning with a context distillation objective to internalize user experiences. Extensive evaluations on long-horizon benchmarks using the Qwen-3 model family (4B to 32B) validate the effectiveness of TSUBASA, surpassing competitive memory-augmented systems that rely primarily on memory writing, such as Mem0 and Memory-R1. Our analyses further confirms that TSUBASA breaks the quality-efficiency barrier to achieve Pareto improvements, delivering robust, high-fidelity personalization with a reduced token budget.

个性化大语言模型（PLLMs）在处理**长周期（Long-Horizon）**任务时面临两大核心瓶颈：
*   **训练-推理差距（Train-Inference Gap）：** 简单的自回归微调（在原始对话上）只能让模型死记硬背，无法应对推理复杂的个性化任务；而 RAG 仅将历史作为外部提示，模型并未真正“内化”用户特征。
*   **质量-效率权衡（Quality-Efficiency Tradeoff）：** 标准 RAG 性能高度依赖检索到的上下文长度，导致推理成本随历史增长而激增。
*   **用户偏好演化：** 现有的记忆机制（如 Mem0）往往使用破坏性的“删除”操作，丢失了用户偏好变化的因果链条。

**TSUBASA**（意为“翅膀”）框架旨在通过“双翼”设计——**动态记忆写入**与**内化记忆读取**，实现高效、隐私保护且能捕捉演化过程的长程个性化。

### 2. 方法论：核心思想与技术细节
TSUBASA 框架由两个协同的模块组成：

*   **动态记忆写入（Dynamic Memory Writing）：**
    *   **观察提取（Observation Extraction）：** 将原始、冗余的对话压缩为高信息密度的“事实观察”（基于 5W1H 原则）。
    *   **记忆管理器（Memory Manager）：** 采用四种自主动作管理记忆库：`ADD`（新增）、`UPDATE`（更新）、`IGNORE`（忽略）以及核心的 **`RECONCILE`（调和）**。`RECONCILE` 将冲突信息编织成带有时间戳的叙事（例如：“用户以前喜欢 X，但自某日起改为喜欢 Y”），保留了演化轨迹。
    *   **时间接地：** 将相对时间（如“昨天”）转换为绝对日期，增强检索精度。

*   **内化记忆读取（Internalized Memory Reading）：**
    *   **自学习流水线（Self-Learning Pipeline）：** 针对目标用户生成合成的 QA 对，解决标注数据稀缺问题，并避免跨用户训练带来的隐私风险。
    *   **上下文蒸馏（Context Distillation）：** 采用教师-学生架构。教师模型处理全量上下文生成响应，学生模型仅输入问题。通过最小化两者在 Top-d Token 上的 **KL 散度损失**，将教师的“暗知识”蒸馏进学生模型的参数中。

*   **隐私保护：** 采用自学习和本地蒸馏，不依赖跨用户数据，适合端侧部署。
*   **非破坏性记忆：** `RECONCILE` 动作解决了用户偏好漂移时的上下文丢失问题，比简单的删除操作更符合人类认知。
*   **高信息密度：** 通过将原始对话压缩为“观察”，极大地提高了检索的信噪比。

*   **开放域推理弱点：** 在连接未提及的常识（Open Domain 任务）时表现略逊，因为合成数据主要针对事实性 QA 优化。
