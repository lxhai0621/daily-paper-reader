## Abstract
Large Vision-Language Models (LVLMs) frequently suffer from hallucinations. Existing preference learning-based approaches largely rely on proprietary models to construct preference datasets. We identify that this reliance introduces a distributional mismatch between the proprietary and target models that hinders efficient alignment. To address this, we propose Alignment via VErified Self-correction DPO (AVES-DPO), a framework that aligns LVLMs using in-distribution data derived from the model's intrinsic knowledge. Our approach employs a consensus-based verification mechanism to diagnose diverse hallucinations and guides the model to self-correct, thereby generating preference pairs strictly compatible with its internal distribution. Extensive experiments demonstrate that AVES-DPO surpasses existing baselines in hallucination mitigation while requiring only 5.2k samples.

### 1. 核心问题与研究动机
*   **核心问题**：大型视觉语言模型（LVLMs）普遍存在“幻觉”问题（即生成与图像不符的内容）。
*   **研究动机**：
    *   **分布不匹配（Distributional Mismatch）**：现有的偏好学习方法（如 DPO）高度依赖 GPT-4V 等闭源模型生成修正数据。作者发现，闭源模型的生成风格与目标模型自身的内在分布存在显著差异，这种“分布不匹配”阻碍了对齐效率。
    *   **幻觉类型单一**：现有研究多集中在“物体存在性”幻觉，而忽视了更细粒度的“属性”和“关系”幻觉。
    *   **成本与依赖**：过度依赖昂贵的闭源 API，缺乏一种利用模型自身能力进行自我进化的有效框架。

### 2. 方法论：AVES-DPO 框架
AVES-DPO（Alignment via VErified Self-correction DPO）的核心思想是**利用模型自身的“声音”进行对齐**，通过自我修正生成分布内的偏好数据。

*   **核心流程**：
    1.  **幻觉验证（Hallucination Verification）**：
        *   **场景图提取**：将模型生成的初始响应解析为包含物体（O）、属性（A）、关系（R）的结构化场景图。
        *   **共识验证**：采用多个开源专家模型（如 YOLO、Grounding DINO、Qwen3-VL）进行交叉验证。只有当多个模型达成共识时才标记为“事实”或“幻觉”，不一致的标记为“模糊”并进一步处理。
    2.  **自我修正（Self-correction）**：
        *   **事实整改**：根据验证结果，引导模型删除或替换初始响应中的幻觉元素，生成简洁的事实描述。
        *   **细节增强**：在保证事实性的基础上，要求模型补充图像中的缺失细节。通过“验证-修正”循环迭代（7B迭代3次，13B迭代5次）确保增强后的内容不再引入新幻觉。
    3.  **偏好学习（Preference Learning）**：
        *   将初始幻觉响应作为负样本（$y^-$），自我修正后的增强响应作为正样本（$y^+$）。
        *   使用 **DPO（直接偏好优化）** 算法更新模型参数，优化目标是增大正负样本之间的似然差。

### 6. 主要结论与发现
*   **高效性**：AVES-DPO 仅需 5.2k 样本即可超越使用 122k 数据的 LLaVA-RLHF，数据效率提升约 25 倍。
*   **细粒度优势**：在处理复杂的“关系（Relation）”幻觉方面表现尤为突出，远超现有基准。
*   **分布对齐的重要性**：实验证明，模型学习“自己的修正结果”比学习“GPT-4V 的修正结果”更容易收敛且效果更好，验证了分布匹配的假设。
*   **通用能力保持**：在缓解幻觉的同时，模型在 MME 等通用感知任务上的得分也有所提升（尤其是 7B 模型）。

### 7. 优点与亮点
*   **分布内对齐**：深刻揭示了外部监督信号带来的分布偏移问题，并给出了优雅的解决方案。
*   **全开源闭环**：从验证专家到目标模型均为开源，摆脱了对闭源 API 的依赖，降低了研究门槛。
*   **高质量数据生成**：通过“验证-修正-再验证”的循环机制，确保了偏好对中正样本的极高可靠性。

### 8. 不足与局限
*   **模型规模的权衡**：在 13B 模型上，虽然幻觉显著减少，但在某些通用知识基准上出现了轻微的性能下降，显示出“抗幻觉”与“知识广度”之间存在权衡。
*   **验证范围限制**：目前的属性和关系验证主要局限于单物体级别，对于涉及多个物体交织的极复杂场景，验证精度仍有提升空间。
*   **任务类型**：主要针对图像描述类任务，对于多轮对话或复杂推理任务的泛化性尚待进一步验证。
