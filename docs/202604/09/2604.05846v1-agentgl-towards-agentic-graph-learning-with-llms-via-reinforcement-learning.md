## 摘要
大语言模型（LLMs）日益依赖智能体能力——迭代检索、工具使用和决策——以克服静态参数化知识的局限性。然而，现有的智能体框架将外部信息视为非结构化文本，未能利用现实世界数据中固有的拓扑依赖关系。为了弥补这一差距，我们引入了智能体图学习（Agentic Graph Learning, AGL），这是一种将图学习重新定义为拓扑感知导航与基于 LLM 推理的交替过程的范式。具体而言，我们提出了 AgentGL，这是首个用于 AGL 的强化学习（RL）驱动框架。AgentGL 为 LLM 智能体配备了用于多尺度探索的图原生工具，通过搜索约束思维来规范工具使用以平衡准确性与效率，并采用图条件课程强化学习策略，在没有逐步监督的情况下稳定长程策略学习。在多种文本属性图（TAG）基准测试和多个 LLM 主干模型上，AgentGL 显著优于强大的 GraphLLMs 和 GraphRAG 基准模型，在节点分类中实现了高达 17.5% 的绝对提升，在链路预测中实现了 28.4% 的绝对提升。这些结果表明，AGL 是使 LLM 能够在复杂关系环境中自主导航和推理的一个极具前景的前沿领域。代码已在 https://github.com/sunyuanfu/AgentGL 公开。

## Abstract
Large Language Models (LLMs) increasingly rely on agentic capabilities-iterative retrieval, tool use, and decision-making-to overcome the limits of static, parametric knowledge. Yet existing agentic frameworks treat external information as unstructured text and fail to leverage the topological dependencies inherent in real-world data. To bridge this gap, we introduce Agentic Graph Learning (AGL), a paradigm that reframes graph learning as an interleaved process of topology-aware navigation and LLM-based inference. Specifically, we propose AgentGL, the first reinforcement learning (RL)-driven framework for AGL. AgentGL equips an LLM agent with graph-native tools for multi-scale exploration, regulates tool usage via search-constrained thinking to balance accuracy and efficiency, and employs a graph-conditioned curriculum RL strategy to stabilize long-horizon policy learning without step-wise supervision. Across diverse Text-Attributed Graph (TAG) benchmarks and multiple LLM backbones, AgentGL substantially outperforms strong GraphLLMs and GraphRAG baselines, achieving absolute improvements of up to 17.5% in node classification and 28.4% in link prediction. These results demonstrate that AGL is a promising frontier for enabling LLMs to autonomously navigate and reason over complex relational environments. The code is publicly available at https://github.com/sunyuanfu/AgentGL.

### 2. 方法论
AgentGL 是首个由强化学习（RL）驱动的 AGL 框架，包含以下核心组件：
*   **图原生搜索工具（GNS Tools）**：
    *   **1-hop/2-hop 邻域搜索**：通过加权融合查询相关性和结构重要性，获取局部证据。
    *   **结构显著性搜索（SS）**：利用 PageRank 分数识别全局拓扑枢纽。
    *   **图稠密搜索（DENSE）**：基于语义嵌入相似度跨越拓扑断裂获取证据。
*   **两阶段强化学习策略**：
    *   **阶段 1：策略引导（Bootstrapping）**：使用包含格式、准确性和**工具覆盖率（Coverage）**的奖励函数，训练 LLM 掌握图导航基本功。
    *   **阶段 2：缓解搜索过度（MSO）**：引入“搜索约束思维”，通过**回顾性终止触发器**和**认知密度正则化（CDR）**，惩罚浅层推理，鼓励智能体在获取足够证据后及时停止，平衡效率与精度。
*   **图条件课程学习（GCCL）**：
    *   利用图的先验属性（如节点分类中的同质性和度数、链路预测中的语义-标签一致性）自动计算样本难度，实现从易到难的平滑训练。
*   **算法实现**：支持 GRPO 和 REINFORCE++ 两种主流的无评论员（Critic-free）策略优化算法。

*   **任务场景**：节点分类（NC）和链路预测（LP），包括**域内评估**和**零样本迁移（Zero-shot）**。

### 5. 实验数量与充分性
*   **实验规模**：在 7 个数据集上进行了详尽的测试，涵盖了从 3B 到 7B 的模型规模。
*   **消融实验**：针对两阶段训练、奖励项（rCOV, CDR, RTT）、课程学习（GCCL）以及超参数（$\lambda_r$）均做了独立消融分析。
*   **客观性与公平性**：
    *   所有基线模型均使用相同的主干 LLM。

### 6. 主要结论与发现
*   **性能卓越**：AgentGL 在节点分类上平均提升 12.7%~24.4%，在链路预测上提升高达 28.4%。
*   **动态优于静态**：交替进行的搜索-推理循环显著优于一次性注入静态上下文的方法（如 GraphLLM）。
*   **效率提升**：通过第二阶段优化，AgentGL 在减少约 17.5% 工具调用的同时，准确率反而提升了约 2.4%，证明了“少即是多”的搜索策略。
*   **泛化能力**：在零样本迁移场景下，AgentGL 的领先优势扩大，表明其学习到的是通用的图导航策略而非简单的模式记忆。

### 7. 优点
*   **范式创新**：首次将图学习系统性地建模为强化学习驱动的智能体决策过程。
*   **工具设计完备**：兼顾了局部与全局、结构与语义四个维度的图探索。
*   **无需人工标注轨迹**：通过 GCCL 和精心设计的奖励函数，实现了在无步骤监督情况下的稳定长程学习。
*   **可解释性**：通过 `<think>` 模块展示了智能体如何根据已获证据调整搜索计划。

### 8. 不足与局限
*   **模态限制**：目前仅支持文本属性图，尚未扩展到包含图像等多模态属性的图数据。
*   **数据分配敏感性**：MSO 阶段的稳定性依赖于两阶段训练数据分配的精细平衡。
*   **图密度挑战**：在极稠密图上的表现及工具调用的分布变化仍需进一步探索。
*   **应用范围**：目前主要针对经典的 NC 和 LP 任务，对于更复杂的图生成或超图推理尚待验证。
