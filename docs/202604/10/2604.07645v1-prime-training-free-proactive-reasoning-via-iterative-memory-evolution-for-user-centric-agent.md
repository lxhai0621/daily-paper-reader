## 摘要
与人类用户协作完成复杂、长程任务的自主工具使用智能体的开发已成为智能体研究的前沿。在多轮人机交互过程中，用户需求的动态性和不确定性带来了重大挑战；智能体不仅需要调用工具，还必须通过有效的沟通迭代地完善对用户意图的理解。虽然强化学习的最新进展为构建更强大的工具使用智能体提供了路径，但现有方法需要昂贵的训练成本，且在长程交互中难以进行轮次级的信用分配。为此，我们引入了 PRIME（通过迭代记忆演化的主动推理），这是一种无梯度学习框架，通过显式的经验积累而非昂贵的参数优化来实现智能体的持续演化。PRIME 将多轮交互轨迹提炼为结构化的、人类可读的经验，并将其组织在三个语义区域：成功策略、失败模式和用户偏好。这些经验通过元级操作进行演化，并通过检索增强生成指导智能体未来的行为。我们在多个不同的以用户为中心的环境中进行的实验表明，PRIME 在提供成本效益和可解释性的同时，达到了与基于梯度的方法相当的性能。总之，PRIME 为构建主动、协作型智能体提供了一种实用的范式，使其能够从人机交互中学习，而无需承担基于梯度的训练所带来的计算负担。

## Abstract
The development of autonomous tool-use agents for complex, long-horizon tasks in collaboration with human users has become the frontier of agentic research. During multi-turn Human-AI interactions, the dynamic and uncertain nature of user demands poses a significant challenge; agents must not only invoke tools but also iteratively refine their understanding of user intent through effective communication. While recent advances in reinforcement learning offer a path to more capable tool-use agents, existing approaches require expensive training costs and struggle with turn-level credit assignment across extended interaction horizons. To this end, we introduce PRIME (Proactive Reasoning via Iterative Memory Evolution), a gradient-free learning framework that enables continuous agent evolvement through explicit experience accumulation rather than expensive parameter optimization. PRIME distills multi-turn interaction trajectories into structured, human-readable experiences organized across three semantic zones: successful strategies, failure patterns, and user preferences. These experiences evolve through meta-level operations and guide future agent behavior via retrieval-augmented generation. Our experiments across several diverse user-centric environments demonstrate that PRIME achieves competitive performance with gradient-based methods while offering cost-efficiency and interpretability. Together, PRIME presents a practical paradigm for building proactive, collaborative agents that learn from Human-AI interaction without the computational burden of gradient-based training.

在多轮人机交互中，以用户为中心的智能体面临两大挑战：一是**用户意图的动态性与不确定性**，需要智能体具备主动询问和澄清的能力；二是**现有强化学习（RL）方法的局限性**。虽然基于梯度的 RL（如 GRPO）能提升性能，但其训练成本极高（需多 GPU 集群）、改进过程不透明（黑盒权重）且难以跨模型迁移。
**PRIME 的核心动机**是：将智能体的提升视为一个“知识积累”问题而非“参数优化”问题。通过显式地捕捉、组织和演化交互经验，实现无需训练（Training-Free）的持续进化。

### 2. 方法论：核心思想与技术细节
PRIME 提出了一个循环演化的框架，核心思想是**“经验即梯度”**。
*   **核心流程**：
    1.  **探索（Exploration）**：智能体在环境中进行多轮交互，收集成功与失败的原始轨迹。
    2.  **提炼（Distillation）**：利用多轮信用分配（Credit Assignment）识别关键轮次，通过 LLM 将轨迹转化为结构化记忆。记忆包含：情境、行动、结果、教训、阶段标签（探索/验证/完成）及适用条件。
    3.  **演化（Evolution）**：通过元级操作优化记忆库。包括：**变异**（细化描述）、**泛化**（去除环境特定细节）、**交叉**（结合不同经验）和**剪枝**（移除低效经验）。
    4.  **推理（Inference）**：采用阶段感知的检索增强生成（RAG）。根据当前交互阶段，从三个语义区检索记忆：
        *   **黄金区（Golden Zone）**：值得模仿的成功策略。
        *   **警告区（Warning Zone）**：需规避的失败模式。
        *   **偏好区（Preference Zone）**：用户行为模式。
*   **数学表达**：PRIME 将目标定义为在记忆库 $M$ 上进行优化，最大化预期性能 $\Phi$，即 $M^* = \arg \max_M E [\Phi(\pi(\cdot| X, \rho(X, M)))]$，其中 $\rho$ 是检索函数，$\pi$ 是冻结权重的 LLM。

### 6. 主要结论与发现
*   **性能卓越**：PRIME 在所有 8 个环境中均显著提升了基座模型的表现，尤其在 FunctionGym（提升 193%）和 TauGym（提升 50%）等复杂任务中表现突出。
*   **逼近 RL 水平**：虽然绝对性能略低于直接进行参数微调的 GRPO，但 PRIME 在无需训练的前提下达到了极具竞争力的水平。

*   **可解释性**：记忆库以人类可读的自然语言存储，开发者可以轻松审计智能体学到了哪些策略或规避了哪些错误。

### 7. 优点（亮点）
*   **低门槛进化**：打破了智能体进化必须依赖高昂算力微调的现状，适合资源受限的场景。
*   **知识解耦**：将“能力”留在模型中，将“经验”存在外部库中，实现了策略的模块化和可插拔。
*   **阶段感知**：通过将交互分为探索、验证、完成三个阶段进行针对性检索，比通用的 RAG 更符合多轮对话的逻辑。

### 8. 不足与局限
*   **依赖上位模型**：在提炼（Distillation）和演化（Evolution）阶段，PRIME 仍需依赖性能强大的模型（如 GPT-4o）作为“老师”来总结经验，这可能引入上位模型的偏见。
*   **推理延迟**：由于每轮交互都需要进行 RAG 检索和 Prompt 扩充，推理时的 Token 消耗和延迟会高于纯微调模型。
*   **性能上限**：由于不改变模型权重，其性能上限受限于基座模型理解和执行检索到的“教训”的能力。
