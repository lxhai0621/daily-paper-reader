## 摘要
个性化大语言模型（PLLMs）因其能够使输出与个人的需求和偏好保持一致而受到广泛关注。然而，它们在处理长周期任务时仍然面临挑战，例如追踪用户大量的对话或活动历史。现有的记忆机制往往无法捕捉不断演化的行为，而检索增强生成（RAG）范式则受困于质量与效率之间的权衡。同时，由于标注数据的稀缺，参数化适配受到训练与推理之间差距的瓶颈限制。为了增强 PLLMs 的长周期能力，我们提出了 TSUBASA，这是一种双管齐下的方法，旨在通过动态记忆演化改进记忆写入，并通过带有上下文蒸馏目标的自学习改进记忆读取，从而内化用户体验。在 Qwen-3 模型系列（4B 到 32B）上进行的广泛长周期基准评估验证了 TSUBASA 的有效性，其表现超越了主要依赖记忆写入的竞争性记忆增强系统，如 Mem0 和 Memory-R1。我们的分析进一步证实，TSUBASA 打破了质量与效率的壁垒，实现了帕累托改进，在减少 Token 预算的情况下提供了稳健、高保真的个性化体验。

## Abstract
Personalized large language models (PLLMs) have garnered significant attention for their ability to align outputs with individual's needs and preferences. However, they still struggle with long-horizon tasks, such as tracking a user's extensive history of conversations or activities. Existing memory mechanisms often fail to capture evolving behaviors, and RAG paradigms are trapped by a quality-efficiency tradeoff. Meanwhile, parametric adaptation is bottlenecked by train-inference gap due to the scarcity of labeled data. To enhance the long-horizon capabilities of PLLMs, we introduce TSUBASA, a two-pronged approach designed to improve memory writing via dynamic memory evolution, and memory reading via self-learning with a context distillation objective to internalize user experiences. Extensive evaluations on long-horizon benchmarks using the Qwen-3 model family (4B to 32B) validate the effectiveness of TSUBASA, surpassing competitive memory-augmented systems that rely primarily on memory writing, such as Mem0 and Memory-R1. Our analyses further confirms that TSUBASA breaks the quality-efficiency barrier to achieve Pareto improvements, delivering robust, high-fidelity personalization with a reduced token budget.

### 1. 核心问题与研究动机
现有的个性化大模型在长程交互中面临两大技术瓶颈：
*   **训练-推理鸿沟（Train-Inference Gap）：** 在原始对话上进行简单的自回归微调（参数化记忆）往往只能实现机械记忆，无法应对推理要求高的复杂个性化任务。
*   **质量-效率权衡（Quality-Efficiency Tradeoff）：** 传统的检索增强生成（RAG）范式中，响应质量高度依赖检索到的上下文长度，导致推理成本随记忆量增加而激增。
*   **用户偏好演化：** 现有记忆机制（如 Mem0）常使用破坏性的“删除”操作，导致历史上下文丢失，难以捕捉用户随时间变化的偏好。

### 2. 方法论：TSUBASA 框架
TSUBASA（日语意为“翅膀”）由两个协同的“机翼”组成：

*   **动态记忆写入（Dynamic Memory Writing）：**
    *   **观察提取：** 从原始对话中提取高信息密度的“事实观察”，减少冗余。
    *   **记忆管理器：** 采用四种自主动作：`ADD`（新增）、`UPDATE`（更新细节）、`RECONCILE`（调和冲突，将矛盾转化为时间线叙述而非删除旧信息）、`IGNORE`（忽略琐碎信息）。
    *   **时间感知：** 将相对时间（如“昨天”）转换为绝对日期，增强检索的准确性。
*   **内化记忆读取（Internalized Memory Reading）：**
    *   **自学习流水线：** 利用模型自身根据用户历史生成合成的 QA 对，解决标注数据稀缺问题。
    *   **上下文蒸馏（Context Distillation）：** 采用教师-学生架构。教师模型接触完整上下文，学生模型仅接触问题。通过 **KL 散度损失函数**，将教师的“暗知识”蒸馏到学生模型的参数中，使学生在不读取长上下文的情况下也能内化用户偏好。

### 7. 优点与亮点
*   **隐私保护：** 与 Memory-R1 不同，TSUBASA 不依赖跨用户数据训练，完全在目标用户的数据范围内运行，符合隐私合规。
*   **非破坏性记忆：** `RECONCILE` 动作保留了用户偏好的演化轨迹，而非简单删除，更符合人类认知。
*   **高效内化：** 首次将上下文蒸馏应用于个性化领域，解决了 RAG 的延迟问题和微调的推理能力问题。

*   **任务覆盖：** 在“开放域”任务（需要抽象推理而非事实检索）上表现略逊于 Memory-R1，原因是合成数据生成目前主要针对事实性 QA。
*   **模型饱和：** 在 32B 规模上提升有限，暗示超大模型可能已经具备了较强的上下文处理能力，内化带来的边际效应递减。
*   **合成数据偏差：** 性能高度依赖于自学习阶段生成的 QA 对质量，若生成过程存在偏差，会影响最终的个性化效果。
