## 摘要
检索增强生成（RAG）系统在当代大语言模型（LLM）中得到了广泛应用，因为它们能够在减少所需输入上下文长度的同时提高生成质量。在这项工作中，我们专注于用于长文档问答的 RAG 系统。当前的方法过度依赖 LLM 生成的描述，导致资源消耗大、延迟高、层级间内容重复，并且由于缺乏或仅有有限的源文本锚定（grounding）而产生幻觉。为了通过锚定提高效率和事实准确性，我们提出了 GroundedKG-RAG，这是一种知识图谱显式地从源文档中提取并锚定在其中的 RAG 系统。具体而言，我们将 GroundedKG 中的节点定义为实体和动作，将边定义为时间或语义关系，每个节点和边都锚定在原始句子中。我们利用语义角色标注（SRL）和抽象语义表示（AMR）解析构建 GroundedKG，然后对其进行嵌入以进行检索。在查询过程中，我们对查询应用相同的转换，并从锚定的源文本中检索最相关的句子进行问答。我们在 NarrativeQA 数据集的示例上评估了 GroundedKG-RAG，发现它在成本更低的情况下，性能与最先进的专有长上下文模型相当，并优于具有竞争力的基准模型。此外，我们的 GroundedKG 具有可解释性和人类可读性，便于结果审计和错误分析。

## Abstract
Retrieval-augmented generation (RAG) systems have been widely adopted in contemporary large language models (LLMs) due to their ability to improve generation quality while reducing the required input context length. In this work, we focus on RAG systems for long-document question answering. Current approaches suffer from a heavy reliance on LLM descriptions resulting in high resource consumption and latency, repetitive content across hierarchical levels, and hallucinations due to no or limited grounding in the source text. To improve both efficiency and factual accuracy through grounding, we propose GroundedKG-RAG, a RAG system in which the knowledge graph is explicitly extracted from and grounded in the source document. Specifically, we define nodes in GroundedKG as entities and actions, and edges as temporal or semantic relations, with each node and edge grounded in the original sentences. We construct GroundedKG from semantic role labeling (SRL) and abstract meaning representation (AMR) parses and then embed it for retrieval. During querying, we apply the same transformation to the query and retrieve the most relevant sentences from the grounded source text for question answering. We evaluate GroundedKG-RAG on examples from the NarrativeQA dataset and find that it performs on par with a state-of-the art proprietary long-context model at smaller cost and outperforms a competitive baseline. Additionally, our GroundedKG is interpretable and readable by humans, facilitating auditing of results and error analysis.

*   **核心问题**：针对长文档问答（Long-document QA），现有的检索增强生成（RAG）系统（如 GraphRAG、RAPTOR）存在三大痛点：
    1.  **高资源消耗与延迟**：过度依赖大语言模型（LLM）生成摘要和描述来构建索引。
    2.  **内容冗余**：层级化摘要结构导致信息在不同层级间重复。
    3.  **幻觉风险**：由于索引内容（如社区摘要）并非直接来自原文，而是 LLM 的二次创作，容易脱离事实。
*   **研究背景**：作者旨在开发一种**显式锚定（Grounded）**的知识图谱索引，确保图谱中的每一个节点和每一条边都能追溯到原始文档的具体句子，从而在降低成本的同时提高事实准确性和可解释性。

### 2. 方法论：核心思想与关键技术
GroundedKG-RAG 的核心思想是将非结构化文本转换为一个节点和边均有原文支撑的结构化知识图谱。

*   **知识图谱定义**：
    *   **节点（Nodes）**：代表实体（Entity）和动作（Action）。
    *   **边（Edges）**：代表语义关系（如 PropBank 中的 A0, A1 角色）或动作之间的时间顺序关系。
    *   **锚定属性**：每个节点和边都包含 `grounded_texts` 属性，存储其来源的原始句子。
*   **构建流程**：
    1.  **预处理**：进行指代消解（Coreference Resolution），确保实体一致性。
    2.  **语义解析**：对比了两种解析技术：
        *   **SRL（语义角色标注）**：识别“谁对谁做了什么”，构建谓语-论元结构。
        *   **AMR（抽象语义表示）**：将句子映射为根有向无环图，抽象掉语法差异，捕捉核心语义。
    3.  **图谱构建**：将解析结果转化为图结构，并添加动作间的时间边。
*   **嵌入与检索**：
    *   **嵌入**：探索了基础节点嵌入、平均邻居嵌入和基于注意力的邻居嵌入，以捕捉局部图上下文。
    *   **检索**：将用户查询也转化为查询图（Query Graph），通过节点相似度匹配检索 Top-K 个相关节点，进而提取其锚定的原始句子作为上下文。
    *   **生成**：将检索到的原始句子输入 LLM 生成最终答案。

### 6. 主要结论与发现
*   **性能表现**：GroundedKG-RAG 在 ROUGE-L 指标上优于 GraphRAG，在 BERTScore 上与昂贵的长上下文模型持平。
*   **解析技术**：**AMR 解析优于 SRL**。AMR 能够更好地识别语义概念（如将“彼得的父亲”和“四个孩子的父亲”映射到核心节点“父亲”），从而提高检索精度。
*   **嵌入策略**：基础节点嵌入表现最好，加入邻居信息（图上下文）并未带来显著提升，甚至可能引入噪声。
*   **过滤策略**：额外的向量相似度过滤或频次过滤反而降低了性能，因为可能会误删包含关键证据但语义重合度较低的句子。

### 7. 优点
*   **高事实性**：通过直接锚定原文句子，从根本上杜绝了索引构建阶段产生的幻觉。
*   **成本效益**：索引构建过程主要在本地 GPU 完成，无需大量消耗 LLM API 资源。
*   **可解释性**：检索结果是人类可读的原始句子，且图谱结构清晰，便于审计和错误分析。
*   **灵活性**：聚合过程是查询自适应的，而非固定的层级结构。

### 8. 不足与局限
*   **长文档挑战**：在处理超长文档（如《鲁滨逊漂流记》）时，BERTScore 仍落后于全上下文模型，说明大规模图谱的检索精度仍有提升空间。

*   **上下文碎片化**：检索到的句子可能存在逻辑断层或相互矛盾，对生成模型的推理能力要求较高。
*   **实验覆盖面**：仅在 NarrativeQA 的三个样本上进行了深入测试，尚未在大规模工业级数据集上验证泛化性。
