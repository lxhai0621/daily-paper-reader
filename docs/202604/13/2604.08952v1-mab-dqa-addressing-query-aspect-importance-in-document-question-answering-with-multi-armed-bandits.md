## 摘要
文档问答（DQA）涉及根据用户查询从文档中生成答案，是文档理解中的一项关键任务。该任务需要解析视觉布局，这促使最近的研究采用多模态检索增强生成（RAG），通过处理页面图像来生成答案。然而，在多模态 RAG 中，视觉 DQA 难以有效利用大量图像，因为检索阶段通常仅保留少数候选页面（例如 Top-4），导致信息丰富但视觉显著性较低的内容被忽略，而倾向于选择常见但信息量较低的页面。为了解决这一问题，我们提出了一种基于多臂老虎机（Multi-Armed Bandit）的 DQA 框架（MAB-DQA），以显式建模查询中多个隐式维度的不同重要性。具体而言，MAB-DQA 将查询分解为感知维度的子查询，并为每个子查询检索特定维度的候选集。它将每个子查询视为一个摇臂，并利用来自少量代表性页面的初步推理结果作为奖励信号来估计维度效用。在探索-利用策略的指导下，MAB-DQA 动态地将检索预算重新分配给高价值维度。通过利用信息量最大的页面及其相关性，MAB-DQA 生成预期结果。在四个基准测试中，MAB-DQA 相比现有最先进方法实现了 5%-18% 的平均提升，持续增强了文档理解能力。代码见 https://github.com/ElephantOH/MAB-DQA。

## Abstract
Document Question Answering (DQA) involves generating answers from a document based on a user's query, representing a key task in document understanding. This task requires interpreting visual layouts, which has prompted recent studies to adopt multimodal Retrieval-Augmented Generation (RAG) that processes page images for answer generation. However, in multimodal RAG, visual DQA struggles to utilize a large number of images effectively, as the retrieval stage often retains only a few candidate pages (e.g., Top-4), causing informative but less visually salient content to be overlooked in favor of common yet low-information pages. To address this issue, we propose a Multi-Armed Bandit-based DQA framework (MAB-DQA) to explicitly model the varying importance of multiple implicit aspects in a query. Specifically, MAB-DQA decomposes a query into aspect-aware subqueries and retrieves an aspect-specific candidate set for each. It treats each subquery as an arm and uses preliminary reasoning results from a small number of representative pages as reward signals to estimate aspect utility. Guided by an exploration-exploitation policy, MAB-DQA dynamically reallocates retrieval budgets toward high-value aspects. With the most informative pages and their correlations, MAB-DQA generates the expected results. On four benchmarks, MAB-DQA shows an average improvement of 5%-18% over the state-of-the-art method, consistently enhancing document understanding. Code at https://github.com/ElephantOH/MAB-DQA.

#### 1. 核心问题与整体含义（研究动机和背景）
在多模态文档问答（DQA）任务中，检索增强生成（RAG）是主流范式。然而，现有的检索方法（如 Colpali）通常采用“延迟交互（Late Interaction）”机制，通过简单的最大池化和求和来计算查询与页面的相似度。
*   **研究动机**：这种机制机械地对待查询中的所有词汇，无法像人类一样区分不同语义维度的重要性。
*   **核心问题**：查询中高频但低信息的词汇（如公司名、格式要求词）往往会产生虚高的相似度分数，导致包含关键证据但视觉显著性较低的页面被无关页面挤出 Top-K 检索列表，这种现象被称为“维度检索退化（Aspect Retrieval Degradation）”。

#### 2. 方法论：核心思想与关键技术
MAB-DQA 框架通过显式建模查询维度的重要性，动态分配检索资源。其核心流程分为三个阶段：
*   **查询感知页面超图构建**：
    *   将原始查询分解为多个“感知维度”的子查询。
    *   构建超图：节点为文档页面，边表示页面间的视觉/语义相似性，**超边**则代表针对特定子查询检索到的候选页面集。
*   **多臂老虎机（MAB）引导检索**：
    *   将每个子查询视为 MAB 中的一个“摇臂（Arm）”。
    *   **奖励机制**：利用视觉语言模型（VLM）对初步检索页面的相关性评分作为奖励信号。
    *   **策略**：采用 **Thompson Sampling（汤普森采样）** 维护 Beta 分布，平衡“探索”（寻找潜在相关维度）与“利用”（深入检索已证实的有效维度），动态调整检索预算。
*   **基于超图的反思推理代理（HRRA）**：
    *   利用检索到的页面及其在超图中的关联性，通过“初始回答-验证-优化”的循环生成最终答案。

#### 3. 实验设计
*   **数据集**：在四个具有挑战性的基准上进行测试：
    1.  **MMLongBench**：评估长文档理解和跨页推理。
    2.  **LongDocURL**：关注长文档的定位与推理。
    3.  **PaperTab**：侧重于科学论文结构和表格理解。
    4.  **FetaTab**：基于维基百科的表格问答。
*   **对比方法（Baselines）**：
    *   纯 VLM 方法（如 Qwen-2.5-VL-7B 直接输入）。
    *   多智能体框架：MDocAgent。
    *   多模态 RAG 框架：M3DocRAG、MoloRAG（当前 SOTA）。
*   **评估指标**：采用 GPT-4o 作为裁判评估答案准确率（Accuracy），并使用 Recall、Precision、NDCG 和 MRR 评估检索性能。

*   **硬件环境**：实验在一台配备 **4 张 NVIDIA V100 GPU** 的系统上运行。
*   **模型使用**：主实验采用 **Qwen-2.5-VL-7B-Instruct** 作为推理引擎，使用 **ColPali** 生成视觉向量嵌入。
*   **推理效率**：文中对比了推理时间，MAB-DQA 的平均推理时间约为 60-66 秒（Top-10 检索），虽然比简单 RAG 慢，但由于其动态策略，效率优于某些复杂的多智能体方法。

#### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 40 页到 500 页不等的长文档场景。
*   **消融实验**：详细分析了查询分解（QD）、MAB 引导检索（MABR）和反思推理代理（HRRA）各自的贡献。
*   **敏感性分析**：对超参数（如奖励权重 $\alpha$、探索因子 $\lambda$、迭代次数 $m$ 等）进行了系统的鲁棒性测试。
*   **充分性评价**：实验设计较为全面，不仅对比了最终答案的准确性，还深入分析了检索阶段的各项指标，并通过定性案例展示了 MAB 如何抑制干扰维度的过程，结果具有较强的说服力。

#### 6. 主要结论与发现
*   **性能提升**：MAB-DQA 在四个数据集上均取得最优结果，相比最强基准（MoloRAG+），答案准确率平均提升了 **10.38%**，在 PaperTab 上提升高达 **18.50%**。
*   **检索突破**：在检索指标上，MAB-DQA 刷新了 MMLongBench 和 LongDocURL 的记录，平均超越 Colpali 基准 **6.55%**。
*   **维度发现**：实验证明，显式建模查询维度并利用 MAB 进行在线权重更新，能有效识别并抑制“看似相关实则干扰”的页面。

#### 7. 优点
*   **创新性**：首次将组合多臂老虎机引入多模态 DQA 的检索优化中，解决了长文档中关键信息被稀释的问题。
*   **动态性**：不同于固定预算的检索，该方法能根据 VLM 的实时反馈调整策略，具有更强的自适应能力。
*   **可解释性**：通过 Beta 分布的变化和热力图，可以直观地观察到模型对查询中不同约束条件的重视程度。

#### 8. 不足与局限
*   **VLM 依赖性**：框架的性能高度依赖于底层 VLM 的推理能力，若 VLM 在特定领域（如医疗、法律）表现不佳，奖励信号将失效。
*   **计算开销**：由于涉及多次 VLM 评估和迭代检索，其计算成本高于传统的单次检索 RAG。
*   **超参数敏感**：虽然做了敏感性分析，但 $\alpha, \beta, \lambda$ 等参数在不同类型的文档间可能需要精细调优，泛化到所有场景可能存在挑战。
*   **算法局限**：目前仅探索了汤普森采样（TS），未对比 UCB 或 Epsilon-Greedy 等其他老虎机算法在 DQA 场景下的表现。
