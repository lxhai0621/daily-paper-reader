## 摘要
跨组织边界部署的检索增强生成（RAG）系统在安全性、准确性和效率之间面临着根本性的权衡。目前的加密方法在解密过程中会暴露明文，而联邦架构则阻碍了资源整合并产生了巨大的开销。我们提出了 Trans-RAG，它实现了一种新颖的向量空间语言范式，其中每个组织的知识都存在于数学隔离的语义空间中。其核心是 vector2Trans，这是一种多阶段变换技术，使查询能够通过以查询为中心的变换动态地“说出”每个组织的向量空间“语言”，在消除解密开销的同时保持了原生的检索效率。安全性评估表明，向量空间接近正交，角度间隔为 89.90°，隔离率达 99.81%。在 8 个检索器、3 个数据集和 3 个大语言模型（LLM）上的实验表明，准确率下降极小（nDCG@10 下降 3.5%），且相比同态加密具有显著的效率提升。

## Abstract
Retrieval Augmented Generation (RAG) systems deployed across organizational boundaries face fundamental tensions between security, accuracy, and efficiency. Current encryption methods expose plaintext during decryption, while federated architectures prevent resource integration and incur substantial overhead. We introduce Trans-RAG, implementing a novel vector space language paradigm where each organization's knowledge exists in a mathematically isolated semantic space. At the core lies vector2Trans, a multi-stage transformation technique that enables queries to dynamically "speak" each organization's vector space "language" through query-centric transformations, eliminating decryption overhead while maintaining native retrieval efficiency. Security evaluations demonstrate near-orthogonal vector spaces with 89.90° angular separation and 99.81% isolation rates. Experiments across 8 retrievers, 3 datasets, and 3 LLMs show minimal accuracy degradation (3.5% decrease in nDCG@10) and significant efficiency improvements over homomorphic encryption.

在医疗、供应链等跨组织协作场景中，共享知识的同时保护数据主权至关重要。现有的安全检索方案存在三大缺陷：
*   **计算开销大：** 传统加密技术（如同态加密）在处理高维向量检索时速度极慢，无法满足实时应用。
*   **架构不匹配：** 以文档为中心的加密方案与现代向量检索（Dense Retrieval）的向量化本质不符，解密过程往往会暴露明文。
*   **隐私泄露风险：** 近期研究表明，向量嵌入（Embeddings）本身会泄露大量语义信息，容易遭受重构攻击。
**Trans-RAG 的核心动机**是建立一种“向量空间语言范式”，让每个组织的知识存在于数学上相互隔离的语义空间中，通过变换查询而非加密文档来实现安全检索。

### 2. 论文提出的方法论
Trans-RAG 移除了传统的文档加密，转而采用**以查询为中心的向量变换（vector2Trans）**。

*   **核心思想：** 为每个组织分配唯一的密钥，将原始向量空间变换为相互“听不懂”的独立坐标系。只有持有特定密钥的查询才能在对应的组织空间内进行有效检索。
*   **关键技术细节（vector2Trans 多阶段变换）：**
    1.  **基于密钥的置换（Permutation）：** 重新排列向量维度，打破坐标间的关联。
    2.  **加密盲化（Cryptographic Blinding）：** 引入与输入相关的零均值噪声，干扰统计分析。
    3.  **有界非线性变换（Bounded Non-linearity）：** 使用 $f_\beta(x) = \tanh(\beta x)/\beta$ 函数，在保持相似性的同时增加逆向工程的难度。
    4.  **正交旋转（Orthogonal Rotation）：** 使用通过密钥生成的正交矩阵进行旋转，确保变换后的空间结构得以保留但坐标完全改变。
    5.  **$L_2$ 归一化：** 确保最终向量在单位超球面上。
*   **工作流程：** 查询编码 $\rightarrow$ 查询变换（针对不同组织生成不同表示） $\rightarrow$ 并行检索 $\rightarrow$ 上下文聚合与重排序 $\rightarrow$ LLM 生成答案。

### 6. 主要结论与发现
*   **高安全性：** 变换后不同组织间的向量空间接近正交（平均夹角 **89.90°**），隔离成功率高达 **99.81%**。
*   **低精度损失：** 相比无保护的检索，nDCG@10 平均仅下降 **3.5%**，在高维模型（如 Stella 8192d）上表现更优。
*   **极高效率：** 相比同态加密，实现了数万倍的加速；相比 AEAD，在大规模数据集（100 万文档）下具有更好的扩展性。
*   **抗攻击性：** 跨组织探测攻击显示，未经授权的查询在异构空间中的检索结果与随机检索无异。

### 7. 优点
*   **范式创新：** 提出了“向量空间语言”概念，将安全问题转化为数学空间隔离问题，非常契合向量数据库的特性。
*   **模型无关性：** 作为一个插件式框架，Trans-RAG 不需要修改现有的嵌入模型或向量数据库架构。
*   **平衡性极佳：** 在保证极高安全性的前提下，将精度损失和计算开销控制在了工业可接受的范围内。

### 8. 不足与局限
*   **超高维计算开销：** 对于极高维度（如 8192 维）的向量，多阶段正交变换的计算复杂度为 $O(nd^2)$，导致查询延迟增加到秒级（约 6s），仍有优化空间。
*   **半诚实模型假设：** 目前主要针对“半诚实”参与者，对于恶意篡改向量数据库或复杂的共谋攻击（Collusion）的防御能力尚需进一步验证。
*   **密钥管理：** 随着组织数量增加，分布式信任建立和密钥生命周期管理的复杂性会上升，论文对此未做深入探讨。
