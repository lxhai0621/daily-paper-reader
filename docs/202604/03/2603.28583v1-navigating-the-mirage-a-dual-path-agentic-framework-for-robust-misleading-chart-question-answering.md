## 摘要
尽管视觉语言模型（VLMs）取得了成功，但由于误导性图表具有欺骗性的视觉结构和扭曲的数据表示，它们仍然是一个重大挑战。我们提出了 ChartCynics，这是一个智能体双路径框架，旨在通过“怀疑式”推理范式揭示视觉欺骗。与整体模型不同，ChartCynics 将感知与验证解耦：诊断视觉路径通过策略性的感兴趣区域（ROI）裁剪捕捉结构异常（如反转轴），而 OCR 驱动的数据路径则确保数值基础。为了解决跨模态冲突，我们引入了一个通过两阶段协议优化的智能体总结器：用于推理蒸馏的 Oracle-Informed SFT 和用于对抗对齐的 Deception-Aware GRPO。该流水线有效地惩罚了视觉陷阱并强制执行逻辑一致性。在两个基准测试上的评估表明，ChartCynics 达到了 74.43% 和 64.55% 的准确率，相比 Qwen3-VL-8B 基座模型实现了约 29% 的绝对性能提升，优于最先进的闭源模型。我们的结果表明，专门的智能体工作流可以赋予较小的开源模型卓越的鲁棒性，为可靠的图表解释奠定了新基础。

## Abstract
Despite the success of Vision-Language Models (VLMs), misleading charts remain a significant challenge due to their deceptive visual structures and distorted data representations. We present ChartCynics, an agentic dual-path framework designed to unmask visual deception via a "skeptical" reasoning paradigm. Unlike holistic models, ChartCynics decouples perception from verification: a Diagnostic Vision Path captures structural anomalies (e.g., inverted axes) through strategic ROI cropping, while an OCR-Driven Data Path ensures numerical grounding. To resolve cross-modal conflicts, we introduce an Agentic Summarizer optimized via a two-stage protocol: Oracle-Informed SFT for reasoning distillation and Deception-Aware GRPO for adversarial alignment. This pipeline effectively penalizes visual traps and enforces logical consistency. Evaluations on two benchmarks show that ChartCynics achieves 74.43% and 64.55% accuracy, providing an absolute performance boost of ~29% over the Qwen3-VL-8B backbone, outperforming state-of-the-art proprietary models. Our results demonstrate that specialized agentic workflows can grant smaller open-source models superior robustness, establishing a new foundation for trustworthy chart interpretation.

论文关注的是**误导性图表问答（Misleading Chart Question Answering, MQA）**。尽管视觉语言模型（VLM）在标准图表理解上表现出色，但在面对故意设计的视觉陷阱（如坐标轴反转、截断坐标轴、不当排序等）时极其脆弱。
*   **研究动机**：现有模型往往产生“认知谄媚”（Cognitive Sycophancy），即过度依赖全局视觉启发式搜索（如线条的物理坡度），而忽略了细微的结构矛盾（如数值刻度），导致其在误导性图表上的表现甚至不如未经训练的人类。
*   **核心挑战**：如何让模型从“被动观察者”转变为“怀疑式审计师”，在视觉趋势与底层数值发生冲突时进行理性仲裁。

#### 2. 方法论：ChartCynics 框架
论文提出了一种名为 **ChartCynics** 的双路径智能体框架，核心思想是将视觉感知与数值验证解耦。
*   **诊断视觉路径（Diagnostic Vision Path）**：
    *   利用图形元素检测模块提取关键区域（ROI），如标题、图例、坐标轴刻度。
    *   通过“盲测”机制（不给模型看问题），强制诊断智能体识别结构异常（如“Y轴从15000开始”），生成行动指令。
*   **OCR 驱动的数据路径（Data Path）**：
    *   将图表序列化为结构化的 Markdown 文本，提取字面数值，绕过视觉误导。
    *   建立动态信任评估，区分高信任度（直接标签）和低信任度（仅靠刻度推断）的数据。
*   **智能体融合与侦探思维链（D-CoT）**：
    *   **五步推理法**：感知审计 -> 数值锚定 -> 欺骗映射 -> 完整性检查 -> 对抗性陷阱拒绝。
*   **两阶段优化协议**：
    *   **Oracle-Informed SFT**：利用大模型（Qwen3-VL-32B）作为教师，结合原始 CSV 数据生成高质量的推理链进行蒸馏。
    *   **Deception-Aware GRPO**：采用群体相对策略优化（GRPO），设计非对称奖励函数——选对加 1 分，掉入视觉陷阱（选了 Trap Answer）重罚 2 分，强制模型学会怀疑。

#### 6. 主要结论与发现

*   **解耦设计**：通过 ROI 裁剪和 OCR 序列化有效解决了 VLM 的“视觉短视”问题。
*   **强化学习创新**：引入非对称奖励（重罚陷阱选项）是应对对抗性视觉样本的有效手段。

*   **OCR 依赖**：数据路径高度依赖 OCR 的准确性，如果图表分辨率极低或文字极度模糊，框架效果可能受限。

*   **欺骗类型覆盖**：虽然涵盖了主流误导手段，但对于更高级的“统计口径欺骗”（如辛普森悖论）等非视觉结构类误导，可能仍需更深层的逻辑推理。
