## 摘要
递归或循环语言模型最近作为一种新的扩展轴出现，通过在潜在状态上迭代优化相同的模型计算来深化推理。我们将这种扩展原则从单一模型扩展到多智能体系统，并提出疑问：智能体协作本身是否可以通过递归进行扩展？为此，我们引入了 RecursiveMAS，这是一个递归多智能体框架，将整个系统建模为统一的潜在空间递归计算。RecursiveMAS 通过轻量级的 RecursiveLink 模块将异构智能体连接为协作循环，从而实现分布内潜在思维生成和跨智能体潜在状态传输。为了优化我们的框架，我们开发了一种内外循环学习算法，通过跨递归轮次的共享基于梯度的信用分配，实现迭代的全系统协同优化。运行复杂度和学习动力学的理论分析表明，RecursiveMAS 比标准的基于文本的多智能体系统（MAS）更高效，并在递归训练期间保持稳定的梯度。在实验上，我们在 4 种具有代表性的智能体协作模式下实例化了 RecursiveMAS，并在涵盖数学、科学、医学、搜索和代码生成的 9 个基准测试中进行了评估。与先进的单/多智能体和递归计算基线相比，RecursiveMAS 一致地实现了 8.3% 的平均准确率提升，同时端到端推理速度提高了 1.2-2.4 倍，Token 使用量减少了 34.6%-75.6%。代码和数据已在 https://recursivemas.github.io 提供。

## Abstract
Recursive or looped language models have recently emerged as a new scaling axis by iteratively refining the same model computation over latent states to deepen reasoning. We extend such scaling principle from a single model to multi-agent systems, and ask: Can agent collaboration itself be scaled through recursion? To this end, we introduce RecursiveMAS, a recursive multi-agent framework that casts the entire system as a unified latent-space recursive computation. RecursiveMAS connects heterogeneous agents as a collaboration loop through the lightweight RecursiveLink module, enabling in-distribution latent thoughts generation and cross-agent latent state transfer. To optimize our framework, we develop an inner-outer loop learning algorithm for iterative whole-system co-optimization through shared gradient-based credit assignment across recursion rounds. Theoretical analyses of runtime complexity and learning dynamics establish that RecursiveMAS is more efficient than standard text-based MAS and maintains stable gradients during recursive training. Empirically, we instantiate RecursiveMAS under 4 representative agent collaboration patterns and evaluate across 9 benchmarks spanning mathematics, science, medicine, search, and code generation. In comparison with advanced single/multi-agent and recursive computation baselines, RecursiveMAS consistently delivers an average accuracy improvement of 8.3%, together with 1.2$\times$-2.4$\times$ end-to-end inference speedup, and 34.6%-75.6% token usage reduction. Code and Data are provided in https://recursivemas.github.io.

*   **研究动机**：虽然单模型可以通过递归计算（在潜空间迭代优化）来深化推理，但现有的多智能体系统大多依赖于**文本中介**的交互。这种方式存在三个主要缺陷：
    1.  **效率低下**：每个智能体必须等待前一个智能体完成文本解码。
    2.  **难以优化**：文本交互阻断了梯度的连续传播，导致无法对整个系统进行端到端的协同训练。

### 2. 方法论：核心思想与关键技术
RecursiveMAS 的核心思想是将每个智能体视为递归计算中的一个“层”，通过潜空间（Latent Space）进行信息流转。

*   **关键技术细节**：
    *   **RecursiveLink 模块**：这是一个轻量级的两层残差投影模块。
        *   **Inner Link（内链）**：在单个智能体内部，将最后一层的隐藏状态映射回输入嵌入空间，支持“潜思维”（Latent Thoughts）的自回归生成。
        *   **Outer Link（外链）**：连接异构智能体（不同模型、不同维度），实现跨模型的潜状态传输。
    *   **递归循环结构**：所有智能体链成一个环路。在 $n$ 轮递归中，智能体仅在潜空间交互，只有在最后一轮的最后一个智能体才会解码输出最终文本。
*   **内外循环学习算法（Inner-Outer Loop Learning）**：
    *   **内循环（模型级）**：预训练每个智能体的 Inner Link，使其生成的潜思维在语义分布上与原模型的输入嵌入对齐。
    *   **外循环（系统级）**：在整个递归路径上进行协同优化。通过跨递归轮次的梯度回传，为每个 RecursiveLink 分配信用（Credit Assignment），使系统学会如何通过迭代协作来修正错误。
*   **理论支撑**：论文通过数学证明展示了 RecursiveMAS 在运行复杂度上优于文本 MAS（将 $O(|V|)$ 的词表解码开销降为 $O(d_h^2)$ 的投影开销），并证明了潜空间连接能保持梯度稳定性，避免文本交互导致的梯度消失。

### 6. 主要结论与发现
1.  **性能提升**：RecursiveMAS 在所有基准测试中平均准确率提升 **8.3%**，在 AIME 等高难度推理任务上优势更明显。

### 7. 优点（亮点）

*   **系统级优化**：内外循环训练方案解决了多智能体系统难以整体协同进化的痛点。
*   **结构无关性**：该框架可以无缝适配各种现有的 MAS 拓扑结构。

### 8. 不足与局限
*   **可解释性挑战**：由于智能体之间在潜空间通信，人类无法直接监控中间协作的自然语言过程（虽然最终输出是文本）。

*   **任务覆盖**：实验主要集中在逻辑推理和知识问答类任务，对于需要大量长文本生成的创造性写作等任务，潜空间压缩是否会造成信息丢失尚待验证。
