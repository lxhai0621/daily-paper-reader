## 摘要
具有长上下文窗口的大语言模型可以直接根据完整的学术、技术和政策文档回答复杂问题，但传递整个文档通常成本高昂、速度缓慢，并可能降低回答质量，同时增加不必要的数据泄露风险。本文针对在长文档中回答多个异构问题的常见场景，在这种场景下，由于文档结构的多样性和查询与分块（query-chunk）之间微弱的语义相似性，固定位置启发式方法和标准的检索增强生成（RAG）往往会失效，这通常需要对嵌入检索器进行针对特定任务和领域的微调。我们提出了选择性注意力引导提取（Selective Attention-Guided Extraction，简称 SAGE），这是一个无需训练、即插即用的上下文压缩框架。它利用轻量级本地 LLM 进行单次预填充，并将语言模型的注意力信号转换为可配置粒度的查询相关性热图。SAGE 进一步引入了差分注意力策略，以更好地隔离与问题相关的证据，然后在用户定义的 Token 预算下选择得分最高的单元，并仅将这些缩减后的上下文转发给下游 LLM 进行答案生成。SAGE 在多个长文档问答基准测试中超越了传统的压缩技术，特别是在仅受限于 10% 上下文预算的情况下，在 QuALITY-hard 上获得了前四名的排名。这实现了 90% 的 Token 削减并保持了具有竞争力的准确性，且无需模型微调或复杂的校准。

## Abstract
Large language models with long context windows can answer complex questions directly from full-length academic, technical, and policy documents, but passing entire documents is often costly, slow, and can degrade answer quality while increasing the risk of unnecessary data leakage. This paper targets the common setting of answering many heterogeneous questions over long document(s), where fixed position heuristics and standard retrieval-augmented generation (RAG) can fail due to document structure variability and weak query-chunk semantic similarity, which often requires task- and domain-specific tuning of embedding retrievers. We propose {Selective Attention-Guided Extraction} (\ourmethod), a training-free, plug-and-play context reduction framework that uses a lightweight local LLM to perform a single prefilling pass and convert language model attention signals into a query-specific relevance heatmap at configurable granularities. \ourmethod\ further introduces \emph{differential attention} strategies to better isolate question-relevant evidence, then selects the top-scoring units under a user-defined token budget and forwards only this reduced context to a downstream LLM for answer generation. \ourmethod\ surpasses traditional reduction techniques across multiple long-document QA benchmarks, notably securing a top-4 rank on QuALITY-hard while constrained to a 10\% context budget. This enables a 90\% reduction in tokens with competitive accuracy, without the need for model fine-tuning or complex calibration.

#### 1. 核心问题与整体含义（研究动机和背景）
随着长上下文大语言模型（LLM）的应用增加，直接处理全文本面临**高昂成本、响应延迟、准确性下降（干扰信息多）以及隐私泄露**等挑战。传统的上下文缩减方法存在局限：
*   **固定位置启发式：** 无法适应多变的文档结构。
*   **标准 RAG（检索增强生成）：** 依赖嵌入向量的语义相似性，在缺乏关键词匹配或证据分散（如推理题）时效果较差。
*   **提示词压缩：** 往往需要特定领域的微调，且可能导致语义扭曲。

**SAGE** 的研究动机是开发一种**无需训练、即插即用**的框架，通过利用模型自身的注意力信号，在严格的 Token 预算内提取最相关的上下文。

#### 2. 方法论：核心思想与关键技术
SAGE 的核心思想是利用轻量级本地 LLM 的**预填充（Prefilling）阶段产生的注意力权重**作为相关性指标。

*   **分块注意力计算（Chunked Attention）：** 将长文档切分为块，利用本地 LLM 计算查询（Query）对文档 Token 的注意力得分。
*   **块长度归一化（Length Normalization）：** 解决 Softmax 机制导致的短块 Token 得分被异常放大的问题，确保全文档尺度下的得分一致性。
*   **差分注意力（Differential Attention）：** 这是 SAGE 的关键创新。通过计算“目标查询”与“对比查询”（如“请重复上下文”或语义最远的另一个问题）之间的注意力差值，抵消掉文档中如页眉、格式化字符等结构性噪声，突出查询特有的证据。
*   **KV 缓存复用：** 针对同一文档的多个问题，缓存文档块的 KV 状态，避免重复编码，提升效率。
*   **单元窗口选择（Unit-Window Selection）：** 在给定 Token 预算下，通过滑动窗口选择得分最高的连续文本段，保证提取内容的语义连贯性。

#### 7. 优点（亮点）
*   **无需训练：** 纯推理侧优化，直接适配现有的预训练模型。
*   **预算可控：** 允许用户精确定义 Token 预算，便于成本控制。
*   **细粒度：** 相比于 RAG 的块级检索，SAGE 能实现 Token 级的相关性感知。
*   **去噪能力：** 差分注意力机制巧妙地解决了 Transformer 容易被结构性 Token 吸引注意力的问题。

#### 8. 不足与局限
*   **预填充开销：** 虽然避免了昂贵的解码生成，但仍需对全文档进行一次预填充扫描，对于极长文档仍有计算门槛。
*   **重复实体干扰：** 在包含大量重复实体（如多个 ZIP 代码）的文档中，随着预算增加，可能会引入干扰项导致精度下降。
*   **对比查询依赖：** 差分效果取决于对比查询的选择，在单问题场景下可能难以找到最佳的对比基准。
