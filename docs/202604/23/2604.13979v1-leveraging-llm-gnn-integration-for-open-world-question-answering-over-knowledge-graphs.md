## 摘要
知识图谱（KG）上的开放世界问答（OW-QA）旨在针对不完整或不断演化的知识图谱进行问答。传统的 KGQA 假设一个封闭世界，即答案必须存在于知识图谱中，这限制了其在现实世界中的适用性。相比之下，开放世界问答需要根据图结构和上下文推断缺失的知识。大语言模型（LLM）擅长语言理解，但缺乏结构化推理能力；图神经网络（GNN）能够对图拓扑进行建模，但在语义解释方面存在困难。现有系统将 LLM 与 GNN 或图检索器相结合。一些系统虽然支持开放世界问答，但依赖于缺乏语义基础的结构化嵌入。大多数系统假设存在观测路径或完整图，这使得它们在链路缺失或多跳推理的情况下变得不可靠。我们提出了 GLOW，这是一个结合了预训练 GNN 和 LLM 的混合系统，用于开放世界 KGQA。GNN 根据图结构预测前 k 个候选答案。这些候选答案与相关的知识图谱事实一起被序列化为结构化提示（如三元组和候选词），以引导 LLM 的推理。这实现了对符号信号和语义信号的联合推理，且无需依赖检索或微调。为了评估泛化能力，我们引入了 GLOW-BENCH，这是一个包含 1,000 个问题的基准测试，涵盖了不同领域的不完整知识图谱。GLOW 在标准基准测试和 GLOW-BENCH 上的表现优于现有的 LLM-GNN 系统，最高提升达 53.3%，平均提升 38%。GitHub 代码和数据已公开。

## Abstract
Open-world Question Answering (OW-QA) over knowledge graphs (KGs) aims to answer questions over incomplete or evolving KGs. Traditional KGQA assumes a closed world where answers must exist in the KG, limiting real-world applicability. In contrast, open-world QA requires inferring missing knowledge based on graph structure and context. Large language models (LLMs) excel at language understanding but lack structured reasoning. Graph neural networks (GNNs) model graph topology but struggle with semantic interpretation. Existing systems integrate LLMs with GNNs or graph retrievers. Some support open-world QA but rely on structural embeddings without semantic grounding. Most assume observed paths or complete graphs, making them unreliable under missing links or multi-hop reasoning. We present GLOW, a hybrid system that combines a pre-trained GNN and an LLM for open-world KGQA. The GNN predicts top-k candidate answers from the graph structure. These, along with relevant KG facts, are serialized into a structured prompt (e.g., triples and candidates) to guide the LLM's reasoning. This enables joint reasoning over symbolic and semantic signals, without relying on retrieval or fine-tuning. To evaluate generalization, we introduce GLOW-BENCH, a 1,000-question benchmark over incomplete KGs across diverse domains. GLOW outperforms existing LLM-GNN systems on standard benchmarks and GLOW-BENCH, achieving up to 53.3% and an average 38% improvement. GitHub code and data are available.

### 2. 方法论
*   **核心思想**：利用预训练的 GNN 预测候选答案，并将其作为“软引导”信号，连同查询实体的局部子图事实一起输入给 LLM，由 LLM 进行最终的语义与结构联合推理。
*   **关键技术流程**：
    1.  **问题理解与链接**：使用 LLM 提取问题中的实体和关系，并通过 SPARQL 查询将其映射到 KG 模式（Schema）。
    2.  **知识检索**：检索目标实体的 1-hop 三元组（提供语义背景）和所有可能的候选标签。
    3.  **GNN 预测**：针对特定的问题模式（如“蛋白质→物种”），调用预训练的 GNN 节点分类模型，输出 Top-K 个候选答案。
    4.  **提示词增强与生成**：将问题、局部子图三元组、GNN 预测结果和候选列表序列化为结构化 Prompt。
*   **变体设计**：
    *   **GLOW-G**：仅提供图上下文（三元组）。
    *   **GLOW-N**：仅提供 GNN 预测结果。
    *   **GLOW-GN**：混合模式（效果最佳）。

*   **实验规模**：在 4 个大型 KG 和多个基准数据集上进行了测试，涵盖了从通用领域到生物医学等专业领域。
*   **分析维度**：论文进行了消融实验（不同变体对比）、Top-K 敏感度分析、知识领域影响分析、多选题选项数量影响分析以及 GNN 错误传播分析。
*   **充分性评价**：实验设计较为全面，不仅对比了开源模型，还对比了商业闭源模型（GPT-4o-mini, DeepSeek-V3），并引入了人工验证环节，确保了评估的客观性。

### 6. 主要结论与发现
*   **性能领先**：GLOW-GN 在所有基准上均优于现有系统，平均性能提升约 **38%**，最高提升 **53.3%**。
*   **纠错能力**：即使 GNN 预测准确率较低（<50%），GLOW 仍能通过 LLM 的语义能力修正 GNN 的错误，比 AskGNN 更具鲁棒性。
*   **语义对齐**：层次匹配（HM）结果显示，LLM 经常给出语义正确但字面不符的答案，GLOW 能有效引导 LLM 给出更精确的术语。
*   **Top-K 影响**：当 GNN 提供的候选答案 K=3 时效果最好，过多的候选词会干扰 LLM 推理。

### 7. 优点
*   **无需微调 LLM**：通过模块化设计，解耦了 GNN 和 LLM，降低了适配新领域或新模型的成本。
*   **处理缺失链路**：不依赖于完整的检索路径，在知识图谱高度不完整时依然有效。
*   **多跳推理**：通过语义解析和子图序列化，支持比现有开放世界方法更复杂的 2 跳推理。
*   **基准贡献**：发布的 GLOW-BENCH 为 OW-KGQA 领域提供了更具挑战性的多跳、跨领域测试集。

### 8. 不足与局限
*   **数据质量依赖**：如果 KG 中的节点和边缘描述极度匮乏（过于稀疏），系统的语义关联能力会受限。
*   **GNN 依赖性**：虽然有纠错机制，但系统性能的上限仍部分受限于预训练 GNN 的分类质量。
*   **任务局限**：目前主要将问答转化为“节点分类”任务，对于更复杂的“链路预测”或生成式长文本回答的覆盖可能不足。
