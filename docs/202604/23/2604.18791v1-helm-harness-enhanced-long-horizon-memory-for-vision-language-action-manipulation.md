## 摘要
视觉-语言-动作（VLA）模型尽管在短程任务中表现强劲，但在长程操纵任务中却表现出系统性的失效。我们表明，在当前的反应式执行设置下，仅靠延长上下文长度无法解决这一失效问题；相反，它源于执行循环中反复出现的三个缺陷：记忆鸿沟（memory gap）、验证鸿沟（verification gap）和恢复鸿沟（recovery gap）。我们提出了 HELM，这是一个与模型无关的框架，通过三个组件解决这些缺陷：一个通过 CLIP 索引关键帧检索关键任务历史的情景记忆模块（EMM）；一个学习得到的状态验证器（SV），它根据观测、动作、子目标和记忆调节的上下文在执行前预测动作失败；以及一个执行回滚和重规划的 Harness 控制器（HC）。SV 是核心的学习贡献：它始终优于基于规则的可行性检查和集成不确定性基准，且其有效性关键取决于对情景记忆的访问。在 LIBERO-LONG 数据集上，HELM 将任务成功率比 OpenVLA 提高了 23.1 个百分点（从 58.4% 提升至 81.5%），而将上下文窗口延长至 H=32 仅带来 5.4 个百分点的提升，且同等预算下的 LoRA 适配仍比 HELM 低 12.2 个百分点。HELM 还提高了在 CALVIN 上的长程任务表现，并在受控扰动下显著提升了恢复成功率。消融实验和机制分析分离了各组件的贡献，我们发布了 LIBERO-Recovery，这是一个用于评估长程操纵中故障恢复的扰动注入协议。

## Abstract
Vision-Language-Action (VLA) models fail systematically on long-horizon manipulation tasks despite strong short-horizon performance. We show that this failure is not resolved by extending context length alone in the current reactive execution setting; instead, it stems from three recurring execution-loop deficiencies: the memory gap, the verification gap, and the recovery gap. We present HELM, a model-agnostic framework that addresses these deficiencies with three components: an Episodic Memory Module (EMM) that retrieves key task history via CLIP-indexed keyframes, a learned State Verifier (SV) that predicts action failure before execution from observation, action, subgoal, and memory-conditioned context, and a Harness Controller (HC) that performs rollback and replanning. The SV is the core learning contribution: it consistently outperforms rule-based feasibility checks and ensemble uncertainty baselines, and its effectiveness depends critically on access to episodic memory. On LIBERO-LONG, HELM improves task success rate by 23.1 percentage points over OpenVLA (58.4% to 81.5%), while extending the context window to H=32 yields only a 5.4-point gain and same-budget LoRA adaptation remains 12.2 points below HELM. HELM also improves long-horizon performance on CALVIN and substantially boosts recovery success under controlled perturbations. Ablations and mechanism analyses isolate the contribution of each component, and we release LIBERO-Recovery as a perturbation-injection protocol for evaluating failure recovery in long-horizon manipulation.

### 1. 核心问题与整体含义
*   **研究背景**：视觉-语言-动作（VLA）模型在短程任务中表现出色，但在长程操纵任务中成功率大幅下降。
*   **核心发现**：长程任务的失效并非单纯因为上下文长度不足，而是源于三个结构性缺陷：
    1.  **记忆鸿沟 (FM)**：固定窗口丢弃了已完成子目标的证据，导致模型重复执行已完成动作。
    2.  **验证鸿沟 (FV)**：动作执行前缺乏可行性检查，导致错误动作静默执行并传播。
    3.  **恢复鸿沟 (FR)**：一旦发生错误，模型无法检测并继续在损坏的状态下运行，引发连锁反应。
*   **研究动机**：通过引入一个模型无关的增强框架（HELM），在不改变VLA骨干模型的前提下，通过外部闭环机制解决上述三大鸿沟。

### 2. 方法论
HELM 框架由三个核心组件构成，形成“检索-提议-验证-执行/恢复”的循环：
*   **情景记忆模块 (EMM)**：
    *   使用 CLIP (ViT-B/32) 提取关键帧特征并建立键值对存储。
    *   **写入策略**：在子目标完成、检测到失败或每隔20步时记录状态。
    *   **检索**：基于余弦相似度检索 Top-k 历史关键帧，并将其序列化为文本注入 VLA 的语言输入中。
*   **状态验证器 (SV)**：
    *   **核心创新**：一个轻量级 MLP 模块，用于在动作执行前预测失败概率 $p_{fail}$。
    *   **输入**：当前观测特征、检索到的记忆特征、提议的动作向量以及子目标文本嵌入。
    *   **关键点**：SV 的有效性高度依赖于记忆上下文，使其能识别出语义上的逻辑错误（如重复放置）。
*   **Harness 控制器 (HC)**：
    *   维护子目标堆栈。若 SV 预测失败，则触发回滚（Rollback）至最近的成功检查点，或进行重规划（Forward Recovery）。

### 3. 实验设计
*   **数据集/场景**：
    *   **LIBERO-LONG**：包含10个任务，平均5.8个子目标。
    *   **CALVIN (ABC→D)**：测试跨环境的长程任务迁移能力。
    *   **LIBERO-Recovery (新协议)**：作者提出的新基准，通过在子目标边界注入随机扰动（如物体位移、夹具状态翻转）来评估恢复能力。
*   **对比方法 (Baselines)**：
    *   基础模型：OpenVLA (H=8, 32, 64), Octo。
    *   增强变体：Oracle Memory（真值记忆上限）、Rule Verifier（基于规则的校验）、Ensemble (5x 集成不确定性)、LoRA (同等数据预算下的微调)、Reflexion (自我反思)。

### 4. 资源与算力
*   **硬件使用**：实验在一张 **NVIDIA A100 (80GB)** GPU 上运行。
*   **训练时长**：状态验证器 (SV) 的训练仅需约 **2 小时**（基于 50K 步的 Rollout 数据）。
*   **推理开销**：每步增加约 **12ms** 的延迟，相比骨干模型仅增加约 15% 的计算负担。

### 5. 实验数量与充分性
*   **实验规模**：主实验涵盖了 2 个主流基准和 1 个新提出的恢复基准；消融实验针对 EMM、SV、回滚机制分别进行了剥离测试。
*   **充分性与公平性**：
    *   对比了 9 种基准方法，特别是包含了“同等数据预算下的 LoRA 微调”，证明了 HELM 架构优于单纯的模型微调。
    *   所有实验均采用 3 个随机种子并报告标准差，确保了结果的客观性。
    *   通过对 83 个失败案例的人工标注（Cohen’s κ=0.81），验证了失效分类的科学性。

### 6. 主要结论与发现
*   **性能飞跃**：在 LIBERO-LONG 上，HELM 将 OpenVLA 的成功率从 **58.4% 提升至 81.5%**（+23.1 pp）。
*   **长上下文局限性**：将上下文窗口从 8 增加到 64，成功率仅提升至 65.1%，证明单纯增加 Context 无法解决结构性失效。
*   **SV 的优越性**：学习得到的 SV 优于基于规则的校验（+8.4 pp vs +6.8 pp），且在推理成本远低于集成方法的情况下达到了相近甚至更优的效果。
*   **恢复能力**：在注入扰动的测试中，HELM 的恢复成功率 (RSR) 达到 54.2%，远超原始模型的 12.3%。

### 7. 优点
*   **模块化与通用性**：作为“插件”式框架，可适配不同的 VLA 骨干模型（如 OpenVLA, Octo）。
*   **预执行干预**：不同于事后反思（Reflexion），SV 在错误发生前进行拦截，极大地保护了任务状态。
*   **高效性**：通过轻量级 MLP 和 CLIP 检索实现，训练和推理成本极低，适合机器人实时控制。

### 8. 不足与局限
*   **数据依赖性**：SV 的训练需要目标环境的 Rollout 数据，这限制了其在完全陌生环境下的零样本部署能力。
*   **回滚假设**：回滚机制假设环境动作是可逆的或可重置的，在某些现实物理场景（如液体倾倒、物体破碎）中难以实现。
*   **Sim-to-Real 挑战**：实验主要在仿真环境中完成，真实世界的传感器噪声和视觉偏移可能影响 CLIP 检索和 SV 的准确性。
