## 摘要
检索增强生成（RAG）通过外部视觉知识扩展了大视觉语言模型（LVLMs）。然而，现有的视觉 RAG 系统通常依赖于通用的检索信号，忽略了复杂推理所必需的细粒度视觉语义。为了解决这一局限性，我们提出了 UniDoc-RL，这是一个统一的强化学习框架，其中 LVLM 智能体共同执行检索、重排序、主动视觉感知和推理。UniDoc-RL 将视觉信息获取建模为具有分层动作空间的序列决策问题。具体而言，它将视觉证据从粗粒度的文档检索逐步细化为细粒度的图像选择和主动区域裁剪，使模型能够抑制无关内容并关注信息密集区域。为了实现有效的端到端训练，我们引入了一种密集多奖励方案，为每个动作提供任务感知的监督。基于群体相对策略优化（GRPO），UniDoc-RL 在不依赖独立价值网络的情况下，使智能体行为与多个目标保持一致。为了支持这种训练范式，我们策划了一个包含细粒度动作标注的高质量推理轨迹综合数据集。在三个基准测试上的实验表明，UniDoc-RL 持续超越了最先进的基准模型，相比之前的基于强化学习的方法提升了高达 17.7%。

## Abstract
Retrieval-Augmented Generation (RAG) extends Large Vision-Language Models (LVLMs) with external visual knowledge. However, existing visual RAG systems typically rely on generic retrieval signals that overlook the fine-grained visual semantics essential for complex reasoning. To address this limitation, we propose UniDoc-RL, a unified reinforcement learning framework in which an LVLM agent jointly performs retrieval, reranking, active visual perception, and reasoning. UniDoc-RL formulates visual information acquisition as a sequential decision-making problem with a hierarchical action space. Specifically, it progressively refines visual evidence from coarse-grained document retrieval to fine-grained image selection and active region cropping, allowing the model to suppress irrelevant content and attend to information-dense regions. For effective end-to-end training, we introduce a dense multi-reward scheme that provides task-aware supervision for each action. Based on Group Relative Policy Optimization (GRPO), UniDoc-RL aligns agent behavior with multiple objectives without relying on a separate value network. To support this training paradigm, we curate a comprehensive dataset of high-quality reasoning trajectories with fine-grained action annotations. Experiments on three benchmarks demonstrate that UniDoc-RL consistently surpasses state-of-the-art baselines, yielding up to 17.7% gains over prior RL-based methods.

### 1. 核心问题与整体含义（研究动机和背景）
现有的视觉检索增强生成（Visual RAG）系统主要面临三个挑战：
*   **检索精度不足**：通用检索器往往只进行粗粒度匹配，难以捕捉复杂推理所需的细粒度语义，导致引入无关上下文并引发幻觉。
*   **视觉利用率低**：现有方法多为“被动消费”，直接将整张图像输入模型，忽略了图像中存在的大量冗余背景，浪费了上下文容量。
*   **优化困难（稀疏奖励）**：传统的强化学习（RL）方法通常只根据最终答案给出奖励（Outcome Reward），导致中间步骤（如检索、裁剪）难以获得明确的信用分配（Credit Assignment）。

**UniDoc-RL** 旨在通过一个统一的强化学习框架，将视觉 RAG 建模为“搜索-选择-感知-推理”的分层决策过程，实现从粗到精的信息获取。

### 2. 方法论：核心思想与技术细节
UniDoc-RL 将 LVLM 智能体置于一个“思考-动作-观察”的循环中，核心技术包括：

*   **分层动作空间（Hierarchical Action Space）**：
    1.  **图像搜索（Search）**：调用外部工具进行粗粒度候选文档检索。
    2.  **精确选择（Select）**：由 LVLM 对候选图进行语义重排序和筛选，过滤文档级噪声。
    3.  **视觉感知（Perceive）**：通过 `<bbox>` 动作主动定位关键区域，执行裁剪（Crop）和缩放（Zoom），模拟人类视觉注意力。
*   **密集多奖励机制（Dense Multi-Rewards）**：
    *   **检索奖励 ($r_{ir}$)**：基于 NDCG 评估检索列表的质量。
    *   **选择奖励 ($r_{sel}$)**：评估模型是否选中了包含答案的正确图像。
    *   **感知奖励 ($r_{crop}$)**：计算预测裁剪框与真实区域（Ground Truth）的交并比（IoU）。
    *   **模式奖励 ($r_{pat}$)**：确保模型遵循预定义的 XML 标签格式。
    *   **结果奖励 ($rans$)**：由奖励模型评估最终答案的正确性。
*   **训练算法**：采用 **GRPO（群体相对策略优化）**。该算法通过组内样本的相对得分来估计优势函数，无需独立的价值网络（Value Network），节省了显存并简化了训练。
*   **数据合成**：利用 Qwen3-VL-235B 作为教师模型，结合 Mineru 布局分析工具，自动合成了包含 1.2 万条 SFT 轨迹和 5500 余条 RL 轨迹的高质量数据集。

*   **实验规模**：在三个主流基准上进行了全面测试，涵盖了单跳、多跳、逻辑推理及多种视觉元素（文本、表格、图表、布局）。
*   **消融实验**：分别验证了“选择动作”和“感知动作”的有效性，并对各项奖励函数（NDCG、IoU 等）的贡献进行了拆解。

### 6. 主要结论与发现
*   **性能领先**：UniDoc-RL 在所有基准上均取得 SOTA，相比之前的 RL 方法（VRAG-RL），在 3B 模型上提升了 **17.5%**，在 7B 模型上提升了 **17.7%**。
*   **RL 的作用**：RL 不仅提高了答案准确率，还显著改变了模型的行为模式——使其从 SFT 阶段的“被动全图阅读”转变为“主动工具调用（频繁且精准的裁剪）”。
*   **分层动作的必要性**：精确选择动作显著提高了检索召回率（如 SlideVQA 从 79.7% 提升至 85.0%），为后续推理提供了更高质量的上下文。

### 7. 优点
*   **拟人化设计**：通过“搜索-选择-感知”的层级结构，成功模拟了人类处理复杂视觉文档时的注意力分配过程。
*   **密集监督**：解决了 RAG 流程中中间步骤难以优化的痛点，通过 IoU 和 NDCG 奖励实现了端到端的精准对齐。
*   **高质量资源贡献**：开源了包含细粒度动作标注的推理轨迹数据集，对社区具有重要价值。

### 8. 不足与局限
*   **数据依赖**：训练轨迹高度依赖于强大的教师模型（如 Qwen3-VL-235B）和布局分析工具（Mineru），对于缺乏此类资源的研究者较难复现数据生成过程。
*   **计算开销**：虽然 GRPO 节省了价值网络的显存，但多轮迭代交互（Multi-round interaction）在推理时会增加延迟和计算成本。
*   **泛化边界**：实验主要集中在文档类图像，对于自然场景图像或极长视频流的 RAG 效果尚待进一步验证。
