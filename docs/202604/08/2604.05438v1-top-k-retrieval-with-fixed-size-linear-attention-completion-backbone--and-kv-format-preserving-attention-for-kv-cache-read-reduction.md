## 摘要
长上下文生成日益受到解码时键值（KV）缓存传输流量的限制，特别是当 KV 缓存被卸载到 GPU 显存之外时。查询感知检索（如 Top-K 选择）通过仅加载 KV 对的子集来减少此类流量，但当注意力权重分散在未检索到的标记上时，对该子集进行 softmax 重新归一化会引入偏差。我们提出了一种检索-补全注意力模块，该模块保持骨干网络权重和 KV 缓存格式不变。对于每个查询，我们计算针对 sink/tail 锚点和查询相关的 Top-K 检索标记的精确注意力，并利用预填充阶段计算的固定大小特征图摘要来估计剩余中间区域的分子和分母。我们在未归一化域中将精确贡献和估计贡献相加，并执行单次归一化，从而在不增加额外注意力侧 KV 读取的情况下恢复缺失的 softmax 权重。在长上下文基准测试中，所提方法在相同的等效标记读取预算下优于仅进行选择的 Top-K 方法，且在高熵注意力头中增益最为显著。

## Abstract
Long-context generation is increasingly limited by decode-time key-value (KV) cache traffic, particularly when KV is offloaded beyond GPU memory. Query-aware retrieval (e.g., Top-K selection) reduces this traffic by loading only a subset of KV pairs, but renormalizing the softmax over the subset introduces bias when attention mass is spread over unretrieved tokens. We propose a retrieval-completion attention module that keeps backbone weights and the KV-cache format unchanged. For each query, we compute exact attention over sink/tail anchors and the query-dependent retrieved Top-K tokens, and estimate the remaining mid-region numerator and denominator using a fixed-size feature-map summary computed at prefill time. We add the exact and estimated contributions in the unnormalized domain and apply a single normalization, recovering the missing softmax mass without additional attention-side KV reads. Across long-context benchmarks, the proposed method improves over selection-only Top-K at matched token-equivalent read budgets, with the largest gains in high-entropy heads.

#### 1. 论文的核心问题与整体含义（研究动机和背景）
在长文本生成任务中，Transformer 模型的解码速度主要受限于 **KV 缓存（KV Cache）的内存访问带宽**（即 Memory-bound），而非计算能力。当上下文极长且 KV 缓存被卸载（Offload）到 CPU 内存或 SSD 时，这一瓶颈尤为突出。
*   **现有方案的缺陷**：目前的查询感知检索方法（如 Top-K 检索）通过只加载一小部分 KV 对来减少流量，但这种“子集归一化”会导致 Softmax 偏置。当注意力权重分布较分散（高熵）时，忽略掉的令牌会显著降低模型精度。
*   **核心目标**：在**不改变骨干模型权重**且**不改变 KV 缓存格式**的前提下，通过一种“检索-补全”机制，在减少 KV 读取量的同时，找回缺失的注意力权重，提高长文本生成的准确性。

#### 2. 论文提出的方法论：检索-补全注意力机制（Retrieval-Completion Attention）
核心思想是将注意力计算划分为精确计算部分和估计补全部分，并在非归一化域进行合并。
*   **区域划分**：将预填充（Prefill）序列分为：
    1.  **锚点区（Anchors）**：包括起始的 Sink 令牌和末尾的 Tail 令牌，始终进行精确计算。
    2.  **中间区（Mid Region）**：应用 Top-K 检索。
*   **关键技术细节**：
    1.  **固定大小摘要（Completion Cache）**：在预填充阶段，利用学习到的正向特征图（Positive Feature Maps, $\phi$）为中间区生成一个固定大小的线性注意力摘要（包含分子和分母）。
    2.  **减法补全（Subtractive Completion）**：在解码时，从摘要中减去已被 Top-K 检索到的令牌的特征贡献，确保补全项仅针对“未被检索”的令牌。
    3.  **单次归一化合并**：在非归一化域（Unnormalized Domain）将精确计算的项（锚点 + Top-K 令牌）与补全估计项相加，最后进行一次统一的 Softmax 归一化。
*   **蒸馏训练**：通过蒸馏学习（Distillation）训练头相关的特征图 $\phi$，使其在对数空间内尽可能逼近原始 Softmax 核函数的分布。

#### 6. 论文的主要结论与发现
*   **精度提升**：在相同的 KV 读取预算下，补全机制显著优于纯 Top-K 检索，尤其是在 Llama 模型上。
*   **熵的影响**：补全机制的增益与注意力头的熵呈正相关。在注意力分布分散（高熵）的头中，补全机制能有效找回丢失的权重；而在注意力集中的头中，Top-K 已足够。
*   **模型差异**：不同模型对检索的敏感度不同。Qwen3 本身对 Top-K 检索的容忍度较高，因此补全机制带来的提升相对较小。
*   **I/O 权衡**：当 KV 缓存卸载到慢速介质（如 SSD）时，该方法通过减少检索数量换取补全计算，能实现端到端的加速。

#### 7. 优点
*   **非侵入性**：无需重新训练原始 LLM，不改变现有的 KV 缓存存储格式，易于集成到 vLLM 等现有推理框架中。
*   **理论严谨**：通过减法操作解决了线性注意力补全中的重复计算问题，并利用单次归一化修正了偏置。
*   **效率平衡**：在长序列下，固定大小的摘要成本被分摊，显著降低了长上下文解码的 I/O 压力。

#### 8. 不足与局限
*   **计算开销**：虽然减少了 I/O，但增加了特征图计算和减法操作的计算量，在计算受限（Compute-bound）的场景下可能无优势。
*   **模型依赖性**：特征图需要针对特定模型进行蒸馏训练，且不同模型间的收益差异较大。
*   **一次性成本**：在生成长度极短的情况下，读取补全摘要的一次性开销可能抵消其带来的 I/O 节省。
*   **检索器依赖**：实验主要基于理想的 Top-K 检索，实际应用中若使用近似最近邻搜索（ANNS），其误差可能与补全机制产生复杂的交互。
