## 摘要
知识库（KB）在各种应用中发挥着关键作用。作为两个代表性的知识库相关任务，知识库补全（KBC）和知识库问答（KBQA）紧密相关且在本质上互补。因此，解决 KBC 和 KBQA 的联合任务以使它们相互增强将是大有裨益的。然而，现有的研究通常依赖小语言模型（SLM）来共同增强它们，而忽略了大语言模型（LLM）强大的推理能力。在本文中，通过结合 LLM 与 SLM 的优势，我们提出了一个名为 JCQL 的新颖框架，该框架能够以迭代的方式使这两个任务相互增强。为了让 KBC 增强 KBQA，我们将 SLM 训练的 KBC 模型作为智能体的一个动作，从而扩充了基于 LLM 智能体的 KBQA 模型的推理路径，缓解了 LLM 在 KBQA 中的幻觉和高计算成本问题。为了让 KBQA 增强 KBC，我们利用 KBQA 的推理路径作为补充训练数据，对 KBC 模型进行增量微调，从而提升了 SLM 在 KBC 任务中的能力。在两个公开基准数据集上的广泛实验表明，JCQL 在 KBC 和 KBQA 任务上均优于所有基准模型。

## Abstract
Knowledge Bases (KBs) play a key role in various applications. As two representative KB-related tasks, knowledge base completion (KBC) and knowledge base question answering (KBQA) are closely related and inherently complementary with each other. Thus, it will be beneficial to solve the task of joint KBC and KBQA to make them reinforce each other. However, existing studies usually rely on the small language model (SLM) to enhance them jointly, and the large language model (LLM)'s strong reasoning ability is ignored. In this paper, by combining the strengths of the LLM with the SLM, we propose a novel framework JCQL, which can make these two tasks enhance each other in an iterative manner. To make KBC enhance KBQA, we augment the LLM agent-based KBQA model's reasoning paths by incorporating an SLM-trained KBC model as an action of the agent, alleviating the LLM's hallucination and high computational costs issue in KBQA. To make KBQA enhance KBC, we incrementally fine-tune the KBC model by leveraging KBQA's reasoning paths as its supplementary training data, improving the ability of the SLM in KBC. Extensive experiments over two public benchmark data sets demonstrate that JCQL surpasses all baselines for both KBC and KBQA tasks.

*   **研究动机**：KBC 和 KBQA 具有天然的互补性——KBC 补全的知识能帮助 KBQA 找到答案，而 KBQA 的推理路径可以作为新知识反馈给 KBC。
*   **现有局限**：

    2.  近期基于大语言模型（LLM）的方法虽然推理能力强，但面临**幻觉问题**（生成不存在的事实）和**高昂的计算成本**（频繁调用 API）。
*   **核心目标**：提出 **JCQL** 框架，通过结合 LLM 的推理能力和 SLM 的专业性/低成本，实现两个任务的迭代式相互增强。

### 2. 方法论：核心思想与关键技术
JCQL 的核心思想是建立一个 LLM 智能体（Agent）与 SLM 模型的闭环互动机制：

*   **KBC $\rightarrow$ KBQA（SLM 增强 LLM）**：
    *   将 SLM 训练的 KBC 模型集成到 LLM Agent 的动作空间中，定义为 `complete(entity, relation)` 动作。
    *   当 LLM 在推理过程中发现知识库缺失三元组时，调用 SLM 进行预测。这利用了 SLM 对结构化知识的精确掌握，缓解了 LLM 的幻觉。
*   **KBQA $\rightarrow$ KBC（LLM 增强 SLM）**：
    *   利用 LLM Agent 在解决问答任务时生成的**推理路径**（Reasoning Paths）作为补充训练数据。
    *   通过**增量微调（Incremental Fine-tuning）**技术更新 SLM。为了防止“灾难性遗忘”，引入了**经验回放（Experience Replay）**策略，在微调时随机采样原始训练集的三元组。
*   **LLM Agent 的动作空间**：
    1.  `search`：在 KB 中搜索实体的邻居。
    2.  `generate`：利用 LLM 内部知识生成子问题或缺失三元组。
    3.  `complete`：调用 SLM 补全缺失的尾实体。
    4.  `finish`：输出最终答案。

### 6. 主要结论与发现
*   **双向增强有效**：JCQL 在 KBC 和 KBQA 两个任务上均显著优于所有基线模型。
*   **缓解幻觉**：通过引入 SLM 的 `complete` 动作，LLM Agent 生成的推理路径更加可靠，减少了虚假事实的产生。
*   **效率提升**：相比于纯 LLM 的推理方法（如 ToG），JCQL 减少了 LLM 的调用次数，缩短了推理时间。
*   **增量学习成功**：经验回放策略成功让 SLM 吸收了 LLM 的推理知识，而没有丢失原有的结构化知识。

### 7. 优点
*   **架构创新**：首次提出结合 LLM 和 SLM 来解决 KBC 与 KBQA 的联合任务，打破了单一模型规模的限制。
*   **闭环迭代**：通过“参数化知识（LLM）$\leftrightarrow$ 结构化知识（KB/SLM）”的转换，实现了知识的动态更新。
*   **实用性强**：在知识库极度不完整（30%）的情况下依然保持稳健性能，且降低了对昂贵 LLM API 的依赖。

### 8. 不足与局限
*   **上下文构建简单**：KBC 任务中 SLM 的上下文仅取自一阶邻居，对于需要深层语义信息的复杂查询可能不足。
*   **增量学习策略较基础**：目前仅使用简单的经验回放，未来可能需要更先进的增量学习算法来处理大规模动态知识更新。
*   **外部资源利用有限**：目前仅依赖单一知识库，尚未整合搜索引擎或其他多源异构数据。
