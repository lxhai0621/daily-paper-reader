## 摘要
大语言模型 (LLMs) 越来越依赖于智能体能力——迭代检索、工具使用和决策——以克服静态参数化知识的局限性。然而，现有的智能体框架将外部信息视为非结构化文本，未能利用现实世界数据中固有的拓扑依赖关系。为了弥补这一差距，我们引入了智能体图学习 (Agentic Graph Learning, AGL)，这是一种将图学习重新定义为拓扑感知导航与基于 LLM 推理的交替过程的范式。具体而言，我们提出了 AgentGL，这是首个用于 AGL 的强化学习 (RL) 驱动框架。AgentGL 为 LLM 智能体配备了用于多尺度探索的图原生工具，通过搜索约束思维来调节工具使用以平衡准确性与效率，并采用图条件课程强化学习策略，在没有逐步监督的情况下稳定长程策略学习。在多种文本属性图 (TAG) 基准测试和多个 LLM 主干模型上，AgentGL 显著优于强大的 GraphLLMs 和 GraphRAG 基准模型，在节点分类中实现了高达 17.5% 的绝对提升，在链路预测中实现了 28.4% 的绝对提升。这些结果表明，AGL 是使 LLM 能够在复杂关系环境中自主导航和推理的一个极具前景的前沿方向。代码已公开于 https://github.com/sunyuanfu/AgentGL。

## Abstract
Large Language Models (LLMs) increasingly rely on agentic capabilities-iterative retrieval, tool use, and decision-making-to overcome the limits of static, parametric knowledge. Yet existing agentic frameworks treat external information as unstructured text and fail to leverage the topological dependencies inherent in real-world data. To bridge this gap, we introduce Agentic Graph Learning (AGL), a paradigm that reframes graph learning as an interleaved process of topology-aware navigation and LLM-based inference. Specifically, we propose AgentGL, the first reinforcement learning (RL)-driven framework for AGL. AgentGL equips an LLM agent with graph-native tools for multi-scale exploration, regulates tool usage via search-constrained thinking to balance accuracy and efficiency, and employs a graph-conditioned curriculum RL strategy to stabilize long-horizon policy learning without step-wise supervision. Across diverse Text-Attributed Graph (TAG) benchmarks and multiple LLM backbones, AgentGL substantially outperforms strong GraphLLMs and GraphRAG baselines, achieving absolute improvements of up to 17.5% in node classification and 28.4% in link prediction. These results demonstrate that AGL is a promising frontier for enabling LLMs to autonomously navigate and reason over complex relational environments. The code is publicly available at https://github.com/sunyuanfu/AgentGL.

### 1. 核心问题与整体含义
*   **研究动机**：尽管大语言模型（LLM）在处理非结构化文本方面表现出色，但在处理具有复杂拓扑依赖关系的**文本属性图（TAGs）**（如引用网络、社交平台、电商生态）时仍面临挑战。
*   **核心问题**：现有的方法（如 GNNs、静态 GraphLLMs 或 GraphRAG）要么缺乏文本语义理解，要么只能利用静态的图上下文，无法实现**动态、拓扑感知的自主探索**。
*   **整体含义**：论文提出了**智能体图学习（Agentic Graph Learning, AGL）**范式，将图学习视为 LLM 智能体在图中进行“导航-推理”的交替迭代过程，并开发了首个由强化学习（RL）驱动的框架 **AgentGL**。

### 2. 方法论
AgentGL 的核心思想是通过强化学习训练 LLM 智能体，使其能够自主决定何时以及如何搜索图结构以获取证据。
*   **图原生搜索工具 (GNS Tools)**：
    *   **1-hop/2-hop 搜索**：基于查询相关性和结构邻近性检索局部邻居。
    *   **结构显著性搜索 (SS)**：利用 PageRank 等全局结构指标识别关键节点。
    *   **图稠密搜索 (DENSE)**：利用语义向量相似度跨越拓扑限制寻找相关节点。
*   **两阶段强化学习策略**：
    1.  **策略引导阶段 (Bootstrapping)**：通过奖励塑造（格式奖励、准确性奖励、工具覆盖率奖励）引导模型学会使用各种图搜索工具。
    2.  **缓解搜索过度阶段 (MSO)**：引入“搜索约束思维”，通过回顾性终止触发器和认知密度正则化，惩罚冗余搜索，鼓励模型在有限证据下进行深度推理。
*   **图条件课程学习 (GCCL)**：
    *   利用图的拓扑先验（如节点度、同质性）和语义先验自动评估样本难度，实现从易到难的平滑训练，提高 RL 的稳定性。
*   **算法实现**：支持 GRPO 和 REINFORCE++ 等主流无评论员（Critic-free）策略优化算法。

### 3. 实验设计
*   **数据集**：涵盖 3 大领域共 7 个 TAG 数据集：引用网络（OGB-Arxiv, PubMed, Arxiv-2023）、电商产品（OGB-Products, Amazon-Photo, Amazon-Computers）和社交网络（Reddit）。
*   **任务场景**：节点分类（NC）和链路预测（LP），包括**域内（In-Domain）**评估和**零样本迁移（Zero-shot Transfer）**评估。
*   **对比基准 (Baselines)**：
    *   **GNNs**：GCN, GraphSAGE, RevGAT。
    *   **GraphLLMs**：LLaGA, GraphGPT, GraphPrompter, GraphICL。
    *   **GraphRAG**：LinearRAG, HippoRAG2, GraphCoT。
    *   **标准智能体搜索**：Search-R1, Search-O1。
    *   **基础 LLM**：Qwen2.5-3B/7B-Instruct。

### 4. 资源与算力
*   **硬件环境**：使用了 1 台配备 **8 张 NVIDIA H100-80G-SXM5 GPU** 的服务器。
*   **软件框架**：基于 OpenRLHF 进行强化学习训练。
*   **模型规模**：主要测试了 Qwen2.5-3B 和 7B 两个版本。
*   **训练细节**：最大序列长度 1600，学习率 2e-6，每个更新步采样 16 个 rollout。

### 5. 实验数量与充分性
*   **实验规模**：在 7 个数据集上进行了详尽的对比，涵盖了不同规模的主干模型（3B/7B）和不同的 RL 算法（GRPO/R++）。
*   **消融实验**：针对两阶段训练、各项奖励函数（rCOV, CDR, RTT）、课程学习（GCCL）以及超参数（λr）均做了专门的消融分析。
*   **客观性**：实验不仅关注准确率，还统计了搜索次数（效率指标），并进行了方差分析和案例研究，证明了结果的稳健性。整体实验设计非常充分且客观。

### 6. 主要结论与发现
*   **性能卓越**：AgentGL 在节点分类上最高提升 17.5%，在链路预测上最高提升 28.4%，显著优于静态 GraphLLM 和 GraphRAG。
*   **泛化能力强**：在零样本迁移场景下，AgentGL 的领先优势扩大，表明其学习到的是通用的图导航策略而非简单的模式记忆。
*   **效率平衡**：通过第二阶段训练，模型能在减少约 17.5% - 22% 搜索次数的同时，进一步提升推理准确性。
*   **算法差异**：发现 GRPO 在节点分类上略优，而 REINFORCE++ 在链路预测上表现更强。

### 7. 优点
*   **范式创新**：首次将图学习定义为智能体决策过程，打破了静态图处理的局限。
*   **工具完备**：设计的 GNS 工具兼顾了局部与全局、结构与语义，覆盖全面。
*   **训练稳定**：引入课程学习（GCCL）解决了图环境下 RL 训练难收敛、易震荡的问题。
*   **实用性高**：通过 MSO 阶段优化了推理成本，使其在实际应用中更具可行性。

### 8. 不足与局限
*   **模态限制**：目前仅支持文本属性图，尚未扩展到包含图像、视频等多模态属性的图数据。
*   **数据分配敏感性**：MSO 阶段的性能高度依赖于两个训练阶段之间的数据分配比例。
*   **图密度挑战**：在极稠密的图中，搜索空间的爆炸可能会增加智能体决策的难度，论文对此类极端情况的讨论较少。
*   **推理延迟**：作为智能体框架，其多轮迭代推理的延迟必然高于单次推理的静态模型。
