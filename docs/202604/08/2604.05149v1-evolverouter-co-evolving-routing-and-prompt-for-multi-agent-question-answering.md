## 摘要
大语言模型智能体通常表现出互补的优势，这使得路由成为多智能体问答中一种极具前景的方法。然而，现有的路由方法在两个重要方面仍存在局限性：它们通常在固定的智能体池上进行优化，而不改进智能体本身；且往往依赖于僵化的协作方案，无法根据查询动态调整参与智能体的数量。我们提出了 EvolveRouter，这是一个可训练的框架，通过同时提升智能体质量和协作结构来解决上述局限性。首先，EvolveRouter 在闭环协同演化过程中将基于图的查询路由与针对性的指令精炼相结合，使路由器的诊断能够指导智能体的改进，而精炼后的智能体则为路由提供更清晰的监督信号。其次，它引入了一种自适应推理策略，通过路由器加权的答案一致性，为每个查询动态确定有效的协作规模。这些设计共同实现了更强大且更高效的多智能体推理。在五个问答基准测试上的实验表明，EvolveRouter 在 F1 分数和精确匹配方面均持续优于 SOTA 路由基准，进一步的分析也证实了闭环精炼和自适应协作的优势。

## Abstract
Large language model agents often exhibit complementary strengths, making routing a promising approach for multi-agent question answering. However, existing routing methods remain limited in two important ways: they typically optimize over a fixed pool of agents without improving the agents themselves, and they often rely on rigid collaboration schemes that cannot adapt the number of participating agents to the query. We propose EvolveRouter, a trainable framework that addresses both limitations by jointly improving agent quality and collaboration structure. First, EvolveRouter couples graph-based query routing with targeted instruction refinement in a closed-loop co-evolution process, allowing router diagnostics to guide agent improvement while refined agents provide cleaner supervision for routing. Second, it introduces an adaptive inference strategy that dynamically determines the effective collaboration size for each query through router-weighted answer agreement. Together, these designs enable more capable and more efficient multi-agent reasoning. Experiments on five question answering benchmarks show that EvolveRouter consistently outperforms SOTA routing baselines in both F1 and exact match, while further analysis confirms the benefits of closed-loop refinement and adaptive collaboration.

### 1. 核心问题与整体含义
*   **研究动机**：虽然大语言模型（LLM）路由技术能根据查询（Query）选择合适的智能体，但现有方法存在两大瓶颈：
    1.  **智能体静态化**：路由方法通常将智能体视为不可变的“黑盒”，仅优化选择逻辑，而忽略了通过改进智能体本身的指令（Prompt）来进一步提升上限的可能性。
    2.  **协作模式僵化**：现有的协作方案要么只选一个智能体，要么固定调用一组智能体，无法根据问题的难易程度动态调整参与者的数量，导致计算资源浪费或性能受限。
*   **核心目标**：构建一个闭环系统，让路由器在学习“选谁”的同时，通过诊断信息指导智能体“如何改进”，并实现推理阶段的按需协作。

### 2. 方法论
EvolveRouter 的核心思想是**闭环协同演化**，主要包含三个阶段：
*   **基于知识图谱的路由（RouterGNN）**：
    *   将查询、上下文实体和智能体建模为异构知识图谱（KG）。
    *   使用异构图神经网络（HGT）学习查询与智能体之间的匹配得分，生成路由分布 $p(a|q)$。
*   **闭环提示词精炼（Prompt Refinement）**：
    *   **诊断信号收集**：在训练路由器的同时，记录各智能体的失败模式、性能表现及路由器的权重分配。
    *   **针对性重写**：利用一个“重写 LLM”对表现不佳但被路由器看重的智能体进行提示词优化。优化过程遵循“最小改动原则”，仅针对诊断出的错误模式（如实体提取错误、格式不符）进行微调。
    *   **验证门控**：只有在验证集上表现提升的提示词才会被采纳，随后路由器在更新后的智能体池上进行增量微调。
*   **自适应推理策略（Adaptive Inference）**：
    *   引入**加权答案一致性（Weighted Answer Agreement）**。
    *   按路由排名依次调用智能体，当已调用智能体的加权共识得分超过阈值 $\tau$ 时提前停止，从而动态确定每个查询所需的协作规模 $K$。

### 6. 主要结论与发现
*   **协同效应**：EvolveRouter 在所有基准上均显著优于 SOTA（如 AgentRouter），证明了联合优化路由和提示词的优越性。

### 7. 优点
*   **闭环反馈机制**：首次将路由器的诊断结果直接用于智能体提示词的自动化迭代，实现了真正的“教”与“学”同步。
*   **高效推理**：自适应停止机制在几乎不损失精度的情况下大幅降低了多智能体系统的推理成本。
*   **结构化建模**：利用异构图捕捉查询、实体与智能体间的复杂关系，比扁平化的路由方法更精准。

*   **重写模型依赖**：提示词的精炼质量高度依赖于 Rewriter LLM（实验中使用 GPT-4o-mini）的能力。
