## 摘要
现有的视觉定位基准主要评估图像区域与字面指代性表达之间的对齐，模型通常可以通过匹配显著的命名类别来取得成功。我们探索了一种互补且更具挑战性的设置，即基于场景的视觉定位，其中目标必须根据角色、意图和关系上下文而非显式命名来推断。我们引入了指代场景理解（Referring Scenario Comprehension, RSC），这是一个专为此设置设计的基准。该基准中的查询是段落长度的文本，描述了物体角色、用户目标和上下文线索，包括对干扰物体的刻意引用，这通常需要深度理解才能解决。每个实例都标注了关于唯一性、杂乱度、尺寸、重叠和位置的可解释难度标签，这些标签揭示了不同的失败模式并支持细粒度分析。RSC 包含约 3.1 万个训练样本、4000 个域内测试样本，以及一个包含未见物体类别的 3000 个样本的分布外划分。我们进一步提出了 ScenGround，这是一种课程推理方法，作为该设置的参考基准，它结合了监督预热与难度感知的强化学习。实验表明，基于场景的查询暴露了当前模型中标准基准未能揭示的系统性失败，并且课程训练提高了在挑战性切片上的性能，并能迁移到标准基准中。

## Abstract
Existing visual grounding benchmarks primarily evaluate alignment between image regions and literal referring expressions, where models can often succeed by matching a prominent named category. We explore a complementary and more challenging setting of scenario-based visual grounding, where the target must be inferred from roles, intentions, and relational context rather than explicit naming. We introduce Referring Scenario Comprehension (RSC), a benchmark designed for this setting. The queries in this benchmark are paragraph-length texts that describe object roles, user goals, and contextual cues, including deliberate references to distractor objects that often require deep understanding to resolve. Each instance is annotated with interpretable difficulty tags for uniqueness, clutter, size, overlap, and position which expose distinct failure modes and support fine-grained analysis. RSC contains approximately 31k training examples, 4k in-domain test examples, and a 3k out-of-distribution split with unseen object categories. We further propose ScenGround, a curriculum reasoning method serving as a reference point for this setting, combining supervised warm-starting with difficulty-aware reinforcement learning. Experiments show that scenario-based queries expose systematic failures in current models that standard benchmarks do not reveal, and that curriculum training improves performance on challenging slices and transfers to standard benchmarks.

*   **核心问题：** 现实世界中，用户往往通过**场景需求、角色意图或功能目标**来指代物体（例如，说“我想看时间”而不是“那个圆形的挂钟”）。现有基准缺乏对这种长篇幅、基于推理的场景化查询的评估。
*   **整体含义：** 论文提出了“指代场景理解”（RSC）任务，旨在推动视觉定位模型从简单的“物体识别”转向复杂的“意图与关系推理”。

### 2. 方法论
*   **RSC 基准构建：**
    *   **数据生成：** 利用 LLM（如 GPT-4o）基于 MS-COCO 和 LVIS 图像生成段落长度的查询。每个查询包含用户角色、目标、至少 3 个辨别线索，并刻意提及干扰项以增加难度。

*   **ScenGround 训练框架：**
    *   **阶段 1：思维引导微调（TP-SFT）：** 使用简单的 RSC 样本进行监督学习，强制模型输出 `<think>` 推理链和结构化的 `<answer>`（包含类别和 BBox）。
    *   **阶段 2：激励课程 GRPO（IC-GRPO）：** 采用群组相对策略优化（GRPO）进行强化学习。
        *   **奖励函数：** 结合了几何奖励（IoU、中心一致性、越界惩罚）、类别奖励（支持别名匹配）和格式奖励。
        *   **难度感知课程：** 训练过程从简单样本逐步过渡到非唯一、高重叠、偏离中心的困难样本，解决 RL 中的奖励稀疏问题。
        *   **提示词集成：** 使用 8 种不同的提示词模板（PTE-8）增强模型对查询表述的鲁棒性。

### 6. 主要结论与发现
*   **能力断层：** 现有模型在“语义理解”和“空间定位”之间存在失衡。闭源模型（如 Claude 3.7）类别识别极准但定位极差；开源模型则相反。
*   **RL 的有效性：** IC-GRPO 显著提升了模型在复杂场景下的定位精度，尤其是在 OOD 类别上。
*   **课程学习的必要性：** 标签感知的课程训练比直接混合训练效果更好，能有效提升模型处理高难度（如高重叠、小目标）样本的能力。
*   **迁移价值：** 在 RSC 上训练的模型在 RefCOCOg 等标准基准上也表现出更强的鲁棒性。

### 7. 优点
*   **任务前瞻性：** 摆脱了简单的“名词匹配”，提出了更符合人类自然语言习惯的场景化定位任务。
*   **细粒度分析：** 引入五维难度标签，使得模型失败模式的分析更加透明和可解释。
*   **训练方案完备：** ScenGround 结合了思维链推理与强化学习，为处理长文本查询提供了有效的技术路径。

### 8. 不足与局限
*   **数据偏差：** 尽管有人工审计，但核心数据仍由 LLM 生成，可能存在潜在的语言风格偏差或模型特有的幻觉。
*   **语义瓶颈：** 在 OOD 场景下，虽然定位精度提升明显，但对完全未见类别的“命名准确率”提升有限，说明语义泛化仍是瓶颈。
*   **应用限制：** 目前仅针对静态图像，尚未扩展到视频流或多轮交互的动态场景。
