## 摘要
街景图像包含个人身份信息 (PII)，其中部分信息具有上下文依赖性。现有的匿名化方法要么对图像过度处理，要么遗漏细微的标识符，而基于 API 的解决方案则会损害数据主权。我们提出了一种名为 CAIAMAR（基于多智能体推理的上下文感知图像匿名化）的智能体框架，用于上下文感知的 PII 分割及基于扩散模型的匿名化。该框架将针对高置信度案例的预定义处理与针对间接标识符的多智能体推理相结合。三个专业智能体通过轮询发言人选择机制在“计划-执行-检查-处理”(PDCA) 循环中进行协作，使大型视觉语言模型能够根据空间上下文（如私有财产与公共财产）而非僵化的类别规则对 PII 进行分类。这些智能体实现了空间过滤的由粗到精检测，其中“侦察与缩放”策略用于识别候选目标，开放词汇分割处理局部裁剪区域，而基于 IoU 的去重（30% 阈值）则防止了冗余处理。具有外观去相关性的模态特定扩散引导显著降低了重识别 (Re-ID) 风险。在 CUHK03-NP 数据集上，我们的方法将行人重识别风险降低了 73%（R1 为 16.9%，而基准值为 62.4%）。在 CityScapes 数据集的图像质量保持方面，我们实现了 KID 为 0.001 和 FID 为 9.1，显著优于现有的匿名化方法。该智能体工作流能够检测跨对象类别的非直接 PII 实例，并保留了下游语义分割性能。该框架完全基于开源模型在本地运行，能够生成符合欧盟 GDPR 透明度要求的人类可解释审计轨迹，同时标记失败案例以供人工审查。

## Abstract
Street-level imagery contains personally identifiable information (PII), some of which is context-dependent. Existing anonymization methods either over-process images or miss subtle identifiers, while API-based solutions compromise data sovereignty. We present an agentic framework CAIAMAR (\underline{C}ontext-\underline{A}ware \underline{I}mage \underline{A}nonymization with \underline{M}ulti-\underline{A}gent \underline{R}easoning) for context-aware PII segmentation with diffusion-based anonymization, combining pre-defined processing for high-confidence cases with multi-agent reasoning for indirect identifiers. Three specialized agents coordinate via round-robin speaker selection in a Plan-Do-Check-Act (PDCA) cycle, enabling large vision-language models to classify PII based on spatial context (private vs. public property) rather than rigid category rules. The agents implement spatially-filtered coarse-to-fine detection where a scout-and-zoom strategy identifies candidates, open-vocabulary segmentation processes localized crops, and $IoU$-based deduplication ($30\%$ threshold) prevents redundant processing. Modal-specific diffusion guidance with appearance decorrelation substantially reduces re-identification (Re-ID) risks. On CUHK03-NP, our method reduces person Re-ID risk by $73\%$ ($R1$: $16.9\%$ vs. $62.4\%$ baseline). For image quality preservation on CityScapes, we achieve KID: $0.001$, and FID: $9.1$, significantly outperforming existing anonymization. The agentic workflow detects non-direct PII instances across object categories, and downstream semantic segmentation is preserved. Operating entirely on-premise with open-source models, the framework generates human-interpretable audit trails supporting EU's GDPR transparency requirements while flagging failed cases for human review.

### 论文总结：基于多智能体推理的上下文感知图像匿名化 (CA-IAMAR)

#### 1. 核心问题与整体含义（研究动机和背景）
随着街景图像（如地图服务、自动驾驶数据集）的普及，个人隐私保护（PII）变得至关重要。现有的匿名化技术（如高斯模糊或简单的生成式替换）存在三大缺陷：
*   **过度处理或遗漏：** 传统方法往往对所有检测到的对象一视同仁，导致图像可用性下降；或者遗漏了依赖上下文的“间接标识符”（如私人住宅门牌号、特定衣着）。
*   **缺乏推理能力：** 无法区分公共标识（如交通标志）与私人信息。
*   **数据主权风险：** 依赖云端 API 处理敏感数据违反了 GDPR 等隐私法规。
**研究动机：** 开发一个能够在本地运行、具备语义推理能力、且能平衡隐私保护与数据可用性的自动化框架。

#### 2. 方法论：核心思想与算法流程
论文提出了 **CA-IAMAR** 框架，采用两阶段处理架构：
*   **第一阶段：预定义确定性处理。** 使用 YOLOv8 等专用模型检测并处理高置信度的直接标识符（全身、车牌）。
*   **第二阶段：多智能体推理（核心）。** 引入三个专业智能体，通过 **PDCA（计划-执行-检查-处理）** 循环协作：
    1.  **审核智能体 (Auditor)：** 利用大型视觉语言模型 (LVLM, 如 Qwen2.5-VL) 识别间接 PII。采用“侦察与缩放 (Scout-and-Zoom)”策略，对疑似区域进行局部裁剪再识别，提高精度。
    2.  **编排智能体 (Orchestrator)：** 负责工作流状态管理，强制执行轮询发言机制，并限制迭代次数（最多 3 次）以防死循环。
    3.  **生成智能体 (Generative)：** 执行基于扩散模型 (SDXL) 的修复。利用 ControlNet 保持姿态和结构，同时通过“外观去相关”技术（随机化衣着颜色和亮度）彻底切断重识别 (Re-ID) 向量。
*   **关键技术细节：** 引入 30% IoU 阈值的去重机制防止重复处理；生成可解释的审计轨迹（Audit Trails），记录每一步推理决策，满足 GDPR 的透明度要求。

#### 3. 实验设计
*   **数据集：**
    *   **CUHK03-NP：** 用于评估行人重识别 (Re-ID) 风险。
    *   **CityScapes：** 用于评估图像质量保持和下游语义分割任务。

    *   GPU 1 专门运行大型视觉语言模型 (Qwen2.5-VL-32B)。

#### 5. 实验数量与充分性
*   **实验规模：** 在 CityScapes 测试集（1,525 张图）和 CUHK03-NP（6,732 张图）上进行了大规模测试。
*   **消融实验：** 对比了“仅第一阶段”与“完整框架”的效果，证明第二阶段多智能体推理额外发现了 1,107 个间接 PII 实例。

*   **图像质量：** 在 CityScapes 上实现了极高的保真度（KID: 0.001, FID: 9.1），远超现有方法。

#### 7. 优点
*   **上下文感知：** 能够根据空间位置（如私人领地 vs 公共道路）动态判断是否需要匿名化。
*   **合规性强：** 全本地化部署，不依赖外部 API，且提供人类可读的审计日志，符合 GDPR 监管需求。
*   **隐私与效用平衡：** 通过外观去相关技术在不破坏图像结构的前提下，极大地降低了自动化监控的识别率。

#### 8. 不足与局限
*   **处理速度慢：** 每张图超过 2 分钟的处理时间，无法满足实时应用需求，仅适用于离线数据集脱敏。

*   **幻觉风险：** 尽管有 PDCA 循环，但 LLM 仍可能出现误报或漏报，完全自动化仍需人工抽检。
