## 摘要
记忆系统通过缓解捕获长期用户-大语言模型（LLM）对话时的上下文窗口限制，对个性化 LLM 至关重要。通常，此类系统利用多个智能体来处理多粒度记忆构建和个性化记忆检索任务。为了优化系统，现有方法侧重于通过提示工程或微调，独立地使智能体专门化于其局部任务。然而，它们忽视了跨智能体协作，而局部智能体的独立优化很难保证全局系统性能。为解决这一问题，我们提出了一种用于多智能体记忆系统的协同强化学习框架（CoMAM），通过联合优化局部智能体来促进协作。具体而言，我们将智能体的执行正则化为序列马尔可夫决策过程（MDP），以将智能体间的依赖关系嵌入到状态转移中，从而产生局部任务奖励（例如记忆构建的信息覆盖率）和全局奖励（即问答准确率）。然后，我们通过局部奖励与全局奖励之间的群体级排名一致性来量化每个智能体的贡献，并将其作为自适应权重来分配全局信用并整合局部-全局奖励。每个智能体都通过这些整合后的奖励进行优化，使局部改进与全局性能保持一致。实验表明，CoMAM 优于领先的记忆系统，验证了我们提出的用于联合优化的协同强化学习的有效性。

## Abstract
Memory systems are crucial to personalized LLMs by mitigating the context window limitation in capturing long-term user-LLM conversations. Typically, such systems leverage multiple agents to handle multi-granular memory construction and personalized memory retrieval tasks. To optimize the system, existing methods focus on specializing agents on their local tasks independently via prompt engineering or fine-tuning. However, they overlook cross-agent collaboration, where independent optimization on local agents hardly guarantees the global system performance. To address this issue, we propose a Collaborative Reinforcement Learning Framework for Multi-Agent Memory Systems (CoMAM), jointly optimizing local agents to facilitate collaboration. Specifically, we regularize agents' execution as a sequential Markov decision process (MDP) to embed inter-agent dependencies into the state transition, yielding both local task rewards (e.g., information coverage for memory construction) and global rewards (i.e., query-answer accuracy). Then, we quantify each agent's contribution via group-level ranking consistency between local and global rewards, treating them as adaptive weights to assign global credit and integrate local-global rewards. Each agent is optimized by these integrated rewards, aligning local improvements with the global performance. Experiments show CoMAM outperforms leading memory systems, validating the efficacy of our proposed collaborative reinforcement learning for joint optimization.

#### 1. 核心问题与整体含义（研究动机和背景）
个性化大语言模型（LLM）需要记忆系统来克服上下文窗口限制，以捕获长期的用户对话历史。目前的记忆系统通常由多个专门的智能体组成（如负责提取事实的智能体、负责生成用户画像的智能体和负责检索的智能体）。
**核心问题：** 现有方法通常通过提示工程或强化学习**独立地**优化各个智能体。这种“局部专家”的集合模式忽略了智能体间的协作，导致局部任务的改进并不总能转化为全局系统性能的提升（例如，提取智能体可能保留了过多噪声，反而干扰了检索智能体的准确性）。本文旨在通过联合优化（Joint Optimization）解决跨智能体协作难题。

#### 2. 方法论：核心思想与关键技术
论文提出了 **CoMAM** 框架，其核心思想是将多智能体记忆系统建模为一个协同强化学习过程：
*   **序列 MDP 正则化：** 将异步执行的异构智能体（提取、画像、检索）正则化为一个顺序马尔可夫决策过程（MDP）。通过状态转移（如提取智能体的输出作为画像智能体的输入），将智能体间的依赖关系嵌入到优化轨迹中。
*   **局部与全局奖励设计：**
    *   **局部奖励：** 提取智能体关注信息覆盖率；画像智能体关注抽象的合理性；检索智能体关注检索精度。
    *   **全局奖励：** 最终问答的准确性（QA Accuracy）。
*   **自适应信用分配（Adaptive Credit Assignment）：** 这是本文的关键创新。利用 **NDCG（归一化折损累计增益）** 衡量局部奖励排名与全局奖励排名之间的一致性。一致性得分越高，说明该智能体对全局目标的贡献越大，从而赋予其更高的全局奖励权重。
*   **联合优化算法：** 基于 **GRPO（群体相对策略优化）** 算法，利用组内相对奖励代替评论家网络（Critic），同时更新所有智能体的策略，实现端到端的协同进化。

*   **协同优于独立：** CoMAM 在所有设置下均显著优于独立优化的 Memory-R1，准确率提升幅度在 8.5% 到 16.7% 之间。

#### 7. 优点
*   **理论严谨：** 将复杂的异步多智能体系统转化为顺序 MDP，为联合优化提供了坚实的数学框架。
*   **创新性信用分配：** 引入 NDCG 排名一致性来动态分配奖励，解决了多智能体强化学习中常见的“信用分配模糊”问题。
*   **泛化性强：** 在不同模型架构和超长文本（1M tokens）下均表现稳健。

#### 8. 不足与局限
*   **静态轨迹限制：** 目前的 MDP 正则化假设了固定的执行顺序，而现实中智能体的调用频率可能是动态的（例如，不是每次对话都需要更新画像）。

*   **局部-局部对齐缺失：** 论文主要关注局部与全局的对齐，尚未显式建模智能体两两之间的直接协同关系。
