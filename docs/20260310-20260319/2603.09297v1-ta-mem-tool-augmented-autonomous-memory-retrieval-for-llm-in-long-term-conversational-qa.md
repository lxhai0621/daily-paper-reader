## 摘要
大语言模型（LLM）在各领域的文本语境中展现出强大的推理能力，但上下文窗口的限制给模型在长程推理任务上带来了挑战，并使其需要一个记忆存储系统。虽然目前已提出了许多利用情景笔记和记忆图谱表示的存储方法，但检索方法仍主要依赖于预定义的工作流或基于嵌入的静态相似度 top-k 检索。为了解决这种灵活性不足的问题，我们引入了一种新型的工具增强型自主记忆检索框架（TA-Mem），该框架包含：(1) 一个记忆提取 LLM 智能体，通过提示词引导其根据语义相关性自适应地将输入切分为子上下文，并将信息提取为结构化笔记；(2) 一个多索引记忆数据库，专为包括基于键的查找和基于相似度的检索在内的不同查询方法而设计；(3) 一个工具增强型记忆检索智能体，它根据用户输入从数据库提供的工具中选择合适的工具来自主探索记忆，并在对获取的记忆进行推理后，决定是进入下一次迭代还是完成最终响应。TA-Mem 在 LoCoMo 数据集上进行了评估，与现有的基准方法相比，取得了显著的性能提升。此外，对不同问题类型中工具使用情况的分析也证明了所提方法的自适应性。

## Abstract
Large Language Model (LLM) has exhibited strong reasoning ability in text-based contexts across various domains, yet the limitation of context window poses challenges for the model on long-range inference tasks and necessitates a memory storage system. While many current storage approaches have been proposed with episodic notes and graph representations of memory, retrieval methods still primarily rely on predefined workflows or static similarity top-k over embeddings. To address this inflexibility, we introduced a novel tool-augmented autonomous memory retrieval framework (TA-Mem), which contains: (1) a memory extraction LLM agent which is prompted to adaptively chuck an input into sub-context based on semantic correlation, and extract information into structured notes, (2) a multi-indexed memory database designed for different types of query methods including both key-based lookup and similarity-based retrieval, (3) a tool-augmented memory retrieval agent which explores the memory autonomously by selecting appropriate tools provided by the database based on the user input, and decides whether to proceed to the next iteration or finalizing the response after reasoning on the fetched memories. The TA-Mem is evaluated on the LoCoMo dataset, achieving significant performance improvements over existing baseline approaches. In addition, an analysis of tool use across different question types also demonstrates the adaptivity of the proposed method.

本文提出了 **TA-Mem** 框架，旨在通过“工具增强”和“自主代理”的思想，让 LLM 能够像使用外部工具一样自主探索记忆数据库，从而实现更精准、灵活的长程信息检索。

### 2. 方法论：核心思想与关键技术
TA-Mem 框架由三个核心组件构成：
*   **情景记忆构造器（Episodic Memory Constructor）：**
    *   利用 LLM 代理进行“一发多任务（One-shot, Multi-task）”处理。
    *   **自适应分块：** 自动检测对话中的话题转换（Topic Shift）进行语义分块，而非固定长度切分。
    *   **结构化提取：** 将每个分块提取为包含摘要、关键词、参与人物、事实、事件、时间戳和语义标签的结构化笔记。
*   **多索引数据库（Multi-Indexed Database）：**
    *   提供多种查询接口（工具）：包括基于字符串匹配的键值查询（人名、标签、关键词）和基于向量余弦相似度的 Top-k 检索（事件、事实）。
    *   支持特定人物的画像查询（获取某人的所有事件或事实）。
*   **自主检索代理（Memory Retrieval Agent）：**
    *   **Agentic Loop：** 检索代理接收问题后，自主决定调用哪些工具、生成查询参数。
    *   **迭代推理：** 获取结果后，代理判断信息是否充足。若不足则继续调用工具，若充足则输出答案。
    *   **缓存机制：** 维护会话级缓存，避免重复检索相同内容，提高 Token 效率。

### 6. 主要结论与发现
*   **性能领先：** TA-Mem 在大多数指标上优于基准模型，尤其在**时间推理（Temporal）**问题上表现突出（F1 提升显著）。
*   **Token 效率：** 尽管采用了多轮迭代的代理设计，但由于工具检索的精准性，其平均 Token 消耗（3755 tokens/q）远低于部分长上下文模型（如 LoCoMo 原型和 MemGPT 的 16000+ tokens）。
*   **自适应性：** 统计显示，处理时间类问题时模型更倾向于调用“事件匹配”工具，而开放域问题则更多调用“事实查询”工具，证明了自主选择工具的有效性。

### 7. 优点（亮点）
*   **检索灵活性：** 将记忆检索从简单的“向量搜索”提升为“自主工具调用”，能够处理更复杂的逻辑查询。
*   **结构化程度高：** 提取阶段保留了丰富的情景元数据（时间、人物关系等），为后续推理提供了高质量素材。
*   **平衡性好：** 在保证高准确率的同时，通过缓存和精准检索较好地控制了 Token 成本。

### 8. 不足与局限
*   **Prompt 依赖性：** 记忆提取的效果高度依赖于 Prompt 的设计，可能存在不稳定性，未来可能需要微调（Fine-tuning）专用模型。
*   **系统延迟：** 代理的迭代循环（Agentic Loop）会导致多次 API 往返，增加了系统的响应延迟，不适用于实时性要求极高的场景。
*   **规模化挑战：** 实验主要在对话数据集上进行，对于海量、非结构化的超大规模知识库，工具调用的复杂度和幻觉风险可能会增加。
