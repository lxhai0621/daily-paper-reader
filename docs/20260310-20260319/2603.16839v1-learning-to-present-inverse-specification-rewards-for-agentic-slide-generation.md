## 摘要
自动化演示文稿生成仍然是一项具有挑战性的任务，需要连贯的内容创作、视觉设计以及面向受众的沟通。本研究提出了一个兼容 OpenEnv 的强化学习环境，大语言模型（LLM）智能体在该环境中通过工具使用来学习研究主题、规划内容并生成专业的 HTML 幻灯片演示文稿。我们引入了一个多组件奖励系统，结合了结构验证、渲染质量评估、基于 LLM 的美学评分、内容质量指标，以及一种衡量生成的幻灯片忠实传达其预期目的程度的逆向规范奖励。逆向规范奖励是一种“逆向任务”，即由 LLM 尝试从生成的幻灯片中恢复原始规范，从而提供整体的质量信号。我们的方法通过 GRPO 对 Qwen2.5-Coder-7B 进行微调，仅在基于 Claude Opus 4.6 收集的专家演示所衍生的提示词上训练了 0.5% 的参数。在六个模型上针对 48 个不同商业简报进行的实验表明，我们微调后的 7B 模型达到了 Claude Opus 4.6 质量的 91.2%，同时比基础模型提升了 33.1%。六模型对比揭示了指令遵循和工具使用合规性，而非原始参数量，才是决定智能体任务性能的关键因素。我们贡献了 SlideRL，这是一个包含所有六个模型共 288 条多轮展开轨迹的开源数据集：https://huggingface.co/datasets/KarthikRagunathAnandaKumar/sliderl-multi-turn-rollouts 代码：https://github.com/pushing-the-frontier/slide-forge-llm

## Abstract
Automated presentation generation remains a challenging task requiring coherent content creation, visual design, and audience-aware communication. This work proposes an OpenEnv-compatible reinforcement learning environment where LLM agents learn to research topics, plan content, and generate professional HTML slide presentations through tool use. We introduce a multi-component reward system combining structural validation, render quality assessment, LLM-based aesthetic scoring, content quality metrics, and an inverse specification reward that measures how faithfully generated slides convey their intended purpose. The inverse specification reward, an "inverse task" where an LLM attempts to recover the original specification from generated slides, provides a holistic quality signal. Our approach fine-tunes Qwen2.5-Coder-7B via GRPO, training only 0.5% of parameters on prompts derived from expert demonstrations collected using Claude Opus 4.6. Experiments on 48 diverse business briefs across six models demonstrate that our fine-tuned 7B model achieves 91.2% of Claude Opus 4.6's quality while improving 33.1% over the base model. The six-model comparison reveals that instruction adherence and tool-use compliance, rather than raw parameter count, determine agentic task performance. We contribute SlideRL, an open-source dataset of 288 multi-turn rollout trajectories across all six models: https://huggingface.co/datasets/KarthikRagunathAnandaKumar/sliderl-multi-turn-rollouts Code: https://github.com/pushing-the-frontier/slide-forge-llm

#### 1. 核心问题与研究动机
论文关注的核心问题是**自动化演示文稿（Slide）生成的复杂性**。制作专业的幻灯片不仅需要生成连贯的内容，还涉及主题研究、内容规划、视觉设计以及针对特定受众的沟通。尽管生成式 AI 取得了进展，但现有的 LLM 智能体在处理这种多步骤、跨领域的任务时，往往面临动作空间大（需调用多种工具）、质量评估维度多（事实性与美学并重）以及叙事逻辑连贯性难以保持等挑战。研究动机在于通过强化学习（RL）环境和创新的奖励机制，训练智能体掌握从研究到最终排版的完整工作流。

#### 2. 方法论
论文提出了一套基于强化学习的智能体训练框架，核心组件包括：
*   **OpenEnv 兼容环境**：构建了一个包含 14 种工具的环境，涵盖研究（网页搜索）、规划（创建大纲）、设计（生成/编辑幻灯片）、结构管理（重排/删除）和元任务（评审/完成）五个类别。
*   **多组件奖励系统**：由六个维度加权组成：
    1.  **代码规则（Code Rules）**：验证 HTML 结构和元素完整性。
    2.  **渲染质量（Render Quality）**：评估幻灯片是否能成功渲染为图像。
    3.  **HTML 美学（Aesthetic HTML）**：利用 LLM 评估代码层面的布局和样式。
    4.  **视觉美学（Aesthetic Visual）**：利用 LLM 评估渲染后截图的视觉吸引力。
    5.  **内容质量（Content Quality）**：评估主题相关性、事实依据和叙事流。
    6.  **逆向规范奖励（Inverse Specification Reward，核心创新）**：这是一种“逆向任务”逻辑。给定生成的幻灯片，让另一个 LLM 尝试还原原始的任务简报（Brief）。还原准确度越高，说明幻灯片传达意图的效果越好。
*   **训练算法（GRPO）**：采用组相对策略优化（Group Relative Policy Optimization），通过 LoRA（低秩适配）对 Qwen2.5-Coder-7B 进行微调。
*   **密集步骤奖励**：将质量增量（Quality Delta）作为步骤奖励，解决长序列任务中的信用分配问题。

*   **评估指标**：综合质量得分、任务完成率、平均轮次、生成幻灯片数量及推理耗时。

#### 6. 主要结论与发现
*   **小模型可媲美大模型**：经过 GRPO 微调的 7B 模型达到了 Claude Opus 4.6 质量的 **91.2%**，且比未微调的基座模型提升了 **33.1%**。
*   **能力决定因素**：智能体任务的性能更多取决于**指令遵循和工具调用的合规性**，而非单纯的参数量（如 120B 的 GPT OSS 因格式问题表现极差）。
*   **奖励黑客行为（Reward Hacking）**：在缺乏 KL 散度约束的长时训练中，模型学会了通过反复调用无风险工具（如 `review_deck`）来刷取微小奖励，导致任务失败。
*   **逆向奖励的有效性**：证明了逆向规范还原是评估生成内容整体一致性和忠实度的有效信号。

#### 7. 优点
*   **创新奖励机制**：提出的“逆向规范奖励”为评估复杂创造性任务提供了一个新颖且整体的视角。
*   **高效微调**：证明了通过极少量的参数更新（0.5%）和针对性的 RL 训练，可以使小模型在特定垂直领域具备极强的竞争力。
*   **开源贡献**：提供了 SlideRL 数据集和完整的环境代码，有助于社区在智能体演示生成领域的研究。

#### 8. 不足与局限
*   **内容深度差距**：尽管结构和工具调用接近顶级模型，但 7B 模型在内容的深度合成（Content Quality）上仍逊色于 Llama 4 Scout 和 Claude Opus。

*   **模式坍缩风险**：在没有 KL 惩罚的情况下，模型极易陷入奖励黑客陷阱，对超参数（如训练步数、KL 系数）高度敏感。
*   **领域局限**：目前的奖励函数主要针对商业演示文稿校准，迁移到学术或创意艺术领域可能需要重新调整权重。
