## 摘要
人工智能中“智能体”一词缺乏标准定义，这使AI智能体研究的评估、比较和可复现性变得复杂。我们通过一项围绕智能体性五个维度组织的综述来应对这一歧义：环境交互、学习与适应、自主性、目标导向行为以及时序连贯性。对于每个维度，我们考察既往工作如何概念化其底层能力，并综合用于评估该能力的指标、基准和评估框架。本综述对智能体评估的当前图景进行了结构化梳理，既突出了已确立的方法，也指出了评估仍然有限或不一致的领域。我们还介绍了 Agent Compendium，这是一个面向公众的数字资源，用于组织和扩展本综述所识别的评估方法。综述与汇编共同为跨AI系统评估和比较智能体能力提供了通用结构，支持更具可复现性的研究、更清晰的交流以及对人工智能体更系统的研究。

## Abstract
The term agent in artificial intelligence lacks a standard definition, complicating the evaluation, comparison, and reproducibility of AI agent research. We address this ambiguity through a survey organized around five dimensions of agenticness: environmental interaction, learning and adaptation, autonomy, goal-directed behavior, and temporal coherence. For each dimension, we examine how the underlying capability has been conceptualized across prior work and synthesize the metrics, benchmarks, and evaluation frameworks used to assess it. This review provides a structured account of the current landscape of agent evaluation, highlighting both established approaches and areas where evaluation remains limited or inconsistent. We additionally introduce the Agent Compendium, a public-facing digital resource that organizes and extends the evaluation methods identified through this review. Together, the survey and compendium provide a common structure for evaluating and comparing agent capabilities across AI systems, supporting more reproducible research, clearer communication, and more systematic study of artificial agents.

### 2.2 各维度的关键技术内容与公式（文字化说明）

**（A）环境交互**（子组件：架构、导航、工具使用、空间分析、一致性、鲁棒性）

- **智能体架构**：深思型（符号化世界模型 + 逻辑推理，基于 Newell & Simon 的物理符号系统假说）、反应型（无内部表示、条件—动作规则，Brooks 主张"智能寓于世界"）、混合型（兼具快速反应与高层规划）；指出尚缺"混合架构中深思/反应配比"的评估方法，建议结合 Carrascosa 等的"反应度"（最大可用余裕时间比例）来构建。
- **导航**：核心指标为**成功率加权逆路径长度（SPL）**——对 N 个测试回合，用二元成功指示量乘以"最短路径长度 / 实际路径与最短路径的较大者"，再对回合取平均。梳理点目标、物体目标、视觉—语言、音视频、具身问答（EQA）、视觉问答（VQA）六类导航及代表性模型（DD-PPO、ZSON、CLIP-Nav、CoW、Room-to-Room、REVERIE、VLN-CE、SoundSpaces、EXPRESS-Bench、NoisyEQA、ScanQA、Oscar 等）。
- **工具使用**：以 MultiCAT-Bench 为分类基准，把输出拆为"调用 / 工具名 / 参数"三层，给出**准确率、总体召回/精确率/F1、工具名召回/精确率/F1、参数召回/精确率/F1** 的公式（要求工具与参数与真值完全匹配；参数分最小、部分、完整三档）。另有 **Tool Dexterity Index（TDI）= 工具使用得分之和 / 工具使用机会总数**，得分规则为"最优使用 +1、误用 −1、忽略更优工具 −0.5"。
- **空间分析**：Felicia 等提出微观（厘米）、中观（米）、宏观（千米）三级尺度，指出"尺度错配是空间 AI 迁移失败的主因"；记忆分短期、长期、情景（记录"何地发生何事"）、空间（编码"哪里"本身的结构）四类；归纳四类失败模式：空间幻觉、参考系混淆、尺度不敏感、时间漂移。论文明确指出**目前没有跨智能体追踪空间失败的方法**，建议作为活跃研究方向。
- **一致性**：三面——结果一致性（同任务重复尝试的成功率稳定性，用伯努利方差 0.25 归一化）、轨迹类型一致性（对动作类型分布计算 Jensen–Shannon 散度）、轨迹序列一致性（对动作序列计算归一化 Levenshtein 距离）、资源一致性（对成本/时间/API 调用计算变异系数后取指数变换）。并引入 Rath（2026）的 **Agent Stability Index（ASI）**中四个一致性维度：输出语义相似度、决策路径稳定性、置信度校准、工具调用序列一致性。
- **鲁棒性**：给出 **RobustSucc**（所有扰动下的平均成功）与 **WorstSucc**（各任务最差扰动成功）公式；区分对抗鲁棒性（含提示注入等智能体特有威胁）、故障鲁棒性（如 404 后自愈）、环境鲁棒性（如表格列顺序变化）、提示鲁棒性（同义改写、跨语言），后三者均用"扰动下准确率 / 基线准确率，上限截断为 1"的比值度量。列举 AgentDojo、HarmBench、AdvBench、JailbreakBench、CyberSecEval 等基准及其效用—安全权衡、攻击成功率、分类器一致率等指标。

**（B）学习与适应**（子组件：效率与成本、轨迹与规划、可靠性、智能体能力、可预测性、通用性）

- **效率与成本**：认知效率分数 **CES =（生成 token 总数 + 工具/API 调用 × token 当量）/ 成功完成任务数**；延迟用分位数（对排序后的完成时间取第 ⌈qN⌉ 个）；token 用量与每任务 token 成本按输入/输出 token 加权求和。强调高 API 成本使系统"技术耀眼但经济上不可持续"。
- **轨迹与规划**：规划含"制定（任务分解 + 执行）"与"反思"两阶段；指标包括**动作有效率**（合法动作占比）、**循环率**（1 − 唯一动作数 / 总步数）、**计划遵循度**（逐步与参考计划一致的比例）。
- **可靠性**：与鲁棒性区分——可靠性指跨时间与重复的稳定表现，用 S 个随机种子的结果均值与方差度量（任务内方差再对任务取平均）。
- **智能体能力层次**（Ritchie 等）：1 工具使用 → 2 规划与目标形成 → 3 适应性 → 4 扎根性 → 5 常识推理。配套给出任务复杂度四级（简单原子/顺序/并行/混合）与任务分解指标：粒度分数 ≥0.75、效率比 ≥0.80、目标对齐余弦相似度 ≥0.85、逻辑正确性 = 1.0；上下文保持指标包括上下文保留准确率、来源追踪准确率、上下文衰减模型（指数衰减 + 多项式长期退化的混合形式）及分短/中/长程的阈值。
- **可预测性**：校准（分箱后的期望校准误差）、判别力（等价于 AUC-ROC 的成功—失败置信度配对比例）、Brier 分数（1 − 置信度与结果的均方误差）。
- **通用性**：Morris 等的五级最低性能阈值（新兴/胜任/专家/卓越/超人类，对应非熟练人类到超越 100% 人类）；Kasirzadeh & Gabriel 批评"通用 vs 狭窄"的二分，提出五级任务广度（单一专长 → 任务域精通 → 多任务域 → 多数任务域 → 完全通用）。

**（C）自主性**

- 四套分级并行呈现：
  - **以任务表现为中心**（Kasirzadeh & Gabriel，借鉴 SAE 驾驶自动化分级）：受限 → 部分 → 中级 → 高 → 完全自主；
  - **以智能体角色为中心**（Morris 等）：AI 作为工具 / 顾问 / 协作者 / 专家 / 智能体（并给出各级对应的过度依赖、定向操纵、准社会关系、大规模劳动力替代等风险）；
  - **以用户角色为中心**（Feng 等）：用户作为操作员 / 协作者 / 顾问 / 审批者 / 观察者；
  - **OECD 行动自主性**：无 / 低（人在环内）/ 中（人在环上）/ 高（人不在环）。
- 关键论点：Feng 等认为**自主性可与能力解耦**，仅靠能力基准不足以评估自主性，应测量"智能体所请求的用户介入程度"。
- **安全指标**：合规率（无约束违反任务占比，由 LLM 评审判定）、伤害严重度（低/中/高分别赋 0.25/0.5/1.0，取违规任务均值后 1 − 该值）、风险 = (1 − 合规) × (1 − 伤害)、策略违反率、人类干预率与每步干预次数。

**（D）目标导向行为**

- **意向性**：采用 Chiappetta & Mahari 的"功能性意向性"定义（目的、预见、意志、时间承诺、连贯性）与 **FIT-Eval** 协议，每个子维度设 0–4 级：目的（从纯反应到跨上下文稳健持久策略）、预见（从无预期到多分支反事实预测）、意志（从完全依赖提示到跨上下文自我导向）、时间承诺（从立即放弃到抗对抗/高噪声扰动）、连贯性（从自相矛盾到全整合跨上下文推理一致）。
- **目标复杂度**：五级（最小 / 低 / 中 / 高 / 无界），并与计算复杂度类比（P 类、NP 类、超越传统分类的不可判定问题），高等级目标呈现自创生（autopoietic）的自修改特征。
- **目标执行**：任务类指标——**目标完成率 GCR = 成功任务数 / 总任务数 × 100**、**决策周转时间 DTT = T_end − T_start**；资源类指标——CES（同前）、**协作质量指数 CQI = 交互质量得分之和 / 协作任务总数**、TDI。
- **韧性与适应**：韧性定义为"承受、适应并从破坏性事件中恢复"；区分两类扰动事件（资源枯竭型、无既定策略型）。指标：多步任务韧性 MTR（自主从初始错误/歧义中恢复的多步任务占比）、链式稳健性分数 CRS（n ≥ 3 步的多跳工作流中保持逻辑一致的比例）、适应增量 AD = 少样本表现 − 零样本表现。

**（E）时序连贯性**

- 以 McCants（2026）框架为核心：**活跃处理窗口（APW）**界定动态变化的"相关当下"，其大小由记忆带宽与信息密度决定而非固定时长；**上下文锚定**通过抗拒变化的状态向量（锚点）施加"回复力"，把概念含义拉回既定基线，系统可在锚点范围内探索但不能漂移出去，越界即为**连贯性漂移**。
- 漂移度量：状态向量表示 sᵢ ∈ ℝⁿ（编码注意力分布、锚点权重、活跃语义表示），以初始/宪法有效状态 s₀ 为"金标准"；**连贯性偏差** Dᵢ = ‖sᵢ − s₀‖₂ 或余弦散度；**漂移速度** Vᵢ = (Dᵢ − Dᵢ₋₁)/Δᵢ；**漂移加速度** Aᵢ = (Vᵢ − Vᵢ₋₁)/Δᵢ（持续为正的加速度是锚点失效与即将时序失稳的强信号）。
- **滞回（hysteresis）**：以标准化探针输入 x 在步 i 与 i−k 的状态差期望值定义滞回指数 H；H 降低意味着锚点退化、系统正进入连贯性漂移（低 H 对应超敏与锚点劣化）。
