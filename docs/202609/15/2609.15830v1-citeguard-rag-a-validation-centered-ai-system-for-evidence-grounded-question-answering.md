## 摘要
检索增强生成（RAG）可以改善对复杂信息的获取；然而，仅检索证据并不能确保答案有据可依、引用有效或能被恰当拒答。本文提出CiteGuard-RAG，一种以验证为中心、面向证据支撑问答的AI系统。该系统集成了混合语义-词汇检索、引用约束生成、句子级依据验证以及单遍重生成。验证在运行时用于判断候选答案在最终交付前应被接受、拒答还是重新生成。CiteGuard-RAG在受控住房法数据集、PrivacyQA和CUAD的400个问题上进行了评估。在受控评估中，其检索准确率达到99.1%，有据答案准确率达到98.3%，引用有效率达到98.3%，且验证未检测到任何幻觉。消融实验结果表明，当移除验证时，即使检索准确率保持不变，有据答案准确率也会急剧下降。外部评估表明，尽管引用有效性仍然很高，但在领域偏移下，证据利用、片段对齐和拒答校准变得更加困难。这些发现表明，可信的RAG系统需要在检索与最终答案交付之间进行显式验证。CiteGuard-RAG提供了一种实用架构，用于在高风险信息获取中将检索、生成、引用检查、拒答和重新生成连接起来。

## Abstract
Retrieval-augmented generation (RAG) can improve access to complex information; however, retrieving evidence alone does not ensure that answers are grounded, citation-valid, or appropriately refused. This paper introduces CiteGuard-RAG, a validation-centered AI system for evidence-grounded question answering. The system integrates hybrid semantic-lexical retrieval, citation-constrained generation, sentence-level grounding validation, and single-pass regeneration. Validation is used at runtime to determine whether a candidate answer should be accepted, refused, or regenerated before final delivery.   CiteGuard-RAG is evaluated on 400 questions across a controlled housing-law dataset, PrivacyQA, and CUAD. In the controlled evaluation, it achieves 99.1% retrieval accuracy, 98.3% grounded-answer accuracy, and 98.3% citation validity, with no validation-detected hallucinations. Ablation results show that grounded-answer accuracy drops sharply when validation is removed, even when retrieval accuracy remains unchanged. External evaluation shows that while citation validity remains strong, evidence utilization, span alignment, and refusal calibration become harder under domain shift.   These findings indicate that trustworthy RAG systems require explicit validation between retrieval and final answer delivery. CiteGuard-RAG provides a practical architecture for linking retrieval, generation, citation checking, abstention, and regeneration in high-stakes information access.

## 一、核心问题与研究动机

- **背景**：大语言模型（LLM）在高风险信息获取场景（如法律问答）中受限于幻觉、来源可追溯性差、拒答行为不可靠等问题。
- **RAG 的局限**：检索增强生成虽通过外部证据缓解部分问题，但**检索成功 ≠ 有据生成**。即使检索到相关段落，模型仍可能遗漏关键证据、过度泛化、将检索文本与参数化知识混合，或产生无支撑的扩展内容。
- **法律领域的额外挑战**：法律语料庞大、异构、结构复杂（层级组织、专业术语、例外条款、论证模式），使检索、分块与证据对齐更加困难。
- **核心研究缺口**：
  - 领域偏移下 RAG 能否强制实现有据、引用有效的回答尚不明确；
  - 词法/语义/混合检索策略对下游接地与幻觉行为的影响未被充分刻画；
  - 现有验证多为事后、答案级或面向评估，缺少**句级引用与证据校验在运行时控制答案接受/重生成/拒答**的研究；
  - 检索、生成、验证、重生成常被分离评估，忽视其交互对最终可靠性的决定作用。
- **整体含义**：论文主张将**接地（grounding）视为运行时控制问题**，而非仅仅是事后评估步骤，并提出以验证为中心的 CiteGuard-RAG 架构。

## 二、方法论

### 2.1 核心思想
- 给定文档语料 D 与查询 q，系统检索证据集 E，生成内部候选答案 a_c，但**不直接交付**；而是逐句检查其主张是否可追溯至检索证据与引用，最终输出经校验的答案 a 或标准化拒答。
- 流程：`D → 解析 → 分块 → 索引 → 检索 → 候选生成 → 验证 → 接受/重生成/拒答`。

### 2.2 文档解析与分块
- **页面感知解析**：每页表示为 `Pi = {text_i, pdf_page_i, printed_page_i}`，保留 PDF 页索引与可选的印刷页码，确保检索、引用展示与评估的可追溯性。
- **段落感知分块**：优先按段落边界切分，不可用时回退到基于标点的句子级切分；相邻文本单元按最大 token 预算聚合，并带重叠以保留跨块上下文。
- **约束**：通过页面跨度限制块扩展，过滤导航文本、目录、过短片段等低信息量内容。每块存储为 `Cj = {text_j, chunk_id_j, pdf_range_j, printed_range_j}`。

### 2.3 混合检索
- **稠密检索**：用 sentence-transformer 编码块与查询，余弦相似度计算语义相关性。
- **稀疏检索**：BM25 计算词法相关性（含 IDF、词频、文档长度归一化）。
- **融合**：两路分数 min–max 归一化后加权融合：`Score_hybrid = α·ŝ_semantic + (1−α)·ŝ_lexical`，α 控制语义–词法权衡，兼顾法律精确短语匹配与语义灵活性。

### 2.4 候选过滤与可选重排序
- 用归一化文本相似度去重，减少重叠块导致的重复证据，提升上下文多样性。
- 评估了基于查询重叠与法律线索词的轻量启发式重排序器，但因**降低受控集性能**而最终禁用；也未使用神经交叉编码器重排序器（聚焦轻量、可本地部署的组件）。

### 2.5 受控证据接地生成
- 检索块格式化为带编号的源块，通过约束提示要求模型：仅依据检索源回答、用行内源标记引用、避免外部法律知识、证据不足时拒答。
- 标准化拒答语：*“文档不包含足够信息回答该问题。”*

### 2.6 生成后验证与单遍重生成
- 将候选答案分解为句子，逐句评估**引用有效性**与**接地支撑**：
  - 引用有效：引用必须指向某个检索源块。
  - 词法接地：`Overlap(s,e) = |Ts ∩ Te| / |Ts|`（阈值 0.10）。
  - 语义接地：句向量余弦相似度（阈值 0.40）。
  - 句子被判定为“有支撑”需同时满足引用有效，且通过词法**或**语义阈值（二者其一）。
- **支持句比例**：`SupportedRatio = (n − u) / n`，n 为总句数，u 为无支撑句数；含一个及以上无支撑句即被标记为幻觉。
- **触发重生成的情形**：无效引用、证据支撑薄弱、无支撑内容、引用格式错误、或在检索上下文充分时仍拒答。
- 重生成仅允许**一次**，使用更严格的接地提示；仅当改进验证合规性或产生干净拒答时才被接受，以控制推理成本、避免无界修正循环。

### 2.7 算法流程（Algorithm 1 概要）
1. 解析 D 为页面感知文本单元 → 2. 构建段落感知证据块 → 3. 混合检索候选 E′ → 4. 去重并选 top-k 证据 E → 5. 若证据不足则返回标准拒答 → 6. 用引用约束提示生成候选 a0 → 7. 计算验证结果 v0 → 8. 若通过则返回 a0 → 9. 否则用验证反馈生成 a1 → 10. 再次验证，通过则返回 a1，否则返回标准拒答。

## 六、主要结论与发现

- **检索本身不足以保证可靠生成**：移除验证后检索准确率保持 99.1% 不变，但有据答案准确率从 98.3% 骤降至 8.7%，引用有效性从 98.3% 降至 12.3%，幻觉率从 0.0% 升至 18.6%。
