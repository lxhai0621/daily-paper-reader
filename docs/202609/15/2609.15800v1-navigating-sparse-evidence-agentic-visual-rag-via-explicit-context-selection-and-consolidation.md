## 摘要
视觉检索增强生成（VRAG）使模型能够通过检索相关页面图像作为视觉证据并推理其内容，来浏览和回答关于视觉丰富文档的查询。然而，有效利用这些视觉证据通常受到两个主要挑战的阻碍。首先，与答案相关的证据是稀疏的，可能集中在一页的一小块区域，也可能分散在多个页面中。其次，现有的智能体方法通常基于原始探索轨迹或压缩的文本记忆生成答案，而不是基于一组显式组织的支撑图像，这使得答案容易受到探索噪声的影响，并模糊了有证据支持的推理轨迹。我们认为，瓶颈不仅在于证据发现，还在于答案生成前对证据的保存与组织。我们提出SCoRE（Selection and Consolidation for Robust Evidence，即面向稳健证据的选择与整合），一个用于显式证据选择与整合的统一智能体循环。在探索过程中，SCoRE仅在维护的文本账本中保留与查询相关的观察及其来源指针，从而在保持视觉上下文有界的同时保存先前的证据。在终止时，它重新加载所引用的原始图像，并整合视觉证据以用于回答，将其排列成逻辑序列。这将最终推理与探索性试错解耦，同时通过索引化的论断—图像链接确保严格的视觉锚定。为实现该统一rollout的端到端优化，我们的训练范式将经过过滤的冷启动轨迹蒸馏与证据感知强化学习相结合，其奖励促进证据覆盖度、整合紧凑性和答案正确性。

## Abstract
Visual Retrieval-Augmented Generation (VRAG) empowers models to navigate and answer queries about visually rich documents by retrieving relevant page images as visual evidence and reasoning over their content. However, effectively utilizing this visual evidence is usually impeded by two main challenges. First, answer-relevant evidence is sparse and may be concentrated in a small region of one page or dispersed across multiple pages. Second, existing agentic methods often generate answers based on raw exploration trajectories or compressed textual memories rather than an explicitly organized set of supporting images, making answers susceptible to exploration noise and obscuring the evidence-backed reasoning trace. We argue that the bottleneck lies not only in evidence discovery but also in its preservation and organization before answer generation. We propose SCoRE (Selection and Consolidation for Robust Evidence), a unified agent loop for explicit evidence selection and consolidation. During exploration, SCoRE retains only query-relevant observations and their source pointers in a maintained textual ledger, preserving earlier evidence while keeping the visual context bounded. At termination, it reloads the referenced original images and consolidates the visual evidence for answering, arranging it into a logical sequence. This decouples final reasoning from exploratory trial-and-error while ensuring strict visual grounding via indexed claim-to-image linkages. To enable end-to-end optimization of this unified rollout, our training paradigm combines filtered cold-start trajectory distillation with evidence-aware reinforcement learning, whose reward promotes evidence coverage, consolidation compactness, and answer correctness.

## 一、核心问题与研究动机

- **背景**：视觉检索增强生成（VRAG）将 RAG 扩展到幻灯片、报告、扫描 PDF 等视觉丰富文档，以整页图像为检索与推理单元。相比 OCR 式方法，它能保留布局、图表、表格等关键多模态线索。
- **两大挑战**：
  1. **证据分布不均（Uneven Evidence Distribution）**：答案相关证据可能仅集中在单页的一小块区域（如一行小字、一个图例），也可能分散在多个页面中，同时存在大量噪声页。
  2. **证据组织隐式化（Implicit Evidence Organization）**：现有智能体方法（如 VRAG-RL 保留原始探索轨迹、VISOR 蒸馏为文本记忆）按“探索顺序”而非“回答所需逻辑顺序”组织证据，导致答案受探索噪声干扰、证据链不可追溯。
- **核心洞见**：瓶颈不仅在于“证据发现”，更在于答案生成前对证据的**保存与组织**。探索应负责发现证据，整合应负责将证据还原并组织成面向回答的视觉证据链。

## 二、方法论：SCoRE 框架

### 2.1 核心思想
提出 **SCoRE（Selection and Consolidation for Robust Evidence）**，一个统一智能体循环，在同一 rollout 内完成**探索 → 证据维护 → 整合 → 回答**，将试错探索与最终推理解耦，同时通过索引化的“论断—图像”链接保证严格视觉锚定。

### 2.2 状态与上下文构造
- 维护两个持久状态：**文本证据账本 L** 与**交互历史 H**。
- 每轮上下文由固定提示、账本、最近 W 轮交互和当前观察拼接而成：
  - `Ct = [Pinit ; Lt ; H_{t-W+1:t-1} ; ot]`，文中取 **W = 2**（保留一次“检索—缩放”链）。
- 超出窗口的原始图像被驱逐，但其查询相关内容已蒸馏进文本账本，从而**有界控制视觉 token 消耗**。
- 引入**意图注入（Intent Injection）**：每次系统返回观察时附带针对当前动作的提示，重述查询并指向已收集证据，防止长程漂移。

### 2.3 动作空间（每轮输出三部分）
- `<observe>`：对当前视觉内容的总结；
- `<relevant>`：二值相关性判断（yes/no）；
- `<action>`：三选一：
  - `<search>`：文本查询 → 视觉检索器返回 top-1 未见过页面；
  - `<bbox>`：在当前页上指定边界框 → 裁剪放大局部区域（动态分辨率控制，解决整页降采样后小字/图表不可读的问题）；
  - `<consolidate>`：终止探索，触发重载与整合。

### 2.4 证据账本的“选择—整合”两阶段
- **来源链接的视觉证据选择**：
  - `Lt = Lt-1 ∥ [(src_t, õ_t)]`，若 ρt = yes；否则 `Lt = Lt-1`。
  - 每条保留条目将文本观察 `õ_t` 与其原始图像源（页面 + bbox 坐标）绑定，供整合阶段重载。
  - 被标记 no 的观察只短暂留在有界窗口中，随窗口推进移除。
- **全局证据整合**：
  - 当触发 `<consolidate>` 或达到最大轮数 T 时，重载账本引用的原始图像；
  - 若图像数 > 1，则对重载图像**重新选择、去噪并重排为逻辑顺序**；若仅 1 张则直接使用；
  - 最终答案生成时标注每条论断对应的账本条目，实现“论断—图像”可追溯。

### 2.5 训练范式（两阶段）
- **冷启动：过滤式轨迹蒸馏**
  - 教师模型 Qwen3.5-122B-A10B 在 SlideVQA 训练查询上生成完整 SCoRE 轨迹；
  - 保留条件：**LLM 判定答案正确 且 全覆盖金标页面**（金标页须出现在最终答案账本中，而非仅被检索到）；
  - 进行 assistant-only 掩码的 SFT，教授结构化输出格式、账本管理与整合行为。
- **强化学习：证据感知奖励（GRPO）**
  - 定义 `P(L) = {page(src) : (src, õ) ∈ L}`，`P*` 为金标页集合，`Pans` 为最终答案账本页面集合：
    - `cov = |P* ∩ Pans| / |P*|`（Recall，奖励保留金标页）；
    - `cmp = |P* ∩ Pans| / |Pans|`（Precision，奖励账本紧凑、惩罚无关检索）。
  - 轨迹奖励：
    - `r = cov + λcmp · I_{cov=1} · cmp + I_{cov=1} · rans − I_{cov<1} · β`
    - 其中 `λcmp = 0.2`，`β = 1`，`rans` 为二元 LLM-as-judge 答案正确性。
  - **门控机制**：紧凑项与答案奖励仅在全覆盖（cov=1）时生效，覆盖不全则施加惩罚 β，防止通过丢弃证据来刷 cmp 或凭不完整账本获得答案奖励。
  - RL 时遮蔽检索视觉观察与系统注入 token，仅对智能体生成 token 计算损失。

## 六、主要结论与发现

- **SOTA 表现**：SCORE 在三个基准、两种骨干规模上均取得最佳整体准确率。7B 下 SlideVQA 72.37→77.16、ViDoSeek 74.87→75.31、MMLongBench 28.45→31.52；3B 下同样保持领先。
- **增益来源**：多跳与复杂布局场景增益最大（SlideVQA 多跳 53.62→62.26；MMLongBench 在 Text/Chart/Figure/Layout 上最佳）。
- **模块互补**：相关性判断与整合缺一不可；训练后去噪责任从“出口”（整合）转移到“入口”（相关性判断）。
- **训练阶段**：主要增益来自冷启动 SFT（55.17→75.62），RL 进一步小幅提升（→77.16）；SFT 显著提升账本覆盖与多跳准确率，RL 更多是“边际精炼”。
- **效率**：SCORE 平均 3.65 轮、3468 token、6.42s 延迟，优于 ViDoRAG（6.22 轮、23259 token、18.85s）等；SCORE-direct 在 4.97s 达到 70% 准确率，位于 Pareto 前沿。
- **覆盖—噪声张力**：高检索完整性不等于高准确率（ViDoRAG 完整性 91.3 但噪声 8.81 页）；SCORE 将噪声页降至 0.16（约为图像类基线最低值的 1/5），以严格筛选换来最高准确率。
- **骨干效应**：增益在中等容量（7B，+18.19）最大，强模型（122B，+2.21）因自身已能处理多图推理与噪声而增益收窄；3B 在仅 prompt 下难以可靠执行整合。
- **失败模式**：错误主要来自细粒度视觉结构感知（如密集图表中品牌与年份的错误绑定），而非检索失败。
