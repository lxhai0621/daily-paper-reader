## 摘要
设计有效的记忆机制对于推进LLM驱动的多智能体系统（MAS）至关重要，有助于智能体共同学习并随时间推移表现得更好。尽管近期工作已带来强大的协作能力，但大多数方法仍使用扁平、无结构的记忆，这类记忆容易被噪声填满并抹除智能体之间的差异。为解决这一问题，我们引入集体-个体记忆协同的概念，并提出CoMem，一种统一私有经验与共享知识以支持多智能体学习的架构。CoMem具有：（i）私有经验沉淀，允许每个智能体随时间保留并更新自身有用的记忆；（ii）集体智慧精选，仅仔细选择被广泛验证的想法在智能体之间共享；（iii）并行双流检索，使智能体既能从自身记忆中提取，也能利用群体智慧，并通过聚类来确保多样性。在ALFWorld和PDDL基准上的实验表明，CoMem取得了强劲的整体性能，并稳健地避免了记忆污染。

## Abstract
Designing effective memory mechanisms is crucial for advancing LLM-driven Multi-Agent Systems (MAS), helping agents learn together and perform better over time. While recent work has led to strong cooperation skills, most methods still use flat, unstructured memories, which easily get filled with noise and erase differences between agents. To address this, we introduce the concept of collective-individual memory synergy and propose CoMem, an architecture that unifies both private experience and shared knowledge for multi-agent learning. CoMem features:(i) Private Experience Sedimentation, which lets each agent keep and update its own useful memories over time;(ii) Collective Wisdom Curation, which carefully selects only widely proven ideas to be shared among agents;(iii)Parallel Dual-Stream Retrieval, which allows agents to draw both from their own memory and the group's wisdom, using clustering to ensure diversity.Experiments on ALFWorld and PDDL benchmarks show that CoMem achieves strong overall performance and robustly avoids memory pollution.

## 1. 核心问题与整体含义

- **研究背景**：LLM 驱动的多智能体系统（MAS）已成为解决复杂协作任务的重要范式（AutoGen、CAMEL、ChatDev、MetaGPT、DyLAN、MacNet、CARD 等）。随着任务难度提升，智能体不仅要协作，还需从历史经验中持续学习，因此**群体记忆（group memory）** 成为支撑长期群体智能的关键。

- **核心问题：记忆污染（Memory Pollution）**。现有 MAS 记忆机制大多采用**扁平、无结构的共享记忆池**，所有智能体不加区分地读写，导致两类相互强化的退化：
  - **噪声累积（Noise Accumulation）**：未经证实的试错行为、偶然成功记录持续涌入共享池，降低存储质量与可靠性。
  - **行为同质化（Behavioral Homogenization）**：跨智能体的反复覆写使角色特定认知轨迹被"平均化"，作者用公式 $\lim_{t\to\infty} H(\pi_{a_i} \| \pi_{a_j}) = 0$ 形式化刻画角色差异的消失。

- **整体含义**：论文主张可持续的群体智能需要**个体稳健学习**与**群体有意义知识**之间的平衡——类比人类社会"个体提议 → 集体筛选 → 共识结晶"的知识演化过程。目标是将记忆解耦为私有层 $\{M^{(i)}_{priv}\}$ 与集体池 $M_{coll}$，既保护个体学习纯度，又沉淀组织级通用智慧。

## 2. 方法论

### 2.1 核心思想

CoMem 采用**双层解耦记忆架构**（Private Layer + Collective Pool），通过一条**双向流动路径**耦合：私有经验经使用感知的滚动剪枝保留，经验证达到阈值的条目被"晋升"到集体池；集体池中效用衰减的条目则被清除。

### 2.2 记忆单元结构

每个记忆条目存储为结构化元组：

$$m = \langle doc\_content,\ metadata \rangle$$

其中 $metadata = \{agent\_name,\ S,\ n_{use},\ n_{succ},\ \iota_{prom}\}$，分别表示归属智能体、效用分数、调用次数、成功调用次数与晋升状态。

### 2.3 三大关键组件

**(i) 私有经验沉淀（Private Experience Sedimentation）**

- 每轮 episode 结束后，智能体 $a_i$ 提取自身执行轨迹 $\tau_i^k = \{(s_1,x_1,y_1),\dots,(s_t,x_t,y_t)\}$（环境状态、思维链推理、动作）。
- 由 LLM 反思蒸馏器从**该智能体的独特视角**将其压缩为少量简洁、可操作的个人洞见，存入私有记忆 $M^{(i)}_{priv}$，赋予初始效用分 $S_0$。
- **严格访问控制**：按 agent identity 过滤，杜绝跨智能体污染。
- **滚动剪枝**：每个条目维护连续未命中计数 $K_{miss}(m)$。若本轮被检索并注入提示则归零，否则 +1；超过阈值 $K_{max}$ 则永久删除。

**(ii) 集体智慧精选（Collective Wisdom Curation）**

- **经验晋升门控**（baseline-conditioned rule）：

$$\iota_{prom} = \mathbb{I}\left[ N_{use}(m) \geq N_{min} \ \wedge\ \bar{R}_m \geq \bar{R} \right]$$

其中 $N_{use}(m)$ 为条目被成功检索的 episode 数（统计下限 $N_{min}$），$\bar{R}_m$ 为使用该条目时的平均任务得分，$\bar{R}$ 为环境全局历史平均表现的滑动基线。仅同时满足"充分曝光"与"持续高于平均"的条目晋升，且晋升后从私有存储移除以避免冗余。

- **集体条目持续质量控制**——混合效用评分：

$$U_t(m) = w \cdot R_{norm} + (1-w) \cdot \frac{1}{|A_m|}\sum_{a \in A_m} \frac{LLM_a(m)}{L_{max}}$$

融合客观归一化回报 $R_{norm}$ 与离线 LLM 聚合的主观洞见质量评分，$w$ 控制二者权重。

- **长期效用 EMA 更新**：

$$S_{t+1}(m) = (1-\alpha) S_t(m) + \alpha \cdot (S_{max} \cdot U_t(m))$$

低于自适应阈值的条目被系统性剔除，保证集体池精简、相关、仅含久经检验的组织智慧。

**(iii) 并行双流检索（Parallel Dual-Stream Retrieval）**

- **私有流**：基于语义嵌入相似度（RAG 范式），从个体层检索 top-ranked 条目注入提示，提供个性化战术指导。
- **集体流 + 多样性过滤**：并发检索团队级已验证智慧；针对多智能体语义重叠风险，引入**在线层次聚类过滤器**，按语义距离分组并每组选一个代表性条目，构建简洁且多样的共识上下文，节省 token 空间。
- 双流并行消除顺序查找瓶颈，实现"无跨层污染"的协同。

## 6. 主要结论与发现

- **结论 1：CoMem 跨框架一致领先**。在 MacNet 上将 ALFWorld 从 79.85 提升至 89.55、PDDL 从 60.78 提升至 70.19；四个框架平均绝对增益为 ALFWorld **+8.02**、PDDL **+4.70**。即便在强基线 CARD 上仍从 84.33→90.30、70.01→72.74。

- **结论 2：传统协作式共享记忆常不如无记忆基线**。如 DyLAN+PDDL 上 G-Memory 仅 59.53（低于 No-memory 67.78），MetaGPT 降至 52.80；单智能体记忆适配 MAS 亦表现不稳定。这印证了噪声累积与行为同质化双重退化的存在。

- **结论 3：成本–性能比优良**。CoMem 以适度 token 增加（主要来自并行双流检索与晋升验证）换取显著且一致的性能提升；协作基线往往消耗相近甚至更高 token 却无稳定收益。

- **结论 4：两层结构均必要且私有层更关键**。AutoGen+PDDL 上完整配置 74.44，去掉集体层降至 62.41（-12.03），去掉私有层降至 65.10（-9.34），说明私有层对抵抗记忆污染的保护略强。

- **结论 5：超参存在倒 U 型最优**。检索深度 $k$ 在 $\{3,5\}$ 稳健（过大注入噪声、过小缺上下文）；$K_{max}$ 在 PDDL 最优为 5、ALFWorld 为 6；EMA $\alpha$ 在两个数据集上均以 **0.5** 为最优（过小滞后于环境变化，过大对单次异常过度反应）。
