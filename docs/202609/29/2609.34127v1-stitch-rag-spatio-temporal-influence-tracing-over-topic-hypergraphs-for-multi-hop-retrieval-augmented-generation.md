## 摘要
多跳检索增强生成要求检索器连接分布在文档中的证据，同时保持生成上下文简洁且忠实。现有索引留下两个互补的缺口：基于块的RAG可能破坏跨段落证据链，而缺乏生成主题来源的无标注成对投影无法同时保留主题级共同参与和每次出现的实体描述。我们提出STITCH-RAG，一个基于超图的框架，包含三个耦合组件。首先，半合并主题超图将多实体共同参与编码为主题摘要超边，同时保留通过规范名等价性链接的逐块实体状态。其次，时空影响桥接传播（STIBP）在频率自适应衰减下，将主题空间传播与跨名称等价状态的确定性块索引链接相结合。第三，连续STIBP分数替代局部化个性化PageRank（PPR）中的二元实体匹配种子。我们刻画了该先验在何种条件下会比二元先验向真实证据分配更多PPR质量。在报告协议下，STITCH-RAG在HotpotQA和2WikiMultiHopQA上相比所比较方法取得了最高报告的Contain-Acc和LLM-Acc点估计，并在标准化检索比较所包含的方法中取得更高的Recall@8。混合领域基准上的结果仍作为辅助性的基于偏好的证据，因为仅可获得由LLM评判的准确率。

## Abstract
Multi-hop retrieval-augmented generation requires a retriever to connect evidence distributed across documents while preserving a concise, faithful generation context. Existing indexes leave two complementary gaps: chunk-based RAG can break cross-passage evidence chains, whereas an unlabeled pairwise projection without generating-topic provenance cannot jointly preserve topic-level co-participation and per-occurrence entity descriptions. We propose STITCH-RAG, a hypergraph-based framework with three coupled components. First, a semi-merged topic hypergraph encodes multi-entity co-participation as topic-summary hyperedges while retaining per-chunk entity states linked by canonical-name equivalence. Second, spatio-temporal influence bridging propagation (STIBP) combines topic-space propagation with deterministic chunk-index linkage across name-equivalent states under frequency-adaptive decay. Third, continuous STIBP scores replace binary entity-match seeds in localized Personalized PageRank (PPR). We characterize the condition under which this prior assigns more PPR mass to ground-truth evidence than a binary prior. Under the reported protocol, STITCH-RAG attains the highest reported Contain-Acc and LLM-Acc point estimates among the compared methods on HotpotQA and 2WikiMultiHopQA, and higher Recall@8 than the methods included in the standardized retrieval comparison. Results on the mixed-domain benchmark remain auxiliary preference-based evidence because only LLM-judged accuracy is available.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：多跳检索增强生成（Multi-hop RAG）要求检索器把分散在不同文档/段落中的证据串联起来，同时给生成器提供简洁、忠实的上下文。
- **现有索引的两类互补缺口**：
  - **基于分块（chunk）的 RAG**：按固定长度切块并按查询相似度排序，容易打断跨段落、跨文档的证据链（论文图 1(a) 中"Film X → Alice Smith → Canada"被切断）。
  - **无标签的成对（pairwise）投影**：缺少"生成该共现关系的主题"这一溯源信息，无法同时保留**主题级多实体共同参与**与**每次出现的实体描述**。论文明确指出，这一限制不适用于带关系标签、溯源、事件 ID 等等价高阶属性的成对图（Proposition 1 仅针对丢弃主题标识的输入）。
- **实体合并的两难**：
  - **完全合并**（full-merge）重复实体提及，会抹去逐块的局部角色/描述（如"出生地"语境与"获奖"语境被混为一个静态 Alice Smith 节点）；
  - **完全不合并**（no-merge）则丢失显式的跨块身份链接。
  - 两种选择在证据依赖主题语境与局部实体状态时都会引入检索噪声。
- **论文主张**：新颖性不在于单个组件，而在于把**保主题超边、语境化实体状态、可操作的名称等价链接、连续 PPR 初始化**四者耦合进同一条检索流水线。

## 2. 方法论

### 2.1 整体思想：compress-then-amplify

- **压缩阶段**：文档 → 块 → 半合并主题超图 H = (V, E, φ, ψ)。
- **放大阶段**：时空影响桥接传播（STIBP）识别相关实体状态通路，再在块级图上做局部化近似 Personalized PageRank（PPR）。
- **术语澄清（重要）**：
  - **spatial（空间）** = 同一超边内的主题共同参与；
  - **temporal（时间）** = 确定性预处理索引中的邻近性，**不是**阅读顺序、编年史、事件时间或因果关系。

### 2.2 半合并主题超图构建

- 用 LLM 提示 `p_ext` 对每个块 c_k 抽取元组 g_{k,r} = (e_{k,r}, V_{e_{k,r}})：主题摘要超边 + 其实体集；要求输出可解析 JSON，实体描述必须落地在原文，缺失则置空字符串。
- **节点** v = (v_name, v_des)：规范名 + 该块特定的描述（ψ 记录局部语境）。
- **φ : V → Σ**：把归一化后同名的提及归入同一"名称等价组"，组内按确定性预处理索引 t_v 排序。论文明确 φ 只是**名称等价启发式**，不是真实实体链接（别名会误分、同形异义会误连）。
- **相对成对投影的结构优势**：含 m 个实体的主题超边用 m 条关联边而非 C(m,2) 条成对边，并保留生成主题身份。

### 2.3 STIBP：空间与索引邻近双通道传播

- **初始激活**：A_q(v) = sim(q, v_des) 若 > δ（δ=0.5），否则 0；超边用未阈值化的 S_q(e) = sim(q, e)。
- **空间桥接**：对已激活 u ∈ e 及每个 v ∈ V_e \ {u}：
  - a_space(v) = A_q(u) · S_q(e)（同时要求源激活与主题相关）。
- **时间（索引邻近）桥接**：对 u 的名称等价组 V*_u，α = n_u / n̄（n_u 为组大小，n̄ 为语料平均组大小），Δt = |t_u − t_v|：
  - a^time_u(v) = A_q(u) · S_q(e_v) · exp(−tanh(αΔt)) · sim(q, c_v)
  - 衰减 f(Δt) = exp(−tanh(αΔt)) ∈ (e⁻¹, 1]：远端证据仍保留非零质量但被衰减；**名字越常见（α 越大），远端状态被抑制越强**。
  - 通道内按来源取 max 聚合（a^time(v) = max(0, max_u a^time_u(v))）。
- **最终实体影响**：a(v) = mean(A_q(v), a_space(v), a_time(v))（三通道等权，排序等价于求和，因每个节点都有三通道）。

### 2.4 块分数投影与局部化近似 PPR

- **实体影响投影到块**：Score(c) = Σ_{v∈V(c)} a(v) · ln(1 + N_v)，N_v 为 v 所在名称等价组大小。
- **连续先验**：ẽI(c) = λ·max{0, sim(q,c)} + ln(1 + Score(c))，λ=0.3；在查询诱导候选集 C_q 上归一化为 p_ST；全零时回退均匀分布。
- **块图**：B(c) = {c′ | 存在 u∈V(c), v∈V(c′) 使 φ(u)=φ(v)}；列归一化得 P，悬挂块自环。
- **PPR 迭代**：π⁽ᵗ⁾ = (1−d)p_ST + dPπ⁽ᵗ⁻¹⁾，π⁽⁰⁾=p_ST，d=0.85，直到 max 变化 < 10⁻⁶；取 top-k（k=8）块送入生成器。
- 关键点：STIBP 与 PPR 均**无需查询时 LLM 调用**，只作用于激活子图（查询诱导集 C_q）。

### 2.5 理论刻画（均为机制性，非端到端保证）

- **Proposition 1（成对主题投影的不可辨识性）**：构造 H₁、H₂ 使 Π(H₁)=Π(H₂)=K₄，但主题选择性传播结果不同 → 仅凭无标签成对投影的检索规则无法一般性复现超边级传播。
- **Proposition 2（半合并实体状态的可恢复性分离）**：在给定假设下，no-merge 下 v_r 得不到时间影响（无跨块 φ）；full-merge 下 v_r 的影响要么被均摊（描述被聚合稀释）要么为零；**只有 semi-merge 同时保留 φ 与 ψ**，使 a(v_r) = (1/3)a_time(v_r) > 0。
- **Theorem 1（频率自适应衰减下的单源下界分离）**：在信号集 R（g_r ≥ β）与噪声集 N（0 < g_n ≤ ϵ，Δ_n ≥ τ）下，信噪比 ≥ (β/(|N|ϵ))·exp(tanh(ατ) − 1)，且对 α 单调不减；但**不含最终 max 聚合与端到端检索**，且允许对远端相关状态的过度抑制。
- **Proposition 3（先验对齐下的折扣证据质量恒等式）**：定义证据可达足迹 h_R = (1−d)Σ_{ℓ≥0} d^ℓ (P^ℓ)ᵀ1_R，则 M_R(p_ST) − M_R(p_B) = h_Rᵀ(p_ST − p_B)；若该差值 ≥ γ > 0，则连续先验分配的 PPR 证据质量至少比二值先验多 γ。论文明确该**充分对齐条件未被独立验证**。
- **复杂度**：离线 O(N_C + N_V + N_E + M + Σ_g n_g log n_g)、线性存储；在线含候选生成 + 激活超边关联 + 名称组传播 + T 次局部 PPR。

## 3. 实验设计

- **数据集 / 场景**：
  - **HotpotQA**、**2WikiMultiHopQA**：沿用 HippoRAG 协议，各分层抽样 1,000 题（HotpotQA 约 520 bridge / 480 comparison；2Wiki 约 280 comparison / 250 inference / 240 compositional / 230 bridge）。

- **对比方法（Baselines）**：Zero-shot、Standard-RAG（稠密检索）作为下界；LightRAG（关系抽取）、LinearRAG（最接近的结构性前作，平坦实体图 + 二值实体匹配初始化的 PPR）、HippoRAG（PPR 图记忆）、Cog-RAG 与 Hyper-RAG（近期超图方法）。
