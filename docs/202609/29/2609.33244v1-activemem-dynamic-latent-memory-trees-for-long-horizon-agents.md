## 摘要
大语言模型（LLM）智能体日益依赖外部记忆来支持长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立上下文片段进行检索，忽略了多步执行背后的过程性依赖。随着记忆规模扩大，这种扁平检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种分层记忆框架，可将智能体经验递归组织为依赖关系感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态记忆扩展、检索与剪枝策略。在多种智能体基准上的实验表明，ActiveMem 在任务完成度、推理稳定性和记忆效率方面持续优于现有基于记忆的智能体。此外，ActiveMem 使紧凑的开放权重模型能够达到与规模显著更大的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

## 2. 方法论

### 核心思想

- 将智能体历史经验递归组织为 **Hierarchical Latent Memory Tree（HLMT，层次潜在记忆树）**。
- 树节点表示可复用的子任务级潜在摘要，边表示执行依赖/父子层次关系。
- 检索时不再返回孤立历史片段，而是根据当前执行状态检索一条依赖一致的记忆路径。
- 记忆拓扑不是静态追加，而是通过强化学习动态执行扩展、更新、合并、剪枝。
- 冻结 LLM 主干，仅训练轻量控制器，用潜在记忆前缀调制 LLM 推理。

### 关键技术细节

- **记忆树节点定义**：节点 \(n_i=(e_i, pa(i), ch(i))\)，其中 \(e_i\) 是节点潜在嵌入，\(pa(i)\) 是父节点，\(ch(i)\) 是子节点集合。
- **树更新**：整体记忆状态按 \(T_t = TreeUpdate(T_{t-1}, a_t^{tree})\) 演化。
- **检索**：
  - 以当前状态隐藏表示 \(h_t\) 为查询。
  - 从根节点递归贪心向下遍历，每层选择与 \(h_t\) 余弦相似度最大的子节点。
  - 当最大相似度低于阈值 \(\tau_{stop}\) 时停止，得到激活路径 \(P_t\)。
- **双头控制器**：
  - 对检索路径做均值池化，得到 \(\bar p_t\)。
  - 与当前隐藏状态拼接后经共享 MLP 得到 \(u_t\)。
  - **Latent Injection Head**：生成连续潜在记忆前缀 \(m_t=W_{latent}u_t\)，作为 soft prompt 或 KV 前缀注入冻结 LLM，调制其推理。
  - **Tree Action Head**：输出离散拓扑动作分布，采样插入、更新、合并、删除等树操作。
- **拓扑更新分两类**：
  - **立即执行**：在线插入新节点或更新叶节点，新嵌入做 L2 归一化，防止表示坍缩。
  - **延迟执行**：回合结束后根据环境回报维护树，用 EMA 平滑节点效用，剪除低效用节点，合并高相似兄弟节点。
- **训练方法**：
  - 使用 **GRPO** 优化控制器参数，避免额外 critic 网络。
  - 引入可验证过程监督，节点效用包含步骤奖励和最终回报。
  - 分层优势由全局组相对优势和局部父子相对优势组成，并做深度折扣。
  - 联合优化潜在注入目标和树动作目标：\(L(\phi)=L_{latent}^{GRPO}+\lambda L_{tree}^{GRPO}\)。
- **算法流程概括**：
  1. 初始化虚拟根节点。
  2. 每步提取当前隐藏状态，检索记忆路径。
  3. 控制器生成潜在记忆前缀并注入 LLM。
  4. LLM 生成动作并与环境交互。
  5. 根据树动作在线更新或缓存拓扑操作。
  6. 回合结束后执行维护、剪枝、合并，并用 GRPO 更新控制器。
