## 摘要
长期记忆通过跨任务保留经验与技能，并支持其在后续长时程决策中的检索、复用和修正，从而支撑 LLM 智能体的自我演化。然而，现有记忆管理方法仍局限于判别式检索，并且需要应对可复用经验所呈现的稀疏、分层且高度冗余的结构：只有一小部分任务相关的轨迹和记忆值得保留、检索或修正。此外，稀疏、延迟且间接的任务级反馈，以及记忆生命周期内薄弱的监督信号，使这些操作的学习更加复杂。而且，持续的记忆演化带来了一种架构张力，即寻址不变性：存储的经验不断被修正，而学习到的检索策略所使用的寻址接口必须保持稳定。为解决这一问题，我们提出 GenMem，将记忆管理重新表述为生成式符号寻址。其核心机制是符号标识符（Symbolic Identifier, SID），这是一种多级离散 token 元组，取自笛卡尔积地址空间；该空间使用不到一百个离散符号，对百万规模的稀疏记忆空间进行因子化分解。记忆智能体不再生成不断变化的原始内容，而是学习生成 SID；同时，记忆演化在固定地址处重写有效载荷，而不改变地址本身。在架构上，GenMem 在多智能体运行框架中耦合了 MemRetriever 和 MemEvolver，并通过 GRPO 进行训练，采用稠密的过程奖励和结果奖励，并进行双通道优化。在离线记忆演化下，涵盖 ALFWorld、WebShop、多跳问答、医学推理和深度研究的实验，评估了 GenMem 相较于强记忆增强基线的表现……

## Abstract
Long-term memory supports the self-evolution of LLM agents by retaining experience and skills across tasks and enabling their retrieval, reuse, and revision in subsequent long-horizon decision-making. Yet existing memory management approaches remain limited to discriminative retrieval and to address the sparse, hierarchical, and highly redundant structure of reusable experience: only a small, task-dependent subset of trajectories and memories warrants retention, retrieval, or revision. Learning these operations is further complicated by sparse, delayed, and indirect task-level feedback, with weak supervision across the memory lifecycle. Moreover, continual memory evolution introduces an architectural tension as addressing invariance: stored experience is perpetually revised, yet the addressing interface consumed by learned retrieval policies must remain stable. To address, we present GenMem, which reformulates memory management as generative symbolic addressing. Its core mechanism is the Symbolic Identifier (SID), a multi-level discrete token tuple drawn from a Cartesian-product address space that factorizes a million-scale sparse memory space using fewer than one hundred discrete symbols. Instead of generating ever-changing raw content, the memory agent learns to generate SIDs, while memory evolution rewrites the payload at a fixed address without shifting the address itself. Architecturally, GenMem couples a MemRetriever and a MemEvolver within a multi-agent harness, trained via GRPO with dense process and outcome rewards with two-channels optimization. Under offline memory evolution, experiments spanning ALFWorld, WebShop, multi-hop QA, medical reasoning, and deep research evaluate GenMem against strong memory-augmented baselines...

## 1. 核心问题与研究动机

### 1.1 背景
- 长期记忆是 LLM 智能体自我演化的关键：跨任务保留可复用的经验与技能，并支持在后续长时程决策中**检索、复用、修正**。
- 与百科式知识不同，这类**经验型记忆**具有三个特征：行动导向（action-oriented）、情境依赖（context-conditioned）、持续演化（continuously evolving）。
- 因此核心问题从"哪条记忆与查询最相似"转变为"哪段经验最能推进智能体当前策略"——且该问题必须在经验本身不断改写的前提下仍然可回答。

### 1.2 两大挑战
- **❶ 稀疏性挑战（Sparsity）**
  - 经验高度冗余：在获取、组织、检索、演化全生命周期中，只有极小部分具有可复用价值；任一查询只与很窄的区域相关；修正集中在被反复触发的条目上。
  - 扁平稠密存储不显式编码"共享子技能"（如多个网页导航任务共享"先搜索再筛选"套路），随记忆库增长会稀释关键关联。
  - 监督进一步恶化：经验效用只能通过延迟、间接的任务结果体现，稀疏的终局奖励难以对单个记忆操作做信用分配。
- **❷ 寻址方差挑战（Address Variance）**
  - 当检索依赖由"当前记忆内容"派生的表示时，每次内容修订都会静默改变哪些查询能命中该条目，即使其功能角色未变。
  - 论文提出**寻址不变性（addressing invariance）**：内容可变，但地址必须稳定。需要"解耦 *where* 与 *what*"——稳定的离散坐标标识功能区域，坐标背后的文本可自由编辑。
  - 由此，智能体应学的不是随修订过时的内容版本，而是"问题 → 所需经验功能角色"的持久映射。

### 1.3 动机类比
- LoRA 用低秩更新、MoE 用稀疏激活、Engram 用条件化知识存储，均利用高维空间中的隐藏规律；同理，可复用经验集中在稀疏、层级化的区域，需要**选择性且稳定的寻址**。

## 2. 方法论

### 2.1 核心思想
- 将记忆管理重构为**生成式符号寻址（generative symbolic addressing）**：记忆智能体不生成不断变化的原始内容，而是学习**生成 SID**；记忆演化只在固定地址处重写载荷（payload），不移动地址。
- 统一了"记忆读取"与"记忆写入/更新定位"两个操作，共享同一符号地址空间。

### 2.2 符号标识符（SID）定义
- 记忆库 \(M=\{m_i\}_{i=1}^N\)，每条 \(m_i=(x_i, z_i)\)：\(x_i\) 为文本经验载荷，\(z_i\) 为 SID。
- SID 是 \(L\) 级离散符号元组：\(z_i=(s_i^1,\dots,s_i^L)\in \mathcal{Z}=[N_1]\times\cdots\times[N_L]\)。
- 给定上下文 \(c\)（可为查询、轨迹或新蒸馏经验），策略生成 \(z=\text{ADDR}_\theta(c)\)，查表得 \(x=\text{LOOKUP}(M,z)\)。
- 容量与词表：\(K_{addr}=\prod_\ell N_\ell\)（可能地址数），\(V_{SID}=\sum_\ell N_\ell\)（层符号总数）。
- **关键性质**：SID 标识的是"记忆槽位"而非某一内容版本；演化写作 \((x_i,z_i)\to(x_i',z_i)\)，地址不变。
- 实际配置：码本 \((48,16,8,8)\)，即 **80 个离散 token 覆盖 49,152 个地址**；同 SID 的多条经验被合并为单条记忆。

### 2.3 SID 构建：无梯度冷启动 + RQ-KMeans
- **经验获取**：多智能体运行框架 StackPlanner 对每个训练查询生成多条轨迹；LLM 抽取器对比正确/失败/未验证轨迹，蒸馏可复用流程与失败教训（保留不确定性），形成种子集 \(X_{seed}\)。
- **量化**：冻结文本编码器 + 前缀提示（强调可复用策略、适用条件、流程）得到 \(e_i=f_{enc}(p_{enc}\oplus x_i)\)。
- **残差量化 K-Means（RQ-KMeans）**：第 1 层对嵌入做 K-Means 得码本；每个嵌入取最近中心索引作为第 1 个符号，再减去该中心，用残差拟合下一层码本，重复 \(L\) 次。形式化：
  - \(s_i^\ell=\arg\min_j \|r_i^{(\ell)}-c_j^{(\ell)}\|_2^2\)，\(r_i^{(\ell+1)}=r_i^{(\ell)}-c_{s_i^\ell}^{(\ell)}\)。
- 共享前缀聚合功能相近的经验，后层符号提供更细区分；码本在构建后固定不变。
- 附录给出评估指标：地址容量、单码利用率 \(U_\ell\)、累积前缀利用率 \(U_{1:\ell}\)、唯一码比 UCR、分布均匀度 DUI（归一化熵均值）、层间独立性 ICR（总相关）等，以及拟合/量化开销的复杂度（\(O(N_{seed}dT_{KM}\sum N_\ell)\) 与 \(O(d\sum N_\ell)\)）。

### 2.4 系统闭环
- **MemRetriever**：由查询与推理上下文生成检索地址 \(z_r\)，取出经验并**改写**为任务适配支持 \(\tilde x_r\)。
- **StackPlanner（多智能体运行框架）**：使用该支持执行任务，产出答案 \(\hat y\) 与轨迹 \(\tau\)。
- **MemEvolver**：蒸馏轨迹，生成更新地址 \(z_e\)，查阅该地址条目后决定操作 \(o\in\{\text{insert},\text{revise}\}\) 与新载荷 \(\tilde x_e\)。
- 闭环公式：Retrieve → Execute → Evolve；revise 可通过"载荷不变/合并/置空"实现保留、整合与删除。

### 2.5 四阶段训练流程
1. **SID 对齐预训练**：5 种文本–SID 映射（正向 \(q\to z\)、\(\tau\to z\)、\(x\to z\)；反向 \(z\to x\)、\(z\to d\)）。前向损失 \(L_{SID}(c,z)=-\sum_\ell \log p_\theta(s^\ell\mid c,s^{1:\ell-1})\)；总目标 \(L_{pre}=\lambda_q L_{q\to z}+\lambda_\tau L_{\tau\to z}+\lambda_x L_{x\to z}+\lambda_{z\to x}L_{z\to x}+\lambda_{z\to d}L_{z\to d}\)。
2. **记忆操作中期训练**：构造 ReAct 风格轨迹，分别训练两个策略（推理 → 生成 SID → 调用工具 → 使用返回经验），用拒绝采样保留格式与正确性达标样本，再由更强教师模型提供推理与角色输出的蒸馏目标。
3. **联合策略后训练（GRPO）**：
   - 过程奖励 \(R_{process}=R_{format}+R_{strategy}+R_{SID}\)（SID 合法性、与真值 SID 的码级一致性、LLM 裁判评估经验策略有用性）。
   - 结果奖励 \(R_{out}=r_{task}(\hat y_{mem},y^\star)-r_{task}(\hat y_{no\text{-}mem},y^\star)+\alpha_{partial}\mathbb{I}[\text{两者皆正确}]\)，即"有无记忆"的对比式奖励 + 部分信用加成。
   - GRPO 目标为带 clip 的组归一化优势 + KL 正则（\(\beta\) 系数），**对 proxy 与 audit 两个通道分别归一化优势**（双通道优化）。
   - 附录补充：MemEvolver 的策略奖励细化为 \(R_{evo}=r_{faithful}+r_{loc}+r_{op}\)（忠实性、定位正确性、操作恰当性）。
4. **在线记忆自演化**：模型参数、编码器与 SID 码本全部冻结；MemEvolver 生成目标 SID（**不对更新载荷重新编码量化**），insert 填充空槽、revise 更新已有条目；记忆库收敛前迭代 \(T\) 步，适应完全通过外部记忆完成，无需梯度更新，也不重分配已有地址。
