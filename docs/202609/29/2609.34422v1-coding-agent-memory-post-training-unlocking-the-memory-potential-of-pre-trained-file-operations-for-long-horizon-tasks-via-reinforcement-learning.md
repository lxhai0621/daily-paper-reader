## 摘要
语言模型智能体越来越多地处理长时程任务，这些任务的交互历史超出模型的活动上下文。近期工作开始使用强化学习将记忆控制纳入策略的一部分，但通常依赖于相对较短时程的领域特定训练环境中的预定义记忆工具。这种设置将学到的记忆行为绑定到基础模型预训练之外的、需从头学习的特定环境接口，因此即使在后期训练之后，智能体仍难以在长时程任务中使用记忆。为解决这些局限，我们引入 Coding Agent Memory Gym (CAMG)，一套涵盖 Shop、Coding、DeepResearch 和 AutoResearch 的长时程智能体强化学习环境。除每个环境原生的任务接口外，CAMG 提供可执行的 shell 访问和贯穿回合的持久化工作区，使智能体能够在一个回合中创建、修改、搜索和复用文件作为记忆。我们还引入 CAMG-RL，它使用完全异步 PPO 在所有四个环境中联合训练单一策略，直接从下游任务奖励中学习这种基于文件的记忆行为，并基于规模匹配的 Qwen3.5 模型训练了 CAMG-RL-4B 和 CAMG-RL-9B。在 SWE-bench Verified 和 MLE-bench Lite 上，CAMG-RL-4B 和 CAMG-RL-9B 分别与 Qwen3.5-35B-A3B 和 Qwen3.5-122B-A10B 具有竞争力。

## Abstract
Language-model agents increasingly tackle long-horizon tasks whose interaction histories exceed the model's active context. Recent work has begun to use reinforcement learning to make memory control part of the policy, often relying on predefined memory tools within domain-specific training environments of relatively short horizons. This setup ties learned memory behavior to environment-specific interfaces that lie outside the base model's pre-training and must be learned from scratch, so even after post-training, agents struggle to use memory in long-horizon tasks. To address these limitations, we introduce Coding Agent Memory Gym (CAMG), a suite of long-horizon agentic-RL environments spanning Shop, Coding, DeepResearch, and AutoResearch. Alongside each environment's native task interface, CAMG provides executable shell access and an episode-persistent workspace, enabling agents to create, revise, search, and reuse files as memory throughout an episode. We also introduce CAMG-RL, which trains a single policy jointly across all four environments with fully asynchronous PPO, learning this file-based memory behavior directly from downstream task reward, and we train CAMG-RL-4B and CAMG-RL-9B from Qwen3.5 models of matching size. On SWE-bench Verified and MLE-bench Lite, CAMG-RL-4B and CAMG-RL-9B are competitive with Qwen3.5-35B-A3B and Qwen3.5-122B-A10B, respectively.

# 论文总结：Coding Agent Memory Post-training（CAMG / CAMG-RL）

## 1. 核心问题与研究动机

- **背景**：语言模型智能体越来越多地处理长时程任务（long-horizon），交互历史不断累积并超出模型的**活动上下文窗口**。例如编码智能体在早期修复被否决后，后续决策仍需回忆该信息，但该轮对话已离开 prompt。
- **现有做法及其缺陷**：近期工作用强化学习把"记忆控制"纳入策略，但通常：
  - 依赖**预定义的专用记忆工具**（如 store/retrieve 等原子操作）；
  - 在**领域特定、时程较短**的训练环境中训练。
  - 结果是记忆行为被绑定到**基础模型预训练分布之外**的环境专属接口上，必须从零学起；即便后训练之后，智能体在长时程任务中仍不会用记忆。
- **核心开放问题**：能否在**代码预训练**的基础上，通过强化学习**激发（elicit）**编码智能体在活动上下文之外保留与复用信息的能力？论文的答案是：用**普通文件系统操作**作为记忆，而不是新造记忆工具。
- **整体含义**：论文主张记忆应当"长在"智能体已有的能力分布之内（shell/文件操作），让下游任务奖励来塑造记忆的创建与复用，而非另建一套需从头学习的记忆接口。

## 2. 方法论

### 2.1 CAMG：长时程智能体 RL 环境套件

- **四个环境**，覆盖四类任务家族：
  - **Shop**：由 720 个已验证 WebShop 商品合成六轮购买任务，会话间清空浏览器与活动会话记录，后续购买依赖先前偏好（跨会话依赖）。共 8 个任务族（自然属性链、潜在偏好、近因覆盖、干扰鲁棒、组合回忆、负约束、意图澄清、选择性记忆）。
  - **Coding**：SWE-smith 的 issue–repo 修复任务，从 59,136 条中筛出 **11,218 条可执行任务（93 个仓库）**，隐藏测试判分，提交哨兵为 `COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT`。
  - **DeepResearch**：LiteResearcher 的 Search–Visit–Answer 交互，从固定检索语料积累证据，最终答案由**冻结的 Kimi-K2.6 语义裁判**判定，共 **26,597 条**任务。
  - **AutoResearch**：公开 OpenMLE 任务包，**931 个任务 / 804 个任务族**，用原生指标私有判分。
- **统一编码智能体接口**：每个环境保留原生任务接口，另加**单一 `shell_command` 工具**（shell-only，仿 mini-swe-agent），可创建、查看、搜索、修改、执行文件。动作空间为 `A_d = A_task_d ∪ A_fs`。
- **回合持久工作区**：每个回合一个私有工作区，跨上下文替换持续挂载；只有 `.agent_memory/` 下的普通文件算作"策略记忆"。
- **上下文替换机制（关键细节）**：
  - 环境在上下文压力或子回合边界处触发替换，并提示策略用**一次普通文件动作**写 `.agent_memory/CONTINUATION.md`（≤8,192 字节）。
  - 环境**不代写、不清空**该文件；写入本身占一个动作槽、被采样并被训练。
  - 环境**仅在验证该文件变为非空普通文件后**才替换活动消息历史；替换后新上下文只给固定任务/工具说明与一个中性提示（**不注入文件内容**），策略需自行读回。
  - 写入失败会有有界重试提示并扣分；回合也可能在从未发生替换的情况下因任务终止条件结束。
- **执行隔离**：网络隔离 Linux 沙箱，限制进程、执行时间、输出大小、文件数与可写字节；公开任务输入只读挂载。

### 2.2 CAMG-RL：从下游任务奖励学习文件记忆

- **联合目标**：在 4 个环境上均匀采样环境，联合优化 `J_CAMG-RL(θ) = (1/|D|) Σ_d J_d(θ), |D|=4`。
- **轨迹形式**：每个完整回复（可先自由推理、以可执行动作结尾）= 一个 RL step；任务动作与文件操作**在同一条动作轨迹上**，因此一次记忆写入能获得**后续任务奖励**的信用。
- **双粒度 PPO（Dual-granularity PPO）**：**每条回复估计一个优势**（稳定，因为每条回复只有一个奖励），**每个 token 裁剪一个比率**（更新细粒度）。对比 Turn-PPO（turn 级）与 SAO（token 级）。
- **信用分配**：
  - 用 GAE 沿"回复步"做递归：`δ_t = r_t + γ(1-e_t)V̄_{t+1} - V̄_t`，`Â_t = δ_t + γλ(1-e_t)Â_{t+1}`，`Ĝ_t = Â_t + V̄_t`，取 **γ=λ=1**。
  - 同一回复内所有采样 token 共享同一优势 `A_raw_{t,j} = Â_t`；随后按环境内中心化、按**环境 token 数倒数加权**（`N_tok/(D_batch·N_d)`）、再做掩码标准化。
  - 比率 `ρ_{t,j}(θ) = exp[log π_θ(...) - ℓ^b_{t,j}]`，策略裁剪 ε=0.2、价值裁剪 ε_V=0.5；评论家只用**策略可见上下文**（不含隐藏状态或未读文件内容）。
- **完全异步 PPO**：因各环境回合时长差异大，rollout 与学习解耦——rollout worker 把完成的回合推入持久队列，learner 取"最早派发"的 64 个完整回合做一次更新并发布新权重；记录策略版本滞后、PPO 比率尾部、裁剪比例等。
- **训练配置**：Qwen3.5-4B 基座，200 次 learner 更新 × 64 回合 = **12,800 回合**；PPO minibatch 510 个回复；AdamW，策略 lr 1e-6 / 价值 lr 1e-5，权重衰减 0.01，梯度裁剪 1.0；prompt 限 30,720 token，回复/观测各限 8,192 token；温度 1，首个 EOS 或长度截断停止；FSDP2 + BF16 + 梯度检查点；生成用 SGLang。
- **稀疏成功型奖励**：Shop 用购买奖励（第 6 轮为 2，错误/无效 -0.01）；Coding 仅 `r_T = 1{隐藏测试通过}`，检查点写失败 -0.1；DeepResearch 仅终局裁判通过为 1，无效动作（含写检查点失败）-0.02；AutoResearch 有效提交 `r_T = min(1, max(0,s_T)+0.1)`，另有首次成功执行 +0.05、首次记录验证指标 +0.1 两个一次性里程碑。
