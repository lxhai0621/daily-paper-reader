## 摘要
智能体记忆会随着智能体读取输入、进行推理和调用工具而增长。更长的历史会增加推理成本，并最终超出上下文窗口。基于 LLM 的摘要可以缩减这一历史，但会增加延迟，且未对信息损失给出显式界。我们提出 LAM，一种有损智能体记忆系统，包含三个组件：一种确定性去重规则，并带有对检索分数的替换界——这是对分数扰动的界，而非排序不变的证明；一个记忆管理器，它保留已缓存前缀，并将压缩与推理重叠执行；以及一个性能模型，可在部署前估计压缩成本。在 600 条智能体轨迹上，LAM 移除了 22.47% 的观测 token，同时保留了所测 gold-patch 证据的 99.984%。在固定删除集下，性能模型预测，与从已预填充上下文中删除记录相比，在预填充前移除记录可带来 71.4 倍至 91.6 倍的端到端加速。该收益来自调度而非规则，并适用于任何保持前缀的测试。

## Abstract
Agent memory grows as agents read inputs, reason, and call tools. Longer histories increase inference cost and eventually exceed the context window. LLM-based summarization reduces this history but adds latency and provides no explicit bound on information loss. We propose LAM, a Lossy Agent Memory system with three components: a deterministic deduplication rule with a substitution bound on retrieval scores - a bound on score perturbation, not a certificate of unchanged ranking; a memory manager that preserves the cached prefix and overlaps compaction with inference; and a performance model that estimates compaction costs before deployment. On 600 agent trajectories, LAM removes 22.47% of observation tokens while retaining 99.984% of the measured gold-patch evidence. At a fixed deletion set, the performance model predicts a 71.4x-91.6x end-to-end speedup from removing records before prefill instead of deleting them from a prefilled context. That benefit comes from the schedule rather than the rule and applies to any prefix-preserving test.

# LAM：具有检索分数误差界的高效有损智能体记忆框架

## 一、核心问题与整体含义

- **背景**：AI 智能体在执行任务时会持续读取文件、运行命令并保留输出。这些历史对任务完成有帮助，但随轨迹增长会推高推理成本，并最终超出上下文窗口，迫使系统必须删除部分内容。
- **现有方法的不足**：
  - **LLM 摘要/学习式压缩器**：需要模型推理，增加延迟，且不提供显式的信息损失界；可复现性依赖权重与执行配置。
  - **SemDeDup**：用 k-means 聚类嵌入，结果随初始化变化（5 个随机种子仅 50.9% 的删除块相同）。
  - **观察掩码**：保留最近 k 条观察，丢弃较早内容，但 k 只暴露 token 预算，不界定删除造成的检索分数损失。
  - 这些方法都暴露了 token 预算、聚类数或窗口大小，但**没有一个参数能界定删除导致的检索分数损失**。
- **核心洞察**：智能体工具输出常重复（重读文件、重跑测试、多次列目录）；精确哈希只能捕捉完全相同的副本，而近重复（仅细节不同）需要第二层机制，且该层应带**查询无关的分数扰动界**。
- **整体含义**：LAM 提出一种有损智能体记忆框架，在压缩历史的同时给出检索分数误差的显式上界，并通过“预填充前移除”的调度策略避免缓存前缀失效带来的重填充开销。

## 二、方法论

### 2.1 核心思想

- 将记录嵌入为单位归一化向量，在**到达时（预填充前）** 用确定性去重规则判断是否可用已有记录替代。
- 三层结构：
  - **L0 字节精确哈希**：对行做 xxHash3，重复行替换为存根（借鉴 vLLM 前缀缓存的分块哈希思路，但作用于文本层）。
  - **L1 ε-等价候选**：对嵌入做量化、分带、哈希，候选对再用全精度 ℓ2 验证。
  - **L2 误差有界字节压缩**：用 cuSZp 压缩保留的嵌入，压缩的是嵌入存储而非上下文文本。

### 2.2 关键公式与算法

- **近似关系**：单位向量下，‖a−b‖₂ ≤ δ 等价于余弦阈值 t：
  - ‖a−b‖₂² = 2 − 2cos(a,b)，合并于 cos ≥ t ⇔ ‖a−b‖₂ ≤ δ = √2−2t。
  - 默认 t = 0.95，δ = 0.3162。
- **δ-替代定义**：(R, π) 是 S 的 δ-替代，若 R ⊆ S，π: S→R 且 π|_R = id，且对每个 x ∈ S 有 ‖x−π(x)‖₂ ≤ δ。
- **定理 1（分数亏缺界）**：对任意单位查询 q，
  - 0 ≤ max_{x∈S} q·x − max_{z∈R} q·z ≤ δ，且两端均紧。
  - 证明用 Cauchy–Schwarz；紧性取 S={a,b}、‖a−b‖₂=δ、q=(a−b)/δ。
- **算法流程（在线形式）**：
  1. 对到达记录 x_j 编码一次得 e_j；
  2. 对 Q_ε(e_j) 做分带哈希，检索候选集 C；
  3. 在 C 中找最低索引且 ‖e_j−e_y‖₂ ≤ δ 的保留记录 y*；
  4. 若存在，发出存根 ⟨x_j≡y*⟩，更新实测界 δ̂ = max(δ̂, ‖e_j−e_y*‖₂)；
  5. 否则保留 x_j，加入索引并存储 cuSZp 压缩后的嵌入。
- **确定性**：固定嵌入、到达顺序与算术实现时，规则可复现；选择最低索引代表消除候选遍历顺序依赖。
- **性能模型**：将一轮拆分为随上下文长度 C 缩放的部分（KV 读取、预填充）与不随其缩放的部分（权重流式读取），φ 为前者占比，Amdahl 上限为 1/(1−φ)；删除就地会触发重预填充项，前缀保留测试则免除该项。

### 2.3 系统设计

- **放置**：CPU 上运行测试，与 GPU 推理重叠；编码成本单独核算。
- **局部性**：分带索引按摘要存储保留记录，避免全上下文扫描。
- **粒度**：编码只处理该轮新增块，不处理完整上下文。

## 六、主要结果与发现

- **移除率—证据保留权衡（核心结论）**：在 SWE-smith 主评测上，LAM 在相同 token 移除率下保留的 gold-patch 证据行数高于观察掩码、LLM 摘要、SemDeDup 与 LLMLingua-2；完整三层流水线（L0+L1+L2）在 ECR@τ 指标上取得最高可移除率，说明“误差有界”并非以牺牲压缩率为代价。
- **层贡献呈累积关系**：
  - L0 单独即可捕获大量完全重复记录，贡献主要移除量；
  - 加入 L1 后，近重复（重读文件、重跑测试、微调命令）被进一步合并，证据保留下降幅度可控；
  - L2 在嵌入存储层面压缩，主要改善内存/带宽而非上下文 token 数，因此对移除率曲线影响较小，但对系统成本有正贡献。
- **调度策略（预填充前移除 vs 删除就地）**：固定删除集下，删除就地会因缓存前缀失效触发重预填充，产生额外 KV 读取与预填充项；预填充前移除避免该惩罚，端到端收益随上下文长度 C 增大而放大，符合 Amdahl 式性能模型中 φ 主导的预测。
- **合并阈值扫描**：5 个阈值下，t 越高（δ 越小）证据保留越好但移除率下降；t=0.95（δ≈0.3162）在两者间取得较优折中，且实测界 δ̂ 始终不超过理论 δ，验证定理 1 的紧性与实现正确性。
- **编码器敏感性**：bge、e5、gte、MiniLM 四种编码器下趋势一致；更强编码器在相同 δ 下能捕获更多近重复，但总体排序稳定，说明结论不依赖单一嵌入模型。
- **确定性验证**：6 个 batch size、2 种硬件、cuSZp 重复压缩下，LAM 的保留/删除决策完全一致；SemDeDup 因 k-means 初始化在 5 个种子下仅约半数删除块相同，形成鲜明对比。
- **CPU/GPU 重叠**：编码与哈希在 CPU 上与 GPU 推理重叠后，端到端延迟增量接近不可见；分带索引的局部性避免了全上下文扫描。
- **跨轨迹 vs 轨迹内 SemDeDup**：两种范围下 SemDeDup 均未能在相同移除率下达到 LAM 的证据保留，说明其不足并非范围选择问题，而是缺乏误差界与确定性代表选择机制。
- **LoCoMo 对照**：由于近重复仅 2 对，LAM 与基线差异不显著，符合“LAM 针对工具输出重复场景”的定位，说明方法并非通用压缩器，而是面向智能体记忆的专用机制。

## 七、局限性

- **查询无关界可能保守**：定理 1 对所有单位查询一致成立，实际查询分布往往集中，最坏情形未必出现，因此 δ 界可能低估可压缩空间。
- **依赖嵌入质量**：δ-替代的正确性以嵌入的 ℓ2 几何为前提；若嵌入未能把语义近重复映射到邻近点，L1 会漏合并，L0 又只能捕捉字节级完全重复。
- **全局单一 δ**：不同记录类型的重复尺度可能不同（日志行 vs 代码块），单一阈值未必最优，论文未深入探索自适应 δ。
- **仅验证两个 agent scaffold 与一个对话对照**：LHTB 与 SWE-smith 覆盖终端/代码场景，但多模态、长文档问答、多轮工具调用混合场景未覆盖。
- **基线效率假设偏乐观**：对 LLM 摘要与 LLMLingua-2 采用接近峰值的吞吐假设，虽使比较偏向基线，但也意味着在真实部署中 LAM 的相对优势可能更大或更小，取决于实际系统调优。
- **系统测量集中于特定硬件**：主要结论在 GB10 与 A100 节点上验证，其他加速器（如 H100、消费级 GPU、纯 CPU 部署）下的重叠收益与带宽瓶颈需进一步确认。

## 八、结论与启示

- **核心贡献**：LAM 是首个在智能体记忆压缩中给出**显式检索分数误差上界**的框架，把“删多少”与“删了会损失多少检索分数”解耦为可调、可验证的参数 δ。
- **方法启示**：
  - 有损记忆不必依赖模型推理；确定性规则 + 几何界可以在低延迟下提供可复现的压缩；
  - “预填充前移除”是缓存感知记忆管理的关键调度选择，删除时机与删除内容同等重要；
  - 分层设计（字节精确 → ε-等价 → 误差有界压缩）使各层职责清晰，便于独立替换与消融。
- **实践意义**：对长期运行的编码/终端智能体，LAM 提供了一条在不牺牲关键证据的前提下控制上下文成本、且行为可复现的工程路径；其误差界可作为系统级 SLO 的一部分进行声明与监控。
- **未来方向**：自适应 δ、查询分布感知的界、跨模态记录的统一替代关系，以及把误差界与下游任务成功率直接耦合的端到端优化。
