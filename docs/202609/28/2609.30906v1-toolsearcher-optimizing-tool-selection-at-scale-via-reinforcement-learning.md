## 摘要
大语言模型（LLMs）擅长自然语言处理，但难以与外部环境交互。工具学习为将 LLMs 扩展为可执行行动的智能体提供了一条有前景的途径，其中工具选择是成功使用工具的关键前提。现有工作通常假设工具集规模较小或预先定义，导致大规模工具选择问题尚未得到充分探索。现实世界的工具库包含大量且多样的工具，使得 LLMs 难以在上下文长度约束下有效搜索、区分和组合工具。我们将大规模工具选择视为智能体强化学习的一项新挑战，并指出，现有的面向知识型问答的强化学习方法不足以在兼顾兼容性的情况下选择工具。为解决这一挑战，我们提出了 ToolSearcher，一种新颖的强化学习框架，用于大规模工具选择中的有效多轮搜索与细粒度优化。具体而言，我们引入了类别约束的工具判别，以提升模型区分功能相似工具的能力；引入事件级搜索建模，以显式优化多轮搜索过程中对目标工具的发现；并引入轨迹对齐的信用分配，为搜索-选择过程的不同阶段提供细粒度奖励信号。在大规模工具选择基准上的大量实验表明，在涉及迭代搜索和复杂工具组合的挑战性设置中，ToolSearcher 始终优于一系列强基线。

## Abstract
Large language models (LLMs) excel at natural language processing but struggle to interact with external environments. Tool learning provides a promising way to extend LLMs into actionable agents, where tool selection is a critical prerequisite for successful tool use. Existing work often assumes a small or predefined set of tools, leaving large-scale tool selection underexplored. Real-world repositories contain a vast and diverse array of tools, making it difficult for LLMs to effectively search, distinguish, and compose tools under context-length constraints. We identify large-scale tool selection as a new challenge for agentic reinforcement learning, highlighting that existing RL methods for knowledge-based question answering are inadequate for selecting tools while considering compatibility. To address this challenge, we propose ToolSearcher, a novel RL framework for effective multi-turn search and fine-grained optimization in large-scale tool selection. Specifically, we introduce category-constrained tool discrimination to improve the model's ability to distinguish functionally similar tools, event-level search modeling to explicitly optimize the discovery of target tools during multi-turn search, and trajectory-aligned credit allocation to provide fine-grained reward signals for different stages of the search-selection process. Extensive experiments on large-scale tool selection benchmarks demonstrate that ToolSearcher consistently outperforms a set of strong baselines in challenging settings involving iterative search and complex tool composition.

- **整体含义**：论文将**大规模工具选择**确立为智能体强化学习（agentic RL）的一个**新挑战**，并提出 ToolSearcher 框架来同时解决"大规模多轮搜索"与"多能力联合学习的奖励设计"两大难题。

## 2. 方法论：核心思想与关键技术细节

### 2.1 任务定义与交互形式
- 给定用户需求 $q$、搜索引擎 $R$、大规模工具库 $\mathcal{T}$，目标是找出满足需求的工具集合 $T_s=\{T_1,\dots,T_n\}$，最大化 $P_\theta(T_s \mid q, \mathcal{T}, R)$。
- 每个工具文档 $d_T=(f, I, O_t)$，含功能描述 $f$、输入约束 $I$、输出模式 $O$。
- 搜索引擎 schema 写入 prompt；LLM 在 `<tool_call>...</tool_call>` 中输出符合 schema 的 JSON 调用，引擎返回检索结果作为外部反馈，形成多轮循环。

### 2.2 类别约束的工具判别（Category-Constrained Tool Discrimination, CCTD）
- **核心思想**：把"全库全局检索"转化为"在功能相似子空间内的类别约束检索"，构造强约束的挑战环境。
- 每个工具按功能归入类别 $C$，工具库表示为 $\{T_{C_1},T_{C_2},\dots,T_{C_m}\}$；搜索引擎增加子类别搜索能力，单步检索形式化为 $D=R(C^*, Q \mid T_{C^*})$。
- **效果**：同类内工具高度相似，迫使模型专注于**区分功能相近工具**，而非仅优化查询语句做细粒度语义匹配。
- **两阶段渐进训练**：第一阶段用 30% 数据在子类别约束下训练（练"分辨相似工具"）；第二阶段切回全局搜索（练"全库细粒度语义检索"）。

### 2.3 事件级搜索建模（Event-level Search Modeling, ESM）
- **动机**：现有 RL 不显式建模搜索过程，无法强化"为兼容工具组合而搜索与规划"的能力。
- 将搜索轨迹 $S$ 显式建模为事件序列 $E=(e_1,\dots,e_k)$，每个事件 $e_k=(a_k, R(a_k))$，$a_k$ 为对搜索引擎的工具调用，$R(a_k)$ 为返回的工具集合。
- **检索 token 掩码**：沿用前人做法对检索到的文档 token 做 loss masking，策略梯度只作用于 LLM 生成的 token。
- **目标事件集合**：只优化"首次搜到此前未覆盖的目标工具"的事件
  $$E^*=\{e_j \mid 1\le j\le k,\ T_{e_j}\neq\varnothing\},\quad T_{e_j}=M(e_j)\cap(T_s\setminus M(E_{<j}))$$
  即**不奖励重复搜索已搜到工具的事件**。
- **优化目标**：最大化 $J_{search}(\theta)=\mathbb{E}\big[\prod_{j=1}^{k}P_\theta(e_j\mid E_{<j})^{\mathbb{1}_{e_j\in E^*}}\big]$。
- **GRPO 式实现**：对每个 prompt 采样 $G$ 条轨迹，采用重要性比 $w_{i,t}(\theta,R)$ 与裁剪的 PPO 目标，并加入 KL 惩罚项；**事件级搜索优势**为
  $$\hat{A}_{i,e(t)}=\max_{T\in T_{e(t)}}\Big[\tfrac{r(T,S_i)-\text{mean}(\{r(T,S_j)\})}{\text{std}(\{r(T,S_j)\})}\Big],\ e(t)\in E_i^*;\quad 0,\ \text{否则}$$
  其中 $r$ 为二值函数（该轨迹是否搜到目标工具 $T$）。由此通过调整轨迹内各事件的梯度，显式度量"每个搜索事件对该轨迹的重要性"。

### 2.4 轨迹对齐的信用分配（Trajectory-Aligned Credit Allocation, TCA）
- **动机**：同一任务的轨迹进度差异很大（已完成、已收集足够信息但选不对、仍处早期搜索阶段），统一奖励无法反映"相对进度"。
- **做法**：最终目标 $J^{(i)}(\theta)=J^{(i)}_{search}(\theta)+\mathbb{E}[\text{选择事件项}]$，即搜索阶段目标 + 选择阶段目标。
- **选择优势** $\hat{A}_{i,e_s^{(i)}}$：仅当该轨迹的搜索过程 $S_i$ 已覆盖全部目标工具（$M(S_i)\cap T_s=T_s$）时，才用选择奖励 $r_s$ 做组内归一化；否则置 0，从而**避免模型在搜索未完成时对选择结果做"凭空猜测"**。
- **搜索端同步去冗余**：对组内已被"掌握"（多条轨迹都搜到）的目标工具对应的事件，把 $\hat{A}_{i,e(t)}$ 置 0，只奖励相对其他轨迹更优的搜索事件。
- **整体效果**：奖励按轨迹所处阶段与相对进展分配，把学习信号集中到尚未掌握的能力上（附录 F 给出了与 GRPO、GDPO、MARAG-R1、GSPO 的梯度系数对比分析）。
