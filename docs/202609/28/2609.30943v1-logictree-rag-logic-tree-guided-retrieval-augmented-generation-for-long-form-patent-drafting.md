## 摘要
长篇幅技术文本生成是知识密集型工作流的基础，但由于需要超越局部连贯性的全局一致逻辑结构和忠实的技术推理，对大型语言模型（LLM）而言仍具挑战性。专利起草是这一挑战的典型实例，它要求通过持续的多专家协作，整体生成一份合法合规且技术详尽完备的文件。现有方法通常侧重于局部章节生成，或依赖人工构建的提纲，限制了现实场景中的可扩展自动化。在这项工作中，我们提出 LogicTree-RAG，一种逻辑树引导的检索增强生成框架，它归纳出一棵层次化逻辑树作为全局组织骨架，以组织和锚定技术披露内容，而无需依赖专家定义的起草先验。逻辑树中的每个节点表示一个技术要素，并通过证据引导的递归生成来构建。随后，一种混合遍历机制将逻辑树映射到专利章节，从而实现可控且章节均衡的生成。大量实验表明，LogicTree-RAG 在内容质量和语言合规性上持续优于强大的基于 LLM 的基线，并在高 token 效率下实现更长的结构化生成，证明了以逻辑为中心的生成方法在复杂技术文档起草中的有效性。

## Abstract
Long-form technical text generation underpins knowledge-intensive workflows, yet remains challenging for large language models (LLMs) due to the need for globally consistent logical structuring and faithful technical reasoning beyond local coherence. Patent drafting is a canonical instance of this challenge, demanding holistic generation of a legally compliant and technically exhaustive document through sustained multi-expert collaboration. Existing approaches often focus on partial section generation or rely on manually crafted outlines, limiting scalable automation in realistic settings. In this work, we propose LogicTree-RAG, a logic tree-guided retrieval-augmented generation framework that induces a hierarchical logic tree as a global organizational backbone to organize and ground technical disclosures, without relying on expert-defined drafting priors. Each node in the logic tree represents a technical element and is constructed through evidence-guided recursive generation. A hybrid traversal mechanism then maps the logic tree into patent sections, enabling controllable and section-balanced generation. Extensive experiments show that LogicTree-RAG consistently improves content quality and language conformity over strong LLM-based baselines and achieves longer structured generation with high token efficiency, demonstrating the effectiveness of logic-centric generation for complex technical document drafting.

## 二、方法论

### 2.1 总体框架（两阶段）
- **阶段 I：逻辑树构建**——将源论文解析为语义单元，构建并递归扩展/精炼逻辑树；
- **阶段 II：专利起草**——遍历逻辑树，按章节聚合节点内容生成长篇专利。

### 2.2 逻辑树定义
- 有向根树 $T=(V,E,r)$，每个节点 $v$ 关联：生成文本片段 $c(v)$ 与支撑证据跨度 $E(v)\subseteq X$；
- 施加**归因约束**：$\forall v\in V, E(v)\neq\emptyset$（每个生成单元至少锚定一条源论文证据）；
- 根节点概括发明，内部节点对应高层章节，叶节点展开细粒度技术细节。

### 2.3 层次化逻辑树初始化
- **布局感知文档分析**（LayoutLM 思路）重建章节/段落层级；
- **语义分块**：对相邻段落计算相似度 $s_{i,i+1}=\text{sim}(E_p(x_i),E_p(x_{i+1}))$，当 $s_{i,i+1}\ge\tau_s$ 且累计 token 不超 $t_{max}$ 时迭代合并，得到语义连贯块集 $\tilde{X}$（区别于固定长度切分）；
- 用指令 $\sigma_I$ 与 $\tilde{X}$ 生成**草稿技术描述** $D_d$，作为根节点 $r$（$c(r)=D_d$，$E(r)=\tilde{X}$），再由 LLM 分解出第一层子节点。

### 2.4 证据引导的递归生成
- 采用 **FIFO 队列的广度优先扩展**，初始队列为叶节点；
- 每轮取出节点 $v_t$，检索上下文证据 $D_{ctx}$；
- **全局新颖性检验**：若 $D_{ctx}$ 已被树中其他节点（排除父节点 $v_f$ 的子节点）覆盖，则跳过 $v_t$；
- 否则执行两个互补过程：
  - **扩展** $E(\cdot)$：基于 $D_{ctx}$ 与 $\sigma_E$ 生成补充段落，切分为子节点 $\{v_t^{c_1},\dots,v_t^{c_k}\}$ 并入队；
  - **精炼** $R(\cdot)$：先用 $\sigma_{R1}$ 检测欠指定术语，若为领域概念则用检索证据 + $\sigma_{R2}$ 精炼，否则用模型内部知识 + $\sigma_{R3}$ 补全；
- 终止条件：队列空或内容长度达到预算 $B$（控制过度生成）。

### 2.5 节点感知语义搜索（Node-Aware Semantic Search）
- 先用节点内容 $c(v_t)$ 从知识库检索 Top-K 候选 $\tilde{D}_{ctx}$；
- 定义**判别性相关性分数**：
  $$S_{dr}(d)=\text{sim}(d,c(v_t))-\max_{v_e\in V^{child}_f\setminus\{v_t\}}\text{sim}(d,c(v_e))$$
  即同时考虑"与当前节点的语义关联"和"与兄弟节点的结构区分度"；
- 仅保留 $S_{dr}(d)\ge\tau_f$ 的跨度作为最终证据。
- **与全局新颖性检验的分工**：前者在**局部兄弟层**保证特异性，后者在**全局树级**控制冗余。

### 2.6 混合遍历策略
- **Background / Summary**：BFS 遍历，保证全面均衡的结构覆盖；
- **Detailed Description**：先用 BFS + LLM 语义聚类识别连贯逻辑子树，再对每个子树 **DFS** 展开细粒度技术内容；
- BFS 建立结构骨架，DFS 实现细粒度扩展，兼顾结构清晰性与语义特异性。

## 六、主要结论与发现

- **内容质量**：LogicTree-RAG 在 Coverage（43.79）、$F_{Pat}$（58.92）、$F_{Src}$（66.34）、ROUGE-L（38.91）上均为最优；相较强 LLM 基线，**技术完备性提升 11.03%，内容保真度提升 6.33%**；
- **语言合规**：Style 得分 65.68 为最优，重复率 $R_r$ 降至 4.14（远优于基线）；连贯性 97.45 仅次于 SFT 版 COPGEN，且**无需任务特定微调**；
- **长度与效率**：输出 20.22k token（显著长于单次调用基线），token 效率最高，接近 SFT 版 COPGEN；
- **泛化性**：在 LCFO 文档扩展任务上不修改核心流程即全面超越基线，说明收益不局限于专利；
- **章节级**：各章节输出长度与参考专利高度对齐，Detailed Description 覆盖度提升最高达 17.4%；
- **消融结论**：
  - 移除逻辑树 → Coverage 降 9.0%；移除检索 → 事实性降 13.2%；
  - 移除语义分块或节点感知重排 → 事实性下降、重复率上升；
  - 移除 σR2（证据精炼）全面退化，而移除 σR3（内部知识）影响甚微（仅 8.6% 步骤触发）；
  - 纯 DFS 遍历产生更长但覆盖更差，验证混合遍历的必要性；
- **人工评审**：在 Overall Quality、Legality、Claim Structure、Antecedent Basis、Fidelity 五维上均获多数偏好（胜率 65%–92%），其中 Claim Structure 与 Antecedent Basis 优势最大；
- **成本**：每专利约 20 次 LLM 调用、311s，递归构建仅占中等开销，成本分布均衡可控。

## 七、优点（亮点）

- **范式创新**：提出"逻辑先于内容"的**逻辑中心生成范式**，用逻辑树作为事实证据与全局生成控制之间的中间表示，摆脱对专家提纲的依赖；
- **结构建模精巧**：节点感知语义搜索的**判别性相关性分数**同时刻画语义特异性与结构区分度，与全局新颖性检验形成局部/全局互补的冗余控制；
- **可控性与可扩展性**：树预算（节点数、深度）显式界定生成边界，使计算成本与生成长度可预测、可调节；
- **遍历策略合理**：BFS+DFS 混合遍历与专利文档的"高层概括 + 深层细化"结构天然契合；
- **证据锚定机制**：归因约束 + σR2 证据精炼，使生成内容可追溯，证据支持率（85.6% fully supported）显著优于 COPGEN（70.4%）；

- **泛化验证**：在非专利任务 LCFO 上验证，提升说服力。
