## 摘要
记忆对于使基于 LLM 的智能体在长程交互中保持连贯、个性化的行为至关重要。然而，现有记忆系统存在一个根本局限：它们从不主动测试自身记忆，只有在真实查询暴露出弱点后才进行修复。这种反应式范式意味着，每一次检索失败都对应着一次真实交互，而代价已经付出。我们提出 MemDream，一个使 LLM 智能体能够进行自探测记忆演化的框架。我们的框架会周期性进入离线“梦境”周期，在其中三个专门化智能体（Dreamer、Analyst、Consolidator）协作，在失败发生之前对记忆图进行探测、诊断和修复。通过组相对策略优化（Group Relative Policy Optimization）训练的策略学习哪些修复操作能带来持久的检索改进，而一种软衰减机制则提供由同一预期信号驱动的可逆遗忘。在 LoCoMo 和 MemoryAgentBench 上的实验表明，MemDream 在 LoCoMo 上将答案 F1 提升 4.5 个点，并在 MAB 上相比最强的反应式演化基线取得高 9.1 个点的总体得分。

## Abstract
Memory is essential for enabling LLM-based agents to maintain coherent, personalized behavior over long-horizon interactions. However, existing memory systems share a fundamental limitation: they never proactively test their own memory, repairing it only after real queries expose weaknesses. This reactive paradigm means every retrieval failure corresponds to a real interaction in which the cost has already been paid. We propose MemDream, a framework that enables self-probing memory evolution for LLM agents. Our framework periodically enters offline dream cycles where three specialized agents (Dreamer, Analyst, Consolidator) collaboratively probe, diagnose, and repair the memory graph before failures occur. A policy trained via Group Relative Policy Optimization learns which repair operations produce durable retrieval improvements, while a soft decay mechanism provides reversible forgetting driven by the same anticipatory signal. Experiments on LoCoMo and MemoryAgentBench demonstrate that MemDream improves answer F1 by 4.5 points on LoCoMo and achieves a 9.1-point higher overall score on MAB over the strongest reactive-evolution baselines.

## 2. 方法论

### 2.1 核心思想

- 受睡眠期记忆巩固（Kumaran et al., 2016）启发，MemDream 周期进入**离线梦境循环（dream cycle）**，由三个共享同一 LLM 主干（Llama-3.1-8B）、各自拥有独立 LoRA 适配器的智能体协作：**Dreamer 探测、Analyst 诊断、Consolidator 修复**。
- 关键洞见：**记忆系统应当测试自身**——自生成的前瞻性探测查询可暴露潜在缺陷，而不必等待真实查询。

### 2.2 记忆架构与问题形式化

- 分层记忆存储 `G = (V, E)`，三层结构：
  - **STIM**（短期交互记忆）：缓冲近期对话页，LRU 淘汰；
  - **MTEM**（中期情景记忆）：按会话分组，带会话级元数据；
  - **LTSM**（长期语义记忆）：存放压缩后的知识条目。
- 每个节点 `v` 携带内容嵌入、实体集、访问统计与检索权重 `w_v ∈ [0,1]`。
- 检索用 **RRF（倒数排序融合）** 融合稠密与稀疏（BM25）检索器，并按节点权重加权：
  `s(v,q) = (Σ_{i∈{dense,BM25}} 1/(k+rank_i(v,q))) · w_v`，随后经交叉编码器重排序。
- 记忆演化被形式化为学习策略 `π: G → G'`，最大化对未来查询分布 `Q` 的期望检索成功率；由于 `Q` 未知，梦境循环学习从中采样，将不可观测分布转化为可训练信号。

### 2.3 三智能体梦境循环

- **Dreamer（探测）**：
  - 计算节点弱点分数 `φ(v)`，含三项：连通性缺失（孤立节点）、冗余度（与邻居高相似）、陈旧度（距上次访问时间）。
  - 选取 `φ(v)` 超阈值的节点为目标，并为其配对**桥接伙伴**：与目标节点经常被共同检索但缺少边的节点（按共可检索性而非嵌入相似度配对）。
  - 生成需要同时整合 `{v*, u*}` 的探测查询；**期望答案逐字复制自目标节点的存储内容**，而非模型生成，保证修复信号扎根于已有记忆、不会追逐幻觉目标。
  - 先以 SFT 训练，再用检索成功率作奖励进行 GRPO。
- **Analyst（诊断）**：
  - 沿两个轴分类失败：**节点内/节点间** × **召回/精度**，得到四个类别：
    - `buried`（节点内召回：事实存在但埋在冗长文本中）
    - `scattered`（节点间召回：证据分散在未连接节点）
    - `redundant`（节点间精度：内容重叠）
    - `noisy`（节点内精度：问候语、填充等低价值节点）
  - 每类映射到一种修复操作（extract / synthesize / merge / prune），并输出目标节点 ID，按最严重优先排序。作者称该分类法在两轴上完备。
- **Consolidator（修复）**：
  - `Extract`：将冗长页转为结构化节点；`Synthesize`：生成带来源链接的摘要节点；`Merge`：合并相似节点并保留边连通性；`Prune`：**软衰减而非硬删除**。
  - 软衰减公式：`w_v ← γ · w_v`，`γ = 0.2`（γ=0 即删除，为消融；γ→1 几乎不变）。
  - 权重恢复：`w_v ← min(1.0, w_v + η · success_count_v)`，若后续循环发现节点重新相关则恢复。
  - 每轮处理不同节点分区，直到收敛：`(1/|D|) Σ_{q∈D} F1(q,G) ≥ τ` 或达到轮数上限 `T_max`。

### 2.4 GRPO 训练

- 三个智能体各自优化固定权重的奖励（可解释项之和）：
  - `r_D`：判别性、下游 QA 影响、查询类型覆盖；
  - `r_A`：可操作性、修复类型多样性、规模适中、结构良好；
  - `r_C`：QA-F1、覆盖保留、时间线索保留、简洁性（merge/synthesize 用类似奖励权衡 QA-F1 与去重/接地）。
- GRPO 损失：`L_GRPO = -(1/N) Σ A_i · log π_θ(a_i|s)`，`A_i = (r_i - r̄)/(σ_r + ε)`，仅高于组均值的 rollout 获得正梯度。
- **三阶段训练**：① SFT 预训练（GPT-4.1 教师数据）→ ② 各智能体独立 GRPO → ③ Dreamer 与 Consolidator 联合微调（Analyst 冻结），联合奖励为记忆质量的提升 `r_joint = (1/|D_new|) Σ [F1(q,G') - F1(q,G)]`，梯度只流向 Dreamer 与 Consolidator。
- 训练超参：学习率 1e-3、组大小 N=4、探索率 ε=0.2 并衰减；部署时模型参数固定，梦境循环只更新外部记忆。

- **LoCoMo**：MemDream 在两种 reader 下均取得最高平均 F1/B-1/R-L。GPT-4.1 下平均 F1 提升 **3.98** 分（相对 FluxMem），时序 F1 提升 **8.57** 分（相对 O-Mem）；但在开放题上落后 FluxMem 1.41 F1（开放题更偏好广泛上下文而非定向探测）。
