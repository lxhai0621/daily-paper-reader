## 摘要
当前智能体在跨任务时基本保持无状态，限制了其从先前交互中持续改进的能力，也使记忆对长时程智能体行为至关重要。现有记忆方法试图复用过往经验，但大多数依赖单一记忆表示（例如轨迹、反思、技能、结构化知识），其有效性因任务分布而异。重新审视这一设计空间，我们评估了13种记忆方法，发现没有单一方法能在各基准上通用，这揭示了管理异构记忆提供者的潜力。我们将智能体记忆形式化为一个路由问题，其中记忆智能体决定从哪个记忆提供者检索、是否注入短期记忆，以及哪些提供者应存储由此产生的经验。基于这一视角，我们提出MemAgent，其具有内容感知路由架构和训练数据合成流水线。该路由架构结合了检索前的内容感知探测、执行期间的短期记忆门控，以及选择性多提供者存储；训练流水线则为路由决策合成阶段特定的监督信号。在GAIA、WebWalkerQA和xBench-DS上，MemAgent将平均准确率提升10.0%，并在所有三个基准上优于每一种单一记忆方法。这些收益仅带来不到0.3%的路由开销，并使平均任务步数减少12%。

## Abstract
Current agents remain largely stateless across tasks, limiting their ability to continually improve from prior interactions and making memory essential for long-horizon agentic behavior. Existing memory methods seek to reuse past experience, but most rely on a single memory representation (e.g., trajectories, reflections, skills, structured knowledge) whose effectiveness varies across task distributions. Rethinking this design space, we evaluate 13 memory methods and find that no single method generalizes across benchmarks, revealing the potential of managing heterogeneous memory providers. We formulate agent memory as a routing problem in which a memory agent decides which memory provider to retrieve from, whether to inject short-term memory, and which providers should store the resulting experience. Based on this perspective, we propose MemAgent, featuring a content-aware routing architecture and a training-data synthesis pipeline. The routing architecture combines content-aware probing before retrieval, short-term memory gating during execution, and selective multi-provider storage, while the training pipeline synthesizes phase-specific supervision for routing decisions. Across GAIA, WebWalkerQA, and xBench-DS, MemAgent improves average accuracy by 10.0% and outperforms every individual memory method across all three benchmarks. These gains come with less than 0.3% routing overhead and a 12% reduction in average task steps.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体已从单轮问答扩展到长时程任务（网页研究、多模态推理、工具调用等），但大多数智能体**跨任务无状态**——每次调用都从零开始，无法复用先前经验，阻碍了持续改进与经验摊销。
- **现有记忆方法的局限**：已有工作（轨迹摘要、反思洞察、结构化知识、工作流模板、过程脚本、可执行技能等）各自只采用**单一记忆表示**，且通常只在自身目标基准上验证。
- **关键实证发现**：作者将 13 种代表性记忆方法统一为"记忆提供者"接口，在 GAIA、WebWalkerQA、xBench-DS 上逐一评估，发现：
  - **没有任何单一方法能在三个基准上同时最优**（如 AWM 在 GAIA +6.1% 却在 WebWalkerQA −0.6%；ExpeL 在 WebWalkerQA +7.6% 但在 GAIA 仅中游）。
  - **事后 Oracle**（只要任一提供者成功即算解决）平均准确率 **89.6%**，远超最佳单一提供者的 **71.0%**（高出 18%+），且 13 个提供者中有 10 个能独特地解决至少一个任务。
- **核心命题**：智能体记忆的关键不是"找到唯一最优格式"，而是**在异构记忆提供者之上做路由（routing）问题**。

## 2. 方法论

### 2.1 核心思想

- 引入**记忆智能体 A_M**，在任务轨迹生命周期中做三类决策，为任务智能体 A_T 服务：
  - **BEGIN**：执行前从长期提供者池 P 中选一个检索并注入系统提示；
  - **IN**：执行中每步决定是否注入结构化短期记忆（QUERY / NO_OP）；
  - **END**：任务结束后选择子集 S ⊆ P 存储轨迹，供未来复用。
- 提供者共享统一接口（`retrieve` / `store`），使路由策略与提供者内部实现解耦。作者另贡献两个提供者：**InsightGraph**（图结构长期记忆）与**规则式短期记忆提供者**。

### 2.2 内容感知路由架构

- **BEGIN —— 内容感知探测（content-aware probing）**：
  - 决策前对所有提供者发起**并行轻量检索**，获得每条最相关记忆的短片段预览；
  - **刻意移除检索分数**（因各提供者评分量纲不可比，保留分数会诱导"选最高分"的捷径），并**随机打乱候选顺序**以消除位置偏差。
- **IN —— 短期记忆门控**：上下文包含任务问题 q、步索引 t、短期记忆紧凑摘要、近期工具调用与观测，判断回忆状态是否真正有助于下一步。
- **END —— 选择性多提供者存储**：上下文包含轨迹摘要、二元任务结果、各提供者的存储描述，选择 3–6 个（可为空）提供者，避免"全量存储"造成记忆污染。

### 2.3 训练数据合成（无真值标签）

- **强制探索（Forced Exploration）**：对每个训练任务，强制遍历所有提供者，并额外变化 IN 阶段动作（QUERY / NO_OP），得到轨迹集 Ξ 及对应结果 {y}，从而在控制任务难度的前提下做跨提供者比较。
- **逐决策奖励（Per-decision Reward）**，三个互补信号：
  1. **任务正确性（BEGIN）**：路由到使任务成功的提供者集合 P⁺ 得正奖励；当 P⁺ 是 P 的**真非空子集**时判别性最强，权重最高。
  2. **LLM-as-Judge 因果归因（BEGIN / IN）**：按维度打分（如 Utilization、Relevance、Helpfulness、Progress、Noise↓、Appropriateness、Missed Opportunity↓），归一化后加权求和：
     - r_d = ⟨w(φ), ŝ⟩，其中 ŝ_i = s_i/s_max（正向维度）或 1 − s_i/s_max（负向维度），w(φ) 位于 (K_φ−1)-单纯形上，r_d ∈ [0,1]。
  3. **下游复用奖励（END）**：仅当被存储的记忆确实被后续任务检索且贡献成功时才有价值：
     - r_end(ξ_τ, p) = ½·min(1, |T^(p)_{>τ}| / H) + ½·(成功下游任务数 / max(|T^(p)_{>τ}|, 1))，H 为饱和常数（取 5）。
- **奖励过滤式 SFT 数据构造**：
  - BEGIN：若 P⁺ 为真非空子集则保留成功决策；若全体成功则按 judge 奖励取 top-k；若全体失败则丢弃任务；r_d = 0 的决策丢弃。
  - IN：保留 r_d ≥ ε_IN 的高质量 QUERY / NO_OP 决策。
  - END：保留 r_end ≥ ε_END（=0.5）的决策。
- **SFT 训练**：用 LoRA 微调 A_M，仅在结构化决策 token 上计算交叉熵（掩码 prompt token），并做**任务级**训练/验证划分以防同任务上下文泄漏。

### 2.4 两个自研提供者（附录）

- **InsightGraph**：类型化知识图 G=(V,E)；节点为 ≤30 词的可操作洞察，边含 same-task 边（w=1.0）与 similar-concept 边（余弦阈值 0.55）。检索为 TF-IDF 与稠密嵌入混合（0.2 / 0.8）选 top-5 种子，再做单跳图扩展（衰减 γ=0.7，每种子最多 3 邻居，分数下限 0.22）；边权按贝叶斯质量项在线自适应（Laplace 平滑，半衰期 κ=5，n_e ≥ 2 才更新）；每 50 任务做一次合并/剪枝。
- **短期记忆提供者**：规则式抽取三类有界结构——已验证事实（≤15，Jaccard>0.6 去重）、URL 历史（≤30）、搜索历史（≤20），并用 14 条正则识别工具错误；采用**保守显示策略**（低于阈值则整体返回空，避免低信息注入）。
