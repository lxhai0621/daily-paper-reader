## 摘要
创作长篇小说与虚构故事的LLM智能体需要对不断演化的故事世界拥有显式记忆，以使新事件与既定事实保持一致。这类记忆必须将异质的叙事信息彼此区分，跨粒度地整合故事发展，并恢复写作请求中隐含的依赖关系。我们提出NarraWorld，一个面向长文本写作的结构化记忆系统，它将记忆构建视为世界创建。从一个共享的、以证据为基础的图出发，NarraWorld派生出四个相互关联的视图：世界事实、各角色信念、未决发展和假设分支（可能世界延续）。借助原子闭包的分层聚合将事件整合为场景、情节线和情节，使每个高层节点都可追溯至其构成来源片段。在检索方面，规划式重构从当前叙事情境和记忆预览中推断查询的依赖关系，然后在token预算内组装相关记录。在三个写作基准上，NarraWorld取得了最强的总体结果。其记忆还能迁移至情境化角色扮演，并在一个通用长期记忆基准上基本保持召回能力，为能够在多样化叙事任务中维持连贯故事世界的智能体开辟了道路。

## Abstract
LLM agents that write long-form fiction need an explicit memory of the evolving storyworld to keep new events consistent with established facts. Such memory must keep heterogeneous narrative information distinct, integrate story developments across granularities, and recover dependencies that a writing request leaves implicit. We present NarraWorld, a structured memory system for long-form writing that treats memory construction as world creation. From a shared evidence-grounded graph, NarraWorld derives four connected views: world facts, per-character beliefs, open developments, and hypothetical branches (possible-world continuations). Hierarchical aggregation with atomic closure consolidates events into scenes, plotlines, and plots, keeping each higher-level node traceable to its constituent source spans. For retrieval, planned reconstruction infers a query's dependencies from the current narrative situation and a preview of memory, then assembles the relevant records within a token budget. Across three writing benchmarks, NarraWorld achieves the strongest aggregate results. Its memory also transfers to situated role-playing and largely preserves recall on a general-purpose long-term memory benchmark, paving the way for agents that sustain coherent storyworlds across diverse narrative tasks.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体在长篇虚构写作中，新事件必须与既有故事事实保持一致；但故事历史很快超出上下文窗口，且长上下文存在“中间信息丢失”问题，因此需要显式的故事世界记忆。
- **三大挑战**：
  - **异质叙事信息**：同一段落可能混合客观世界事实、角色信念、剧情发展、伏笔可能性，且彼此可能冲突。
  - **跨粒度整合**：如“背叛”可能跨十章逐步累积，记忆需把多章证据整合为单一发展，同时不丢失底层事实。
  - **隐含依赖恢复**：写作请求往往信息不足，如“重写背叛场景”还需角色关系、受影响知识边界等隐含记忆。
- **整体含义**：论文将长文写作记忆构建视为“世界创建”，而非简单相似检索。记忆应表示动态、视角依赖的故事世界，既保留共享事实，也保留私有心智、开放发展与可能世界分支。

## 2. 方法论

### 2.1 核心思想

- 提出 **NarraWorld**：从一个共享的、以证据为基础的叙事图 \(G_\tau\) 出发，派生四个相互关联的记忆视图：
  - **W：Shared World**，共享世界事实、事件、状态、关系。
  - **B[c]：Private Minds**，角色 \(c\) 的知识、信念、怀疑、误解。
  - **D：Narrative Development**，跨事件的剧情发展、目标、冲突、关系轨迹。
  - **H：Possible Worlds**，与未决发展相关的有界假设分支。
- 四视图不是独立记忆，而是同一证据图的不同投影：  
  \(W_\tau=\Pi^W_\tau(G_\tau)\), \(B_\tau[c]=\Pi^{B[c]}_\tau(G_\tau)\), \(D_\tau=\Pi^D_\tau(G_\tau)\), \(H_\tau=\Pi^H_\tau(G_\tau)\)。

### 2.2 增量记忆构建

- 给定新源文本单元 \(U_\tau\)，更新共享图：  
  \(G_\tau=\text{Update}(G_{\tau-1},U_\tau)\)。
- 更新分四阶段：
  - **实体解析**：角色、地点、物体链接到已有实体，否则新建记录。
  - **事件与事实抽取**：记录事件、命题、状态变化；状态变化关闭旧有效区间，不覆盖历史。
  - **角色访问追踪**：记录角色通过观察、交流、推理等获得的信息，区分共享事实与私有信念。
  - **发展与可能性更新**：更新开放剧情线，并为未决发展生成受约束的假设候选，加入 H。

### 2.3 跨叙事尺度组织

- 层级为：  
  **事件 \(E_\tau\) → 场景 \(S_\tau\) → 故事线 \(L_\tau\) → 情节 \(P_\tau\)**。
- **原子闭包**：每个高层节点保留其成员事件、W/B/D 记录和源证据片段；检索时可先选高层摘要，再展开到底层事实。
- H 记录在被源文本实现前不进入层级，只作为条件性可能保留。

### 2.4 写作时的记忆重建

- 请求定义为 \(q=(x_\tau,\eta_q)\)，其中 \(x_\tau\) 是写作脚手架，\(\eta_q\) 指定叙述者、受述者、聚焦者、故事时间、话语位置、分支等。
- **可采纳视图投影**：  
  \(V_q=\Pi^{\eta_q}(M_\tau)\)，根据时间、披露状态、聚焦、分支过滤可用记忆。
- **预览引导依赖规划**：规划器读取请求、当前段落、角色名册和记忆预览 \(\sigma(V_q)\)，输出：  
  \((F_q,K_q,r_q,N_q)=\Psi(x_\tau,\eta_q;\sigma(V_q))\)，分别表示证据形式、焦点角色、检索意图、缺失信息需求。
- **尺度自适应检索**：  
  \(E_q=\text{Expand}(K_q,F_q;V_q)\cup R(x_\tau,r_q,N_q,K_q,F_q;V_q)\)，结合词法、语义、时间、认知、发展访问，高层匹配可展开到底层。
- **预算组装**：  
  \(C^{\text{mem}}_q=\text{Reconstruct}(q,V_q;b)\)，在 token 预算 \(b\) 内按 W/B/D/H 分组渲染，B 按角色组织，H 保留前提与条件，不把可能性当作已接受事实。
