## 摘要
外部记忆使语言模型智能体能够回答关于过长历史的问题，这些历史超出了答案模型上下文窗口的限制。更新带来了比检索近期事实更难的问题：更改一个关系可能将多跳问题重定向到与问题中未出现的实体有关的记录。我们研究了这种依赖更新的证据选择问题，并提出了 Contract Memory Compiler（CMC）。在看到问题之前，CMC 使用语言模型识别历史中的关系，并记录每个关系在何处被陈述。它应用后续更新来确定当前关系，从问题中提及的实体出发沿着这些关系进行追踪，并在一次调用中将对应的原始记录传给答案模型。因此，是当前状态决定读取哪些证据，而不仅仅是在先前选定的上下文中刷新取值。据我们所知，CMC 在 FactConsolidation 上取得了当前最优的多跳准确率，总体达到 78.25%，在 262K 时达到 61.0%。在提取的关系和答案模型保持固定的情况下，如果在解析更新之前选择证据，多跳准确率会降至 21.50%。我们还提出了 MQuAKE-MemStream，这是一个由 MQuAKE-Remastered 反事实案例构建的有序记忆流衍生数据集。

## Abstract
External memory lets language-model agents answer questions about histories too long for the answer model's context window. Updates create a harder problem than retrieving a recent fact: changing one relation can redirect a multi-hop question to records about an entity absent from the question. We study this update-dependent evidence selection problem and introduce the Contract Memory Compiler (CMC). Before seeing a question, CMC uses a language model to identify relations in the history and record where each one was stated. It applies later updates to determine the current relations, follows them from entities named in the question, and passes the corresponding original records to the answer model in one call. Thus the current state determines which evidence is read, rather than merely refreshing values in a previously selected context. To the best of our knowledge, CMC achieves state-of-the-art multi-hop accuracy on FactConsolidation, reaching 78.25% overall and 61.0% at 262K. With the extracted relations and answer model held fixed, selecting evidence before resolving updates reduces multi-hop accuracy to 21.50%. We also introduce MQuAKE-MemStream, a derived dataset of ordered memory streams built from MQuAKE-Remastered counterfactual cases.

## 1. 核心问题与整体含义

- **研究背景**：语言模型智能体需长期与同一用户交互，历史往往超出答案模型上下文窗口，因此依赖外部记忆存储跨会话信息，并在每次回答时只向模型提供少量记录。记忆系统涉及压缩、图结构、时序版本、检索等多种设计，但真正决定答案质量的是"哪些记录被放进当前输入"。
- **核心痛点**：记忆的**更新**带来比"检索最近事实"更难的问题——改变一条关系可能把多跳问题重定向到**问题中根本未出现的实体**。论文举例：周会原本在 Room A，后来改到 Room B；问题"周会在几楼？"在更新前后完全相同，但正确答案需要读取的旧记录从"Room A 的楼层"变成了"Room B 的楼层"。
- **问题定义**：作者将这一任务命名为 **update-dependent evidence selection（依赖更新的证据选择）**。关键区分：
  - **值刷新**：在已选定的键/上下文里替换成最新值；
  - **键选择**：更新会改变"下一次跳转应访问哪个键"，因此必须在**选择证据之前**先解析当前关系。
- **整体含义**：论文主张"先解析、再遍历"（Resolve, Then Traverse）的读取顺序，将当前状态作为证据选择的依据，而非仅在旧上下文中刷新数值，为长历史智能体记忆提供了一种新的读取范式。

## 2. 方法论：Contract Memory Compiler (CMC)

### 2.1 核心思想
- 在**问题到达之前**离线完成关系抽取与当前图物化；在**问题到达时**从问题实体出发沿当前图做有界遍历，并把对应的**原始记录**一次性交给答案模型（单次调用）。
- 提出**有界读取契约（bounded read contract）**，规定"更新如何影响当前值"与"证据覆盖范围"。

### 2.2 形式化设定
- 有序断言流 $H_{\le t}$，解析后的边 $e=(s,r,o,\tau)$，其中 $s$ 主语、$r$ 关系、$o$ 宾语、$\tau$ 源位置。
- **最后写入胜出（last-write-wins）**：同一键 $(s,r)$ 的较晚断言覆盖较早断言，当前状态 $G_t$ 每个键只保留一条边。
- **读取契约**：对查询 $q$，$A_q$ 为问题显式命名的图主语，$d_{G_t}(A_q,s)$ 为最短有向距离，跳数上限 $h$，则
  $$C_h(q,G_t)=\{(s,r,o,\tau)\in G_t: d_{G_t}(A_q,s)<h\}$$
- 两个可检验性质：**Currency（时效性）**——每条边都是其键的最后写入；**Bounded graph coverage（有界图覆盖）**——深度小于 $h$ 的可达主语的所有当前出边都被包含（"有界闭包"，可能包含问题未要求的支路）。

### 2.3 五阶段流程
- **Stage 1 解析并保留出处**：LLM 将记录标记为 `facts`（主-关-宾三元组）/`unresolved`（保留原记录直接阅读）/`no fact`；做结构校验（记录 ID、JSON schema、字面主语宾语跨度）；用仅基于源文本的 LLM 对齐统一关系名；规范化实体键；保留源位置与原文；未解析记录构成残差集 $U$。
- **Stage 2 物化当前图**：按源顺序重放断言到以（规范化主语 + 对齐关系）为键的字典，每次出现替换该键的边，得到跨查询共享的 $G_t$。
- **Stage 3 锚定显式查询实体**：规范化问题，找出作为完整规范化文本跨度出现的图主语；若一个匹配被更长的匹配包含则保留更长者；其余构成 $A_q$。
- **Stage 4 遍历当前图**：从锚点做 BFS，包含深度 0–4 的所有当前出边，**每个被选宾语成为下一跳主语**（关键：被更新的值会重定向后续证据选择）；按最短深度处理环；按 $(s,r)$ 去重；前沿为空或达到 5 跳上限时停止。
- **Stage 5 渲染源记录**：检索支撑所选边的原始编号记录并加入所有 unresolved 记录；按位置去重、恢复源顺序、施加 60,000 字符预算（含证据前缀），溢出时保留**最新的连续整记录后缀**；提示读者"序号越大越新"。

### 2.4 其他接口与成本
- 更广的 MemoryAgentBench 评估中另用：原始窗口检索（2,048 字符窗口、256 重叠、BM25）、card/raw 查表、覆盖说明加原文回退。
- 实现成本：最新状态构建是一次有序遍历；图读取为扫描锚点、有界遍历、按源位置排序。262K 下 CPU 读取中位数 13.8 ms（p95 144.3 ms）。

## 3. 实验设计

### 3.1 数据集 / 场景
- **FactConsolidation（MemoryAgentBench）**：800 道问题，单跳/多跳各 400，历史长度 6K/32K/64K/262K，含矛盾更新的有序长历史，问最终记忆状态；使用官方子串精确匹配评分。
- **MQuAKE-MemStream（本文提出）**：由 MQuAKE-Remastered 的两跳反事实案例构建的有序记忆流衍生数据集，保留原问题与答案标签；把 pre-edit / post-edit 事实拼成有序块（seed 20260907），最终 800 单跳 + 798 多跳问题；5,560 条断言全部被关系语法解析。
- **MemoryAgentBench 完整四能力网格**：1,000 AR + 700 TTL + 171 LRU + 200 FC 问题，覆盖 14 个源数据集、130 个历史；含 LongMemEval、ReDial、∞Bench、DetectiveQA、文档 QA、分类任务等。

### 3.2 对比方法
- **固定抽取 + 固定读者下的证据视图对比**（核心对照）：

  - `Fact BM25`（20.75% MH，含 size-matched 版本 7.25%）；
  - `Fact dense BGE-M3`（33.25% MH）；
  - `Latest state`（17.00% MH，600/800 截断）；
  - `Raw history`（5.00% MH，600/800 截断）。
- **读者替换**：Qwen3.5-4B（76.50% MH）、Llama-3.1-8B（55.00% MH）、Qwen3.5-9B、HY4-preview。
- **前端替换**：语法适配器（手工模式，79.00%/80.25%）、直接 LLM 抽取（78.25%）、源诱导混合（76.50%）。

## 6. 主要结论与发现

- **顺序至关重要**：固定抽取与读者时，先选证据再解析更新（Prior read + refresh）多跳仅 21.50%，而"先解析再遍历"（CMC）达 78.25%，差距 56.75 点。
- **CMC 达到 SOTA**：FactConsolidation 多跳总体 78.25%，262K 下 61.0%；单跳 97.25%（与 BM25 97.50% 接近）。
- **成本更低**：CMC 平均读者输入 185 token，远低于 fact BM25 的 1,528 token，且无截断。
- **结论跨读者/前端稳健**：Qwen3.5-4B 76.50% vs 20.50%、Llama-3.1-8B 55.00% vs 11.50%；语法适配器 79.00%/80.25% vs 22.50%；直接 LLM 前端 78.
