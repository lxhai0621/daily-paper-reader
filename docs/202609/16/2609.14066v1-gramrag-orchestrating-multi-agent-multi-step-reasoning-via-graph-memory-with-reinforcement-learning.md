## 摘要
尽管现有多智能体检索增强生成（RAG）系统在复杂多模态推理任务上展现出潜力，但它们在推理深度和记忆结构方面仍存在根本性局限，在回答知识密集型问题时面临检索不足和状态盲视等问题。为解决这些局限，我们提出 GraMRAG，一个由图记忆引导的多智能体 RAG 框架，它集成了一个动态多模态记忆图，以实现稳定、多步的多模态推理。我们引入一种视觉-文本桥接推理范式，将多尺度实体裁剪与 ReAct 风格的视觉工具链统一起来，增强长时程跨模态推理能力。我们进一步构建一个多模态记忆图，将智能体推理形式化为动态有向无环图（DAG），显式建模动作-观察依赖关系，以缓解状态盲视并抑制冗余检索。此外，我们提出拓扑感知策略优化（TAPO），利用图拓扑进行关键路径识别和针对性节点剪枝，从而在多步推理轨迹中实现细粒度信用分配。在具有挑战性的多模态基准上的大量实验表明，我们的方法持续优于现有基线，并在复杂长时程推理任务上取得最先进性能。

## Abstract
Although existing multi-agent Retrieval-Augmented Generation (RAG) systems have demonstrated promise on complex multimodal reasoning tasks, they remain fundamentally limited in reasoning depth and memory structure, suffering from inadequate retrieval and state blindness when answering knowledge-intensive questions. To address these limitations, we propose GraMRAG, a graph memory-guided multi-agent RAG framework that integrates a dynamic multimodal memory graph to enable stable, multi-step multimodal reasoning. We introduce a vision-text bridged reasoning paradigm that unifies multi-scale entity cropping with a ReAct-style visual toolchain, enhancing the long-horizon cross-modal reasoning capability. We further construct a multimodal memory graph that formalizes agent reasoning as a dynamic directed acyclic graph (DAG), explicitly modeling action-observation dependencies to mitigate state blindness and suppress redundant retrieval. Moreover, we propose Topology-Aware Policy Optimization (TAPO) that leverages graph topology for critical path identification and targeted node pruning, enabling fine-grained credit assignment across multi-step reasoning trajectories. Extensive experiments on challenging multimodal benchmarks demonstrate that our approach consistently outperforms existing baselines and achieves state-of-the-art performance on complex long-horizon reasoning tasks.

## 2. 方法论：核心思想与关键技术细节

### 2.1 视觉-文本桥接推理范式（Vision-Text Bridged Reasoning）

- **多尺度视觉实体定位**：给定图像 `I`、查询 `q` 与视觉归纳提示 `pv`，Visual Explorer 在每步 `t` 同时生成粗粒度上下文区域与细粒度实体级 patch，形成候选框集合 `Bt = {b1_t, ..., bNt_t}`，并触发视觉检索动作 `Avt = VSearch(Bt)`。
- **两阶段视觉工具链**：图像搜索模块将裁剪区域与 web 级索引匹配，返回候选 URL；网页检索模块以结构化 Markdown 抓取页面内容，得到观测 `Ovt = VisChain(Avt)`。
- **独立 Hit/No Hit Judge**：由独立判别器输出二元接受信号 `st = Judge(I, q, Ovt) ∈ {0,1}`。命中（st=1）则将观测加入有效证据池 `Ev`；未命中（st=0）则触发更细粒度裁剪或改写查询。该设计实现了**探索策略与证据评估的解耦**，提升鲁棒性。
- **模态桥接与文本推理**：Captioning 模块生成图像文本描述 `D`，将视觉轨迹中 `I` 替换为 `D`、移除视觉归纳提示，保留 CoT 推理 `Rt`、动作 `Avt` 与 judge 验证过的观测，转发给装备 web 搜索工具的 Text Researcher，生成文本推理轨迹 `τtext`。
- **证据聚合**：Evidence Validator 跨模态校验全部证据，解决冲突、过滤幻觉并生成最终答案 `aout`；最终合并得到完整多模态轨迹 `τ`。

### 2.2 多模态记忆图（Multimodal Memory Graph）

- **图结构**：构建动态有向无环图 `Gt = (Vt, Et)`，显式编码动作-观察依赖，记录各智能体探索轨迹。
- **节点模式**：每个节点为类型化四元组 `ni = (μi, κi, σi, νi)`：
  - `μi ∈ {nroot, nvis, nbrd, ntxt, nans}` 为模态类型标签；
  - `κi` 为驱动节点创建的搜索查询/动作描述；
  - `σi` 为检索或生成内容的简洁文本摘要；
  - `νi` 为视觉特征库（仅 nvis 节点填充）。
- **五类节点**：根节点（用户查询+图像，永久驻留）、视觉节点（视觉探索阶段产生，含 Hit/No Hit 判定）、桥接节点（单例，存储图像描述 `D`）、文本节点（文本研究阶段产生）、答案节点（最终答案，标志推理终止）。
- **四阶段迭代扩展协议**：
  1. **视觉扩展**（t ∈ [1, Tv]）：插入 nvis 节点并加顺序边；
  2. **模态桥接**：插入 nbrd 节点并以跨模态桥接边连接最后一个视觉节点；
  3. **文本扩展**（t ∈ [Tv+1, Tv+Tt]）：插入 ntxt 节点并连接桥接节点到首个文本节点；
  4. **答案生成**：证据充足时插入 nans 节点，推理结束。
- **意义**：将推理轨迹以结构化 DAG 而非一维序列保存，使各智能体可高效查询完整历史推理状态，同时为 RL 细粒度信用分配提供拓扑骨架。

### 2.3 拓扑感知策略优化（TAPO）

- **图结构轨迹分解**：策略模型 `πθ` 每步接收图序列化上下文 `Ct = {ssys, q, Ht}`（`Ht = Serialize(Gt-1)`），产生与单个图节点构建精确对应的推理片段 `st = (Ct, ζt, At, Ot) → nt`；完整轨迹分解为有序片段序列 `Ψ = {s1, ..., sTv+Tt, sans}`，建立策略梯度信号与图拓扑的结构性对应。
- **拓扑驱动信用分配**：
  - **正确轨迹（r=1）**：从 `nans` 沿有向边反向遍历至 `nroot` 识别**关键推理路径 ρ\***；不在 ρ\* 上的节点为"拓扑死胡同"（对正确答案无因果贡献的探索步骤），抑制其梯度以免强化无目的探索。
  - **错误轨迹（r=0）**：识别**认知上有价值的节点集合 Nval**。nvis 节点中存储 `st=1` 的视为有价值；ntxt 节点由专门的相关性评估器判定是否与查询直接相关。将 Nval 从负梯度更新中排除，避免惩罚那些实际上做了有效检索、但因其他步骤失败导致整条轨迹失败的步骤。
- **梯度掩码与目标函数**：
  - 掩码定义：`ψt = I(r=1)·I(nt ∉ ρ*) + I(r=0)·I(nt ∈ Nval)`，`ψt=1` 抑制梯度，`ψt=0` 正常更新。
  - TAPO 目标：在标准 PPO 裁剪目标上乘以 `(1-ψg,i)` 因子进行选择性门控，并加入 KL 正则项 `β·KL[πθ ∥ πref]`。
  - 效果：正轨迹中屏蔽死胡同步骤，负轨迹中保护有价值检索步骤，实现步骤级精确信用分配。

## 6. 主要结论与发现

- **SOTA 性能**：GraMRAG 在所有基准上持续领先，4B 设置整体平均 **48.5%**，8B 设置 **53.5%**，分别较最强基线 VimRAG（45.6% / 50.1%）进一步提升。

- **两条 RL 洞见**：① 优化稳定性根本上取决于保证正确的正梯度信号、消除负轨迹中的模糊更新；② rollout 样本质量（偏好对齐程度）比单纯扩大训练集规模对性能更具决定性。

- **基线适配疑点**：个别基线在特定数据集上表现异常偏低（如 4B 下 UniversalRAG 在 MMLongBench 仅 5.2），可能存在实现或提示适配问题，论文未做深入分析，可能影响对比公平性的说服力。
- **图结构的可扩展性隐忧**：随交互轮次增加，DAG 节点与边持续增长，序列化上下文 `Ht` 的长度控制策略、剪枝或压缩机制未充分讨论，长时程下是否仍会出现上下文压力有待验证。

## 9. 对领域的启示与总体评价

- **范式意义**：GraMRAG 的核心贡献在于把"记忆"从一维序列升级为结构化图，并让强化学习的信用分配直接作用于图拓扑。这一"结构即信用"的思路，为多模态智能体的长时程推理与训练提供了可复用的设计模板。
- **方法论价值**：视觉-文本桥接范式说明，在多模态场景中不必让策略模型直接消化原始视觉观测，而可通过描述性桥接降低模态鸿沟，这为视觉 RAG 的工程化落地提供了更易控的路径。
- **实践启示**：实验结果支持"推理深度决定检索质量"的判断——提升检索轮次并配合结构化记忆，比单纯扩大检索规模或训练集更有效；同时提示 RL 训练中负样本的处理方式（保护有价值步骤）与正样本的稀疏化处理（屏蔽死胡同）同等重要。
- **总体评价**：论文问题定位准确、方法体系完整、实验规模在同类工作中较为充分，SOTA 结果与消融结构相互印证，具备较强的学术与工程参考价值。主要短板在于资源报告不全、消融与统计严谨性有待加强、跨模型泛化与成本分析缺失，这些也是后续工作可优先补足的方向。
