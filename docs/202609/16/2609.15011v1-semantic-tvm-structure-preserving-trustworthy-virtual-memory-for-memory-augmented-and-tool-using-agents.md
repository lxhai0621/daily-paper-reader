## 摘要
记忆增强与工具使用智能体在远程LLM处理检索到的记忆、工具动作和中间观察结果时，会暴露精确的私有值。单向掩蔽限制了直接暴露，但会移除可信执行所需的值，并可能通过后续观察泄露这些值。我们提出可信虚拟内存（TVM），一种闭环运行时，将精确值状态保留在本地，同时向远程模型呈现受保护的视图。在这一单一运行时内，Rule-TVM用可在本地恢复的句柄替换整个受保护字段，而Semantic-TVM则仅替换由可信本地模型预测的敏感片段，从而保留周围与任务相关的上下文。在两个提供商的Memory-EHR和Memory-RAP上，片段级投影恢复了全字段替换下损失的大部分EHR效用（在DeepSeek上任务成功率为84.17%对52.33%），同时测得的暴露保持在低位，工作流仍可执行。

## Abstract
Memory-augmented and tool-using agents expose exact private values when remote LLMs process retrieved memory, tool actions, and intermediate observations. One-way masking limits direct exposure but removes values needed for trusted execution and can leak them through later observations. We propose Trustworthy Virtual Memory (TVM), a closed-loop runtime that keeps exact-value state local while presenting a protected view to the remote model. Within this single runtime, Rule-TVM replaces whole protected fields with locally recoverable handles, and Semantic-TVM instead replaces only sensitive spans predicted by a trusted local model, preserving surrounding task-relevant context. On Memory-EHR and Memory-RAP across two providers, span-level projection recovers most of the EHR utility lost under whole-field replacement (Task Success 84.17% vs. 52.33% on DeepSeek) while measured exposure stays low and workflows remain executable.

# Semantic-TVM 论文详细中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：记忆增强与工具使用型 LLM 智能体（memory-augmented / tool-using agents）在运行中会组合检索示例、历史动作、私有记录与工具观测结果。当在线 LLM 由远程托管时，每一次序列化请求都可能暴露检索记忆或中间状态中的精确私有值（如用户标识符、记录绑定、历史搜索词等）。
- **已有工作的不足**：
  - 单向掩码（one-way masking）虽能降低初始请求中的暴露，但会移除可信执行所需的精确标识符，导致工作流不可执行。
  - 智能体工作流跨越多轮请求，可信执行器返回的观测可能重新包含这些私有值，仅保护初始提示无法覆盖完整执行周期。
  - 已有研究（如 PAPILLON、MINIM、SlotGuard、PlanTwin）分别处理了部分环节，但缺乏一个贯穿"投影—解析—执行—重投影"全生命周期的闭环方案。
- **核心问题**：如何在向远程 LLM 提供足够任务上下文的同时，保证精确私有值始终不进入任何在线序列化消息，且可信执行仍可正常进行？
- **整体含义**：论文提出 Trustworthy Virtual Memory（TVM），将远程可见上下文与本地精确值状态分离，并在同一运行时内提供两种粒度的投影实现（Rule-TVM 与 Semantic-TVM），以在隐私与效用之间取得更优权衡。

## 2. 论文提出的方法论

### 2.1 核心思想
- TVM 在智能体路径中插入一个**可信本地中介 T**，形成闭环运行时：本地保留精确值，向远程模型只呈现"受保护视图"。
- 信任边界明确：TVM、本地投影模型、恢复存储与执行器属于可信域；远程 LLM 提供商属于不可信域，所有出站消息均被审计。

### 2.2 关键技术细节与流程
- **投影（Projection）**：在第 t 轮，给定公开任务 x、检索记忆 R_t 与场景适配器 A_s，执行  
  (R̃_t, ρ_t) = T_project(R_t, x, A_s)  
  其中 R̃_t 为在线安全视图，ρ_t 为本地恢复状态；在线模型只接收 R̃_t，不接收 ρ_t。
- **解析（Resolve）与执行（Execution）**：当远程模型输出计划/动作 a_t 后，本地执行器在可信域内解析  
  â_t = T_resolve(a_t, ρ_{≤t})，o_t = E(â_t)  
  解析前会校验工具、参数路径、期望类型与作用域。
- **重投影（Reprojection）**：执行产生的观测在进入下一轮请求前被重投影  
  õ_t = T_reproject(o_t, ρ_{≤t})  
  原始观测与解析后的动作永不进入在线历史。
- **暴露度量（零匹配准则）**：对受保护值清单 P_τ 与全部实际传输消息 Q_τ，要求  
  ∀q ∈ Q_τ, ∀v ∈ P_τ: Match(v, q) = 0  
  即序列化请求中不得出现精确匹配或保守归一化变体。

### 2.3 两种投影粒度
- **Rule-TVM（整字段投影）**：按部署策略 Π_s 对受保护字段整体分配句柄 h，本地存储 H_τ[h] = (p, v, type(v), policy(p))；句柄不编码原始值。这是确定性实现，将掩码扩展为可逆的闭环路径。
- **Semantic-TVM（片段级投影）**：仅改变投影算子。由可信本地模型 G_φ 预测敏感片段  
  (m̃_i, ρ_i) = G_φ(m_i, x, A_s)  
  只替换预测出的敏感 span：需精确执行的 span 获得作用域槽位（scoped slot），其他受保护 span 获得作用域占位符；其余内容保留在原始字段或模式边界内。ρ_i 在可信域内保留试验级路径、精确值、引用与敏感标签。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark
- **Memory-EHR**：基于 MIMIC-III 的查询设置，源自 EHRAgent 风格的代码生成工作流。智能体按编辑距离检索 4 个示例，经在线 LLM 生成查询程序并本地执行。受保护信息包括患者标识符、记录绑定，以及历史示例中存在但当前任务未披露的精确可执行值。记忆规模 200，k = 4。
- **Memory-RAP**：500 条 WebShop 记忆，按编辑距离检索 3 个示例。智能体根据历史动作构造搜索动作，由本地搜索工具执行并返回观测。当前公开指令与类别为公开，仅源自历史动作的精确搜索词受保护。该数据集为隐私披露探针，无独立真值答案，因此仅报告 Execution Success。记忆规模 500，k = 3。
- **两个远程提供商**：DeepSeek-V4-Flash 与 MiniMax-M2。
- **本地投影模型**：gemma4:e4b-it-qat，温度 0。

### 3.2 对比方法
- **No Defense**：原始检索记忆直接发送给在线 LLM。
- **Masking**：单向出站替换为固定占位符，无可信恢复与观测重投影。
- **Rule-TVM**：整字段句柄/胶囊投影，带本地解析与重投影。
- **Semantic-TVM**：场景条件化、模式保持的片段级投影，带本地恢复状态。
- **Classifier-TVM**（消融中）：用本地分类器替代规则字段决策，但仍保持全有或全无操作。

### 3.3 评价指标
- **Leak Rate**：完全捕获的试验中，至少一个受保护值出现在捕获的远程请求中的比例；不完整试验记为 privacy-unknown 并排除出分母。
- **Capture Complete**：所有必需请求是否被捕获。
- **Execution Success**：程序或动作执行成功率。
- **Task Success**：最终结果正确率（覆盖所有尝试的试验）。

## 6. 论文的主要结论与发现

- **暴露显著降低**：No Defense 下 EHR 有 78.50% 的捕获请求包含受保护值匹配，RAP 为 100%；Rule-TVM 的 Leak Rate 不超过 0.67%，Semantic-TVM 在 EHR 不超过 1.00%、RAP 不超过 12.00%。
- **片段级投影恢复效用**：在 DeepSeek 上，Semantic-TVM 将 EHR Task Success 从 Rule-TVM 的 52.33% 提升到 84.17%；在 MiniMax 上从 6.17% 提升到 76.83%。对应 Leak Rate 仅从 0.33% 升至 1.00%、从 0.00% 升至 0.50%（No Defense 为 78.50%）。
- **执行成功率差异明显**：EHR 上 Semantic-TVM 达到 87.50%–92.33%，而 Rule-TVM 为 46.67%–61.67%；RAP 上两者均保持 99% 以上。
- **字段级分类不足以恢复效用**：Classifier-TVM 仍接近 Rule-TVM（DeepSeek 47.83% vs 52.33%；MiniMax 7.00% vs 6.17%）。
- **组件作用分工**：Recovery 主要提升 EHR 任务效用；场景 Adapter 主要为 RAP 提供隐私上下文以降低暴露。
- **总体结论**：在共享运行时路径下，表示策略决定工作点——Rule-TVM 最小化暴露，Semantic-TVM 保留更多 EHR 可执行性；粒度应结合管线选择并与验证过的本地恢复耦合。

## 7. 优点（方法或实验设计亮点）

- **闭环生命周期设计**：TVM 不止保护初始提示，而是覆盖投影、解析、执行、重投影全过程，解决了观测回流泄露问题。
- **统一算子、两种粒度**：Rule-TVM 与 Semantic-TVM 共享生命周期、解析与重投影路径，只在投影粒度上不同，便于对照分析与按管线选型。
- **结构保持的片段级投影**：只替换敏感 span，保留查询操作符、关系与动作模式等任务相关上下文，避免整字段替换造成的信息瓶颈。
- **可信执行与隐私解耦**：精确值仅存在于可信域，句柄不编码原始值，解析前进行工具、路径、类型与作用域校验，安全边界清晰。
- **度量客观可操作**：采用零匹配准则在序列化消息边界测量可检测暴露，区分完全捕获与隐私未知试验，指标定义透明。
- **消融设计清晰**：Adapter × Recovery 的 2×2 矩阵有效分离了两个组件的贡献。

## 8. 不足与局限

- **隐私度量范围有限**：仅测量受保护清单中值的精确或归一化匹配，不建立语义隐私，也无法阻止从保留上下文中推断信息。
- **句柄元数据泄露**：试验级句柄仍会暴露每类基数和哪些位置指向同一记录。
- **对抗性风险**：检索内容可被投毒以操纵投影模型；重投影可能漏掉非预期结构中的值；恢复与模式修复也可能重新引入原始内容。
- **覆盖范围有限**：仅两个提供商、两个管线、不同效用定义，未测量投影保真度、本地延迟、吞吐量或硬件成本。
- **算力信息缺失**：未报告 GPU 型号、数量、训练时长等资源细节。
- **工具侧不在范围内**：接收精确参数的工具提供商、本地状态与记忆存储未纳入信任分析。
- **部署建议**：高保障部署应结合保守投影与类型化恢复绑定，并根据管线选择粒度。
