## 摘要
长时程语言模型智能体会不断累积推理历史，即使在早期决策已被执行和观测之后，仍会增加上下文长度和推理成本。与静态思维链压缩不同，移除历史推理可能会改变未来动作以及由此产生的交互轨迹。我们研究此类推理何时可以被安全遗忘。我们提出面向长时程推理的交互感知压缩（Interaction Aware Compression for Long Horizon Reasoning, ICLR），这是一种免训练的在线方法，它使用冻结的代理熵对推理块进行排序，同时保留动作、工具调用和观测。在 260 个 WorkBuddyBench 任务上，ICLR 将平均奖励从 0.699 提升至 0.718，同时将输入、输出和缓存读取 token 分别减少 25.5%、14.4% 和 33.3%。消融实验揭示了轨迹放大效应：局部删除推理会通过改变后续交互，对总计算量产生非线性变化。表示探测、激活修补和受控轨迹分析进一步表明，一旦任务相关的派生状态被可靠地外化到代码、文件、工具输出或环境反馈中，历史推理就会变得更可替代。这些结果将智能体推理刻画为动态工作状态，而非永久的交互历史。

## Abstract
Long horizon language model agents continually accumulate reasoning history, increasing context length and inference cost even after earlier decisions have been executed and observed. Unlike static Chain of Thought compression, removing historical reasoning can change future actions and the resulting interaction trajectory. We study when such reasoning can be safely forgotten. We propose Interaction Aware Compression for Long Horizon Reasoning (ICLR), a training free online method that ranks reasoning blocks using frozen proxy entropy while preserving actions, tool calls, and observations. On 260 WorkBuddyBench tasks, ICLR improves average reward from 0.699 to 0.718, while reducing input, output, and cache read tokens by 25.5%, 14.4%, and 33.3%, respectively. Ablations reveal trajectory amplification, where local reasoning deletion produces nonlinear changes in total computation by altering subsequent interaction. Representation probing, activation patching, and controlled trajectory analyses further suggest that historical reasoning becomes more replaceable once task relevant derived state has been reliably externalized into code, files, tool outputs, or environmental feedback. These results characterize agent reasoning as dynamic working state rather than permanent interaction history.

## 1. 核心问题与整体含义
- **研究动机**：长时程语言模型智能体在“推理—行动—观测”循环中不断累积历史推理。即使早期决策已执行并获得环境反馈，旧推理仍会被反复放入后续请求，导致上下文变长、推理成本上升。
- **核心问题**：历史推理在何时可以被安全遗忘？与静态思维链压缩不同，智能体中的推理删除会改变下一步动作、工具调用、观测以及后续决策，因此不能仅以“最终答案是否不变”来衡量。
- **整体含义**：论文将智能体推理视为**动态工作状态**，而非永久交互历史。其未来价值取决于当前任务状态，尤其取决于任务相关派生状态是否已被外化到代码、文件、工具输出或环境反馈中。

## 2. 方法论：ICLR
- **核心思想**：提出 **Interaction Aware Compression for Long Horizon Reasoning (ICLR)**，一种免训练的在线压缩方法。它在真实交互循环中压缩已完成的推理，同时保留动作、工具调用、观测和最终答案。
- **在线压缩流程**：
  - 第 \(t\) 步交互记为 \(S_t=(R_t,A_t,O_{t+1})\)，其中 \(R_t\) 为推理，\(A_t\) 为动作/工具调用，\(O_{t+1}\) 为观测。
  - 第 \(k\) 次请求前历史为 \(H_k=(P,S_1,\dots,S_{k-1})\)。
  - ICLR 在每个已完成步骤后，仅压缩刚完成的推理，写回持久历史，后续请求均基于压缩后的轨迹。
- **代理熵评分**：
  - 将推理按双换行切分为块 \(R_t=(B_1,\dots,B_N)\)。
  - 使用冻结代理模型计算 token 级预测熵：
    \[
    h_t=-\sum_{v\in V}p_\theta(v|c_t)\log_2 p_\theta(v|c_t)
    \]
  - 块得分 \(H(B_i)\) 为块内 token 熵均值。低熵表示代理模型更确定，被视为更可压缩。
- **上下文条件排序**：
  - 评分器接收系统提示、工具定义、累积交互历史及当前步骤，按因果顺序评分，即 \(H(B_i|H_t)\)。
  - 同一推理在不同轨迹状态下可能得到不同分数。
- **块选择与替换**：
  - 删除最低熵的 \(\lfloor 0.8N\rfloor\) 个推理块，替换为 `[SKIP]`，保留块顺序和原文。
  - 当 \(N=1\) 时不删除。压缩仅作用于推理，动作、工具参数、工具输出、观测和最终答案不变。
- **干预变体**：
  - **Step Only Entropy**：仅用当前步骤推理评分，去除历史上下文。
  - **Delete All Thinking**：删除全部目标推理，保留动作和观测。
  - **Random r**：随机删除 \(r\in\{5\%,10\%,20\%,40\%\}\) 的推理 token。
- **未来必要性分析**：
  - **表示探测**：在压缩边界用线性探针预测后续是否出现重新推导、额外推理或重规划，采用严格任务级嵌套划分。
  - **激活修补**：在冻结传感器模型中，用完整历史残差替换删除历史残差，测量下一 token 分布恢复程度。
  - **状态外化分析**：定义 \(G_i=I(U_i\neq\emptyset)\)，区分任务相关派生状态是否仍仅存在于推理中。
  - **受控状态干预**：比较保留/删除最新推理、代码写盘后清除推理、保留/隐藏环境反馈等。
