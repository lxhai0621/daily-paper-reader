## 摘要
现代大语言模型（LLM）和AI智能体日益支持整合来自非结构化来源证据的数据工程工作流。此类流水线通常先进行数据检索、集成与排序，再进入更复杂的智能体推理或动作，例如用于科学发现。这些工作流中的核心检索问题联合执行多属性过滤、多向量搜索、精确关系连接以及带阈值的嵌入相似性连接。给定一个规划好的查询和单调评分函数，我们的DASE查询引擎构建并排序候选证据元组。它包含：(i) 一个面向结构化谓词、多向量和关系链接的多步推理查询模型；(ii) SemJI，一种用于稀有近邻对的稀疏物化嵌入相似性连接索引；(iii) 一个协同设计的执行层，结合谓词感知的ANN遍历、批量访问和基于阈值的分数聚合。在科学发现类工作负载上，对于多步推理查询，DASE在召回率相当的情况下，检索候选证据的速度比强RDBMS、重排序和向量数据库基线快6倍到46倍；对于需要语义算子后处理的任务，DASE充当高召回预过滤器，使下游LLM评估更便宜且更准确——例如，在SemBench E-Commerce上，它将BigQuery的质量从0.67提升到0.80，同时将成本从2.42美元降至0.54美元。

## Abstract
Modern LLMs and AI agents increasingly support data engineering workflows that integrate evidence from unstructured sources. Such pipelines typically do data retrieval, integration, and ranking before proceeding to more complex agentic reasoning or actions, e.g., for scientific discovery. The core retrieval problem in these workflows jointly executes multi-attribute filtering, multi-vector search, exact relational joins, and thresholded embedding-similarity joins. Given a planned query and monotone scoring function, our DASE query engine constructs and ranks candidate evidence tuples. It comprises (i) a multi-step reasoning query model over structured predicates, multiple vectors, and relational links; (ii) SemJI, a sparse materialized embedding-similarity join index for rare near-neighbor pairs; and (iii) a co-designed execution layer that combines predicate-aware ANN traversal, batched access, and threshold-based score aggregation.   On scientific-discovery workloads, DASE retrieves candidate evidence for multi-step reasoning queries 6x to 46x faster than strong RDBMS, rerank, and vector-database baselines at comparable recall; and for tasks that require semantic-operator post-processing, DASE acts as a high-recall prefilter that makes downstream LLM evaluation both cheaper and more accurate -- e.g., on SemBench E-Commerce it improves BigQuery quality from 0.67 to 0.80 while cutting cost from $2.42 to $0.54.

# 论文总结：Efficiently Linking Unstructured Data for Multi-step Reasoning

## 1. 核心问题与研究动机

- **背景**：现代 LLM 与 AI 智能体日益承担数据工程工作流，需要从非结构化来源（文档、段落、知识图谱注解、分子结构等）中整合证据，以支撑科学发现、深度研究（deep research）、广域搜索（wide search）等任务。
- **核心检索难题**：这类工作流在进入智能体推理之前，需先完成一个联合检索原语——同时执行 **多属性过滤（P）、多向量相似度评分（S）、精确关系连接以及带阈值的嵌入相似度连接（J）**，并将候选证据元组按统一评分函数排序返回 top-k。
- **现有方案不足**：
  - 向量数据库（Pinecone、Weaviate、Milvus）不原生支持多表连接规划与多信号联合排序；Milvus 支持混合搜索但无关系连接规划。
  - 标准 RDBMS 的 ANN 索引仅面向 1-to-N 点查询，无法执行 M-to-N 嵌入相似度连接；且无法联合评估多信号评分，导致真正 top 结果可能深埋于 ANN 排序流中，无法提前终止。
  - 检索式重排序（rerank）可能召回率偏低；向量优先/过滤优先策略在“中间地带”效率低下。
- **整体含义**：多步推理查询在索引、优化与执行层面引入新挑战，需要重新思考数据系统的查询执行方式，以支持“智能体优先”的架构。

## 2. 方法论

### 2.1 查询模型

- 多步推理查询形式化为三元组 **Q = (P, S, J)**：
  - **谓词 P**：结构化布尔约束集合，每个谓词建模为指示函数 p_i: R → {0,1}。
  - **相似度连接条件 J**：{(e_{1,i}, e_{2,i}, dis_i, τ_i)}，当嵌入距离 dis_i(e_1, e_2) ≤ τ_i 时建立链接，属于可行性谓词而非评分信号。
  - **评分模型 S**：score_f(s_1, ..., s_|S|)，每个 s_i 是“越高越好”的亲和度（距离经非增变换 φ 转为亲和度），聚合函数 f 逐坐标非递减（如非负加权和），满足 Fagin 单调性假设，支持阈值式 top-k 高效求值。

### 2.2 SemJI（语义连接索引）

- **核心思想**：高维近似各向同性嵌入空间中，成对距离集中在稠密主体（bulk），语义上有意义的近邻对仅占稀薄左尾。因此可**物化近距离对**作为稀疏连接索引。
- **定义**：给定物化半径 τ_cap，物化 J_τcap = {(A,B) | dist(A,B) ≤ τ_cap}，每项记录源字段、元组指针与距离。
- **正确性与覆盖**：精确构造可精确回答 τ_q ≤ τ_cap 的相似度连接谓词；τ_q > τ_cap 时由基引擎枚举外带 τ_cap < dist ≤ τ_q。ANN 构造为近似索引，仅对其检索到的候选集精确。
- **构造方式**：
  - 精确构造：枚举笛卡尔积保留所有 ≤ τ_cap 的对，作为近似构造召回的 ground truth。
  - 近似构造：基于 ANN 结构 filter-and-refine；备选 E2LSH（未实际实现）；**首选半径扩展 HNSW（Algorithm 1）**——将剪枝门限放宽为 max(beam 边界, τ_cap)，提升范围查询召回但不保证完备性。
- **批量执行优化**：精确构造用分块向量化距离计算；近似构造按共享上层遍历或哈希桶分组探针，提升局部性。
- **多步推理支持**：将物化连接视为关系视图，链式执行 R_chain ← Fetch(J_1,τ_1) ⋈ ... ⋈ Fetch(J_m,τ_m)，投影后得到语义半连接谓词 P_J 下推至 Filtered-Score Streamer。
- **容量式阈值维护**：以保留对数为预算 B_max，查询溢出时异步容量倍增（B' = min{B_max, max{2J, J_min}}），重新物化新距离带并发布新版本。静态关系下最多 ⌈log₂(B_max/J_min)⌉ 次扩展，成对物化工作量有输出空间摊销保证。
- **各向异性鲁棒性**：检测中心化嵌入协方差是否集中在少数方向；采用 PCA 白化或 ABTT（移除主方向）等缓解策略，并在变换空间中重新校准 τ_cap 与构建索引，绝不将变换向量查询原始索引。

### 2.3 DASE 执行策略

- **系统架构**：由 Multi-Scoring Aggregator (MSA)、多个 Filtered-Score Streamer (FSS)、SemJI Access Controller 组成，与数据库、ANN 索引、Join 索引管理器协同。
- **谓词感知 ANN 遍历**：
  - 灵感来自 ACORN 的 Oracle Graph 思想，模拟“仅由通过过滤的项构成的索引”。
  - **传递邻居扩展**：当某节点直接邻居全部被过滤时，查看 2 跳邻居，以无效节点为桥梁跨越图间隙。
  - **Bloom 过滤器优化**：将节点过滤集编译为 Bloom 过滤器（O(N log(1/ε)) 位，O(N) 构建），以位运算快速校验；数据集过大时回退磁盘策略。
- **Filtered-Score Streamer (FSS)**：生成单信号按降序排列且通过过滤的流，按选择性 σ 自适应选择路径：
  - **语义路径**：σ < σ_1 属性优先；σ > σ_2 向量优先后过滤；中间区间用谓词感知 ANN 遍历。阈值 σ_1, σ_2 由离线 profiling 在固定召回目标下确定。
  - **关系路径**：按距离升序扫描连接索引，可借助 B-tree 加速。
  - **属性路径**：用 B-tree 索引过滤。
- **Multi-Scoring Aggregator (MSA)**：
  - 直接改编 Fagin 阈值算法（TA），保留排序访问、随机访问、top-k 缓冲与阈值停止测试；随机访问可遍历多跳 SemJI 谓词。
  - 当第 K 名分数 ≥ 阈值 τ = score_f(L[1],...,L[n]) 时停止。
  - **精确性**：所有流完备且全局有序、随机访问可重建所有有效元组、分量分数精确时结果精确；使用 ANN 或近似 SemJI 时仅对检索候选集精确。
  - **分布感知流选择**：替代轮询，选择预期能最大降低终止间隙 G = τ - θ_K 的流；线性评分下预期阈值降低约 w_i/(N·f_i(L[i]))，并结合其他流截断分布估计 θ_K 的预期提升，取 i* = argmax{E[Δτ_i] + E[Δθ_{K,i}]}。
- **SemJI Access Controller**：
  - **物化连接谓词**：将拓扑约束转为扁平过滤谓词 P_J ← ⋈ SemJIFetch(J_i)，下推剪枝。
  - **流式关系分数**：按预计算语义距离排序输出 (id, dis) 对，作为标准排序信号输入 MSA。
  - **负载监控与演化触发**：跟踪基引擎完成率（溢出率），超容差时异步触发容量倍增扩展。

- **谓词感知 ANN**：2-hop 自适应策略相比穷举基线取得约 40× 加速（10.1 vs 0.23 QPS），召回

（接上）与基线相当，说明跨越过滤间隙的传递扩展在保持结果质量的同时显著减少了无效节点访问。

- **总体定位**：DASE 表明，将语义连接作为可物化的稀疏索引原语、并让多信号评分在流式 top-k 框架下联合求值，能够同时改善召回与效率；其价值不限于更快检索，更在于为下游 LLM/智能体提供更干净、更完整的证据集，从而在质量与成本上双重获益。

## 7. 局限性与未来工作

- **近似性边界**：SemJI 依赖 ANN 构造，仅对其检索到的候选集精确；半径扩展 HNSW 提升范围查询召回但不保证完备性，τ_q > τ_cap 时仍需基引擎枚举外带区间。因此端到端精确性取决于流是否完备且全局有序，近似组件会引入“对候选集精确”而非“对全集精确”的语义。
- **阈值校准依赖**：τ_cap、σ_1、σ_2 等关键参数依赖离线 profiling 与嵌入分布假设；各向异性缓解虽在变换空间重新校准，但仍需针对新数据集重新确定阈值与物化比例，迁移成本未充分讨论。
- **分布与负载代表性**：IMDB、MOLECULE 工作负载多为模板/合成生成，可能与真实智能体查询分布存在偏差；各向异性实验基于 reservoir 样本而非全量，结论的普适性需进一步验证。
- **能力不对等的比较**：部分基线在功能上退化（Milvus 无连接规划、Score-First 在 W7/W8 不可行），超时被计为失败，可能放大 DASE 的相对优势，论文虽已说明，但横向结论应审慎解读。
- **未来方向**：扩展至流式/更新频繁的数据（增量维护物化连接）、多模态与非文本嵌入、更复杂的连接拓扑与聚合函数、以及在真实 deep research 智能体闭环中的端到端评估，均是自然延伸。

## 8. 总体评价

- **贡献层次**：论文将“多步推理检索”从单一向量检索问题重新界定为 **P/S/J 联合查询执行**问题，并给出可落地的系统方案（SemJI 索引 + DASE 执行器），在问题建模与工程实现两端都有实质性贡献。
- **方法亮点**：
  - 以“高维嵌入距离集中于稠密主体、有意义近邻居稀薄左尾”的几何直觉，支撑**稀疏物化语义连接**这一核心设计，并给出精确/近似两条构造路径与容量式演化机制。
  - 将 Fagin 阈值算法与过滤感知 ANN 遍历、分布感知流选择结合，使多信号 top-k 能在多流上高效、可提前终止地求值。
  - 谓词感知 ANN 的 2-hop 传递扩展与 Bloom 过滤优化，针对“过滤后图断裂”这一实际问题给出简洁有效的缓解。
- **实证强度**：覆盖多数据集、多类工作负载、多系统基线与多维度指标，含穷举参考、置信区间与系统性消融，复现材料公开；但合成负载、近似语义与能力不对等比较构成主要外部效度约束。
- **实践意义**：对“智能体优先”的数据系统具有直接启示——语义连接可像关系连接一样被索引与规划，多信号检索应作为一等查询原语而非事后重排序；对科学发现、深度研究等需要跨源证据整合的场景尤具价值。
