## 摘要
现代检索增强生成（RAG）中的开放式查询正变得越来越“弥散”，需要将大量文档组装到有限的 LLM 上下文窗口中。为确保检索质量，系统使用快速的双编码器和更昂贵的交叉编码器（CE）对候选文档进行打分。然而，CE 预算 $B$ 受到延迟的严格限制，且通常小于上下文窗口容量 $k$。这种不匹配使标准重排序在结构上存在缺陷：它浪费计算去验证显而易见的顶部候选，却忽略了初始排序中更靠后的相关文档。为解决这一问题，我们提出了 BoundaryMORPH，一种新颖算法，专门根据 LLM 的上下文容量 $k$ 来分配 CE 预算。利用高斯过程，BoundaryMORPH 将初始双编码器排序视为结构化先验，并智能地将 CE 调用用于在边界处判定 top-$k$ 集合成员资格，而不是寻找单个最相关文档。每次 CE 调用的信息都会传播到未评分文档，从而最大化预算的效用。我们证明，BoundaryMORPH 在多个模型和数据集上，针对开放式查询实现了最先进的集合检索质量（在最强基线上提升 $+5.4$ nCG@100）。

## Abstract
Open-ended queries in modern Retrieval-Augmented Generation (RAG) are increasingly "diffuse," requiring a large set of documents to be assembled into a finite LLM context window. To ensure retrieval quality, systems use fast dual-encoders and more expensive cross-encoders (CEs) to score candidates. However, the CE budget $B$ is strictly bounded by latency and is often smaller than the context window capacity $k$. This mismatch makes standard reranking structurally flawed: it wastes compute verifying obvious top candidates while ignoring relevant documents further down the initial ranking. To address this, we introduce BoundaryMORPH, a novel algorithm that allocates CE budget specifically for the LLM's context capacity $k$. Using a Gaussian Process, BoundaryMORPH treats the initial dual-encoder ranking as a structural prior and intelligently spends CE calls on resolving top-$k$ set membership at the boundary, rather than seeking a single most-relevant document. Information from each CE call propagates to unscored documents, maximizing the utility of the budget. We demonstrate that BoundaryMORPH achieves state-of-the-art set retrieval quality across multiple models and datasets with open-ended queries ($+5.4$ nCG@100 over the strongest baseline).

## 1. 核心问题与整体含义（研究动机与背景）

- **弥散式查询（Diffuse Query）的兴起**：随着 RAG 与 deep-research agent 的普及，用户的开放式查询越来越"弥散"——一个查询（如 "Effects of light pollution?"）往往有几十甚至上百篇相关文档，无法靠单篇或少数几篇文档回答，需要把**大量相关文档**塞进 LLM 上下文。

- **两阶段检索的固有矛盾**：
  - 第一阶段：廉价的双编码器（dual-encoder）通过 MIPS 检索出候选池（如 top-10k）；
  - 第二阶段：昂贵的交叉编码器（CE）对少量候选精细打分。
  - 但 **CE 预算 $B$ 受延迟严格限制，通常小于上下文容量 $k$**（即 $B < k$），论文图示中 $k=100$、$B=25$。

- **标准重排序的结构性缺陷**：
  1. 只对 MIPS top-$B$ 重排序，会漏掉排序更靠后的相关文档；
  2. 当 $B < k$ 时，剩余 $k-B$ 篇文档无法被 CE 评估，系统对"该保留谁、该舍弃谁"缺乏信息。
  - 传统做法把预算浪费在**验证显而易见的 top 文档**上（这些文档无论如何都会被放进上下文），是纯粹的算力浪费。

- **问题重构**：论文将 RAG 文档选择重新定义为一个**预算受限的 top-$k$ 集合选择问题**（budgeted top-k set selection），而非传统的"寻找单一最相关文档"问题。

## 2. 方法论：核心思想与关键技术细节

### 核心思想（两大洞察）
1. **Morph 而非丢弃 MIPS 排序**：双编码器虽不完美，但提供强壮的、免标定的全局相关性表面，应作为结构先验，CE 调用只用来"弯曲"这个表面，而非重建。
2. **瞄准容量边界而非最大值**：上下文容量 $k$ 已知，花费预算确认绝对高分的文档是浪费；真正的不确定性只存在于**纳入/排除的边界**上。

### 关键技术细节

- **高斯过程（GP）代理模型**：
  - 建模对象为**残差** $r(d) = f_{CE}(q,d) - \mu_0(d)$，而非原始 CE 分数。
  - 先验均值 $\mu_0(d)$ 设为文档的 **MIPS 百分位排名**（scale-free，无需逐查询标定）。
  - 核函数采用方向性 **vMF 核** $K(d,d') = \exp(\kappa(\cos(d,d')-1))$，带宽由 median heuristic 自动设定（无需调参）。
  - 后验均值与方差有闭式解：$\mu_t(d) = \mu_0(d) + k_t(d)^\top \tilde{K}_t^{-1}(y_t - \mu_0(A_t))$，$\sigma_t^2(d) = K(d,d) - k_t(d)^\top \tilde{K}_t^{-1} k_t(d)$。
  - **两个可利用性质**：证据附近方差坍缩（区域可判定为"已解决"）；远离证据时均值回退到先验。

- **查询作为零成本观测**：将查询向量作为一个 $y=1$ 的免费观测锚点注入 GP，无需 CE 调用即可收紧查询附近的方差。

- **边界采集规则（Boundary Acquisition）**：
  - 用当前后验均值把候选池分为 **incumbents**（top-$k$ 暂定集合 $S_t$）和 **challengers**（$C \setminus S_t$）。
  - 选择**标准化边界差距最小**的配对：
    $$(j^*, i^*) = \arg\min_{j \in S_t,\, i \in C \setminus S_t} \frac{\mu_t(j) - \mu_t(i)}{\sigma_t(j) + \sigma_t(i)}$$
  - 再对这对中**不确定性更高**的一方（$\sigma$ 更大者）花掉一次 CE 调用。
  - 即：$j^*$ 是"最受威胁的 incumbent"，$i^*$ 是"最强的 challenger"。

- **与已有工作的关系**：该规则改编自 active set ordering（Mean Prediction / LUCB），标准 GP-UCB 是 $k=1$ 的特例。

- **复杂度**：核矩阵构建 $O(N^2)$；后验更新 $O(B^3 N)$；采集步骤 $O(k(N-k))$ 每步。实测中 $O(B)$ 次顺序 CE 推理主导延迟。

### 数据集与场景

- **候选池**：每查询 Qwen3-Embedding-4B MIPS 的 top-$N = 10{,}000$。

### Benchmark / 评价指标
- **nCG@k**（主指标）：面向人类相关性判断，衡量"返回的 $k$ 篇中，相对最优集合的累计相关性比例"。

- **不采用 recall / nDCG@k / MAP**：因为相关文档常超过 $k$，排序顺序不是关键，关键是哪些文档进入上下文。

### 对比方法

- **SS（Single-Stage Rerank）**：标准策略，对 MIPS top-$B$ 用 CE 打分。
- **BAGEL**：零先验 + 标准 GP-UCB（全局最大值搜索），最接近的 GP 方法。
- **RGS**：贪心 kNN 图扩展方法。
- **Agentic loop（DSP）**：多跳检索-阅读智能体基线（附录中对比）。

## 6. 主要结论与发现

1. **全面超越基线**：BoundaryMORPH 在所有 (dataset × B × k) 组合上均最优，高 $k$ 时增益最大（相对次优基线平均 **+3.8 pp nCG@100、+7.3 pp CE-nCG@200**；最强基线上 **+5.4 nCG@100**）。
2. **两个组件均必要**：移除边界采集降低 1.5–2.6 pp，移除 MIPS 先验降低 2.1–3.8 pp，且每个数据集/指标单元都成立。
3. **真正针对容量 $k$ 优化**：当给定 $k_{opt}$ 时，在 $k_{eval}=k_{opt}$ 处性能达峰，证明算法确实利用了已知容量。
4. **预算花在边界**：BoundaryMORPH 最终返回的文档中，被 CE 实际打分的比例远低于 BAGEL（"free" relevance 占比高），说明它跳过了无争议文档。
5. **多模态查询增益更大**：多模态质量（multimodal mass）与相对 BAGEL 的逐查询增益呈 **Spearman ρ = +0.59, p = 3.5×10⁻⁹**——算法能跨越"山谷"探索次级语义峰。
6. **鲁棒性**：跨 4 种 embedder × CE 组合优势保持；检索器越弱，增益越大（弱检索器下相对 SS 提升 +14.0 pp）。
7. **核函数不敏感**：核选择对方法无显著影响，选择能力主要由采集规则与先验驱动。
8. **延迟与质量权衡**：CE 推理主导延迟，预算 $B$ 可作为延迟旋钮；BoundaryMORPH 近乎 Pareto 占优，且支配所有 agentic loop 配置。

## 7. 优点

- **问题重构清晰**：将 RAG 选择明确建模为 budgeted top-k set selection，指出传统 max-seeking 与集合选择目标的结构性错配。
- **方法优雅且免调参**：GP + MIPS 百分位先验 + vMF 核 + median heuristic，无需任何超参搜索，实用性强。
- **信息传播高效**：GP 核让一次 CE 调用影响其近邻未打分文档，突破 $B$ 次调用的信息瓶颈（对比 AcuRank 的独立信念更新）。
- **边界采集规则有理论支撑**：与 LUCB / active set ordering 建立联系，且 GP-UCB 是其 $k=1$ 特例，理论视角统一。
- **实验严谨**：共享候选池、基线逐单元调优、双指标分离主张、慷慨的基线构造、统计检验（Wilcoxon + BH 校正）。
- **多模态分析有洞察力**：用 persistence-based clustering 定义 multimodal mass，并做 LLM 语义审计（ARI 均值 0.635），从几何到语义闭环验证。
- **延迟分析务实**：与 agentic loop 对比，论证 GP 信息传播比自然语言 notes 更高效。

## 8. 不足与局限

- **顺序执行限制**：每次 CE 调用后需更新 GP 后验，**无法批处理**，在高度并行的生产环境中可能不如单阶段重排序（可大批量摊销）有硬件优势。
- **GP 规模瓶颈**：精确后验更新 $O(B^3 N)$，$B=500$ 时 GP 更新达 27.86 s，若未来 CE 推理大幅变便宜，GP 相对开销将凸显。
- **文档数 vs token 限制**：以离散文档数 $k$ 近似上下文容量，而真实 LLM 上下文受 token 约束；虽依赖 chunking 使 token 分布较窄，但变长 chunk 场景仍需适配。
- **查询适用范围窄**：仅针对弥散式查询（需多源），对 $k=1$ 的简单事实型查询无优势，此时标准 max-seeking 已足够。
- **仅解决集合选择，不解决上下文内排序**：因主动跳过无争议 top-$k$，其相对顺序完全依赖 GP 估计；作者论证"是否纳入"比"放在哪里"更重要（引用随机打乱不劣于精细重排的研究），但仍是未解决问题。
- **评测池限制**：所有方法共享 top-10k 池，TravelDest 池覆盖率中位数仅 0.74（最低 0.29），部分相关文档在检索阶段即已丢失，任何选择器都无法恢复。
- **无训练但依赖预计算**：MIPS 排名需预计算；先验质量直接影响性能（检索器越弱绝对性能越低）。
