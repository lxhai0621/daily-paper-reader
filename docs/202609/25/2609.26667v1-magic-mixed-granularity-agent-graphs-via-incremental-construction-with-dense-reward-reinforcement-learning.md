## 摘要
协作拓扑同时影响基于LLM的多智能体系统的性能与执行成本。由于任务在复杂度和所需能力上存在差异，近期方法会生成任务特定的协作图，以指定智能体参与方式与信息流。然而，具有代表性的拓扑生成器在整个组织中要么使用单个智能体，要么使用预定义组，忽略了不同子任务之间不同的协作需求。我们的核心见解是，为每个功能角色局部地选择粒度，从而在一个组织内将细粒度控制与可复用协作模式结合起来。学习这样的组织需要探索一个组合构建空间，而来自最终答案奖励的中间反馈有限。因此，我们提出MAGIC，一种用于混合粒度图生成的密集奖励强化学习框架。具体而言，MAGIC通过依次选择一个功能角色，将其实例化为单个智能体或可复用组，并将其连接到已有单元，来构建混合粒度智能体图。我们直接使用在当前策略下采样的轨迹回报来优化构建策略，并使用基于势函数的奖励塑形，从基于探测的效用和结构信号中提供中间反馈，同时保留累积任务奖励。MAGIC在八个基准上优于最先进的基线，并在我们的效率研究中展现出强大的推理效率。

## Abstract
Collaboration topology shapes both the performance and execution cost of LLM-based multi-agent systems. Because tasks differ in complexity and required capabilities, recent approaches generate task-specific collaboration graphs that specify agent participation and information flow. However, representative topology generators use either individual agents or predefined groups throughout an organization, overlooking differing collaboration needs across subtasks. Our key insight is to select granularity locally for each functional role, combining fine-grained control with reusable collaboration patterns within one organization. Learning such organizations requires exploring a combinatorial construction space with limited intermediate feedback from final-answer rewards. Therefore, we propose MAGIC, a dense-reward reinforcement learning framework for mixed-granularity graph generation. Specifically, MAGIC constructs a mixed-granularity agent graph by sequentially selecting a functional role, instantiating it as a single agent or reusable group, and connecting it to existing units. We directly optimize the construction policy using returns from trajectories sampled under the current policy and use potential-based reward shaping to provide intermediate feedback from probe-based utility and structural signals while preserving the cumulative task reward. MAGIC outperforms state-of-the-art baselines across eight benchmarks and demonstrates strong inference efficiency in our efficiency study.

## 一、核心问题与研究动机

- **背景**：基于 LLM 的多智能体系统（MAS）通过结构化交互协调专业化智能体，其协作拓扑同时决定任务性能与执行成本。由于不同任务在复杂度与所需能力上差异显著，近期工作转向为每个任务生成任务特定的协作图，指定智能体参与方式与信息流。
- **核心矛盾——固定粒度失配（Fixed-Granularity Mismatch）**：
  - **智能体级方法**（如 G-Designer、ARG-Designer）在指定智能体上预测边或生成原子角色与连接，但缺乏可复用的组先验，构建序列长。
  - **组级方法**（如 GoAgent）将预定义协作组作为可复用单元连接，但把组当作不可分的构建单元，限制细粒度结构控制，对单智能体即可处理的子任务强加多智能体执行。
  - 两类方法都在构建前固定节点粒度，只能产生全原子或全组拓扑。
- **具体例证**（API 更新任务）：调查上游变更与测试兼容性可能值得一个 SearchGroup 和 TestingGroup，而实现一两行的补丁只需一个 ProgrammerAgent。固定粒度无法同时满足这两类需求。
- **学习困难**：
  - 混合粒度空间是组合空间：即使固定角色-边骨架，m 个双粒度角色也有 2^m 种实现（D2 给出覆盖上界 Coverage(B) ≤ min(1, B/2^m)）。
  - 最终答案奖励对中间构建决策的反馈有限：相同终分的轨迹在终端奖励下无法区分（D3 显示 MMLU-Pro 上中间 ADD 动作非零优势率仅 32.81%）。
- **核心见解**：为每个功能角色**局部地**选择粒度，在一个组织内统一细粒度控制与可复用协作模式，全原子与全组组织作为特例。

## 二、方法论

### 2.1 核心思想
- MAGIC 从空图出发，**增量式**构建混合粒度智能体图：每步选择一个功能角色，将其实例化为单智能体（AtomicAgent）或可复用组（Group），并连接到已有单元。
- 直接使用**当前策略采样轨迹的回报**优化构建策略，无需预先收集成功轨迹语料；用**基于势函数的奖励塑形**从探测效用与结构信号中提供中间反馈，同时保持累积任务奖励不变。

### 2.2 问题形式化
- 给定查询 Q 与固定角色库 R，构建任务特定的混合粒度智能体图 G = (U, E)，其中 U = {u_i = (i, r_i, z_i)}，z_i ∈ Z(r_i) ⊆ {AtomicAgent, Group}。
- 目标：最大化期望任务分数 max_θ E[E_{G~p_θ(·|Q,R)}[S(Execute(Q,G), y*)]]，约束 G ∈ G_legal 且 N ≤ N_max（顶层单元数上限）。

### 2.3 执行语义
- **原子单元**使用一个角色执行器；**组**使用固定内部智能体图 + 聚合器，对外暴露相同的输入-输出契约。
- 执行时组展开为内部 DAG，按依赖顺序运行；固定外层总结器从所有汇点结果生成最终答案。
- 空图（含立即 STOP）使用基础 LLM 直接回答的最小提示。
- 执行 LLM 与文本编码器**全程冻结**，仅训练图编码器、特征投影、池化与动作头。

### 2.4 任务条件增量构建策略
- **图编码**：冻结的 MiniLM 编码查询与角色实现语义；节点特征融合语义、粒度、构建位置与度数嵌入；共享的 **Edge-aware GRUCell** 按构建顺序编码单元，结合前驱均值表示与查询嵌入。
- **决策上下文**：任务条件注意力池化节点状态，与查询、构建进度拼接后投影。
- **分层动作**：π_θ(a_t|s_t) = π_θ(r_t|s_t) · π_θ(z_t|r_t,s_t) · Π_j π_θ(b_jt|r_t,z_t,s_t)，即角色选择 → 粒度选择 → 前驱边（独立伯努利）。角色与 STOP 共享一个掩码分类分布。
- **合法性掩码**：限制可用角色、可兼容实现、展开深度上界；前驱必须为已有单元，禁止自环与重复；达到单元上限时非 STOP 角色全部被掩码，STOP 成为唯一合法选择（概率为 1 的显式动作）。

### 2.5 基于势函数的密集奖励优化
- **探测效用**：对每个查询的轨迹组，从其他训练查询中固定选择探测集 P（4 个问题），执行部分图获得多查询参考效用。
  - 配对效用增益：ΔU_t = Σ_{p∈P}[S(G_{t+1},p) − S(G_t,p)] / (|P| + κ)
- **结构复杂度**：C(G) = w_n[N_exp(G) − b_n]⁺ + w_e[E_exp(G) − b_e]⁺（展开后的节点/边数，含免费额度）。
- **角色重复**：D(G) = Σ_r [m_r(G) − 1]⁺。
- **单步增量**：d_t = αΔU_t − βΔC_t − γ_R ΔD_t；累积势 Φ_{t+1} = Φ_t + d_t，Φ_0 = 0。
- **奖励塑形**：r'_t = r^task_t + ηΦ_{t+1} − Φ_t；构建期基础奖励为 0，终止时获得任务分数，STOP 处完全结算势（S(G,q) − Φ_P(G)）。
- **命题 1（回报保持）**：当 Φ_0 = Φ_T = 0 且塑形与回报使用相同折扣 η 时，Σ η^t r'_t = Σ η^t r^task_t，证明通过势差望远镜求和，因此塑形保持期望任务回报与最优策略集（η=1 时轨迹总回报恰等于终端任务分数）。

### 2.6 策略优化
- 每查询采样 K=2 条轨迹，计算折扣回报 G_{k,t}，在**相同动作位置**上跨轨迹归一化：A_{k,t} = (G_{k,t} − μ_t)/(σ_t + ε)。
- 损失函数：L = −sg(A) log π_θ(a|s) + β_KL D_KL(π_θ‖π_ref) − β_H H(π_θ)，动作平均包含最终 STOP。
- 参考策略为 RL 开始时的冻结副本；KL 与熵在全分层动作分布上计算；无价值网络，无预收集成功轨迹语料。
- 训练与推理成本分离：探测评估与策略更新仅限训练，推理时仅构建并执行图。

### 2.7 关键超参数
- α=1，β=0.02，γ_R=0.05，η=1，κ=1，u_0=0.5，w_n=w_e=1，b_n=b_e=6；
- 最多 3 个外层单元，最大展开深度 4；Adam 固定学习率 10⁻⁴，β_KL=0.01，β_H=0.001。
