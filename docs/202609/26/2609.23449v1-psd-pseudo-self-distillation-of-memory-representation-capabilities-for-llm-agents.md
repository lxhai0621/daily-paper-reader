## 摘要
记忆系统正成为 LLM 智能体的核心组件，但构建和维护记忆仍然成本高昂，因为它依赖于反复调用大型专有语言模型。这种成本为大规模部署记忆增强型智能体造成了主要障碍。在本文中，我们提出了伪自蒸馏（PSD），一个使小语言模型（SLM）能够通过多阶段训练流程，从强大的黑盒预言机中蒸馏行为，从而构建分层记忆表示的框架。标准蒸馏方法需要访问教师的 logits 或隐藏状态，而闭源模型不会暴露这些内容。与传统的自蒸馏设置不同——传统设置中的监督信号来自模型自身的预测、采样轨迹或聚合输出——PSD 支持单模型蒸馏设置，同时通过提示词引入外部预言机知识。PSD 使用单个小模型承担两种角色：教师看到包含预言机答案作为参考上下文的特权提示，学生只看到任务提示。学生学习复现教师的输出分布，从而在无需访问预言机内部信息的情况下，将预言机引导的行为吸收到自身权重中。在 LoCoMo 上，经 PSD 训练的 Qwen3-0.6B、1.7B 和 4B 在下游检索任务上达到或超过 GPT-4.1-mini，而部署成本仅为其一小部分，其中离策略 PSD 在大多数条件下取得了最强结果。我们进一步表明，这种记忆构建能力可以分布外迁移到 LongMemEval，尽管学生仅在 LoCoMo 上训练，且从未接触 LongMemEval 数据。

## Abstract
Memory systems are becoming a core component of LLM agents, but constructing and maintaining memory remains expensive because it relies on repeated calls to large proprietary language models. This cost creates a major barrier to deploying memory-enhanced agents at scale. In this paper, we present Pseudo Self-Distillation (PSD), a framework that enables small language models (SLMs) to construct hierarchical memory representations by distilling behavior from a strong black-box oracle through a multi-stage training pipeline. Standard distillation methods require access to teacher logits or hidden states, which closed models do not expose. Unlike conventional self-distillation settings, where supervision is derived from a model's own predictions, sampled rollouts, or aggregated outputs, PSD enables a single-model distillation setup while channeling external oracle knowledge through the prompt. PSD uses a single small model in two roles: a teacher that sees a privileged prompt containing the oracle's answer as reference context, and a student that sees only the task prompt. The student learns to reproduce the teacher's output distribution, absorbing oracle-guided behavior into its own weights without accessing the oracle's internals. On LoCoMo, PSD-trained Qwen3-0.6B, 1.7B, and 4B match or exceed GPT-4.1-mini on downstream retrieval at a fraction of the deployment cost, with off-policy PSD achieving the strongest results across most conditions. We further show that this memory-construction capability transfers out-of-distribution to LongMemEval, despite the students being trained exclusively on LoCoMo with no exposure to LongMemEval data.

## 1. 核心问题与整体含义

- **背景**：记忆系统正成为 LLM 智能体的核心组件，智能体需要在长周期交互中保留、组织并复用信息。分层记忆架构（如 MEMORA）通过多阶段流水线构建结构化记忆表示，在 LoCoMo、LongMemEval 等长程基准上达到 SOTA。
- **核心痛点**：高质量记忆构建并非单次推理，而是多阶段、schema 约束的流水线（分段→情景记忆→事实提取→整合→线索锚点），每阶段需多次调用强专有模型（如 GPT-4.1-mini）。随着交互历史增长，调用次数急剧膨胀，造成高昂部署成本，成为规模化部署记忆增强智能体的主要障碍。
- **直接替换小模型失败**：作者用 Qwen3 系列直接替换时，出现大量 JSON 格式错误、字段缺失、生成截断和幻觉；由于流水线顺序执行，上游错误会传播至所有下游阶段，导致记忆质量与下游检索性能显著下降。
- **蒸馏的两难**：经典蒸馏（logits/隐藏状态）与序列级蒸馏分别依赖教师内部信息或 off-policy 教师轨迹；on-policy 方法（GKD、SKD 等）需要可查询的独立教师；自蒸馏方法（OPSD、Purified OPSD）虽无需外部教师，但此前仅用于有明确参考答案的数学/代码推理任务。
- **整体含义**：PSD 旨在仅凭黑盒 oracle 的**最终文本输出**，将记忆构建能力蒸馏进白盒小模型，从而以极低部署成本实现与 GPT-4.1-mini 相当甚至更优的记忆构建质量。

## 2. 方法论

### 2.1 核心思想

- **关键观察**：当模型被提供高质量参考答案时，其输出分布会向该参考偏移。
- **单模型双角色**：同一个 Qwen 小模型分饰两角——
  - **教师**：接收特权提示（任务提示 + oracle 答案作为参考上下文）；
  - **学生**：仅接收普通任务提示。
- 训练目标：最小化教师与学生下一 token 分布的散度，使 oracle 引导的行为被吸收进学生权重，而**无需访问 oracle 的 logits 或隐藏状态**。
- 与常规自蒸馏的区别：常规自蒸馏的监督来自模型自身预测/采样/聚合输出；PSD 则建立了一条通过提示词引入外部 oracle 专长的通道。

### 2.2 关键技术细节

- **前置流水线（MEMORA 五阶段）**：Segmentation（对话分段）、Episodic Memory（情景记忆）、Factual Extraction & Consolidation（事实提取与整合，含 Top-K 相似检索 + LLM 选择器 + create-or-update 规则）、Cue Anchor Generation（[Main Entity]+[Key Aspect] 复合线索锚点）、Update Decision（更新决策）。
- **Oracle 数据收集**：用 GPT-4.1-mini 在 LoCoMo 训练集上跑完整流水线，记录每个阶段每次调用的输入上下文与格式化响应，构成 stage-labeled 数据集 $D_{oracle}$。
- **Stage 1：SFT 预热**：
  - 在 $D_{oracle}$ 上用 Qwen 调优提示 $P^{Qwen}_k$ 做 LoRA 微调；
  - 因各阶段样本量极不均衡（$N_{seg} \ll N_{epi} \ll N_{fact} \lesssim N_{cue}$），采用**阶段均衡采样**（每阶段等量 $n_k$）；
  - 损失为阶段均衡的 token 级交叉熵，既教会任务，也对齐 GPT-4.1-mini 的格式与措辞，为后续蒸馏奠定基础。
- **Stage 2：PSD 分布蒸馏**：
  - **初始化**：教师与学生均从 SFT checkpoint 初始化（$\theta_T \leftarrow \theta_{SFT}$，$\theta_S \leftarrow \theta_{SFT}$）；仅更新学生适配器，**教师冻结**，防止目标分布漂移并起正则作用。
  - **提示不对称**：学生输入 $x^S_k = P^{Qwen}_k(x_k)$；教师输入 $x^T_k = [P^{Qwen}_k(x_k); y_k]$，其中 $y_k$ 为 oracle 响应。
  - **散度**：对温度缩放后的 softmax 分布计算散度，默认使用 **Jensen–Shannon Divergence（JSD）**：$D^{JSD}_\beta(p_T \| p_S) = \beta D_{KL}(p_T \| M) + (1-\beta) D_{KL}(p_S \| M)$，$M = \beta p_T + (1-\beta) p_S$；亦考虑 forward KL 与 reverse KL。
- **三种 rollout 变体**：
  - **On-policy PSD**：学生按学生提示自行生成 rollout $\hat{y}$，师生在同一 rollout token 上分别前向计算分布并算散度；梯度只流入学生，教师 detached。意在匹配推理时学生实际访问的状态。
  - **Off-policy PSD**：教师按特权提示生成 rollout $\tilde{y}$，师生分别在各自提示下对其前向计算分布；轨迹由 oracle 锚定，监督更干净、质量更高。
  - **Mixed PSD**：线性插值 $L_{mixed} = \pi L_{on} + (1-\pi) L_{off}$，$\pi$ 可固定或调度（如早期偏 off-policy、后期偏 on-policy）。

### 2.3 算法流程（文字版）

1. 用 GPT-4.1-mini 在 LoCoMo 训练集上执行完整 MEMORA 流水线，收集 $D_{oracle}$；
2. 在 $D_{oracle}$ 上对 Qwen3 小模型做阶段均衡 SFT，得到 $\theta_{SFT}$；
3. 复制 $\theta_{SFT}$ 为冻结教师 $\theta_T$ 与可训练学生 $\theta_S$；
4. 对每个训练实例：学生用任务提示、教师用特权提示；按选定变体生成 rollout；
5. 在 rollout 各位置计算教师与学生下一 token 分布间的 JSD，仅对 $\theta_S$ 反向传播；
6. 重复直至收敛，得到可独立部署的 PSD 学生模型，用于完整记忆构建流水线。

## 6. 主要结论与发现

- **训练管线贡献**：Base 模型几乎不可用（0.6B 整体 LLM-judge 仅 0.1688），SFT 大幅缩小格式差距，PSD 在每个规模上进一步提升 LLM-judge：0.6B 0.7674→0.8211，1.7B 0.7805→0.8211，4B 0.7805→0.8699，且规模越大增益越大。
- **超越专有上界**：PSD-Qwen3-4B 在 LoCoMo 上取得全场最高 overall LLM-judge（0.8699），超过 MEMORA(GPT-4.1-mini) 的 0.849 与 Full Context 的 0.825；单跳类最佳（0.9355），多跳类与 MEMORA、Full Context 并列最佳

；temporal 与 open-domain 类别亦有竞争力。这表明通过提示通道引入 oracle 专长，可让小模型在结构化记忆构建上反超其教师，而不只是逼近。

- **跨数据集 OOD 迁移**：在未参与训练的 LongMemEval 100 题子集上，PSD 相对 SFT 在三个规模上均有提升，说明蒸馏获得的是可迁移的"记忆构建行为模式"（分段、事实抽取、整合、线索生成），而非对 LoCoMo 训练集的记忆化。但迁移增益幅度小于 in-domain，且与部分基线的差距仍存在，提示 OOD 场景下小模型的天花板更明显。

- **PSD 变体对比（关键消融）**：
  - **Off-policy PSD 最优**：轨迹由教师特权提示（含 oracle 答案）生成，师生在同一高质量轨迹上对齐，监督信号干净、方差小。
  - **On-policy PSD 失效甚至退化**：学生自行 rollout 会迅速偏离 oracle 轨迹；由于教师与学生共享同一 SFT 初始化，且学生早期输出本就存在格式/字段缺陷，教师在学生生成的劣质前缀上难以给出有效修正分布，导致师生分布差异过小（梯度信号弱）或差异集中在错误位置（放大错误）。这一结果反直觉，作者据此强调"在缺乏可验证奖励的记忆构建任务中，on-policy 自蒸馏并不天然占优"。
  - **Mixed PSD（π=0.5）居中**：线性混合未带来超越纯 off-policy 的收益，说明在本任务上轨迹质量比状态分布匹配更关键。

- **规模效应**：PSD 的增益随模型规模单调增大（0.6B < 1.7B < 4B），暗示该蒸馏范式需要一定的容量底座来吸收 oracle 引导的行为；过小的模型即便有教师分布引导，也难以在 schema 约束的多阶段流水线中保持稳定性。

- **成本-质量权衡**：PSD 学生模型可独立部署，无需在推理时调用 GPT-4.1-mini；结合 LoRA 微调与共享初始化，作者主张该方法在保持质量的同时显著降低了记忆构建的调用成本（但论文未给出量化的成本对比）。

- **评估公平性**：LongMemEval 仅评估类别均衡的 100 题子集，而对比基线在完整 500 题上报告，跨方法比较不完全对等；LoCoMo 为单数据集训练，OOD 结论受子集规模限制。
- **统计严谨性**：未报告多次运行的均值/方差或置信区间，训练与推理的随机性影响无法评估；LLM-as-a-Judge 单一评估模型（gpt-4o-mini）可能引入评判偏差，未做多评审模型一致性验证。
- **算力与超参缺失**：GPU 型号、数量、训练时长、学习率、LoRA rank、训练步数、温度与 JSD 权重 β 等关键细节未完整披露，复现与成本核算困难。
- **oracle 依赖**：方法仍需要强专有模型在训练集上跑完整流水线以收集 $D_{oracle}$，数据收集阶段的一次性成本未被量化；未做教师模型替换（如更强/更弱 oracle）的敏感性分析。
- **泛化范围**：仅验证 Qwen3 系列（0.6B/1.7B/4B）与 MEMORA 流水线，未测试其他模型家族、其他记忆架构（Mem0、Zep 等流水线）或其他语言/领域。
- **机制解释的深度**：on-policy 失效给出的解释以定性为主，缺乏对师生分布散度随训练动态变化的定量刻画（如逐阶段梯度范数、KL 轨迹）。
- **评测维度**：以 LLM-judge、BLEU、F1 为主，缺少对记忆库结构正确性（如 schema 合规率、字段完整率、幻觉率、重复条目率）的细粒度诊断，而后者恰是流水线稳定性的核心。

## 8. 启示与价值

- **方法论层面**：PSD 把"提示即通道"的思想引入自蒸馏，证明仅凭黑盒 oracle 的**最终文本输出**即可实现分布级蒸馏，绕开了对 logits、隐藏状态或可查询教师 API 的依赖，为"用闭源强模型能力反哺开源小模型"提供了一条低侵入路径。
- **任务层面**：首次系统地将自蒸馏应用于**无参考答案、schema 约束、多阶段流水线**的智能体记忆构建任务，扩展了自蒸馏的适用边界（此前多限于数学/代码等有明确正确性信号的推理任务）。
- **工程层面**：stage-labeled 数据 + 阶段均衡 SFT + off-policy PSD 的组合，为其他"多阶段 LLM 流水线降本"场景（如数据清洗、知识图谱构建、报告生成）提供了可迁移的配方。
- **反直觉发现的价值**：on-policy 自蒸馏在本任务上失效，提示社区不能默认"on-policy 一定优于 off-policy"，轨迹质量与任务可验证性应作为方法选择的前置条件。
