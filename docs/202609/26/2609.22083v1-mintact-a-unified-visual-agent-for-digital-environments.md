## 摘要
我们提出 MintAct，一个视觉-语言模型系列，统一了 UI 定位、跨移动端、桌面端和网页的多步导航，以及视觉工具使用，并提供 2B、4B 和 8B 三种规模。通过精心设计环境、数据和训练配方，MintAct 模型在这些能力上均达到各领域专用模型的性能。为此，我们开发了可扩展的环境与强化学习（RL）基础设施。在环境方面，我们在异构的领域后端上托管数百个并发实例，同时服务于轨迹数据收集和在线 RL。为实现高效且可扩展的 RL 训练，异步框架显式控制跨域训练分布，并在噪声环境反馈和离策略漂移下保持稳定。实验结果表明，在相当模型规模下，MintAct 在广泛基准上取得最先进性能（在 OSWorld-Verified 上为 48.9）。

## Abstract
We present MintAct, a family of vision-language models that unifies UI grounding, multi-step navigation across mobile, desktop, and web, and visual tool use, trained at 2B, 4B, and 8B scales. Through careful design of our environments, data, and training recipes, MintAct models match the performance of per-domain specialists across all of these capabilities. To enable this, we develop a scalable environment and reinforcement learning (RL) infrastructure. On the environment side, we host hundreds of concurrent instances across heterogeneous per-domain backends, serving both trajectory data collection and online RL. To enable efficient and scalable RL training, an asynchronous framework keeps explicit control over the cross-domain training distribution and remains stable under noisy environment feedback and off-policy drift. Experimental results show that MintAct achieves state-of-the-art performance (48.9 on OSWorld-Verified) across a wide range of benchmarks at comparable model sizes.

## 2. 方法论：核心思想、关键技术与训练流程

- **统一策略形式**：给定系统提示 \(c\)、指令 \(g\)、历史观察 \(o_{\le t}\) 和历史动作/推理 \(a_{<t}\)，策略 \(\pi_\theta(a_t \mid c,g,o_{\le t},a_{<t})\) 先生成推理，再输出 UI 操作或工具调用。Grounding 是单步特例；导航和视觉工具使用是多步形式。
- **统一设计三原则**：
  - 共享观察与 grounding 空间：所有 UI 域仅用原始截图，动作以归一化到 \(999\times999\) 的像素坐标表示，不依赖 DOM、无障碍树或平台 API；
  - 提示条件化动作集：不把各域动作粗暴合并，而是通过域特定系统提示暴露对应动作/工具；
  - 平衡跨域混合：SFT 和 RL 中显式保持各域训练分布平衡，避免某域主导。
- **环境与数据管线**：
  - 移动端：AndroidWorld 模拟器，RL 时并发 >100 实例；
  - 桌面端：基于 OSWorld 的 Docker 化虚拟桌面，RL 时并发 >200 实例，每实例约 10 CPU 核、40 GB 内存；
  - 网页端：Weblica-Cache 和 Weblica-Synth，本地服务，避免真实网络延迟与不可复现问题；
  - 视觉工具使用：MM-ToolSandBox，支持多轮、多图、动态工具注册和代码执行；
  - 合成环境：通过 coding agent 生成移动/桌面 OS 界面，覆盖约 3,348 个 fork 环境、约 16,300 个任务。
- **训练配方分四阶段**：
  1. **高分辨率单步 SFT**：使用 GroundCUA、Molmo-Point、GUI-Odyssey、AndroidControl 等，建立 grounding 与单步能力，输入图像上限约 2,116,800 像素；
  2. **低分辨率多步 SFT**：使用四个域的多步轨迹（移动约 42.7k、桌面约 23.5k、网页约 51.7k、VTU 约 59.8k），按 25:25:25:25 混合，图像上限约 921,600 像素，轨迹最多 30 轮，VTU 最多 100 轮；
  3. **RFT + 拒绝采样**：先为每域训练 RL 专家，再用专家生成成功轨迹，经 VLM judge 过滤后蒸馏回单一模型；
  4. **联合 agentic RL**：在移动和桌面上联合异步 RL，直接与环境交互，按任务结果优化。
- **异步 RL 框架**：
  - 组件包括 Rollouter、Environment Manager、Trainer、Message Queue、Parameter Synchronizer；
  - Rollouter 通过 SGLang 多推理 worker 并发生成轨迹组；Environment Manager 维护异构环境池并独占分配；Trainer 用 Megatron 训练；消息队列 FIFO 缓冲，限制样本陈旧度；参数同步每 \(K\) 步推送权重。
  - 使用 GRPO 式组相对优势，不做标准差归一化；动态组过滤剔除全成功/全失败组；
  - 稳定性机制：
    - 对负优势分支做 dual-clip，防止离策略更新发散；
    - 用截断重要性采样（TIS）校正训练引擎与推理引擎数值差异；
    - 屏蔽环境失败导致的假负奖励；
    - 联合 RL 中通过 per-domain quota、quota-normalized backpressure、fallback 控制跨域训练分布，防止快域主导。
