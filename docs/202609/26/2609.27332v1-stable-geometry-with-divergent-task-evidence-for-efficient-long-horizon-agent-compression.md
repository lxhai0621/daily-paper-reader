## 摘要
长时程智能体会积累不断增长的交互历史，从而增加上下文和推理成本。我们发现，仅凭几何冗余不足以作为安全压缩的准则。尽管智能体历史呈现出很强的低维结构，相似的全局几何仍可能保留数量差异极大的任务证据。在保留块数量相同的情况下，证据感知选择将下一动作 Top-3 保留率从 0.31 提升至 0.69，而质心相似度仍为 0.98。受控替换进一步表明，动作相关信息可以被大幅改变，而全局几何度量几乎保持不变。受几何与证据之间这一差距的启发，我们提出了几何引导的证据保留记忆（GEM），这是一种免训练压缩器，会优先保护任务与执行证据，再利用几何残差完成覆盖。GEM 将每任务平均总 token 使用量从 2.69M 降至 2.11M，降低了 21.4%，同时保持相当的任务奖励。我们的结果表明，高效的智能体历史压缩应优化保留下来的任务证据，而非仅优化几何覆盖。

## Abstract
Long horizon agents accumulate growing interaction histories that increase context and inference costs. We find that geometric redundancy alone is an insufficient criterion for safe compression. Although agent histories exhibit strong low dimensional structure, similar global geometry can preserve very different amounts of task evidence. At identical retained block counts, evidence aware selection raises next action Top 3 retention from 0.31 to 0.69, while centroid similarity remains 0.98. Controlled replacement further shows that action related information can be substantially altered while global geometric measures remain nearly unchanged. Motivated by this gap between geometry and evidence, we introduce Geometry Guided Evidence Preserving Memory (GEM), a training free compressor that protects task and execution evidence before using geometric residuals to complete coverage. GEM reduces mean combined token usage from 2.69M to 2.11M per task, a 21.4% reduction, while maintaining comparable task reward. Our results show that efficient agent history compression should optimize for preserved task evidence rather than geometric coverage alone.

# 论文总结：Stable Geometry with Divergent Task Evidence for Efficient Long-Horizon Agent Compression

## 1. 核心问题与研究动机

- **背景**：长时程（long-horizon）语言模型智能体在执行任务时会持续累积任务指令、计划、工具调用、环境观测、报错信息与中间产物，历史轨迹不断增长，反复前向完整交互历史会显著推高上下文长度与推理成本。
- **现有做法的隐含假设**：已有系统通过摘要、编辑、检索或选择性保留来压缩历史。许多方法（如基于几何覆盖的贪心选择）默认"表示空间冗余 ⇒ 可安全删除"。
- **论文的核心质疑**：作者发现智能体历史表示确实呈现强低维结构（各向异性、能量集中于少数主方向），但**几何冗余并不等于执行冗余**。相似的全局几何可能保留差异极大的任务证据。
- **关键反例直觉**：修改文件的计划、执行修改的命令、之后的局部读取，三者在语义方向上可能高度接近，但它们确立的任务状态事实完全不同——某个块可能几乎不贡献新的几何变化，却承载着下一步动作所必需的信息。作者将此称为**"几何与证据之间的鸿沟"（gap between geometry and evidence）**。
- **整体含义**：高效的智能体历史压缩应以"保留任务证据"为优化目标，而非单纯追求几何覆盖；几何只应用于在证据被保护之后补全剩余覆盖。

## 2. 方法论：GEM（Geometry-Guided Evidence-Preserving Memory）

### 2.1 核心思想
- 免训练（training-free）的外部压缩器，作用于**完整交互块**（一个 assistant 工具调用消息 + 其全部对应 tool 结果，按 call ID 匹配，同增同删）。
- **两阶段选择**：先保护任务与执行证据（protected set），再用几何残差补全覆盖；两阶段不是独立选择器，保护集是几何补全的种子。
- 保留块保持原始消息内容与时间顺序，不生成摘要、不改动 acting model、不使用其隐状态。

### 2.2 几何分析工具（第 3 节）
- 冻结编码器将每个块映射为单位向量 $x_i \in \mathbb{R}^d$，对中心化矩阵做 SVD：$X_c = X - \mathbf{1}\bar{x}^\top = U\Sigma V^\top$。
- 用两个谱统计量刻画集中度：有效秩 $r_{\text{eff}} = \exp(-\sum_j p_j \log p_j)$（$p_j = \sigma_j^2/\sum_k \sigma_k^2$）与 $r_\rho$（解释 $\rho=0.90$ 中心化能量所需的方向数）。
- 覆盖度度量：质心相似度 $C(S)$、捕获能量 $E(S)$（平均投影到保留张成空间）。
- 证据度量：动作方向投影 $P_a(S)$、相对保留率 $R_a(S)$、下一动作 Top-3 保留率 $T_3(S;a)$。
- 低能量子空间份额 $m_{\text{low}}(a)$：动作投影中落在 90% 能量截断之后方向上的比例。

### 2.3 证据保护集
- 去重并集 $P_t = P^{\text{recent}}_t \cup P^{\text{goal}}_t \cup P^{\text{state}}_t \cup P^{\text{error}}_t \cup P^{\text{source}}_t$。
- 具体规则：近期上下文保留 4 个完整块；目标证据保留与当前任务最相似的 1 个块；状态证据最多 3 条（通过状态查询、文件路径、显式编辑调用及 Bash/Python 写入模式识别）；错误证据在 8 块年龄窗口内最多 2 条；当"源类"观测占比 ≥ 50% 时激活源保护，保留来自不同源的近期记录。
- 作者明确：检测到写入只是"可能的状态变更"，不代表写入成功；错误记录过期也不代表错误已解决——这些是廉价的保护线索，而非完整的环境符号模型。

### 2.4 几何残差补全与在线转发
- 理想核心选择问题：$B^\star_t = \arg\min_{B} |B|$ s.t. $P_t \subseteq B$，$E(B) \ge \tau$，$|B| \le K_t$，其中 $K_t = \max\{K, |P_t|\}$（证据数超过名义容量时容量自动扩张）。
- 用贪心替代精确求解：从 $B = P_t$ 出发，构造正交基 $Q_B$（modified Gram-Schmidt），每次选残差最大的候选：
  $r_i(B) = 1 - \|Q_B^\top x_i\|_2^2$，$i^\star = \arg\max_{i \notin B} r_i(B)$，直至满足覆盖、容量或候选耗尽。
- **保护块不会因残差小而被删除**；残差衡量的是"未被当前几何张成覆盖的信息"，而非任务相关性。
- 默认设置：覆盖目标 $\tau = 0.90$，名义核心容量 $K = 16$。
- 在线转发约束：$B_t \subseteq S_t \subseteq [n]$，$L(S_t) \ge (1-\delta)L([n])$，$\delta = 0.05$（单次请求最多削减 5% 字符数）；完整块不可分割，故一次事件可能什么都没删。
- 触发时机：首次可压缩请求、会话/目标变化后、或新增 256 个块后；块数少于 16 的请求保持不变；两次全局重选之间保留已转发集合并追加新块与新激活证据。
- 附录给出理论性质：残差即重建误差，$E(B) \ge \tau$ 意味着平均平方重建误差 ≤ $1-\tau$；每次加入新方向覆盖单调不减；转发不变量 $P_t \subseteq B_t \subseteq S_t$，保留消息保持调用-结果结构与时间序。

## 6. 主要结论与发现

- **几何与证据的分离**：相同保留块数下，证据感知选择把下一动作 Top-3 保留率从 **0.31 提升到 0.69**，而质心相似度仍为 **0.98**；动作投影 0.91→0.94，最终状态投影 0.90→0.94，目标投影 0.91→0.94。
- **受控替换**：定向删除低能量但高动作对齐的块，使动作投影 −0.03、Top-3 保留 −0.33，而质心相似度与捕获能量变化均为 +0.00——直接证明全局几何度量对动作相关信息的丢失几乎不敏感。
- **历史确实存在结构化冗余**：真实历史的中心化有效秩中位数在孤立块空间为 8.39（feature-shift 16.99、Gaussian 19.96），选择器空间为 14.04（23.54、30.07）；但低有效维数**只说明集中，不说明可安全删除**。
- **端到端效果**：Full260 上平均 combined token 从 2.69M 降至 2.11M（**降低约 21.4%**），平均 Score 从 69.87 变为 70.18。Security 降幅最大（5.98M→3.95M，奖励 0.48→0.50）；Office 奖励上升且 token 减少；Web 奖励持平、token 减少；**Code 是边界情形**（1.37M→1.35M，奖励下降约 0.02）。
- **消融**：20 任务批次上 GEM 得分 60.39 vs Base 60.75（差 0.36 分），combined token 减少约 35.30%，为全批次最高奖励与最低 token；Random completion 53.06、Geometry only 55.03，均明显更差。
- **扫描规律**：在全部 K ∈ [8,20] 上证据约束选择都优于 geometry-only；τ 从 0.85 升到 0.95 时，保留比例 0.38→0.53、Top-3 保留 0.58→0.65，说明 τ=0.90 只是一个观测到的权衡工作点，而非普适最优阈值。
- **成本来源**：净节省主要来自 cached input 下降（2.60M→1.82M），但 GEM 引入了 embedding 开销（46.97K）并提高了 uncached input（48.70K→201.48K），因此节省并非免费。

## 7. 优点

- **问题识别精准且有实证支撑**：把"几何覆盖"与"执行证据"明确区分，并用同预算比较 + 受控替换两种独立证据形式加以验证，而非仅停留在直觉论述。
- **方法简洁、免训练、即插即用**：不修改 acting model、不生成摘要、不需要隐状态或参数更新，保留原始消息与调用-结果结构、保持时间序，工程落地成本低。
