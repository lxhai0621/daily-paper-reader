## 摘要
强化学习已在可验证领域显著提升大语言模型（LLM）智能体，但仍难以应用于开放式智能体任务，因为此类任务的解决方案多样，且难以获得可靠的标量奖励。近期的成对评估方法通过以相对偏好替代逐点评分，缓解了奖励判别崩溃。然而，它们仍将丰富的比较反馈压缩为单一的轨迹级奖励，掩盖了决定性的中间步骤，并阻碍了成功行为被固化为可复用技能。我们提出 ArenaFlow，一种面向开放式智能体强化学习的分层信用传播框架。ArenaFlow 利用基于锦标赛的相对排序来推导轨迹级奖励信号。每次比较还配备了结构化反思评估，从而揭示三类监督信息：关键成功步骤、可复用策略技能，以及所检索技能的使用归因。在步骤层面，ArenaFlow 根据锦标赛存活深度，将轨迹级优势传播到高置信度的关键步骤，从而能够更有针对性地优化局部推理行为。在技能层面，ArenaFlow 根据组级使用归因估计技能效用，并通过效用感知的更新、剪枝和检索来维护全局技能记忆。由此得到的高效用技能进一步作为未来探索的策略先验。大量实验验证了 ArenaFlow 在开放式智能体任务上的有效性。

## Abstract
Reinforcement learning has substantially improved large language model (LLM) agents in verifiable domains, but remains difficult to apply to open-ended agent tasks, where solutions are diverse and reliable scalar rewards are hard to obtain. Recent pairwise evaluation methods alleviate reward discrimination collapse by replacing pointwise scoring with relative preferences. However, they still compress rich comparative feedback into a single trajectory-level reward, obscuring decisive intermediate steps and preventing successful behaviors from being consolidated into reusable skills. We propose ArenaFlow, a hierarchical credit propagation framework for open-ended agent reinforcement learning. ArenaFlow leverages tournament-based relative ranking to derive trajectory-level reward signals. Each comparison is further equipped with structured reflective evaluation, which reveals three types of supervision: pivotal success steps, reusable strategy skills, and usage attribution of retrieved skills. At the step level, ArenaFlow propagates trajectory-level advantages to high-confidence pivotal steps according to tournament survival depth, enabling more targeted optimization of local reasoning behaviors. At the skill level, ArenaFlow estimates skill utility from group-level usage attribution and maintains a global skill memory through utility-aware updating, pruning, and retrieval. The resulting high-utility skills further serve as policy priors for future exploration. Extensive experiments validate ArenaFlow's effectiveness on open-ended agent tasks.

## 1. 核心问题与整体含义

- **研究动机**：强化学习（RL）已在数学推理、代码生成等**可验证领域**显著提升 LLM 智能体能力，因为此类任务可通过规则获得可靠标量奖励。但**开放式智能体任务**（如深度研究报告生成、个性化旅行规划）解空间庞大、评价标准主观多元，难以设计可靠奖励信号，RL 应用受限。
- **现有方法的缺陷**：
  - **逐点奖励建模**（pointwise scoring）：由 LLM-as-a-Judge 为每条轨迹打绝对分数，易出现**奖励判别崩溃**——高质量候选轨迹分数集中在狭窄区间，优化信号被评判模型的固有噪声主导。
  - **成对偏好评估**（pairwise evaluation）：以相对偏好替代绝对评分，缓解了上述问题，但仍将丰富比较反馈**压缩为单一轨迹级奖励**，导致两个后果：① 轨迹级优势被均匀施加到全部推理步骤，决定性局部行为被琐碎步骤稀释；② 比较评估中暴露的成功推理模式在给出偏好决策后被丢弃，未能固化为可复用经验。
- **整体含义**：论文将开放式智能体优化重新表述为**分层信用传播问题**，主张比较反馈不应止于轨迹级偏好，而应向下传播到关键推理步骤（用于针对性策略优化），并跨轨迹积累为可复用技能（用于长期探索引导）。这是阿里 Token Hub 团队提出的技术报告。

## 2. 方法论

### 2.1 核心思想
ArenaFlow 在锦标赛式相对排序范式基础上，为每次成对比较配备**结构化反思评估**，从评判模型中挖掘三类监督信号：**关键成功步骤**、**可复用策略技能**、**检索技能的使用归因**；随后在步骤级与技能级两个层面传播信用信号，并维护全局技能记忆。

### 2.2 锦标赛式相对排序（轨迹级信号）
- 给定查询 $x$，策略模型生成轨迹组 $\mathcal{G}=\{\tau_1,\dots,\tau_N\}$（$N=16$）。
- 采用**种子单败淘汰锦标赛**：先以贪心解码轨迹作为锚点建立初始排序先验，再通过二叉锦标赛结构两两比较。
- 每条轨迹获得组内排名 $\text{Rank}(\tau_i)\in\{0,\dots,N-1\}$（0 为最优），转换为分位数式奖励：$r_i = 1 - \frac{\text{Rank}(\tau_i)}{N-1}$。
- 组内归一化得到轨迹级优势：$A_i = \frac{r_i-\mu_r}{\sigma_r+\epsilon}$。

### 2.3 结构化反思评估
评判模型 $J$ 对每对轨迹除输出胜负外，还输出：
- **关键成功步骤**：获胜轨迹中实质性促成胜利的中间推理/动作步骤。
- **可复用技能**：从轨迹中抽象出的自然语言技能模式，含名称、描述、核心原理、实施指南、失败规避约束。
- **技能归因**：若 rollout 中注入了检索技能，判断其是否在关键成功步骤中被实质使用。

### 2.4 步骤级信用传播
- 以**锦标赛存活深度**作为关键步骤置信度：在更深轮次（击败更强对手）中识别的关键步骤更可靠。
- 深度权重：$\omega_m = \frac{\exp(\eta\cdot m/D)}{\sum_{j=1}^{D}\exp(\eta\cdot j/D)}$，$\eta$ 控制锐度。
- 步骤原始信用分：$q_i^k = \sum_{m\in R_i}\omega_m\cdot\mathbb{I}(k\in P_i^m)$。
- 轨迹内归一化：$g_i^k = \frac{q_i^k}{\max_j q_i^j+\epsilon}$。
- 最终步骤优势：$A_i^k = A_i + \max(A_i,0)\cdot g_i^k$——保留全局偏好方向，仅对正优势轨迹中的关键步骤选择性放大。

### 2.5 技能级信用传播
- **技能抽象与记忆更新**：收集最终冠军轨迹涉及的技能，由 LLM 汇总整合为高层**元技能**，插入全局技能记忆 $\mathcal{B}$；若语义等价但更具泛化性/细粒度，则进行版本感知替换。
- **组级使用归因**：同一组轨迹共享相同检索技能，故检索不等于有用。仅当评判模型明确将技能归因到关键成功步骤时才赋予效用：
  $C_x^s = \sum_{\tau_i\in\mathcal{G}}\sum_{m\in R_i}\omega_m\cdot\mathbb{I}(s\in Q_i^m)$。
- 归一化：$z_x^s = \frac{C_x^s-\mu_x^C}{\max_{s'}C_x^{s'}-\mu_x^C+\epsilon}$。
- **效用估计与剪枝**：在线均值更新 $U_s \leftarrow \frac{n_s U_s+z_x^s}{n_s+1}$；活跃检索池 $\mathcal{B}_{\text{active}}=\{s\in\mathcal{B}\mid n_s<K \lor U_s\ge 0\}$，即仅当已评估至少 $K$ 次且效用仍为负时才剪枝（热身机制防止过早丢弃新技能）。

### 2.6 效用感知技能检索与策略优化
- **两阶段检索**：先按余弦相似度语义召回 top-$2k$ 候选，再用 $\phi_{\text{ret}}(x,s)=\text{Sim}(x,s)+\lambda\cdot U_s$ 重排，取 top-$k$（$k=3$）注入系统提示。
- **策略优化目标**：采用类似 GRPO 的裁剪目标，但使用步骤级优势 $A_i^k$：
  $\max_{\pi_\theta}\mathbb{E}_{x,\mathcal{G}}\left[\sum_{\tau_i}\sum_{k=1}^{L_i}\min\left(\rho_i^k A_i^k,\ \text{clip}(\rho_i^k,1-\epsilon,1+\epsilon)A_i^k\right)\right]$。

## 3. 实验设计

- **数据集 / Benchmark**：
  - **Open-Travel**：个性化行程规划，含 5 个子任务（多路点路线 Direction、单日行程 1-Day、交通比选 Compare、POI 搜索 Search、多日行程 M-Day），提供 6 类旅行工具。
  - **Open-DeepResearch**：多轮网络搜索与信息综合，含技术文档撰写、研究计划制定、复杂概念通俗解释三类场景。
  - **DeepResearch Bench**（迁移评估）：100 个博士级研究任务，覆盖 22 个领域，采用官方 RACE 指标（Comprehensiveness / Insight-Depth / Instruction-Following / Readability）。
  - **评测协议**：Open-Travel 与 Open-DeepResearch 使用 Qwen3-Max + Claude-4-Sonnet 双评判的 LLM-as-a-Judge，对推理轨迹与最终答案按任务专属评分标准成对比较，取双评判均分。
- **对比方法**（三大类）：
  - **强闭源模型**：GPT-5.2、Grok-4、Gemini-2.5-Pro、Claude-4.5-Sonnet。
  - **代表性 RL 算法**：逐点奖励类（GRPO、GSPO、Reinforce++）、成对偏好类（Writing-Zero、Pref-GRPO、ArenaRL）；后两者含冷启动+RL 流程，ArenaRL 为直接 RL。
  - **专有深度搜索系统**：Grok Deeper Search、Perplexity Deep Research（仅 DeepResearch Bench）。
- **主干与评判**：所有可训练基线统一使用 Qwen3-8B 主干与相同评判模型；ArenaFlow 使用 Qwen3-Max 作结构化反思评判。

## 6. 主要结论与发现

- **性能领先**：Open-Travel 平均分 55.4（ArenaRL 35.9、Pref-GRPO 32.2、Claude-4.5-Sonnet 35.5）；Open-DeepResearch 平均分 69.1（ArenaRL 54.7、Pref-GRPO 47.3）；DeepResearch Bench 总体 43.2（ArenaRL 37.6、Pref-GRPO 34.1），接近 Grok Deeper Search（40.2）与 Perplexity Deep Research（42.3）。
- **无需冷启动**：相较冷启动+RL 方法（Pref-GRPO）在 Open-Travel 提升 23.2 分、Open-DeepResearch 提升 21.8 分。
- **可迁移性**：在 Open-DeepResearch 上训练的模型可迁移至 DeepResearch Bench，说明学到的是可复用研究策略而非基准特定行为。
- **消融结论**：移除技能记忆退化最大（55.4→41.2），其次为步骤级信用（→48.6）与技能级信用（→50.7），深度权重移除也造成下降（→51.1），表明步骤级与技能级信用存在协同效应。
- **鲁棒性**：更强评判模型带来更好性能，且性能不绑定特定评判族。
- **超参规律**：检索技能数 $k=3$ 最优（过少指导不足、过多引入冗余干扰）；效用权重 $\lambda=0.2$ 最优；剪枝使技能记忆从近线性增长的 800 个压缩至约 248 个。
- **训练效率**：ArenaFlow 20 步内达 28.9，ArenaRL 仅 14.3；最终收敛值约 55.4 vs 35.9。

## 7. 优点

- **问题切入精准**：将"比较反馈被压缩为单一轨迹奖励"这一痛点形式化为分层信用传播问题，视角清晰且动机图（Fig.1）对比直观。
- **方法设计巧妙**：
  - 用**锦标赛存活深度**作为关键步骤置信度，天然利用了淘汰赛结构的强度信息，且不破坏轨迹级偏好优化的稳定性（仅对正优势轨迹放大）。
  - 技能效用估计建立在**使用归因**而非检索频次上，避免"被检索即被记为有用"的偏差。
  - 带热身机制的剪枝（$n_s<K \lor U_s\ge 0$）防止新技能被过早淘汰，工程上稳健。
- **技能记忆闭环完整**：抽象→更新（含版本演进）→归因→效用累积→剪枝→效用感知检索，形成自我演化循环。
- **实验较为扎实**：多基准、多基线、多消融、跨评判鲁棒性、超参敏感性、人工标注可靠性验证、计算成本分析均有覆盖，且给出可复用技能与完整 case 轨迹的可视化示例。
- **效率优势明显**：相比 Pref-GRPO 大幅减少 LLM 调用与 token 消耗，性能反而更高。
