## 摘要
个性化智能体需要基于长期历史交互进行推理，以推断显式偏好和隐式行为证据。早期的扁平检索方法独立地对记忆片段打分，忽略了分布式信息，而当前的结构化记忆框架依赖与查询无关的静态图，无法捕捉依赖上下文的关系。关键的是，原始文本记忆本质上相互纠缠且含有噪声，使得细粒度个性化和跨会话推理在计算上代价高昂。为此，我们提出 LGM，一种新颖的神经符号框架，将长期记忆解耦转移到连续潜在空间。具体而言，(i) 我们不再持久化固定图，而是借助稀疏自编码器设计了一种定制化的潜在图构建方法。针对每个查询，它将历史交互映射为潜在记忆节点，并将记忆痕迹解耦为稀疏概念激活，动态合成查询感知的关系边权重。(ii) 随后，图编码器将查询嵌入视为条件偏好，以指导在任务特定的潜在子图上进行非线性消息传递。这产生了高度表达性的记忆表示，以实现有效激活。在长期个性化基准上的大量实验表明，LGM 在捕捉显式和隐式偏好方面显著优于最先进的基线，同时能够实现个性化响应。

## Abstract
Personalized agents are required to reason over long-term history interactions to infer both explicit preferences and implicit behavioral evidence. While early flat retrieval methods score memory fragments independently and neglect the distributed information, current structured memory frameworks rely on query-agnostic static graphs that fail to capture the context-dependent relations. Crucially, raw textual memories are inherently entangled and noisy, making fine-grained personalization and cross-session reasoning computationally prohibitive. To this end, we present LGM, a novel neuro-symbolic framework that shifts long-term memory disentanglement into a continuous latent space. Specifically, (i) instead of persisting fixed graphs, we design a tailored latent graph construction with a sparse autoencoder. Subject to each query, it maps historical interactions into latent memory nodes and disentangles the memory traces into sparse concept activations, dynamically synthesizing query-aware relational edge weights. (ii) A graph encoder then treats the query embedding as a conditioning preference to direct non-linear message passing across the task-specific latent subgraph. This yields a highly expressive memory representation for effective activations. Extensive experiments on long-term personalization benchmarks demonstrate that LGM significantly outperforms state-of-the-art baselines in capturing both explicit and implicit preferences while enabling personalized responses.

- **现有方法的两大范式及其缺陷**：
  - **扁平检索（Flat Retrieval）**：将历史轮次或摘要片段独立嵌入、按向量相似度检索。问题在于**独立打分**，无法捕捉分布在远距离会话中的多跳证据。
  - **结构化记忆框架（如 GraphRAG）**：用图结构建模关系依赖，但依赖**查询无关的静态图**，邻接结构在任务到来前即固定，无法推断仅在特定查询触发下才浮现的动态、上下文相关关系。
- **核心痛点**：原始文本记忆本质上**纠缠且嘈杂**——单次交互同时编码主题、意图、情感与上下文，而仅有一小部分与当前请求相关。在 token/prompt 空间做细粒度偏好解耦和跨会话推理计算代价高昂（KV 缓存膨胀、重复 LLM 调用、无关文本干扰）。
- **核心研究问题**：能否在不反复回放完整文本历史的前提下，按需解耦并组织用户长期记忆？
- **三个根本张力**：
  1. 原始文本与隐状态将显式偏好与细微习惯纠缠，难以在不丢失长尾证据的情况下解耦；
  2. 历史事件与查询的相关性随查询变化，刚性文本图重建太慢，拓扑需在潜在空间动态自适应；
  3. 潜在空间推理虽避免上下文窗口饱和，但多步传播存在信息坍缩风险——状态需紧凑以支持快速生成，同时严格忠实于历史证据。

## 2. 方法论

### 2.1 核心思想

- 提出 **LGM（Latent Graph Memory）**，一个**神经符号框架**，将长期记忆的解耦与关系推理转移到**连续潜在空间**，实现端到端可微优化。
- 记忆生命周期（选择 → 关联 → 聚合 → 利用）统一为可微过程，而非外部的离散读/写控制。

### 2.2 三大模块与关键技术细节

**(i) 潜在记忆解耦（Latent Memory Disentanglement）**

- 将每个历史交互与当前查询 x ∈ H ∪ {q} 通过骨干语言模型 fθ 编码为潜在节点 zx。
- **多层聚合**：读取 4 个均匀分布的中间层 {8, 16, 24, 32} 的隐状态并求平均（低层携带词汇线索，高层携带语义与行为抽象，隐式偏好存在于混合中）。
- **掩码池化（Masked Pooling）**：沿序列维度压缩，再经投影映射到共享潜在空间（d = 32）。
- **稀疏自编码器（SAE）**：将稠密 zx 解耦为稀疏、非负的概念编码 cx：
  - cx = S(ReLU(Wenc zx))，ẑx = Wdec cx
  - 其中 S(·) 抑制弱激活，ẑx 为重构。
  - SAE 损失：Lsae = ‖ẑx − zx‖²₂ + λΩ(cx)
  - 该步骤将“记忆是关于什么”与“如何表述”分离，使直接指令与微弱习惯可在共享概念空间中匹配，即使表面文本无关。

**(ii) 查询条件潜在图构建（Query-Conditioned Latent Graph Construction）**

- 构建图 G(q) = (V, E, ω)，节点集 V = {zq} ∪ {zi} 包含查询与所有记忆。
- **边权由查询决定**：ωq→i = φ(cq, ci) ∈ [0, 1]，即查询与记忆的归一化概念重叠度。
- 由于 cq 随查询变化，同一记忆池在不同查询下形成不同拓扑；添加自环与双向 query↔memory 类型关系 rij。
- **关系图网络（RGN）**：从 z(0)i = zi 开始，执行 T = 4 步消息传递：
  - m(t)i = Σ_{j∈N(i)} ωj→i ψ(z(t)i, z(t)j, rij)
  - z(t+1)i = Upd(z(t)i, m(t)i)
- **置换不变读出**：g = Readout({z(T)i})，得到紧凑记忆状态；评分头产生节点级相关性 si = ⟨z(T)i, g⟩。
- 该传播将多个单独弱线索沿查询激活边组合成一个推断出的隐式偏好。

**(iii) 图条件推理（Graph-Conditioned Reasoning）**

- 投影器将 g 映射为少量软潜在前缀 token P̃ = {P̃k}pk=1 ∈ R^{p×dlm}，每个被重新缩放到普通 token 嵌入的范数，使前缀“告知”而非“支配”注意力。
- 前缀被前置到查询嵌入 E(q)，自回归生成响应：y ∼ fθ([P̃; E(q)])。
- **生成监督**：监督生成参考响应文本 y⋆（而非离散选项分类）：
  - Lgen = −Σt log fθ(y⋆t | y⋆<t, [P̃; E(q)])
- **证据重构（Evidence Reconstruction）**：防止潜在记忆坍缩为无信息信号的关键机制。复用 fθ 作为解码器，要求同一前缀在固定解码指令 ρ 下重构支撑证据文本 e⋆：
  - Lrecon = −Σt log fθ(e⋆t | e⋆<t, [P̃; E(ρ)])
- **总体目标**：L = Lgen + Lrecon + Lsae，端到端训练。

### 2.3 算法流程（Algorithm 1）

1. **阶段 1**：对 H ∪ {q} 中每项编码为潜在节点 zx，经 SAE 解耦为稀疏概念 cx；
2. **阶段 2**：按概念重叠度计算边权 wi，连接 query↔memory，执行 T 步消息传递，读出紧凑状态 g；
3. **阶段 3**：将 g 投影为潜在前缀 token，前置到查询后由 LLM 生成答案。
