## 摘要
长期记忆对于大型语言模型（LLM）智能体在长程交互中保持一致性和个性化至关重要。现有记忆系统通常依赖固定粒度或静态模式，但当偏好、事件、约束和时间更新等异构信息嵌入单一混合表示时，这些设计往往难以应对。由此产生的语义干扰使 top-K 检索对噪声敏感，并且常导致相关证据排名靠后。我们提出 AutoViewMem，一个数据驱动框架，在索引之前将长期对话记忆组织为自配置、低重叠的语义视图。AutoViewMem 从交互轨迹中发现候选视图，选择一个紧凑的互补视图集，并利用这些视图指导写入时对具有来源依据的记忆进行结构化抽取。这种表示优先的设计将语义解耦从检索时转移到写入时，使标准 top-K 相似度搜索无需显式路由或迭代检索即可检索到聚焦的证据。我们进一步应用离线整合来提高记忆的紧凑性和一致性。在 LoCoMo 和 PersonaMem 基准上，基于 Qwen3-8B 和 Qwen3-14B 两种骨干模型的实验表明，AutoViewMem 在保持简单推理流程的同时，相较于强记忆基线提升了长时程问答和个性化能力。

## Abstract
Long-term memory is essential for large language model (LLM) agents to maintain consistency and personalization over extended interactions. Existing memory systems typically rely on fixed granularities or static schemas, but these designs struggle when heterogeneous information, such as preferences, events, constraints, and temporal updates, is embedded in a single mixed representation. The resulting semantic interference makes top-K retrieval sensitive to noise and often leaves relevant evidence poorly ranked. We present AutoViewMem, a data-driven framework that organizes long-term conversational memory into self-configuring, low-overlap semantic views before indexing. AutoViewMem discovers candidate views from interaction traces, selects a compact complementary view set, and uses these views to guide write-time structured extraction of provenance-grounded memories. This representation-first design moves semantic disentanglement from retrieval time to write time, allowing standard top-K similarity search to retrieve focused evidence without explicit routing or iterative retrieval. We further apply offline consolidation to improve memory compactness and consistency. Experiments on the LoCoMo and PersonaMem benchmarks, under both Qwen3-8B and Qwen3-14B backbones, show that AutoViewMem improves long-horizon question answering and personalization over strong memory baselines while preserving a simple inference pipeline.

## 1. 核心问题与研究动机

- **背景**：LLM 驱动的对话智能体在长期陪伴、个性化助手、企业支持等场景中，交互跨度可达数周甚至数月，远超有限上下文窗口。即便使用长上下文模型，直接塞入完整历史也因话题漂移、用户状态演变、显著事实的长尾分布而低效——大量低相关上下文增加成本与噪声，关键细节被淹没在远端 token 中。
- **现有方案与瓶颈**：主流系统采用"写入—检索—生成"的非参数化外部记忆。设计焦点常被归结为**记忆粒度**问题：细粒度单元碎片化证据、损害召回；粗粒度单元注入无关内容。由此产生 MemGAS（多粒度）、SeCom（分割压缩）等工作。
- **核心洞察**：粒度并不能完全解释检索失败。长对话本质上是**异构**的——偏好、计划、事实、事件、时间更新常共存于同一对话片段。当这些混合内容被嵌入到单一表示空间时，语义无关信息在相似度搜索中相互干扰，形成盲区与"覆盖—噪声"权衡。
- **真正的问题**：这是一个**先于检索的表征问题**——在索引之前，记忆应如何组织，才能让异构语义在多样化未来查询下仍可被访问？
- **整体含义**：论文提出"表示优先（representation-first）"的视角，主张将语义解耦从**检索时**前移到**写入时**，用标准 top-K 检索即可获得聚焦证据，无需显式路由或迭代检索。

## 2. 方法论

### 2.1 核心思想

- **视图（View）定义**：视图是一个轻量级 schema，包含名称、槽位集合与抽取模板，用于指导 LLM 从对话中填充字段。
- **视图与粒度正交**：粒度控制记忆单元大小；视图定义对同一证据的语义投影。论文中的"正交"是**实用主义**的——指语义相似度下互补、低重叠，而非线性代数意义上的严格正交。
- **核心设计选择**：在记忆进入向量索引之前降低语义纠缠。一旦记忆在互补视图下写入，简单的全局 top-K 搜索即可构建聚焦上下文。
- **整体架构**：两阶段——(i) 在线视图归纳与写入管线；(ii) 离线整合。查询时接口保持常规：检索器在单一索引上搜索。

### 2.2 在线自适应记忆学习（发散—收敛策略）

**阶段一：视图发现（View Discovery）**

- 对话以有序 chunk 序列到达，系统先累积弱信号（重复实体、稳定偏好、反复出现的约束）。
- 每隔 N = 50 个 chunk，LLM 从近期交互轨迹提出 **10 个候选视图**，每个候选包含名称、槽位、抽取模板，可直接作为写入时抽取指令。

**阶段二：视图收敛（View Convergence）**

- 候选集噪声大且冗余：先对指令字符串做精确去重，再用与记忆索引相同的稠密编码器对候选编码。
- 使用**行列式点过程（DPP）**选择紧凑、多样的活跃视图集 V*_u（K = 10）。对 ℓ2 归一化嵌入 z_i，L-ensemble 核为 L_ij = q_i (z_i^T z_j) q_j，质量 q_i 均匀，偏好 det(L_S) 大的子集，从而抑制诱导相似抽取行为的视图（非 DPP 消融使用均匀随机选择）。
- 每个选中的种子用其 **top-30 最近邻**扩展，并由 LLM 汇总为规范化抽取指令。
- **视图归一化**：指令级去重，语义相似候选重写为一条简洁抽取指令；每条抽取项存储视图标签、时间戳、出处。视图不强制互斥，重叠投影由出处身份去重处理。

**阶段三：自适应抽取（Adaptive Extraction）**

- 对每个对话 chunk x，LLM 在 V*_u 的每个活跃视图下评估，仅当证据与该视图相关时返回结构化事实——允许同一证据被投影到多个互补视图。
- 查询时对所有记忆项在**单一统一索引**上做标准 top-K 稠密检索，按 token 预算合并并轻量去重后传给 LLM。
- **关键评测细节**：当多个检索项共享同一底层证据时，仅首次出现计入检索指标，防止多视图投影人为抬高覆盖率。

### 2.3 离线记忆整合

- **定位**：与在线写入刻意分离，异步运行，不改变查询时检索接口。
- **精确去重**：对规范化文本/结构化表示做哈希，保留一条记录并合并元数据（视图标签、出现次数、出处）。
- **相似图聚类**：构建无向相似图 G = (V, E)，当 cos(e_i, e_j) ≥ 0.9 时连边；连通分量定义候选整合批次，过大分量按递增阈值（0.90 → 0.999）递归切分。
- **LLM 裁决**：相似度只提出候选，绝不强制合并。对每个簇由 LLM 按三种情况重写为规范记录：
  - **包含（Containment）**：一项被另一项涵盖；
  - **互补（Complementarity）**：不重叠事实合并；
  - **相似但独立（Independence）**：相似但表达不同事实的项保持分离。
- 冲突主张、不同时间版本、不同具体细节保持独立；规范记录保留合并出处，支持审计与回滚。

## 6. 主要结论与发现

- **LoCoMo**：AutoViewMem 在两种骨干下均取得最佳整体 Judge，以及最强的整体 F1 与 BLEU-1；在 Qwen3-8B 下 Judge 超过 Full History，在 Qwen3-14B 下仅略逊于 Full History。词法增益在 **Temporal 与 Single-Hop** 问题上最显著，说明视图化记忆产生更接地气的回答。
- **PersonaMem-32k**：两种骨干下均取得最佳整体准确率；Qwen3-14B 下比最强基线高 5 分以上、比 Full History 高近 14 分（69.10 vs 55.18）。优势集中在需要**综合**而非单纯回忆的能力上——泛化（Gen 84.2）、偏好推荐（P-Rec 74.5）、建议（Sugg 46.2）、原因回忆（R-Rsn 83.8），且随骨干增大而扩大。
- **简单管线即可获益**：由于使用标准 top-K 检索，增益主要来自**记忆如何被写入与整合**，而非更复杂的查询时控制器。
- **消融结论**（固定 K₀ = 30）：
  - 完整模型 Judge 最佳（0.837）、无正例率最低（5.14%）；
  - 去掉多视图组织 → 最弱的 Judge 与 BLEU-1，说明**仅结构化抽取不够**；
  - 去掉整合 → J 降至 0.801、无正例率最差（9.83%），说明**冗余控制在紧预算下很重要**；
  - 去掉 DPP（随机选择）→ 词法指标尚可，但无正例率升至 7.03%，说明 DPP 起**多样性先验**作用，而非唯一增益来源。
- **预算敏感性**：AutoViewMem 与 Mem0 均随 K 增大先升后饱和，但 AutoViewMem 始终更优，尤其在小预算下——聚焦视图使早期检索上下文噪声更小。
- **案例分析**：对同一模糊话语，固定提示只记录表层事实；AutoViewMem 通过用户自适应视图分离出"情境是什么""用户在其中重视什么""为何在情感上重要"三个语义不同方面，且历史推断（如足球）在未被当前话语确认时以**试探性**方式表达。

- **算力与成本披露不足**：未给出 GPU 型号/数量、总推理 token 消耗、离线整合的调用次数与延迟。由于视图归纳（每 50 chunk 一次、10 个候选）与离线整合（逐簇 LLM 裁决）都是 LLM 密集调用，缺少这部分信息使复现与部署成本评估存在困难。
- **超参数缺乏敏感性分析**：活跃视图数 K = 10、发现间隔 N = 50、邻居扩展 top-30、聚类阈值 τ = 0.9（及递归切分 0.90→0.999）等关键超参均取自固定设定，未报告其取值对性能与无正例率的影响，读者难以判断方法对超参的鲁棒性。
- **消融覆盖面有限**：消融仅在 Qwen3-8B 上完成，未验证在 14B 骨干下"多视图组织 > 单纯结构化抽取"的结论是否仍然成立；此外缺少"视图数量少于/多于 10"的对照。
- **统计严谨性欠缺**：未报告多次运行的标准差、置信区间或显著性检验，考虑到 LoCoMo 的 Judge 差异往往只有零点零几，部分结论的稳定性难以确认。
- **对 LLM 裁决质量的依赖**：视图归纳、抽取、整合三个环节均依赖同一 LLM 的判断，论文未分析当 LLM 出现漏抽、幻觉抽取或错误合并时系统的退化行为，也未给出与人工标注的一致性检验。
- **基准覆盖偏窄**：PersonaMem 仅使用 32k 档，LoCoMo 为英语长对话；跨语言、跨领域（如企业工单、医疗随访）以及超长（>10 万轮）场景下的可扩展性未被检验。
- **视图语义的领域相关性**：视图由数据在线发现，论文未讨论当对话主题发生剧烈漂移时，早期归纳的活跃视图集是否需要重建，以及 V*_u 的更新/淘汰机制。
- **证据级去重的双面性**：为防止多视图投影虚增覆盖率而采用的"仅首次出现计入"规则虽然严谨，但也可能低估多视图在 token 预算内的实际贡献，指标与真实使用体验之间可能存在偏差。
- **无正例率与最终质量的因果链未完全打通**：论文观察到"无正例率低 → Judge 高"的相关性，但未进一步分解错误来源（视图缺失、抽取遗漏、还是嵌入本身不可分）。

## 9. 对后续研究的启示

- **表征优先范式的可迁移性**：把"记忆如何被组织"与"如何被检索"分层，并将语义解耦前移到写入阶段，这一思路原则上可迁移到 RAG 文档库、多模态记忆、代码库检索等同样存在异构语义干扰的场景。
- **用 DPP 做 schema/提示选择**：以行列式点过程在嵌入空间挑选互补的抽取模板，是一种低成本、无需训练的"提示集多样性"手段，可复用于工具选择、角色设定、few-shot 示例挑选等任务。
- **评测方法本身即贡献**：证据级去重与 no-positive rate 为多视图/多表示记忆系统提供了更公平的度量方式，后续工作若沿用多投影设计，应将其作为默认评测规范。
- **"简单检索器 + 好表征"的对照价值**：论文以标准 top-K 作为查询接口，说明在多数场景下，提升瓶颈可能不在查询时控制器而在写入时的信息组织，这为"复杂 agentic 检索"路线提供了一个必要的反例基准。
- **异步整合作为长期记忆的默认组件**：将去重、聚类、冲突裁决放入离线路径，可在不牺牲在线延迟的前提下控制记忆膨胀，这一架构约定值得被后续长期记忆系统采纳。

## 10. 总体评价

AutoViewMem 的核心贡献不在于提出新的检索算法，而在于重新定位了长对话记忆的问题边界：检索失败的根因往往是**异构语义在单一表示空间中的相互干扰**，而非记忆单元的大小或检索器的强度。论文以"视图"为中介，把语义解耦前移到写入阶段，用 DPP 保证视图互补、用离线 LLM 裁决控制冗余，并在查询时保持最朴素的 top-K 检索——这一"重写入、轻查询"的设计既提升了可解释性，也降低了工程复杂度。实验上，双基准、双骨干、逐项消融与证据级去重评测共同支撑了其主要主张，尤其在 PersonaMem 的泛化、推荐与建议类能力上优势明显。主要不足集中在超参敏感性、算力成本披露、消融骨干单一与统计显著性检验的缺失，这些属于可补强的工程性缺口，而非对核心论点的实质性反驳。总体而言，这是一篇问题定位清晰、方法自洽、评测规范的长对话记忆系统工作，其"表征优先"视角对后续研究具有较好的参考价值。
