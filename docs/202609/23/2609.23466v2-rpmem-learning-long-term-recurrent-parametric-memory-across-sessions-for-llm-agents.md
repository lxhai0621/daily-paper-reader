## 摘要
长期运行的LLM智能体需要能够在跨会话间持续存在并演化的记忆。基于文本的记忆在每次查询时检索并重构过去的交互，使得随着历史增长，长时程性能越来越依赖检索质量和上下文推理。参数化记忆将经验直接编码到模型计算中，但现有方法对跨会话记忆演化的支持有限。它们与特定骨干模型的耦合进一步限制了模型替换后的记忆复用。我们提出RPMem，一种两阶段架构，它通过前向计算将每个会话编译为与模型无关的潜在记忆，并通过任务训练的循环门控选择性地将其与保留的记忆整合。随后，整合后的记忆被映射为骨干模型特定的低秩适配（LoRA）参数，使得在替换骨干模型时编码能力能够迁移。在三个长期记忆基准和五个不同骨干模型上的评估表明，其具有广泛泛化能力，且更新成本和内存占用近乎恒定。在PERMA上使用Qwen3-8B时，RPMem达到85.52%，分别超过最强的参数化基线和基于文本的基线5.32和12.98个百分点。消融实验验证了会话编译与跨会话整合的互补作用，而动力学分析表明，该门控习得了任务特定的记忆整合策略。这些结果确立了RPMem作为一种生命周期无关的参数化记忆框架，能够维护不断演化的跨会话记忆，并在骨干模型替换后仍可复用。我们的实现可在 https://github.com/Quark-Medical/rpmem/tree/main 获取。

## Abstract
Long-running LLM agents require memory that persists and evolves across sessions. Text-based memory retrieves and reconstructs past interactions at every query, making long-horizon performance increasingly dependent on retrieval quality and contextual reasoning as histories grow. Parametric memory encodes experience directly into model computation, but existing approaches provide limited support for cross-session memory evolution. Their coupling to a specific backbone further restricts memory reuse after model replacement. We introduce RPMem, a two-stage architecture that compiles each session into a model-independent latent memory through forward computation and selectively integrates it with retained memory via a task-trained recurrent gate. The consolidated memory is then mapped to backbone-specific low-rank adaptation (LoRA) parameters, allowing the encoding capability to transfer when the backbone is replaced. Evaluation across three long-term memory benchmarks and five diverse backbones demonstrates broad generalization with near-constant update cost and memory footprint. With Qwen3-8B on PERMA, RPMem reaches 85.52%, outperforming the strongest parametric and text-based baselines by 5.32 and 12.98 percentage points, respectively. Ablations validate the complementary roles of session compilation and cross-session consolidation, while dynamics analyses reveal that the gate acquires task-specific memory integration strategies. These results establish RPMem as a lifecycle-independent parametric memory framework that maintains evolving cross-session memory that remains reusable across backbone replacements. Our implementation is available at https://github.com/Quark-Medical/rpmem/tree/main.

## 2. 方法论

### 2.1 总体架构（两阶段）

- **阶段一：单会话记忆编译**——将每个会话通过前向计算编码为固定形状、模型无关的潜在记忆，并解码为 LoRA 参数。
- **阶段二：跨会话记忆整合**——用轻量循环门控在任务监督下选择性整合新会话与已积累记忆，记忆尺寸固定。
- **推理**：所有模块冻结，记忆循环更新，通过当前骨干的解码器映射为 LoRA 参数供查询使用。

### 2.2 单会话记忆编译

- **记忆编译器 = 会话编码器 + 模型特定 LoRA 解码器**：
  - 会话编码器 = 冻结上下文编码器 $E_\xi$ + 可训练 Perceiver 重采样器 $G_\phi$。
  - 冻结编码器从 $L$ 个均匀间隔深度抽取特征 $X_t \in \mathbb{R}^{L \times n_t \times d_e}$；重采样器按层独立压缩为固定形状 $q_t \in \mathbb{R}^{L \times M \times r \times d}$，与会话长度 $n_t$ 无关。
- **解码与注入**：解码器 $D_\beta(q_t)$ 生成 LoRA 因子对 $\{A_{t,\ell,m}, B_{t,\ell,m}\}$，按 $\tilde{W}_{t,\ell,m} = W_{\ell,m} + \gamma B_{t,\ell,m} A_{t,\ell,m}$ 注入冻结骨干。
- **训练目标（分布匹配）**：对每个会话的 Q 个查询–响应对，对齐"上下文条件分布 $p^{ctx}$"与"适配器条件分布 $p^{mem}$"：
  - 在固定参考响应轨迹上，取 $p^{ctx}$ 的 Top-K 词表 $S_{i,j}$，并将剩余概率聚合为尾部类别；
  - 采用**前向 KL**（式 9）作为 token 级损失，先对响应内位置平均、再对查询对平均，得到会话损失 $L_{FKL}$；

- **骨干替换机制**：保留 $G_\phi$，为新骨干实例化目标解码器 $D_{\beta'}$，用相同前向 KL 目标优化 $\beta'$（编码器与目标骨干冻结）。记忆表示不变，仅解码适配新的层数与模块维度。

### 2.3 跨会话记忆整合

- 记忆 $h_t$ 与 $q_t$ 同形状，$h_0=0$，$h_1=q_1$（首会话直接初始化）。
- **循环门控**（$t \geq 2$）：
  - 保留张量 $z_t = \sigma([h_{t-1}; q_t] W_g + b_g)$，逐坐标 sigmoid；
  - 状态更新 $h_t = z_t \odot h_{t-1} + (1 - z_t) \odot q_t$。
- **参数效率**：门控在所有层、模块、秩索引间共享，仅 $2d^2+d$ 个参数，与 $L, M, r$ 无关。
- **训练**：冻结 $\theta, \xi, \phi, \beta$，仅优化门控参数 $\psi = \{W_g, b_g\}$，任务损失 $L_{con}(\psi) = \mathbb{E}[\ell_{task}(p_{\theta \oplus \Lambda_T}(\cdot|x), y)]$；梯度穿过冻结骨干与解码器回传。编译表示 $q_t$ 可预计算缓存。

## 6. 主要结论与发现

- **主结果**：Qwen3-8B 在 PERMA 上达 **85.52%**，超 Metis-9B **5.32 pp**、超 Full Context **12.98 pp**；PersonaMem-v2 Overall 达 **40.22%**（超 SFT 8.58 pp）；Pref Eval 300 回合达 **74.81%**（随历史增长不降反升，与 LightMem 的下降趋势相反）。
- **跨骨干泛化**：5 个骨干上相对更强参考条件提升 5.95–20.41 pp；跨骨干复用（Head Transfer）将跨模型均值从 75.97% 提升至 **89.64%**，全部 28 个组合均优于从头训练。
- **消融结论**：编译目标中 Fixed FKL 最优（比 Top-K CE 高 7.86 pp、比 Compiler SFT 高 24.31 pp），说明概率分布的相对似然与尾部质量覆盖均重要；整合规则中学习门控比最强固定规则（因子平均）高 **31.31 pp**，且在 MD 历史（异构记忆）增益更大（41.16 pp）。
- **效率**：64 会话时写入耗时 0.043 s（比 rank concatenation 快约 22×、比 Mem0 快约 292×），更新成本与内存增长分别仅 **1.03×** 和 **1.00×**，查询不携带历史 token（PersonaMem-v2 上前向时间 0.055 s vs Full Context 4.287 s）。
- **通用能力保留**：MMLU/GSM8K/IFEval 上距 Base LLM 分别仅差 1.83/1.43/3.81 pp，且优于 Latest Session。
- **动力学发现**：门控习得结构化更新策略——域建立事件写入幅度更大（为补充事件的约 5 倍差异量级），同域写入模式相似度更高（0.872 vs 0.784），新事件对同域历史衰减更强（存活率 0.458 vs 0.818）；域建立事件的长程存活优势从 1 次更新后的 1.31× 增至 60 次后的 6.64×。

## 7. 优点

- **问题定义清晰且有价值**：首次

- **问题定义清晰且有价值**：首次将"生命周期独立性"从工程细节提升为可被形式化、可被实验测量的研究目标，并给出"保留编码器与记忆表示、仅重训解码器"的可操作实现路径，使"记忆可迁移"从口号变为可验证的量化指标（28 个骨干–设置组合）。

- **架构解耦带来的组合自由度**：把"会话→潜在记忆"（编码器）与"潜在记忆→骨干参数"（解码器）显式分离，使记忆表示与骨干架构解耦、记忆的"写入"与"读取"解耦。这一设计同时带来两个收益：骨干可替换（解码器重实例化即可）与查询零历史 token（记忆直接参与计算而非进入上下文）。

- **参数效率与门控设计精巧**：跨会话整合只用 $2d^2+d$ 个参数、与层数/模块数/秩数无关，且在所有层、模块、秩索引间共享。这使得整合模块的参数量与记忆张量形状彻底脱钩，避免了"记忆越大、更新模块越重"的常见困境，也让单折训练可在 13 分钟内完成。

- **效率指标具有说服力**：写入 0.043 s、更新成本 1.03×、内存增长 1.00×、峰值增量显存 0.575 GiB、检查点 2.004 MiB，均在绝对值上处于"可长期在线运行"的量级；与 rank concatenation（2.826 GiB）和 Mem0 的对比给出了明确的量级差，而非仅相对百分比。

- **消融实验设计规范**：编译目标消融（6 种）与整合规则消融（3+3 种）均在同一编译器检查点、同一分段与历史边界下进行，变量控制严格；且消融结论指向具体机制（"相对似然 + 尾部质量"双重要求），而非仅报告"某配置最好"。

- **超越准确率的机制性分析**：记忆动力学部分没有停留在指标层面，而是通过写入幅度、域内相似度、源存活率刻画了门控学到的"域建立事件优先、同域事件互相衰减"的结构化策略，并给出 1.31×→6.64× 的存活优势演化，为"模型是否真的在管理记忆"提供了内部证据。

- **主动披露局限**：作者主动报告 PERMA 复现性诊断、协议敏感性，以及域动力学中归一化位置标准化均差 0.962 的残余混淆，态度上偏向可证伪而非过度声称因果。

## 8. 局限与不足

- **骨干替换并非零成本**：生命周期独立性要求为新骨干重新优化解码器 $\beta'$，仍需要目标骨干上的训练数据与算力（大模型如 Qwen3.5-35B-A3B 需 32 GPU 跨 4 节点）。因此它是"记忆可复用"，而非"记忆即插即用"。

- **编码器仍是固定的、与预训练特征绑定的组件**：会话编码器依赖冻结上下文编码器 $E_\xi$ 的多深度特征，若目标骨干与编码器的表示空间差异过大，仅靠解码器对齐可能触及能力上限；论文的 5 个骨干均属相近规模/家族，跨家族、跨模态的外推性尚未验证。

- **记忆容量固定带来的潜在饱和**：$h_t$ 与 $q_t$ 同形状、尺寸不随会话数增长，长期看存在信息瓶颈风险。虽然 300 回合偏好实验未见下降，但更长时间尺度（数千会话）下固定容量的写入-覆盖平衡尚不清楚。

- **门控容量高度受限**：全共享的逐坐标 sigmoid 门控虽参数极省，但也意味着它无法表达"按层/按模块差异化保留"的策略。论文的补充消融（标量门控、EMA、更新平均）显示学习门控最优，但未探索"分层门控"等中间容量方案，容量-性能的权衡曲线不完整。

- **遗忘机制是隐式且非可解释的**：记忆的覆盖由门控数值隐式决定，论文未提供显式的删除/编辑接口。对于需要合规删除、精确修订特定历史事实的场景（PERMA 的"修订"设置只是间接测试），缺乏可控性。

- **训练依赖任务监督信号**：整合阶段的门控在任务损失下训练，需要带标注的下游任务数据。对于缺少任务标签的开放域长期交互，如何获得监督信号（自监督/偏好信号）未讨论。

- **编译阶段成本不低**：采样类目标需 2,939–5,284 GPU 小时，即便 Fixed FKL 最优路线也需要数百 GPU 小时量级；论文未给出编译成本与性能的显式帕累托前沿，也未说明更小预算下的退化曲线。

- **评估环境的仿真性质**：PERMA 为 10 个模拟用户、PersonaMem-v2 与 Pref Eval 为派生查询，均非真实长期部署。真实场景中的噪声、意图漂移、多用户交织、隐私约束等未被覆盖。

- **近似带来的理论空白**：前向 KL 损失通过 Top-K 词表截断并将剩余概率聚合为尾部类别，这一近似在 K 的取值、尾部质量分布上缺少理论界的分析（论文仅给出经验上的 K=3 变体对比）；分布匹配与下游任务性能之间的理论联系亦未建立。

- **部分结论的因果性有限**：如前所述，域动力学中的"域建立 vs 补充"效应与时间位置存在残余混淆（标准化均差 0.962），因此"门控主动识别域建立事件"的解读需谨慎，不能排除位置先验的贡献。

- **对比公平性的边界**：主对比中 Metis-9B 直接评估其发布检查点，与在 Qwen3-8B 上训练的 RPMem 并非同骨干；虽然补充了同骨干（Qwen3.5-9B）与多规模对比，但核心表格中跨方法结论仍受骨干差异影响。

## 9. 总体评价与启示

RPMem 的核心贡献不在于单项指标，而在于把一个此前被视为"架构副产品"的问题——记忆能否在模型换代后存活——转成了可训练、可测量、可迁移的系统属性。其技术路线可概括为"记忆表示与骨干解耦、写入与整合解耦、整合与容量解耦"三条正交设计，每条都对应一个明确的工程痛点。

对领域的启示有三点：其一，参数化记忆的竞争力不仅取决于能否编码经验，更取决于记忆的**可移植性**与**在线更新成本**，后者决定其能否真正用于长跑型智能体；其二，轻量循环门控在固定容量下已能学到结构化的保留/衰减策略，说明"记忆管理"本身是可学习的、且不一定需要大参数预算；其三，评估长期记忆需要同时报告准确率、效率、通用能力保留与迁移性四类指标，单看准确率容易高估方案的实际可用性。

若要推进该方向，最值得补足的是：跨家族/跨模态骨干的迁移验证、显式可编辑遗忘接口、以及无监督场景下的整合训练信号。若这三点得到回答，生命周期独立性有望从"可迁移"进一步走向"可持续演化"。
