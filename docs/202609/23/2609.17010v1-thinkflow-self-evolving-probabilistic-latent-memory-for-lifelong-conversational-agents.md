## 摘要
终身对话智能体依赖记忆系统来维持与用户的深度、情境感知交互。然而，现有的显式文本记忆流程存在严重的信息瓶颈，往往会丢失细微的行为模式与情感变化。此外，这类系统在部署后通常保持静态，无法在没有人工反馈的情况下自主适应用户的个人习惯与偏好。认知科学表明，人类完全在潜在空间中维持心智模型，并通过预测编码不断对其进行优化。受此启发，我们提出 ThinkFlow，一种面向终身对话智能体的新型端到端潜在记忆框架。ThinkFlow 通过将对话流动态压缩为概率潜在记忆技能来绕过文本瓶颈，能够自主将复杂的用户状态整合为解耦的连续向量，且不产生语义干扰。为突破这一障碍，我们引入测试时演化范式。通过将教师引导的潜在对齐用于引导初始状态，并结合自监督的下一用户话语预测任务进行持续优化，该框架成功克服了冷启动挑战，实现了无需标签的终身个性化。在长期对话基准上的大量实验表明，ThinkFlow 显著优于主流记忆系统，能够在扩展的多会话交互中提供高度个性化且上下文准确的响应。

## Abstract
Lifelong conversational agents rely on memory systems to maintain deep, context-aware interactions with users. However, existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts. Furthermore, being typically static post-deployment, they cannot autonomously adapt to personal habits and preferences without manual feedback. Cognitive science, however, suggests that humans maintain mental models purely in a latent space and continuously refine them through predictive coding. Inspired by this, we propose \textbf{ThinkFlow}, a novel end-to-end latent memory framework for lifelong conversational agents. ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills, autonomously consolidating complex user states into disentangled, continuous vectors without semantic interference. To break this barrier, we introduce a test-time evolution paradigm. By coupling teacher-guided latent alignment to bootstrap the initial state with a self-supervised next-user-utterance prediction task for continuous refinement, the framework successfully overcomes cold-start challenges and achieves label-free lifelong personalization. Extensive experiments on long-term conversation benchmarks demonstrate that ThinkFlow significantly outperforms prevailing memory systems, providing highly personalized and contextually accurate responses over extended multi-session interactions.

- **背景**：LLM 正从静态问答工具演变为需要与用户建立终身关系的对话智能体，个性化记忆成为关键能力。

  - 这导致**严重的信息瓶颈**：隐含用户偏好、情感变化、未言明的行为模式等细微信息被剥离。
  - 文本记忆库在部署后**静态不变**，无法在无人工反馈下自主适应用户个性。
  - 直接喂入完整多会话历史则计算开销大，且加剧**语义稀释**，导致检索退化。
- **认知科学启发**：
  - **内隐心理理论**：人类并非记忆离散文本摘要，而是在潜在抽象空间中持续追踪他人心理状态。
  - **预测编码**：大脑不断生成对未来的自上而下预测，并依据预测误差精炼内部模型。
- **核心主张**：放弃显式文本瓶颈，纯在潜在空间中通过自监督预测反馈维持持续演化的记忆，可实现真正的零样本终身个性化。

## 2. 方法论

### 2.1 核心思想
将对话流动态压缩为 **K 个解耦的概率潜在记忆技能向量**，作为专门的"认知感受器"，分别捕捉事实、情感、偏好等不同侧面，避免语义干扰。

### 2.2 三大核心组件

**（1）概率潜在记忆技能（PLMS）**
- 用 K 个可学习潜在技能 S ∈ R^(K×D) 通过**交叉注意力**关注当前轮的思维流隐藏状态 E_t。
- 引入**分布保持缩放因子** 1/√c（c = L/K 为压缩率），防止压缩后方差坍缩为确定性点质量。
- 通过两个并行线性层输出均值 μ_t 和 log 方差 log σ²_t，用**重参数化技巧**采样：Ŝ_new = μ_t + σ_t ⊙ ε，ε ~ N(0, I)。
- 用 **KL 散度损失**将近似后验推向标准高斯先验。

**（2）门控潜在巩固器（GLC）**
- 引入**信息增益门** g_t ∈ (0,1)^(K×D)，由 MLP 基于新旧记忆技能拼接表示学习得到。
- 使用 **GRU 核心**条件式逐步更新：S_t = g_t ⊙ GRU(Ŝ_new, S_old) + (1−g_t) ⊙ S_{t−1}。
- 高新颖性信息（如"酒店/巴黎/$200"）门值高（≈0.91），噪声（如"哈哈/嗯/也许"）门值低（≈0.12），从而过滤无用对话噪声并优雅遗忘过时元素。

**（3）上下文感知超对齐器（CAHA）**
- 采用**超网络**方法，基于当前用户查询 x_t 的语言特征生成低秩变换矩阵 W_adapt = W_down(x_t) × W_up(x_t)。
- 通过残差投影得到最终对齐记忆技能：S_aligned = S_t + S_t × W_adapt。
- 对齐后的技能作为**软提示**前置到语言模型以条件化生成。

### 2.3 自监督测试时演化（两阶段训练）

**阶段 1：教师引导潜在对齐（解决冷启动）**
- 教师模型读取完整明文历史 H_<t 输出目标分布 P_T(y | H_<t, x_t)。
- 学生模型仅读当前查询 x_t 和潜在记忆 S_t 输出 P_S(y | S_t, x_t)。
- 损失：L_Phase1 = D_KL(P_T ∥ P_S) + α·L_KL。

**阶段 2：下一用户话语预测（持续终身学习）**
- 教师模型从第 2 个会话起下线。
- 智能体在第 t 轮生成响应 a_t 并更新记忆至 S_{t+1}；第 t+1 轮用户给出新查询 x_{t+1}。
- 用 S_{t+1} 和先前响应 a_t 预测用户下一话语 x_{t+1}，以交叉熵损失 L_CE 作为隐式监督信号。
- 高损失直接迫使 GLC 门关闭，防止记忆被坏更新污染。
- 引入**最小熵置信先验** L_Conf 防止语义坍缩。
- 损失：L_Phase2 = L_CE(x_{t+1} | S_{t+1}, a_t) + β·L_Conf + α·L_KL。

### 2.4 算法流程（Algorithm 1）
- **阶段 1**：对冷启动会话每轮依次执行 CAHA 对齐 → 学生预测 → PLMS 压缩 → GLC 巩固 → 最小化 KL 散度。
- **阶段 2**：对后续会话每轮依次执行 CAHA → PLMS → GLC → 预测下一用户话语 → 最小化交叉熵 + 置信度 + KL。

- **概率建模**：用概率分布而非确定性向量建模记忆，显式捕捉交互不确定性。
- **技能解耦**：K 个潜在技能作为专门认知感受器，防止不同话题间语义干扰。

- **效率卓越**：token 与时间开销远低于显式方法，适合实时陪伴场景。
- **可解释性**：t-SNE 可视化揭示潜在空间的结构分离，增强方法透明度。
