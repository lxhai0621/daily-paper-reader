## 摘要
长时程大语言模型（LLM）智能体依赖外部记忆系统在扩展交互中保留用户偏好与任务知识。传统检索机制优化语义兼容性而非下游效用，经常将过时、误导性或冲突的证据引入活动上下文。我们提出MeClear，一种任务条件化的记忆清除框架，通过合作归因识别具有负向下游效用的记忆，并选择性地将其从智能体执行中抑制。MeClear将留一法筛选与采样合作Shapley归因相结合，在交互证据间分配效用，有效解决单一移除评估失效的冗余冲突遮蔽问题。利用归因排名，MeClear在嵌套过滤上执行查询范围的极小清除策略，验证清除后上下文的任务恢复，同时不永久改变持久记忆库。在十个长对话记忆池上的综合实验评估表明，MeClear实现了85.9%的目标召回率和82.3%的整体任务恢复率，相比留一法（LOO）基线提升了25.5个百分点。

## Abstract
Long horizon Large Language Model (LLM) agents rely on external memory systems to preserve user preferences and task knowledge across extended interactions. Conventional retrieval mechanisms optimize semantic compatibility rather than downstream utility, frequently introducing outdated, misleading, or conflicting evidence into the active context. We present MeClear, a task conditioned memory clearance framework that identifies memories featuring negative downstream utility through cooperative attribution and selectively suppresses them from agent execution. MeClear combines Leave One Out screening with sampled cooperative Shapley attribution to distribute utility across interacting evidence, effectively resolving redundant conflict masking where single removal evaluations fail. Utilizing attribution rankings, MeClear executes a query scoped minimal clearance strategy over a nested filtration, verifying task recovery on the cleared context without permanently altering the persistent memory bank. Comprehensive experimental evaluations across ten long dialogue memory pools demonstrate that MeClear achieves a target recall of 85.9% and an overall task recovery rate of 82.3%, representing a 25.5 percentage point improvement over Leave One Out (LOO) baselines.

## 一、核心问题与整体含义

长期运行的 LLM 智能体（long-horizon LLM agents）需要依赖外部记忆系统来存储用户偏好、任务知识和历史观察。然而，随着交互历史不断累积，记忆库中会混入过时、冗余、误导或相互冲突的记录。传统检索机制的核心缺陷在于：

- **只优化语义相关性，而非下游任务效用**——高语义相似度的记忆可能在实际执行中是有害的；
- **历史记忆之间存在复杂的交互关系**，如冗余有害记忆会互相遮蔽（redundant masking），两个单独无害的记忆组合后才产生危害（joint harm）；
- **单条记录的反事实干预（如 Leave-One-Out）无法识别被同伴遮蔽的有害记忆**，导致"零观测效应"掩盖真实危害。

因此，论文提出的核心问题是：**如何在不断变化的查询条件下，识别并安全地抑制那些对当前任务产生负面效用的记忆，同时不破坏持久记忆库中可能对未来任务有用的信息？**

整体含义在于：该工作将"记忆维护"从语义匹配层面提升到**合作博弈论归因层面**，并引入"查询范围内可逆清除"而非"永久删除"的范式，为长时程智能体的可靠记忆管理提供了新的解决思路。

## 二、方法论

### 2.1 核心思想

MeClear 将记忆清除建模为一个**任务条件化的合作博弈决策过程**：把检索到的记忆集合视为博弈中的玩家，把任务正确率视为特征函数，通过 Shapley 值衡量每条记忆在多样化记忆联盟中的边际效用贡献，从而识别具有稳定负向贡献的有害记忆，并在不修改底层数据库的前提下，对当前查询上下文进行最小化、可验证的清除。

### 2.2 四阶段流程

MeClear 包含四个主要阶段：

1. **自适应任务条件检索（Adaptive Task-Conditioned Context Retrieval）**：从记忆库中获取固定上下文 `Mt = ρ(qt, Bt; K)`，冻结该上下文，后续所有干预均在此集合上操作，避免检索随机性干扰归因结果。
2. **局部反事实筛选（Local Counterfactual Screening）**：对每个记忆执行留一法（LOO）评估，计算局部效应 `dt,i = vt(Mt) − vt(Mt \ {mi})`。由于单条删除可能被冗余记忆遮蔽，该步仅作为可解释的局部诊断信号，不直接作为有害性判定依据。
3. **反事实合作归因（Counterfactual Cooperative Attribution）**：采用**排列采样的Shapley值估计**，对记忆集合的随机排列进行采样，计算每条记忆在不同前缀联盟上的平均边际贡献：
```
ψt,i = (1/|Πt|) Σ_{π∈Πt} [vt(Pi(π) ∪ {mi}) − vt(Pi(π))]
```
   实际操作中抽样 L 条排列得到无偏估计 `ψ̂t,i`。Shapley 归因能揭示 LOO 无法识别的情况——如两条冗余有害记忆各自获得 −Δ/2 的归因值。
4. **验证式查询范围清除（Verified Query-Scoped Clearance）**：将有害记忆按贡献值从负到正排序，构造嵌套候选清除集 `Ct,j = {mσ(1), ..., mσ(j)}`，对每个候选计算任务增益 `ĝt(j) = v̂t(Mt \ Ct,j) − v̂t(Mt)`，筛选"增益为正且通过任务恢复验证"的最小基数候选集，最终输出查询范围内的净化上下文，而不触碰持久记忆库。

### 2.3 关键理论保证

- **定理1（冗余危害盲点）**：在两条可替换的有害记忆同时存在时，LOO 效应为零（因为删除一条后另一条仍维持危害），而 Shapley 归因值均为 −Δ/2，证明 LOO 的盲区可通过合作归因破解。
- **命题1（有限样本估计保证）**：所提 Shapley 估计器是无偏的，并满足 Hoeffding 集中不等式形式的均匀误差上界。
- **定理2（查询范围清除保证）**：所选的清除上下文保证经验性能不退化；若选择非零清除集，则一定通过恢复验证，且在最大增益类中实现最小基数。

## 六、主要结论与发现

1. **MeClear 在所有主要指标上优于 LOO**：目标召回率 85.9% vs 38.3%；精确集合匹配 47.0% vs 34.2%；任务恢复率 82.3% vs 56.8%，提升 25.5 个百分点。
2. **MeClear 在冗余冲突上优势最显著**：LOO 在冗余冲突下召回率崩至 12.3%、恢复率仅 6.3%，MeClear 维持 83.2% 召回和 68.4% 恢复，证明合作归因能有效穿透冗余遮蔽。
3. **MeClear 在联合非加性交互上也表现稳健**：精确匹配从 LOO 的 0.0% 提升至 43.5%，恢复率达 91.8%。
4. **验证式清除保证了非降级**：MeClear 的清除策略保证经验效用不降级，80.5% 的配对案例实现恢复（44.0% 精确 + 36.5% 无害过度选择），仅 14.8% 恢复失败。
5. **ContextCite 是最接近的竞争者**：恢复率 81.5%，与 MeClear 差距（+0.8%）在置信区间内不显著；但 MeClear 在残留风险上更低（13.3% vs 18.8%）。

## 七、优点

- **理论动机清晰且严谨**：从合作博弈论出发给出 Shapley 归因的定义，辅以定理1（冗余盲点证明）和命题1（有限样本估计保证）等数学支撑，方法有据可依。
- **不修改持久记忆的设计非常务实**：考虑到记忆效用是查询条件的函数，MeClear 采用"查询范围可见性控制"而非永久删除，避免跨任务灾难性遗忘。
- **验证式清除避免盲目干预**：在清除前验证候选上下文的恢复状态，从机制上保证不会因清除而损害任务表现。
- **消除了 LOO 的遮蔽盲区**：通过联盟平均边际贡献识别单条删除无法发现的冗余或联合危害，这是核心方法论突破。
- **实验设计严谨**：构建了行为可验证的因果故障集，评估协议严格（多次独立试验 + 固定种子 + 聚类 bootstrap 置信区间），分层比较了故障机制、故障类型和对话来源。
- **可视化充分**：多张图表从归因、清除构成、性能热图、风险前沿等多角度展示结果。

## 八、不足与局限

1. **计算开销较高**：MeClear 需要针对 L=16 条排列、每条排列涉及多组反事实评估进行 LLM 推理，且每次查询都需要构造嵌套候选集并逐一验证，实际推理成本显著高于简单检索或 LOO。论文未报告精确的时延/成本数据。
2. **评估规模受限**：仅基于 LoCoMo 数据集的 10 个对话、745 个案例，规模相对较小；联合交互组样本尤其少（n=85），可能影响结论的统计稳健性。
3. **模型单一性**：任务智能体仅为 Kimi-k2.6，评判器仅为 Qwen3.6-Flash，未考察不同能力层级的智能体（如更强或更弱的模型）对归因质量和清除效果的影响。
4. **阈值敏感性未深入讨论**：虽然论文声称容差 τ 是唯一阈值且与 κ 统一为 0.05，但未系统地分析 τ 值变化对性能的影响，在不同场景下可能需要重新调优。
5. **实际记忆库安全性的长期影响未被验证**：虽然机制上保证了不修改持久记忆，但"在当前查询中反复清除同一条记忆"的长期行为（每条查询的推理成本都需重复归因）是否会导致效率问题，论文未讨论。
6. **对真实世界数据复杂度的覆盖有限**：评估中的故障均为人工注入并经过行为验证，其分布、性质和表述方式可能与自然累积的真实记忆偏差不同，外部效度有待验证。
7. **与 ContextCite 的对比优势不显著**：在总体恢复率上 MeClear 仅领先 +0.8 个百分点，置信区间包含零，说明在非冗余场景下优势有限，论文或将更多增量价值集中在冗余和联合机制上。
