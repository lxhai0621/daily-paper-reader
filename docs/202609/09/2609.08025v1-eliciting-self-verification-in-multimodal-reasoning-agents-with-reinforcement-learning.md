## 摘要
推理智能体越来越多地依赖外部工具（如网络搜索）来回答复杂查询。强化学习（RL）微调算法（如GRPO）已改善了纯文本语言模型中的长程推理，特别是在编码和数学方面。然而，多模态智能体中可靠的工具使用仍然具有挑战性，因为模型必须解释文本和图像，同时整合嘈杂的检索证据，且通常在没有显式验证信号的稀疏结果级监督下进行。我们提出了通过强化学习进行自我验证（SVRL），一种仅使用强化学习的微调框架，训练多模态智能体在其自身的推理轨迹中验证和过滤检索到的证据，从而在推理时减少对外部验证器的依赖。SVRL还引入了一种搜索感知惩罚，以阻止不必要的工具调用，以及一种查询多样性奖励，以鼓励多样且形式良好的搜索查询，为搜索时机和搜索内容提供细粒度反馈。使用SVRL对Qwen-2.5-VL-7B进行仅5000个视觉问答示例的微调，在多跳VQA泛化和跨基准工具效率方面取得了一致的提升。总体而言，SVRL缩小了紧凑型智能体与更大的专有模型之间的差距，同时大幅降低了训练和推理成本。

## Abstract
Reasoning agents increasingly rely on external tools such as web search to answer complex queries. Reinforcement learning (RL) finetuning algorithms such as GRPO have improved long-form reasoning in text-only language models, particularly for coding and mathematics. Reliable tool use in multimodal agents, however, remains challenging because models must interpret text and images while integrating noisy retrieved evidence, often under sparse outcome-level supervision without explicit verification signals. We present Self-Verification via Reinforcement Learning (SVRL), an RL-only finetuning framework that trains multimodal agents to verify and filter retrieved evidence within their own reasoning traces, reducing reliance on external verifiers at inference time. SVRL also introduces a search-aware penalty that discourages unnecessary tool calls and a query-diversity reward that encourages diverse, well-formed search queries, providing fine-grained feedback on when and what to search. Finetuning Qwen-2.5-VL-7B with SVRL on only 5{,}000 visual question answering examples yields consistent gains in multi-hop VQA generalization and tool efficiency across benchmarks. Overall, SVRL narrows the gap between compact agents and much larger proprietary models while requiring substantially lower training and inference cost.

## 1. 核心问题与整体含义

- **研究背景**：多模态大语言模型（MLLMs）正从静态感知系统发展为可调用外部工具（如网络搜索、图像搜索）的交互式智能体。然而，纯文本模型在编码、数学等领域的 RL 微调（如 GRPO）已取得显著成功，多模态智能体的工具使用仍充满挑战。
- **核心问题**：模型在解答视觉问答任务时，需要同时理解文本与图像，并整合来自检索结果中的 **噪声证据**；而训练信号通常是**稀疏的结果级奖励（最终答案是否正确）**，缺少对中间步骤（是否搜索、搜索什么、信任哪些证据、何时停止）的明确监督。
- **具体痛点**：
  1. 模型对“何时需要搜索”缺乏校准：约 10%+ 案例该搜而未搜，30%+ 案例进行了不必要搜索；
  2. 检索结果噪声大且互相矛盾，模型容易“盲信第一条片段”，在检索结果中有相关证据时仍可能答错（分析中超过 28%）；
  3. 稀疏监督导致奖励组内方差过小，GRPO 更新信号弱，且不同失败模式无法区分。
- **论文意义**：提出 **SVRL（Self-Verification via Reinforcement Learning）**，一种纯 RL 微调框架，使多模态智能体在自身推理轨迹中显式生成验证信号、过滤检索证据，并在推理时无需任何外部验证器，从而在低训练/推理成本下逼近大规模专有模型的工具型推理性能。

## 2. 方法论：SVRL 框架

### 核心思想
将“何时搜索”“如何搜索”“如何验证证据”转化为**可学习的轨迹级奖励信号**，通过强化学习直接优化多模态智能体的工具使用策略。

### 总体流程
- 以 VQA 为任务形式：输入图像 I 与问题 q，模型输出结构化中间步骤（reason、工具调用、verify 标签）和最终答案 y。
- 采用 ReAct 风格提示模板，动作包括：图像搜索 `<search><img>`、文本搜索 `<text_search>`、最终答案 `<answer>`，并在工具调用后输出二进制证据相关性掩码 `<verify> ... </verify>`。
- 将 SVRL 目标嵌入 KL 约束的 GRPO 目标：`max_θ E [ r(τ) ] − β KL(πθ || π_ref)`。

### 奖励结构
最终轨迹奖励为：

```
r(τ) = (1 − α) * racc(τ) * r_svrl(τ) + α * r_fmt(τ)
```

其中：
- `racc`：最终答案与 ground-truth 的精确匹配正确与否（0/1）；
- `r_fmt`：提示格式合规性（0–1）；
- `r_svrl = raware · rcount · rqalign · rsalign`，由四个细粒度因子组成。

### 关键技术点
1. **搜索校准（何时搜索）**：
   - 用基础模型在无工具条件下单次前向预测得到“弱先验”：若预测正确，则将该样本标记为 `search_free`；
   - 引入 `raware`：当模型在本来不需要搜索的样本上调用工具时，将该因子调低为 0.1，从而惩罚无谓搜索而不抑制必要搜索。

2. **查询多样性（搜索什么）**：
   - 要求模型一次生成 k（=5）个候选查询，随机执行其中唯一且合规的一条；
   - 用 `rcount = max(ε, 有效唯一查询数/5)` 来鼓励模型产生多样化、表达清晰的查询，避免查询坍缩。

3. **自我验证（证据过滤）**：
   - 让模型在每次工具调用后，输出二进制相关性掩码（`<verify>` 标签）并配以简短自然语言理由；
   - 训练时使用一个**带 ground-truth 答案的外部预言机（GPT-5）**为查询和检索片段生成“是否有用”的监督标签，分别得到 `rqalign` 和 `rsalign`；
   - 模型被训练成让自己的自验证分数与预言机标签一致，推理时**丢弃外部验证器**，完全由模型自发验证。

4. **训练稳定处理**：
   - 为避免细粒度奖励下 GRPO 组内优势不稳定，采用 **Dr. GRPO**（移除标准差与长度归一化）；
   - 消融发现：若将所有奖励项简单相加而非相乘，会出现“部分答错却仍得到部分奖励”的奖励黑客行为；因此 SVRL 将细粒度项按 `racc * r_svrl` 乘性门控，只有答案正确时才赋予过程分。
   - 还尝试过 LLM judge 奖励，但容易导致答案冗长、模糊化，故训练仍采用精确匹配，仅评估阶段使用 LLM judge。

### 算法伪代码
- 先对全部训练样本做无工具自标注，得到 `search_free` 标签；
- 迭代 GRPO 更新：对每个样本采样一组（G=4）rollouts，解析最终答案、动作参数、自验证掩码；
- 调用预言机 verifier 得到 Query 和 Snippet 标签，计算各奖励因子，得到轨迹奖励；
- 使用 Dr. GRPO 目标函数完成策略更新。

## 7. 局限与批判性分析

尽管实验结果亮眼，论文仍存在以下值得注意的局限：

1. **训练依赖 GPT-5 预言机作为奖励信号源**：虽然推理时不再使用预言机，但训练阶段仍然需要访问一个闭源、强模型对每一条查询和检索片段进行二分类标注。这带来两点隐忧：
   - 预言机的判断噪声被直接传入奖励，若预言机在域外场景中系统性偏好某种表达，则模型学到的“验证”能力可能只是对该偏好的模仿；
   - 从纯开源复现角度看，这构成了数据/信号层面的“蒸馏”，与“纯 RL”的说法略有张力，因为其过程奖励并非纯粹由规则或环境提供。

2. **结果度量依赖精确匹配（EM）**：作者承认 EM 对同义改写不友好，因此训练奖励可能低估了语义正确但措辞不同的答案；虽然评估阶段辅以 LLM judge，但训练仍可能因 EM 的严苛而抑制模型表达能力。这一情况与现有 RLVR 工作一致，但对开放域 VQA 类任务影响可能更大。

3. **“验证”仍停留在证据与问题的局部相关性层面**：`rqalign` 与 `rsalign` 本质上是二分类相关性掩码，并不评估证据与最终推理解释之间的逻辑一致性。这意味着 SVRL 虽能抑制噪声证据，却不一定能学到深层的证伪或多步演绎验证，示例中的复杂推理更多依赖 base 模型已有的能力。

4. **搜索决策的奖励标记使用弱先验替代 oracle**：`raware` 以“无工具单次前向答案是否正确”来决定是否应当搜索，这假设当基础模型已能回答正确时，任何搜索都是不必要的。但在某些知识型任务中，即使用户的答案正确，搜索到的补充材料也能增强答案可信度或支持多模态对齐；此假设可能使模型偏向“不做功”的保守策略。

5. **评测数据集的规模与偏差控制不透明**：论文仅披露 FVQA 训练、测试规模（5000/1800），对 InfoSeek、LiveVQA 等外部评测的子采样协议、难度分布、证据源版本均未详细说明，跨基准可比性难以完全确认，少量百分点差异可能落在评测集构造方式内。

6. **未与同规模开源模型做全面的工具推理对比**：主要弱基线是同一基座上的自研 MMSearch-R1++；与更成熟的开源智能体如基于 Qwen2.5-VL 的 WebWiz、AssistantVision 等的横向对比略少，难以估计该方法相对于“非 RL 但精心指令调优”的增益究竟有多少。

7. **7B 到 8B 骨干的可扩展性仍有限**：论文只报告了小参数模型的实验，未验证 SVRL 在 30B/70B 级别模型上的收益是否持续（考虑到小模型的自我验证上限可能更低，而在大模型上 RL 收益可能被指令跟随能力稀释或放大，仍是开放问题）。

## 8. 总结评价

SVRL 是一篇方法务实、分析深入的工作。它抓住了多模态智能体工具调用中真正棘手的“证据鉴别”问题，并以奖励塑形与搜索校准的组合方式给出了一套不需推理时验证器的轻量 RL 解决方案。其消融设计非常扎实，从搜索频率、查询多样性与验证掩码几个维度分别量化不同失败模式的贡献，并明确揭示了“证据利用”比“查询生成”更具决定性——这一结论对未来工作有很强的指导价值。论文的写作风格以实证驱动，几乎所有关键设计都配有归因实验，整体可信度较高；弱项主要体现在对预言机依赖的正当性讨论不够充分，以及外部评估一致性偏弱。如后续能将训练过程奖励改为更鲁棒、开源可复现的信号（如基于规则的冲突检测或小型判别器），并将验证从“相关”提升至“逻辑蕴含”层面，该方法具有推广为通用多模态智能体训练范式的潜力。
