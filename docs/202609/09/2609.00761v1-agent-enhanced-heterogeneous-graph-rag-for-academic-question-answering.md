## 摘要
学术问答需要对异质学术图谱进行推理，其查询范围从简单的属性查找到跨作者-论文-venue结构的多跳推理。现有的检索增强生成（RAG）系统在此场景下存在三个局限：（1）固定检索策略无法适应不同查询复杂度；（2）缺乏充分性评估导致证据不完整或不一致；（3）缺乏对图事实的结构化验证。为解决上述问题，我们提出一种智能体化异质图RAG方法，将RAG流程的三个核心阶段转化为显式的智能体决策步骤。查询感知检索智能体分析查询类型并选择合适的图遍历策略；充分性感知重排智能体评估证据完整性并自适应扩展检索子图；图基验证智能体在最终回答前检查实体、关系和属性的正确性。在由OpenAlex和DBLP构建的异质图上的实验表明，我们的方法持续优于强LLM、图增强RAG和基于智能体的基线方法。

## Abstract
Academic question answering requires reasoning over heterogeneous scholarly graphs, where queries range from simple attribute lookups to multi-hop inference across author--paper--venue structures. Existing retrieval-augmented generation (RAG) systems struggle in this setting due to three limitations: (1) fixed retrieval strategies that do not adapt to varying query complexity, (2) the absence of sufficiency evaluation leading to incomplete or misaligned evidence, and (3) a lack of structured verification against graph facts. To address these issues, we propose an agentic heterogeneous graph RAG method that transforms the three core stages of the RAG pipeline into explicit agentic decision steps. A query-aware retrieval agent analyzes query type and selects an appropriate graph traversal strategy; a sufficiency-aware reranking agent assesses evidence completeness and adaptively expands the retrieved subgraph; and a graph-grounded verification agent checks entity, relation, and attribute correctness before finalizing the answer. Experiments on heterogeneous graphs constructed from OpenAlex and DBLP suggest that our method consistently outperforms strong LLM, graph-augmented RAG, and agent-based baselines.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：学术问答需要在由作者、论文、venue 构成的异质学术图谱上进行推理，查询范围涵盖简单的属性查找（如查询某篇文章发表年份）到复杂的多跳关系推理（如查询某作者发表在某顶级会议上的被引用数最高的论文）。
- **现有 RAG 的三点局限**：
  - **固定检索策略**：检索深度统一，无法区分简单属性查询与多跳推理查询的不同需求；
  - **缺乏证据充分性评估**：一次性检索子图，无法保证检索到的子图能满足查询中隐含的实体、约束或聚合信号；
  - **缺乏图基事实验证**：生成答案后几乎不检查答案中的实体是否存在、关系是否有效、属性是否正确。文本退火检测方法（如 SelfCheckGPT、self-consistency）主要依赖自一致性，而非利用图事实进行结构化验证。
- **核心问题**：如何在异质学术图中构建能够自适应查询复杂度、控制证据充分性并进行图基验证的智能体 RAG？

### 2. 论文提出的方法（方法论）

论文提出 `Agent-Enhanced Heterogeneous Graph RAG` 方法，将 RAG 的三阶段显式转化为三个智能体决策步骤：

- **总体流程**：查询 → 检索计划 → 子图检索与自适应扩展 → 答案生成 → 图基验证 → 最终答案。

- **（1）查询感知检索智能体（Query-Aware Retrieval Agent）**：
  - 将自然语言查询解析为结构化检索计划：**类型 t ∈ {属性, 直接关系, 聚合, 多跳}**、**起始节点类型 s ∈ {作者, 论文, venue}**、**跳跃预算 h**、**实体提及 E(q)**、**遍历策略 π_t**；
  - 正式化为：**Ω(q) = (t, s, h, E(q), π_t)**；
  - 使用经过提示词设计的 GPT-4-turbo 分类器推断查询类型，其概率分布记为 p(t|q) = softmax(f_θ(q))，取概率最大的类型 t★ 后，通过固定映射确定遍历策略。

- **（2）图检索与充分性感知重排智能体（Sufficiency-Aware Reranking Agent）**：
  - **实体查找**：通过 embedding 相似度选择起始节点——v★ = arg max sim(φ(q), φ(v))，使用 sentence-transformers（all-MiniLM-L6-v2，384 维）实现；
  - **遍历**：执行初始遍历得到子图 G_q⁽⁰⁾ = Traverse(v★, h, π_t)；
  - **充分性评分**：通过公式 **S_suf(q, G_q⁽ⁱ⁾) = α·Cov(q, G_q⁽ⁱ⁾) + (1-α)·Rel(q, G_q⁽ⁱ⁾)** 评估现有子图是否充分。Cov 计算实体覆盖率（实体提及匹配率），Rel 衡量查询与子图节点描述的语义相似度；
  - **自适应扩展**：若 S_suf < τ，则触发受控扩展 G_q⁽ⁱ⁺¹⁾ = Expand(G_q⁽ⁱ⁾, π_t)，最多扩展两次以控制延迟和子图规模。

- **（3）答案生成与图基验证智能体（Graph-Grounded Validation Agent）**：
  - 将最终子图线性化作为上下文交给 LLM 生成答案；
  - 验证 Agent 计算事实一致性评分：**S_cons(a, G_q) = β₁·EntAlign(a, G_q) + β₂·RelAlign(a, G_q) + β₃·AttrMatch(a, G_q)**：
    - EntAlign：答案中实体能否链接到子图中的节点（字符串匹配+embedding 相似度）；
    - RelAlign：答案中描述的关系三元组是否与子图中已有边对应；
    - AttrMatch：答案中数值和类别属性（年份、venue、计数）是否与对应节点属性一致；
  - 若 S_cons < γ，触发重新生成（最多两次，以控制计算成本），最终仍不达标则输出不确定性信号。

### 3. 实验设计

- **数据集**：基于 OpenAlex 和 DBLP 构建的学术异构图，包含 3 类节点（作者、论文、venue）和 2 种关系（writes、published_in）：
  - OpenAlex：76,569 节点，105,290 边；
  - DBLP：62,443 节点，79,697 边。
- **Benchmark 构建**：依据查询类型学，为每个数据集生成 400 个查询（每类 100 个：属性、直接关系、聚合、多跳），金标准答案自动从图事实中提取。
- **骨干模型与实现**：全部智能体控制器和最终答案生成使用 GPT-4-turbo；实体查找使用 sentence-transformers；每次查询最多允许 2 次检索扩展和 2 次基于验证的重生成。
- **评估指标**：Accuracy（金标答案精确匹配）、F1（实体级精确率与召回率）、Hit@1（首个预测答案是否正确）。
- **对比基线**分为三类：
  - 纯 LLM：Qwen-2.5-7B、GPT-o3；
  - 图增强 RAG：Vanilla RAG、GraphPrompter、GraphRAG、KGRAG、GraphCoT；
  - 智能体/复杂度感知 RAG：AdaptiveRAG（复杂度感知检索）、Agent-G（智能体检索控制）。
