## 摘要
在长期对话中的问答代理必须对海量、时间上分散的对话历史进行推理。然而，现有的记忆机制主要将过去的信息视为“被动”存储的事实，导致语义鸿沟和不可靠的推理。为解决这一局限，我们提出RuleMem，一种基于规则的记忆框架，从历史交互中归纳出可复用的逻辑规则，以“主动”引导证据检索和推理。具体而言，RuleMem从对话中构建自然语言的Horn子句，并通过规则困惑度一致性（RPC）机制进行验证。这些归纳的规则能够检索语义上遥远的证据，同时为答案生成提供显式的逻辑结构。我们在两个长期对话基准LoCoMo和LongMemEval_s*上对RuleMem进行了全面评估。在与LoCoMo上的14个基线进行严格比较时，RuleMem取得了最高准确率，超过基线平均值27.47个百分点（相对提升54.3%）。

## Abstract
Question answering agents in long-term conversations must reason over massive, temporally dispersed dialogue histories. However, existing memory mechanisms primarily treat past information as \textit{passively} stored facts, leading to semantic gaps and unreliable reasoning. To address this limitation, we propose RuleMem, a rule-based memory framework that induces reusable logical rules from historical interactions to \textit{actively} guide both evidence retrieval and reasoning. Specifically, RuleMem constructs natural-language Horn clauses from conversations and validates them via a Rule Perplexity Consistency (RPC) mechanism. These induced rules enable the retrieval of semantically distant evidence while providing an explicit logical structure for answer generation. We conducted a comprehensive evaluation of RuleMem on two long-term conversational benchmarks, LoCoMo and LongMemEval_s*. In a rigorous comparison against 14 baselines on LoCoMo, RuleMem achieved the highest accuracy, exceeding the baseline average by 27.47 points (a 54.3% relative improvement).

## 1. 论文的核心问题与整体含义（研究动机与背景）

**问题背景**：在长期对话场景中进行问答（QA）要求代理在海量、非结构化、时间上高度分散的对话历史中完成推理；而大语言模型（LLM）的上下文窗口有限、参数化记忆难以持续更新，因此外部记忆模块已成为当代 Agent 系统的标配组件。

**核心矛盾**：现有记忆机制可将过去的信息视为"被动"存储的物品，存在两类深层挑战：

- **语义鸿沟导致召回失败**：当问题与证据之间缺乏词面或浅层语义重合时（例如问题问"Alice 为什么缺席会议"，而证据只记录"Alice 预订了假期"），基于相似度检索的方法容易漏检关键证据。
- **证据松散导致推理失败**：即使成功召回相关事实，面对冗长、杂乱排列的上下文，LLM 自身难以完成逻辑链条的串联，易出现推理断裂或幻觉。

**作者的核心观察与立场**：已有记忆范式分为两层——"事实记忆"（存储片段、基于相似度检索，如 MemGPT、Mem0）和"事实组织"（用知识图谱、Zettelkasten 网络、时间轴等进行结构化组织，如 Zep、A-MEM、MemInsight），但两者都停留在实例层面。当记忆规模扩大时，实例间密集连接会引入大量与查询无关的噪声，LLM 仍需自行推断哪些事实能作为前提、能推出什么结论，从而产生不必要的推理负担与失败风险。

**整体主张（rule induction 范式）**：借用人类认知规律——人类会从具体观察中归纳可复用规则；因此记忆不应只限于记录或组织片段，而应**从历史交互中归纳抽象逻辑规则**，以规则"主动"引导证据召回与推理。这是一个比"记忆"和"组织"更高层级的认知抽象，也是论文提出的核心含义。

## 2. 方法论：核心思想、技术细节与公式流程

### 2.1 核心思想

RuleMem 将长期对话记忆组织为一个闭环系统，包含三个主要阶段：

1. **自底向上的规则归纳（Bottom-Up Induction）**：从对话历史的具体事实中提取并抽象出通用的逻辑规则；
2. **RPC 验证（RPC Validation）**：对归纳得到的规则进行可靠性筛选；
3. **自顶向下的规则引导问答（Top-Down Deduction）**：在回答新问题时，先用规则引导证据检索，再以规则为推理骨架生成答案。

系统维护两个记忆空间：
- **事实记忆库 MF**：存储从对话中抽取的含时间戳的事实四元组（主体、关系、客体、时间）；
- **规则记忆库 MR**：存储从事实中归纳出的自然语言 Horn 子句规则。

### 2.2 关键技术细节

**(1) 规则的形式化表示——自然语言 Horn 子句**

每条规则 r ∈ MR 表达为：

```
r: B1 ∧ B2 ∧ … ∧ Bn ⇒ H  (n ≥ 1)
```

- Body（前件）为合取式自然语言关系短语，含类型占位符（如 [Person]、[Event]、[Location]）；
- Head（后件）为单一原子结论。
- 这一设计兼顾了形式逻辑结构的严谨性与自然语言的语义灵活性。

**(2) Bottom-Up 归纳流程（记忆构建阶段）**

- **事实记忆化**：解析长对话 → 抽取（subject, relation, object, timestamp）四元组 → 存入事实记忆库 MF；
- **推理路径挖掘**：在事实构成的时序知识图谱结构上做约束随机游走采样候选路径 → 由 LLM 过滤不合理路径，并对照原始对话片段重构出清晰的推理路径（reasoning paths）；
- **规则归纳**：将相似关系模式的路径分组，使用 LLM 将实体名抽象为类型占位符，蒸馏出共享的通用因果规则。

**(3) RPC（Rule Perplexity Consistency）验证机制**

直接提示 LLM 归纳规则容易得到过度泛化或幻觉的规则，因此引入 RPC 以困惑度（perplexity）变化来度量规则在连续语义空间中的可靠性：

- **内部一致性信号（self consistency）**：衡量给定规则身体 T_A^r 后是否降低结论 T_C^r 的自回归负对数似然：

  Δ_self(r) = ℓM(T_C^r | ∅) − ℓM(T_C^r | T_A^r)

- **外部事实一致性信号（fact consistency）**：在规则基础上进一步加入从事实库检索到的证据 T_E^r，衡量外部事实是否进一步降低结论的条件困惑度：

  Δ_fact(r) = ℓM(T_C^r | T_A^r) − ℓM(T_C^r | T_A^r ⊕ T_E^r)

- **综合置信度**：

  RPC(r) = α·σ(Δ_self(r)) + (1−α)·σ(Δ_fact(r))

只有 RPC 分数超过阈值 τ 的规则才能进入规则记忆库。实验中默认 α=0.4、τ=0.5。

**(4) Top-Down 规则引导 QA（推理阶段）**

- **检索规则（Retrieval Rules）**：将新问题 Q 与规则库中规则的 Head 做 embedding 相似度匹配，激活 Top-N 条候选规则；
- **引导召回（Guided Recall）**：激活规则的 Body（前件）作为检索线索，从事实库 MF 中召回相似事实；再引入 LLM 作为"语义合一操作符"，根据问题实体与规则类型约束过滤掉变量绑定错误或类型不符的事实，得到精准支撑证据；
- **显式推理（Explicit Reasoning）**：将 {问题、激活规则、引导证据} 组织为结构化 prompt，使生成模型在"规则推理骨架 + 事实细节支撑"双重约束下生成最终答案。

### 2.3 流程总结（文字版）

```
第一阶段：构建。对话 → 事实抽取 → 构建时序知识图谱 → 采样+LLM重构推理路径 → 分组归纳为 Horn 规则 → RPC 验证筛选 → 入库
第二阶段：推理。新问题 Q → 匹配规则 Head 激活规则 → 以规则 Body 为线索召回候选事实 → LLM 语义合一过滤 → 规则+证据+问题 → 结构化生成答案
```

## 6. 论文的主要结论与发现

1. **RuleMem 表现优越**：在 LoCoMo 基准上，RuleMem 的平均准确率达到 78.05%，在 14 个基线对比中获得最高准确率，**超过基线平均值 27.47 个百分点（相对提升约 54.3%）**；BLEU 平均 36.90，F1 平均 32.96，大部分指标位居第一或第二。
2. **各类问题全面领先**：在需要深层逻辑演绎的 Multi-hop（准确率 82.43）与 Open-domain（78.37）任务上提升尤为显著；Single-hop 生成质量最高（BLEU 42.12）；Temporal 问题的 F1/BLEU 大幅超越现有方法（F1 49.00 vs. 最好基线 21.33）。
3. **Guided Recall 有效缓解召回失败**：规则前件作为检索线索可将各基线的平均召回率从 0.56 提升至 0.79（相对提升 41.1%），跨越语义鸿沟检索到逻辑相关但词面不重叠的证据。
4. **Explicit Reasoning 有效缓解推理失败**：注入抽象规则作为逻辑骨架，可将推理失败数量从平均 120.4 降至 105.9（相对减少约 12.0%）。
5. **RPC 验证机制是保障规则质量的关键**：去除 RPC 后准确率大幅下降（78.05 → 65.90），说明高可靠性的规则过滤是必要的。
6. **超参数存在最优平衡点**：τ=0.5、α=0.4 时效果最佳——过低阈值会引入过度泛化的规则，过高则导致规则记忆过稀疏；外部事实一致性信号（α 较小）主导地位更强。

## 7. 优点总结

1. **切入点新颖且具有认知学基础**：将记忆从"被动存储"提升到"规则归纳与主动引导"的新抽象层级，并援引人类归纳学习规律作为合理支撑，概念上有明显创新。
2. **规则表示兼顾形式与语义**：以自然语言 Horn 子句表达规则，既有逻辑学的结构严谨性，又有自然语言的语义灵活性；用类型占位符替代实体，控制泛化粒度。
3. **RPC 验证机制设计巧妙**：通过条件困惑度下降同时度量"模型先验内部一致性"和"外部事实一致性"，在连续语义空间上近似规则支持度，为无监督规则筛选提供了可行且可计算的手段；使用 Sigmoid 和权重系数将两信号统一为可调分数。
4. **完整双层记忆架构实现"主动引导"**：规则记忆库在推理时先行匹配（head 匹配），再将 body 用作检索线索（引导证据）、将规则整体用作推理骨架（显式推理），三阶段配合环环相扣。
5. **实验对比充分、分类设计清晰**：14 个基线覆盖三类记忆范式；主实验按四类问题的难度做分项报告；同时设计了两类针对性机制验证实验（Guided Recall 疗效、Explicit Reasoning 疗效），并配合成功/失败案例分析、消融实验与超参数敏感性分析，能较好地定位性能收益来源。
6. **对失败模式的显式识别**：将问题切分为"召回失败"和"推理失败"两个可单独量化的环节，使实验验证具备因果推断逻辑，而不仅是黑箱式端到端对比。

## 9. 延伸思考与未来研究方向

基于论文贡献与其自身暴露的局限，可从以下几个方向做进一步探索：

1. **规则生命周期管理**：将规则记忆库视为随时间演化的知识系统，引入规则间的支持度/置信度统计与定期重验证机制，实现规则的自动更新、合并与淘汰，避免"死规则"长期污染推理。
2. **规则与证据的优先级仲裁**：论文失败案例表明规则可能与当前具体事实矛盾。未来可在探针 prompt 中显式加入"证据优先于规则"的冲突消解指令，或为每条规则附带适用范围与例外条件，以降低先入为主的诱导偏差。
3. **规则归纳的成本压缩**：多阶段 LLM 调用（路径采样、规则归纳、困惑度验证）开销较高，可探索蒸馏轻量归纳器、复用单次调用的中间结果，或用可学习的判别模型替代部分 LLM 环节。
4. **结合在线学习与个性化**：规则库本质上是针对单一对话主体的"认知画像"，可尝试将高频规则抽象为长期人格/偏好模板，低频规则保留为情境化记忆，实现从"记忆"到"理解"的递进。

## 10. 总结性评价

RuleMem 的价值不在于增加一个检索模块，而在于提出了一种记忆范式的转移——从"记住什么"转向"从记忆中总结出什么规律，并用规律反哺记忆的提取与推理"。其将**规则归纳（自底向上）**与**规则引导演绎（自顶向下）**闭合为统一框架，以自然语言 Horn 子句作为规则载体，配合 RPC 验证机制在一定程度上抑制了无监督归纳带来的幻觉风险。实验证据也支持其核心主张：规则的引导作用能同时缓解语义鸿沟导致的召回失败与证据松散导致的推理失败。

当然，该工作仍处于"规则记忆"范式的早期阶段——规则的长期演化、冲突消解、成本控制与统计严谨性均待完善。但其"以抽象规则作为记忆组织的高层单元"这一思路，为长期对话代理超越"更大上下文"与"更精密检索"的既有路线提供了一条值得关注的新路径。
