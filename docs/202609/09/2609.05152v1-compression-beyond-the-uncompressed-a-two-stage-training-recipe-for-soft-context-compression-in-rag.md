## 摘要
检索增强生成（RAG）利用外部知识增强语言模型，但冗长的检索上下文会膨胀输入并降低推理效率。软上下文压缩将每个文档编码为大幅缩短的嵌入序列。然而，现有方法大多通过从未压缩的RAG系统中蒸馏输出来训练，这固有地限制了它们相对于原始模型的性能。为解决此限制，我们提出DEX-Comp，一种两阶段训练方案：纯蒸馏阶段仅在未压缩RAG的正确响应上对压缩模型进行热启动，然后硬探索阶段仅对未压缩RAG失败的查询运行强化学习，迫使模型探索更适合压缩表示的计算模式。在五个开放域问答基准上，从top-5到top-30的检索深度，DEX-Comp将检索上下文压缩了$16\times$，并将推理速度提升了$4\times$--$24\times$，同时在不同检索深度下实现与未压缩RAG基线相当或更优的性能。跨多种数据集和骨干网络的消融实验与评估进一步证实了每个阶段的贡献以及我们方法的泛化性。

## Abstract
Retrieval-Augmented Generation (RAG) enhances language models with external knowledge, but the lengthy retrieved context inflates the input and degrades inference efficiency. Soft context compression encodes each document into a substantially shorter embedding sequence. However, most existing approaches are trained by distilling outputs from uncompressed RAG systems, inherently limiting their performance relative to the original model. To address this limitation, we propose DEX-Comp, a two-stage training recipe: Pure Distillation warm-starts the compression model on the uncompressed RAG's correct responses only, and Hard Exploration then runs reinforcement learning solely on queries the uncompressed RAG fails, forcing the model to explore computation patterns better suited to compressed representations. On five open-domain QA benchmarks at retrieval depths from top-5 to top-30, DEX-Comp compresses retrieved contexts by $16\times$ and accelerates inference by $4\times$--$24\times$, while achieving performance comparable to or exceeding the uncompressed RAG baseline across retrieval depths. Ablations and evaluations across diverse datasets and backbones further confirm the contribution of each stage and the generalization of our approach.

### 1. 核心问题与研究动机

- **背景**：检索增强生成（RAG）通过引入外部知识大幅提升了语言模型在知识密集型任务上的表现，但检索到的长上下文会显著增加输入长度，导致推理延迟升高，甚至可能超出模型的上下文窗口。
- **现有方案的缺陷**：软上下文压缩（将文档编码为更短的连续嵌入序列）虽在信息密度上优于硬压缩，但现有方法大多通过**蒸馏未压缩 RAG 模型的输出**进行训练，因而性能天然受限于教师模型的行为模式。压缩模型读入的是短而密集的嵌入序列，却继承了教师模型在离散 token 上养成的逐 token 推理习惯，这种"计算模式错配"是性能差距的重要来源。
- **核心研究问题**：如何突破蒸馏带来的性能上界，使软压缩模型在压缩表示上探索出更优的计算策略，甚至超越未压缩的 RAG 基线？现有软压缩工作普遍只在较浅检索深度（top-5）下评估，也难以反映真实部署场景。

### 2. 方法论：DEX-Comp 两阶段训练方案

#### 核心思想

将"可靠模仿"与"定向探索"分离：先在教师正确回答的子集上进行纯蒸馏获得有能力的初始化，再仅在教师失败的查询子集上进行强化学习，迫使模型探索超越教师行为的计算模式。

#### 方法架构

- 采用自编码范式：将文档文本与若干特殊压缩 token 拼接，经压缩器 $C_\phi$ 编码后，取压缩 token 位置的隐状态作为压缩嵌入序列 $e_i = C_\phi(d_i)$（长度为 $\lfloor L_i/\tau \rfloor$，$\tau$ 为固定压缩率）。
- 压缩过程**离线运行**，每个文档只需编码一次、缓存后即可在推理时即时访问。
- 解码器 $G_\theta$ 为自回归语言模型，基于压缩嵌入和查询生成回答。压缩器与解码器共享同一骨干 LLM，通过两个独立的 LoRA 适配器实现，大幅降低训练成本。

#### 阶段 I：纯蒸馏（Pure Distillation, PD）

- 将训练集按教师（未压缩 RAG）回答是否正确划分为 $S^+$ 与 $S^-$。
- **仅在教师回答正确的子集 $S^+$ 上**最小化教师与学生响应分布之间的 KL 散度：
  $$\mathcal{L}_{PD}(\phi,\theta) = \mathbb{E}_{(q,D_q)\sim S^+}\left[D_{KL}\left(P_T(r|D_q,q)\ \|\ P_\theta(r|e_1,\dots,e_k,q)\right)\right]$$
- 梯度同时流经解码器 $\theta$ 和（经 $e_i$ 的）压缩器 $\phi$。
- **与现有方法的本质区别**：不把教师当作需要完全克隆的"神谕"，而是将模仿仅视为获得良好初始化的快速途径——因为压缩模型最优的计算策略未必与教师在离散 token 上的推理模式一致。

#### 阶段 II：硬探索（Hard Exploration, HE）

- 在阶段 I 初始化基础上，**仅在教师失败的查询子集 $S^-$ 上**进行强化学习。
- 采用 GRPO（Group Relative Policy Optimization）：对每个查询采样 $G$ 条候选响应，以是否匹配标准答案的二元奖励 $R^{(g)}=\text{eval}(r^{(g)},r^*)\in\{0,1\}$ 为基础，在组内做标准化得到优势 $A^{(g)}$。
- 优化带裁剪的策略梯度目标，并加入对 PD 检查点 $\pi_{\text{ref}}$ 的 KL 正则：
  $$\mathcal{L}_{HE} = -\mathbb{E}_{q\sim S^-}\left[\frac{1}{G}\sum_{g=1}^{G}\frac{1}{|r^{(g)}|}\sum_{t=1}^{|r^{(g)}|}\min\left(\rho_t^{(g)}A^{(g)},\ \text{clip}(\rho_t^{(g)},1-\varepsilon,1+\varepsilon)A^{(g)}\right)\right] + \beta D_{KL}[\pi_{\phi,\theta}\|\pi_{\text{ref}}]$$
- **为何只在 $S^-$ 上探索**：此子集上的任何提升更可能来自教师未曾展示的新行为，而非简单的模仿复制，从而推动模型真正超越教师。

### 6. 主要结论与发现

1. **超越未压缩 RAG**：在 16× 压缩下，DEX-Comp 在所有数据集、所有检索深度上均超过未压缩 RAG 基线（平均 CEM/LLM-judge 提升在 top-5/15/30 下分别为 +3.82/+2.01、+3.89/+2.34、+3.12/+2.53）。这是**首个在多个真实检索深度下超越未压缩 RAG 的查询无关软压缩方法**。
2. **显著的效率提升**：top-30 时 TTFT 加速 23.73×、计算量降低 13.61×、峰值显存降低 4.02×，且随 $k$ 增大增益越明显。
3. **训练深度与推理深度匹配效果最佳**，但用 top-30 训练的单一模型可直接迁移到 top-5/15 仍保持优越或相当表现，跨深度泛化能力强。
4. **两阶段均不可或缺**：删除任一阶段均导致稳定且显著的性能下降；只蒸馏教师正确响应优于蒸馏全部响应；只在教师失败子集上做 RL 优于在正确子集或混合子集上做 RL。
5. **压缩即隐式去噪**：DEX-Comp 在 Resilience Rate（鲁棒性）上的增益大于 Boost Rate（信息利用率），说明压缩在去除检索噪声方面有额外优势。
6. **嵌入呈现空间特化**：部分嵌入聚焦文档局部区域、部分捕捉全局信息，说明模型学会以"局部+全局"的方式分配有限的容量。

### 7. 方法亮点

- **问题诊断精准**：将性能差距归因于"训练方式"而非"表示能力"，从蒸馏数据筛选入手提出解决方案，切中要害。
- **两阶段互补设计巧妙**：纯蒸馏（能力初始化）与硬探索（突破上界）在数据子集上完全互补（$S^+$ vs $S^-$），逻辑自洽，避免了 RL 在教师已能答对的样本上做无意义探索。
- **突破"模仿上界"的意义**：此前软压缩领域普遍接受"压缩模型只能逼近未压缩基线"的想法，DEX-Comp 首次以实证打破这一隐含假设。
- **训练/推理同深度匹配 + 跨深度泛化的双重验证**：实验设计兼顾了实验室理想条件（训练深度=推理深度）与部署实用性（一个模型应对多深度）。
- **计算开销控制**：LoRA + 离线压缩 + 共享骨干的设计使训练和推理成本相对可控，实用性强。

### 8. 不足与局限

- **评测范围有限**：仅覆盖开放域问答的答案正确性指标，未评估生成内容的忠实性（faithfulness）、可归因性（grounding/ citation）以及对抗性或长文生成场景下的表现（作者在限制一节中已承认）。
- **奖励信号粗糙**：二元 CEM 奖励无法区分回答的部分正确性、无法惩罚幻觉内容，可能引导模型走"答案字符串命中"的捷径而非真正的推理能力提升。
- **与任务特定 RL 的混淆**：未压缩 RAG 基线未做任务特定 RL 训练，而 DEX-Comp 第二阶段本身是 RL——因此"超越未压缩 RAG"中有一部分增益来自 RL 而非压缩本身，作者承认当前设置无法严格分离这两者的贡献。
- **离线预计算的存储与更新成本**：需要预先压缩并缓存整个语料的嵌入，对于动态更新频繁或规模极大的语料库，存储与增量更新成本可能成为瓶颈。
- **LLM-as-judge 的可复现性问题**：使用专有模型做裁判，读者难以完全复现该指标的结果（已提示词和 CEM 指标作为补偿）。
- **未报告的细节**：训练时长、总算力消耗、消融实验的统计显著性（主实验报了 $p<0.05$，消融未报）等信息缺失，可能影响读者对实际部署成本的评估。
