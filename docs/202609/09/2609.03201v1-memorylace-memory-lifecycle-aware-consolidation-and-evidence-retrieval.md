## 摘要
长期大语言模型代理必须在交互过程中保留信息，同时区分重复出现的证据、历史状态、更新和未解决的矛盾。现有的文本记忆系统能够高效检索语义相关的记忆，但往往使这些关系隐式化，而更丰富的结构化方法则通过全局图、层次抽象或反思来建模这些关系，但复杂度较高。我们提出了MemoryLACE（MemLACE），一个轻量级记忆框架，通过稀疏合并、取代和矛盾关系显式建模文本证据的生命周期，同时保留原子自然语言记忆及其来源。不同于独立检索记忆，MemLACE重构了关系感知的证据单元，为下游推理呈现当前、历史、支持和冲突的证据。在BEAM和StructMemEval上，使用开放权重和专有LLM骨干模型，MemLACE在同骨干比较中取得了最高整体性能，同时相对于最强反射式记忆基线Hindsight，在BEAM上的端到端运行时间减少了66.6%。消融研究表明，生命周期扩展和时间感知是这些增益的主要贡献者。综合来看，结果表明，显式建模文本证据的局部生命周期足以显著改善长期记忆推理，而无需全面的知识图谱或全局反思。

## Abstract
Long-term LLM agents must preserve information across interactions while distinguishing repeated evidence, historical states, updates, and unresolved contradictions. Existing textual memory systems retrieve semantically relevant memories efficiently but often leave these relationships implicit, whereas richer structured approaches model them through global graphs, hierarchical abstractions, or reflection at greater complexity. We introduce MemoryLACE (MemLACE), a lightweight memory framework that explicitly models the lifecycle of textual evidence through sparse merge, supersession, and contradiction relations while preserving atomic natural-language memories and their provenance. Rather than retrieving memories independently, MemLACE reconstructs relation-aware evidence units that expose current, historical, supporting, and conflicting evidence for downstream reasoning. Across BEAM and StructMemEval, using open-weight and proprietary LLM backbones, MemLACE achieves the highest overall performance in same-backbone comparisons while reducing end-to-end runtime on BEAM by 66.6% relative to Hindsight, the strongest reported reflective-memory baseline. Ablation studies identify lifecycle expansion and temporal awareness as the principal contributors to these gains. Together, the results demonstrate that explicitly modeling the local lifecycle of textual evidence is sufficient to substantially improve long-term memory reasoning without requiring comprehensive knowledge graphs or global reflection.

### 1. 核心问题与研究动机

- **问题背景**：长期运行的大语言模型（LLM）代理需要在多轮会话、跨会话的交互中持续记忆和更新用户信息，包括偏好、计划、约束、任务进度及已建立的事实。然而，仅仅"检索相关文本"是不够的，因为新证据与旧记忆之间存在三种复杂关系：**重复**（重申同一事实）、**取代**（新信息替代旧状态）、**矛盾**（同一范围内不可兼容的声称）。可靠的记忆系统必须能区分这些关系，并向推理模型呈现一个有序、演化中的证据图景。
- **现有方法的两难**：
  - **扁平文本式记忆系统**（如 SimpleMem、Mem0）：存储与检索高效，但记忆之间的关系是隐式的，模型面对多个独立文本片段时难以自行推断其演化关系（如"哪个是最新状态""两个声称是否冲突"）。
  - **结构化/层级化/反思式系统**（如 A-MEM、Zep、Hindsight、MemOS）：显式建模语义、因果或层级关系，但需要构建全局知识图谱、抽象层级或全局反思阶段，工程复杂度和运行成本高。
- **核心研究问题**：能否在不构建全面全局结构的前提下，仅通过显式建模**局部证据生命周期**（合并、取代、矛盾三种关系），即显著提升长期记忆推理能力？

### 2. 方法论：MemoryLACE 框架

#### 2.1 核心思想

MemoryLACE 采取"扁平文本记忆与全面结构记忆之间的轻量中间路线"：将记忆保持为**原子化的自然语言条目**并携带来源信息，仅在需要解释证据演化时建立**稀疏的局部生命周期关系**。它不做全局归一化的知识图谱，也没有专门的全局反思阶段。

#### 2.2 记忆表示

每个记忆条目定义为六元组：
> **mᵢ = (xᵢ, τᵢ, zᵢ, pᵢ, aᵢ, Rᵢ)**

- **xᵢ**：原子化的自然语言陈述（单条显式证据），脱离原对话上下文仍可独立理解；
- **τᵢ**：证据支撑的时间元数据（如事件发生时间或有效期限）；
- **zᵢ**：轻量元数据（实体、关键词、主题、地点等）；
- **pᵢ**：来源信息（支持该记忆的对话轮次标识符）；
- **aᵢ**：活动状态（是否属于当前有效的记忆集合）；
- **Rᵢ**：生命周期关系引用集合（零个或多个**合并、取代、矛盾**关系）。

全部记忆构成稀疏关系图 **G = (M, E)**，其中 E 仅含三种关系：有向的**取代边**（新→旧、旧→新双向均存）以及对称的**合并边**与**矛盾边**。

#### 2.3 Stage I：记忆构建与整合（写路径）

1. **记忆构建**：采用类似 SimpleMem 的滑动窗口方法（20 轮窗口、2 轮重叠），将对话转换为原子化独立记忆；重叠导致的重复提取被合并，来源信息被整合；来自不同轮次的真实重复则保留为独立记忆以待合并。
2. **候选与关系选择**：对每条新记忆，先进行语义相似度和同实体匹配，再扩展至相关记忆的一跳生命周期邻居，形成候选集 C(m_new)；用交叉编码器对候选集重排（只影响比较顺序，不决定关系）；随后由整合模块**每次仅选择一个关系策略和最多一个目标记忆**：
   > **r ∈ {merge（合并）, update（更新/取代）, contradict（矛盾）, no action（无操作）}**
   - **merge**：同一事实的重复证据；
   - **update**：同一状态的时序变更（新取代旧）；
   - **contradict**：同一范围内不兼容的声称；
   - **no action**：相互独立的记忆。
3. **生命周期状态更新**：发生 update 时，旧记忆转为非活动（aₒ ← 0），新记忆成为活动链头（aₙ ← 1），并建立双向取代边；矛盾记忆保持活动状态并建立对称矛盾边；默认采用**链接式合并**策略——合并的记忆保留原始文本和来源，仅增加双向合并引用，而"紧凑式合并"则会丢弃原文、合成单条新记忆（作为对比变体）。
4. **局部批量演化**：对每组新加入的记忆进行一次"联合审查"，修复仅在同时观察多条新记忆时才能发现的关系（如一条记忆与多条旧记忆相关），但只调整关系与活动状态，不重写记忆文本。

#### 2.4 Stage II：证据检索与上下文构建（读路径）

1. **混合活动记忆检索**：仅对活动记忆进行检索，融合四个通道——语义相似度、关键词匹配、结构化模板相关性、主题相关性——并使用**倒数排名融合（RRF）** 合并排序：
   > **s_RRF(m) = Σ_c 1 / (k + rank_c(m))**
   
   初始检索限于活动记忆，避免被取代的旧状态干扰。
2. **生命周期扩展与证据单元构建**：每个活动锚点沿取代链（受限于 80 节点）回溯历史状态，并沿矛盾边（最多 4 条）寻找冲突证据；相关记忆被聚类为**证据单元**——由取代、矛盾、合并边连接的连通组件构成，取代链按从旧到新排列，矛盾对保持并列呈现。
3. **链感知重排与上下文打包**：对**整个证据单元**而非单个文本片段进行重排打分（保证关系相连的记忆被联合评估而非彼此竞争），在上下文预算内优先保留完整的证据单元，超预算时丢弃单元内优先级较低的记忆，但保证取代链顺序不被破坏。
4. **证据导向的答案生成**：打包的上下文按生命周期顺序呈现，向 LLM 明确区分当前、被取代和冲突的记忆。模型无需从无序文本片段中自行推测关系。

### 6. 主要结论与发现

- **整体性能**：在 BEAM 100K 上，MemoryLACE 在 Qwen3.5-4B 与 Qwen3.5-9B 两种骨干下均取得同骨干最优整体准确率（4B：45.4% vs. Hindsight 40.1%；9B：51.9% vs. Hindsight 50.3%）。在 StructMemEval 上，MemoryLACE 以 52.08% 超越 Mem-Agent 的 35.00%（+17 个百分点以上）。
- **性能分布特征**：MemoryLACE 的优势集中在需要**联合考量多条相关记忆**的能力上——偏好遵循、戒断、多跳推理、事件排序和指令遵循；而知识更新仅获边际提升（因为单一活动记忆查询已足够，额外分组收益有限）。Hindsight 在时序推理、信息抽取和摘要上仍有优势，反映两者设计取舍不同。
- **消融发现**：**生命周期扩展**（移除后 −5.16 个百分点）与**时间感知**（移除后 −4.97 个百分点）是最大的两个贡献来源，且两者作用机制完全不同——前者决定"检索到哪些相关记忆"（影响知识更新、多跳与时序推理），后者决定"记忆间的差异被理解为矛盾还是有序变化"（影响矛盾解决与偏好遵循）。两者不可互换。
- **效率发现**：在 Qwen3.5-9B 上，MemoryLACE 总运行时间较 Hindsight 减少 **66.6%**（约 3 倍加速），最大节省来自记忆构建阶段（3.02 倍加速），因为 MemoryLACE 用有界候选比较和局部批量修复取代了 Hindsight 的全局反思阶段。
- **核心理论结论**：显式建模文本证据的**局部**生命周期足以在推理上显著超越全局反思或全面知识图谱的方法——长期记忆的关键挑战不在于更丰富的全局结构，而在于保留"证据如何随时间演化"。

### 7. 方法亮点

- **极简但表达力强的关系建模**：仅用三种稀疏关系（合并、取代、矛盾）就捕获了证据演化的核心模式，避免全局知识图谱的高额维护开销。
- **有界、增量的整合决策**：每次只对一个"关系-目标"对做出单一决策，降低决策复杂度，提高了整合正确性；辅以批量步骤修复跨条目遗漏关系，兼顾了可检查性与完备性。
- **保留原子自然语言 + 来源追踪**：记忆内容不被改写（默认配置下），取代和矛盾不删除原文，支持历史回溯且可审计。
- **关系感知的证据单元检索**：这是关键创新——按"组/单元"而非单条文本进行重排与打包，使依赖关系的记忆在进入 LLM 上下文之前就已按其生命周期结构组织好，而无需 LLM 自行从无序文本中推断关系。
- **时间感知的整合**：利用事件时间（而非对话时间）区分"有序更新"与"真正矛盾"，是消融研究中证明的关键能力。
- **效率与性能兼得**：实验证明了"轻量结构 + 局部建模"能达到甚至超越重度反思/图结构方法的效果，为实际部署提供了更经济的方案。
- **消融诊断清晰**：消融实验不仅报告了性能分数差异，还深入分析了不同组件影响不同认知能力（如生命周期扩展影响知识更新与多跳，时间感知影响矛盾解决与偏好），具有较好的解释性。

### 8. 不足与局限

- **任务覆盖的短板**：
  - 计数推理在 StructMemEval 上得 0%（说明纯粹依赖证据单元无法解决全局数值累积类问题）；
  - 推荐任务仅 8.33% 的场景级通过率（需跨众多偏好信号做全局统计与排名）；
  - Hindsight 在时序推理（+8.7 分）、信息抽取（+5.2）与摘要（+4.9）上仍明显优于 MemoryLACE，说明原子记忆 + 局部证据打包的方式并不利于需要全局信息重构或精确时间区间计算的任务。
- **实验局限**：
  - StructMemEval 仅对比了一个基线（Mem-Agent），代表性和说服力有限；
  - BEAM 的后端仅限 Qwen 模型族，跨模型族泛化结论不足；
  - 时间感知消融中，"时间感知"组件定义较泛、影响路径依赖推理级分析而非直接实验控制，因果解读需谨慎。
  - 论文未单独分析证据单元打包中超预算时截断历史记忆对下游推理的具体影响。
- **架构实现的潜在复杂性与可扩展性**：
  - 合并/取代关系虽稀疏，但长时运行（百万级记忆）下关系图的存储与遍历开销、候选集中的一跳邻居扩展的复杂度尚未充分讨论；
  - 记忆整合依赖 LLM 做出 update/contradict 决策，当证据本身表述模糊或跨度极长时，误判关系（如将矛盾误判为更新）可能导致信息沉默丢失（active 状态被错误关闭）——这类错误级联风险未被评测；
  - 原子化记忆的质量直接取决于基础记忆构建环节的效果，MemoryLACE 本身没有防御低质量提取的机制。
- **应用限制**：适用于以"证据演变"为核心特征的交互场景（偏好修正、计划变更、事实更新），但不适合需要全局统计聚合、深层数值推理或其他专用计算能力的任务；论文作者也坦承未来需引入专门的聚合算子（计算器/代码执行工具）来覆盖这类场景，说明当前方案本身在这些能力上是盲区。
- **权重争议的可能性**：取消侧通道"默认合并策略（链接式）优于紧凑式"的结论依赖单一消融对，而紧凑式在矛盾解决上反而更好（44.1 vs. 40.3），表明两种策略各有利弊，不同应用场景可能需要不同的默认配置。
