## 摘要
传统大语言模型（LLM）的作用范围局限于单个用户会话，使其知识仅限于单次对话，并无法学习随时间演变的用户偏好。现有的智能体记忆系统缓解了这一限制，但通常在单用户层面运行，限制了可跨用户共享以改进下游响应的公共知识。我们提出 AIM（Agentic Interoperable Memory，智能体可互操作记忆），一个统一且隐私感知的记忆框架，使多智能体、多用户 LLM 系统能够持久管理私有记忆与共享记忆。AIM 动态地将信息分类为私有（仅限一个用户且其他用户不可访问）或公共（所有用户均可访问）。它实施索引级访问控制，使私有记忆仅能由其所有者检索，从而在保护敏感数据的同时，允许有益的共享知识改进协调性与一致性。我们还提出 MUMBench（Multi-User Memory Benchmark，多用户记忆基准），一个包含四个领域中私有与可共享信息的多用户交互数据集。据我们所知，MUMBench 是首个旨在评估多用户环境中多种记忆操作（包括检索、创建、更新和删除）的公开数据集。在 MUMBench 上的三次独立运行中，AIM 实现了 96.0% 的可见性分类准确率、58.8% 的严格操作准确率和 70.5% 的状态感知操作准确率。

## Abstract
Traditional large language models (LLMs) are scoped to individual user sessions, limiting their knowledge to a single conversation and preventing them from learning user preferences that evolve over time. Existing agentic memory systems address this limitation but generally operate at the individual-user level, restricting the public knowledge that could be shared across users to improve downstream responses. We introduce AIM (Agentic Interoperable Memory), a unified, privacy-aware memory framework that enables multi-agent, multi-user LLM systems to persistently manage private and shared memory. AIM dynamically classifies information as private, scoped to one user and inaccessible to others, or public, accessible to all users. It enforces index-level access controls so that private memories are retrievable only by their owner, protecting sensitive data while allowing beneficial shared knowledge to improve coordination and consistency. We also introduce MUMBench (Multi-User Memory Benchmark), a dataset of multi-user interactions containing private and shareable information across four domains. To our knowledge, MUMBench is the first public dataset designed to evaluate multiple memory operations, including retrieval, creation, update, and deletion, in a multi-user environment. Across three independent runs on MUMBench, AIM achieves 96.0% visibility classification accuracy, 58.8% strict operation accuracy, and 70.5% state-aware operation accuracy.

## 1. 核心问题与研究动机

- **背景**：主流 LLM 被限定在单个用户会话内，模型知识仅来自单次对话，无法学习随长时间演化的用户偏好。
- **现状缺陷**：现有智能体记忆方案（MemGPT、A-MEM、Mem0、MemInsight、CAIM 等）本质上是**单智能体、单用户**的，缺少多用户访问控制与跨智能体同步；多数智能体仍以无状态方式运行，导致重复交互、上下文碎片化、个性化受限、缺乏统一记忆生命周期。
- **核心矛盾**：一方面需要跨用户共享公共知识以提升协调性、一致性与整体智能；另一方面又必须严格保护用户的私有敏感信息。二者需要同时满足。
- **整体含义**：论文提出 **AIM（Agentic Interoperable Memory）**——一个统一、隐私感知、系统无关的可互操作记忆框架，使多智能体、多用户 LLM 系统能持久管理私有与共享记忆，并配套提出首个多用户记忆基准 **MUMBench**。
- **与已有工作的三点差异**：
  - 用 LLM 分类**自动推断可见性标签**，而非要求用户手动标注；
  - 在**检索索引层面确定性地**执行访问控制（而非概率性过滤），使私有记忆对非所有者结构性不可达；
  - 支持**多标签操作检测**（一条消息可同时触发写入与检索），而 Mem0 等假设每轮仅一个操作。

## 2. 方法论

### 2.1 核心思想

AIM 将多智能体记忆管理分解为共享演化存储之上的**两条级联推理路径**：

- **写路径**：操作检测 → 结构化抽取 → 可见性分类 → 语义去重 → 持久化；
- **读路径**：可见性约束稠密检索 → 标签级重打分 → LLM 重排序 + 时效融合。

两条路径均受统一的可见性谓词 V 约束。

### 2.2 问题形式化

- 用户集 U、智能体集 A、记忆存储 M。每条记忆 $m_i$ 包含：内容 $c_i$、稠密嵌入 $e_i \in \mathbb{R}^d$、拥有者 $u_i$、创建智能体 $a_i$、可见性 $v_i \in \{\text{PUBLIC}, \text{PRIVATE}\}$、关键词标签集 $\tau_i$、时间戳 $t_i$、辅助元数据 $\mu_i$。
- 可见性谓词：$V(u, m_i) = (v_i = \text{PUBLIC}) \lor (v_i = \text{PRIVATE} \land u_i = u)$。
- 写操作附加所有权要求：更新/删除仅允许创建用户（或无用户上下文时创建智能体）执行，防止跨用户覆盖（即使对公共记忆）。
- 该设计在**单一共享索引**上实现多租户隔离，无需为每个用户单独建库。

### 2.3 关键技术细节

- **多标签意图检测 $f_{op}$**：将消息映射到 $\{C, R, U, D\}$ 的子集或 NONE。例如"我刚搬到旧金山，能推荐晚餐地点吗？"→ `{C, R}`。通过 in-context learning 实现，含操作分类体系、各标签（含多标签）few-shot 示例，以及**隐私守卫**（试图诱导他人私有信息的查询映射为 ∅），并用约束解码限制输出标签范围。
- **结构化记忆抽取 $f_{ext}$**：输出变长元组列表 $\{(c_j, \tau_j, \mu_j)\}$，即文本内容 + 显著关键词标签 + 可选溯源元数据（时间上下文、领域类别），用 JSON 模式约束解码。
- **隐私感知可见性分类 $f_{cls}$**：由带归纳偏置的提示 LLM 输出 PUBLIC / PRIVATE。公共信号包括集体事件（团队会议、截止日期）、组织公告、共享资源；私有信号包括个人偏好、个人日程、私信、敏感数据（健康、财务）。该标签决定后续去重范围、检索过滤与更新/删除权限。
- **上下文语义去重 $f_{dedup}$**：三分类 CREATE / UPDATE（返回指向旧记忆 $\hat{m}$ 的指针）/ NO-OP。先检索**作用域受限比较集** $M_v$：公共候选对比全部公共记忆，私有候选仅对比同用户私有记忆——这是隐私保护设计，防止通过去重信号发生跨用户信息泄露。整个比较集序列化后由 LLM 单次前向完成语义重叠与时间取代判断。
- **记忆表示与索引**：嵌入维度 $d=3072$；标签增强嵌入 $e_i = \phi(\text{concat}(c_i, \tau_{i,1}, \dots))$，将内容与关键词联合编码以改善关键词型查询的检索；向量索引用 HNSW 做近似最近邻，用户/智能体/可见性/标签等元数据字段独立索引以支持谓词下推。
- **级联检索（三阶段）**：
  - **Stage 1 可见性约束稠密检索**：将 $V(u, \cdot)$ 作为服务端过滤器推入向量索引，返回按余弦相似度排序的 top-k 候选（HNSW 复杂度 $O(\log|M|)$），他人私有记忆**从不进入候选集**。
  - **Stage 2 标签级语义重打分**：$s_{tag}(q, m_i) = \cos(\phi(q), \phi(\tau_i))$，采用**双阈值门控**（$s_{vec} \ge \tau_{vec}$ 且 $s_{tag} \ge \tau_{tag}$）作为精度闸门，仅两者都满足者进入重排。
  - **Stage 3 LLM 重排序 + 时效融合**：逐点 LLM 打分 $s_{rel} = g_\theta(\cdot) \in [0,1]$，采用保守评分准则（>0.7 需直接且具体相关，不确定默认 ≤0.4），反映"呈现无关记忆比漏掉边缘相关记忆危害更大"的成本不对称；再与归一化时效分 $s_{rec} = (t_i - t_{min})/(t_{max} - t_{min})$（区间退化时取 0.5）做**算术平均**得到最终分 $s_{final} = (s_{rel} + s_{rec})/2$，排序后截断到 k。
- **LLM 调用预算**：Stage 1、2 仅用嵌入查询，只有 Stage 3 调用 LLM（每个存活候选一次），双阈值过滤会大幅剪枝，实际打分数量远小于 k。
- **模块化**：$f_{op}, f_{ext}, f_{cls}, f_{dedup}, \phi, g_\theta$ 及向量索引均由抽象接口定义、经配置驱动工厂实例化，可独立替换或禁用（如替换专有 LLM 为开源模型、HNSW 换其他 ANN 算法）。
- **生命周期算法（Algorithm 1）**：意图检测 → 若含 R 则检索 → 若含 C/U 则抽取、逐条分类、构造作用域受限比较集、去重并执行创建/更新（更新需通过 $V(u,\hat{m}_j)$）→ 若含 D 则在 $V(u,\cdot)$ 约束下删除最相似记忆 → 返回更新后的存储与检索集。

## 3. 实验设计

### 3.1 基准：MUMBench（本文提出）

- **构成**：672 条人工验证、按时间顺序排列的用户—智能体交互，覆盖 **93 个唯一用户**、**205 条唯一记忆**、**150 条私有记忆 / 56 条公共记忆**、**60 条对抗查询**。
- **四个领域**：Coding（150）、Customer Support（218）、Education（160）、Travel Planning（144）。
- **操作分布**：CREATE 205、READ 152、UPDATE 117、DELETE 77、NOOP 131。
- **构造方式**：用 GPT-4o 合成生成（含基础提示 + 四个领域专用提示），再由人类研究者按验证清单逐条校验（记忆完整性、访问控制、变异性、领域特定检查），确保时序正确、无重复记忆、操作与载荷正确、隐私分类无误、无未授权私有记忆访问。
- **独特性**：区别于 LOCOMO（单用户、多会话）与 MemoryAgentBench（单智能体检索/测试时学习/长程理解/选择性遗忘），MUMBench 是首个评估**多用户环境下完整决策流水线**（操作判定 + 载荷执行 + 私有/公共分类 + 对抗查询下私有记忆不可外泄）的公开基准。

### 3.2 评估指标（分层评分框架）

- **严格准确率**：金标与预测操作经"规范归一化"（丢弃 no-op、空结果读与空目标删除塌缩为 no-op、create/update/read 重数截断为 1、delete 重数保留）后作为规范多重集完全匹配。
- **状态感知准确率**：维护预测回合的实时镜像，按实际存储状态校正金标（目标未创建的 update 放宽为 create，针对缺失内容的 read/delete 放宽为 no-op），并取 max(strict, 状态校正后匹配) 以避免误罚。
- **Judge-decision 准确率**：strict 与 state-aware 均为 0 时，由全上下文 LLM 裁判给出 exact / defensible / wrong 三档判定，作为操作准确率上界估计。
