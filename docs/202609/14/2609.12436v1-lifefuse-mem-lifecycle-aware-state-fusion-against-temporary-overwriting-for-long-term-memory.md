## 摘要
长期运行的 LLM 智能体需要能够在多次交互中保持连贯内部状态的记忆机制。我们研究一种生命周期标注的记忆设定：训练期间由写入片段提供生命周期元数据，评估期间使用相位感知读出。该设定反映了区分以下两类信息的需要：应在未来交互中持续产生影响的信息，与仅应影响当前上下文的信息。这些生命周期之间的不匹配可能导致临时信息覆盖持久知识，从而在持续型智能体中引发行为漂移。在这一设定下，我们提出 LifeFuse-Mem，一种生命周期感知的神经记忆框架，它根据信息的时间承诺对信息进行分离。LifeFuse-Mem 使用专用记忆组件和生命周期感知更新，使稳定知识与瞬态知识能够在本地演化，而不会将临时上下文转换为持久状态。在受控的反覆盖基准上，LifeFuse-Mem 提升了受获取控制的保留效果并减少了临时覆盖；在两个公开的长记忆基准上，它仍具有广泛的竞争力。这些结果表明，显式的生命周期信号有助于诊断并缓解紧凑型在线记忆中的覆盖问题。

## Abstract
Long-running LLM agents require memory mechanisms that maintain coherent internal states across interactions. We study a lifecycle-labeled memory setting in which write episodes provide lifecycle metadata during training, and phase-aware readout is used during evaluation. This setting reflects the need to distinguish information that should remain influential across future interactions from information that should affect only the current context. A mismatch between these lifecycles can cause temporary information to overwrite durable knowledge, leading to behavioral drift in persistent agents. Within this setting, we introduce \textbf{LifeFuse-Mem}, a lifecycle-aware neural memory framework that separates information according to its temporal commitment. LifeFuse-Mem uses dedicated memory components and lifecycle-aware updates to allow stable and transient knowledge to evolve locally without converting temporary context into durable state. On the controlled anti-overwrite benchmark, LifeFuse-Mem improves acquisition-controlled retention and reduces temporary overwrite; on two public long-memory benchmarks, it remains broadly competitive. These results suggest that explicit lifecycle signals can help diagnose and mitigate overwrite in compact online memory.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：基于大语言模型（LLM）的智能体正从短时助手演变为持续交互、积累经验、执行长时任务的持久型系统。这类系统依赖记忆机制在上下文窗口之外维持连贯的内部状态（用户偏好、行为策略、累积知识等）。
- **核心问题**：与常规存储系统不同，智能体记忆必须处理**时间有效性根本不同**的信息——部分信息应跨未来交互持续生效（持久知识），另一部分仅应影响当前情境（临时上下文）。现有记忆系统大多忽视这一"生命周期"维度，导致一个根本性失败模式。
- **失败模式定义**：作者提出 **临时覆盖（Temporary Overwrite）**——当生命周期不同的信息经同一记忆通路存储与更新时，临时上下文会覆盖持久知识。例如：智能体的持久策略要求"外部操作前需用户确认"，但某次调试会话中用户临时指示"沙箱内可跳过确认"。若无生命周期感知，该临时指令可能被固化为持久更新，导致智能体逐步偏离原定行为，且这种漂移是**静默发生**的，会损害行为一致性与用户信任。
- **根因分析**：临时覆盖的根源在于记忆表示中**缺乏生命周期解耦**。现有神经记忆机制通常将交互历史压缩到共享隐状态，并用统一动态更新，导致瞬态假设与持久知识争夺同一表征容量。因此，解决该问题不仅需要扩大容量或改进检索，而需要**显式按信息影响时长分离的记忆架构**。
- **研究定位**：作者研究一个**受控但具诊断性的生命周期标注记忆设定**：写入片段在训练时提供生命周期元数据，评估时使用相位感知读出。该设定旨在显式生命周期信号下隔离临时覆盖问题，**不声称能从无标注历史中自主发现生命周期**。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
LifeFuse-Mem 通过**写入、训练、读出**三个环节施加生命周期控制，在紧凑在线记忆状态内实现生命周期感知分离，而无需依赖外部键值表返回答案。框架包含三部分：可塑性/稳定性子空间划分、监督式永久路由器、相位感知保护态读出。

### 关键技术细节

- **生命周期感知子空间划分**：
  - 不采用对原始秩维度的固定切分，而是为每个注入注意力模块学习一个近似正交基：设 $R_l \in \mathbb{R}^{r\times r}$ 为可学习方阵，$Q_l = \mathrm{orth}(R_l)$ 为正交化基（前向传播时通过 QR 分解实现），满足 $Q_l^\top Q_l = I$。
  - 将记忆读、键、值向量旋转到该基下：$\tilde{q}_t = Q_l^\top q_t^m$，$\tilde{k}_t = Q_l^\top k_t^m$，$\tilde{v}_t = Q_l^\top v_t^m$。
  - 前 $r_A$ 个坐标定义为**可塑性子空间 A**，剩余 $r_B = r - r_A$ 个坐标定义为**稳定性子空间 B**。实验中 $r=8$，$r_A = r_B = 4$。
  - 通过正交正则项 $L_{orth} = \frac{1}{Lr^2}\sum_l \|R_l^\top R_l - I\|_F^2$ 保持子空间可分离，同时允许模型学习更合适的坐标系。
  - 记忆状态 $S_t \in \mathbb{R}^{r\times r}$ 的在线更新采用行级保留、擦除、写入系数的仿射形式：
    $S_t = \kappa_t \odot_{row} S_{t-1} - \epsilon_t \odot_{row}[(S_{t-1}\tilde{k}_t)\tilde{k}_t^\top] + \omega_t \odot_{row}[\tilde{v}_t\tilde{k}_t^\top]$

- **永久路由与子空间写入**：
  - 对每个写入 token 预测永久路由权重 $\rho_t = \sigma(w_r^\top h_t + b_r)$。
  - 路由目标来自片段元数据：永久生命周期 token 标 $y_i=1$，临时标 $y_i=0$，无标注者被掩码。路由监督损失为二元交叉熵 $L_{route}$。
  - 路由器通过**行缩放**影响写入：可塑性行对所有 token 可写；稳定行使用临时尺度与永久尺度的插值 $a_{t,j} = 1$（$j\le r_A$），$a_{t,j} = a_{tmp} + \rho_t(a_{perm} - a_{tmp})$（$j > r_A$）。主运行采用 `permanent_boost` 模式，$a_{tmp}=0$、$a_{perm}=1$。
  - 行缩放将基础系数转换为 $\kappa_{t,j} = 1 - a_{t,j} + a_{t,j}\lambda_{t,j}$，$\epsilon_{t,j} = \omega_{t,j} = a_{t,j}\beta_{t,j}$。因此高 $\rho_t$ token 可更新可塑性与稳定行，低 $\rho_t$ token 主要更新可塑性行。
  - 此外实施**子空间键隔离**：常规在线写入时稳定键坐标被衰减（复现运行中为 0.5），使写入在键轴上也偏好可塑性坐标。

- **片段式学习目标**：
  - 采用"先写后读"目标：模型先消费写入消息更新记忆到 $S_{write}$，然后在**禁用写入**的情况下回答最终助手目标，强制答案依赖已存储状态。
  - 总目标：$L = L_{CE} + \lambda_{route}L_{route} + \lambda_{orth}L_{orth} + \lambda_{hc}(u)L_{hc} + \lambda_{ret}L_{ret} + \lambda_{sp}L_{sp}$。
  - 硬候选损失 $L_{hc}$：给定正确答案 $y^+$ 与难负例 $y^-$，鼓励负例损失至少比正例大 $m_{hc}$，并在早期答案学习稳定后渐入。
  - 永久样本额外使用保留排序损失 $L_{ret}$，施加永久值优于临时/被拒候选的压力。
  - 稀疏惩罚将平均写门保持在较小目标 $\beta_0$（复现运行中为 0.05）。

- **保护态融合与生命周期读出（仅限受控协议）**：
  - 在 Phase A 后检查点记忆状态 $S_A$，覆盖后状态为 $S_{AB}$，构造稳定行保护态 $S_{stable}$：可塑性行取自 $S_{AB}$，稳定行取自 $S_A$。
  - 对永久查询，候选得分在 $S_A$ 与 $S_{stable}$ 下分别计算长度归一化 token 对数概率，融合得 $s_{fuse}(y) = \alpha s_A(y) + (1-\alpha)s_{stable}(y)$，主融合权重 $\alpha = 0.70$。
  - 对临时查询，不做保护或融合，直接用完整覆盖后状态 $S_{AB}$ 评分，使读出匹配查询的预期生命周期。

## 6. 主要结论与发现

- **反覆盖效果显著**：相比 δ-Mem，LifeFuse-Mem 在受获取控制保留率 Ret. 上，Qwen3-4B 从 57.72% 提升至 63.71%，SmolLM3-3B 从 60.27% 提升至 69.39%；同时 Ovr. 分别从 42.28% 降至 36.29%、从 39.73% 降至 30.61%。说明对已获取的永久事实，LifeFuse-Mem 更不容易在 Phase B 后返回冲突临时值。
- **端到端永久查询准确率提升有限**：Qwen3-4B 上从 19.32% 微升至 20.12%，SmolLM3-3B 上从 19.95% 微降至 19.65%。表明 LifeFuse-Mem 主要改善**条件于成功获取后的抗覆盖能力**，而非大幅提升永久查询整体正确概率。
- **临时查询行为保持稳定**：Temp. 在各方法间相近，说明保留增益并非来自简单压制 Phase B 信息。
- **公开基准兼容性良好但不均匀**：Qwen3-4B 上 LoCoMo 从 41.24% 升至 42.41%，MemoryAgentBench 从 31.83% 微升至 32.24%；SmolLM3-3B 上 LoCoMo 从 30.65% 大幅升至 38.30%，MemoryAgentBench 从 20.13% 微升至 20.21%。但类别级结果分化（如 TTL 提升、LRU 与 SF 下降）。
- **消融结论**：**路由监督是最关键组件**，移除后 Ret. 在 Qwen3-4B 降至 58.68%、SmolLM3-3B 降至 59.45%，Ovr. 升至 41.32% 与 40.55%。稳定行与永久保留损失提供较小但一致的增益；硬候选损失主要影响候选校准，对 Ret./Ovr. 影响不一致。

- **给出了清晰的组件归因**：消融结论明确指向**路由监督为最关键组件**，稳定行与保留损失提供一致的小增益，硬候选损失影响候选校准而非保留率。这种归因有助于后续研究者判断哪些机制是必要的、哪些是可选的。

## 8. 不足与局限

- **端到端收益有限，存在"条件性增益"问题**：核心指标 Ret./Ovr. 改善明显（如 SmolLM3-3B 上 Ret. +9.12 个百分点、Ovr. −9.12 个百分点），但**端到端永久查询准确率几乎不变**（Qwen3-4B 19.32%→20.12%，SmolLM3-3B 19.95%→19.65%）。这说明方法主要改善的是"已成功获取后的抗覆盖能力"，而获取（acquisition）本身仍是瓶颈。绝对准确率约 20% 也意味着整体任务仍远未解决，生命周期机制的价值被上游失败所掩盖。

- **依赖显式生命周期标注，实用性受限**：训练时需要片段级生命周期元数据（永久/临时标签），评估时需要相位感知读出（Phase A 检查点 $S_A$ 与覆盖后 $S_{AB}$ 的显式区分、融合权重 $\alpha$）。在真实长时交互中，这类标注通常不可得，且"相位"边界往往模糊。作者虽已声明此为受控设定，但这实质上限制了方法的即插即用性。

- **公开基准结果不一致，泛化性存疑**：LoCoMo 与 MemoryAgentBench 上整体增益较小且**类别级分化明显**（如 TTL 提升但 LRU 与 SF 下降）。这提示生命周期控制机制可能与某些记忆能力（如长程理解、选择性遗忘）存在张力或干扰，而论文对此类负面结果的机理解释不足。

- **骨干规模受限**：仅在 3B–4B 的两个相对较小模型上验证，未涉及更大模型。生命周期解耦是否在更大模型中仍有必要、是否与模型容量存在替代关系，尚无证据。

- **受控基准与真实场景存在差距**：自建基准为合成、结构化的 1,000 片段设定（固定 4 条保护事实、6 个冲突键、4 轮覆盖），虽针对性强，但真实长时交互中的覆盖往往是渐进的、隐式的、多来源的，方法的鲁棒性有待检验。

- **算力与实现细节透明度不足**：正文未报告 GPU 型号、数量、训练时长与总算力开销，关键超参数（$a_{tmp}$、$a_{perm}$、$\beta_0$、$\alpha$、各 $\lambda$）仅指向附录，削弱了独立复现与成本评估的可行性。

- **读出阶段对检查点的人工依赖**：保护态 $S_{stable}$ 需显式保存 Phase A 检查点并做行级拼接，融合权重 $\alpha=0.70$ 为人工设定（虽有敏感性消融）。这更接近一种"推理时的记忆状态编辑"策略，与"在线自适应的生命周期记忆"的理想形态仍有距离。

## 9. 对后续研究的启发

- **从"防覆盖"走向"生命周期发现"**：本工作把问题隔离在标注设定下，最自然的延伸是让智能体**从无标注交互中自主推断信息的生命周期**（如通过指令的语境线索、用户显式/隐式信号、跨会话一致性检验），这将决定该方向能否真正落地。

- **获取与保留需协同优化**：由于端到端收益受限于获取瓶颈，未来可探索将生命周期解耦与更强的记忆获取/写入策略联合设计，而非仅优化抗覆盖。

- **生命周期机制与其他记忆能力的张力值得深究**：LRU、SF 等类别下降提示，可塑性/稳定性划分可能以牺牲某些能力为代价。理解"保护持久知识"与"选择性遗忘"之间的权衡，可能催生更精细的多目标记忆动力学。

- **指标体系的推广**：受获取控制的 Ret./Ovr. 与 Temp. 三件套，为记忆系统评测提供了一种可借鉴的范式——即在评估记忆保真度时，需先控制"是否获取成功"，再判断"是否被覆盖"，避免把获取失败误归因于覆盖。
