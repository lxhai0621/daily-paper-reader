## 摘要
长期对话智能体必须通过从冗长的对话历史中回忆信息来回答用户查询，然而直接使用完整历史成本高昂且往往不可靠，而压缩的记忆单元可能丢失问答所需的细粒度证据。受自传体记忆的重构观启发，我们提出 CueMem，一个线索引导的框架，它将提取的记忆记录视为检索线索而非自包含的证据，并从其源对话轮次中重构与查询相关的对话上下文。在记忆构建过程中，CueMem 从对话轮次中提取细粒度记忆线索，并将每条线索链接到其源轮次。在查询时，它检索与查询相关的线索，将其映射到源轮次锚点，并基于这些锚点在捕捉时间邻近性和语义相关性的轮次图上进行扩展，从而从原始对话中重构一个紧凑的证据上下文，用于 LLM 答案生成。在 LoCoMo 和 LongMemEval 上的实验表明，CueMem 始终优于具有代表性的长期记忆基线。进一步分析表明，与完整历史的 LLM 设置相比，基于图的上下文重构有助于恢复支持性对话证据，同时减少查询时的输入 token 数和延迟。这些结果凸显了检索线索作为自包含记忆证据的一种有效替代方案，可用于长期对话问答。

## Abstract
Long-term conversational agents must answer user queries by recalling information from extended dialogue histories, yet directly using the full history is costly and often unreliable, while compressed memory units may lose fine-grained evidence needed for question answering. Motivated by the reconstructive view of autobiographical memory, we propose CueMem, a cue-guided framework that treats extracted memory records as retrieval cues rather than self-contained evidence and reconstructs query-relevant dialogue context from their source turns. During memory construction, CueMem extracts fine-grained memory cues from dialogue turns and links each cue to its source turn. At query time, it retrieves query-relevant cues, maps them to source-turn anchors, and expands from these anchors over a turn graph that captures temporal proximity and semantic relatedness, reconstructing a compact evidence context from the original dialogue for LLM answer generation. Experiments on LoCoMo and LongMemEval show that CueMem consistently outperforms representative long-term memory baselines. Further analyses show that graph-based context reconstruction helps recover supporting dialogue evidence while reducing query-time input tokens and latency compared with the full-history LLM setting. These results highlight retrieval cues as an effective alternative to self-contained memory evidence for long-term conversational question answering.

## 1. 核心问题与研究动机

- **背景**：LLM 驱动的对话智能体在真实场景中往往面临长时、多轮对话，需要从冗长的历史中回忆信息来回答用户查询。
- **现有方案的两难**：
  - 直接使用完整对话历史：受上下文长度限制、噪声干扰、"lost-in-the-middle" 现象影响，推理延迟高且效果不可靠。
  - 压缩式记忆单元（分段、摘要、显著信息抽取）：容易丢失问答所需的细粒度证据；向量索引会将多个语义信号纠缠在单一稠密表示中，导致检索精度下降。
- **核心洞察**：现有系统多把检索到的记忆单元当作"自包含证据"直接用于生成，这与自传体记忆的"重构观"相悖——人类记忆并非完美存储，而是由线索引导、从更广泛的自传体知识库中**重构**出来。
- **论文含义**：提出将记忆记录视为"检索线索"而非"自包含证据"，通过线索定位源对话轮次，再从原始对话中重构证据上下文，兼顾证据完整性与查询效率。

## 2. 方法论

### 2.1 核心思想
CueMem 遵循 **线索 → 锚点 → 上下文（cue-to-anchor-to-context）** 的重构流程：离线从对话轮次抽取细粒度线索并链接源轮次；在线检索查询相关线索、映射为源轮锚点，在轮图上扩展重构紧凑证据上下文，供 LLM 生成答案。

### 2.2 关键技术与流程

- **记忆线索抽取（离线）**
  - 将每条线索实例化为关系三元组 $c_i = (t_i, \tau_i)$，其中 $t_i$ = (主语, 关系, 宾语)，$\tau_i$ 为源对话轮次指针。
  - 用 LLM 从每轮对话中抽取三元组（一轮可产生多条或无线索），再用嵌入模型编码为稠密向量用于检索与建图。

- **轮图构建（离线）**
  - 节点 = 对话轮次 $u_i$；边集 $E = E_{temp} \cup E_{sem}$。
  - **时间边**：连接时间窗口 $w$ 内的相邻轮次 $N_{temp}(v_i)=\{v_j \mid 0<|i-j|\le w\}$，保留局部对话连续性。
  - **语义边**：在线索级计算余弦相似度取 top-k 最近邻，再映射回各自源轮节点，建立跨距离的语义关联（线索级比轮次级更原子、干扰更小）。

- **上下文重构（在线）**
  - 编码查询 $q$，检索 top-$m$ 条最相似线索 $C_q$，其源轮指针构成锚点集 $A_q$。
  - 在轮图上从锚点做一跳扩展：$N_G(A_q)=\{j \mid \exists i\in A_q,(v_i,v_j)\in E\}$。
  - 证据上下文 $E_q=\{u_j \mid j\in A_q\cup N_G(A_q)\}$，按原始时间顺序排序后送入 LLM。
  - 生成形式化：$a = \text{LLM}(\text{Prompt}(q, E_q))$。

- **记忆管理**
  - 离线构建与在线重构分离，推理时不处理完整历史。
  - ADD：近实时插入新线索与源轮节点；DELETE：时间衰减或 LRU 策略；UPDATE：不设专门机制，新信息作为新线索加入，生成时通过"优先考虑最新证据"的指令处理冲突。

## 6. 主要结论与发现

- **性能优势**：CueMem 在 LoCoMo 上总体准确率 84.07%，超过最强基线 5.26%；在 LongMemEval 上 94.29%，超过最强基线 1.60%，两个数据集均取得最佳。

- **知识更新**：即使没有专门的 UPDATE 操作，CueMem 在知识更新类问题上仍最优，归因于线索重构的完整证据 + 简单"优先最新"指令，LLM 能自行识别并忽略过时信息。

- **泛化性**：多数基线只在单一数据集表现好，而 CueMem 在不同长度、结构与问题分布的对话上表现更一致。
