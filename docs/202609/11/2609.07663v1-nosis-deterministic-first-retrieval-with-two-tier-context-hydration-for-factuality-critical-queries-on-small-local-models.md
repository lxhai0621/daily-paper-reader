## 摘要
一个错误的数字比没有答案更糟。在事实性至关重要的领域——媒体中的受众指标、排期与版权；医疗中的剂量与检验值；金融与法律中的数字与引文——一个自信却捏造的值，比坦诚承认不确定更具破坏性。然而，这正是我们在小型本地语言模型上观察到的主要失效模式：即便上下文中已包含正确证据，模型仍会捏造看似合理的数字与时间戳。近期研究刻画了这一范式的真实局限：在 7B 参数以下，检索增强生成（RAG）的瓶颈并非检索质量，而是上下文利用。我们提出 Noesis，即 Noesis 架构中确定性优先的查询平面，它在生成之前完成所有确定性判断。其机制源自摄取架构（另有一项专利申请涉及该架构）：（a）生产端事实层，逐字呈现预计算的指标事实，不进行排序；（b）位置寻址与确定性跨源对齐，在查询时之前以零 LLM 成本完成解析；（c）将来源范围界定为归因约束，并配以多层命名引用路由；（d）双层上下文，支持由模型触发的逐字填充。在四项消融实验中，一个 2B 模型在事实完整性上与 35B 模型持平（所有运行均给出精确值；在缺失实体陷阱上零捏造数字）；在 2B 规模下，结构化检索比扁平 RAG 高出 11.4 个百分点；仅骨架上下文在提示缩小 20–30% 的情况下仍能保留定量答案；而填充可在约 8 秒内恢复逐字叙述，相比之下需约 29 秒。对于受监管领域，有两项性质至关重要：每个查询均在单次生成调用中完成解析，且每个报告值都可依构造追溯至其确切来源与位置。

## Abstract
A wrong number is worse than no answer. Across factuality-critical domains -- audience metrics, scheduling and rights in media; dosages and lab values in healthcare; figures and citations in finance and legal -- a confident but fabricated value is more damaging than an honest admission of uncertainty. Yet this is the dominant failure mode we observe on small local language models: even when correct evidence is present in context, models fabricate plausible numbers and timestamps. Recent work characterizes a real limit of this regime: below 7B parameters, the bottleneck of retrieval-augmented generation (RAG) is not retrieval quality but context utilization.   We present Noesis, the deterministic-first query plane of the Noesis architecture, which makes every deterministic judgment before generation. Its mechanisms follow from the ingestion architecture (subject of a separate patent application): (a) a producer-side fact layer rendering precomputed metric facts verbatim without ranking; (b) positional addressing with deterministic cross-source alignment, resolved ahead of query time at zero LLM cost; (c) provenance scoping as an attribution constraint with multi-tier named-reference routing; and (d) two-tier context with model-triggered verbatim hydration.   Across four ablations, a 2B model reaches parity with a 35B model on factual integrity (exact values in all runs; zero confabulated numbers on absent-entity traps); structured retrieval beats flat RAG by +11.4 points at 2B; skeleton-only context preserves quantitative answers at 20-30% smaller prompts; and hydration recovers verbatim narrative in ~8s versus ~29s. Two properties matter for regulated domains: each query resolves in a single generation call, and every reported value is traceable to its exact source and position by construction.

## 1. 核心问题与整体含义

- **研究动机**：在本地、低延迟、数据主权敏感场景中，RAG 常部署于小型语言模型（SLM）。但现有研究发现，7B 以下模型的瓶颈不在检索质量，而在**上下文利用能力**：即便检索到的段落包含正确答案，小模型也常无法可靠使用，标准 RAG 甚至可能产生负收益。
- **更严重的问题**：在“事实性关键查询”中，如精确数值、时间戳、跨源对齐、多源归因，主导失败模式不是检索未命中，而是**编造（confabulation）**：即使正确证据已在上下文中，模型仍会生成看似合理但语料中不存在的数字与时间戳。
- **整体含义**：一个错误数字比没有答案更危险。媒体受众指标、医疗剂量、金融与法律数字等领域中，基于捏造值的决策具有实际危害。论文主张，小模型与答案质量之间的耦合并非模型容量问题，而是**查询接口与上下文装配方式的问题**。
- **核心命题**：对于生产端已结构化的语料，确定性基础设施而非模型规模，才是事实性关键查询中答案质量与稳定性的首要决定因素。

## 2. 方法论

### 2.1 核心思想

- **确定性优先（Deterministic-First）**：在生成之前完成所有可确定性判断，把模型不该做的算术、定位、对齐、归因判断交给基础设施。
- **生产端 / 查询端解耦**：知识库声明自己拥有什么，查询平面消费这些声明，不解释格式。图作为一等导航器回答“信息在哪里”，嵌入只在该位置取内容，反转了传统 RAG 中“向量相似度决定、结构装饰”的优先级。
- **认知分层（Epistemic Tiering）**：上下文按“证据被何种机制选中”装配，而非按单一相似度分数排序。

### 2.2 关键技术机制

- **确定性事实层**
  - 摄取阶段对每个指标序列预计算极值及其位置，物化为知识库中的确定性事实节点。
  - 查询时逐字渲染到上下文顶部，位于任何散文之前。
  - 事实**没有阈值等级**：不被评分、排序或过滤；存在即进入上下文。
  - 词汇由生产端声明，指标名表面变体映射到同一序列，无需模型解释。

- **位置寻址与跨源对齐**
  - 内容沿知识库声明的有序属性进行位置寻址，机制通用，无领域语义。
  - 跨源对齐在查询前确定性解析，将位置观测与同一区间内容关联。
  - “X 峰值时发生了什么”通过预计算关系遍历回答，而非模型推理。
  - 查询平面保持领域词汇无关，位置性声明必须来自被寻址属性。

- **溯源约束与命名引用路由**
  - **范围界定约束归因，不限制数据访问**：命名来源在检索中优先，即使相似度信号弱也能到达。
  - 上下文携带显式溯源规则：一个来源的数据不得归因给另一命名来源；但多实体问题仍是一等公民。
  - 在 KB 选择、文件选择、实体激活各层，**有损信号不能否决确定性名称匹配**。
  - 地址承诺：命名内容即地址，mesh 路由承诺到拥有该内容的 KB。
  - 两个限制：短 token 不能单独锚定引用，需多 token 佐证；相关性需跨多个区域持续激活，避免大语料偶然匹配。
  - 对话状态：从先前助手回复中确定性抽取引用，作为指代性后续问题的地址。

- **双层上下文与模型触发式逐字填充**
  - **Tier 1 骨架**：确定性事实、图结构、类型边、轴对齐坐标，零散文块。
  - 两阶段契约：模型要么完全从骨架回答，要么输出有界 fetch 指令，每个指令命名一个 KB 清单中的文件。
  - 系统解析指令、验证文件、在命名文件范围内取逐字片段；全局向量填充仅作为饥饿阀。
  - Phase 2 呈现骨架加已填充片段并标记为权威，模型再回答。
  - **无需训练**：纯 prompt 契约，无控制 token、无 RL、无约束解码。
  - **构造上全域**：解析失败、取回失败、LLM 失败均降级为前一变体答案；未知文件名被丢弃而非致命。

- **认知分层与地址有界装配**
  - **Tier 0（计算）**：生产端计算事实，逐字渲染，无阈值。
  - **Tier 1（寻址）**：位置或命名引用确定性解析出的逐字片段，紧接 Tier 0，带来源文件与地址窗口；不参与排名竞争，顶部放置缓解位置偏差。
  - **Tier 2（发现）**：残余 token 预算下的语义填充，类似标准 RAG。
  - **双层装配**：确定性寻址解析出文件集 F 后，Tier 2 填充被约束在 F 内；有界取回不足时恢复全局填充作为饥饿阀；无地址解析时退化为无约束行为。
  - 命名来源界定答案域，命名实体只在域内锚定，不剪枝结构。
  - 与学习式分层压缩不同：粗层是确定性结构，细层可在已解析地址逐字恢复；与 MemGPT 等虚拟内存不同：取回在基础设施内对确定性地址执行，地址解析时零额外模型轮次。

## 6. 主要结论与发现

- **F1 固定基础设施下的平价**：2B 模型在事实性关键问题上与 35B 模型持平，精确值、诚实拒绝、干净归因均保持；模型规模在此查询类内是次要变量。
- **F2 陷阱零编造**：缺失节目问题上 4/4 诚实拒绝，零语料数字被归因给缺失实体。
- **F3 证据验证**：一个陷阱运行中，模型主动请求 hydration 验证两个真实指标文件，检查后才拒绝，而非凭参数记忆断言缺失。
- **F4 自发发射**：在无协议提示的 FULL 模式中，两个模型均自发输出 fetch 指令，6/6 命名正确文件；提示防御性解析是生产必需。
- **F5 逐字细节的规模依赖精度**：35B 包含精确时间戳，2B 逐字引用对话但省略时间戳；内容保真保持，位置细节优雅降级。
- **F6 按需支付填充成本**：定量问题停在 phase 1，零取回；叙事问题两阶段仍比 eager 快，约 8 秒 vs 约 29 秒。
- **F7 寻址问题无需语义散文**：48 次运行零 hydration fetch，零跨节目泄漏，2B 与 35B 内容持平，18/24 严格 needle，6 次近失仅为格式未回显节目名。
- **F8 扩展电池一致性**：85/85，冷生产栈 18 KB，稳定性来自基础设施而非采样。
- **F9 释义鲁棒性有边界**：跨语言改写中一次丢失与源文件名 token 重叠，导致确定性事实缺失，模型诚实报告缺失； canonical 形式 10/10。
- **F10 并发负载优雅降级**：并发 4 和 8 下 12/12 成功，延迟随竞争比例上升，单 GPU 表现为队列而非断路器。
- **F11 确定性层承载答案，神经读出可丢弃**：移除 42–50% 的多 KB 提示中的激活读出，50 个多 KB 运行全通过，中位延迟降三分之一。
- **F12 按分数比例骨架预算质量中性**：提示缩小 26%，TTFT 降 26%，无高质量损失；均匀切分会饿死高相关 KB。
- **F13 问题对齐事实结构消除多实体误读**：平坦事实列表导致模型偶发“上下文不含实体 A 值”，即使值已存在；改为每实体连续块加问题对齐行后，后续 20/20 通过。贪婪解码不等于比特级确定性，稳定性来自结构而非模型确定性。

## 7. 优点

- **问题选择精准**：聚焦事实性关键查询中的编造失败，而非一般性 RAG 检索提升，实际危害明确。
- **架构原则清晰**：确定性优先、生产 / 查询解耦、认知分层、地址有界装配，形成可解释的装配原则。
- **机制与保证构造性**：事实层无阈值、命名引用不被有损信号否决、地址解析后语义填充受限、无地址时字节级退化，保证是构造性的而非分数性的。
- **训练-free 的 hydration 协议**：纯 prompt 契约，任何 chat 模型可遵循；自发发射结果暗示触发行为可能已潜伏于预训练模型。
- **小模型平价验证**：2B 模型匹配 35B 模型，且对比刻意对作者论点不利，因为 35B 参数记忆远强，反而证明答案来自基础设施。
- **失败驱动与人工复核**：每个机制对应实测失败；自动 needle 误判被人工纠正；负控制、陷阱、跨程序泄漏检查细致。
- **效率与质量并重**：骨架省 20–30% 提示，hydration 约 3 倍加速，移除神经读出再省 42–50% 提示并降延迟三分之一，骨架预算再省 26%。
- **可追溯性**：每个报告值可按构造追溯到确切来源与位置，适合受监管领域。

## 8. 不足与局限

- **统计证据薄弱**：主电池 N=5，消融臂 N=1–3，证据是方向性的，未报告置信区间或显著性检验。
- **领域与规模局限**：单一广播媒体领域，小型演示 KB，18 个活跃 KB；跨医疗、金融、法律等事实性关键领域的泛化未验证。
- **模型范围有限**：仅比较一个约 2B 稠密模型与一个约 35B 稀疏 MoE 模型，未覆盖其他小模型家族或量化配置。
- **残余失败模式**：
  - 2B 在稠密单事实查找上仍有一次未命中，虽为诚实拒绝而非编造。
  - 跨语言释义下文件名匹配可能失败，导致确定性事实未进入上下文，F9 已刻画但未解决。
  - 开放总结问题对超大文档的 peripheral 数字需问题明确命名主题，否则报告缺失。
- **贪婪解码非比特确定**：多线程量化推理仍存在逐请求非确定性，F13 显示结构修复可消除近同分决策翻转，但底层非确定性仍在。
- **延迟仍高**：冷生产栈单 KB 定量问题 p50 15–33 秒，多 KB mesh 相关 p50 48–81 秒，最大 86.1 秒；并发 8 时最大 321 秒，prefill 主导。
- **指标偏差风险**：needle 指标奖励显式提及预期事实，结构分数略偏扁平 RAG；作者承认结构分数不是事实性指标。
- **缓存条件混杂**：Ablation D 延迟为热前缀缓存，冷 prompt 收益来自另一组实验；报告混合时需谨慎解读。
- **专利与复现限制**：生产端摄取架构为另一专利申请主题，本文只覆盖查询平面；完整系统复现可能受专利与未公开细节限制。
- **应用限制**：方法依赖生产端结构化语料与知识库声明；对无寻址契约的语料，行为退化为无约束 RAG，不带来额外保证。
