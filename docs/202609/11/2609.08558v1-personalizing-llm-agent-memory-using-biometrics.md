## 摘要
个性化记忆通过跨交互存储和复用用户特定数据，帮助 LLM 智能体提供稳定、定制化的辅助。然而，在多用户场景中，检索不仅要考虑语义相似度，还要考虑当前请求者是否与所存储记忆关联的身份匹配。我们提出 Bio-Memory，一种生物特征感知的记忆架构，使记忆检索同时取决于语义相似度与生物特征匹配。Bio-Memory 构建于 A-Mem 之上，为每个原子记忆笔记增加生物特征嵌入，并在语义排序之前利用生物特征匹配构建检索候选池。我们在 LoCoMo 上，在 10 用户共享智能体设置下，基于 7 个人脸基准和 10 个掌纹协议评估 Bio-Memory。在所有数据集上，Bio-Memory 能一致地区分所有者与非所有者查询。在人脸个性化下，在 CALFW 上，F1/BLEU-1 的最大平均差距达到 27.29% / 21.15%；在掌纹个性化下，在 MS_Blue 上，相应的差距为 25.75% / 19.22%。这些结果支持将生物特征作为共享环境中个性化记忆检索的一种实用控制信号。

## Abstract
Personalized memory helps LLM agents deliver stable, tailored assistance by storing and reusing user-specific data across interactions. In multi-user scenarios, however, retrieval must consider not only semantic similarity but also whether the current requester matches the identity associated with the stored memory. We propose Bio-Memory, a biometric-aware memory architecture that conditions memory retrieval on both semantic similarity and biometric matching. Built on top of A-Mem, Bio-Memory augments each atomic memory note with a biometric embedding and uses biometric matching to form the retrieval candidate pool before semantic ranking. We evaluate Bio-Memory on LoCoMo in a 10-user shared-agent setting over 7 face benchmarks and 10 palmprint protocols. Across datasets, Bio-Memory consistently separates owner and non-owner queries. Under face-based personalization, the largest average gap reaches 27.29% / 21.15% in F1 / BLEU-1 on CALFW; under palmprint-based personalization, the corresponding gap is 25.75% / 19.22% on MS_Blue. These results support biometrics as a practical control signal for personalized memory retrieval in shared environments.

# 论文总结：Personalizing LLM Agent Memory Using Biometrics

## 1. 核心问题与整体含义

- **背景**：LLM 智能体正从一次性问答系统演变为持久化个人助理，依赖外部记忆架构（如 A-Mem、MemoryBank、Mem0、PersonaMem-v2）跨会话存储和复用用户偏好、日程、历史交互等个性化信息。
- **核心问题**：现有记忆系统默认基于"外部提供的身份"（账号、用户 ID、会话边界）进行个性化检索。但在共享环境（智能家居助手、公共终端、企业助理）中，账号/会话可被共享、复用或保持活跃状态，**逻辑身份与物理请求者身份会分离**。
- **关键矛盾**：同一个查询（如"What is my next appointment?"）应根据"谁在物理上发出请求"返回不同记忆。仅靠语义相似度排序，无法区分不同用户的语义相同笔记，可能将他人隐私记忆返回给当前请求者。
- **整体含义**：个性化记忆不仅是"相关性"问题，更是"用户对齐"问题——系统必须同时判断**哪些记忆相关**以及**这些记忆属于谁**。

## 2. 方法论

### 核心思想
- 提出 **Bio-Memory**，一种生物特征感知的记忆架构，构建在 A-Mem 之上。
- 为每条原子记忆笔记增加一个**生物特征嵌入**，使检索同时受语义相似度与生物特征匹配双重约束。
- **关键设计**：生物特征匹配在语义排序**之前**执行，用于构建候选池（而非仅用于会话认证）。

### 关键技术细节

- **记忆笔记结构扩展**：
  `mi = {ci, ti, Ki, Gi, Xi, ei, Li, bi}`
  其中 ci 为交互内容，ti 为时间戳，Ki 为 LLM 生成关键词，Gi 为标签，Xi 为上下文描述，ei 为语义嵌入，Li 为语义链接集合，bi 为存储的生物特征嵌入。
- **属性生成**：`Ki, Gi, Xi ← LLM(ci ∥ ti ∥ Ps1)`，使用专门提示模板 Ps1。
- **语义嵌入**：`ei = fenc(concat(ci, Ki, Gi, Xi))`。
- **生物特征嵌入**：人脸使用 ArcFace，掌纹使用 CCNet；均 L2 归一化，用余弦相似度匹配。同一对话样本的所有记忆共享同一模板 bi = b_gal(u)。
- **生物特征匹配指示函数**：
  `Mbio(bt, bi) = I[sim_bio(bt, bi) ≥ τD]`
  其中 bt 为查询时的实时探针嵌入，τD 为按基准优化的验证阈值（取正负样本余弦分数分布主峰之间的交点）。
- **候选池构建**：`Mmatch_t = {mi ∈ M : Mbio(bt, bi) = 1}`
- **时序排序**：`Mtime_t = SortTime(Mmatch_t)`
- **语义检索**：`sim_sem(qt, mi) = et^T ei / (‖et‖2‖ei‖2)`
- **最终检索集**：
  `Rt = TopK_{mi∈Mtime_t} sim_sem(qt, mi)`（当 Mmatch_t ≠ ∅）；否则 `Rt = ∅`。K 固定为 10。
- **响应生成**：`Ct = Format(Rt)`，`ŷt = LLM(qt, Ct)`；当 Rt = ∅ 时，模型仅依赖参数化知识作答。

### 算法流程（文字描述）
1. 新交互到达 → 生成结构化笔记属性（关键词、标签、上下文）→ 计算语义嵌入 → 附加生物特征嵌入。
2. 保留 A-Mem 原有的链接生成与记忆演化机制。
3. 查询时：先做生物特征匹配筛选候选池 → 按时序排序 → 在池内做语义相似度排序 → 取 Top-K → 序列化为上下文 → 送入 LLM 生成答案。

## 3. 实验设计

### 数据集与场景
- **下游 QA 数据**：LoCoMo（长对话记忆基准），使用固定 10% 测试子集（采样比 0.1）。
- **生物特征基准**：
  - 人脸 7 个：AgeDB-30、CALFW、CFP-FF、CFP-FP、CPLFW、LFW、VGG2-FP。
  - 掌纹 10 个协议：CasiaM_460/700/850、IITD、MS_Blue/Green/NIR/Red、PolyU、Tongji。
- **场景构造**：将 10 个 LoCoMo 对话合并为一个 10 用户共享智能体记忆库，每个对话绑定一个生物身份，所有记忆共享该模板。

### 评测协议
- 两种查询角色：
  - **Owner**：探针嵌入与目标记忆模板匹配 → 记忆可进入候选池。
  - **Non-owner**：探针嵌入不匹配 → 目标记忆被排除。
- **问题类型**：Multi-Hop、Temporal、Single-Hop（最能反映检索质量对下游回答的影响）。
- **指标**：Token 级 F1 与 BLEU-1，报告宏平均及 Owner 与 Non-owner 的平均差距（Avg. Gap）。

### 对比方法
- 论文**未与其他基线方法（如纯语义检索、MemoryBank、Mem0 等）进行横向对比**，主要对比为同一系统内部的 Owner 与 Non-owner 条件。Owner/Non-owner 共享同一记忆库、同一检索配置、同一问题子集，唯一差异是查询探针生物特征嵌入。

## 6. 主要结论与发现

- **一致区分性**：在所有数据集、所有问题类型、两个指标上，Owner 均显著优于 Non-owner。

- **问题类型敏感度**：Temporal 问题最敏感（Non-owner 几乎崩塌），Multi-Hop 和 Single-Hop 也表现出明显分离。
- **跨模态一致性**：人脸与掌纹两种模态保持相同方向性结论，验证质量越高，记忆边界越清晰。
- **核心机制解释**：Bio-Memory 的作用发生在候选池构建阶段，本质是**检索时的访问控制**，而非对生成结果的后期调整。

## 7. 优点

- **问题定位准确**：明确指出共享环境中"逻辑身份 ≠ 物理身份"这一被现有记忆系统忽视的安全与个性化漏洞。
- **方法轻量且模块化**：仅作为检索层扩展，不改动 A-Mem 的笔记组织、链接生成与演化机制，易于集成到现有系统。
- **设计原则清晰**："先生物过滤、后语义排序"的顺序保证了身份一致性，避免跨用户笔记在同一候选集内竞争。
- **优雅的空池回退**：当生物匹配失败时返回空记忆上下文，宁可拒绝也不返回身份错配的记忆，符合隐私保护直觉。
- **跨模态验证充分**：同时覆盖人脸（ArcFace）与掌纹（CCNet）两类互补生物特征，增强了结论的泛化性。
- **实验控制严格**：Owner/Non-owner 共享除探针外的所有配置，内部对比客观；提供定量表格与定性检索轨迹双重证据。
- **阈值设计有依据**：τD 基于各基准的正负样本分数分布主峰交点确定，具备一定可解释性。
