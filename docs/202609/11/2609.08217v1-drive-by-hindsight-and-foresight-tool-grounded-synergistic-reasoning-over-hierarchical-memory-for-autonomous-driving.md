## 摘要
VLMs在自动驾驶领域已展现出前景，但仍受困于幻觉、时空感知薄弱和泛化能力有限。近期方法通过CoT解释、检索增强生成或静态注入工具输出来改进推理与决策。尽管这些机制丰富了上下文，模型既不会主动感知场景信息，也不会在回答后积累经验。为克服这些局限，我们提出了据我们所知首个将分层记忆与主动工具调用紧密耦合于闭环推理中的协同框架。我们的贡献有三方面。(i) 分层驾驶记忆：场景级短期记忆维护动态场景状态，而不断演化的长期记忆检索可复用的经验与工具策略。(ii) 记忆-工具协同推理框架：在场景状态和检索经验的引导下，模型在推理时自适应调用工具以精炼其推理，并离线将可复用经验整合到长期记忆池中。(iii) 数据生成与两阶段训练流程：通过多步教师rollout构建的经校验记忆-工具轨迹，用于SFT和GRPO训练。我们的7B模型在DriveLMM-o1上达到80.03的整体推理得分和79.09%的MCQ准确率，超过最强基线7.74个MCQ百分点，并在多个基准上表现出强泛化能力。值得注意的是，消融与分析研究验证了每个组件的有效性，并进一步揭示了分层记忆的互补作用。短期记忆增强时空理解，将STSBench准确率提升24.2个百分点，而离线长期记忆整合在所有参数冻结的情况下额外带来3.57个百分点的MCQ增益，展示了通过积累驾驶经验实现的持续自演化。

## Abstract
VLMs have shown promise for autonomous driving, yet still suffer from hallucination, weak spatio-temporal perception, and limited generalization. Recent methods improve reasoning and decision-making through CoT explanations, retrieval-augmented generation or the static injection of tool outputs. Although these mechanisms enrich the context, the model neither proactively perceives scene information nor accumulates experience after answering. To overcome these limitations, we present, to our knowledge, the first synergistic framework that tightly couples hierarchical memory with proactive tool invocation in a closed reasoning loop. Our contributions are threefold. (i) Hierarchical Driving Memory: a scene-level short-term memory maintains the dynamic scene state, and an evolving long-term memory retrieves reusable experience and tool strategies. (ii) Memory-Tool Synergistic Reasoning Framework: guided by the scene state and retrieved experience, the model adaptively invokes tools to refine its reasoning at inference time and consolidates reusable experience into a long-term memory pool offline. (iii) Data Generation and Two-stage Training Pipeline: verified memory-tool trajectories built by multi-step teacher rollout are used to train with SFT and GRPO. Our 7B model reaches an overall reasoning score of 80.03 and MCQ accuracy of 79.09% on DriveLMM-o1, surpassing the strongest baseline by 7.74 MCQ points and generalizes strongly across benchmarks. Notably, ablation and analysis studies validate the effectiveness of each component and further reveal the complementary roles of hierarchical memory. Short-term memory strengthens spatio-temporal understanding, improving STSBench accuracy by 24.2 points, while offline long-term memory consolidation yields an additional 3.57-point MCQ gain with all parameters frozen, demonstrating continual self-evolution through accumulated driving experience.

  - **工具增强路线**：如 AgentThink 将**预先计算好的**工具输出拼进上下文，属于单向、单轮的被动注入，而非主动取证。
- **作者类比人类驾驶**：真实驾驶不是对静态帧的一次性识别，而是「**前瞻（foresight）**」——持续跟踪自车与关键目标的运动趋势；与「**后见（hindsight）**」——调用长期积累的可迁移经验，判断风险优先级与动作选择。
- **核心研究问题**：能否在一个统一的闭环推理框架中，同时整合**时空感知（STM）、主动感知（工具调用）与经验积累（LTM）**，从而让自动驾驶推理模型具备人类驾驶的前瞻与后见特征？
- **整体含义**：论文主张自动驾驶 VLM 研究应从「扩大静态感知 + 孤立推理」转向「**可持续演化、可交互的驾驶智能**」。

## 二、方法论

### 2.1 总体框架

- 给定问题 \(q\) 与当前六视角观测 \(I_t\)，策略 \(\pi_\theta\) 以**场景级短期记忆 \(M_s\)**、从**跨场景长期记忆 \(M_l\)** 检索的 Top-K 条目 \(E_K\)、以及**驾驶工具集 \(\mathcal{T}\)** 为条件生成答案：\(y \sim \pi_\theta(q, I_t, M_s, E_K, \mathcal{T})\)。
- 模型迭代式地识别「证据缺口」→ 调用工具 → 累积观测 → 直到判定证据充分后作答。

### 2.2 分层驾驶记忆（Hierarchical Driving Memory）

- **场景级短期记忆 \(M_s\)**：
  - 对相邻两个时刻 \(I_{t-1}, I_t\) 的环视图像，用预训练 BEV 感知模型（HERMES 风格）编码为 ego-centric BEV 表示，输出结构化语义描述与场景属性：\((d_\tau, n_\tau) = F_{BEV}(I_\tau)\)。
  - 组织为场景图 \(M_s = \Phi_{graph}(d_{t-1}, d_t, n_{t-1}, n_t) = (V, R)\)，节点含自车、交通参与者、道路要素，边表示空间/时间/交互关系。
  - 仅在输入场景推进时刷新，单条轨迹内**只读**。目的是避免把多帧六视角图像直接喂给 VLM 造成上下文膨胀与隐式跨视角对齐负担。
- **跨场景长期记忆 \(M_l\)**：
  - 条目定义为 \(e_i = (c_i, r_i, p^+_i, \pi^{tool}_i, w_i)\)：适用场景/任务条件、风险因素摘要、可复用成功推理模式、有效工具使用策略、检索效用权重。
  - 检索打分：\(S(e_i|q,M_s) = \mathrm{sim}(E_m([q;M_s]), E_m(e_i)) + \lambda \bar{w}_i\)，取 Top-K（实验中 K=4）。查询向量由「问题 + 当前短期记忆」联合编码，使「任务问什么」与「场景长什么样」同时进入语义匹配。
  - 初始化含 **23,388 条**经验条目（从 OmniDrive 抽取的交通规则与通用驾驶知识），编码用 `all-MiniLM-L6-v2` 的 384 维向量。
  - **离线巩固**：仅对通过验证的轨迹抽取经验，\(B^+_n = \{\mathrm{Ext}(C) \mid \mathrm{Vrf}(C)=1\}\)，\(M^{(n+1)}_l = \Phi_{con}(M^{(n)}_l, B^+_n)\)；流程包含语义聚类、去重、冲突消解、抽象、合并；效用更新 \(w_i \leftarrow w_i + \eta g_i(C)\)，其中 \(g_i(C)=1\) 仅当该条目被检索且被验证器判定为对本次轨迹有实际帮助。
  - 在线推理期间 LTM **只读**，仅离线更新。

### 2.3 记忆-工具协同推理（MTSR）

- 从初始上下文 \(x_0 = (q, I, M_s, E_K)\) 出发，完整轨迹为 \(C = (x_0, s_1, \dots, s_T, y)\)，每步 \(s_t = (h_t, a_t, o_t, u_t)\) 分别表示推理状态、动作、工具观测、修正后的场景信念。
- 动作生成：\((h_t, a_t) \sim \pi_\theta(\cdot \mid x_0, H_{<t})\)，\(a_t \in \mathcal{T} \cup \{\text{finish}\}\)；形成 **Think–Action–Observation–Update** 循环，无预定义工具序列。
- 证据充分后发出 `finish`，生成最终答案 \(y \sim \pi_\theta(\cdot \mid x_0, H_{\le T})\)。
- 两类记忆在单次查询内保持固定，仅「瞬态场景信念」随观测演化。
- 工具库共 **27 个可调用函数**，报告实验中用到 20 个核心工具，覆盖：开放词汇 2D 检测（YOLO-World）、实例筛选、相机/单目 3D 定位、深度估计、成对 3D 距离、深度序比较、前车/周边/前方/区域检测、自车状态（速度、加速度、转向、任务目标）、未来轨迹预测（约 3 s）、占用栅格与地图查询（可行驶区域、车道类别、路肩、车道线、人行横道）。

### 2.4 数据生成与两阶段后训练

- **多步教师 rollout 与校验**：教师策略从 \(x_0\) 与初始 \(M^{(0)}_l\) 出发，经 MTSR 循环生成多步轨迹；验证包括最终答案正确性、工具调用合法性、推理—观测一致性、最大步数/冗余过滤，失败则重新生成。教师为 Qwen3.6-Plus，生成 7,000 条轨迹，**6,383 条通过验证**。
- **两阶段逐步 SFT（warm-up）**：
  - Phase 1：**移除执行器返回的观测**，只训练工具选择与参数生成（13,679 条记录，3 epoch）。
  - Phase 2：从 Phase-1 checkpoint 继续，带完整记忆与工具反馈，学习**观测落地推理**（20,062 条记录，20 epoch）。
  - 统一目标 \(L^{(p)}_{SFT}(\theta) = -\mathbb{E}_{C\sim D^{(p)}}[\sum_{j\in Y^{(p)}(C)} \log \pi_\theta(z^{(p)}_j | z^{(p)}_{<j})]\)；执行器返回的观测作为上下文但**不参与损失**。
- **轨迹级 GRPO**：从 Phase-2 checkpoint 出发，每输入采样 \(G=8\) 条轨迹，采用**正确性门控的分层奖励**（6 个互斥层级）：
  - Tier 1：正确 ∧ 用工具 ∧ 引用记忆 +0.7；Tier 2：正确 ∧ 用工具 ∧ 无记忆引用 +0.5；Tier 3：正确 ∧ 无工具 0.0；Tier 4：错误 ∧ 用工具 +0.2；Tier 5：错误 ∧ 无工具 0.0；Tier 6：格式非法 0.0。
  - 设计要点：记忆引用奖励被正确性完全门控；但工具使用奖励**故意不完全门控**（Tier 4 > Tier 3），作为冷启动引导项与防「直接作答捷径」项；由于层级互斥、每轨迹只计一次，奖励对调用次数是平的，不激励更深调用；组内标准化使 Tier 4 只在组内无正确答案时产生正优势。
  - 目标含 clip 项与 KL 正则 \(L_{GRPO}(\theta)\)，\(\beta = 0.001\)，π_ref 由 Phase-2 策略初始化。

## 四、主要实验结果

### 4.1 DriveLMM-o1（主基准）

- 方法在**整体推理得分、五个驾驶维度、MCQ 准确率**上均取得最优或接近最优表现，显著超越同 backbone（Qwen2.5-VL-7B）的 Direct 与 CoT 版本，并在多数维度上超过参数规模更大的 Qwen2.5-VL-72B、Qwen3-VL-8B 与 GPT-4o 等闭源/大模型基线。

### 4.2 DriveMLLM（空间理解，零样本/单样本）

- 8 个细粒度空间任务（L/R、F/B、RHD、RD、PPos、BBox、CVD、CD）的均值 AccS 优于 Direct、CoT 与 DirectTool 基线，说明短期记忆提供的 BEV 结构化语义与工具提供的 3D 定位/深度信息对**视角不变的空间关系判断**确有帮助。
- 与 Qwen+DirectTool（把工具输出一次性拼接）相比，本方法的 Think–Action–Observation–Update 循环带来更稳定的增益，尤其在 BBox、CVD、CD 等需要精确几何量的任务上。

### 4.3 STRIDE-QA（跨数据集、时序定位）

- 在 0–3 s 的定位成功率 LSR、均值 MLSR、时间定位一致性 TLC 上优于包括 GPT-4o 在内的基线，体现出**前瞻能力**：借助未来轨迹预测工具与场景级短期记忆，模型能对自车与关键目标的运动趋势做连续跟踪，而非仅依赖单帧。
- 由于 STRIDE-QA 与 nuScenes 不相交，结果支持方法的**泛化性**主张——长期记忆承载的是可迁移经验而非数据集特定模式。

### 4.4 STSBench（时序空间推理 MCQ）

- 在 ego 运动、ego–agent、agent 运动、agent–agent 关系及微平均上均领先，进一步验证框架对**多参与者交互关系**的建模能力。

### 4.5 DriveBench（定性鲁棒性）

- 在视觉退化（水体飞溅、雾天、低能见度）下仍能给出合理推理，归因于：短期记忆提供结构化场景语义（对像素级退化不敏感）、工具调用可主动补足被削弱的信息、长期记忆提供与具体视觉条件解耦的经验先验。该部分仅作定性分析，不计入主表。

## 五、消融与分析

- **记忆消融**：分别移除短期记忆 \(M_s\) 与长期记忆 \(M_l\) 后性能下降，二者同时移除时下降最大，说明「时空感知」与「经验积累」互补——前者提供当前场景的可演化信念，后者提供跨场景的可迁移策略。
- **检索条数 K**：K 从 1 增至 4 时性能提升，继续增大收益递减甚至略降，K=4 为较优折中；过多条目引入噪声与上下文负担。
- **工具消融**：去掉工具调用后退化为纯静态推理，性能明显回落；去掉「执行器返回观测」的 Phase-1（仅学工具选择）不足以支撑观测落地推理，证明 Phase-2 的必要性。
- **两阶段 SFT**：跳过 Phase-1 直接训练会因工具调用格式/参数不稳定而效果变差；Phase-1 起到**稳定工具接口**的 warm-up 作用。
- **GRPO 奖励设计**：移除「记忆引用奖励」或改变分层奖励结构后，工具使用率与最终正确率之间的平衡被破坏；Tier 4（错误但用工具）保留正奖励有助于冷启动阶段探索工具使用、避免模型过早收敛到「直接作答」捷径，而组内标准化保证其仅在组内无正确答案时产生正优势。
- **经验巩固**：仅用通过验证的轨迹抽取经验（\(B^+_n\)）优于纳入全部轨迹；效用更新 \(w_i \leftarrow w_i + \eta g_i(C)\) 使被证实有用的条目更易被检索，形成正反馈；离线流程中的去重与冲突消解避免了记忆膨胀与自相矛盾。
- **在线只读 LTM**：推理期间不写入长期记忆，避免单次错误推理污染记忆库，也保证同批次样本间的一致性与可复现性。

## 六、结论与贡献

- **贡献一**：提出分层驾驶记忆，将「场景级短期记忆（BEV 场景图）」与「跨场景长期记忆（可复用推理模式 + 工具策略 + 效用权重）」分离，并给出离线巩固与效用更新的完整机制。
- **贡献二**：提出记忆-工具协同推理（MTSR），把工具调用从「预先计算的被动注入」转为**无预定义序列的主动取证**，形成 Think–Action–Observation–Update 闭环。
- **贡献三**：设计多步教师 rollout + 校验的数据生成管线与两阶段逐步 SFT + 轨迹级 GRPO（正确性门控的分层奖励）后训练方案，将闭环推理行为蒸馏进 7B 模型。
- **贡献四**：在 DriveLMM-o1、DriveMLLM、STRIDE-QA、STSBench 四个基准（含跨数据集与定性鲁棒性分析）上验证有效性，支持「可持续演化、可交互的驾驶智能」这一研究取向。

## 七、局限与可讨论点

- **离线记忆更新的时延**：LTM 仅在离线巩固阶段更新，新场景中真正「前所未见」的经验无法即时写入，长期记忆的演化速度受限于离线流程的触发频率。
- **教师依赖**：训练轨迹与经验条目源自 Qwen3.6-Plus 教师，存在教师能力上限与风格偏置传导的风险。
- **奖励工程敏感性**：分层奖励的层级取值（+0.7/+0.5/0.0/+0.2）与「工具使用奖励不完全门控」的设计是人为选择，跨基准的稳健性仍需更系统的敏感性分析。
- **工具覆盖**：27 个工具虽覆盖面广，但仍是封闭集合，面对开放世界长尾场景（施工、极端天气、罕见交通参与者）可能缺少可调用证据源。
- **评测维度**：LLM judge 在 12 维度上的 1–10 打分存在主观性与评委偏置；主基准与训练数据同源（nuScenes）时的泄漏风险需以 STRIDE-QA 这类跨域结果作为主要佐证。
- **计算成本**：多步工具调用 + 每输入 8 条轨迹的 GRPO 采样带来显著推理与训练开销，论文未充分报告延迟/显存等部署侧指标。

## 八、一句话总评

论文把自动驾驶 VLM 的推理从「静态感知 + 单轮注入」重构成「**短期记忆管时空、长期记忆管经验、工具调用管取证**」的闭环，并通过两阶段 SFT 与分层奖励 GRPO 将这一行为内化到 7B 模型，在多个基准（含跨数据集时序定位）上取得一致提升，是「记忆 + 工具 + 强化学习」三位一体路线在自动驾驶场景中较完整的一次工程化验证。
