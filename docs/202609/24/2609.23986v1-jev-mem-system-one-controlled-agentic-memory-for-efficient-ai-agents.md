## 摘要
智能体记忆对于长时程 AI 智能体正变得不可或缺，然而许多现有系统依赖自回归 LLM 来控制记忆的组织、检索和使用方式，从而将昂贵的生成置于记忆操作的关键路径上。我们提出 Jev-Mem，一种受 System-One/System-Two 认知启发的新型智能体记忆架构。System One 负责快速、轻量的决策，而 System Two 则执行较慢的审慎推理。Jev-Mem 通过专用的 System-One 控制平面、结构化的多关系记忆平面以及 System-Two 推理平面，将这种分工引入智能体记忆。System-One 控制器在构建期间管理记忆类型划分和关系组织，并在检索期间动态执行查询路由、检索预算分配、图遍历、候选评分和自适应停止。System Two 仅在复杂推理和答案合成时被调用。这一设计同时提升了记忆有效性和系统效率：在 LoCoMo 上，Jev-Mem 取得了 0.777 的 LLM-as-a-Judge 总体得分，相较于最强基线相对提升 11.0%，同时将记忆构建时间降至 158 s，较最快的竞争记忆系统提速 6.6 倍，并将平均查询延迟降至 0.93 s，减少了 36.7%。

## Abstract
Agentic memory is becoming essential for long-horizon AI agents, yet many existing systems rely on autoregressive LLMs to control how memories are organized, retrieved, and used, placing expensive generation on the critical path of memory operations. We introduce \textbf{\method}, a new agentic memory architecture inspired by System-One/System-Two cognition. System One captures fast, lightweight decision-making, whereas System Two performs slower, deliberative reasoning. Jev-Mem brings this division of labor to agentic memory through a dedicated System-One control plane, a structured multi-relational memory plane, and a System-Two reasoning plane. The System-One controller governs memory typing and relational organization during construction, and dynamically performs query routing, retrieval-budget allocation, graph traversal, candidate scoring, and adaptive stopping during retrieval. System Two is invoked only for complex reasoning and answer synthesis. This design improves both memory effectiveness and system efficiency: on LoCoMo Jev-Mem achieves an overall LLM-as-a-Judge score of 0.777, an 11.0\% relative improvement over the strongest baseline, while reducing memory construction time to 158\,s, a 6.6$\times$ speedup over the fastest competing memory system, and lowering average query latency to 0.93\,s, a 36.7\% reduction.

## 1. 核心问题与整体含义

- **研究背景**：长时程 AI 智能体（如编程助手、个人助理、研究智能体）需要在固定上下文窗口之外持续积累用户偏好、任务历史与环境知识，因此**智能体记忆（Agentic Memory）** 成为关键组件，负责保存、组织、更新与检索过往经验。
- **核心痛点**：现有智能体记忆系统在记忆构建（写入）与检索（读取）过程中，普遍依赖**自回归 LLM** 来完成记忆类型判定、关系构建、查询路由、候选评分与停止决策等高频操作。这些操作虽然是"语义性"的，但**并非"生成性"**——它们只需输出标签、概率或分数，却被迫以逐 token 生成、格式化、解析的方式执行，导致昂贵生成位于记忆操作的关键路径上，累积成显著的延迟与推理开销。
- **现有方案的局限**：固定启发式规则高效但缺乏灵活性；通用自回归 LLM 灵活但每次调用都需重复生成，成本高昂。
- **整体含义**：论文借鉴认知科学中的 **System-One / System-Two** 双过程理论（快、自动 vs. 慢、审慎），提出将**记忆控制本身视为一等系统层**，用轻量化的 System-One 控制面处理高频结构化决策，仅把复杂推理与答案合成留给 System-Two，从而同时提升记忆有效性与系统效率。

## 2. 方法论

### 2.1 核心思想

- 将智能体记忆重构成三个平面：
  - **System-One 控制面**：执行高频、有界的结构化决策（类型判定、关系构建、查询路由、预算分配、图遍历、候选评分、证据评估、自适应停止）。
  - **共享结构化记忆数据面**：维护规范化的观测节点及语义、时间、因果、实体四类多关系视图，以及共享的向量与关键词索引。
  - **System-Two 推理面**：仅在需要开放生成或深度推理时被调用，用于最终答案合成。
- 关键抽象是**类型化 System-One 控制器 J(S, Q)**：给定结构化状态 S 和一批显式决策问题 Q，输出独立命题的概率或互斥选项的分布；同一状态下的多个决策可**批量调用**，避免自由文本生成与解析。

### 2.2 记忆表示

- 观测定义：`o_t = (x_t, τ_t, μ_t)`，分别表示内容、时间戳、来源。
- 记忆状态：`M_t = (V_t, {Eg_t}_{g∈G}, Ivec_t, Ilex_t)`，其中 `G = {semantic, temporal, causal, entity}`。
- 所有关系视图共享同一套规范记忆节点 V_t，同一对记忆之间可同时存在多种类型边；向量与词法索引提供互补入口。

### 2.3 写入路径（System-One 引导的记忆构建）

- 流程：`o_t → type → candidates → relations → M_t`
- **类型判定**：对每条有效观测预测四个重叠特征（episodic / semantic / procedural / preference），作为注释而非互斥分类；规范节点保留原始观测、来源、时间戳、嵌入、实体与类型分数。
- **候选发现与关系判定分离**：先用确定性检索（向量相似度、词法重叠、共享实体、时间邻近）从 V_t 中选出至多 Kw 个候选，避免控制器成本随记忆规模线性增长。
- **关系插入**：仅当 `P(g | v, u) ≥ θ_rel`（阈值 0.60）时插入类型 g 的边；时间顺序可由时间戳直接生成，精确共享标识符可直接生成实体关系；隐式时间顺序时由控制器在 before/after/during/contains/overlaps/same_time/unknown 中选择。
- **设计权衡**：默认保留所有观测（不做不可逆的 store-or-discard 决策），通过选择性关系构建与检索阶段的筛选来控制信息规模；周期性维护在有限邻域内检测冗余、矛盾、过时与新增链接；合并/提升为文本抽象需显式升级到 System-Two，且概率阈值 ≥ 0.85 且矛盾分数 < 0.85。

### 2.4 读取路径（自适应 System-One 检索）

- 将检索视为**闭环控制过程**，而非单次 top-k 搜索：
  - **查询路由**：预测各关系视图的相关性 `p(q) = {p_g(q)}`、多跳需求 h(q) 与近因重要性 r(q)；`p_g(q) ≥ θ_act`（0.10）时激活对应视图。
  - **预算分配**：`w_g(q) = p_g(q)^γ / Σ p_j(q)^γ`，在给活跃图分配最小预算 m 后按权重分配剩余总预算 B（默认 80）；多跳需求决定遍历深度 `D(q) = min{D_max, max(1, ⌈D_max · h(q)⌉)}`。
  - **锚点检索**：通过 reciprocal-rank fusion 融合向量与关键词排名，`s_RRF(v,q) = Σ 1/(κ + rank_L(v))`，κ=60；最高排名节点初始化已访问集与搜索前沿。
  - **证据引导扩展**：每轮评估证据充分性 s_d、继续检索期望效用 u_d、缺失必需证据 m_d、未解决矛盾 c_d。停止条件为 `s_d ≥ θ_suff ∧ m_d < θ_cont ∧ c_d < θ_cont`，或 `u_d < θ_cont`。
  - **候选评分**：综合嵌入相似度 z_v、查询相关性 a_v、关系有用性 ℓ_v、信息新颖度 n_v、证据支持度 c_v 与边权重 π_e，并按近因预测调整；top-W（默认 10）候选进入下一轮 beam 并加入累积证据。
  - **迭代循环**：`route → retrieve → assess → expand → reassess`。
- **最终合成**：检索终止后，将得分最高的 K 条记忆交给 System-Two LLM 生成答案 `y = SystemTwo(q, E)`。
- **开销有界性**：一次写入仅需一次批量类型请求与一次批量关系请求；一次查询仅需一次路由请求及每轮至多一次证据评估与一次批量候选评分请求；独立限制图扩展数、检查边数、访问节点数、深度（8）、控制器调用次数（16）与时间预算（15 秒）。

## 7. 优点

- **架构层面的创新**：首次将 System-One/System-Two 认知分工**架构性地**应用于记忆子系统，而非仅在单次推理回合内分配算力，形成统一的写入与读取控制抽象。
- **类型化概率接口**：用有界输出（标签、概率、分数）替代自由文本生成与解析，显著降低控制路径开销；同一状态下的决策可批量执行。
- **候选发现与关系判定解耦**：避免控制器成本随记忆规模线性增长，工程上可扩展。
- **非破坏性写入策略**：保留全部原始观测，避免摄入时不可逆的信息丢失；选择性体现在关系构建与检索阶段。

- **显式开销上界**：对图扩展、边、节点、深度、控制器调用与时间均设硬性上限，保证控制过程本身不会失控。

  - 将认知双过程理论从"单轮推理的算力分配"扩展到"记忆子系统的架构分工"，具有一定概念贡献。
  - 效率数量级改善（构建加速 6.6 倍、延迟降低约三分之一）若可复现，对生产级长时程智能体具有直接工程价值。
- **风险与边界**：方法有效性高度依赖 System-One 控制器预测质量；若控制器在分布外场景下校准不佳（概率失真），可能导致错误路由、过早停止或遗漏关键证据，且由于是闭环控制，误差可能累积。

## 11. 总体评价

- **贡献定位**：本文的核心贡献是**架构性**而非算法性的——它没有提出新的记忆编码模型或检索算法，而是重新划分了记忆系统中"快速控制"与"慢速推理"的职责边界，并用类型化概率接口将前者工程化。
- **证据强度**：主实验结论清晰（准确率最高 + 效率最优），直接支撑核心主张；但证据广度（单数据集、无消融、无方差）与深度（无敏感性、无成本分析）不足，削弱了结论的普适性说服力。
- **写作与呈现**：问题动机（生成性 vs. 非生成性操作的错配）阐述到位，架构描述系统完整，超参数与流程细节较充分。
- **改进方向**：补充第二基准与消融实验、报告多次运行方差、披露算力与成本、对关键阈值做敏感性分析、验证多关系视图的增量价值、并与更强 System-Two backbone 对比。
- **一句话总结**：Jev-Mem 通过将记忆控制重构为轻量 System-One 控制面、把生成式推理留给 System-Two，在 LoCoMo 上同时取得了最高准确率与显著更低的延迟与构建时间，展现了架构分离的潜力，但其泛化性、组件贡献与成本效益仍需更充分的实验验证。
