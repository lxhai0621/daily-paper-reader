## 摘要
长时程语言模型智能体会不断累积交互历史，这增加了计算成本，同时使相关信息更难被保留和复用。现有的上下文管理方法主要关注如何压缩或检索历史，但在很大程度上仍未回答：模型本身是否在这些记忆操作发生之前就已经表征了对其的需求。我们研究了每个智能体动作之前的隐藏状态，发现压缩与回忆需求已经被编码在模型的内部表征中。这些信号无法由简单的上下文长度或交互进度解释，并且它们在不同模型深度上表现出不同的形成模式。我们进一步表明，大多数记忆决策信息保存在紧凑的近期上下文中，而选择性恢复的历史证据则补充了近期上下文所缺失的长程依赖。基于这些发现，我们提出 Preaction Memory with Evidence Retrieval（PaMER），它将状态引导的压缩与外部证据检索相结合。PaMER+ 进一步引入步骤级证据选择，仅恢复当前任务所需的历史信息。在 WorkBuddyBench 上，跨多种上下文管理基线和模型骨干的实验表明，我们的框架在保持有竞争力的任务性能的同时，大幅降低了上下文消耗。

## Abstract
Long horizon language model agents continuously accumulate interaction history, increasing computational cost while making relevant information harder to preserve and reuse. Existing context management methods mainly focus on how to compress or retrieve history, but largely leave open whether the model itself already represents the need for these memory operations before they occur. We study the hidden state immediately before each agent action and find that compression and recall needs are already encoded in the model's internal representations. These signals cannot be explained by simple context length or interaction progress, and they exhibit distinct formation patterns across model depth. We further show that most memory decision information is preserved in a compact recent context, while selectively restored historical evidence complements the long range dependencies that recent context misses. Based on these findings, we propose Preaction Memory with Evidence Retrieval (PaMER), which combines state guided compression with external evidence retrieval. PaMER+ further introduces step level evidence selection to recover only the historical information required by the current task. Experiments on WorkBuddyBench, across multiple context management baselines and model backbones, show that our framework substantially reduces context consumption while maintaining competitive task performance.

## 2. 方法论

### 2.1 核心思想

- 在智能体每个动作前提取隐藏状态，训练独立探针预测两类记忆需求：
  - **压缩（Compression）**：旧上下文应被压缩，同时保留任务相关信息。
  - **召回（Recall）**：当前推理需要已离开活动上下文的早期证据。
- 探针仅读取冻结语言模型的表征，不更新底层模型；目标是检验预训练表征中是否已存在可线性读取的记忆决策信息。
- 基于分析结论提出 **PaMER** 与 **PaMER+**：
  - PaMER：状态引导压缩 + 外部证据检索。
  - PaMER+：进一步做步骤级证据选择，只恢复当前任务所需的历史原始步骤。

### 2.2 关键技术细节

- **预动作表征**：
  - 令 \(o_t\) 为下一步动作前的可用上下文，取冻结模型输出 RMSNorm 后最后一个输入 token 的隐藏状态：
    \[
    h_t = \phi^{(L)}(o_t)[-1] \in \mathbb{R}^{4096}
    \]
  - 输入使用与智能体状态一致的对话格式和工具描述；不包含标注信息或未来动作。
- **探针与训练**：
  - 线性探针：\(p_t^m = \sigma((w^m)^\top h_t + b^m)\)，分别预测压缩与召回。
  - 另测一层隐藏层 MLP，以检验非线性读出是否带来额外收益。
  - 损失为类加权二元交叉熵，权重 \(\rho_m = N^-_m/N^+_m\) 仅在训练集计算。
  - 以问题为单位做 70/15/15 分组划分，五个随机种子；阈值由验证集 F1 选择后固定用于测试；AUROC 为主指标，AUPRC、F1 为辅。
- **层间分析**：
  - 在每一层独立训练探针，比较最后一个输入 token 与全输入 token 平均池化。
  - 同时记录正负样本探针 logit 差 \(\Delta\)，但强调 logit 差受探针尺度影响，AUROC 才是主排序指标。
- **历史信息需求分析**：
  - **Recent2 条件**：保留系统与任务前缀 \(P_t\) 加最近两个完整交互块 \(R_t\)，约使用 Full Context 的 26.0% token。
  - **Decision KD**：用 Full Context 教师预测做决策蒸馏，训练压缩头；教师仅训练时使用。
  - **恢复历史证据**：\(C^{recover}_t = P_t \oplus E_t \oplus R_t\)，其中 \(E_t\) 为恢复的历史证据。
  - 比较 Selective Raw Top1/3/5、Qwen Top1/3/5、Hidden Bank、GRU 等历史记忆形式。
- **PaMER 在线控制器**：
  - 保留任务/系统前缀与最近两个完整块；更早完整块作为压缩候选，候选至少 1024 tokens。
  - 五个独立压缩头读取 \(P_t \oplus R_t\) 的最终状态；至少 3/5 头超过验证阈值才触发压缩。
  - 压缩头训练损失：
    \[
    L_s = \text{WBCE}(z_{t,s}, y^c_t) + 0.5 \cdot \text{BCEWithLogits}(z_{t,s}, p^{full}_{t,s})
    \]
  - 触发压缩后，总结旧块，用 Qwen3-Embedding-8B 编码并存储摘要与来源链接；原始块仅在存储成功后移除。
  - 当前请求返回 \(P_t \oplus R_t\)，不插入新摘要，也不在同次请求召回，避免立即检索抵消压缩收益。
  - 后续请求用任务与 Recent2 构造查询，按余弦相似度检索 Top3 摘要，插入前缀与近期块之间。
  - 任何记忆操作失败时保留原始历史，不应用不完整更新。
- **PaMER+ 步骤级证据选择**：
  - 摘要记录 `step_details`，将摘要内容链接到原始历史步骤。
  - 选择器指定 `raw_steps_needed`，仅将明确选中的完整历史块送入召回路径。
  - 选中摘要只用于定位候选记忆，不授权恢复其覆盖的全部步骤。
  - 对分区、重叠、缺失步骤、无效标识符做校验；无效选择被拒绝。
  - 缓存身份由排序后的摘要与步骤标识符计算；空选择与失败操作区分处理。

### 2.3 算法流程概述

- 输入规范请求，加载持久化记忆；若会话标识或工具结构无效，直接返回原请求。
- 构造有效历史，划分为前缀 \(P_t\)、旧块 \(O_t\)、近期块 \(R_t\)。
- 若旧块 token 数 ≥ 1024，提取冻结 Qwen3.5-9B 最终状态，运行五个压缩头；3/5 投票触发压缩。
- 压缩成功且事务检查通过：生成摘要与嵌入，提交记忆，返回 \(P_t \oplus R_t\)；当次不召回。
- 若存在记忆，则用任务与 Recent2 检索最多三个摘要，构造 \(P_t \oplus E_t \oplus O_t \oplus R_t\)；检索或工具协议校验失败则返回原请求。
- 无压缩、无召回时返回有效历史或原请求。
