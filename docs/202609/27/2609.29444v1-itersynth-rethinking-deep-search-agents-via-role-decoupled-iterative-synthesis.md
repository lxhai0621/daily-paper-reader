## 摘要
深度搜索要求LLM智能体分解复杂查询、检索证据并综合有依据的答案，然而现有ReAct风格智能体存在两个局限：角色耦合，即一个策略必须同时处理规划、证据使用和综合；以及上下文累积，即不断增长的搜索历史引入噪声并掩盖有用信息。为解决这些问题，我们提出IterSynth，一种角色解耦且基于摘要的范式，它在用于识别信息需求的Planner与用于将证据整合到不断演化的摘要状态中的Synthesizer之间交替。该设计将规划与综合分离，同时使用摘要作为搜索的持久状态，从而减少能力耦合和上下文噪声。为有效训练IterSynth，我们进一步提出用于强化学习的角色解耦策略优化（RDPO），它将最终结果奖励与回合级评分标准评估相结合，并计算角色特定的优势以实现更精确的信用分配。在BrowseComp和Xbench-DS等五个长时程深度搜索基准上的实验表明，IterSynth-8B平均得分为50.7，超过先前最强的≤8B智能体 +4.2%。此外，IterSynth作为一种模型无关的提示范式，在前沿专有模型上相比ReAct及类似提示范式带来显著的零样本提升。

## Abstract
Deep search requires LLM agents to decompose complex queries, search for evidence, and synthesize grounded answers, yet existing ReAct-style agents suffer from two limitations: role coupling, where one policy must handle planning, evidence use, and synthesis; and context accumulation, where growing search histories introduce noise and obscure useful information. To address these issues, we propose IterSynth, a role-decoupled and summary-based paradigm that alternates between a Planner for identifying information needs and a Synthesizer for integrating evidence into an evolving summary state. This design separates planning from synthesis while using the summary as the persistent state of search, reducing both capability coupling and context noise. To train IterSynth effectively, we further introduce Role-Decoupled Policy Optimization (RDPO) for reinforcement learning, which combines terminal outcome rewards with turn-level rubric evaluations and computes role-specific advantages for more precise credit assignment. Experiments on five long-horizon deep-search benchmarks such as BrowseComp and Xbench-DS show that IterSynth-8B achieves an average score of 50.7, surpassing the strongest prior $\leq$8B agent by +4.2\%. Moreover, IterSynth serves as a model-agnostic prompting paradigm, delivering substantial zero-shot gains over ReAct and similar prompting paradigms on frontier proprietary models.

## 1. 核心问题与研究动机

- **背景**：深度搜索（Deep Search）要求 LLM 智能体分解复杂查询、多轮检索证据、识别信息缺口并综合有依据的答案。当前开源智能体普遍采用 ReAct 式单策略线性流程：在一个不断膨胀的上下文中交替执行推理、搜索与综合。
- **两大瓶颈**：
  - **角色耦合（Role Coupling）**：单一无差别策略需同时承担规划、查询构造、证据过滤、缺口识别、冲突消解与最终综合等异质能力，容易导致过早终止、冗余搜索或证据利用浅薄。
  - **上下文累积（Context Accumulation）**：长程搜索不断堆积检索段落、中间思维与部分结论，有用证据被噪声掩盖，早期错误沿轨迹传播。论文附录 H 实测显示，即使在 64K 上下文下，ReAct 在 BrowseComp 上仍有超过 59% 的轨迹因上下文耗尽而无法终止。
- **现有方案不足**：
  - 多智能体方法（如 InfoFlow）将子任务分配给不同模型，降低认知负担但增加推理成本、部署复杂度与协调开销。
  - 摘要式方法（如 IterResearch、AgentFold、ReSum）周期性压缩历史，但摘要通常被视为外部辅助模块而非可学习、可优化的搜索策略组成部分，规划与证据使用仍然耦合。
- **整体含义**：论文主张需要一种统一范式，在**单一共享策略**内同时实现角色解耦与有界上下文，并将摘要更新作为搜索行为的显式可优化组件。

## 2. 方法论

### 2.1 核心思想

- **IterSynth**：一种角色解耦、基于摘要的迭代深度搜索范式。同一 LLM 策略在两种角色间交替：
  - **Planner（规划者）**：仅观察原始问题 $q$ 与当前全局摘要 $M_t$，决定下一步搜索查询或终止输出最终答案。动作空间为 $\{\text{search}(q_t), \text{answer}(\hat{a})\}$。
  - **Synthesizer（综合者）**：读取检索证据，过滤无关段落、提取有用发现、消解局部矛盾，更新全局摘要 $M_{t+1}$。动作空间仅限摘要更新，不能发起查询或输出最终答案。
- **关键设计**：两个角色由**同一策略、共享参数**执行，仅通过角色提示（role prompt）、信息访问权限与动作约束区分。摘要 $M_t$ 成为搜索的持久状态，而非被动压缩产物。
- **结构优势**：同时获得多智能体系统的专业化收益与摘要式智能体的上下文控制收益，且不增加参数量。

### 2.2 双角色 MDP 形式化

- 形式化为增广 MDP：$\langle \mathcal{S}, \mathcal{D}, \mathcal{E}, \mathcal{T}, \mathcal{R} \rangle$。
- **状态空间**：$s_t = (q, M_t)$，Planner 仅观察紧凑状态，而非完整历史。
- **决策空间**：每轮迭代包含连续两个角色条件子步骤：
  - Planner 子步骤：$d_t^P = [\text{Think}_t^P, a_t] \sim \pi_\theta(\cdot \mid s_t, \rho^P)$，其中 $\rho^P$ 为 Planner 提示。
  - Synthesizer 子步骤（若 Planner 选择搜索）：$d_t^S = [\text{Think}_t^S, M_{t+1}] \sim \pi_\theta(\cdot \mid s_t, d_t^P, \text{TR}_t, \rho^S)$。
- **环境与转移**：若 $a_t = \text{search}(q_t)$，环境返回检索文档 $\text{TR}_t \sim \mathcal{E}(\cdot \mid a_t)$，状态转移为 $s_{t+1} = \mathcal{T}(s_t, d_t^P, \text{TR}_t, d_t^S) = (q, M_{t+1})$；若 $a_t = \text{answer}(\hat{a})$，轨迹终止，跳过 Synthesizer。
- **算法流程**（Algorithm 1）：初始化 $M_0 \leftarrow \emptyset$；每轮构造有界上下文 $s_t = (q, M_t)$，Planner 决策，若为答案则终止，否则环境执行搜索，Synthesizer 综合去噪得到 $M_{t+1}$，工作区重建后进入下一轮。

### 2.3 训练流程（两阶段）

- **冷启动 SFT**：
  - 聚合公开深度搜索数据集（DeepDive、DeepForge、REDSearcher）与人工策划的合成真实场景问题。
  - 使用前沿模型 Qwen3.5-397B-A17B 在实时搜索环境中合成 Planner–Synthesizer 双角色轨迹。
  - 多阶段过滤：修复格式与工具调用错误、移除幻觉推理步骤、仅保留最终答案可验证正确的轨迹，最终保留约 **10K 条高质量轨迹**，平均每条 **4.37 轮**迭代。
  - 每条轨迹展开为逐轮样本，每个 Planner 与 Synthesizer 响应均为独立监督目标，共约 **87.4K 角色条件样本**。
  - 对 Qwen3-8B 进行全参数 SFT，工具返回结果在损失中被 mask。

- **RDPO（Role-Decoupled Policy Optimization）**：
  - **多轮轨迹与复合奖励**：对每个查询执行 $G$ 次独立 rollout，每条轨迹 $i$ 展开 $T_i$ 轮，产生 $\sum_{i=1}^G T_i$ 个交互轮次样本。复合奖励为：
    $$r_{i,t}^{\rho} = r_{\text{acc},i} + \alpha \cdot r_{\text{rubric},i,t}^{\rho}$$
    其中 $r_{\text{acc},i} \in \{0,1\}$ 为终端正确性奖励，广播到该轨迹所有轮次；$r_{\text{rubric},i,t}^{\rho}$ 为 LLM judge 按角色评分标准给出的轮级奖励；$\alpha$ 为缩放系数（主实验取 0.5）。
  - **角色解耦组优势**：将复合奖励按角色划分为两个独立池 $R_q^{\rho} = \{r_{i,t}^{\rho} \mid i \in [1,G], t \in [1,T_i]\}$，在各自池内归一化：
    $$A_{i,t}^{\rho} = \frac{r_{i,t}^{\rho} - \mu_q^{\rho}}{\sigma_q^{\rho}}$$
    其中 $\mu_q^{\rho}$、$\sigma_q^{\rho}$ 为对应角色池的均值与标准差。解耦后的优势直接接入标准 GRPO 目标，无需额外算法修改。
  - **评分标准构建**：从 20 对正负对比轨迹中，由 Claude-4.6-Sonnet 分三阶段提炼：对比轨迹收集 → 逐对角色特定标准归纳 → 标准合并（每角色上限 5 条）。Planner 维度包括 Gap/Spec/Term，Synthesizer 维度包括 Faith/Cov/Consol。训练时由 Gemini-2.5-flash-lite 在线评分。

## 5. 主要发现与结论

### 5.1 核心结论

- **范式有效性**：在**单一共享策略**内同时实现角色解耦与有界上下文是可行的，且无需增加参数规模或引入多模型协调开销。IterSynth-8B 以 8B 参数在 5 个长程深度搜索基准上取得 50.7% 的平均成绩，验证了"角色解耦 + 摘要即状态"这一范式的有效性。
- **跨规模竞争力**：8B 模型可超越部分 30B 级训练智能体（ReSum-30B、AgentFold-30B-A3B、OpenSeeker-30B-SFT），说明**结构化角色划分带来的收益可以部分替代参数规模**。
- **训练信号的关键性**：RDPO 的角色解耦归一化是性能提升的核心来源。使用相同的复合奖励但混合角色归一化（w/o RD）反而低于纯结果奖励 GRPO（47.2 vs 48.9），表明**奖励本身的信息量只有在按角色正确分配信用时才能被有效利用**——混合归一化会让 Planner 的高方差轮级信号污染 Synthesizer 的优势估计，反之亦然。
- **角色不可互换**：替换 Synthesizer 导致平均分下降 17.4%，替换 Planner 下降 41.1%。Planner 的退化影响更大，说明**搜索方向与终止决策的质量是深度搜索的上限约束**；而 Synthesizer 更多影响证据利用率。两者均显著优于不替换，说明双角色分工确实产生了不可替代的专业化收益。
- **架构归因**：控制实验（相同数据规模、教师模型、训练管线）显示 IterSynth-SFT 超 ReAct-SFT +11.5 分、IterSynth-RDPO 超 ReAct-RL +12.6 分，排除了数据与教师模型带来的混淆，将增益明确归因于**范式本身**。
- **上下文控制收益**：由于 Planner 始终只观察 $(q, M_t)$ 这一有界状态，轨迹长度增长不再导致上下文线性膨胀。附录 H 的上下文溢出分析显示，IterSynth 在 64K 预算下因上下文耗尽而失败的比例显著低于 ReAct 基线，缓解了长程搜索中最主要的失败模式之一。

### 5.2 效率与成本

- 共享参数设计使得**推理成本与单智能体相当**，避免了 InfoFlow 类多智能体方案的显存与协调开销。
- 由于 Planner 上下文被压缩为问题 + 摘要，单轮推理的输入 token 数远小于 ReAct，尽管总轮次可能略多，**总体 token 成本仍具竞争力**；效率与成本分析一节给出了逐基准的 token 消耗与延迟对比。
- 摘要的显式可学习性带来一个副作用：Synthesizer 学会了**主动丢弃冗余证据**，使得摘要长度在训练过程中趋于稳定而非持续增长（训练动态分析一节）。

### 5.3 局限性与未来工作

- **对摘要质量的依赖**：全局摘要 $M_t$ 是 Planner 唯一的信息来源，一旦 Synthesizer 在早期轮次丢失关键证据，Planner 后续难以恢复。Faith（忠实性）与 Cov（覆盖度）维度是 rubric 中权重最高但也最难稳定的部分。
- **评测依赖 LLM judge**：轮级奖励依赖 Gemini-2.5-flash-lite 在线评分，judge 模型的鲁棒性实验表明性能对 judge 选择存在一定敏感度；尽管 rubric 由 Claude-4.6-Sonnet 从 20 对对比轨迹中提炼并限制每角色 5 条以内，评分标准的覆盖完备性仍受限于这 20 对样本的代表性。
- **RDPO 训练成本**：64 × H20 约 90 小时的 RL 阶段成本仍高于纯 SFT，如何在不损失角色解耦收益的前提下降低 RL 开销是后续方向。
- **工具环境限定**：实验仅覆盖 Search Engine + Web Browser 两类工具，未验证在代码执行、数据库查询等异构工具场景下的泛化性。
- **潜在方向**：将双角色扩展为更多角色（如 Critic、Verifier）而仍保持共享参数；探索摘要的层次化结构；以及在更长程（>100 轮）任务上的表现。

## 6. 总体评价

论文的主要贡献可归纳为三点：(1) 提出 IterSynth 范式，在单一共享策略内通过角色提示、信息访问权限与动作约束实现 Planner–Synthesizer 解耦，并将摘要提升为搜索的显式持久状态而非外部压缩模块；(2) 提出 RDPO，通过按角色划分奖励池并独立归一化优势，解决复合奖励下多角色信用分配问题，且可无修改地接入标准 GRPO；(3) 在 5 个长程深度搜索基准上以 8B 规模取得与 30B 级智能体可比的性能，并通过角色交换、控制实验、混合归一化消融等系统性实验将增益明确归因于范式设计而非数据或算力。

其方法论层面的启示在于：**深度搜索智能体的瓶颈未必是模型能力不足，而可能是角色耦合与上下文累积这两类结构性问题**；通过将异质能力分配给同一策略的不同角色条件模式，并以有界摘要作为跨轮唯一状态，可以在不增加参数的前提下同时缓解两者。
