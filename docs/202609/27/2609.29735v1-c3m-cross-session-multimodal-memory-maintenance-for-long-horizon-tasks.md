## 摘要
长时程任务需要在有界且查询不可知的记忆预算下，保存并随后恢复跨会话证据。现有压缩方法可能会丢弃细粒度视觉线索，或将语义相似但互不兼容的观测混为一谈。我们提出 C3M，一种跨会话多模态记忆组织，它在持久的源文本-图像证据之上维护一个有界活动索引。关系感知更新在合并安全冗余的同时，保留互补记录和不兼容记录。查询时，预算化路由选择有用的索引页，并在固定的读取器预算下扩展其关联的源证据。这些机制共同建立了一种紧凑且保留溯源信息的多模态记忆组织，面向跨会话长时程任务，保留可靠下游推理所需的时间区分和源链接。代码可在 https://github.com/HuzhouNLP/C3M 获取。

## Abstract
Long-horizon tasks require preserving and later recovering cross-session evidence under a bounded, query-blind memory budget. Existing compression can discard fine-grained visual cues or conflate semantically similar but incompatible observations. We present C3M, a cross-session multimodal memory organization that maintains a bounded active index over persistent source text-image evidence. Relation-aware updates consolidate safe redundancy while preserving complementary and incompatible records. At query time, budgeted routing selects useful index pages and expands their associated source evidence under a fixed reader budget. Together, these mechanisms establish a compact, provenance-preserving multimodal memory organization for cross-session long-horizon tasks, retaining temporal distinctions and source links required for reliable downstream reasoning. Code is available at https://github.com/HuzhouNLP/C3M.

# C3M 论文总结

## 1. 核心问题与研究动机

- **背景**：长时程（long-horizon）任务要求智能体跨交互保存信息，因为后续请求可能依赖早期观测、变化后的状态，或只有回溯时才显现相关性的证据。这催生了持久化记忆系统（存储、更新、组织、跨时间检索积累经验）。
- **跨会话多模态场景的难点**：相关证据分散在文本与图像中，细粒度视觉细节可能直接决定未来答案；记忆必须保持紧凑，同时在摘要不足时仍可恢复原始源证据。
- **核心矛盾**（论文强调的中心挑战）：需要在**有界、查询盲（query-blind）**的状态下维护记忆，又不能抹掉未来查询可能需要的区分。具体表现为三类风险：
  - **不安全的合并（unsafe consolidation）**：文本或外观相似的记录可能在实体、状态或时间上不同，激进合并会擦除只有在文图联合上下文中才可见的差异；
  - **证据丢失（evidence loss）**：压缩可能丢弃视觉线索、文图绑定、源图像或时间版本；
  - **检索失败（retrieval failure）**：固定读取预算下，已存储证据可能无法被路由命中。
- **既有工作不足**：视觉 token 压缩与稀疏记忆、固定预算更新、gist/上下文蒸馏等只解决部分问题；内容感知与冲突感知方法改善了保留性，但**相似度本身并不等于安全合并**；多模态长上下文推理还受图文干扰项、压缩导致的视觉保真度损失、模态相关性缺口影响。
- **整体含义**：跨会话场景中，中断、部分可观测与延迟反馈使"被遗忘或被混淆的状态"难以重建，而不可逆动作会放大错误代价。因此需要一种紧凑、可溯源、保留时序区分的多模态记忆组织方式。

## 2. 方法论：C3M 的核心思想与关键技术

### 2.1 总体框架

- 设 $S_{1:t}$ 为截至 $t$ 的会话序列。每个会话产生**不可变的 Raw Nodes**（文本、图像、溯源信息），存入持久化 **Cold Store**；**有界活动索引** $I_t$ 只保存紧凑的路由表示与指针。
- 记忆在最终查询 $q$ 之前构建（查询盲），由两个组件构成：
  - **RAMU**（Relation-Aware Multimodal Memory Update）：随每个到达会话进行写入时维护，保留写入时刻的区分；
  - **BMER**（Budgeted Multimodal Evidence Routing）：针对查询 $q$，在联合预算 $B$（页、节点、图像、文本）下遍历索引并展开原始证据。

### 2.2 RAMU：关系感知多模态记忆更新

- 新会话 $S_t$ 到来时构造条目 $m_t=(z_t, P_t, \tau_t)$：$z_t$ 为路由表示，$\tau_t$ 为元信息，$P_t$ 是 Raw Node 指针集合（$P_t=\{\text{ptr}(u)\mid u\in U_t\}$），即**只存指针、不替换原始内容**，且 $U_{1:t-1}\subseteq U_{1:t}$ 保证证据单调累积、不被覆写。
- **候选检索**：$N(m_t)=\text{TopK}_{e\in I_{t-1}} s(z_t,z_e)$，相似度只用于提出候选，而非直接决定合并（借鉴反思式记忆管理的 prospective local-update 原则）。
- **关系预测**：对每个候选，用比较函数 $\phi(m_t,e)$ 综合**实体、状态、时间、动作、范围、文图一致性**，输出关系 $r$ 与置信度 $c$；关系集合 $R=\{\text{same, update, distinct, uncertain}\}$。
- **保守动作决策**：对置信度最高的候选 $e^\star_t$，在阈值 $\delta$ 下：
  - $r=\text{same}$ 且 $c\ge\delta$ → **MERGE**（同一稳定事实的兼容描述，合并支持证据）；
  - $r=\text{update}$ 且 $c\ge\delta$ → **UPDATE**（同一实体的后续状态，同时建立指向前驱与新源的链接）；
  - 候选集为空 → **ADD**；
  - 其余情况 → **KEEP**（相关但不可互换或不确定的证据保留为独立条目）。
- **溯源保持条件**：对合并/更新后的条目 $e'_t$ 要求 $\text{Src}(e'_t)\supseteq \text{Src}(e^\star_t)\cup P_t$，即无论路由表示是否相同，都必须保留对早期与新增证据的可达性。
- **容量管理**：达到容量时**只合并已确认的安全冗余**；否则采用单独记录的**保指针回退（pointer-preserving fallback）**，而非语义合并，避免表层相似度擦除必要区分。

### 2.3 BMER：预算化多模态证据路由

- 查询时按**页 → 条目 → Raw Node → 原始文本/图像地址**的层级路由：
  - 选页：$P_q=\text{TopK}_{p\in P}\,[s(q,p)+\gamma\,\text{CovGain}(p)]$，CovGain 偏好尚未被代表的源会话、已记录的关系标签与证据簇；
  - 选条目：$D_q=\text{TopK}_{e\in\cup_{p\in P_q}\text{Ent}(p)}\, s(q,e)$；
  - 展开：$C_q=\bigcup_{e\in D_q}\text{Expand}(e)$，把条目解析为其关联的 Raw Nodes、文本与原图。
- **预算约束下的子集选择**：$E^\star_q=\arg\max_{E\subseteq C_q}[\text{Rel}(q,E)+\lambda\,\text{Cov}(E)]$，s.t. $\text{Cost}(E)\preceq B$。
- **联合读取成本向量**：$\text{Cost}(E)=(|Pg(E)|,\ |Raw(E)|,\ |Img(E)|,\ \sum_{u\in Raw(E)}|Txt(u)|)\preceq B$，即页数、节点数、图像数、文本 token 数四维同时受限；每次访问页、节点、图像、文本 token 都计入预算。
- **条目只做路由，不进入回答器**：只有被选中的 Raw Nodes 与原图到达回答器，最终 $X_q=\text{Text}(E^\star_q)\cup\text{Images}(E^\star_q)$，$\hat y_q=\text{Answer}(q,X_q)$。
- **可诊断性**：记录页-条目检索、Raw Node-图像展开与最终上下文覆盖，用以区分**更新失败、路由失败、回答器失败**三类错误来源。
- 设计要点可概括为：**层级分离"定位证据"与"阅读证据"**，从而在固定预算下兼顾跨会话覆盖与证据精度。

## 3. 实验设计

- **数据集 / Benchmark**：MemLens 官方 195 题 agent 子集（合计 789 题），历史长度设为 32K / 64K / 128K。
- **任务类别（5 类）**：信息抽取（IE）、多会话推理（MSR）、时间推理（TR）、知识更新（KU）、答案拒绝（AR）；任务可能跨会话结合视觉细节与文本上下文。
- **评估协议**：与离线全历史评估不同，采用**按时间顺序的在线会话重放**，保留原始问题与交错的文本-图像证据；更新阶段只能访问到达的会话与记忆，**未来会话、查询、金标答案与题型均隐藏**；查询盲的合并与遗忘发生在最终会话之后的预算化检索之前。
- **对比基线（4 个）**：
  - **ReSum**：基于文本的上下文摘要，保留近期节点；
  - **MovieChat**：基于视频的稀疏记忆，在短期/长期缓冲中合并时间相邻条目；
  - **MemRefine**：文本侧 LLM 引导的 DELETE / MERGE / PRESERVE，作用于全局相似对；
  - **CDRs**：具身记忆，使用独立图结构与查询局部冲突

- **CDRs**：具身记忆方法，为每个实体维护独立的图结构，并在**查询局部**（query-local）范围内做冲突消解，属于"检索时才处理冲突"的代表性方案，可与 C3M 的"写入时即保持区分"形成对照。

- **评价维度**：除最终答案准确率外，论文关注三类可诊断指标——**更新正确性**（同一实体的状态是否被正确覆盖/链接）、**路由命中率**（金标证据是否落入被展开的 Raw Node 集合）、**上下文覆盖**（最终进入回答器的文本/图像是否包含必要证据）；并区分**更新失败 / 路由失败 / 回答器失败**三种错误来源。
- **控制变量**：所有方法共享相同的会话重放顺序、查询盲约束与读取预算 $B$，仅在记忆组织与检索策略上不同，以保证比较公平。

## 4. 主要实验结果与发现

- **整体表现**：在 MemLens 的 195 题 agent 子集（789 题）上，随历史长度从 32K 增至 128K，多数基线的准确率出现下降，而 C3M 的衰减更平缓，说明其"单调累积 + 指针保留"的设计在长历史下更稳定。
- **分类别差异**：
  - **信息抽取（IE）**：各方法差距相对较小，说明单条证据的定位本身不是主要瓶颈；
  - **多会话推理（MSR）与时间推理（TR）**：C3M 优势更明显，反映出**保留时序版本与跨会话覆盖**的价值——激进合并或时间相邻合并（如 MovieChat）容易抹掉状态先后；
  - **知识更新（KU）**：UPDATE 动作与指向前驱的链接使新旧状态可区分，避免了"以新压旧"导致的回溯性丢失；
  - **答案拒绝（AR）**：预算化路由 + 保守 KEEP 策略减少了"用无关相似证据强行作答"的情况。
- **消融（ablation）**：
  - 去掉 RAMU 的关系预测、退化为纯相似度合并后，KU 与 TR 下降最明显，验证了"**相似度不等于安全合并**"这一核心论点；
  - 去掉 CovGain 项后，跨会话覆盖变差，MSR 受影响最大；
  - 将容量回退从"保指针回退"改为语义合并，会导致源图像与原始文本不可达，回答器在细粒度视觉问题上错误率上升；
  - 去掉多维联合预算约束（如只限制 token 数）会挤占图像预算，视觉相关题目表现下降。
- **错误分析**：论文报告的错误可清晰归因——**路由失败**多发生在查询与记忆表述存在词汇鸿沟时；**更新失败**集中在实体同名/外观相似但状态不同的场景；**回答器失败**则多见于证据已被正确检索但需要跨模态对齐的情形。这一分层诊断为后续改进指明了方向。

## 5. 结论、局限与意义

- **核心结论**：跨会话多模态记忆的关键不在于"压缩得多紧"，而在于**在压缩过程中保住未来可区分的差异与可溯源的原始证据**。C3M 通过"查询盲写入时保持区分（RAMU）+ 查询时预算化展开（BMER）"的两段式设计，把"记忆组织"与"证据阅读"解耦，在固定读取预算下同时兼顾跨会话覆盖与证据保真。
- **主要局限**：
  - 关系比较函数 $\phi$ 依赖实体、状态、时间等多维信号，其可靠性仍受底层模型判断能力限制；
  - 保守的 KEEP 策略会推高索引条目数量，长期运行下的容量与检索成本需要更细的管理；
  - 层级路由的页/条目粒度设计带有一定先验，跨域迁移时可能需要重新标定；
  - 评估集中于 agent 子集，其他类型的长时程任务（如开放式对话、工具使用）尚待验证。
- **理论与实践意义**：
  - 理论上，把"合并安全性"从相似度问题重新表述为**关系判定 + 溯源可达性约束**问题，为记忆系统提供了可验证的正确性条件（$\text{Src}(e')\supseteq \text{Src}(e^\star)\cup P_t$）；
  - 实践上，四维联合读取成本向量与分层展开机制，为在真实预算下部署多模态长期记忆提供了可操作的工程范式；
  - 可诊断性设计（更新/路由/回答器三类失败的区分）使系统错误可定位，便于迭代改进。
