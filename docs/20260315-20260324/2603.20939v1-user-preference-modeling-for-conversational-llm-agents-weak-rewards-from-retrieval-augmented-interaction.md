## 摘要
大语言模型越来越多地被用作个人助手，但大多数模型缺乏持久的用户模型，导致用户不得不在不同会话中重复陈述偏好。我们提出了向量自适应检索评分（VARS），这是一个与流水线无关、冻结骨干网络的框架。该框架在共享偏好空间中利用长期和短期向量来表示每个用户，并使用这些向量来偏置结构化偏好记忆上的检索评分。这些向量根据用户反馈的弱标量奖励进行在线更新，从而在无需针对每个用户进行微调的情况下实现个性化。我们在 MultiSessionCollab 上进行了评估，这是一个具有丰富用户偏好配置文件的在线多会话协作基准测试，涵盖了数学和代码任务。在冻结骨干网络的情况下，用户感知检索的主要优势在于提高交互效率，而非大幅提升原始任务准确率：我们的完整 VARS 智能体实现了最强的综合性能，在任务成功率上与强大的 Reflection 基准相当，并降低了超时率和用户工作量。学习到的长期向量还与跨用户偏好重叠相一致，而短期向量则捕捉了特定会话的适应性，这支持了双向量设计的可解释性。代码、模型和数据可在 https://github.com/YurenHao0426/VARS 获取。

## Abstract
Large language models are increasingly used as personal assistants, yet most lack a persistent user model, forcing users to repeatedly restate preferences across sessions. We propose Vector-Adapted Retrieval Scoring (VARS), a pipeline-agnostic, frozen-backbone framework that represents each user with long-term and short-term vectors in a shared preference space and uses these vectors to bias retrieval scoring over structured preference memory. The vectors are updated online from weak scalar rewards from users' feedback, enabling personalization without per-user fine-tuning. We evaluate on \textsc{MultiSessionCollab}, an online multi-session collaboration benchmark with rich user preference profiles, across math and code tasks. Under frozen backbones, the main benefit of user-aware retrieval is improved interaction efficiency rather than large gains in raw task accuracy: our full VARS agent achieves the strongest overall performance, matches a strong Reflection baseline in task success, and reduces timeout rate and user effort. The learned long-term vectors also align with cross-user preference overlap, while short-term vectors capture session-specific adaptation, supporting the interpretability of the dual-vector design. Code, model, and data are available at https://github.com/YurenHao0426/VARS.

以下是对该论文的深度结构化总结：

### 1. 核心问题与研究动机
*   **核心问题**：现有的 LLM 助手通常缺乏持久的用户模型。用户在不同会话（Sessions）中必须重复陈述其特定的偏好（如代码风格、数学推导步骤等），导致长期协作效率低下。
*   **研究背景**：虽然现有的检索增强生成（RAG）或长短期记忆方案可以存储历史对话，但它们通常仅依赖查询相似度进行检索，缺乏一个能够随交互不断进化的“用户状态”来优先筛选最相关的偏好。
*   **研究目标**：开发一种无需对大模型进行昂贵的每用户微调（Per-user Fine-tuning），且能从用户微弱反馈中在线学习偏好的轻量级框架。

### 2. 方法论（VARS 框架）
VARS 采用“冻结骨干网络 + 学习用户向量”的思路，核心组件包括：
*   **偏好提取（Preference Extraction）**：使用一个轻量级微调模型（Qwen3-0.6B）将对话窗口转换为结构化的 JSON 偏好卡片（包含“条件”和“动作”）。
*   **双向量用户状态（Dual-Vector User State）**：
    *   **长期向量 ($z^{(L)}$)**：跨会话持久存在，捕捉用户稳定的风格偏好。
    *   **短期向量 ($z^{(S)}$)**：在会话内更新并指数级衰减，捕捉瞬时上下文。
*   **用户感知检索评分**：在冻结的重排序器（Reranker）得分基础上，增加一个用户向量与记忆卡片向量的内积项作为偏置：$s(u, m) = s_{base} + \langle z_{eff}, v_m \rangle$。
*   **在线强化学习更新**：
    *   **弱奖励信号**：通过关键词匹配（如“谢谢”、“错误”、“重做”）从用户的下一轮回复中提取标量奖励。
    *   **REINFORCE 更新**：利用该奖励信号，通过策略梯度算法在线调整用户向量，使向量向产生正向反馈的记忆卡片靠拢。

### 3. 实验设计
*   **数据集与场景**：使用 **MULTI SESSION COLLAB** 基准测试，涵盖数学（math-hard, math-500）和代码（bigcodebench）任务。
*   **实验设置**：模拟 60 个具有独特偏好配置文件的用户，每个用户进行 60 个会话，总计 3600 个会话。
*   **对比方法（Baselines）**：
    *   **Vanilla**：无记忆。
    *   **Contextual**：全历史拼接。
    *   **All-memory**：拼接所有提取的偏好。
    *   **Reflection**：基于会话摘要的反射机制（强基线）。
    *   **RAG**：标准检索，无用户向量。

### 4. 资源与算力
*   **模型训练**：偏好提取器（Qwen3-0.6B）在 **H200 GPU** 上进行了全参数微调（SFT），使用了约 56.4 万条样本。
*   **推理与评估**：使用 vLLM 部署。智能体模型为 Llama-3.1-8B-Instruct，用户模拟器为 Llama-3.3-70B-Instruct。
*   **算力消耗**：论文未明确给出总训练时长，但强调了 VARS 在推理时仅需计算低维向量内积，计算开销极低。

### 5. 实验数量与充分性
*   **实验规模**：进行了 3600 场完整的交互会话，规模较大，足以支撑统计显著性分析。
*   **消融实验**：针对长短期向量的作用、奖励函数的敏感性、检索门控机制等进行了详细的消融研究。
*   **客观性**：使用了配对 t 检验（Paired t-tests）来验证 VARS 相对于强基线（Reflection）的改进是否具有统计学意义。实验设计考虑了任务成功率、超时率和用户工作量等多个维度，较为全面。

### 6. 主要结论与发现
*   **效率提升是核心**：在冻结骨干模型的前提下，VARS 的主要贡献不在于大幅提升任务成功率（与 Reflection 相当），而在于**显著提高交互效率**。它降低了超时率，并减少了用户为了纠正模型而输入的 Token 数量。
*   **向量的可解释性**：学习到的长期向量在空间分布上与用户真实的偏好重叠度（Jaccard 相似度）呈正相关，证明向量确实捕捉到了用户身份特征。
*   **缓解偏好过载**：相比于简单的 RAG，VARS 通过用户向量偏置，能更精准地从庞大的记忆库中筛选出用户真正关心的偏好，避免了因注入过多无关偏好而导致的模型困惑。

### 7. 优点
*   **即插即用（Pipeline-agnostic）**：无需修改或微调核心 LLM，适用于任何冻结的骨干网络。
*   **在线进化**：能够通过交互过程中的弱信号（甚至不需要显式的点赞/点踩）自动优化用户模型。
*   **长短期分离**：双向量设计有效地平衡了用户的持久习惯与当前任务的临时需求。

### 8. 不足与局限
*   **模拟器偏差**：实验依赖于 LLM 模拟的用户，可能无法完全反映真实人类用户的耐心、反馈模糊性或偏好漂移。
*   **奖励信号简单**：目前主要依赖关键词匹配提取奖励，对于复杂或隐含的负面反馈捕捉能力有限。
*   **隐私风险**：持久化的用户偏好向量和结构化记忆卡片涉及用户画像，存在潜在的隐私泄露风险，需配合严格的数据管理。
*   **任务覆盖**：虽然涵盖了数学和代码，但在更具主观性的创意写作或开放式对话场景下的表现尚待验证。
