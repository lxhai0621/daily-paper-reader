## 摘要
我们提出了SimpleSearch-VL，一种高效、可靠且实用的多模态智能搜索框架。其核心思想是改进智能体自身的搜索与验证过程，而非扩展数据、工具或辅助模型组件。在效率方面，分解自适应展开（FAR）通过形成更具信息性的训练组来提高采样效率，同时利用冗余样本来缓解长尾延迟并暴露困难样本。在可靠性方面，SimpleSearch-VL执行证据验证推理，显式使用思维链验证来评估检索到的视觉和文本线索与原始上下文的相关性。在实用性方面，SimpleSearch-VL保持轻量级工具接口，并在智能体内部执行网页自摘要，无需额外外部依赖。仅使用5K监督工具交织轨迹和2K强化学习数据，SimpleSearch-VL分别将Qwen3-VL智能体基线在8B和30B-A3B变体上提升了平均15.8和16.0个点。SimpleSearch-VL-30B-A3B模型进一步实现了与智能体Gemini-3-Pro竞争的性能。

## Abstract
We present SimpleSearch-VL, an efficient, reliable, and practical framework for multimodal agentic search. Its core idea is to improve the agent's own search-and-verification process rather than scaling data, tools, or auxiliary model components. For efficiency, Factorized Adaptive Rollout (FAR) improves sampling efficiency by forming more informative training groups while using redundant samples to mitigate long-tail latency and expose hard samples. For reliability, SimpleSearch-VL performs evidence-verified reasoning, explicitly using chain-of-thought verification to assess the relevance of retrieved visual and textual cues to the original context. For practicality, SimpleSearch-VL keeps a lightweight tool interface and performs webpage self-summary within the agent, requiring no additional external dependencies. With only 5K supervised tool-interleaved trajectories and 2K RL data, SimpleSearch-VL improves Qwen3-VL agentic baselines by 15.8 and 16.0 average points for the 8B and 30B-A3B variants, respectively. The SimpleSearch-VL-30B-A3B model further achieves performance competitive with agentic Gemini-3-Pro.

## 1. 核心问题与整体含义（研究动机和背景）

多模态智能体搜索面临三大挑战：
- **效率**：多轮工具交互导致 rollout 生成存在长尾延迟，固定预算无法自适应停止或再分配。
- **可靠性**：检索到的视觉和文本证据可能看似合理但实际不匹配，缺乏显式验证机制。
- **实用性**：现有系统依赖复杂工具编排和外部模型（如独立的网页摘要器），部署和维护成本高。

本文提出 **SimpleSearch-VL**，核心思路是**改进智能体自身的搜索与验证过程**，而非扩展数据、工具或辅助模型组件，从而实现高效、可靠、实用的多模态智能搜索。

## 2. 方法论

### 核心思想
通过因子化自适应展开（FAR）优化 RL 中的 rollout 分配，通过证据验证推理提升检索可靠性，通过自摘要访问减少外部依赖。

### 关键技术细节

| 模块 | 描述 |
|------|------|
| **Factorized Adaptive Rollout (FAR)** | 将固定预算分配分解为两个维度：**Prompt Expansion**（增加候选 prompt 组）和 **Rollout Allocation**（水平扩展 rollout 数量）。信号评估使用“答案正确性”的组内变异（至少一个正确和一个错误）。扩展规则：只有当前组所有 rollout 都错误时才分配额外槽位，一旦出现正确结果则过滤后续冗余 rollout。停止条件：收集到足够有效组或达到预算阈值。组过滤：仅保留包含混合结果的组参与策略更新。 |
| **Evidence-Verified Reasoning** | 显式利用缩略图验证：`image_search` 工具返回匹配缩略图、标题和 URL，模型在利用之前检查视觉匹配一致性。文本搜索结果同样支持页面级验证。通过思维链暴露验证决策。 |
| **Self-Summarized Visit** | 对访问的网页，由策略模型自身根据提取目标（goal）生成简洁摘要，无需独立摘要模型。 |
| **Region-Level Cache** | 对重复的搜索框（通过 IoU ≥ 0.7 匹配）缓存结果，减少外部调用。 |
| **策略更新** | 使用 RLOO 估计器，基于完整组的留一化基线计算优势值，仅对策略生成 token 应用剪辑后的 PPO 目标。 |

### 工具接口
仅三种工具：`text_search`、`image_search`（支持多区域多图像索引）、`visit`（附带 goal 条件摘要）。

## 6. 主要结论与发现

1. SimpleSearch-VL 在 Qwen3-VL 基线上平均提升 **15.8 点（8B）** 和 **16.0 点（30B）**，性能超越多数同尺寸开源模型。

5. 自摘要比外部摘要更好（+1.8~2.6 点），且节省部署资源。
6. 数据高效：使用 7× 更少 SFT 和 4× 更少 RL 数据达到领先性能。

## 7. 优点

- **数据高效低成本**：仅 5K SFT + 2K RL 即可取得优异结果，训练只需单节点 8 H200，约 1 天。
- **FAR 创新**：首次将 rollout 预算分解为 Prompt Expansion 和 Rollout Allocation，在减少冗余计算同时暴露难样本。
- **显式证据验证**：通过缩略图匹配直接检查视觉检索结果，提升可靠性且开销极小。
- **自摘要消除外部依赖**：简化部署，保持端到端一致性。
- **轻量工具接口**：仅三种原语，易于扩展和复制。
- **全面消融**：系统评估了各组件的贡献，设计决策有充分依据。
- **公平对比**：在同一 benchmarking 协议下对比多种方法，结果可信。

## 8. 不足与局限

- **训练数据规模较小**：尽管高效，但 5K+2K 可能无法覆盖所有难例，泛化性未知。
- **多图像场景占比低**：SFT 中仅 7%，RL 中 20.2%，多图像推理能力可能受限。
- **失败案例分析**：存在实体选择错误（如误选 Taylor Swift）和细粒度证据提取失败，说明验证链路仍有漏洞。
- **仅基于 Qwen3-VL 基座**：方法性能可能受限于基座能力，未在其他模型（如 LLaVA、InternVL）上验证。
- **RL 奖励信号依赖 LLM judge**：当精确匹配不可用时，判断可能引入噪声。
- **地域/语言偏差**：训练数据来源多为英文及维基百科，可能缺少低资源语言或文化特定知识。
- **未报告方差**：实验结果均基于单次运行，未提供标准差或多次重复统计。
