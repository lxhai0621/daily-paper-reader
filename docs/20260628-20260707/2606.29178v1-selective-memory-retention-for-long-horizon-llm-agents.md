## 摘要
记忆对增强型LLM智能体何时重要？我们通过TraceRetain进行研究，这是一个轻量级框架，用于冻结LLM智能体中的有界外部记忆，根据可解释特征（成功、年龄、访问频率、冗余、特异性、相似性、下游效用）对条目进行评分，并在容量达到时驱逐得分最低的条目。在干净的ALFWorld上使用gpt-5-mini，外部记忆在两个种子下相比无记忆有显著改善，但不同有界保留策略之间的差异落在Wilson 95%置信区间内：干净的ALFWorld从T=100到T=200并未自然表现出记忆污染问题，而保留策略正是为此设计的。在受控的噪声写入压力（75%合成干扰项）下，无界记忆和FIFO-K50在Precision@5上下降（20.2%至12.4%和15.8%至3.8%），而TraceRetain-CEM基本不变（16.9%至16.6%），并保持了97/100的任务成功率。其机制是：无界记忆具有最高的平均相似度（0.87）但最低的精确度，表明失败的干扰项在嵌入空间中接近查询。在保留的分布内评估中，记忆增强策略在50个任务中解决了47到49个，而无记忆为39/50。在饱和的干净基准上，有界保留以零任务成功代价换取了记忆和步骤效率，仅在流包含噪声时才与缓存启发式方法有所区别。

## Abstract
When does retention matter for memory-augmented LLM agents? We study this with TraceRetain, a lightweight framework for bounded external memory in frozen LLM agents that scores entries by interpretable features (success, age, access frequency, redundancy, specificity, similarity, downstream utility) and evicts the lowest-scoring ones at capacity. On clean ALFWorld with gpt-5-mini, external memory robustly improves over no memory across two seeds, but differences among bounded retention policies fall within Wilson 95% CIs: clean ALFWorld at T=100 to T=200 does not naturally exhibit the memory pollution retention is designed to address. Under a controlled noisy-write stress (75% synthetic distractors), unbounded memory and FIFO-K50 degrade on Precision@5 (20.2% to 12.4% and 15.8% to 3.8%) while TraceRetain-CEM is essentially unchanged (16.9% to 16.6%) and preserves 97/100 task success. The mechanism: unbounded memory has the highest mean similarity (0.87) but lowest precision, indicating failed distractors close to the query in embedding space. Held-out in-distribution evaluation shows memory-augmented policies solving 47 to 49 of 50 tasks vs. 39/50 for no memory. Bounded retention buys memory and step efficiency on saturated clean benchmarks at no task-success cost, and only differentiates from cache heuristics when streams contain noise.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：LLM智能体依赖外部记忆进行长周期任务，但随着记忆积累，可能出现“记忆污染”——即检索到的记忆包含大量相似但无用的条目（如失败的轨迹、冗余信息），导致检索质量和下游行为下降。本文研究了一个实证问题：在当前的记忆增强型智能体基准测试中，**何时**记忆保留（即容量受限的驱逐策略）真正重要？
- **整体含义**：回答该问题的直接意义在于可持续的持续适应：有界记忆（bounded memory）可以限制检索时的候选集大小和提示词token开销，从而降低推理成本；如果保留策略不重要，开发者可以简单采用缓存启发式方法；如果重要，则需投入学习型保留策略的成本。本文通过提出的TraceRetain框架作为探针，对比多种策略，刻画了不同场景下的表现。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将外部记忆管理视为**容量有约束的保留问题**：智能体在执行任务流时，每完成一个任务，将轨迹摘要记录到记忆库中；当记忆库大小超过容量K时，必须驱逐部分记忆。保留策略通过评分函数决定哪些记忆保留。
- **关键技术细节**：
  - **特征向量**：对每个记忆条目，在时刻t计算一个特征向量φ(m_i, t)，包含12个可解释特征：成功/失败标志、归一化年龄、上次访问间隔、访问频率对数、特异性、冗余度、步骤效率、观察到的下游效用、效用计数置信度、上次检索相似度、平均检索相似度等。
  - **评分函数**：s_i = w^T φ(m_i, t)，其中w为特征权重向量。分数最低的记忆被驱逐。
  - **两种评分器变体**：
    - TraceRetain-Linear：固定权重（手工设定奖励成功、特定、高频记忆，惩罚陈旧、未使用、冗余、失败记忆），无需额外LLM调用。
    - TraceRetain-CEM：使用交叉熵方法（CEM）在20个任务的调优子集上搜索权重，优化由成功率、步骤效率和检索精确度组合的标量目标。搜索为黑箱种群搜索，非强化学习。
  - **检索机制**：使用嵌入相似度（text-embedding-3-large）检索最多k个记忆（top-5），然后作为上下文输入冻结的ReAct风格LLM（gpt-5-mini）。

1. **外部记忆显著提升任务成功率**：在所有四个条件下，有记忆策略相比无记忆都有稳定提升，配对符号检验绝大多数显著。
