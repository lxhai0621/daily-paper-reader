## 摘要
当多模态AI智能体被要求遗忘一个事实时，当前的记忆系统通常会删除文本条目并报告成功。我们发现，该事实仍可从保留的用户图像中恢复，包括标记给完全不同事实的图像，因为VLM在推理时会使用隐式视觉线索。我们引入了信息溯源图（IPG），这是一个按删除能力对记忆表示进行分类的分类体系。IPG揭示了删除通过多个渠道失败。我们的基准测试MemLeak通过删除级联测量了这一点：对具备删除能力的系统进行直接探测的恢复率<1%，但保留的相关文本可实现18.3%的恢复，保留的图像可实现12.0%的恢复（盲基线为0.0%，假阳性率为0.3%）——其中47%的图像泄露无法通过文本恢复。内容感知语义删除将图像残留降至2.0%。该残留出现在多个VLM、一个生产记忆系统以及真实Unsplash许可的照片中。双标注人员的人工验证（kappa=0.88）确认了评估者的可靠性。

## Abstract
When a multimodal AI agent is asked to forget a fact, current memory systems usually delete the text entry and report success. We find that the fact can remain recoverable from retained user images, including images tagged to entirely different facts, because VLMs use implicit visual cues at inference time. We introduce the Information Provenance Graph (IPG), a taxonomy that classifies memory representations by deletion affordance. The IPG reveals that deletion fails through multiple channels. Our benchmark, MemLeak, measures this across a deletion cascade: direct probing of deletion-capable systems yields <1%, but retained correlated text enables 18.3% recovery, and retained images enable 12.0% recovery (0.0% blind baseline, 0.3% FPR) -- with 47% of image leaks not text-recoverable. Content-aware semantic deletion reduces the image residual to 2.0%. The residual appears across multiple VLMs, a production memory system, and real Unsplash-licensed photographs. Dual-annotator human validation (kappa = 0.88) confirms judge reliability.

# MemLeak: 诊断多模态智能体记忆中的信息泄露

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当多模态AI智能体（如Mem0、Letta等）被要求遗忘某个用户事实时，当前系统通常只删除文本条目，但该事实仍可从保留的用户图像中恢复——即使这些图像与待删事实无关。这是因为视觉大语言模型（VLM）在推理时会利用图像中的隐式视觉线索（如地点、装备、场景等），跨通道重建出已删事实。
- **整体含义**：揭示了现有“记录级删除”范式的根本不足——事实在系统中的传播是多层级的（文本、嵌入、图像文件、图像嵌入、图边、衍生事实、行为模式），而当前系统仅能操作信息溯源图（IPG）中“可寻址”（addressable）的节点。该问题不仅是一个工程漏洞，更构成合规风险（如GDPR第17条要求的“遗忘权”），因为即使删除日志显示成功，信息仍可通过图像等渠道泄露。
- **研究动机**：提供诊断工具（MemLeak基准）和理论框架（IPG），帮助系统开发者测量、理解并缓解这类多通道泄漏，也为监管者提供行为验证思路。

## 2. 论文提出的方法论

### 2.1 核心思想：信息溯源图（IPG）

- 将每个用户事实 \( f \) 的表示为有向无环图 \( G_f = (V_f, E_f, \delta) \)：
  - **\( V_f \)**：所有表示节点（文本条目、文本嵌入、图像文件、图像嵌入、图边、隐式视觉特征、衍生事实、行为模式等）。
  - **\( E_f \)**：信息流边，表示节点间的派生关系。
  - **删除能力函数 \( \delta \)**：将节点分为三类：
    - **addressable（可寻址）**：系统可直接根据事实标识定位并删除。
    - **linked（可链接）**：仅当维护了从事实到该节点的溯源链接时才能删除。
    - **persistent（持久性）**：不受当前存储级删除机制影响（如隐式视觉特征），需要内容感知审计。
- **遗忘完备性**：\( FC_S(f) = |已删除节点| / |总节点| \)。
- **泄漏与通用推理的区别**：泄漏发生在“同一用户的保留数据（图像、嵌入等）被用于重建该用户已删事实”，而非模型本身的通用知识（如VLM能从埃菲尔铁塔照片认出巴黎不算泄漏）。

### 2.2 关键技术细节

- **MemLeak基准**：包含113个合成实体画像（每个20个事实，5类：位置、职业、偏好、关系、拥有物），其中38个多模态画像配有536张生成图像及523张Unsplash真实照片。
- **探测类型**：
  - P1（文本删除+图像探测）：最核心，测试保留图像能否泄漏已删事实。
  - P2（图像删除+文本探测）：对称测试。
  - P3（隐性持久性）：事实从未以文本存储，仅存在于图像中。
  - P4（跨图像重建）：从2-3张保留图像联合重建。
  - P5（行为残留）：行为模式在删除后仍持续。
- **评估指标**：跨模态泄漏率（CMLR），使用3模型LLM判断器集成（GPT-4.1、Claude Sonnet 4、Gemini 2.5 Flash），多数投票判定泄漏。人工验证（双标注者，Cohen’s κ=0.88）确保可靠性。
- **缓解措施——内容感知语义删除**：在删除文本+标记图像后，用VLM审计器扫描剩余图像，标记与已删事实语义相关的候选图像并移除。仅需一次额外VLM推理。

## 6. 论文的主要结论与发现

1. **事实级遗忘失败是多渠道的**：
   - 文本直接探测：<1%（所有删除系统）。
   - 保留相关文本泄漏：18.3%（文本相关性即可暗示已删事实）。
   - 保留图像泄漏：12.0%（图像提供额外且更难审计的通道）。
   - 两者叠加：47%的图像泄漏无法通过文本恢复。
2. **内容感知语义删除可大幅缓解图像泄漏**：从12.0%降至2.0%（需移除21%保留图像）。
3. **残留现象普遍**：在多个VLM（Claude Sonnet 4、GPT-4o）、生产系统（Mem0）和真实照片中均存在。
4. **单次内容感知审计（一次VLM推理）可消除6倍泄漏**（35/36基线泄漏被清除），但最后2.0%仍需表示级干预。
5. **对系统构建者的建议**：需实施溯源跟踪（级联删除标记图像）、添加VLM审计器（删除语义相关图像）、开发相关感知文本删除策略。

## 8. 不足与局限

- **数据合成**：主要结果基于生成画像和AI生成图像；虽然用Unsplash真实照片验证（结果一致），但库存照片仍非真实用户照片中的复杂关联（如社交关系、日常活动等），生态效度有限。

- **仅评估纯视觉模态**：未涉及音频、视频等其他模态的多模态记忆系统。
