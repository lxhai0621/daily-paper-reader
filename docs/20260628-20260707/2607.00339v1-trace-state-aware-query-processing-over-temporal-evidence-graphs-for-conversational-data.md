## 摘要
对话数据日益被用作长期运行助手和AI代理的持久用户状态来源。然而，由于对话自然演化（计划被修订、偏好改变、后续消息常常取代或与先前信息矛盾），查询这些数据仍然具有挑战性。现有的长期记忆管道大多将记忆视为独立的文本或向量对象，这种方法通常检索语义相似但过时的证据，对状态感知推理的支持有限。为解决此问题，我们提出TRACE，一个基于时序证据图的对演化对话数据进行查询处理的框架。TRACE将对话建模为跨越事件、会话和主题的分层图，并丰富了类型化的时序、因果、更新和矛盾关系。关键的是，该框架维护有效性注释，使过时事实对历史查询可用，但在当前状态答案中被折价。查询时，TRACE结合基于向量的笔记检索和图引导的证据搜索，生成有效性感知的支持路径和用于答案生成的混合上下文。这种设计将词汇召回与证据重建分离，实现对长对话历史的有限查询时间推理。在长对话问答（QA）基准上的实验表明，TRACE提升了时序和多跳推理，消融实验突显了层次结构、更新感知种子和路径基础证据的重要性。

## Abstract
Conversational data is increasingly used as a persistent source of user state for long-running assistants and AI agents. However, querying this data remains challenging because conversations naturally evolve: plans are revised, preferences change, and later messages frequently supersede or contradict earlier information. Existing long-memory pipelines largely treat memories as independent text or vector objects. This approach often retrieves semantically similar but stale evidence, offering limited support for state-aware reasoning. To address this problem, we present TRACE, a query processing framework over temporal evidence graphs for evolving conversational data. TRACE models conversations as a hierarchical graph spanning events, sessions, and topics, enriched with typed temporal, causal, update, and contradiction relations. Crucially, the framework maintains validity annotations so obsolete facts remain accessible for historical queries but are discounted for current-state answers. At query time, TRACE combines vector-based note retrieval with graph-guided evidence search, generating validity-aware support paths and a hybrid context for answer generation. This design separates lexical recall from evidence reconstruction, enabling bounded query-time reasoning over long conversational histories. Experiments on long-conversation query-answering (QA) benchmarks show that TRACE improves temporal and multi-hop reasoning, with ablations highlighting the importance of hierarchy, update-aware seeding, and path-grounded evidence.

## 2. 论文提出的方法论

### 核心思想
将对话建模为**分层时间证据图**，包含事件、会话和主题三层顶点，边类型包括支持（causes, enables, prevents, before）和演化（updates, contradicts），并维护**有效性注释**（validity score v ∈ {1, 0.5, 0}）以区分当前有效与过时事实。查询时结合**向量检索**（从笔记记忆N获取语义相关片段）与**图引导的证据搜索**（生成有效性感知支持路径），并采用**查询形状感知的答案计划**。

### 关键技术细节
- **离线图构建**：
  - 事件提取：从每个会话总结中提取事件顶点和内部边（`Devent(St)`）。
  - 跨会话链接：通过参与者和主题约束的门控（`A(e)`）限制候选对，减少组合爆炸。
  - 边推理：基于时间排序确定`before`边，LLM/规则推断支持/演化边。
  - 层次注入：通过关联事件-会话-主题（`Inc(ES) ∪ Inc(ET)`）形成统一遍历基质。
- **有效性语义**：
  - 更新边 `updates(en→eo)` 使旧事件 `v(eo)=0`，传播到因果依赖的事件（`v=0.5`）。
  - 矛盾边 `contradicts` 不改变有效性，但在路径评分中被惩罚。
  - 无效化因果边：`causes/prevents` 边从过时事件出发会被跳过。
- **在线查询处理**（算法1）：
  - **种子选择**：通过密集检索笔记获得事件顶点 `V0(q)`，并扩展实体、更新邻域、层次相关事件得到 `Vq`。
  - **路径生成**：从 `Vq` 双向遍历，应用三个硬剪枝规则（不跨越无效因果边、拒绝违反时间顺序的路径、移除连续矛盾边）。
  - **证据排名**：路径评分 `S(π) = α·NS + β·PC + γ·TC + δ·UV`，四个信号分别基于神经相关性、路径置信度（含边缘置信度和矛盾惩罚）、时序一致性、更新有效性。
  - **上下文组装与答案计划**：混合上下文包含笔记 `Cnote` 和图路径 `Cpath`，预算重新分配；根据查询形状选择答案计划（时序、偏好、多跳、事实）。
- **后置证据追踪**：可选阶段，利用生成答案重新评分路径以提供可审计的解释。

- **TRACE在长期对话QA上显著优于所有基线**：在LoCoMo上LLM judge得分0.661，比最强基线Nemori高5.7pp，比A-Mem高12.8pp；在LongMemEval S上比Nemori高4.5pp，比A-Mem高13.8pp。

- **混合上下文策略有效**：通过路径证据补充纯向量检索的盲点。
- **可解释性良好**：边审计准确率94%（事实）、89%（标签）；80%+的提示含足够线索；但时序边错误传播到路径忠实度。

## 7. 优点：方法或实验设计上的亮点

- **方法论创新**：将时间数据库的valid-time概念引入对话记忆，通过显式的update/contradict边和有效性传播机制处理事实演化，区别于传统RAG的平面检索。
- **模块化架构**：离线图构建与在线查询处理分离，支持增量更新（未实现但提及）；向量回忆与结构重建解耦。
- **查询形状感知计划**：针对不同问题类型（时序、偏好等）定制答案计划和提示，提升生成质量。
- **充分且公平的实验设计**：对比多种SOTA系统和两个不同系列骨干模型，排除骨干特定优势；使用标准LLM-judge和人工注释；进行详细消融和压力测试。
- **可解释性分析**：评估了三层可解释性（图本身、提示速览、后验路径忠实度），为可信AI提供证据。

## 8. 不足与局限

- **构建成本高**：离线图构建依赖大量LLM调用（尤其是LongMemEval S需要38+小时），不适用于实时或频繁更新的场景。
- **Stress Test效果有限**：valid_acc仅0.390，远低于Full-Context的0.542，表明部分更新链的分布式证据难以被有限路径遍历完全覆盖。
- **时序边精度不足**：边审计中时序标签准确率仅89%，同时间戳事件排序错误传播到路径评分和最终答案，导致路径忠实度在Temporal类别仅22.5%。
- **跨骨干鲁棒性的例外**：在DeepSeek-V4-Flash上，TRACE的temporal-reasoning类别被Nemori超越（0.656 vs 0.748），表明特定骨干可能放大不同策略的优势。
- **LongMemEval S上的适用性限制**：因缺少同一话题多轮矛盾，更新感知边数量极少（1-8条），构建中关闭了更新检测，使得TRACE在该基准的优势主要来自层次结构和路径遍历。
- **未探索多代理场景**：实验仅在单人对话上；与多智能体协作轨迹的兼容性未知。
- **计算资源不透明**：未报告GPU型号和数量，阻碍了成本和可复现性的评估。
