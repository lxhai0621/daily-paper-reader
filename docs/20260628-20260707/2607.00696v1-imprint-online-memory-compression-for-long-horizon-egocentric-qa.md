## 摘要
长时程自我中心问答涉及回答发生在过去数小时或数天的事件。这需要记忆表征既能保持检索有效性，又能随着数天或数周的记录进行扩展。现有长时程自我中心问答方法将记忆构建为观察结果的分层文本摘要。虽然这有效减少了记忆大小，但摘要优化的是描述性压缩而非检索：重复交互被吸收为粗略的文本描述，而不是作为显式、重复的记忆单元保留，使得长时程证据聚合变得困难。我们提出Imprint，一种以交互为中心的记忆框架，将长时程自我中心记忆制定为在线记忆压缩问题而非摘要问题。传入的观察结果首先表示为结构化的交互记录，并持续组织成重复出现的交互模式。利用人类记忆巩固信号——重复性、近因性和独特性，Imprint选择性地保留并压缩交互，形成紧凑的面向检索的记忆。我们在EgoLifeQA上评估了Imprint，这是一个为期七天的自我中心基准测试，包含需要推理查询前数小时至数天内发生交互的问题。使用相同的LLM，Imprint将问答准确率从31.0%提升至35.8%，与EgoRAG相比，基于证据的答案增加6倍，记忆占用减少2.3倍，检索延迟降低11.8倍。这些结果表明，记忆压缩为长时程自我中心问答提供了可扩展且检索有效的基础。

## Abstract
Long-horizon egocentric question answering involves answering about events that have occurred hours or days in the past. This requires memory representations that remain both retrieval-effective and scalable over days or weeks of recording. Existing long-horizon egocentric QA methods construct memory as hierarchical textual summaries of observations. While effective for reducing memory size, summarization optimizes for descriptive compression rather than retrieval: repeated interactions are absorbed into coarse textual descriptions instead of being preserved as explicit, recurring memory units, making long-horizon evidence aggregation difficult. We propose Imprint, an interaction-centric memory framework that formulates long-horizon egocentric memory as an online memory compression problem rather than summarization. Incoming observations are first represented as structured Interaction Records and continuously organized into recurring interaction patterns. Using human memory consolidation signals of recurrence, recency, and distinctiveness, Imprint selectively retains and compresses interactions into a compact retrieval-oriented memory. We evaluate Imprint on EgoLifeQA, a seven-day egocentric benchmark containing questions that require reasoning over interactions occurring hours to days before the query. With the same LLM, Imprint improves QA accuracy from 31.0% to 35.8%, increases evidence-grounded answers by $6\times$ compared with EgoRAG, reduces memory footprint by $2.3\times$, and decreases retrieval latency by $11.8\times$. These results demonstrate that memory compression provides a scalable and retrieval-effective foundation for long-horizon egocentric question answering.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：长时程自我中心问答（Long-Horizon Egocentric QA）需要回答关于过去数小时甚至数天前发生事件的问题。现有方法将原始视频转换为分层文本摘要来压缩记忆，但这种摘要优化的是**描述性压缩**而非**检索效率**：重复交互被抽象为粗粒度描述，丢失了结构化交互模式，导致长时间跨度的证据聚合困难（例如无法准确回答“最近是否更频繁地跳过午餐？”这类行为推理问题）。
- **背景**：早期自我中心数据集（如Ego4D）仅覆盖秒到小时级活动，而EgoLife等新基准提出多天连续记录。现有检索增强方法（如EgoRAG）使用分层字幕摘要，但检索质量受限于摘要丢失的交互结构。同时，认知记忆理论指出，人类记忆通过选择性巩固（基于重复性、近因性、独特性）实现高效长期存储，而现有方法未利用这些信号。
- **动机**：亟需一种既能保留交互结构、支持时间聚合，又能随记录增长保持可扩展性的记忆表征方法。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将长时程自我中心记忆构建转化为**在线记忆压缩**问题，而非文本摘要问题。通过结构化交互记录表示观测，并利用认知启发的显著性信号（频率、近因性、独特性）选择性地保留和合并交互，形成紧凑的检索导向记忆。
- **关键技术细节**：
  1. **交互记录（Interaction Records）**：每个观测被解析为结构化记录 `(person, action, object, start_time, end_time)`，使用LLM从字幕中提取。保留了交互参与者、动作、对象等结构化信息，避免摘要中的语义模糊。
  2. **在线压缩流程**（算法1）：
     - **事件原型分配**：对每个交互记录，使用句子编码器对其动作和对象进行嵌入，并加上最近 k 个历史交互形成上下文嵌入。将其分配给最相似的事件原型（余弦相似度 > δg），否则创建新原型（上限Nmax=300）。原型维护重复计数和最近时间戳，用于后续重要性评估。
     - **交互重要性评分**：基于三个认知信号计算权重 `w(f_i)`：
       - 频率：`log(1 + ν_nt)`（原型重复次数）
       - 近因性：`e^{-λΔT}`（距上次出现的时间衰减，λ=1.14）
       - 独特性：`1 / (1 + log(1+N_t))`（N_t为当前原型总数）
     - **交互合并**：保留重要性超过阈值 τ=0.2 的记录，然后与已有记忆条目（M）中的记录比较动作-对象嵌入和上下文嵌入，若相似（余弦 > δm=0.75）则合并为一条记忆条目（保持时间顺序和聚合重要性），否则创建新条目。
  3. **检索与问答**（算法2）：给定问题q，先由LLM分解为检索线索（对象、动作、时间约束等）。候选记忆条目根据加权相似度排序：`s_k = γ1 cos(entity) + γ2 cos(action) + γ3 * importance`（γ1=0.53, γ2=0.29, γ3=0.18）。取Top-5，若有时间约束则进一步过滤，最后LLM基于检索证据生成答案。对于实体日志、关系图、习惯洞察等类别，可直接从检索结果映射选项（设定阈值θ），否则调用LLM推理。

## 3. 实验设计

- **数据集**：EgoLifeQA [19]，一个3000道多选题的基准，来源于多人连续7天自我中心视频记录。实验使用了其中参与者Jake的500题基准（涵盖五个推理类别：ENTITY LOG、EVENT RECALL、RELATION MAP、HABIT INSIGHT、TASK MASTER）。
- **Benchmark**：对比方法为EgoRAG [19]（使用GPT-4o的官方结果，以及使用Qwen2.5-7B-Instruct复现版本）。为公平比较，Imprint和复现EgoRAG均使用相同字幕生成器（EgoGPT）和相同LLM（Qwen2.5-7B-Instruct）。
- **主要指标**：
  - 问答准确率（Accuracy）
  - 接地准确率（Grounded Accuracy, GA）：答案正确且其解释直接来源于检索到的交互记录字段（而非模型参数知识）。

## 6. 主要结论与发现

- Imprint相较EgoRAG（使用相同LLM）实现**QA准确率从31.0%提升至35.8%**，**接地准确率从10.8%提升至64.8%**（提升约6倍），表明交互中心记忆能更好地检索到支持证据。
- **记忆效率**：内存占用从EgoRAG的254.2 MB降至109 MB（降低2.3倍）；检索延迟从20.1秒/查询降至1.7秒/查询（提升11.8倍）。
- 分类别分析：在需要跨时间追踪实体、事件回忆、关系映射和习惯洞察的类别上提升显著（如HABIT INSIGHT接地准确率达80%），而在需要多步推理的Task Master上提升较小。
- 时间间隔分析：对于证据在24小时内的问题，接地准确率保持在53-64%，优于EgoRAG的<22%。
- 消融表明：事件原型分配和重要性评分对性能影响最大，验证了重复性、近因性和独特性三个信号的有效性。
- Imprint的压缩过程在连续7天记录中，记忆增长比EgoRAG慢，尤其在Day3后差距扩大，表明在线压缩有效抑制冗余。

## 7. 优点

- **方法论新颖**：将长期记忆建模为交互结构的在线压缩问题，而非文本摘要，更贴合认知记忆原理。
- **可解释性强**：重要性评分基于直观的认知概念（频率、近因、独特性），易于理解和调试；检索过程可追溯至具体交互记录。
- **效率与效果双赢**：在提高答案质量的同时显著降低存储和检索开销，适合未来长期穿戴设备场景。
- **实验设计严谨**：控制了字幕生成器和LLM，确保对比公平；提供了多种消融和超参数分析，验证了设计选择。
- **接地准确率指标**：引入GA指标区分真正基于记忆的答案与模型猜测，更具意义。

## 8. 不足与局限

- **依赖字幕质量**：交互记录从自动生成的字幕中提取，若字幕存在人物、动作、对象识别错误，会传播到整个记忆和检索过程（论文自身承认）。未评估字幕质量影响。
- **重要性分数为启发式**：当前使用固定数学模型（log、指数衰减），可能存在最优自适应策略；论文建议未来可探索可学习记忆启发式。
- **实验范围局限**：只在单一数据集（EgoLifeQA）的一个参与者（Jake）上验证，未测试其他参与者或更长时间（如数周）的记录。数据集类别分布不均匀（HABIT INSIGHT和TASK MASTER题目较少），可能影响统计可靠性。
- **未与多模态方法对比**：Imprint完全基于语言（字幕和LLM），未与直接利用视频特征的端到端方法对比；也未与最新的长上下文模型（如GPT-4-128k）进行公平比较（EgoRAG的GPT-4o结果36.0%高于Imprint的35.8%，但Imprint用更小模型Qwen2.5-7B）。
- **参数依赖性强**：多个阈值（δg, δm, τ, λ等）需要手动调参，可能存在过拟合当前数据集的风险。未提供跨数据集泛化测试。
- **实时性受限**：压缩仍需要批量处理字幕（3小时处理7天数据），并非真正的流式实时处理；且需要LLM提取交互记录，开销较大。
