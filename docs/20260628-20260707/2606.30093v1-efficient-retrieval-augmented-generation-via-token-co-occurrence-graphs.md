## 摘要
检索增强生成通过将生成过程锚定于外部知识来缓解大语言模型中的幻觉问题。然而，标准RAG方法在多跳推理中表现不佳。尽管近期基于图的RAG方法改进了互连块的检索，但它们通常依赖于计算昂贵且易出错的基于LLM的提取流水线。为解决这些问题，我们提出TIGRAG（Token-Induced GraphRAG），一种基于Token共现知识图谱的高效图增强RAG框架。TIGRAG利用滑动窗口共现统计直接建模Token之间的拓扑关系，从而实现可扩展的图构建。在推理阶段，它结合基于图的语义扩展和神经重排序来检索多跳推理所需的互连证据。具体而言，它引入了一种迭代的实体驱动检索策略，利用从先前检索上下文中提取的桥接实体逐步扩展查询。我们在三个广泛采用的多跳问答基准上评估了TIGRAG。实验结果表明，我们的框架在检索和下游问答任务上均持续优于稠密检索和基于图的RAG方法，同时大幅降低了索引时间、推理延迟和提示词占用。

## Abstract
Retrieval-Augmented Generation (RAG) mitigates hallucinations in Large Language Models (LLMs) by grounding the generation process on external knowledge. However, standard RAG approaches struggle with multi-hop reasoning. While recent graph-based RAG methods improve the retrieval of interconnected chunks, they often rely on computationally expensive and error-prone LLM-based extraction pipelines. To address these issues, we propose TIGRAG (Token-Induced GraphRAG), an efficient graph-augmented RAG framework based on a token co-occurrence Knowledge Graph. TIGRAG directly models topological relationships between tokens using sliding-window co-occurrence statistics, thus enabling scalable graph construction. During inference, it combines graph-based semantic expansion and neural reranking to retrieve interconnected evidence for multi-hop reasoning. Specifically, it introduces an iterative entity-driven retrieval strategy that progressively expands the query using bridging entities extracted from previously retrieved contexts. We evaluated TIGRAG on three widely adopted multi-hop Question Answering (QA) benchmarks. Experimental results demonstrated that our framework consistently outperforms dense retrieval and graph-based RAG methods in both retrieval and downstream QA tasks, while substantially reducing indexing time, inference latency, and prompt footprint.

### 1. 核心问题与整体含义
- **研究背景**：标准检索增强生成通过检索外部知识缓解LLM幻觉，但在多跳推理中失效（因文档被视为孤立单元）。图增强RAG通过知识图谱结构化检索可改善多跳推理，但传统图RAG依赖LLM进行实体和关系提取，导致计算开销大、延迟高，且提取错误会传播。
- **核心问题**：如何在不借助昂贵LLM的情况下，构建高效的图结构以支持多跳推理？
- **本文贡献**：提出TIGRAG（Token-Induced GraphRAG），基于**Token共现统计**构建轻量级知识图谱，无需LLM参与，再结合PPR语义扩展、动态候选池化与神经重排序，实现低延迟、高精度的多跳证据检索。

### 2. 方法：核心思想与关键技术
- **核心思想**：利用滑动窗口统计语料中token的共现频率，构建无向加权图（节点为token，边权重为共现频次），并通过图拓扑进行语义扩展。
- **离线图构建流程**：
  1. 将文档按句子切分，采用滑动窗口（窗口大小s=6，重叠o=2）生成文本块。
  2. 对每个块进行分词、去停用词、过滤短词/非数值token，得到有效token集。
  3. 对所有有效token，在块内用窗口大小w=4统计共现，构建图G=(N,E)，边权重为全局共现频次。
  4. 预计算每个文本块的稠密嵌入（使用Nomic Text 1.5模型）和token→块映射。
- **在线推理流程（单跳）**：
  1. 将用户查询经相同预处理得到种子token集（∩图中的节点）。
  2. **语义扩展**：以种子节点作为个性化向量，运行**个性化PageRank（PPR）**，取得分最高的γ个token作为扩展集Φμ，并L1归一化得分。
  3. **候选检索**：检索包含Φμ中任意token的块，使用**图加权BM25评分**：ρ(c,μ)=∑_{v∈Φμ∩Vc} p̂(v)·BM25(v,c)。
  4. **动态候选池**：按ρ降序排序，取累积得分达到阈值th_ρ=0.8的前α个块，形成动态池Pμ。
  5. **神经重排序**：计算查询嵌入与各候选块嵌入的余弦相似度，按相似度降序输出最终排序。
- **多跳推理**：
  1. 从第一跳输出的前ι=1个块中，使用NER提取命名实体，去重后构造扩展查询（原始查询+所有实体拼接）。
  2. 对新查询重复图检索和重排序，但重排序阶段使用每个实体分别与查询拼接后的嵌入计算相似度，取最大值作为块得分。
  3. 合并所有跳的结果，取每个块的最大相似度作为最终得分，选择前β=5个块作为LLM上下文。

### 7. 优点
- **方法创新**：完全用统计共现代替LLM提取，极大降低成本，同时保持图拓扑对多跳推理的支持。
- **动态过滤机制**：通过累积得分阈值自适应调整候选池规模，减少噪声。
- **多跳迭代策略**：利用NER提取桥接实体逐步扩展查询，避免固定向量检索局限。
- **实验全面**：不仅评估检索和生成，还比较索引、推理时间、上下文长度，验证实际可用性。
