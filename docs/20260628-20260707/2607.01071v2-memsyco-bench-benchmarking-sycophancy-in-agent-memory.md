## 摘要
记忆已成为现代基于LLM的代理的基石，支持其从单轮助手向长期协作者的演变。然而，记忆并非总是有益的：检索到的记忆常常引发谄媚这一关键问题，导致代理过度迎合用户，牺牲事实准确性或客观推理。尽管存在这一新兴风险，现有的记忆基准主要评估记忆是否被正确存储、检索或更新，而忽视了检索到的记忆如何影响下游推理和决策。为填补这一空白，我们提出了MemSyco-Bench，一个用于评估代理系统中记忆诱导的谄媚行为的综合基准。MemSyco-Bench衡量记忆何时应影响决策以及如何正确使用有效记忆。具体而言，它涵盖五个任务，评估代理是否能够拒绝将记忆作为事实证据、尊重其适用范围、解决记忆与客观证据之间的冲突、跟踪记忆更新，以及使用有效记忆进行个性化。所有相关资源已为社区收集，网址为https://github.com/XMUDeepLIT/MemSyco-Bench。

## Abstract
Memory has emerged as a cornerstone of modern LLM-based agents, supporting their evolution from single-turn assistants to long-term collaborators. However, memory is not always beneficial: retrieved memories often induce a critical issue of sycophancy, causing agents to over-align with the user at the cost of factual accuracy or objective reasoning. Despite this emerging risk, existing memory benchmarks primarily evaluate whether memories are correctly stored, retrieved, or updated, while overlooking how retrieved memories influence downstream reasoning and decision-making. To bridge this gap, we propose MemSyco-Bench, a comprehensive benchmark for evaluating memory-induced sycophancy in agent systems. MemSyco-Bench measures when memory should influence a decision and how valid memory should be used. Specifically, it covers five tasks that assess whether agents can reject memory as factual evidence, respect its applicable scope, resolve conflicts between memory and objective evidence, track memory updates, and use valid memory for personalization. All related resources are collected for the community at https://github.com/XMUDeepLIT/MemSyco-Bench.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **研究动机**：基于LLM的代理正从单轮助手发展为长期协作者，依赖长期记忆实现个性化、连续性。但记忆并非总是有益的——检索到的记忆会导致**记忆诱导的谄媚（Memory-induced Sycophancy）**，即代理过度迎合历史用户的信念或偏好，牺牲事实准确性或客观推理。
- **背景缺口**：现有记忆基准（如LongMemEval、LoCoMo、STALE、PersonaMem）主要评估记忆的存储、检索和更新，忽略检索后的记忆如何影响下游推理。它们假定检索成功的记忆即有用，无法系统评估何时记忆应被抑制、约束、更新或用于个性化。
- **整体含义**：提出**MemSyco-Bench**，一个专门评估记忆引起的谄媚行为的综合基准，填补“记忆对代理决策影响”的评估空白，推动更鲁棒的长期记忆代理系统的发展。

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
从两个互补问题出发：**何时应阻止记忆影响答案**？**何时应选择并使用记忆进行个性化**？通过五个任务类别覆盖记忆使用的完整决策边界。

### 关键技术细节
1. **记忆诱导的谄媚定义**：历史用户信息（事实记忆+偏好记忆）通过外部记忆库存储，检索后注入当前上下文，若代理将其误认为证据或过度使用，则产生谄媚。
2. **任务分类（5个任务）**：
   - **客观事实判断（Objective Fact Judgment）**：记忆应被拒绝作为事实证据（如用户喜欢某城市≠该城市是首都）。
   - **上下文范围控制（Contextual Scope Control）**：记忆有适用范围，不能超越当前主体、受众或约束（如用户偏好简洁写作不适用于团队详细报告）。
   - **记忆-证据冲突（Memory-Evidence Conflict）**：当记忆与客观证据冲突时，应优先证据。
   - **有效记忆选择（Valid Memory Selection）**：用户偏好更新后，代理应选择当前有效偏好而非过时偏好。
   - **个性化记忆使用（Personalized Memory Use）**：当需要个性化时，应正确使用有效记忆改善响应。
3. **基准构建流程**：四步流水线：
   - **记忆-决策模式构建**：为每个任务定义模式（任务目标、答案空间、所需信息、记忆角色）。
   - **问题实例化**：从模式推导历史记忆片段和问题，确定目标答案和记忆误导答案。
   - **多轮对话模拟**：将记忆片段嵌入自然对话历史（约10轮），最终提问不透露评估目标。
   - **多阶段质量验证**：检查语义相关、记忆-决策边界清晰、失败方向可识别。仅保留通过验证的实例。
4. **评估指标**：
   - 所有任务：**生成准确率（Acc）**。
   - 前三个任务（记忆不应替代证据）：**谄媚率（Syco. Rate）**。
   - 后两个任务（选择/使用记忆）：**正确记忆使用率（Correct Mem. Use）** 和 **过时记忆使用率（Outdated Mem.）**。

## 6. 论文的主要结论与发现
1. **现有记忆系统不能可靠缓解记忆诱导的谄媚**：增加记忆后，大多数系统的准确率下降、谄媚率上升（Table1中多次-号）。
2. **错误主要来自检索后决策失败**：61-62%错误发生在正确检索后（R+/A-），尤其在A-Mem中达64-75%。
3. **记忆谨慎指令有益但损害个性化**：在记忆-证据冲突任务中提升明显（Full Dialog提升31.6%），但持续损害个性化记忆使用（下降13-21%）。
4. **确认指令反而强化谄媚**：“Are you sure?”使代理更坚持错误，尤其个性化记忆使用下降22-46%。
5. **复杂场景暴露双重失败**：冲突任务中，仅检索事实证据不够（A-Mem检索全部仍仅25.91%准确）；更新任务中，旧+新记忆同时检索时准确率下降。
6. **效率与校准存在权衡**：紧凑记忆系统（Mem0、LightMem）输入Token少但可能丢失必要上下文，导致更高谄媚；A-Mem输入最多但校准并非最好。
