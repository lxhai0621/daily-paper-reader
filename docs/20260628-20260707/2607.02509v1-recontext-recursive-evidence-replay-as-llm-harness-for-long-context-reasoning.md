## 摘要
理解和推理长上下文已成为在现实应用中部署大型语言模型的关键要求。尽管近期的大型语言模型支持越来越长的上下文窗口，但它们通常无法利用输入中已有的相关证据，揭示了上下文访问与有效上下文利用之间的差距。在这项工作中，我们提出递归证据重放作为大型语言模型的长上下文推理工具（RECONTEXT），这是一种无需训练的推理方法，用于改进长上下文推理。RECONTEXT利用模型内部的相关性信号构建查询条件的证据池，并在最终生成之前重放它，同时保留完整的原始上下文。这种递归选择过程将证据组织与答案生成分离，无需训练、外部记忆或上下文修剪。我们还基于关联记忆提供了理论分析，将上下文表征为记忆存储，问题作为检索线索，注意力作为线索-痕迹关联，重放作为痕迹再激活。在八个128K上下文长度的长上下文数据集上的实验表明，RECONTEXT在Qwen3-4B、Qwen3-8B和Llama3-8B上一致地提高了证据利用，在所有三个骨干模型上取得了最佳平均排名。代码可在https://github.com/Yanjun-Zhao/ReContext获取。

## Abstract
Understanding and reasoning over long contexts has become a key requirement for deploying large language models (LLMs) in realistic applications. Although recent LLMs support increasingly long context windows, they often fail to use relevant evidence that is already present in the input, revealing a gap between context access and effective context utilization. In this work, we propose Recursive Evidence Replay as LLM Harness for Long-Context Reasoning (RECONTEXT), a training-free inference method for improving long-context reasoning. RECONTEXT uses model-internal relevance signals to construct a query-conditioned evidence pool and replays it before final generation while preserving the full original context. This recursive selection process separates evidence organization from answer generation without training, external memory, or context pruning. We also provide a theoretical analysis based on associative memory, which characterizes the context as a memory store, the question as a retrieval cue, attention as cue-trace association, and replay as trace reactivation. Experiments on eight long-context datasets with 128K context length show that RECONTEXT consistently improves evidence utilization across Qwen3-4B, Qwen3-8B, and Llama3-8B, achieving the best average rank on all three backbones. Code is available at https://github.com/Yanjun-Zhao/ReContext.

- **问题：** 当代大型语言模型（LLM）虽然能够处理极长的上下文（如128K tokens），但在推理时常常「看得见，用不上」——证据明明存在于输入中，模型却无法有效定位和利用，导致回答错误或产生幻觉。这一现象被称为**上下文访问与有效利用之间的差距**。
- **整体含义：** 论文指出，解决这一问题不能只靠扩展上下文窗口或简单压缩输入，而需要一种**上下文驾驭（Context Harness）**机制——在不丢失任何原始信息的前提下，动态识别、组织并强调与当前问题最相关的证据，从而提升长上下文推理的可靠性。

## 2. 论文提出的方法论

### 2.1 核心思想
- **RECONTEXT** 是一种**完全不需要额外训练**的推理阶段方法。
- 它利用**模型自身内部的注意力信号**（问题token对上下文token的注意力权重）来识别候选证据，将这些零散的token映射回完整的句子，形成一个有序的**证据池**。
- 在生成最终答案之前，模型会**递归地**（多个回合）更新这个证据池：每一轮都基于当前的提示（包含完整上下文、已有证据池和问题）重新计算注意力，挑选出与之前证据相关的新证据，添加到池中。
- 最终，模型在**完整上下文 + 证据池 + 问题**的提示下生成答案。原始上下文始终保持完整，证据池仅用于突显，不剪枝任何内容。

### 2.2 关键技术细节
- **证据选择：** 使用提示的末尾少量token（如8个）作为「线索token」，计算它们对所有上下文token的平均注意力，经过指数衰减和归一化得到每个token的相关性分数。选取分数最高的K个token位置。
- **证据具体化（Materialization）：** 将选中的token位置映射回其所属的完整句子，保留句子的自然语言表达，形成可读的证据片段。
- **递归过程：** 设初始证据池\(E^{(0)}=\emptyset\)。在第j轮，提示为\([C;\phi(E^{(j-1)});q]\)，其中C是完整上下文，\(\phi\)是证据格式化函数，q是问题。模型读取该提示后，从**原始上下文C**（而非整个提示）中根据新的注意力分数挑选新证据，将尚未出现在池中的证据追加到池中。经过固定轮数R（如2轮）后，最终生成答案。
- **理论分析：** 将上下文视为记忆存储，问题为检索线索，注意力为线索-痕迹关联，证据重放为痕迹再激活。论文证明了每一步重放后，模型隐藏表示与答案嵌入向量的余弦相似度严格单调递增。

## 3. 实验设计

- **数据集（8个长上下文基准）：** 采用HELMET构建的6个QA数据集（NQ、TriviaQA、HotpotQA、PopQA、NarrativeQA、InfBench QA）、InfBench MC（多项选择）和CLIPPER（长文本声明验证）。所有数据集均使用128K上下文长度。

## 6. 主要结论与发现

- **RECONTEXT在所有三个骨干模型上均取得最佳平均排名**（Qwen3-4B: 1.00, Qwen3-8B: 1.46, Llama3-8B: 1.29）。
- **平均准确率从Vanilla的0.24提升至0.30，相对提升24.6%**（跨三个骨干、八个数据集的Acc平均）。
- 递归选择（多轮）相比单轮有了显著提升，说明条件于已有证据可以发掘更深层次的相关信息。
- 保留完整上下文、仅强调证据，优于压缩或外部记忆方法。
- 理论证明支持了证据重放能单调改进表示与答案的相似度，为现象提供了数学解释。

## 7. 优点

- **训练无关**：不改变模型参数，不依赖额外数据集，可即插即用。
- **保留完整上下文**：避免信息丢失，同时通过证据池提供显式聚焦。
- **利用模型内在信号**：无需外部检索系统，注意力分数自然反映问题相关性。
- **递归机制**：能逐步发现与已有证据链相关的新证据，适合多跳推理。
- **理论支撑**：基于关联记忆模型提供了严格的单调改进证明。
- **实验全面**：覆盖多模型、多任务、多超参数消融，并进行了鲁棒性验证。

## 8. 不足与局限

- **需要模型内部注意力信号**：无法直接用于不开放注意力的闭源API（如GPT-4 API），限制了应用范围。
- **推理延迟增加**：虽然比DySCO快，但相比Vanilla仍需额外时间（约40%增加），对实时性要求高的场景不友好。
- **超参数任务依赖**：最佳递归轮数R和token预算K因任务而异，缺乏统一最优设置。
- **上下文长度探索有限**：实验仅在128K和64K下进行，未测试更长（如1M或以上）场景下方法的有效性。
- **注意力噪声风险**：证据选择完全依赖注意力分数，若模型注意力存在偏差，可能引入噪音证据，影响生成质量。
