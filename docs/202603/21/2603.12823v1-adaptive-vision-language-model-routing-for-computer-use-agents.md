## 摘要
计算机使用智能体（CUA）通过依赖视觉语言模型（VLM）来解释屏幕截图并预测定位的工具调用，从而将自然语言指令转换为图形用户界面（GUI）操作（如点击、按键和滚动）。然而，不同 VLM 的定位准确率差异巨大，而目前的 CUA 系统通常不考虑任务难度，将每个操作都路由到单个固定模型。我们提出了自适应 VLM 路由（AVR），这是一个在 CUA 编排器和 VLM 池之间插入轻量级语义路由层的框架。对于每个工具调用，AVR 从多模态嵌入中估计操作难度，探测小型 VLM 以测量置信度，并将操作路由到其预测准确率满足目标可靠性阈值的最廉价模型。对于具有先前 UI 交互记忆的“热”智能体，检索到的上下文进一步缩小了小型模型和大型模型之间的能力差距，使得许多操作无需升级即可处理。我们将路由形式化为成本与准确率的权衡，推导出基于阈值的模型选择策略，并使用 ScreenSpot-Pro 定位数据以及 OpenClaw 智能体路由基准对 AVR 进行评估。在这些设置下，AVR 预计可降低高达 78% 的推理成本，同时与全大模型基准相比，准确率差距保持在 2 个百分点以内。当与 Visual Confused Deputy 护栏结合使用时，AVR 还会将高风险操作直接升级到最强的可用模型，从而在单一路由框架内实现了效率与安全性的统一。相关模型、基准和代码已提供：https://github.com/vllm-project/semantic-router。

## Abstract
Computer Use Agents (CUAs) translate natural-language instructions into Graphical User Interface (GUI) actions such as clicks, keystrokes, and scrolls by relying on a Vision-Language Model (VLM) to interpret screenshots and predict grounded tool calls. However, grounding accuracy varies dramatically across VLMs, while current CUA systems typically route every action to a single fixed model regardless of difficulty. We propose \textbf{Adaptive VLM Routing} (AVR), a framework that inserts a lightweight semantic routing layer between the CUA orchestrator and a pool of VLMs. For each tool call, AVR estimates action difficulty from multimodal embeddings, probes a small VLM to measure confidence, and routes the action to the cheapest model whose predicted accuracy satisfies a target reliability threshold. For \textit{warm} agents with memory of prior UI interactions, retrieved context further narrows the capability gap between small and large models, allowing many actions to be handled without escalation. We formalize routing as a cost--accuracy trade-off, derive a threshold-based policy for model selection, and evaluate AVR using ScreenSpot-Pro grounding data together with the OpenClaw agent routing benchmark. Across these settings, AVR projects inference cost reductions of up to 78\% while staying within 2 percentage points of an all-large-model baseline. When combined with the Visual Confused Deputy guardrail, AVR also escalates high-risk actions directly to the strongest available model, unifying efficiency and safety within a single routing framework. Materials are also provided Model, benchmark, and code: https://github.com/vllm-project/semantic-router.

*   **核心问题**：当前的计算机使用智能体（CUA）在执行任务（如点击、滚动、输入）时，通常对每一个步骤都调用昂贵的顶级视觉语言模型（VLM，如 GPT-4o 或 Qwen2.5-VL-72B）。
*   **研究动机**：
    *   **成本高昂**：一个多步任务可能产生数十万个 Token，单次任务成本可达 0.10-0.40 美元，难以大规模部署。
    *   **能力非线性缩放**：实验表明，模型参数量增加并不等同于 GUI 定位精度的线性提升（例如 7B 的专用模型在某些任务上优于 1.8T 的通用模型）。
    *   **任务难度差异**：点击大按钮很简单，但在复杂 IDE 中寻找小图标很难。对简单任务使用大模型是资源浪费。
*   **整体含义**：提出一种自适应路由框架（AVR），通过动态选择最经济且够用的模型，在保持高精度的前提下大幅降低推理成本。

### 2. 论文提出的方法论：AVR 框架
AVR 在智能体编排器和模型池之间插入了一个语义路由层，核心流程如下：
*   **难度分类（Difficulty Classification）**：利用轻量级多模态嵌入模型（120M 参数）提取截图区域和动作描述的特征，通过与已知“难/易”案例库对比，计算视觉和语义难度得分 $d(t_i)$。
*   **置信度探测（Logprob Probing）**：先对小型 VLM（如 7B）进行非流式探测，获取其输出 Token 的平均对数概率（Logprobs）作为置信度分数 $\text{conf}(t_i)$。
*   **记忆补偿（Memory Compensation）**：针对“热”智能体（已有交互记录），从记忆库中检索相关 UI 上下文注入 Prompt。研究发现，记忆对小模型的能力提升远超大模型，能有效缩小两者差距。
*   **路由决策逻辑**：
    *   **简单/高置信度**：由小型 VLM 处理。
    *   **困难/低置信度**：升级（Escalate）至大型 VLM。
    *   **高风险动作**：触发安全护栏（Visual Confused Deputy），直接强制路由至最强模型并进行二次验证。

*   **实验规模**：分析了 26 个专业软件场景下的定位表现，涵盖了从简单的浏览器到复杂的 CAD、视频剪辑软件。

### 6. 主要结论与发现
*   **成本大幅下降**：在保持与全大模型基准误差小于 2% 的情况下，AVR 预计可降低 **52%（冷启动）至 78%（热启动+难度分类）** 的推理成本。
*   **记忆是“等化器”**：记忆注入能显著提升小模型的置信度（从 0.83 提升至 0.96），使其在特定上下文中表现接近大模型。
*   **难度比模型更关键**：不同应用间的难度差异（精度波动达 7 倍）远大于同一家族内不同规模模型的精度差异。

### 7. 优点
*   **效率与安全统一**：首次将成本优化路由与安全护栏（防范视觉欺骗攻击）整合在同一个决策框架内。
*   **即插即用**：作为透明代理存在，无需对底层 VLM 进行微调，易于集成到现有 CUA 系统中。
*   **冷热启动兼顾**：既考虑了新任务的难度预判，也利用了长期交互产生的记忆红利。

### 8. 不足与局限
*   **端到端实测缺失**：部分核心结论（如表 4 的成本节省）是基于数据投影计算的，缺乏在 OSWorld 等实时交互环境下的闭环性能数据。
*   **延迟开销**：虽然小模型生成快，但“探测-决策-再请求”的流程引入了一次额外的往返时延（RTT），对于极短任务可能不划算。
*   **记忆冷启动**：对于完全陌生的应用程序，AVR 的优势受限于难度分类器的覆盖范围，初期可能存在过度升级的情况。
