## 摘要
虽然大语言模型（LLMs）为机器人任务规划提供了语义灵活性，但它们易受幻觉和逻辑不一致的影响，限制了其在长程领域中的可靠性。为了弥合非结构化环境与严谨规划合成之间的差距，我们提出了 DUPLEX，这是一种智能体双系统神经符号架构，它将 LLM 严格限制在模式引导的信息提取上，而非端到端规划或代码生成。在我们的框架中，前馈快系统（Fast System）利用轻量级 LLM 从自然语言中提取实体、关系等，并将其确定性地映射到经典符号规划器的规划领域定义语言（PDDL）问题文件中。为了解决复杂或描述不足的场景，慢系统（Slow System）仅在规划失败时激活，利用求解器的诊断信息驱动高容量 LLM 进行迭代反思和修复。在 12 个经典和家庭规划领域进行的广泛评估表明，DUPLEX 在成功率和可靠性方面均显著优于现有的端到端和混合 LLM 基线。这些结果证实，关键不在于让 LLM 更好地进行规划，而是将其限制在它擅长的部分——结构化语义落地（semantic grounding），并将逻辑规划合成留给符号规划器。

## Abstract
While Large Language Models (LLMs) provide semantic flexibility for robotic task planning, their susceptibility to hallucination and logical inconsistency limits their reliability in long-horizon domains. To bridge the gap between unstructured environments and rigorous plan synthesis, we propose DUPLEX, an agentic dual-system neuro-symbolic architecture that strictly confines the LLM to schema-guided information extraction rather than end-to-end planning or code generation. In our framework, a feed-forward Fast System utilizes a lightweight LLM to extract entities, relations etc. from natural language, deterministically mapping them into a Planning Domain Definition Language (PDDL) problem file for a classical symbolic planner. To resolve complex or underspecified scenarios, a Slow System is activated exclusively upon planning failure, leveraging solver diagnostics to drive a high-capacity LLM in iterative reflection and repair. Extensive evaluations across 12 classical and household planning domains demonstrate that DUPLEX significantly outperforms existing end-to-end and hybrid LLM baselines in both success rate and reliability. These results confirm that The key is not to make the LLM plan better, but to restrict the LLM to the part it is good at - structured semantic grounding - and leave logical plan synthesis to a symbolic planner.

### 1. 核心问题与研究动机
*   **核心问题**：大语言模型（LLM）在处理长程（Long-horizon）机器人任务规划时，虽然具备出色的语义理解能力，但极易产生**幻觉**、**逻辑不一致**以及**违反物理约束**等问题。
*   **研究背景**：传统的符号规划器（如基于 PDDL 的规划器）逻辑严密且可验证，但存在“知识获取瓶颈”，即难以将非结构化的现实环境自动转化为严谨的符号表示。现有的神经符号方法（如 LLM+P）尝试让 LLM 直接编写 PDDL 代码，但在复杂场景下，LLM 生成的代码往往存在语法或逻辑错误，导致规划失败。
*   **核心理念**：论文认为不应让 LLM 直接进行规划或写代码，而应将其限制在它最擅长的任务上——**模式引导的信息提取（IE）**，而将逻辑合成交给符号规划器。

### 2. 方法论
DUPLEX 提出了一种**智能体双系统架构**，模拟人类认知的“快慢系统”：
*   **快系统（Fast System - 前馈路径）**：
    1.  **引导式信息提取**：利用轻量级 LLM（如 Qwen3-8B）根据预定义的 Schema（来自领域 PDDL 文件），从自然语言描述中提取实体（Objects）、关系（Relations）和状态（States）。
    2.  **确定性映射**：使用预编写的脚本将提取的结构化信息（JSON）自动填充到 PDDL 问题文件模板中，确保 100% 的语法正确性。
    3.  **符号规划**：调用经典规划器（如 Fast Downward）生成动作序列。
*   **慢系统（Slow System - 反思路径）**：
    *   **触发机制**：仅在快系统规划失败（如规划器报错或找不到解）时激活。
    *   **智能体反思**：利用高容量 LLM（如 GPT-4o）作为诊断代理，分析规划器的错误诊断信息，识别缺失的隐式状态或语义错误，并迭代修复 PDDL 文件，直到获得可行解。
*   **分层验证机制**：涵盖规则级（语法）、语义级（幻觉纠正）和逻辑级（因果推理）三个层面的错误修复。

### 7. 优点
*   **架构优雅**：将非确定性的语义处理（LLM）与确定性的逻辑搜索（符号规划器）解耦，取长补短。
*   **高可靠性**：通过脚本映射规避了 LLM 生成 PDDL 语法错误的问题，通过反思机制解决了逻辑遗漏问题。
*   **效率平衡**：双系统设计确保了简单任务的快速响应和复杂任务的深度思考。

*   **模态限制**：目前主要依赖文本提取，在视觉信息丰富的环境中，可能存在指代歧义或观察遗漏。
