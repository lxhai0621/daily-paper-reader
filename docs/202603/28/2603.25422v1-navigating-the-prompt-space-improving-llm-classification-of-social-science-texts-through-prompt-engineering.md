## 摘要
近期在社会科学领域利用大语言模型（LLMs）进行文本分类的发展表明，成本可以显著降低，而性能有时可以与现有的计算方法相媲美。然而，由于当前测试中性能表现差异巨大，我们转向了如何最大化性能的问题。在本文中，我们关注提示上下文（prompt context）作为提高准确性的可能途径，通过系统地改变提示工程的三个方面：标签描述、指令引导（instructional nudges）和少样本示例。通过两个不同的示例，我们的测试表明，提示上下文的极小增加能带来最大的性能提升，而此后进一步增加上下文往往只能产生边际性能增长。令人担忧的是，增加提示上下文有时反而会降低准确性。此外，我们的测试表明模型、任务和批处理大小（batch size）之间存在显著的异质性，这强调了对每个 LLM 编码任务进行单独验证的必要性，而非依赖通用规则。

## Abstract
Recent developments in text classification using Large Language Models (LLMs) in the social sciences suggest that costs can be cut significantly, while performance can sometimes rival existing computational methods. However, with a wide variance in performance in current tests, we move to the question of how to maximize performance. In this paper, we focus on prompt context as a possible avenue for increasing accuracy by systematically varying three aspects of prompt engineering: label descriptions, instructional nudges, and few shot examples. Across two different examples, our tests illustrate that a minimal increase in prompt context yields the highest increase in performance, while further increases in context only tend to yield marginal performance increases thereafter. Alarmingly, increasing prompt context sometimes decreases accuracy. Furthermore, our tests suggest substantial heterogeneity across models, tasks, and batch size, underlining the need for individual validation of each LLM coding task rather than reliance on general rules.

*   **核心问题**：如何通过系统性地调整提示词上下文（Prompt Context）来最大化社会科学文本分类的准确率？

### 2. 方法论
论文通过系统性地改变提示词的三个核心维度来构建实验框架：
*   **标签描述（Label Descriptions）**：对比仅提供类别名称与提供来自官方代码簿（Codebook）的详细定义。
*   **指令引导（Instructional Nudges）**：加入基于领域知识的特定注意事项（例如：明确规定“堕胎”相关法案应归类为“民权”而非“健康”）。
*   **少样本示例（Few-shot Examples）**：对比零样本（Zero-shot）与为每个类别提供少量标注示例。
*   **关键技术细节**：研究还引入了**批处理大小（Batch Size）**的变量（从1到1000），探讨在单次调用中处理多个文本对性能和成本的影响。

*   **Benchmark**：以人类专家标注的真实标签（Ground Truth）作为基准。
*   **对比模型**：选择了 OpenAI 的 **GPT-4o** 和 Google 的 **Gemini 2.0 Flash**。
*   **对比方法**：对上述三个提示词维度进行全组合测试（共 $2^3=8$ 种配置），并在不同批处理大小下重复实验。

*   **算力说明**：论文未提及具体的本地 GPU 硬件（如 A100/H100 数量），因为研究主要通过 API 调用闭源模型（GPT-4o 和 Gemini 2.0 Flash）。

*   **实验规模**：研究涵盖了2个不同性质的任务（多分类 vs 二分类）、2个主流模型、8种提示词配置以及5种批处理梯度。

### 6. 主要结论与发现
*   **边际效应递减**：极小幅度的上下文增加（如仅加入标签描述）能带来最大的性能提升；随后进一步增加上下文（如同时加入示例和引导）带来的收益趋于平缓。

*   **非确定性**：即使将温度参数（Temperature）设为 0，模型输出仍不完全确定，存在跨请求的变异性。
*   **高度异质性**：没有通用的提示词准则，性能高度依赖于具体模型、任务类型和批次大小。

### 7. 优点
*   **系统性强**：不仅关注提示词内容，还关注了批处理大小这一常被忽视的工程变量。
*   **实战导向**：使用了真实的社会科学研究任务（法案分类和情感检测），而非通用的 NLP 榜单，对社科学者有直接指导意义。
