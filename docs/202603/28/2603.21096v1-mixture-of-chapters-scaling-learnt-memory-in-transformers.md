## 摘要
Transformer 缺乏一种显式的架构机制来存储和组织训练过程中获取的知识。我们引入了可学习的稀疏记忆库：一组随机初始化并端到端训练的潜标记（latent tokens），Transformer 层通过交叉注意力机制对其进行查询，以检索存储的知识。为了在不产生过高注意力计算成本的情况下扩展记忆容量，我们受专家混合（Mixture-of-Experts）架构启发，提出了基于章节的路由机制，将记忆库划分为多个章节，并训练一个路由器为每个输入选择相关的子集。这使得在保持计算可控的同时，能够将记忆扩展到 262K 个标记。我们在预训练和指令微调的相关基准测试中，将我们的方法与标准 Transformer（在等效 FLOPs 设置下）进行了评估。我们的模型超越了等效 FLOPs 的基准模型，这表明存在一个新的扩展维度，并证明了显式联想记忆提供了与模型参数中隐式捕获的知识互补的能力。此外，我们观察到在持续训练下知识保留能力有所提高，并且在不同训练阶段转换（例如从预训练到指令微调）时具有抗遗忘的鲁棒性。

## Abstract
Transformers lack an explicit architectural mechanism for storing and organizing knowledge acquired during training. We introduce learnable sparse memory banks: a set of latent tokens, randomly initialized and trained end-to-end, that transformer layers query via cross-attention to retrieve stored knowledge. To scale memory capacity without prohibitive attention costs, we propose chapter-based routing inspired by Mixture-of-Experts architectures, partitioning the memory bank into chapters and training a router to select relevant subsets per input. This enables scaling to 262K memory tokens while maintaining tractable computation. We evaluate our approach against standard transformers (in iso-FLOP settings) on pre-training and instruction fine-tuning across relevant benchmarks. Our models surpass iso-FLOP baselines suggesting scope for a new axis of scaling, demonstrating that explicit associative memory provides complementary capacity to what is captured implicitly in model parameters. Additionally, we observe improved knowledge retention under continued training, with robustness to forgetting when transitioning between training phases (e.g., pretraining to instruction fine-tuning).

#### 1. 核心问题与整体含义
Transformer 模型通常将知识隐式地存储在稠密参数中，这导致知识难以独立扩展、检查或编辑。现有的长文本或知识增强方案（如 RAG、KV-cache 压缩）多侧重于外部检索或推理时管理，而非模型内部的可学习存储。本文提出了 **Mixture of Chapters (MoC)**，旨在为 Transformer 引入一种**显式、可学习且可扩展的内部关联记忆库**。其核心意义在于开辟了模型扩展的新维度：通过稀疏路由访问的大规模潜在标记（Latent Tokens）库，在不显著增加计算开销的前提下，增强模型的知识容量和记忆稳定性。

#### 2. 方法论
*   **核心思想**：在 Transformer 块中嵌入一个由随机初始化、端到端训练的潜在标记组成的“记忆库”。模型通过交叉注意力机制查询该库以提取知识。
*   **关键技术细节**：
    *   **记忆层（Memory Layer）**：输入序列的隐藏状态作为 Query，记忆库中的标记作为 Key 和 Value。
    *   **章节划分（Chapters）**：将庞大的记忆库 $M$ 划分为 $C$ 个“章节”（每个章节包含 $T$ 个标记）。
    *   **序列级路由（Sequence-level Routing）**：受 MoE 启发，使用轻量级路由器对输入序列进行池化并评分，仅选择 Top-$k$ 个相关章节参与交叉注意力计算。
    *   **计算优化**：将注意力复杂度从 $O(L \cdot N_m)$ 降低到 $O(L \cdot k \cdot T)$，其中 $N_m$ 是总记忆标记数（实验中扩展到了 262,208 个）。
*   **算法流程**：对每个 Batch，路由器根据隐藏状态选择章节 -> 拼接选中的章节标记 -> 执行交叉注意力 -> 通过残差连接将结果反馈至主干网络。

#### 3. 实验设计
*   **数据集**：
    *   **预训练**：使用 FineWeb-Edu 的 9.6B Token 子集。
    *   **指令微调 (IFT)**：使用 UltraChat 200k 数据集（约 230M Token）。
*   **Benchmark**：MMLU、ARC-Challenge (ARC-C)、BoolQ、OpenBookQA (OBQA)。
*   **对比方法**：
    1.  **Vanilla (backbone-only)**：16 层标准 Transformer。
    2.  **Vanilla (iso-FLOP)**：24 层标准 Transformer（通过增加深度来匹配 MoC 的预训练总计算量）。
    3.  **Mixture of Chapters (MoC)**：12 层标准层 + 4 层记忆层。

#### 4. 资源与算力
*   **硬件**：预训练使用 8 张 GPU（DDP 模式）；指令微调使用 4 张 GPU。论文未明确说明具体的 GPU 型号（如 A100 或 H100）。
*   **训练时长**：预训练 9600 步；指令微调 2 个 Epoch（3200 步）。

#### 5. 实验数量与充分性
*   **实验规模**：涵盖了从头预训练到指令微调的完整生命周期，并进行了多项消融实验（如 Top-k 路由参数、记忆库冻结 vs. 更新、学习率影响等）。
*   **充分性与公平性**：实验采用了 **iso-FLOP（等效算力）** 基准，这是评估架构改进最客观的标准，确保了 MoC 的性能提升并非单纯来自计算量的增加。虽然 9.6B Token 的规模在当前大模型领域不算大，但作为架构验证实验已足够充分。

#### 6. 主要结论与发现
*   **性能超越基线**：在相同算力下，MoC 的预训练验证损失低于标准 Transformer，且在知识密集型任务（如 MMLU）上表现更优。
*   **缓解灾难性遗忘**：在重度指令微调阶段，标准模型在 ARC-C 和 BoolQ 上的准确率大幅下降（接近随机猜测），而 MoC 模型表现极其稳定，证明显式记忆库起到了“知识锚点”的作用。
*   **记忆库可复用性**：在微调阶段冻结预训练好的记忆库，其效果与持续更新记忆库相当，这为高效的下游适配提供了可能。

#### 7. 优点
*   **扩展性强**：通过稀疏路由机制，成功将内部记忆扩展至 26 万个标记，且计算成本可控。
*   **鲁棒性高**：显式记忆结构显著增强了模型在持续学习中的知识保留能力。
*   **设计优雅**：将 MoE 的稀疏激活思想巧妙应用于关联记忆检索，而非单纯的 FFP 层扩展。

#### 8. 不足与局限
*   **实验参数规模较小**：尚未在千亿级参数（100B+）或万亿级 Token 规模上验证其扩展定律（Scaling Laws）。
*   **解释性挑战**：虽然记忆是“显式”的，但潜在标记仍是高维向量，无法像 RAG 那样直接阅读检索到的具体文本内容。
*   **实现复杂度**：引入了额外的路由逻辑和交叉注意力层，增加了系统实现的复杂度和推理时的显存占用（存储记忆库）。
