## 摘要
软上下文压缩通过将长上下文编码为较少数量的潜代币（latent tokens），减少了大型语言模型（LLMs）处理长上下文的计算工作量。然而，现有框架采用统一的压缩率，未能考虑到自然语言信息密度的极大差异。虽然采用密度感知的动态压缩率似乎很直观，但实证研究表明，模型在处理由输入相关的连续结构超参数参数化的操作时存在内在困难。为了解决这一缺陷，我们引入了半动态上下文压缩框架。我们的方法具有一个离散率选择器，它根据内在信息密度预测压缩目标，并将其量化为一组预定义的离散压缩率。该选择器在合成数据上与压缩器高效地进行联合训练，并以摘要长度作为代理来创建压缩率预测的标签。广泛的评估证实，我们以均值池化为骨干的密度感知框架始终优于静态基准，为上下文压缩技术建立了稳健的帕累托前沿。我们的代码、数据和模型权重可在 https://github.com/yuyijiong/semi-dynamic-context-compress 获取。

## Abstract
Soft context compression reduces the computational workload of processing long contexts in LLMs by encoding long context into a smaller number of latent tokens. However, existing frameworks apply uniform compression ratios, failing to account for the extreme variance in natural language information density. While adopting a density-aware dynamic compression ratio seems intuitive, empirical investigations reveal that models struggle intrinsically with operations parameterized by input dependent, continuous structural hyperparameters. To resolve this pitfall, we introduce Semi-Dynamic Context Compression framework. Our approach features a Discrete Ratio Selector, which predicts a compression target based on intrinsic information density and quantizes it to a predefined set of discrete compression ratios. It is efficiently jointly trained with the compressor on synthetic data, with the summary lengths as a proxy to create labels for compression ratio prediction. Extensive evaluations confirm that our density-aware framework, utilizing mean pooling as the backbone, consistently outperforms static baselines, establishing a robust Pareto frontier for context compression techniques. Our code, data and model weights are available at https://github.com/yuyijiong/semi-dynamic-context-compress

### 1. 核心问题与整体含义（研究动机和背景）
大语言模型（LLM）在处理长上下文时面临巨大的计算和内存开销。**软上下文压缩（Soft Context Compression）**通过将长文本编码为少量的连续潜代币（latent tokens）来缓解这一问题。
*   **现有痛点：** 现有的压缩方法通常采用**固定压缩率**，忽略了自然语言信息密度的巨大差异（如技术报告与聊天记录的密度完全不同）。
*   **技术陷阱：** 虽然“完全动态”的压缩率（根据输入实时决定任意长度）看似理想，但作者发现 LLM 难以处理这种由输入决定的、具有无限可能性的**连续结构超参数**，这会导致模型性能崩溃。
*   **研究目标：** 提出一种既能感知文本密度，又能避免训练不稳定的“半动态”压缩方案。

### 2. 论文提出的方法论
核心思想是引入**半动态上下文压缩框架**，将连续的密度预测转化为离散的结构操作。
*   **离散比例选择器 (Discrete Ratio Selector, DRS)：** 
    *   模型首先通过一个回归头预测文本的压缩目标（在对数空间 $\log_2$ 中预测）。
    *   **量化机制：** 将连续的预测值强制量化到一组预定义的离散压缩率集合中（例如 $\{2\times, 4\times, 8\times, 16\times, 32\times\}$）。这确保了模型只需学习有限数量的结构化操作。
*   **均值池化 (Mean-Pooling) 骨干：** 实验发现，相比于流行的“压缩代币（Compression Tokens）”方法，简单的均值池化在无需大规模预训练的情况下表现更优，因此被选为核心架构。
*   **单阶段联合训练：** 编码器在一次前向传播中同时完成密度预测和特征提取。
*   **密度代理标签：** 使用教师模型生成的“极简摘要”长度作为信息密度的代理标签，通过监督微调（SFT）而非强化学习（RL）来训练预测头。
*   **用户可控性：** 引入 `scale` 参数，允许用户在推理时通过调整偏置项来全局控制压缩的激进程度（平衡效率与精度）。

### 6. 主要结论与发现
*   **半动态优于静态：** 在相同的平均压缩率下，半动态框架在所有评估指标上均优于固定比例基准，成功建立了新的帕累托前沿（Pareto Frontier）。
*   **结构超参数陷阱：** 证实了 LLM 无法有效处理连续变化的结构参数（如任意步长的池化），而离散化操作能显著稳定训练。
*   **均值池化的潜力：** 在轻量级微调场景下，均值池化比专门设计的“压缩代币”更有效。
*   **双向注意力必要性：** 在高压缩倍数（$\ge 16\times$）下，编码器使用双向注意力对捕捉关键信息至关重要。

### 7. 优点
*   **创新性：** 巧妙地通过“连续预测+离散量化”解决了动态压缩中的训练不稳定问题。
*   **高效性：** 单阶段架构减少了推理延迟，且无需复杂的强化学习或大规模文本重构预训练。
*   **灵活性：** 提供了 `scale` 参数，赋予用户在推理阶段动态调节压缩强度的能力。
*   **实用性：** 采用纯 SFT 流程，易于复现和部署。

### 8. 不足与局限
*   **上下文长度限制：** 实验主要集中在 2048 代币以内的短文本，尚未在大规模长文档（如 100k+ tokens）上验证其极端情况下的表现。

*   **离散桶的限制：** 压缩率被限制在预定义的离散集合中，虽然稳定，但在某些极端精细的场景下可能不如理想中的完全动态方案灵活。
