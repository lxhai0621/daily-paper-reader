## 摘要
视觉-语言模型 (VLM) 在不同视角下对同一物体的描述往往不一致，这阻碍了具身智能体随时间构建一致语义表示的能力。以往的方法通过离线多视图聚合或多阶段流水线来解决不一致性，这些流水线将探索、数据关联和描述学习解耦，对先前观察到的物体的推理能力有限。在本文中，我们介绍了一种统一的、记忆增强的视觉-语言智能体，它在单个自回归框架内同时处理数据关联、物体描述和探索策略。该模型处理当前的 RGB 观测、自顶向下的探索地图以及序列化为物体级标记 (tokens) 的物体级情景记忆，从而确保在长序列中保持持久的物体身份和语义一致性。为了以自监督方式训练模型，我们利用基于分歧的策略和一种在多视图描述历史中强制执行一致性的伪描述模型，在逼真的 3D 环境中收集了一个数据集。在手动标注的物体级测试集上进行的广泛评估表明，与基准模型相比，标准描述分数提高了高达 11.86%，描述自相似性提高了 7.39%，同时通过紧凑的场景表示实现了可扩展的性能。代码、模型权重和数据可在 https://hsp-iit.github.io/epos-vlm/ 获取。

## Abstract
Vision-Language Models (VLMs) often yield inconsistent descriptions of the same object across viewpoints, hindering the ability of embodied agents to construct consistent semantic representations over time. Previous methods resolved inconsistencies using offline multi-view aggregation or multi-stage pipelines that decouple exploration, data association, and caption learning, with limited capacity to reason over previously observed objects. In this paper, we introduce a unified, memory-augmented Vision-Language agent that simultaneously handles data association, object captioning, and exploration policy within a single autoregressive framework. The model processes the current RGB observation, a top-down explored map, and an object-level episodic memory serialized into object-level tokens, ensuring persistent object identity and semantic consistency across extended sequences. To train the model in a self-supervised manner, we collect a dataset in photorealistic 3D environments using a disagreement-based policy and a pseudo-captioning model that enforces consistency across multi-view caption histories. Extensive evaluation on a manually annotated object-level test set, demonstrate improvements of up to +11.86% in standard captioning scores and +7.39% in caption self-similarity over baseline models, while enabling scalable performance through a compact scene representation. Code, model weights, and data are available at https://hsp-iit.github.io/epos-vlm/.

### 1. 核心问题与研究动机
*   **核心问题**：现有的视觉-语言模型（VLM）在具身智能体（如机器人）导航过程中，对同一个物体从不同视角、距离或遮挡条件下观察时，往往会给出不一致甚至矛盾的描述（语义漂移）。
*   **研究背景**：
    *   **缺乏持久性**：静态 VLM 缺乏物体永久性意识，无法将多次观察关联到同一物理实体。
    *   **流水线解耦**：现有方法通常将探索、数据关联和描述生成分为多个独立阶段，导致智能体无法根据语义的不确定性主动调整观察视角。
    *   **目标**：构建一个能够随时间推移构建稳定、一致物体表示的统一具身智能体。

### 2. 方法论（EPOS-VLM）
*   **核心思想**：提出 **EPOS-VLM** 框架，将数据关联（Data Association）、物体描述（Object Captioning）和导航动作（Action Prediction）集成在一个统一的自回归视觉-语言-动作模型中。
*   **关键技术细节**：
    *   **物体级情节记忆（Episodic Memory）**：维护一个持久的存储库，记录每个物体的 ID、3D 位置以及历史描述频率。
    *   **记忆序列化（Tokenization）**：将情节记忆转化为结构化文本标记（如 `[OBJ-ID]`, `[POS]`, `[CAP-HISTORY]`），直接输入 VLM 的上下文窗口，使其能进行长程推理。
    *   **统一输出序列**：模型在每个时间步输出一个结构化序列：`[MATCH]`（关联当前检测与记忆 ID）、`[CAPTION]`（生成一致性描述）和 `[ACTION]`（决定下一步移动）。
    *   **3D-CPS 伪标签生成器**：在训练阶段，利用 3D 感知的伪描述模型（3D-CPS），通过聚合多视图信息和 3D 几何覆盖率，为每个物体生成一个视角无关的“标准描述”作为监督信号。
    *   **基于分歧的探索策略**：智能体倾向于访问那些描述不一致性（Disagreement）较高的区域，以主动消除语义歧义。

### 3. 实验设计
*   **数据集与场景**：
    *   使用 **Habitat** 仿真平台，基于 **HM3D**（1000 个大规模 3D 环境）和 **Gibson** 数据集。
    *   **训练集**：HM3D 的 128 个场景。
    *   **测试集**：手动标注的 HM3D（28 个场景）和 Gibson（32 个场景，用于跨领域泛化评估）。
*   **基准模型（Benchmarks）**：
    *   **单图 VLM**：Qwen3-VL, BLIP-2, InternVL, CoCa, Florence 等。
    *   **多视图聚合方法**：IC3, ECO-score, LD-CPS。
*   **评估指标**：
    *   **描述准确性**：BLEU-4, METEOR, ROUGE-L, CIDEr, SPICE。
    *   **语义一致性**：SBERT 嵌入的余弦相似度（Mean CS）及四分位距（IQR）。
    *   **数据关联**：跟踪准确率（Acc）、ID 切换次数（IDSW）等。

### 4. 资源与算力
*   **硬件**：使用了 **2 张 NVIDIA A100 GPU**。
*   **训练细节**：

    *   推理时间稳定在约 0.7s/步，内存占用极低（<10 KB 文本记忆），远优于基于点云的方法（约 1GB）。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了伪描述生成对比、物体级描述准确性、跨视图一致性、数据关联性能、消融实验（有无记忆）以及不同探索策略（随机、前沿探索、EPOS 策略）的对比。
*   **充分性评价**：实验设计非常充分。不仅在同分布数据集上验证，还进行了跨数据集（Gibson）的泛化测试；通过消融实验明确了记忆模块的贡献；手动标注的测试集保证了评估的客观性和公平性。

### 6. 主要结论与发现
*   **性能提升**：EPOS-VLM 在 SPICE 指标上比最强基准提升了 **11.86%**，在描述一致性（Mean CS）上提升了 **7.39%**。
*   **记忆的重要性**：消融实验显示，移除情节记忆会导致 SPICE 分数下降 14.15%，证明了长程语义推理必须依赖持久化记忆。
*   **主动探索的价值**：相比于单纯的几何覆盖（前沿探索），基于语义分歧的探索策略能显著提高最终描述的质量。
*   **高效性**：通过文本标记化的稀疏记忆表示，模型在保持高精度的同时，计算开销和内存占用远低于传统的稠密 3D 表示方法。

### 7. 优点与亮点
*   **统一性**：将感知、记忆、推理和动作整合进一个自回归框架，避免了多阶段流水线的误差累积。
*   **创新的记忆表征**：将 3D 空间信息和语义历史转化为 VLM 可理解的 Token，实现了“即插即用”的记忆增强。
*   **自监督闭环**：通过 3D-CPS 自动生成高质量训练数据，降低了对人工标注的依赖。

### 8. 不足与局限
*   **分割依赖**：模型仍依赖外部的实例分割模型（如 Mask2Former），分割错误会直接导致关联和描述失败。
*   **环境限制**：实验主要在静态、逼真的 3D 扫描环境中进行，尚未在包含动态物体（如行人）或严重传感器噪声的真实物理世界中验证。
*   **实时性挑战**：虽然内存占用低，但 0.7s 的推理延迟对于高速移动的机器人可能仍显不足。
