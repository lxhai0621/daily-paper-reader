## 摘要
大语言模型（LLM）智能体正成为自主无线网络管理的关键赋能技术。然而，可靠地部署这些智能体需要能够反映真实工程风险的基准测试。现有的无线基准测试仅评估单一且孤立的能力，并统一处理所有错误，忽略了级联链式故障和灾难性的单位混淆（例如 dB 与 dBm）。我们提出了 WirelessBench，这是首个面向基于 LLM 的无线智能体的容差感知、集成工具的基准测试。WirelessBench 组织为三层认知层级：领域知识推理（WCHW，1,392 项）、意图驱动的资源分配（WCNS，1,000 项）以及移动性下的主动多步决策（WCMSA，1,000 项）。此外，WirelessBench 基于三个设计原则建立：(i) 具有灾难性错误检测的容差感知评分；(ii) 需要符合 3GPP 标准的射线追踪查询以获取信道质量的工具必要型任务；以及 (iii) 思维链（CoT）可追溯项，其中每个基准项都附带完整的 CoT 轨迹，从而能够对智能体在推理链中失败的位置进行细粒度诊断。我们的数值结果显示，直接提示模型（GPT-4o）得分为 68%，落后于集成工具的智能体（84.64%）16.64 个百分点；23% 的错误是精确匹配指标无法察觉的灾难性故障。更重要的是，该层级结构将错误分解为四个可操作的诊断类别，这是扁平化评估无法揭示的。代码和数据：https://wirelessbench.github.io/。

## Abstract
LLM agents are emerging as a key enabler for autonomous wireless network management. Reliably deploying them, however, demands benchmarks that reflect real engineering risk. Existing wireless benchmarks evaluate single isolated capabilities and treat all errors uniformly, missing both cascaded-chain failures and catastrophic unit confusions (\textit{e.g.}, dB vs.\ dBm). We present \wb{}, the first tolerance-aware, tool-integrated benchmark for LLM-based wireless agents. \wb{} is organized as a three-tier cognitive hierarchy: domain knowledge reasoning (WCHW, 1{,}392 items), intent-driven resource allocation (WCNS, 1{,}000 items), and proactive multi-step decisions under mobility (WCMSA, 1{,}000 items). Moreover, \wb{} is established on three design principles: \emph{(i)}~tolerance-aware scoring with catastrophic-error detection; \emph{(ii)}~tool-necessary tasks requiring a 3GPP-compliant ray-tracing query for channel quality; and \emph{(iii)}~Chain-of-Thought (CoT)-traceable items, where every benchmark item ships with a complete CoT trajectory enabling fine-grained diagnosis of where in the reasoning chain an agent fails. Our numerical results show that the direct-prompting model (GPT-4o) scores $68\%$, trailing a tool-integrated agent ($84.64\%$) by $16.64$\,pp; $23\%$ of errors are catastrophic failures invisible to exact-match metrics. More importantly, the hierarchy decomposes errors into four actionable diagnostic categories that flat evaluation cannot reveal. Code and data: https://wirelessbench.github.io/.

### 2. 论文提出的方法论
WirelessBench 构建了一个 **3×3 的设计矩阵**，结合了三层认知分级和三大设计原则：

*   **三层认知分级（Hierarchy）**：
    1.  **WCHW (Tier 1)**：无线通信作业，测试基础知识推理（如香农容量、误码率计算）。
    2.  **WCNS (Tier 2)**：网络切片意图处理，要求智能体理解需求并调用“射线追踪工具”获取信道质量（CQI）进行资源分配。
    3.  **WCMSA (Tier 3)**：移动服务保障，最难的一层，要求智能体预测用户轨迹、预估未来 CQI 并做出主动决策。
*   **关键技术细节与公式**：
    *   **容差感知评分（Tolerance-Aware Scoring）**：引入相对误差 $\epsilon = \frac{|\hat{y} - y|}{\max(|y|, \delta)}$。根据误差大小给予分段信用分（如 $\epsilon \le 1\%$ 得 1.0 分，$\epsilon > 10\%$ 得 0 分）。
    *   **灾难性错误检测**：显式检测单位不匹配（如 dBW vs dBm）和数量级错误，一旦发现直接判为 0 分。
    *   **工具必要性设计**：WCNS 和 WCMSA 任务中不提供 CQI，智能体必须自主决定调用 `ray_tracing(x, y, region)` 接口。
*   **数据清洗流程**：采用受心理测量学启发的“漏斗式”清洗，利用 10 个 LLM 的响应矩阵计算**项目-总分相关性（ITC）**和 **Mokken 量表分析**，剔除区分度低或单调性差的题目。

### 6. 论文的主要结论与发现
1.  **工具集成是核心**：集成工具的智能体（84.64%）比直接提示的 GPT-4o（68%）高出 **16.64 个百分点**。
2.  **隐藏风险暴露**：23% 的错误属于“灾难性单位/数量级错误”，这些错误在传统的精确匹配指标下无法被有效识别。

4.  **性能瓶颈**：目前的瓶颈在于可靠的数值计算和工具编排，而非简单的语言理解。

### 7. 优点
*   **工程落地性强**：首次将“容差”和“灾难性错误”引入无线 AI 评估，非常符合通信工程的实际风险剖析。
*   **物理真实性**：任务基于 3GPP 标准和真实校园地图，而非随机生成的虚假数据。
*   **诊断细粒度**：通过 CoT 轨迹追踪，可以精准定位智能体是在“公式选择”、“工具调用”还是“数值计算”环节出错。
