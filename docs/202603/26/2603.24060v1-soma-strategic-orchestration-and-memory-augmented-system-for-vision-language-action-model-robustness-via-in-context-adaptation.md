## 摘要
尽管视觉-语言-动作（VLA）模型作为通用机器人控制器展现出巨大潜力，但由于缺乏长期记忆、因果故障归因和动态干预能力，它们在分布外（OOD）任务中应对感知噪声和环境变化的鲁棒性仍然受到根本性限制。为了解决这一问题，我们提出了 SOMA，这是一个策略编排与记忆增强系统，它在无需参数微调的情况下，升级了冻结的 VLA 策略，以实现鲁棒的上下文自适应。具体而言，SOMA 通过一个在线流水线运行，该流水线包含对比式双记忆检索增强生成（RAG）、归因驱动的大语言模型（LLM）编排器以及可扩展的模型上下文协议（MCP）干预，同时一个离线记忆整合模块不断将执行轨迹提炼为可靠的先验知识。在 LIBERO-PRO 和我们提出的 LIBERO-SOMA 基准测试上，针对三种骨干模型（pi0、pi0.5 和 SmolVLA）的实验评估表明，SOMA 实现了 56.6% 的平均绝对成功率提升。这包括在长时程任务链中 89.1% 的显著绝对提升。项目页面和源代码可在以下网址获取：https://github.com/LZY-1021/SOMA。

## Abstract
Despite the promise of Vision-Language-Action (VLA) models as generalist robotic controllers, their robustness against perceptual noise and environmental variations in out-of-distribution (OOD) tasks remains fundamentally limited by the absence of long-term memory, causal failure attribution, and dynamic intervention capability. To address this, we propose SOMA, a Strategic Orchestration and Memory-Augmented System that upgrades frozen VLA policies for robust in-context adaptation without parameter fine-tuning. Specifically, SOMA operates through an online pipeline of contrastive Dual-Memory Retrieval-Augmented Generation (RAG), an Attribution-Driven Large-Language-Model (LLM) Orchestrator, and extensible Model Context Protocol (MCP) interventions, while an offline Memory Consolidation module continuously distills the execution traces into reliable priors. Experimental evaluations across three backbone models (pi0, pi0.5, and SmolVLA) on LIBERO-PRO and our proposed LIBERO-SOMA benchmarks demonstrate that SOMA achieves an average absolute success rate gain of 56.6%. This includes a significant absolute improvement of 89.1% in long-horizon task chaining. Project page and source code are available at: https://github.com/LZY-1021/SOMA.

### SOMA：通过策略编排与记忆增强提升 VLA 模型鲁棒性

#### 1. 核心问题与整体含义（研究动机和背景）
现有的视觉-语言-动作（VLA）模型（如 $\pi_0$、OpenVLA）虽然在通用机器人控制上表现出色，但在面对**分布外（OOD）**场景时鲁棒性极差。其核心缺陷在于：
*   **缺乏长期记忆**：无法从过去的失败或成功中学习。
*   **缺乏因果归因**：难以诊断执行失败的具体原因（是感知错误还是规划偏差）。
*   **缺乏动态干预**：一旦环境发生微小变化（如光照、遮挡、指令模糊），静态策略往往会陷入死循环或崩溃。
SOMA 旨在不微调模型参数的前提下，通过外部记忆和工具编排，赋予冻结的 VLA 模型“在线自适应”能力。

#### 2. 方法论：核心思想与关键技术
SOMA 提出了一个解耦的架构，分为**在线执行**和**离线整合**两个流程：

*   **双重记忆检索（Dual-Memory RAG）**：
    *   不同于传统只存成功案例的 RAG，SOMA 同时存储**成功（$M_{succ}$）**和**失败（$M_{fail}$）**经验。
    *   通过 CLIP 编码器检索当前任务最相关的历史轨迹，为 LLM 提供对比参考，从而实现更精准的故障诊断。
*   **归因驱动的 LLM 编排器**：
    *   使用大语言模型（如 Qwen3-VL）作为大脑，分析当前观测与检索到的记忆之间的差异（$\Delta$）。
    *   根据诊断结果，从工具库中选择并参数化干预手段，合成“干预链”（Chain-of-Intervention）。
*   **模型上下文协议（MCP）干预工具库**：
    *   **Paint-to-Action**：通过视觉遮罩或纹理替换解决视觉域偏移。
    *   **Eraser**：擦除环境中的干扰物，减轻因果混淆。
    *   **Prompt-Refiner**：将模糊的自然语言指令重写为策略易理解的标准指令。
    *   **Chaining-Step**：将长程任务分解为短程子任务。
    *   **Encore**：在检测到执行停滞时进行关键状态回滚和重试。
*   **离线记忆整合（Memory Consolidation）**：
    *   任务结束后，异步地将新轨迹存入库中，并利用 LLM 对历史记忆进行交叉验证和精简，防止知识陈旧。

*   **长程任务突破**：在最难的长程任务链中，成功率从接近 0% 提升至 90% 左右（绝对提升 **89.1%**）。

*   **记忆的重要性**：双重记忆（成功+失败）比单一成功记忆能显著减少 LLM 的推理轮数，提高干预效率。

#### 7. 优点
*   **即插即用（Plug-and-play）**：无需昂贵的参数微调，直接升级现有 VLA 模型。
*   **失败学习**：创新性地引入失败案例作为“负面约束”，解决了传统 RAG 的“成功偏差”问题。
*   **可扩展性**：MCP 协议允许开发者根据新出现的故障类型轻松添加新工具。
*   **解耦设计**：在线干预保证了实时性，离线整合保证了知识的持续进化。

#### 8. 不足与局限
*   **推理延迟**：依赖大型多模态模型（如 32B 级别的 LLM）进行编排，可能会引入显著的推理延迟，影响实时高频控制。
*   **工具依赖性**：系统的上限受限于 MCP 工具库的丰富程度，如果故障超出了现有工具（如视觉擦除、重试）的处理范围，系统将失效。
*   **LLM 偏见风险**：LLM 在归因时可能产生幻觉，导致错误的干预（如误删目标物体），虽然双重记忆有所缓解，但风险依然存在。
*   **仿真与现实差距**：实验主要在 LIBERO 仿真环境中完成，真实物理世界中的复杂接触力学和传感器噪声可能对 MCP 工具提出更高挑战。
