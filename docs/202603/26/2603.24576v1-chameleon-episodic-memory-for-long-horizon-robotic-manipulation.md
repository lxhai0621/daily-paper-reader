## 摘要
机器人操作通常需要记忆：遮挡和状态变化可能导致决策时的观测产生感知混淆，使得动作选择在观测层面呈现非马尔可夫性，因为相同的观测可能源于不同的交互历史。大多数具身智能体通过语义压缩的轨迹和基于相似性的检索来实现记忆，这会丢弃用于消除歧义的细粒度感知线索，并可能返回感知上相似但与决策无关的情景。受人类情景记忆的启发，我们提出了 Chameleon，它通过写入基于几何的多模态标记来保留消除歧义的上下文，并通过可微记忆栈产生目标导向的回忆。我们还引入了 Camo-Dataset，这是一个使用 UR5e 真实机器人的数据集，涵盖了感知混淆下的情景回忆、空间追踪和序列操作。在各项任务中，Chameleon 在感知易混淆的设置下，相较于强基准模型，一致地提高了决策可靠性和长程控制能力。

## Abstract
Robotic manipulation often requires memory: occlusion and state changes can make decision-time observations perceptually aliased, making action selection non-Markovian at the observation level because the same observation may arise from different interaction histories. Most embodied agents implement memory via semantically compressed traces and similarity-based retrieval, which discards disambiguating fine-grained perceptual cues and can return perceptually similar but decision-irrelevant episodes. Inspired by human episodic memory, we propose Chameleon, which writes geometry-grounded multimodal tokens to preserve disambiguating context and produces goal-directed recall through a differentiable memory stack. We also introduce Camo-Dataset, a real-robot UR5e dataset spanning episodic recall, spatial tracking, and sequential manipulation under perceptual aliasing. Across tasks, Chameleon consistently improves decision reliability and long-horizon control over strong baselines in perceptually confusable settings.

### 论文总结：Chameleon —— 面向长程机器人操作的情景记忆

#### 1. 核心问题与研究动机
*   **核心问题**：在长程机器人操作中，由于遮挡、状态变化或重复动作，机器人往往面临“感知混淆”（Perceptual Aliasing）问题。这意味着在决策时刻，当前的视觉观测是**非马尔可夫**的（即仅凭当前画面无法判断下一步动作，必须依赖历史信息）。
*   **研究背景**：现有的具身智能体记忆机制通常采用语义压缩（如将历史转为文本）或基于相似性的检索（RAG模式）。这种做法会丢失关键的细粒度几何线索，且容易检索出视觉相似但决策无关的错误片段。
*   **研究动机**：受人类“情景记忆”系统（内嗅皮层-海马体-前额叶皮层，EC-HC-PFC）启发，旨在构建一种能保留几何细节、减少干扰并实现目标导向检索的记忆架构。

#### 2. 方法论：Chameleon 架构
Chameleon 采用“感知 $\rightarrow$ 记忆 $\rightarrow$ 策略”的闭环管线，核心思想是将记忆写入为可索引的事件，并通过可微动力学进行检索。
*   **感知层（Perception）**：
    *   **双流编码**：腹侧流（Ventral）利用预训练的 DINO 提取外观特征；背侧流（Dorsal）利用末端执行器（EE）的几何位姿作为锚点，生成动作相关的空间描述符。
    *   **几何偏置注意力**：通过对极几何约束（Epipolar Bias）和末端执行器锚点偏置，实现多视角（前视与手眼相机）特征的对齐与增强，保留消除歧义所需的细粒度线索。
*   **记忆层（Memory）**：
    *   **分层可微记忆栈**：模拟海马体功能，将多模态 Token 分解为多个“时空锚点”（Spatial-Temporal Anchors）。
    *   **情景与工作状态耦合**：使用选择性状态空间模型（SSM，类似 Mamba）维护情景状态（长期存储）和工作状态（即时控制）。
    *   **HoloHead（潜在想象）**：引入一个内部预测头，训练记忆状态 $h_t$ 去预测未来的 2D/3D 路径点。这种“模式补全”目标迫使记忆状态保留任务相关的关键信息。
*   **策略层（Policy）**：
    *   **条件流匹配（CFM）**：仅基于单一的记忆读取状态 $h_t$，通过整流流（Rectified Flow）生成未来一段时序的末端位姿轨迹，提高长程控制的稳定性。

#### 3. 实验设计
*   **数据集**：发布了 **Camo-Dataset**，包含 360 段 UR5e 机器人的真实演示数据。
*   **实验场景**：
    1.  **情景回忆（清理指定盘子）**：在三个外观相同的盘子中识别出之前被标记为“脏”的那一个。
    2.  **空间追踪（三杯倒扣猜球/Shell Game）**：在杯子多次交换位置后，追踪藏有物体的杯子。
    3.  **序列操作（添加多种调料）**：按特定顺序操作三种调料勺，需记忆已完成的步骤。
*   **对比基准（Baselines）**：
    *   **Diffusion Policy**（扩散策略）
    *   **Flow Matching**（流匹配）
    *   **ACT**（动作分块 Transformer）
*   **评估指标**：除了成功率（SR），还引入了决策成功率（DSR，衡量记忆检索准确性）和操作成功率（MSR）。

#### 4. 资源与算力
*   **硬件**：使用单张 **NVIDIA RTX 4090 GPU** 进行训练。
*   **训练时长**：每个任务训练约 **20,000 步**。
*   **推理效率**：端到端推理延迟约为 **82ms/步**，支持实时操作。

#### 5. 实验数量与充分性
*   **实验规模**：每个任务类别进行了 **36 次独立的真实机器人测试**（总计 108 次实机测试）。
*   **消融实验**：设计了 5 种变体，包括移除记忆模块、使用简单记忆库（Memory Bank）、使用原生 Mamba、移除背侧流几何信息、移除 HoloHead 想象目标。
*   **充分性评价**：实验设计涵盖了情景、空间、序列三个记忆维度，对比了当前主流的具身智能算法，并进行了深入的表征分析（如 UMAP 可视化），论证了记忆状态的“模式分离”与“模式补全”能力，实验结果较为客观、公平。

#### 6. 主要结论与发现
*   **性能领先**：Chameleon 在所有感知混淆任务中显著优于基准模型，尤其在需要长程记忆的“添加调料”任务中，决策成功率提升巨大。
*   **记忆有效性**：实验证明，简单的循环神经网络或基于相似性的检索不足以处理感知歧义，而 Chameleon 的结构化时空锚点能有效减少干扰。
*   **想象力的作用**：HoloHead 预测任务能显著稳定记忆表征，使机器人即使在视觉线索消失后仍能维持正确的决策目标。

#### 7. 优点与亮点
*   **生物启发性**：将神经科学中的海马体功能（模式分离/补全）成功转化为可工程化的 SSM 架构。
*   **几何关联**：通过将 3D 几何先验（对极几何、EE 锚点）引入 Transformer 注意力，解决了多视角特征融合中的歧义问题。
*   **任务设计**：Camo-Dataset 专门针对“非马尔可夫”决策点设计，填补了现有机器人数据集在复杂记忆测试上的空白。

#### 8. 不足与局限
*   **泛化性限制**：目前仅在单一机器人平台（UR5e）上验证，尚未展示跨机器人形态的迁移能力。
*   **缺乏语义集成**：该模型侧重于感知层面的情景记忆，尚未与大语言模型（LLM）或视觉语言模型（VLM）的高层语义推理能力深度结合。
*   **操作误差**：主要的失败模式仍集中在物理接触阶段（如抓取时的微小位姿偏差），这反映了模仿学习在精密操作上的固有挑战。
