## 摘要
有效的导航智能依赖于长期记忆，以支持即时泛化和持续适应。然而，现有方法面临困境：模块化系统依赖显式建图但缺乏灵活性，而基于 Transformer 的端到端模型受限于固定上下文窗口，限制了在长时间交互中的持久记忆。我们提出了 StateLinFormer，这是一种采用有状态记忆机制训练的线性注意力导航模型。该机制在连续的训练片段中保留循环记忆状态，而不是在每个批次边界重新初始化。这种训练范式有效地近似了在无限长序列上的学习，使模型能够实现长时程记忆保留。在 MAZE 和 ProcTHOR 环境中的实验表明，StateLinFormer 的性能显著优于其无状态线性注意力对应模型以及具有固定上下文窗口的标准 Transformer 基准模型。值得注意的是，随着交互长度的增加，持久的有状态训练显著提高了上下文相关的适应能力，这表明模型在导航任务中的上下文学习（ICL）能力得到了增强。

## Abstract
Effective navigation intelligence relies on long-term memory to support both immediate generalization and sustained adaptation. However, existing approaches face a dilemma: modular systems rely on explicit mapping but lack flexibility, while Transformer-based end-to-end models are constrained by fixed context windows, limiting persistent memory across extended interactions. We introduce StateLinFormer, a linear-attention navigation model trained with a stateful memory mechanism that preserves recurrent memory states across consecutive training segments instead of reinitializing them at each batch boundary. This training paradigm effectively approximates learning on infinitely long sequences, enabling the model to achieve long-horizon memory retention. Experiments across both MAZE and ProcTHOR environments demonstrate that StateLinFormer significantly outperforms its stateless linear-attention counterpart and standard Transformer baselines with fixed context windows. Notably, as interaction length increases, persistent stateful training substantially improves context-dependent adaptation, suggesting an enhancement in the model's In-Context Learning (ICL) capabilities for navigation tasks.

*   **研究动机**：作者认为限制长期记忆的关键不在于架构容量，而在于**优化协议**。通过消除训练与推理之间关于记忆处理的差异，使模型能够在无限长的交互流中学习。

#### 2. 核心方法论
*   **核心思想**：提出 **StateLinFormer**，将线性注意力架构（Linear Attention）与**有状态训练（Stateful Training）**范式相结合。
*   **关键技术细节**：
    *   **线性注意力架构**：采用 RWKV-7 架构作为解码器，利用其恒定的计算复杂度和显式记忆状态 $M_t$ 来支持无限长度的序列处理。
    *   **有状态训练协议**：在训练过程中，不再在每个 Batch 开始时将记忆状态 $M$ 初始化为 0，而是将上一个 Batch 的最终状态 $M_T^{(b)}$ 传递给下一个 Batch 的初始状态 $M_0^{(b+1)}$。
    *   **优化视角**：这种方法改变了优化目标，使模型参数在由自身循环动力学诱导的“记忆状态分布”下进行优化，而非集中在零初始化状态附近。这有效地近似了在无限长序列上的梯度下降（截断梯度）。
    *   **模型结构**：采用编码器-解码器结构。使用 SigLIP 预训练权重作为目标编码器和图像编码器，RWKV-7（18层，512隐藏维度，约 0.2B 参数）作为动作解码器。

#### 3. 实验设计
*   **实验场景与数据集**：

*   **Benchmark**：引入了**持续对象导航（CON）**基准。与传统任务不同，CON 要求智能体在同一环境中连续完成一系列目标，且不重置环境，强调经验的积累与复用。

#### 5. 实验数量与充分性
*   **实验规模**：涵盖了从简单的网格地图到复杂的 3D 逼真场景。

*   **公平性**：所有对比模型在参数量（约 0.2B）上进行了对齐。在 ProcTHOR 实验中，StateLinFormer 仅用 1/4 的数据量（10M vs 40M）就超越了预训练的 SPOC 模型，体现了极高的学习效率。实验设计较为客观，通过 Success Rate 和 Steps to Goal 两个核心指标进行了全面评估。

#### 6. 主要结论与发现
*   **性能优越性**：StateLinFormer 在所有环境中均显著优于无状态版本和 Transformer 基准。
*   **涌现上下文学习（ICL）能力**：实验发现，随着交互步数的增加，StateLinFormer 的成功率持续上升。这表明模型在不更新参数的情况下，能够通过累积的记忆状态实现对新环境的在线适应。

*   **训练范式创新**：通过简单的状态传递机制解决了长程导航中的记忆瓶颈，无需复杂的显式建图插件。
*   **高效性**：线性注意力架构保证了推理时的低延迟和低显存占用。
