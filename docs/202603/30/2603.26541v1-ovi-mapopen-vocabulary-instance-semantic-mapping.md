## 摘要
增量式开放词汇 3D 实例语义地图构建对于在复杂日常环境中运行的自主智能体至关重要。然而，由于需要鲁棒的实例分割、实时处理以及灵活的开集推理，这仍然具有挑战性。现有方法通常依赖于闭集假设或密集的逐像素语言融合，这限制了可扩展性和时间一致性。我们提出了 OVI-MAP，将实例重建与语义推理相解耦。我们建议构建一个类别无关的 3D 实例地图，该地图由 RGB-D 输入增量构建，而语义特征仅通过视觉语言模型从一小部分自动选择的视图中提取。这种设计在整个在线探索过程中实现了稳定的实例跟踪和零样本语义标注。我们的系统能够实时运行，并在标准基准测试中优于最先进的开放词汇地图构建基准。

## Abstract
Incremental open-vocabulary 3D instance-semantic mapping is essential for autonomous agents operating in complex everyday environments. However, it remains challenging due to the need for robust instance segmentation, real-time processing, and flexible open-set reasoning. Existing methods often rely on the closed-set assumption or dense per-pixel language fusion, which limits scalability and temporal consistency. We introduce OVI-MAP that decouples instance reconstruction from semantic inference. We propose to build a class-agnostic 3D instance map that is incrementally constructed from RGB-D input, while semantic features are extracted only from a small set of automatically selected views using vision-language models. This design enables stable instance tracking and zero-shot semantic labeling throughout online exploration. Our system operates in real time and outperforms state-of-the-art open-vocabulary mapping baselines on standard benchmarks.

#### 1. 核心问题与研究动机
在机器人自主导航和增强现实（AR/VR）领域，构建具有实例级理解能力的 3D 语义地图至关重要。然而，现有技术面临三大挑战：
*   **闭集限制**：传统方法依赖固定类别的预测器，无法识别训练集之外的新物体。
*   **计算开销大**：直接将高维视觉语言模型（VLM）特征存储在每个体素或点上，会导致巨大的内存和计算负担，难以实现实时在线运行。
*   **实例不稳定性**：在缺乏语义先验的情况下，跨帧的实例关联容易出现碎片化或错误合并。

**OVI-MAP 的核心动机**是提出一种**解耦架构**，将“几何实例重建”与“开放词汇语义推理”分开处理，从而在保证实时性的同时实现鲁棒的开集识别。

#### 2. 方法论
OVI-MAP 的核心思想是先构建类别无关的 3D 实例地图，再针对性地提取关键视图进行语义标注。

*   **类别无关的实例地图重建**：
    1.  **2D 实体分割与几何细化**：使用 CropFormer 提取类无关的 2D 掩码，并结合深度图的几何不连续性进行细化，减少欠分割。
    2.  **3D 提升与空间投票关联**：将 2D 掩码投影为 3D 点云，通过在 TSDF（截断符号距离场）体素网格中进行空间投票，将当前观测关联到已有的全局实例 ID，无需语义标签参与。
    3.  **增量融合**：采用加权融合更新 TSDF 值和实例标签，确保时空一致性。
*   **对象中心化的视图选择（关键创新）**：
    *   系统为每个 3D 实例维护一个**单位球面覆盖图**。
    *   只有当新视角提供了该物体未曾观测到的表面区域（即视角新颖度超过阈值）时，才会触发 VLM 查询。这极大地减少了冗余计算。
*   **语义特征聚合**：
    *   对选定视图进行多尺度裁剪和背景遮罩处理。
    *   使用 SigLIP 等 VLM 提取视觉嵌入，并根据可见像素数量进行加权平均，生成稳定的实例级语义描述符。

*   **鲁棒性**：类别无关的实例关联避免了语义预测错误导致的实例漂移。
*   **灵活性**：支持零样本推理，能够处理任意文本查询，适应开放世界环境。

#### 8. 不足与局限
*   **依赖 2D 分割质量**：系统的性能上限受限于前端 2D 分割模型（如 CropFormer），在处理极小物体或视觉极其复杂的遮挡场景时可能失效。
