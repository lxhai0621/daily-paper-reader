## 摘要
提升语言模型数学推理能力的主流范式依赖于具有可验证奖励的强化学习。然而，现有方法孤立地处理每个问题实例，未能利用训练过程中出现并积累的可复用策略。为此，我们提出了 ARISE（通过内在技能演化的智能体推理），这是一个分层强化学习框架，其中共享策略既在顶层管理技能，又在底层生成响应（分别称为技能管理器和执行器）。管理器通过专门的技能生成展开（rollout）来维护分层技能库，该过程对成功的解题轨迹进行结构化总结（执行后），同时采用策略驱动的选择机制来检索相关技能，以约束未来的展开（执行前）。分层奖励设计引导了推理能力与技能库质量的协同演化。在两个基础模型和涵盖竞赛数学及 Omni-MATH 的七个基准测试上的实验表明，ARISE 一致优于 GRPO 系列算法和记忆增强基线，在分布外（out-of-distribution）任务上的提升尤为显著。消融研究证实，每个组件都对观察到的改进有所贡献，且技能库质量和推理性能在整个训练过程中同步提升。代码可在 \href{https://github.com/Skylanding/ARISE}{https://github.com/Skylanding/ARISE} 获取。

## Abstract
The dominant paradigm for improving mathematical reasoning in language models relies on Reinforcement Learning with verifiable rewards. Yet existing methods treat each problem instance in isolation without leveraging the reusable strategies that emerge and accumulate during training. To this end, we introduce ARISE (Agent Reasoning via Intrinsic Skill Evolution), a hierarchical reinforcement learning framework, in which a shared policy operates both to manage skills at high-level and to generate responses at low-level (denoted as a Skills Manager and a Worker, respectively). The Manager maintains a tiered skill library through a dedicated skill generation rollout that performs structured summarization of successful solution traces (after execution), while employing a policy-driven selection mechanism to retrieve relevant skills to condition future rollouts (before execution). A hierarchical reward design guides the co-evolution of reasoning ability and library quality. Experiments on two base models and seven benchmarks spanning both competition mathematics and Omni-MATH show that ARISE consistently outperforms GRPO-family algorithms and memory-augmented baselines, with particularly notable gains on out-of-distribution tasks. Ablation studies confirm that each component contributes to the observed improvements and that library quality and reasoning performance improve in tandem throughout training. Code is available at \href{https://github.com/Skylanding/ARISE}{https://github.com/Skylanding/ARISE}.

#### 1. 核心问题与研究动机
*   **核心问题**：当前的数学推理强化学习（如 DeepSeek-R1 采用的 GRPO）通常孤立地处理每个问题。一旦训练中的某个尝试（rollout）结束，其中产生的成功推理策略往往被丢弃，无法在后续训练或推理中被复用。
*   **研究动机**：现有的“记忆增强”或“技能库”方法通常依赖外部检索器，这导致技能选择与策略优化脱节。作者希望构建一个让技能库与模型策略**协同演化**的框架，使模型能自主发现、积累并利用通用的解题技巧。

#### 2. 方法论
ARISE 提出了一个**分层强化学习（HRL）**框架，将单一策略 $\pi_\theta$ 同时作为“技能管理器（Manager）”和“执行者（Worker）”：
*   **核心思想**：通过一个共享参数的策略来管理技能库的“下载（选择）”和“上传（生成）”，并利用分层奖励引导模型优先使用有效的技能。
*   **关键技术细节**：
    *   **策略驱动的技能选择**：不使用外部向量检索，而是利用策略自身的**条件对数概率（log-probability）**对候选技能进行评分，从而让梯度能直接作用于技能选择偏好。
    *   **技能生成（OG+1）**：在标准的 $G$ 个解题尝试之外，增加一个专门的展开（rollout），将成功的解题轨迹总结为结构化的 JSON 技能文档（包含技能名、核心洞察、步骤、验证方法）。
    *   **两层技能库架构**：分为**缓存（Cache）**（活跃池，用于选择）和**仓库（Reservoir）**（存档池，用于长期存储），通过五种操作（添加、更新、驱逐、加载、删除）动态维护。
    *   **分层奖励设计**：奖励 $R \in \{0, 1, 2\}$。其中 $r_2$ 代表“使用技能且解答正确”，$r_1$ 代表“未使用技能但解答正确”，$r_0$ 代表“解答错误”。这种设计通过组相对优势（Group Relative Advantage）迫使模型学习如何有效利用技能。
*   **训练流程**：分为两个阶段。**阶段 I（预热）**：积累基础能力并初步填充技能库；**阶段 II（全量训练）**：激活技能选择和分层奖励，实现策略与技能库的协同进化。

#### 3. 实验设计
*   **基础模型**：Qwen3-4B-Instruct-2507 和 Phi-4-mini-instruct (3.8B)。
*   **训练数据集**：DeepScaleR 数据集（约 4 万个数学题目，涵盖 AMC、AIME、MATH 等）。
*   **基准测试（Benchmarks）**：
    *   **分布内（In-Distribution）**：AMC 2023, AIME 2024, AIME 2025。
    *   **分布外（Out-of-Distribution）**：Omni-MATH（包含代数、数论、组合、几何四个领域）。
*   **对比方法**：
    *   **GRPO 家族**：标准 GRPO, Dr.GRPO, DAPO, GSPO。
    *   **记忆/技能增强类**：EvolveR, SimpleMem, SkillRL。

#### 4. 资源与算力
*   **硬件环境**：使用了 **8 张 NVIDIA A100-80GB GPU**。
*   **训练细节**：总计 2000 个优化步骤。
*   **开销分析**：相比于标准 GRPO，ARISE 的总训练时长增加了约 **16.6%**。其中主要的额外开销来自技能生成（OG+1 步骤，占 9.4%）和技能评分（占 4.7%）。

#### 5. 实验数量与充分性
*   **实验规模**：在两个不同架构的基础模型上进行了验证，涵盖了 7 个主流数学基准。

*   **公平性**：所有对比方法均在相同的计算预算（G=8）和相同的数据集下进行训练。

#### 6. 主要结论与发现
*   **性能领先**：ARISE 在所有基准测试中均优于 GRPO 系列和现有的记忆增强方法。
*   **OOD 泛化能力强**：在 Omni-MATH 上的提升尤为显著（Qwen3 提升 2.9%），说明演化出的技能库具有跨领域的通用性。
*   **协同演化效应**：实验观察到技能库的质量（Utility）与模型的推理准确率同步增长。
*   **技能库饱和**：训练后期，准确率的提升更多来自于模型对现有技能的“精准选择”，而非技能库规模的无限扩张。

#### 7. 优点
*   **内生性（Intrinsic）**：将技能管理融入策略梯度优化，解决了外部检索器不可微、不匹配的问题。
*   **效率平衡**：通过 220 字符的硬性限制和两层缓存机制，在增加极少 Token 开销（约 3%）的情况下获得了显著的性能增益。
*   **结构化强**：定义的 JSON 技能模式确保了推理策略的可解释性和可复用性。

#### 8. 不足与局限
*   **任务局限性**：目前仅在数学推理任务上进行了验证，尚未扩展到代码生成或多步骤工具调用等更广泛的智能体场景。
*   **Schema 依赖**：技能生成依赖于预定义的 JSON 格式，如果格式定义不当，可能会限制复杂策略的表达。
*   **Token 冗余风险**：虽然单次注入开销小，但在极长上下文任务中，频繁的技能注入可能仍会带来推理成本的累积。
