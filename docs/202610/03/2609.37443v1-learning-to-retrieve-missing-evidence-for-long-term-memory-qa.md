## 摘要
长期记忆使语言模型能够在未来对话中利用过去的交互。然而，回答一个问题所需的证据可能分散在相隔较远的对话轮次中，而问题本身又缺少定位这些证据所需的线索。检索到的事实可以揭示这些线索，从而促使模型基于已找到的证据做出检索决策。我们提出 MERA（Missing-Evidence Retrieval Augmentation，缺失证据检索增强），它将全局可搜索的记忆与问题特定的证据状态分离。经核验的证据引导后续检索，同时不限制对全局记忆的访问。我们通过强化学习训练一个轻量级规划器，奖励能够找回此前缺失证据的查询。MERA 在 Qwen3-30B 和 GPT-4o-mini 主干模型上均取得了较高的答案准确率。使用 Qwen3-30B 进行证据处理和答案生成时，训练后的 0.6B 规划器在 LoCoMo 上达到 77.40% 的准确率，在 LongMemEval-S 上达到 71.29%，分别超过未经检索接地训练的 30B 规划器 4.10% 和 3.96%。在 LoCoMo 上，后续检索轮次将累积证据召回率从 55.5% 提高到 80.5%。

## Abstract
Long-term memory enables language models to use past interactions in future conversations. However, evidence needed to answer a question may be scattered across distant turns, while the question itself omits clues needed to locate it. Retrieved facts can reveal these clues, motivating retrieval decisions conditioned on evidence already found. We introduce MERA (Missing-Evidence Retrieval Augmentation), which separates globally searchable memory from a question-specific evidence state. Verified evidence guides subsequent retrieval without restricting access to the global memory. We train a lightweight planner through reinforcement learning, rewarding queries that recover previously missing evidence. MERA achieves strong answer accuracy across Qwen3-30B and GPT-4o-mini backbones. With Qwen3-30B for evidence processing and answer generation, the trained 0.6B planner achieves 77.40% accuracy on LoCoMo and 71.29% on LongMemEval-S, exceeding a 30B planner without retrieval-grounded training by 4.10% and 3.96%, respectively. On LoCoMo, later retrieval rounds increase cumulative evidence recall from 55.5% to 80.5%.

# 论文总结：Learning to Retrieve Missing Evidence for Long-Term Memory QA

## 1. 核心问题与研究动机

- **背景**：长期记忆让语言模型能在未来对话中复用过去交互的信息。近年记忆系统主要关注"存什么、怎么组织、怎么维护"（如 Mem0、A-MEM、MemoryOS、LightMem），即优化**跨问题共享的持久化记忆表示**。
- **核心痛点**：
  - 回答一个问题所需的证据往往**稀疏且分散在相距很远的对话轮次**中；
  - 问题本身常常**缺少定位证据所需的实体、事件或时间线索**；
  - 因此，仅按问题相似度逐条检索，仍可能遗漏关键证据。
- **关键挑战转变**：不只是"哪些记忆相关"，而是"**在已经找到什么的基础上，下一步该检索什么**"。已检索到的事实本身可以揭示新的搜索锚点。
- **现有方法的不足**：
  - 持久记忆方法缺少"问题特定的、经核验的证据状态"；
  - IRCoT 用累积段落与推理改写查询，但**没有显式的验证步骤**区分已确立证据与中间内容；
  - 图遍历类方法（GraphReader、Think-on-Graph、HippoRAG）的检索可达性受**预构建图连通性**限制，可能无法触及图外证据。
- **论文贡献定位**：提出 MERA，把"全局可搜索记忆"与"问题特定证据状态"解耦，并用强化学习训练轻量规划器，以"是否找回缺失证据"为奖励信号。

## 2. 方法论：MERA

### 2.1 核心思想
- 将**持久化、可全局搜索的记忆索引**与**为每个问题临时维护的证据状态**分离；
- 已验证证据用于引导后续检索（提供新锚点），但**不限定搜索边界**——检索仍可在全局索引上进行，可命中图中尚未出现的实体；
- 用检索**实际结果**而非"标准查询字符串"来评价规划器动作。

### 2.2 三阶段流程
1. **离线记忆构建**：对每个对话轮次抽取**自包含原子事实**（代词消解、保留主谓宾方向性），附带关键词、主题标签、说话人、时间戳、轮次标识；事实连同元数据一起嵌入并索引，保留父轮次标识。索引可跨问题复用。
2. **在线证据引导检索**：
   - **规划器**（轻量）依据证据状态输出一小组**结构化检索意图**：`I_ℓ^t = (d_ℓ^t, k_ℓ^t, c_ℓ^t)`，分别描述期望事实、关键实体/概念、粗粒度主题标签；
   - **检索器**将意图拼接为查询文本，在全局原子事实索引上匹配，做**父轮次事实聚合**（把同一轮次的所有抽取事实合并为一条记录，按最高原子匹配分排序），并按父轮次去重、排除已看过证据；
   - **验证器**依据问题、当前图与已接受证据，判定候选是否有用，仅有用者进入接受集；
   - **状态更新**：`G_{t+1}=Merge(G_t,ΔG_t)`、`E_{t+1}=E_t∪E_t`、`Q_{t+1}=Q_t∪a_t`。
3. **检索接地的规划器训练**（见 2.4）。

### 2.3 证据状态与证据图
- 证据状态：`s_t = (q, G_t, Q_t, S_t, E_t)`，包含问题、证据图、历史查询、已查看候选、已接受证据。
- 证据图：`G_t = (V_t, L_t, X_t, D_t, Ψ_t)`，其中 V_t 为类型化节点（人物、组织、地点、事件、日期、数量、状态），L_t 为有向带标签关系，X_t 为活跃检索锚点，D_t 为已失效/耗尽方向，Ψ_t 为指向来源轮次的溯源链接。
- **时间规范化**：区分"轮次时间"与"事件时间"；相对表达按轮次时间解析，模糊表达保留锚定区间，无时间表达时不得把轮次时间当作事件时间；年龄、金额、计数、时长走同一显式计算流程，并保留原始表述与溯源。

### 2.4 检索接地的策略优化（GRPO）
- 训练数据来自完整检索轨迹中**每次规划器调用前**保存的状态，覆盖初始检索、互补检索、后期补全；**过滤掉"全部 rollout 都无新证据"或"全部 rollout 都找全"的状态**，保留有区分度的决策点。
- 令 `E*` 为金标准父轮次，`F_t` 为第 t 轮前已找到的金证据，`U_t = E* \ F_t` 为剩余证据，`R(o_t)` 为某输出实际召回的父轮次，则：
  - 缺失证据召回率 `x_t = |R(o_t) ∩ U_t| / |U_t|`；
  - 进度项 `p_t = |F_t| / |E*|`；
  - **检索奖励** `R_ret(o_t) = x_t [1 + p_t(1 - x_t)]`。
- 奖励特性：对**已找到的证据不再给分**（避免重复命中）；不同措辞只要找回相同缺失证据即得同分；进度项使后期部分补齐获得更高权重；奖励计算粒度与验证、答案生成、金标注一致（父轮次级）。
- 优化算法：**GRPO**，同一证据状态下采样一组输出、执行检索、归一化为组内相对优势 `A_i = (r_i - r̄)/(σ_r + ε)`，使用裁剪代理目标 + KL 正则 + 可选熵项；另加**关键词数量惩罚**与**响应长度惩罚**。
- **只更新规划器**，记忆索引、证据模型、答案模型保持冻结。
- 终止条件：证据判定充分（需满足最低探索要求）、连续多轮无有效意图/候选/图更新、或达到轮次上限 `T_max`。
