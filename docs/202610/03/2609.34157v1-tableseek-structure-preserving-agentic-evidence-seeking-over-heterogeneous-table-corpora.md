## 摘要
开放域表格检索旨在寻找包含足够证据、可用于回答问题或验证陈述的表格。然而，语义相关性常常具有误导性：主题相似的表格可能缺少所需事实，而承载答案的证据往往局限于少数单元格，其含义依赖于周围的模式和表格上下文。异构的模式、值格式和序列化方式进一步削弱了一次性匹配的效果。我们提出 TableSeek，一个面向异构表格语料库的结构保持型智能体搜索框架。该框架不是一次性对表格排序，而是由 LLM 智能体迭代地追踪稀疏线索、检查保持模式的预览、识别模式级和值级不匹配，并细化其调查。TableSeek 以单元格和模式作为证据锚点，同时保留完整表格作为证据单元，从而在实现细粒度定位的同时，不丢失解释和可回答性检查所需的上下文。在不依赖检索器训练或预计算语义索引的情况下，TableSeek 能生成透明的证据搜寻轨迹，并在异构表格基准上取得与强检索-重排序流水线相比具有竞争力的端到端性能。这些结果表明，主动的、保持结构的证据搜寻是开放域表格检索中一种有前景的范式。

## Abstract
Open-domain table retrieval seeks tables that contain sufficient evidence for answering a question or verifying a claim. Yet semantic relevance is often misleading: topically similar tables may lack the required facts, while answer-bearing evidence is often confined to a few cells whose meaning depends on surrounding schema and table context. Heterogeneous schemas, value formats, and serializations further weaken one-shot matching.   We present TableSeek, a structure-preserving agentic search framework for heterogeneous table corpora. Instead of ranking tables once, an LLM agent iteratively follows sparse clues, inspects schema-preserving previews, identifies schema- and value-level mismatches, and refines its investigation. TableSeek uses cells and schemas as evidence anchors while retaining complete tables as evidence units, enabling fine-grained localization without losing the context required for interpretation and answerability checking.   Without relying on retriever training or a precomputed semantic index, TableSeek produces transparent evidence-seeking trajectories and achieves competitive end-to-end performance against strong retrieval-and-reranking pipelines on heterogeneous table benchmarks. These results suggest that active, structure-preserving evidence seeking is a promising paradigm for open-domain table retrieval.
