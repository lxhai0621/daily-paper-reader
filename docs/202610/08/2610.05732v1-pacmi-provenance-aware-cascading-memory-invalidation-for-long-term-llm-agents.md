## 摘要
LLM智能体依赖长期记忆，以在长时程任务中保留并复用信息。现有方法对处理随着新观察或领域证据到来而过时的记忆支持有限。这类过时记忆可能仍具有语义相关性，会继续影响依赖它的记录，并作为历史证据保留价值。这需要两种能力：依赖追踪，以识别下游影响；历史保留，以保存有用的历史记录。我们提出溯源感知级联记忆失效（PACMI）框架，该框架在带有类型化依赖边的溯源图中表示记忆和新证据。PACMI将记录分配到四状态有效性格中，将有效性变化传播到依赖记忆，并利用得到的状态进行检索和过时前提检测。我们还引入一个诊断基准，包含跨五个领域的100个案例和300个查询。评估将节点级、上下文级和答案级性能分开衡量。PACMI在该基准上取得最高的最终答案准确率，并且其与最强基线的配对差异在精确McNemar检验下显著。前提检查器在受控查询分布上实现了完美的精确率、召回率和F1值。级联传播主要提升记忆状态正确性：移除它会使最终答案错误数从3增加到11，但配对差异未达到0.05显著性阈值。代码和数据将公开提供。

## Abstract
LLM agents rely on long-term memory to retain and reuse information when performing tasks over long horizons. Existing methods provide limited support for handling memories that become outdated as new observations or domain evidence arrive. Such outdated memories may remain semantically relevant, continue to affect dependent records, and retain value as historical evidence. This calls for two capabilities: dependency tracking to identify downstream effects and historical preservation to retain useful past records. We propose Provenance-Aware Cascading Memory Invalidation (PACMI), a framework that represents memories and new evidence in a provenance graph with typed dependency edges. PACMI assigns records to a four-state validity lattice, propagates validity changes to dependent memories, and uses the resulting states for retrieval and stale-premise detection. We also introduce a diagnostic benchmark with 100 cases and 300 queries across five domains. The evaluation separates node, context-, and answer-level performance. PACMI achieves the highest final-answer accuracy on this benchmark, and its paired difference from the strongest baseline is significant under an exact McNemar test. The premise checker achieves perfect precision, recall, and F 1 on the controlled query distribution. Cascading propagation primarily improves memorystate correctness: removing it increases final-answer errors from 3 to 11, but the paired difference does not reach the 0.05 significance threshold. Code and data will be made publicly available.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 智能体在执行长时程任务时依赖长期记忆来保留和复用信息，已有工作（MemGPT、Mem0、A-MEM、Zep、GraphRAG 等）主要关注记忆的存储、组织、压缩与检索效率。
- **核心问题**：当新观察或新领域证据到来时，已有方法对"记忆是否仍然有效"缺乏系统支持。过时记忆具有三个棘手特性：
  - 可能**仍具语义相关性**，因此仅靠相似度检索无法识别其失效；
  - 会**继续影响下游记录**（如派生出的判断、建议、决策）；
  - 作为**历史证据仍有价值**，不应被直接删除。
- **能力缺口**：解决该问题需要两种能力——**依赖追踪**（识别下游受影响记录）与**历史保留**（非破坏性地保存过去记录）。现有基准（LoCoMo、LongMemEval、MemoryAgentBench、STALE、MemConflict）多关注事实召回、时间推理或直接冲突，**没有隔离"下游传播失效"与"当前/历史/失效用途区分"**这一问题。
- **理论定位**：作者将 PACMI 定位为"自然语言智能体记忆上的真值维护系统（TMS）"，与 JTMS/ATMS、AGM 信念修正、数据库溯源与增量视图维护（PROV-DM）同源，但有三个差异：关系需由 LLM 在确定性约束下推断、标签非二值而是分级有效性格、撤销是非破坏性的（历史查询仍需该记录）。

## 2. 方法论

### 2.1 核心思想
- 将先验记忆与新证据表示为**溯源图** \( G_t=(V_t,E_t) \)，边为类型化依赖边（评测图中含 `supports`、`used-by`；分类后可新增 `updates`、`contradicts`）。
- 把"本地语义判断"与"全局有效性传播"解耦：辅助 LLM 只做局部关系分类，级联传播沿依赖边完成下游状态更新。

### 2.2 四状态有效性格（Validity Lattice）
- 状态序：`active < needs-verification < historical-only < superseded`，该序与推理时查询相关检索偏置一致（current 查询偏置：+0.12、+0.04、−0.10、−0.22）。
- 多路径到达同一节点时取**更强状态**（"keep the stronger state"规则）。
- 状态分配**非破坏性**：原始文本保留，superseded 记录仍可作为历史证据。
- 实现中还区分 `stale`（contradict 直接目标）与 `invalidated`（derived-from 边到达、完全排除检索），但基准未实例化，故未纳入公式。

### 2.3 关键技术流程（对应 Algorithm 1）
1. **插入新证据** \( e_{t+1} \)，所有推理时状态初始化为 `active`。
2. **候选排序**：对每条先验记忆计算 \( s_{cand}=0.82\,s_{cos}+0.18\,s_{tok}+0.08\,\mathbb{I}[\sigma_e=\sigma_i\neq other] \)，保留最多 6 个候选（本基准中排序不剪枝）。
3. **关系分类**：辅助 LLM（deepseek-v4-flash）对每个候选预测 `duplicate / refine / update / contradict / temporally-compatible / unrelated`，再经**确定性 slot、稳定性、时间性约束**归一化。
   - 仅 `update`/`contradict` 可创建直接目标；
   - 若候选有来自其他先验记忆的入边 `supports`/`used-by`，则视为下游记录，交由传播处理。
4. **级联失效**：从直接目标 BFS 遍历出边；`supports → needs-verification`，`used-by → historical-only`；未到达节点保持 active；记录操作日志、保留原文。
5. **有效性感知检索**：按语义相关度、时效、slot 匹配、新证据状态、查询相关状态偏置排序，取 top-5 构成上下文 \( C_q \)；historical 查询反而偏向 historical-only/superseded。
6. **前提检查**：消费图状态（而非仅检索上下文），对比 superseded 旧记录与新证据/active 记录；若检测到查询假设过时事实，则在答案 prompt 中插入"旧事实 vs 当前事实"的纠正块，否则使用中性 prompt。

## 3. 实验设计

### 3.1 数据集 / Benchmark
- **自建诊断基准**：100 个案例、300 个查询、跨 5 个领域（Personal Profile、Location & Preference、Work & Project、Finance & Recommendation、Tool/Workflow State），每领域 20 例。
- 每例结构固定：6 条先验记忆（M1 直接受影响、M2 下游、M3 更深下游、M4 仍有效相关记忆、M5 语义相似硬负例、M6 无关干扰项）+ 1 条新证据 + 3 个查询（Q1 当前状态、Q2 过时前提、Q3 历史状态）。
- 依赖拓扑固定为二跳链：\( M1 \xrightarrow{supports} M2 \xrightarrow{used-by} M3 \)；标注状态为 M1=superseded、M2=needs-verification、M3=historical-only、M4–M6=active。

### 3.2 对比方法
- **Vector RAG**：语义 top-k 检索。
- **Recency-RAG**：加入时效分（0.7 相似度 + 0.3 时效）。
- **LLM-Only Update**：本地分类并**原地改写**候选记忆后再余弦检索。
- **CUPMem-style**（改编自 STALE）：对直接声明被替换的单值 slot 做 supersession，历史查询允许旧值，但**不传播下游**。
- **A-MEM-style**：构建语义链接并扩展一跳邻居，无显式有效性传播（上下文上限 8 条，其余方法为 5 条）。
- 所有方法共用同一答案模型（deepseek-v4-pro）、嵌入模型（all-MiniLM-L6-v2）、temperature=0。

### 3.3 评估指标（分三层）
- **节点级**：DR（直接过时节点召回）、AR（受影响节点召回）、UI（欠失效）、OI（过度失效）。
- **上下文级**（仅 Q1/Q2）：SIC（过时上下文占比）、CVER（当前有效证据召回）、New-Evidence Coverage。
- **答案级**：Final Accuracy、Stale Reuse、Premise Resistance、Q3 历史保留准确率；由固定 deepseek-v4-pro judge 评分。
- **统计**：10,000 次案例级 bootstrap（seed=20260728）得 95% 百分位置信区间；预设定配对二元比较用双侧精确 McNemar 检验。

### 3.4 消融
- w/o Provenance Graph、w/o Cascading Invalidation、w/o Validity States、w/o Premise Checking、w/o Historical Preservation 共 5 个变体，均保持其余流程不变。

## 5. 实验数量与充分性

- **主实验**：6 种方法 × 6 类指标（节点、上下文、答案三层）× 3 种查询类型，报告点估计与 bootstrap 置信区间。
- **消融实验**：5 个变体 × 多层指标（含按查询类型细分、Recall@Depth-1/2）。
- **统计检验**：3 组预设配对 McNemar 比较（PACMI vs A-MEM-style、vs w/o Cascading、vs w/o Premise Checking）。

- **充分性评价**：
  - **优点**：指标分层清晰、消融完整、统计协议（bootstrap + McNemar）明确、置信区间与错误案例均有披露，结论与假设 A1–A3 绑定表述，避免过度声称。
  - **不足**：
    - 每例仅 6 条先验记忆、上下文预算 5，检索接近饱和，无法体现真实规模下的行为；
    - 拓扑固定为二跳链且由标注提供，**过度失效与多路径状态消解从未被触发**（所有方法 OI=0）；
    - 每方法仅运行一次（temperature=0），未做多 seed；
    - 答案评判与答案生成同属一个模型家族，存在自偏好偏差；
    - A-MEM-style 上下文上限为 8 条，与其他方法的 5 条不匹配，CVER 等覆盖率指标被高估（文中已承认该混淆）；

## 6. 主要结论与发现

- **答案级主结果**：PACMI 最终准确率 0.99，显著优于最强基线 A-MEM-style 的 0.90（300 条配对查询中错误 3 vs 29，双侧精确 McNemar p=2.56×10⁻⁶）。优势**全部集中在 Q2 过时前提查询**（0.97 vs 0.71）；Q1、Q3 多数方法均达天花板。
- **前提检查器**：在受控查询分布上 P/R/F1 均为 1.00（100 TP、200 TN、0 FP、0 FN），但作者强调该结果**条件于**已由图状态分离出的过时/当前事实集合与模板化查询类型，**不能**外推为无限制长上下文中的完美前提检测。
- **级联传播**：主要提升**记忆状态正确性**与可审计性（移除后 AR 从 1.00 降至 0.00、UI 从 0.00 升至 1.00、SIC 从 0.34 升至 0.41）；答案级错误从 3 升至 11，但 p=0.0574 **不显著**。
- **检索层面未全面占优**：A-MEM-style 的 CVER 更高（0.88 vs 0.83），PACMI 的 SIC 更低（0.34 vs 0.47），即 PACMI 更少引入过时材料但覆盖略低；Stale Reuse 两者均舍入为 0.00。
- **破坏性改写的代价**：LLM-Only Update 直接过时节点召回与 PACMI 并列 1.00，但历史查询崩溃（Q3 准确率 0.42，58 例 Q3 错误），因其原地改写丢失旧值——在受控环境下复现了持续 LLM 更新记忆的退化现象，支持**非破坏性失效**的必要性。
- **消融最重要模块**：去掉前提检查（Final 0.99→0.83，Premise 1.00→0.80，p=1.78×10⁻¹³）与去掉历史保留（Final 0.99→0.77，Hist. 1.00→0.36）造成最大答案级下降。

## 7. 优点

- **问题定位新颖且清晰**：首次把"下游依赖追踪 + 历史非破坏性保留"从一般记忆管理中分离出来，并用 TMS/AGM/数据溯源的理论谱系做支撑。
- **方法论有原则性**：四状态格不是任意约定，而是与推理时检索偏置严格对应的操作化定义；多路径取强状态的规则与格序一致。
- **本地判断与全局传播解耦**的设计合理，使 LLM 只需处理局部关系语义，依赖结构由确定性遍历处理，降低 LLM 推理负担。
- **评估分层**（节点 / 上下文 / 答案）并明确区分"验证实现正确性"与"证明比较优势"，避免把由标注拓扑决定的指标当作性能优势。
- **假设前置声明（A1–A3）**：明确说明依赖边由标注提供、固定二跳链、标签是拓扑的确定性函数，并在 Limitations 中列出每项假设对应的缺失实验（图质量退化研究、拓扑扩展、记忆规模扩展、跨家族/人工评判）。
- **非破坏性失效**得到实验支持：历史保留消融显示破坏性改写导致 Q3 准确率从 1.00 崩至 0.36。
- **统计透明度高**：报告 bootstrap 区间、完整不一致计数、未做多重比较校正并说明理由、非显著结果不解读为等价。

## 8. 不足与局限

- **依赖图由标注提供（A1）**：PACMI 获得 Vector/Recency R
