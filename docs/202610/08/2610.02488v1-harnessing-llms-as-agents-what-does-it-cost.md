## 摘要
语言模型智能体日益依赖执行框架来管理有界上下文、持久记忆、工具、验证与重复执行，然而现有的模型能力概念并未量化这些机制所消耗的计算资源。我们提出语言模型智能体机器（Language Model Agent Machine, LAM），一种资源受限抽象，它固定底层语义模型，同时显式计入执行框架级资源。我们建立四类结果。通信：在同时调用-传输预算下，LAM 执行与红-蓝石子游戏逐实例等价，从而将经典 I/O 下界迁移到上下文-内存流量。访问：内存接口导致渐近分离，包括指针追逐中随机访问与非推测顺序访问之间的 Θ(n) 差距。重计算：在上下文容量为 C、持久内存容量为 S 时，位反转 DAG 需要 Θ(n^2/(C+S)+n) 次模型调用，量化了存储的中间状态何时能避免重复的语义计算。可靠性：我们推导出紧的阶段局部采样界、精确的不完美验证成本，以及具有闭式最优验证间隔的 Young--Daly 型检查点定律。在 GPT-6 Astra 上进行的受控实验与留出实验检验了通信和可靠性预测，包括检查点最优值、程序化检查下的策略选择，以及链式 MATH 任务中调用粒度、逻辑输入流量与可靠性之间的权衡。这些结果共同为语言模型智能体执行框架的计算成本提供了一种资源理论。

## Abstract
Language-model agents increasingly rely on harnesses that manage bounded context, persistent memory, tools, verification, and repeated execution, yet existing notions of model capability do not quantify the computational resources these mechanisms consume. We introduce the Language Model Agent Machine (LAM), a resource-bounded abstraction that fixes the underlying semantic model while explicitly charging harness-level resources. We establish four classes of results. Communication: LAM execution is instancewise equivalent to red--blue pebbling under simultaneous call--transfer budgets, transferring classical I/O lower bounds to context--memory traffic. Access: memory interfaces induce asymptotic separations, including a $Θ(n)$ gap between random and non-speculative sequential access on pointer chasing. Recomputation: bit-reversal DAGs require $Θ(n^2/(C+S)+n)$ model calls with context capacity $C$ and persistent-memory capacity $S$, quantifying when stored intermediate state avoids repeated semantic computation. Reliability: we derive tight stage-local sampling bounds, exact imperfect-verification costs, and a Young--Daly-type checkpoint law with a closed-form optimal verification interval. Controlled and held-out experiments on GPT-6 Astra test communication and reliability predictions, including checkpoint optima, policy selection under programmatic checking, and tradeoffs among call granularity, logical input traffic, and reliability on chained MATH tasks. Together, these results provide a resource theory for the computational cost of language-model agent harnesses.

- **整体含义**：论文提出 **Language Model Agent Machine（LAM）**，把 agent harness 架构变成可分析、可比较、可优化的数学对象，建立一套“智能体执行资源理论”。其价值在于把语义能力与 harness 执行成本分离，从而解释为何相同模型在不同 harness 下可有渐近不同的调用、通信、存储与可靠性成本。

## 2. 方法论
- **LAM 形式化**：LAM 是一个资源受限机器  
  \[
  \Lambda=(L,\text{ctrl},X,M,O_{\text{tool}},O_{\text{ver}})
  \]  
  其中 \(L\) 是语义模型接口，\(\text{ctrl}\) 是控制器，\(X\) 是有界活跃上下文，\(M\) 是持久记忆，\(O_{\text{tool}}\) 与 \(O_{\text{ver}}\) 是工具和验证器接口。
- **资源显式计费**：追踪模型/工具/验证器调用数 \(N_{\text{model}},N_{\text{tool}},N_{\text{ver}}\)，输入/输出 token \(T_{\text{in}},T_{\text{out}}\)，内存块读写/移动 \(Q_{\text{blk}},Q_{\text{move}}\)，容量 \(C,S\)，目标失败概率 \(\delta\)。
- **值溯源原则（VPA）**：每个语义块必须来自输入、声明常量或付费的模型/工具调用；复制、移动、存储保留来源，重计算产生同一计算值的新实例。控制器不能免费创造任务相关语义内容。
- **通信：红-蓝鹅卵石等价**：
  - 计算 DAG 中，红石子表示块在活跃上下文 \(X\)，蓝石子表示在持久记忆 \(M\)，load/store 表示上下文-内存传输。

  - 推论：经典 I/O 下界可迁移为 harness 通信下界；例如 \(n\times n\) 网格 DAG 有 \(Q_{\text{blk}}=\Theta(n^2/C)\)；顺序链中全历史重放需 \(\Theta(n^2b)\) 逻辑输入，而依赖感知提示只需 \(\Theta(nb)\)。
- **访问：内存接口改变复杂度**：
  - 指针追逐任务中，随机访问可 \(k\) 次读完成，非推测顺序访问则需 \(\Omega(kn)\) 期望磁头移动，形成 \(\Theta(n)\) 级分离。
  - 单栈 FIFO 检索有精确前沿：可行条件为  
    \[
    C\ge \lceil(n+1)/2\rceil,\quad S\ge (n-C)^+,\quad Q^\star_{\text{blk}}=2(n-C)^+
    \]  
    若要求无复制流式写入，则需 \(C\ge n\)。
- **重计算：持久化 vs 语义重算**：
  - 对位反转 DAG \(\Delta^{rev}_n\)，在上下文容量 \(C\)、持久内存容量 \(S\) 下，最优模型调用数为  
    \[
    \Theta\left(\frac{n^2}{C+S}+n\right)
    \]  
    并有显式双侧常数与可行域：\(C\ge3\)、\(C+S\ge4\)。
  - 当 \(C+S=\Omega(n)\) 时可达线性调用；否则总语义容量不足会强制超线性重算。无持久化时 \(S=0\)，复杂度为 \(\Theta(n^2/C+n)\)。
