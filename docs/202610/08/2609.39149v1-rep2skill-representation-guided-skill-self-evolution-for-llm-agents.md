## 摘要
文本技能使基于大语言模型（LLM）的智能体无需更新模型参数即可积累可复用的程序性知识。然而，现有技能演化仍主要局限于文本空间：优化器必须仅依据长执行轨迹和稀疏的任务结果来诊断成功与失败模式，并修订技能。这种纯文本范式将智能体的内部表征——其中包含其不断演化的执行状态的丰富记录——排除在技能优化循环之外。我们探究智能体能否通过反思自身内部表征来改进其外部文本技能。我们提出Rep2Skill，一种面向智能体技能自演化的表征引导框架。具体而言，在收集到的智能体执行轨迹（rollouts）上，Rep2Skill对其内部模型表征轨迹进行建模，以定位偏离成功执行动态的轮次，并进一步结合执行上下文将这些信号解释为可操作的文本反馈，用于有针对性的技能修订。在两个智能体环境、两个开源LLM上的实验表明，在自演化设置中，Rep2Skill持续优于纯文本方法；该设置中同一LLM同时充当执行器和优化器，且无需更强的外部模型。这为智能体自我改进超越纯文本反思确立了一个有前景的方向。

## Abstract
Textual skills enable large language model (LLM) based agents to accumulate reusable procedural knowledge without updating model parameters. Yet existing skill evolution remains largely confined to the text space: an optimizer must diagnose success and failure patterns, and revise skills solely from long execution trajectories and sparse task outcomes. This text-only paradigm leaves the agent's internal representations, which contain rich records of its evolving execution state, outside the skill optimization loop. We ask whether an agent can improve its external textual skills by reflecting on its own internal representations. We introduce Rep2Skill, a representation-guided framework for self-evolution on agent skills. Specifically, upon the collected agent rollouts, Rep2Skill models their internal model representation trajectories to localize turns that deviate from successful execution dynamics, and it further interprets these signals alongside the execution contexts as actionable textual feedback for targeted skill revision. Experiments on two agent environments with two open-source LLMs show that Rep2Skill consistently outperforms text-only approaches in the self-evolution setting, where the same LLM serves as both executor and optimizer without a stronger external model. This establishes a promising direction moving agent self-improvement beyond text-only reflection.

## 2. 方法论
### 2.1 核心思想
- 对同一任务实例、同一技能采样一组 rollout，建模其内部隐藏状态轨迹。
- 用成功执行轨迹训练表征动态模型，将偏离成功动态的轮次视为关键轮次。
- 将这些表征信号“语言化”为有轨迹依据的文本反馈，再交给技能优化器进行有目标、验证门控的技能修订。

### 2.2 关键技术细节与流程
- **问题设定**：冻结 LLM 智能体 \(\pi_\theta\)，文本技能 \(s\)，任务 \(x\)，轨迹 \(\tau=(o_1,a_1,\dots,o_T,a_T)\)，任务得分 \(r(\tau)\)。目标是最大化 \(J_D(s)\)。标准技能更新为 \(s_{n+1}=O(s_n,\tau)\)；Rep2Skill 额外使用内部表征轨迹 \(H(\tau)=(h_1,\dots,h_T)\)。
- **分组 rollout 采样**：对任务 \(x\) 和当前技能 \(s_n\)，采样 \(K\) 个 rollout 组成组 \(G(x,s_n)\)。论文默认 \(K=4\)。组内差异作为相对诊断证据。
- **表征提取与投影**：从冻结智能体固定层（实现中为 decoder layer 24）提取每轮隐藏状态，平均 token 后经 PCA 投影到 64 维，并标准化；PCA 和标准化仅用成功轨迹拟合。
- **轮级表征归因**：用 Neural CDE 建模成功执行的表征动态，基于历史表征预测下一轮表征。预测误差  
  \[
  c_t^{(k)}=\|h_t^{(k)}-\hat h_t^{(k)}\|_2^2
  \]  
  作为归因分数。误差越大，越偏离成功执行动态。取 Top-\(K_c\)（默认 \(K_c=3\)）为关键轮次。
- **表征到文本的语言化**：同一冻结 LLM 充当分析器 \(M_a\)，输入当前技能、任务、完整轨迹、关键轮次及其归因分数，输出结构化诊断。诊断类型包括：
  - `suspect_rule`
  - `rule_conflict`
  - `execution_deviation`
  - `missing_rule`
  - `insufficient_evidence`
- 分析器必须引用技能原文和轨迹步骤作为证据，输出经程序化校验；不合格响应被丢弃。每个 rollout 生成反馈 \(F^{(k)}\)。
- **技能修订**：技能优化器 \(O\) 汇总当前技能、组内 rollout 和表征引导反馈，生成候选技能：
  \[
  s_{n+1}=O(s_n,\{\tau^{(k)},F^{(k)}\}_{k=1}^K)
  \]
  采用类似 SkillOpt 的 consolidation 与 validation-gated update：候选技能在验证集上评估，只有优于当前技能才接受，否则保留 \(s_n\)。文本编辑预算默认 \(L=4\)。
- **整体算法流程**：离线训练表征轨迹模型 → 每轮采样任务 batch → 每组采样 \(K\) 个 rollout → 提取并投影隐藏状态 → 计算轮级归因分数 → 选关键轮 → 分析器生成文本反馈 → 优化器生成候选技能 → 验证门控接受/拒绝 → 输出最终技能 \(s_N\)。
- **实现特点**：执行器、分析器、优化器均为同一冻结 LLM，无更强外部模型；程序化校验分析器输出，降低不 grounded 反馈风险。
