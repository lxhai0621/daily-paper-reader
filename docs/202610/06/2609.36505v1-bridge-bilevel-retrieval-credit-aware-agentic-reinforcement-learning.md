## 摘要
具有可验证奖励的智能体强化学习（ARL）通过让大语言模型（LLMs）学习交替进行搜索与推理，提升了其处理知识密集型任务的能力。然而，大多数现有 ARL 方法仅优化由 LLM 生成的 token，并将检索到的证据视为环境观测。这造成了信息信用缺口：由缺失或误导性证据导致的失败被归因于 LLM 策略，而非检索器，这促使人们联合训练 LLM 与检索器。本文表明，检索与 LLM 策略学习对顺序敏感：先适配检索器再优化策略，比相反顺序带来更大的奖励增益。为了在允许两个组件共同适应的同时保持这种层级关系，我们将检索增强的智能体强化学习建模为一个双层优化问题。为高效求解，我们提出 BRIDGE，一种内存高效的一阶双层方法，其动机来自对 RL 与检索目标的损失景观分析。在七个开放域问答基准上，BRIDGE 在 3B 和 7B 骨干模型上均取得了最高平均准确率，相较于最强基线，在多跳平均上分别提升了 9.6 和 3.4 EM 点。它还在医学问答基准上取得了最佳的平均答案准确率和推理质量。

## Abstract
Agentic reinforcement learning (ARL) with verifiable rewards improves the ability of large language models (LLMs) to tackle knowledge-intensive tasks by learning to interleave search and reasoning. However, most existing ARL methods optimize only LLM-generated tokens and treat retrieved evidence as environment observations. This creates an information-credit gap: failures caused by missing or misleading evidence are attributed to the LLM policy rather than to the retriever, which motivates training the LLM and the retriever jointly. In this paper, we show that retrieval and LLM policy learning are order-sensitive: adapting the retriever before optimizing the policy yields a larger reward gain than the reverse order. To preserve this hierarchy while allowing both components to co-adapt, we formulate retrieval-augmented agentic RL as a bilevel optimization problem. To solve it efficiently, we introduce BRIDGE, a memory-efficient first-order bilevel method motivated by a loss-landscape analysis of the RL and retrieval objectives. Across seven open-domain QA benchmarks, BRIDGE achieves the highest average accuracy with both 3B and 7B backbones, improving the multi-hop average over the strongest baseline by 9.6 and 3.4 EM points, respectively. It also achieves the best averaged answer accuracy and reasoning quality across medical QA benchmarks.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：带可验证奖励的智能体强化学习（ARL）让 LLM 在多轮交互中交替进行"推理—搜索—读取证据—作答"，从而提升知识密集型任务表现。但主流 ARL 方法（如 Search-R1、VT-Search）**只对 LLM 生成的 action token 计算 RL 损失**，把检索返回的证据当作环境观测（observation token）并从损失中掩码掉。
- **核心问题：信息信用缺口（information-credit gap）**。当 rollout 失败是因为检索到的证据缺失或误导时，RL 更新却去惩罚 LLM 围绕该证据的动作，而不会去改进检索器。该问题在多跳问答中尤其严重——证据分散在多个文档中，只有检索先暴露全部证据，LLM 才可能学会推理。
- **关键观察：优化顺序敏感**。作者在 VT-Search 基线上对比两种串行流程：
  - **RAG-then-RL**（先调检索器、再 RL 调策略）：在多数数据集上优于纯 RL 基线，多跳任务增益尤其明显；
  - **RL-then-RAG**（反向顺序）：在通用 QA 上甚至可能不如纯 RL。
  - 结论：检索器与策略优化存在**天然层级关系**——检索器应先适配以"让有用证据可得"，LLM 再学习在此证据下搜索与推理。
- **与已有工作的差异**：已有路线要么把检索器适配到冻结生成器，要么联合优化检索器与 LLM 策略，但**均未考虑两者之间的有序依赖**。本文把它形式化为双层优化问题，并给出内存高效的一阶解法。

## 2. 方法论

### 2.1 核心思想
- 将检索增强智能体 RL 建模为 **bilevel optimization**：下层用 RAG 似然优化检索器（对当前策略而言"最有用的证据"），上层用 RL 可验证奖励优化 LLM 策略（在"其最优检索器"配合下最大化结果奖励）。
- 通过**损失景观分析**发现可省略传统一阶双层估计器中的部分项，从而只需维护**一个**检索器状态，显著降低显存。

### 2.2 双层优化建模
- 上层（策略）：`min_θ J_RL(θ, η)`，其中 `J_RL(θ,η) = -E_{x∼D_tr, τ∼π_θ(·|x;η)}[R(x,τ) − β·D_KL(π_θ‖π_ref)]`，奖励为二元 exact-match 结果奖励；用 **GRPO** 做组内归一化优势估计，并在多轮 action token 上做 clip 代理目标。
- 下层（检索）：`η ∈ η*(θ) := argmin_{η'} L_RAG(θ, η')`，其中
  `L_RAG(θ,η) = -E_{(h,y)} log Σ_{d∈N_k(h)} ρ_η(d|h) p_θ(y|h,d)`，
  `ρ_η(d|h) = softmax_{d∈N_k(h)} s_η(h,d)`，`s_η(h,d)=f_η(h)ᵀg(d)`（查询编码器可训练、文档编码器冻结）。
  - 每次检索返回 top-M 文档给 LLM，但训练时用 top-k（k > m）候选集，使检索器获得比实际暴露更多的文档级训练信号。
- 层级含义：**检索优先**（下层），策略在由此得到的检索器上优化（上层），且训练全程共同演化。

### 2.3 内存高效一阶求解（关键技术细节）
