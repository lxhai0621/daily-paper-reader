## 摘要
长期智能体不仅必须记住关于用户的真实信息，还必须记住随着共享历史演变，特定智能体应如何与该用户协同工作。现有基准主要监督用户事实和偏好，或可跨用户复用的经验，使这种关系特定的智能体记忆仍为隐式。此外，大多数先前工作仅通过长交互历史上的最终答案问答来评估模型，使评估仍不完整且不可靠。为此，我们提出 DyadMem，并给出新定义：用户条件化关系型智能体记忆（User-conditioned Relational Agent Memory, URAM）。DyadMem 沿相同的多会话轨迹联合标注用户侧记忆和 URAM，得到 6 个记忆类别。总之，它包含 3,065 个片段、50,961 个会话和 61,210 个 QA 实例，并带有大量会话级 Capture 和 Update 黄金标注、查询级 Recall 支持，以及两种 QA 设置：Gold-Memory 和 Full-Pipeline。在 16 个开放权重模型和 4 个专有模型上，Gold-Memory QA 始终表现强劲，但 Full-Pipeline QA 急剧下降。这种差距明确支持了我们细粒度评估设计。此外，若干定量结果进一步揭示，即便是前沿 LLM 也会出现 Capture 召回率低、Recall 不完整和不安全删除的问题。我们进一步进行了一项严格实验，以验证 URAM 的有效性，并观察到其对全部 20 个模型均有正向效果。总之，DyadMem 是一个双域、全流程的记忆基准，其广泛的标注工作有助于推动该领域的发展。

## Abstract
Long-term agents must remember not only what is true about a user, but also how a particular agent should work with that user as their shared history evolves. Existing benchmarks primarily supervise user facts and preferences or experience reusable across users, leaving this relationship-specific agent memory implicit. Additionally, most prior works measure the model solely with final-answer QA over long interaction histories, making the assessment still incomplete and unreliable. To this end, we introduce DyadMem with the proposed new definition User-conditioned Relational Agent Memory (URAM). DyadMem jointly annotates user-side memory and URAM along the same multi-session trajectories, resulting in 6 memory categories. To summarize, it includes 3,065 episodes, 50,961 sessions, and 61,210 QA instances, with extensive session-level Capture and Update gold annotations, query-level Recall support, and two QA settings: Gold-Memory and Full-Pipeline. Across 16 open-weight and 4 proprietary models, Gold-Memory QA is consistently strong, yet Full-Pipeline QA drops sharply. Such a gap explicitly supports our fine-grained evaluation design. Additionally, several quantitative results further reveal low Capture recall, incomplete Recall, and unsafe-deletion issues arising from even the frontier LLMs. We further conduct a rigorous experiment to validate the effectiveness of our URAM and observe the positive effects for all 20 models. In summary, DyadMem is a dual-domain, full-pipeline memory benchmark with extensive annotation efforts for advancing the domain's development.

## 1. 核心问题与整体含义

- **研究动机**：长期交互智能体不仅要记住“用户是谁、用户喜欢什么”，还必须记住“这个特定智能体应如何与这个特定用户协作”。后者会随着双方共享历史演进而变化，但现有基准大多只监督用户事实、偏好，或跨用户可复用的通用智能体经验。
- **关键缺口一**：缺少对“关系特定智能体记忆”的显式建模。论文提出 **User-conditioned Relational Agent Memory (URAM)**，即用户条件化关系型智能体记忆，用于刻画特定用户—智能体关系下的协作规则、方法和工作知识。
- **关键缺口二**：多数长期记忆基准只用最终答案 QA 评估，无法区分记忆构建、更新、检索、使用等阶段的问题。正确回答可能掩盖不完整或不安全的记忆库；错误回答也无法定位失败阶段。
- **整体含义**：DyadMem 是一个**双域、全流程**长期记忆基准，同时标注用户侧记忆与 URAM，并对 Capture、Update、Recall、Gold-Memory QA、Full-Pipeline QA 分阶段评估，使失败可定位。

## 2. 方法论

### 2.1 核心思想

- **双域记忆**：
  - 用户侧记忆：`user_profile`、`fact`。
  - URAM：`agent_identity`、`agent_method`、`agent_knowledge`。
  - 共享记忆：`episodic`，记录具体交互事件，可支持任一域。
- **关系特定性**：URAM 不是泛化的用户画像，也不是跨用户可迁移的任务经验，而是“这个智能体应如何服务这个用户”的协作性记忆。
- **全流程监督**：对同一多会话轨迹，联合标注会话级 Capture、会话级 Update、查询级 Recall 支持，以及两种 QA 设置。

### 2.2 任务形式化与关键公式

- 一个 episode 表示为 `E = ({S_t}_{t=1}^T, Q)`，其中每个 session 包含时间锚点、完整对话、金标 Capture 条目、金标 Update 操作。
- 记忆条目标记为 `m_i = (i, κ_i, c_i)`，`i` 为唯一索引，`κ_i` 为 6 类之一，`c_i` 为自包含内容。
- 金标记忆库按时间递推：
  - `B*_t = Dedup((B*_{t-1} ∪ C*_t) \ L*_t) ∪ A*_t`
  - 其中 `C*_t` 为当前 session 的 Capture 条目，`L*_t` 为删除条目，`A*_t` 为新增条目；`Dedup` 保留同 key 的最后出现。
- Capture 只接收当前完整 session 和时间锚点，不提供历史 session。
- Gold-conditioned standalone Update 接收当前对话、金标 prior bank、金标当前 Capture，隔离上游错误。
