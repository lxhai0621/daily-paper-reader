## 摘要
大型语言模型（LLM）越来越多地作为调用外部工具的自主智能体。然而，这种能力引入了工具幻觉，即选择错误的工具或生成无效调用。现有缓解方法报告了显著改进，但我们识别出一种此前被忽视的失败模式，我们将其称为“幻觉逃逸”。这些方法在它们所调优的工具配置上减少了幻觉，但在其他配置上却增加了幻觉，从而抵消了收益。我们进一步研究这一现象，发现当模型内在的工具使用倾向与当前工具配置相冲突时，幻觉会急剧上升；并且现有方法会强化而非抑制这些倾向，这反过来又导致了幻觉逃逸。基于这些发现，我们提出了EscapeGuard，一种无需训练的推理时方法，它结合了冲突感知门控与由配置导出的注意力增强，以缓解工具幻觉并防止幻觉逃逸。在多种模型上的六个基准测试中，EscapeGuard将工具选择幻觉降低了9.0个百分点，并抑制了幻觉逃逸，将跨配置均值降低了23.7个百分点，并在配对查询评估中实现了89.1%的净提升。我们希望这项工作能够鼓励超越单一工具配置的评估，并为更可靠的使用工具的LLM智能体铺平道路。

## Abstract
Large language models (LLMs) increasingly serve as autonomous agents that invoke external tools. However, this capability introduces tool hallucination, selecting incorrect tools or generating invalid calls. Existing mitigation methods report substantial improvements, yet we identify a previously overlooked failure mode that we term Hallucination Escape. These methods reduce hallucination on the tool configuration they are tuned on but increase it on other configurations, canceling out the gain. We further investigate this phenomenon and find that hallucination rises sharply when a model's intrinsic tool-use tendencies conflict with the current tool configuration, and that existing methods reinforce rather than suppress these tendencies, which in turn contributes to hallucination escape. Building on these findings, we propose EscapeGuard, a training-free inference-time method that combines conflict-aware gating with configuration-derived attention enhancement to mitigate tool hallucination while preventing hallucination escape. Across six benchmarks on various models, EscapeGuard reduces tool-selection hallucination by 9.0 pp and suppresses hallucination escape, lowering the cross-configuration mean by 23.7 pp and achieving an 89.1% net improvement in paired-query evaluation. We hope this work can encourage evaluation beyond a single tool configuration and pave the way for more reliable tool-using LLM agents.

# 论文总结：理解与缓解使用工具的LLM智能体中的幻觉逃逸

## 1. 核心问题与研究背景

- **工具幻觉问题**：LLM 越来越多地作为自主智能体调用外部工具，但会产生工具幻觉，分为两类：
  - **工具选择幻觉（Tool-selection Hallucination）**：选择不存在或不相关的工具；
  - **工具使用幻觉（Tool-usage Hallucination）**：生成未定义的参数名或未接地的参数值。
- **比文本幻觉更危险**：一次幻觉的工具调用可能在真实系统上触发不可逆操作。
- **现有方法两大流派**：
  - **训练类**：Relign（犹豫式延迟）、Gorilla（检索感知微调）、PALADIN（故障注入轨迹微调）；
  - **引导类（Steering）**：LinSteer（激活差分向量引导）、PRISMS（检测器门控方向干预）。
- **被忽视的失败模式——"幻觉逃逸"（Hallucination Escape）**：现有方法只在调优时所用的工具配置上评估，在它们所调优的配置上减少幻觉，却在其他配置上增加幻觉，收益被抵消。
- **核心研究问题**：幻觉逃逸的驱动因素是什么？为什么现有方法反而加剧它？

## 2. 方法论：EscapeGuard

### 2.1 核心思想

- **免训练、推理时干预**：检测模型内在工具使用倾向与当前运行时工具配置的冲突，仅在检测到冲突时，将模型注意力重定向回当前工具配置，而非固定修正。
- **关键设计原则**：纠正信号绑定当前配置，因此能自然适应工具重命名、替换和 schema 变化。

### 2.2 关键技术细节（三阶段流程）

**Stage ❶ 输入准备**
- 给定查询 $q$ 与工具配置 $C$，序列化时为每个工具 $t$ 记录三类 token 跨度：工具名 $S_{name}(t)$、描述 $S_{desc}(t)$、参数 schema $S_{schema}(t)$。

**Stage ❷ 冲突感知门控（Conflict-Aware Gating）**
- 复用 §4.2 的冻结冲突探针，为每个生成阶段 $r \in \{sel, arg\}$ 计算冲突分数：
$$P^r_{conflict}(q,C) = \sigma(w_r^\top h^{(l^*_r)}(q,C) + b_r)$$
- 仅当 $P^r_{conflict}(q,C) > \tau_r$ 时才激活干预，否则保持原始计算。

**Stage ❸ 上下文特定注意力增强（Context-Specific Attention Enhancement）**
- **工具选择阶段**：目标跨度为所有工具名与描述并集 $S_{sel}(C)$；
- **参数生成阶段**：目标跨度切换为已选工具的 schema $S_{arg}(C,t)$。
- 注意力 logit 修正公式：
$$\tilde{z}_{ij} = z_{ij} + \lambda_r \frac{P^r_{conflict}-\tau_r}{1-\tau_r} \mathbb{1}[P^r_{conflict}>\tau_r] \mathbb{1}[j \in S_r]$$
- 其中 $\lambda_r$ 为最大干预强度，$(\cdot)/(1-\tau_r)$ 将阈值以上的冲突分数线性重缩放到 $[0,1]$，使偏置随冲突强度线性增长而非固定开关。
- 随后按正常 softmax 计算注意力 $\tilde{\alpha}_{ij} = \text{softmax}_j(\tilde{z}_{ij})$。

**超参数设置**：$\tau_r = 0.6$，$\lambda_r = 1.8$（在留出数据上选定）；混合注意力架构（如 Qwen-3.5）仅对全注意力层干预。

### 2.3 机制调查发现（方法动机）

- **内在倾向存在**：无工具配置时做 closed-book 诱导（每查询 K=10 次采样，温度 0.7），选择先验强度 0.61–0.78，使用先验 0.57–0.71；
- **冲突导致幻觉**：对齐条件下幻觉率低且平稳；冲突条件下幻觉率随先验强度五分位 Q1→Q5 单调上升（选择 $\rho=0.58$–$0.72$，参数名 $\rho=0.50$–$0.64$）；
- **内部可探测**：逐层逻辑回归探针检测冲突准确率 85%–87%（选择）、77%–79%（参数名），预测幻觉 AUROC 0.81–0.84 / 0.74–0.75；
- **现有方法强化倾向**：先验强度增加 0.04–0.14，强化越强逃逸比 $E_w$ 越大（最高 2.42）。

## 6. 主要结论与发现

- **幻觉逃逸的确认**：所有五种方法均满足逃逸定义——在调优配置 C1 上降低 7.5 pp 平均，但在其余五种配置上平均增加 13.0 pp，跨配置均值均高于基座模型，方差平均高 62.8%；
- **查询侧同样存在**：方法修复目标查询错误的同时，有 37%–50% 概率在配对查询上引入新错误；
- **工具使用幻觉近乎免疫**：所有方法对 TUHR 的改变在任何配置下不超过 1.5 pp（共享正确子集下 ≤0.8 pp）；
- **机制解释**：模型存在内在工具使用倾向，冲突时幻觉随倾向强度单调上升，且被现有方法强化（先验 +0.04–0.14），强化越强逃逸越严重（$E_w$ 最高 2.42）；
- **EscapeGuard 效果**：
  - TSHR 降低 9.0 pp（各模型-基准组合 4.3–14.7 pp）；
  - ANHR 相对降低最高 67%，TUHR 全面下降，AVHR 改善较小；
  - 跨配置均值降低 23.7 pp（LLaMA −24.2，Qwen −23.3），方差降低约 40%；
  - 配对查询净改进 87.8%–90.4%（修复率 91.6%/93.8%，迁移损害仅 4.2%/3.6%）；
  - 机制验证：EscapeGuard 不改变内在先验（$\Delta S_{prior}$ 约 ±0.007），但显著提升对当前配置的注意力（如 0.18→0.41）与输出 margin。

## 7. 优点

- **问题识别新颖且有价值**：首次系统定义并形式化"幻觉逃逸"，揭示现有评估仅限单一配置的盲区，具有方法论警示意义；
- **机制—方法闭环**：从行为证据 → 内部探针验证 → 现有方法强化分析，形成完整因果链，方法设计直接由机制发现驱动；
- **方法设计巧妙**：
  - 免训练、推理时，不修改权重、不引入新训练数据，部署成本低；
  - 冲突感知门控只对高冲突输入干预，避免全局副作用；
  - 纠正信号绑定当前配置，天然适应重命名/替换/schema 变化；
  - 注意力偏置随冲突强度线性缩放，避免硬开关；
- **实验严谨**：数据隔离、多重对照（随机标签、仅查询、novelty-matched）、共享正确子集分析、双重指标聚合验证、多随机种子；
- **泛化性强**：跨 6 个骨干（含 MoE、不同规模、不同家族）与 6 个基准一致有效；
- **效率优秀**：仅 4%–6% 延迟开销，探针参数 <0.01%，重训成本低。

## 8. 不足与局限

- **参数值幻觉改善有限**：AVHR 改善幅度小（如 LLaMA-8B 仅 −0.8 pp），因为参数值与倾向冲突关联弱（$\rho=0.30$–0.38）；C4/C5 残余 OHR 主要由 AVHR 主导；
- **干扰工具场景收益最小**：C6 下改善仅 13.2–13.6 pp，可能因混淆工具稀释了增强的注意力信号；
- **配置与架构覆盖有限**：论文自述六种配置和架构虽具代表性但不穷尽；
- **探针需按模型刷新**：每个模型更新需重新训练探针（15–25 分钟），虽成本低但非零；
- **混淆因素未完全排除**：作者承认完全排除分布偏移作为混淆需要固定配置干预倾向强度，这在预训练模型中不易实现；
- **单轮协议限制**：评估基于单轮工具调用，未覆盖多轮智能体场景中的累积误差与长程依赖；
- **潜在偏差风险**：C2–C6 配置由 GPT-5.6-Terra 辅助生成，虽经人工复核与自动化校验，仍可能残留构造偏差。
