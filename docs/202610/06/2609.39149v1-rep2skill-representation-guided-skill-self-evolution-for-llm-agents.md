## 摘要
文本技能使基于大语言模型（LLM）的智能体无需更新模型参数即可积累可复用的过程性知识。然而，现有的技能演化在很大程度上仍局限于文本空间：优化器必须仅依据冗长的执行轨迹和稀疏的任务结果来诊断成功与失败模式，并修订技能。这种纯文本范式将智能体的内部表征——其中包含其不断演化的执行状态的丰富记录——排除在技能优化回路之外。我们探究智能体能否通过反思自身的内部表征来改进其外部的文本技能。我们提出Rep2Skill，一个表征引导的智能体技能自演化框架。具体而言，在收集到的智能体执行轨迹上，Rep2Skill对其内部模型表征轨迹进行建模，以定位偏离成功执行动态的轮次，并进一步结合执行上下文将这些信号解释为可操作的文本反馈，用于有针对性的技能修订。在两个智能体环境和两个开源LLM上的实验表明，在自演化设置中，Rep2Skill持续优于纯文本方法；该设置中同一个LLM同时充当执行器和优化器，且无需更强的外部模型。这为智能体自我改进超越纯文本反思确立了一个有前景的方向。

## Abstract
Textual skills enable large language model (LLM) based agents to accumulate reusable procedural knowledge without updating model parameters. Yet existing skill evolution remains largely confined to the text space: an optimizer must diagnose success and failure patterns, and revise skills solely from long execution trajectories and sparse task outcomes. This text-only paradigm leaves the agent's internal representations, which contain rich records of its evolving execution state, outside the skill optimization loop. We ask whether an agent can improve its external textual skills by reflecting on its own internal representations. We introduce Rep2Skill, a representation-guided framework for self-evolution on agent skills. Specifically, upon the collected agent rollouts, Rep2Skill models their internal model representation trajectories to localize turns that deviate from successful execution dynamics, and it further interprets these signals alongside the execution contexts as actionable textual feedback for targeted skill revision. Experiments on two agent environments with two open-source LLMs show that Rep2Skill consistently outperforms text-only approaches in the self-evolution setting, where the same LLM serves as both executor and optimizer without a stronger external model. This establishes a promising direction moving agent self-improvement beyond text-only reflection.

## 2. 方法论（Rep2Skill）

### 2.1 核心思想
将内部表征轨迹作为**细粒度信用分配的额外证据源**：通过对同一任务采样多条 rollout，比较其表征动态差异，定位偏离"成功执行动态"的轮次，再把这些表征信号**口语化**为有轨迹依据的文本反馈，最终引导文本空间中的技能修订。

### 2.2 预备形式化
- 冻结LLM智能体 $\pi_\theta$，文本技能 $s$，任务实例 $x$；执行产生轨迹 $\tau=(o_1,a_1,\dots,o_T,a_T)$，获得任务级得分 $r(\tau)\in[0,1]$。
- 技能期望性能 $J_D(s)=\mathbb{E}_{x\sim D}\mathbb{E}_{\tau\sim\pi_\theta(x;s)}[r(\tau)]$；标准技能演化为 $s_{n+1}=O(s_n,\tau)$。
- 在每个交互轮次 $t$ 从固定层提取隐状态 $h_t\in\mathbb{R}^d$，得到表征轨迹 $H(\tau)=(h_1,\dots,h_T)$。

### 2.3 表征空间归因（对应算法第 1–11 行）
- **组内 rollout 采样**：对每个任务实例 $x$ 与当前技能 $s_n$，采样一组 $K=4$ 条 rollout $G(x,s_n)=\{\tau^{(k)}\}$，借鉴 group-relative 优化思想，用组内变异作为结构化诊断证据（既暴露多样行为，又共享同一任务与技能上下文）。
- **表征提取与降维**：用一次额外因果前向传播，读取解码器**第 24 层**隐状态并对该轮所有 token 取平均；用 PCA 投影到 **64 维**并逐维标准化（投影与统计量仅在成功训练轨迹上拟合）。输入只含轨迹正文，**排除当前技能、任务奖励与失败信息**，防止结果泄漏。
- **轨迹建模**：采用**神经受控微分方程（Neural CDE）**建模隐轨迹。将轮次索引归一化为 $u_t$，用 Hermite 三次插值（后向差分）在时间增广观测 $(u_t,h_t^{(k)})$ 上构造控制路径 $X^{(k)}(u)$，保证 $X^{(k)}$ 在 $[u_1,u_t]$ 上只依赖前 $t$ 轮：
  $$y^{(k)}(u)=y^{(k)}(u_2)+\int_{u_2}^{u}\Big[f_\phi(y^{(k)}(v))\cdot\big[\gamma_\phi(\dot X^{(k)}(v))\odot \dot X^{(k)}(v)\big]\Big]dv,\quad \hat h^{(k)}_t=g_\phi(y^{(k)}(u_t))$$
  其中 $f_\phi$ 为向量场、$\gamma_\phi$ 为控制门（tanh-MLP 输出并 L2 归一化）、$g_\phi$ 为线性读出；首轮作为初始条件（经 MLP 编码 + 小型自治 ODE 传播），**从不被打分**。隐层维度 $m=64$，Euler 求解器。
- **训练细节**：只用**成功轨迹**（每数据集约 50 条，来自与训练/验证/测试划分不相交的独立任务集），最小化一步预测误差，AdamW（lr $10^{-4}$、weight decay $10^{-5}$、batch 32），最多 300 epoch，验证损失 20 轮不改善即早停。
- **在线打分**：归因分数 $c_t^{(k)}=\lVert h_t^{(k)}-\hat h_t^{(k)}\rVert_2^2$，**偏差越大表示越偏离成功执行动态**；取分数最高的 $K_c=3$ 轮作为关键轮次 $C^{(k)}$（并列时偏向更早轮次）。

### 2.4 表征到文本的口语化（对应算法第 13–15 行）
- 由**分析器 $M_a$（同一个冻结 LLM）**承担：输入当前技能 $s_n$、任务 $x$、完整轨迹 $\tau^{(k)}$、所有已打分轮次的归因分数及关键轮次集合，输出 $F^{(k)}=M_a\big(s_n,x,\tau^{(k)},\{(t,c_t^{(k)})|t\in C^{(k)}\}\big)$。
- 输出为**摘要 + 至多 3 条诊断**，每条诊断须归入五类之一：`suspect_rule`（规则缺少必要条件/可能误导）、`rule_conflict`（规则冲突）、`execution_deviation`（技能正确但执行偏离）、`missing_rule`（缺失决策条件）、`insufficient_evidence`（证据不足）。每条记录决策上下文、技能引文、轨迹证据、反证据、适用条件、修改假设与建议。
- **程序化校验**：技能引文必须是 $s_n$ 的精确子串（`suspect_rule`/`execution_deviation` 需 1 条，`rule_conflict` 需 2 条互异引文）；证据必须引用合法 step 并逐字摘录；`execution_deviation` 与 `insufficient_evidence` **不得建议改技能**。校验失败则整条反馈被丢弃。生成上限 2048 token。
- 提示词明确强调：高预测误差只表示"表征意外变化"，**不等于动作质量或因果**；探索与状态改变子目标可能是有用的；不得凭空断言未尝试的替代方案会成功；不得记忆物体位置。

### 2.5 文本空间技能演化（对应算法第 17–22 行）
- 优化器 $O$ 整合组内反馈，生成候选技能 $s_{n+1}=O\big(s_n,\{\tau^{(k)},F^{(k)}\}_{k=1}^K\big)$，流程沿用 SkillOpt 的"整合 + 验证门控"（关闭其 slow-update 与 meta-skill 模块）。
- **分层合并**：失败驱动与成功驱动补丁分别按 4 条一块递归合并；合并时去重、消解冲突、优先多次出现的系统性编辑、避免编辑同一文本区域，最终以失败驱动编辑优先。
- **编辑选择**：若合并补丁超过 $L$ 条，按系统性影响、与当前技能的互补性、通用性与可操作性排序取前 $L$（编辑预算相当于"文本学习率"，固定 $L=4$）。
- **应用与验证门控**：按精确字符串匹配顺序应用（找不到目标则跳过或回退为追加）；在留出选择集上评估（ALFWorld 用成功率、WebShop 用平均任务分），**仅当严格优于 $s_n$ 才接受**，否则保留原技能；另维护 step buffer 记录历史失败模式与被拒编辑，避免重复无效修订。
