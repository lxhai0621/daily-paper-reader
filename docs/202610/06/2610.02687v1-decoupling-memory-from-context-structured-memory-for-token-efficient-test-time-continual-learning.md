## 摘要
大语言模型（LLM）正越来越多地部署于企业、科学和医疗应用中，其中的智能体必须整合领域特定知识并从经验中适应。上下文工程通过推理时提供的指令、策略和证据来改善模型行为，为权重更新提供了一种实用的替代方案。然而，在线适配上下文通常需要代价高昂的试错过程，而查询往往被独立处理，使有用经验无法延续。记忆系统通过在交互间保留信息来应对这一局限，但持续向共享上下文追加信息的方法会面临令牌成本上升、上下文窗口限制，以及随上下文扩展而出现的性能退化。我们提出了上下文优化的统一形式化表述，并表明智能体记忆系统的更新可以被解释为对模型上下文的一种优化更新过程。这一视角试图为研究记忆设计及其效率提供一个有原则的框架。随后我们提出 GraphMemory，一种轻量级的基于图的记忆，能够积累、精炼、组织并连接可复用的策略。对于每个查询，GraphMemory 仅检索相关子图，从而实现在线上下文适配，而无需让模型接触整个记忆。在有界检索下，随着已处理样本数量的增长，检索到的记忆量保持恒定。实验表明，GraphMemory 在实现具有竞争力的下游性能的同时，相比我们的基线方法使用的记忆构建令牌约少 81–85%。

## Abstract
Large language models (LLMs) are increasingly deployed in enterprise, scientific, and medical applications, where agents must incorporate domain-specific knowledge and adapt from experience. Context engineering offers a practical alternative to weight updates by improving model behavior through instructions, strategies, and evidence supplied at inference time. However, adapting context online typically requires a costly trial-and-error process, while queries are often processed independently, preventing useful experience from carrying forward. Memory systems address this limitation by retaining information across interactions, but approaches that continually append information to a shared context face increasing token costs, context-window limits, and performance degradation as the context expands. We introduce a unified formulation of context optimization and show that an agent memory system update can be interpreted as an optimization update procedure over the model's context. This perspective attempts to provide a principled framework for studying memory design and its efficiency. We then propose GraphMemory, a lightweight graph-based memory that accumulates, refines, organizes, and connects reusable strategies. For each query, GraphMemory retrieves only the relevant subgraph, enabling online context adaptation without exposing the model to the entire memory. Under bounded retrieval, the amount of retrieved memory remains constant as the number of processed examples grows. Experiments show that GraphMemory achieves competitive downstream performance while using approximately 81-85% fewer memory-construction tokens than our baselines.

# 论文总结：Decoupling Memory from Context（GraphMemory）

## 1. 核心问题与研究动机

- **背景**：LLM 已广泛部署于企业、科学、医疗等专业场景，智能体需要吸收领域知识并从交互经验中持续适应。但部署后的智能体基本是"静态"的：固定参数下，一次交互获得的信息不会自然改善后续行为。
- **现有路径的局限**：
  - **参数高效微调（PEFT）/即时适配器**：需要访问模型权重与训练基础设施，学到的状态绑定在特定模型参数上，难以在部署中持续适应、也难以跨智能体迁移。
  - **上下文工程（Context Engineering）**：无需改权重，通过指令、示例、策略、证据适配冻结模型。但提示优化方法（MIPROv2、GEPA、OPRO、TextGrad、TRACE）通常针对离线数据集优化**单一任务级提示**，不累积部署经验。
  - **持久记忆系统**（Dynamic Cheatsheet、ACE）：把可复用策略写入外部自然语言记忆，可检查、可编辑、可跨智能体迁移。但这类系统维护的是**扁平集合或单一不断增长的文件**，每个查询都要处理越来越大的异构记忆上下文。
- **核心痛点（本文的关键洞察）**：问题不在于"存储的记忆在增长"（持续学习本就应保留经验），而在于**全记忆系统把"存储规模"与"每次查询处理的记忆量"耦合在一起**，导致：
  - 令牌成本随训练步数增长（最终上下文 O(N)，累积暴露可达 O(N²)）；
  - 逼近上下文窗口上限，需要截断（如 ACE 需设 80k 令牌上限）；
  - 混合大量与当前输入无关的异构经验，引起上下文退化/崩溃。
- **整体含义**：需要一种**记忆接口**，使存储知识可以持续增长，而每次查询的活跃上下文保持很小——即"将记忆与上下文解耦"。

## 2. 方法论

### 2.1 统一形式化：把记忆更新视为上下文优化

- **离线上下文优化**：设 $D=\{(x_i,y_i)\}_{i=1}^n$，$f$ 为冻结模型，$c$ 为文本上下文，定义经验上下文风险 $L_D(c)=\frac{1}{n}\sum_i \mathbb{E}[\ell(f(c,x_i),y_i)]$，目标 $c^*\in\arg\min_c L_D(c)$。因 $c$ 是离散令牌序列且模型可能为黑盒，无法做一阶优化。
- **两类近似**：
  - 候选池搜索（MIPROv2 在指令×示例的乘积空间中搜索；GEPA 用执行轨迹反思、自适应扩展候选档案 $A_{t+1}=A_t\cup\text{Propose}(c_t,\tau_t)$），得到固定的任务级上下文。
  - 迭代式文本更新：$\Delta c_t = O(c_t, x_t, \hat{y}_t, \tau_t)$，$c_{t+1}=c_t\odot\Delta c_t$。作者指出该式**结构上类比于上下文上的梯度下降步**（$\Delta c_t$ 充当更新方向），但不是真正的梯度，也不保证降低目标。
- **从局部更新到记忆**：记忆系统不从整数据集改进单一全局上下文，而是从单个经验中抽取短上下文块 $\Delta_i$，形成外部记忆库 $\delta=(\Delta_1,\dots,\Delta_n)$，并定义**局部代理目标** $L_D^{block}(\delta)=\frac{1}{n}\sum_i\mathbb{E}[\ell(f(\Delta_i,x_i),y_i)]$。
  - 作者明确说明该代理**与全局目标不等价**（块可能过拟合并源样本），其动机是实践性的：让不完美的模型预言机只需"蒸馏一条聚焦的经验"，比"重写整个全局上下文"更容易。**泛化被交给记忆接口（组合/检索机制）** 承担。

### 2.2 两个命题：增长趋势对比

- **仅追加（append-only）记忆**：$c_\delta^{(t+1)}=c_\delta^{(t)}\oplus\Delta^{(t)}$。
  - **命题 1**：若每例最多产生一个长度 ≤B 的块，则 $\text{len}(c_\delta^{(N)})\le L_0+NB=O(N)$；累积记忆上下文暴露为 $O(N^2)$（附录推导）。
  - 图 1 显示 ACE 的实测提示令牌增长与该追加式预测趋势一致。
- **有界检索记忆**：$\delta^{(t+1)}=\delta^{(t)}\cup\{\Delta^{(t)}\}$，$c_\phi^{(t+1)}(x)=\phi(\delta^{(t+1)},x)$，其中 $\phi$ 检索查询相关子集。
  - **命题 2**：若每块 ≤B 令牌、每次至多检索 K 块，则 $\text{len}(c_\phi^{(N)}(x))\le KB=O(1)$，累积为 $O(N)$。
  - 注意：该界只约束喂给 Generator 的记忆内容，**不约束存储量与检索内部开销**。

### 2.3 GraphMemory：图结构化记忆

- **基本思想**：以 ACE 为工作母机（Generator–Reflector–Curator），在**两个接口**上做改动——Generator 读什么、Curator 写什么。整体循环变为 **RETRIEVE–GENERATE–REFLECT–CURATE**。
- **图结构**：有向图 $G^{(t)}=(V^{(t)},E^{(t)})$。节点存 ACE 风格的知识点（含唯一 ID、短路由键、完整 bullet 内容）；有向边 $e=(u,v)$ 表示"检索到 u 后，v 的知识可能有用"。
- **检索（两阶段）**：
  1. LLM Retriever 读取**紧凑索引**（仅 ID + 短键，不含完整内容），输出至多 2 个索引分区、至多 6 个入口节点（结构化 JSON，非法 ID 丢弃）。
  2. 从入口做**权重优先的广度优先遍历**：最多 2 跳、至多 12 个节点、至多 2500 令牌序列化内容；每个节点只展开其出边中权重最高的 2 个邻居，同分时以目标节点 ID 确定性打破平局；重复节点只加载一次。仅加载到的节点全文喂给 Generator。
  - **无全记忆回退机制**：若图为空或未选出有效入口，则检索结果为空、直接无记忆生成，避免悄悄退化为全 playbook 暴露。
- **边权：置信度加权证据 + Beta 后验**：
  - 每条有向边维护两个非负分数计数：$S_e^{(t)}$（有益）与 $F_e^{(t)}$（有害），按均匀 Beta(1,1) 先验视作分数伪计数，$\theta_e\mid H_t\sim\text{Beta}(1+S_e,1+F_e)$，排序权重取后验均值 $w_e^{(t)}=\frac{S_e+1}{S_e+F_e+2}$（新边中性权重 0.5）。
  - Generator 生成后报告一个**有序影响轨迹** $M_t=[n_1,\dots,n_k]$（仅接受本次已加载节点的 ID），相邻项构成候选有向转移；Reflector 将每条候选标为 helpful / harmful / neutral 并给出置信度 $c_e\in[0,1]$，据此按 $S_e+c_e$ 或 $F_e+c_e$ 更新，neutral 或 $c_e=0$ 不改变计数。
  - 幻觉 ID、重复对、非法标签、越界置信度在更新前丢弃，每例每条唯一转移至多更新一次；**观察不自动建边**，新边只能由经过校验的 Curator 操作引入；删除边也需 Curator 显式操作。
- **Curator 的局部写入**：可新增/修订节点、新增/修订边或两者兼有，**局部应用、不重写其余图**；新节点插入紧凑索引，新边决定后续检索可达性。
- **执行顺序（防泄漏）**：先检索 $c_t=\phi(G^{(t)},x_t)$ 并生成 $\hat{y}_t=f(c_t,x_t)$，之后 Reflector 才检查预测与反馈，Curator 再产出局部编辑得到 $G^{(t+1)}$。因此由 $y_t$ 派生的信息**不会影响对 $x_t$ 的预测**，只对后续样本可用。
