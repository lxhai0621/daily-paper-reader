## 摘要
长期记忆使 LLM 智能体能够回忆过去的交互，并在跨会话中保持一致，但记忆系统往往在表示、索引、检索和评估方面各不相同，因此难以比较。我们提出了一个基于共享 5W 式对话记忆的受控评估框架。局部化图配置遍历一个共同的基础图；AdaptiveGraph 添加了时间顺序边和个性化 PageRank 扩散。我们还在相同提取笔记上评估 BM25，并将 OpenClaw 作为原始输入外部参考。检索排序因记忆设置而异。在 LongMemEval-S 上，AdaptiveGraph 是最强的图配置，MRR 为 0.844，但 BM25 达到 0.867，OpenClaw 达到 0.880。在 ATANT Core 上，局部化图遍历优于扩散和 BM25，而 BM25 在压力轮次中领先。在测试范围内缩小 LongMemEval-S 并不能复现 ATANT 的扩散惩罚，但测试的最小存储仍大于 ATANT Core，因此存储规模无法被排除。该惩罚在宽松的内容匹配标准下也依然存在。词汇归一化和提取质量会显著影响图检索，而在排名前五的未命中中，缺少提取标签很常见。因此，检索策略应与记忆设置联合评估，并与强词汇基线进行比较。

## Abstract
Long-term memory lets LLM agents recall past interactions and remain consistent across sessions, but memory systems are hard to compare because they often vary in representation, indexing, retrieval, and evaluation. We present a controlled evaluation framework based on shared 5W-style conversational memories. Localized graph configurations traverse a common base graph; AdaptiveGraph adds chronological edges and Personalized PageRank diffusion. We also evaluate BM25 over the same extracted notes and OpenClaw as a raw-input external reference. Retrieval rankings vary across memory settings. On LongMemEval-S, AdaptiveGraph is the strongest graph configuration at 0.844 MRR, but BM25 reaches 0.867 and OpenClaw 0.880. On ATANT Core, localized graph traversal outperforms diffusion and BM25, whereas BM25 leads the stress rounds. Reducing LongMemEval-S within the tested range does not reproduce the ATANT diffusion penalty, but the smallest tested store remains larger than ATANT Core, so store size cannot be ruled out. The penalty also persists under a permissive content-match criterion. Vocabulary normalization and extraction quality substantially affect graph retrieval, and missing extraction tags are common among top-five misses. Retrieval strategies should therefore be evaluated jointly with the memory setting and against strong lexical baselines.

# TAGGRAPH 论文结构化总结

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体受限于固定上下文窗口，需要长期记忆来个性化回应、回答关于过往事件的问题并跨会话保持一致。基于检索的记忆虽可扩展，但一个"相关但表示不佳或排序靠后"的记忆对智能体而言依然不可用。
- **核心痛点**：现有记忆系统在**表示（representation）、索引（indexing）、检索（retrieval）、评测（evaluation）**四个环节上各不相同，且常常同时改动全部组件，导致无法判断到底是哪一项带来了性能增益，也无法确认图结构是否真的优于强词法基线。
- **整体含义**：论文并非提出一个更强的记忆系统，而是提出一个**受控评测框架**，在共享的 5W 式对话记忆与统一基础图上，分离比较"局部图遍历 vs. 图扩散 vs. 词法检索"的检索行为差异，强调检索策略必须与具体记忆设置联合评估。

## 2. 方法论

### 2.1 核心思想
- 所有后端实现统一的 `remember()`（存储）与 `query()`（检索）接口。
- 图配置共享同一套：抽取笔记、5W 本体（ontology）、基础 tag–topic–file 图；仅局部遍历变体与 AdaptiveGraph 在遍历/排序方式上不同。

### 2.2 记忆摄取与抽取
- 每个 user–assistant 交互存为单个 Markdown 文档，作为**原子检索单元**，保留原始对话。
- LLM 抽取结构化的 **5W+Extra** 表示：`Who / What / When / Where / Why / Extra`，外加一句短 `Summary`。
- 抽取原则：只抽取交互中明确支持的信息；**以用户陈述为主要记忆来源**，助手回复仅用于澄清话题，不引入新事实；优先精确率而非召回率；避免推断用户身份、偏好、技能水平或长期目标。
- 概念以**短的层级本体标签**表示（如 `career/software_engineering`、`company/google`、`programming/python`），提示模型优先复用已有本体条目，但生成后**不强制**执行该偏好。

### 2.3 图构建
- 有向图包含四类节点：**tag 节点**（抽取概念）、**topic 节点**（聚合相关记忆）、**file 节点**（Markdown 交互）、**ontology 节点**（分类树）。
- 边类型：
  - tag–topic 与 topic–file 边：连接概念与记忆；
  - **相似边**：共享至少 3 个 5W 属性的 topic 相连；
  - **本体边**：父子关系；
  - AdaptiveGraph 额外添加**时间顺序 file 边**（连接相邻对话文件）。

### 2.4 检索方法
- **TagGraph（局部本体引导遍历）**：词法匹配标签 → 在父子概念上有界 BFS 扩展 → 沿 Tag→Topic→File 路径产生候选文件 → 按图距离打分（直接匹配优先）。
  - `TagGraph-Basic`：原始词法重叠。
  - `TagGraph-Stopwords`：剔除在某 case 中出现频率 >15% 的查询词，防止常见词打开过宽图区域。
  - `TagGraph-TFIDF`：在过滤基础上按语料级 TF-IDF 加权内容重叠。
- **AdaptiveGraph（扩散式检索）**：在基础图上加入时间顺序 file 边，用**个性化 PageRank（随机游走带重启）**替代局部遍历。查询匹配的本体标签初始化 teleportation 向量，同时给候选 file 节点赋 TF-IDF 内容重叠分数作为直接文件种子。迭代公式：
  \[
  x^{(k+1)} = \alpha M^\top x^{(k)} + (1-\alpha)s
  \]
  其中 \(M\) 为转移矩阵，\(s\) 为查询导出的 teleportation 向量，阻尼因子 \(\alpha=0.85\)，迭代 20 次；最终按 PageRank 概率对对话文件排序。
- **BM25 基线**：对**同一批抽取笔记**全文应用 Okapi BM25（\(k_1=1.5, b=0.75\)），无本体、无图，是固定记忆存储下的无图词法对照。
- **OpenClaw**：外部生产基线，直接索引**原始文本**，用稠密余弦相似度与 BM25 以 0.7/0.3 加权（`nomic-embed-text-v1.5` + SQLite FTS5），不属于受控消融。

## 3. 实验设计

- **数据集 / 场景**：
  - **LongMemEval-S**：500 道多会话历史问题，每道配约 40–50 个过往会话，仅 1 个或少数相关；含 multi-session、temporal-reasoning、knowledge-update、single-session-assistant 等题型；另有 oracle 变体（只给金标会话）作为无干扰上界。
  - **ATANT**：跨 6 个生活领域（Career、Daily Life、Health、Learning、Life Events、Relationships）的持续叙事，含 **Core** 与 **Stress Rounds R2–R5** 两个划分。
- **Benchmark 性质**：LongMemEval 提供长而干扰密集的历史，ATANT 提供紧凑但演化的个人叙事，用于检验排序策略能否跨记忆机制迁移。
- **对比方法**（共 6 种）：OpenClaw、TagGraph-Basic、TagGraph-Stopwords、TagGraph-TFIDF、AdaptiveGraph、BM25。
- **抽取模型**：Gemma、GPT-OSS、Qwen3-Small 三种指令微调模型，固定同一抽取提示（temperature 0），以将差异归因于抽取模型而非提示工程。
- **评测指标**：主要为 **MRR**；LongMemEval 上将笔记映射到源会话、深度 40 去重后匹配金标标签，并报告 per-type recall@k；ATANT 无金标会话标签，以**内容包含匹配**判定相关（严格：包含全部期望子串；宽松：包含任一子串）。另做了 top-5 笔记 → Qwen3-Small 生成的**下游答案准确率**方向性检查（containment accuracy 与 token F1）。

  - LongMemEval-S 的**干扰项密度扫描**（0、3、8、18、36 个干扰会话）；

  - 词汇归一化（停用词、TF-IDF）效果分析；
  - **失败案例诊断**（658 条金标笔记池，C1–C4 分类）；
  - 下游答案准确率方向性验证（N=487）。
- **充分性与公平性**：
  - **优点**：图配置共享摄取、本体、基础图，BM25 使用同一抽取笔记，构成较严格的受控比较；抽取模型与提示固定；对检索深度做过敏感性检查（depth 20/40/80 MRR 变化 <0.004）。

    - OpenClaw 索引原始文本，与受控组不同源，作者自己也将其定位为"外部参考"而非消融；

    - 检索深度敏感性只在一个配置上验证，未覆盖其他方法与 ATANT。

## 6. 主要结论与发现

- **没有一种方法在所有设置下最优**：
  - LongMemEval-S：AdaptiveGraph 是**最强图配置**（Gemma 抽取下 0.844 MRR），但 **BM25 达 0.867、OpenClaw 达 0.880**，词法基线反超。
  - ATANT Core：**局部化遍历领先**（TagGraph-Stopwords 最佳），AdaptiveGraph 垫底，BM25 居中。
  - ATANT Stress R2–R5：**BM25 在所有抽取模型下领先**，但 AdaptiveGraph 随轮次推进逐步逼近，在 3 个 R5 设置中的 2 个达到或超过局部配置。
- **图扩散的双面性**：在 LongMemEval-S 上，AdaptiveGraph 比 TagGraph-TFIDF 提升 0.126–0.382 MRR；但在 ATANT Core 上**去掉扩散反而提升 MRR +0.158**。作者将后者描述性称为"topic dilution（话题稀释）"，并明确表示**未识别其成因**。
- **扩散与文件种子强替代**：GPT-OSS 下，去掉文件种子损失 0.119 MRR，去掉扩散仅损失 0.020；当种子缺失时，扩散的价值大幅上升（36 干扰下 +0.577 vs. 有种子时 +0.020），说明配置强度很大程度来自词法路径。
- **扩散收益依赖干扰项**：无干扰时扩散贡献 0.000，干扰密度升高时约 +0.02，但并非单调。
- **词汇归一化影响巨大**：停用词过滤使 LongMemEval-S MRR 提升 **36.5%–59.3%**；TF-IDF 加权在过滤后带来较小但一致的增益（0.404–0.706 → 0.428–0.718）。
- **抽取质量是系统性约束**：同一 TagGraph-TFIDF 下，Gemma 0.718 vs. GPT-OSS 0.428，差距 0.290，超过 Basic→TFIDF 整个检索流程进展（0.132）。Gemma 每 case 仅 376.5 个不同标签（GPT-OSS 918.5、Qwen3-Small 1,140.5）且复用率约高一倍。
- **失败诊断**：658 条金标笔记中，651 条在至少一种抽取模型下**缺少 helpful tag**；仅 7 条在所有抽取模型下都有 helpful tag 但因配置不同而结果不同。缺失抽取标签是 top-5 未命中的常见原因。
- **下游答案准确率**随检索排序变化：containment 从 TagGraph-Stopwords 的 14.6% → TFIDF 的 18.7% → AdaptiveGraph 的 25.3%。

## 7. 优点

- **受控评测设计**：统一 `remember()/query()` 接口、共享抽取笔记与基础图、BM25 使用同一存储，使"图结构是否优于词法排序"这一核心问题可被干净检验。
- **可解释的 5W 表示**：标签仅作检索键，返回单元仍是完整 Markdown 交互，避免因标签化而丢失原始关系、数值与约束。
- **多维度稳健性检验**：覆盖干扰项密度扫描、严格/宽松匹配、per-type recall、词汇归一化、组件消融、失败案例分类，远超单一 MRR 报告。
- **诚实的自我限定**：作者明确区分"受控结论"与"外部参考"，对"topic dilution"只作描述性假设，并主动指出存储规模与评测严格性**无法解释** ATANT 惩罚，未过度声称机制。
- **失败分析有价值**：通过独立于检索结果的 helpful tag 判定，将大量失败归因到抽取可达性层面，对后续系统设计有直接指导意义。

## 8. 不足与局限

- **抽取方差贯穿全部图结果**：所有图配置的性能都继承 LLM 抽取的随机性与盲点，抽取质量的影响甚至超过检索算法差异，使图方法的增益难以稳定归因。
- **实现层面的限制**：每个 case 重建图而非增量更新；扁平 Markdown 存储不适合部署规模；AdaptiveGraph 的幂迭代分数可追溯性弱于 TagGraph 的本体路径。
- **表示特异性**：所有图配置继承 5W schema，未与自由文本摘要或关系三元组比较，排序结论可能是表示特定的。
- **ATANT 交叉现象未解释**：严格性无法解释该惩罚，存储规模只被部分检验（LongMemEval-S 扫描未达到 ATANT Core 的 7.7 notes/story），真正成因需要直接测量图结构与分数重分配。
- **对比范围有限**：未纳入 OpenClaw 之外的稠密/混合检索器，也未纳入 HippoRAG、Zep、MAGMA、A-MEM 等更强图记忆系统；未使用前沿模型抽取；未评估成本与完整 LLM-judge 评测。
- **主指标偏窄**：以检索排序为主，答案准确率仅是方向性检查，且使用与主表不同的打分实现。
- **诊断的因果性弱**：失败诊断基于 pooled miss set 且缺少成功案例对照组，只能审计可达性，不能估计抽取失败的因果贡献。
