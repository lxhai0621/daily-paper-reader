## 摘要
大语言模型（LLM）智能体如今能够承担日益复杂的任务，但它们将交互历史组织为记忆的方式并不能确保对当前世界形成连贯的理解。我们提出 PoS，一种推理时框架，它构建并持续维护显式信念状态，作为智能体的决策上下文。每个信念将当前世界状态的估计与未解决的任务需求相结合，明确智能体仍需学习和完成的内容。为使该信念可靠且可执行，PoS 验证其一致性并监控任务进展，以检测“信念陷阱”（Belief Trapping），即智能体持续行动却未朝目标取得有意义进展。随后，恢复策略会根据陷阱模式与未解决任务需求的类型进行定制。在涵盖执行与诊断的四个基准上，实验表明，PoS 在三种 LLM 主干模型下均在每个基准上取得最高总体性能。消融实验证明了一致性验证与恢复的重要性，而上下文扩展实验显示其对上下文增长的韧性。总之，这些结果支持将信念构建与持续维护作为长时程上下文管理的基础，而不仅限于历史保留与压缩。

## Abstract
Large language model (LLM) agents can now undertake increasingly complex tasks, but the way they organize interaction history into memory does not ensure a coherent understanding of the current world. We introduce PoS, an inference-time framework that constructs and continually maintains explicit belief states as the agent's decision context. Each belief combines an estimate of the current world state with unresolved task requirements, making explicit what the agent still needs to learn and accomplish. To keep this belief reliable and actionable, PoS validates its consistency and monitors task progress to detect Belief Trapping, where the agent continues to act without making meaningful progress toward the goal. Recovery is then tailored to both the trapping pattern and the type of unresolved task requirement. Experiments on four benchmarks spanning execution and diagnosis show that PoS achieves the highest overall performance on every benchmark with all three LLM backbones. Ablations demonstrate the importance of consistency validation and recovery, while context-scaling experiments show resilience to context growth. Together, these results support belief construction and continual maintenance as a foundation for long-horizon context management beyond history retention and compression.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体已具备超长上下文窗口、更强推理与工具调用能力、外部记忆系统与执行框架，可承担越来越复杂的任务。但交互时程变长后，动作会改变环境、新观测会推翻旧推断，累积上下文混杂了"过去状态的证据"与"中间判断"，难以判断哪些事实仍成立、哪些推断仍有支撑、还有什么未解决。
- **现有做法的局限**：
  - 原始轨迹按时间保序，记忆机制对历史做选择、压缩、重组，但**"能访问证据"不等于"拥有对当前世界连贯、可修正、可核查的估计"**。
  - 任务状态若隐含在增长的上下文中，过时或不一致信息会持续影响后续决策。
- **理论视角**：POMDP 中的信念状态 $b_t(s)=P(s_t=s\mid h_t)$ 是决策的充分统计量，可递归更新。已有工作（QuBE、StateAct、ReflAct、Tru-POMDP、ABBEL、Graph of States、LongHorizon-Harness 等）开始显式表示信念，但**显式构建信念只是起点**，还缺两项要求：
  1. **一致性**：LLM 自生成的信念更新可能引入冲突状态或无证据支撑的推断（如微波炉同时记为开与关）。
  2. **防"信念陷阱"（Belief Trapping）**：一致但无进展——重复无效动作、循环访问旧状态、收集与目标无关的信息，直到预算耗尽。
- **研究缺口**：T3 能检测信念偏离并截断轨迹（用于 RL），CGDP 用耗尽门终止无效取证，但都**不在推理过程中恢复**。作者称尚无框架同时做到"持续一致性验证 + 在线诊断与恢复"。
- **整体含义**：长时程智能体的下一道瓶颈不是"保留更多历史"，而是**维护一个可执行的当前世界表示**；信念构建与持续维护应成为长时程上下文管理的基础。

## 2. 方法论（PoS：Progression of States）

### 2.1 总体架构（三个组件）
1. **Belief Modeling**：构建任务条件化的显式信念。
2. **Belief-Guided Interaction**：基于信念选动作、验证信念更新。
3. **Trapping-Aware Recovery**：检测并恢复信念陷阱。

### 2.2 信念建模
- 信念定义为四元组：$B_t=(W_t,\ G,\ \Delta^E_t,\ \Delta^A_t)$
  - $W_t$：任务相关世界状态，采用 **Entity–State–Relation** 结构；Entity 为对象/智能体，State 为自然语言描述，Relation 为有向连接；每条 State/Relation 附带**来源（provenance）、置信度、支撑证据**。只保留能影响动作可行性、结果评估或目标满足的记录。
  - $G$：任务目标与完成标准。
  - $\Delta^E_t$：**认知缺口**（还需了解什么）；$\Delta^A_t$：**成就缺口**（还需达成什么）。二者区分"要学的"与"要做的"。

### 2.3 信念引导交互
- 从 $\Delta^E_t\cup\Delta^A_t$ 中选出一个**活跃缺口** $\Delta_t$（避免在多个缺口间摇摆），完整信念仍作为决策状态保留。
- 动作选择：$a_t\sim\pi(\cdot\mid B_t,\Delta_t,C_t)$，$C_t$ 为恢复约束，正常交互时为空。
- **Belief Sentinel 校验**：任务智能体由 $B_t,a_t,o_{t+1}$ 生成候选信念 $\tilde B_{t+1}=U(B_t,a_t,o_{t+1})$，但它可能继承幻觉或推理错误。Sentinel 审计新增/修改的 Entity、State、Relation、Gap：
  - **内部不一致**：同一实体被赋予互斥状态；
  - **外部不一致**：与最新观测或其他交互证据矛盾。
  - 反馈给任务智能体，智能体结合证据修订后提交为 $B_{t+1}$。

### 2.4 陷阱感知恢复
- **步级进度标签** $u_t\in\{0,1\}$：
  - 诊断任务：$d^{diag}_t=\frac12\sum_x|c_t(x)-c_{t-1}(x)|$，$u_t=\mathbb{I}[d^{diag}_t>\epsilon]$（置信度变化，升与降都算）；
  - 执行任务：Sentinel 判断该转移是否缩小活跃缺口、获取所需信息或推进可行路径。
- **窗口级健康度**：在最近 $K$ 个已验证转移上计算三个信号：
  1. **缺口持续度** $P_X$（$X\in\{E,A\}$）：窗口内初始未解决缺口始终未解决的比例；
  2. **进度停滞度** $S_t$：无进展转移比例；
  3. **信念复现度** $R_t$：以世界状态（Entity/State/Relation 集合的平均 Jaccard 距离 $d_W$）在各时间滞后上取最大复现率。
  - 健康度：$H_t=1-\max_{X\in\{E,A\}}\big[P_X\max(S_t,R_t)\big]$，当 $H_t\le\theta_H$ 判定为信念陷阱。
  - **聚合方式的设计论证**：几何平均在 $S_t$ 或 $R_t$ 为 0 时恒为 1（漏检）；取 max 则当 $P_X=1$ 时误判为陷阱（把"未完成的需求"当成"停滞"）；因此采用"以持续度加权较强的停滞或复现信号"。
- **因子化诊断**（同一窗口内）：
  - **智能体动态模式** $\rho_t$，按顺序判定：
    - Static：$d_W(W_t,W_{t-1})\le\epsilon_W$（局部状态不变）；
    - Cycle：$R_t\ge\theta_R$ 且主导复现滞后 $k^*_t>1$（周期性回归）；
    - Drift：世界状态变化但活跃缺口投影未推进。
  - **受阻缺口类型** $X$：比较非空缺口集的 $P_E$ 与 $P_A$，取持续度更高者（并列时诊断任务优先认知缺口、执行任务优先成就缺口）。
- **恢复约束**：$C_t=C_{pattern}(\rho_t,\mathcal{W}_t)\cup C_{gap}(X,B_t,\Delta_t)$
  - 模式约束：Static→抑制无效的"状态–动作"转移；Cycle→切断主导滞后 $k^*_t$ 对应的循环转移；Drift→重新锚定到活跃缺口。
  - 缺口约束：$X=E$ 要求获取**可区分性证据**；$X=A$ 要求引发**与目标相关的状态变化**。
  - 恢复期间活跃缺口不变；转移经验证后重算 $H_t$，$H_t>\theta_H$ 则释放约束，否则更新诊断与约束。
- **超参数**（附录 D.4）：$K=8$、$L=4$、$\epsilon_W=0.15$、$\epsilon=0.30$、$\theta_H=0.25$、$\theta_R=0.75$；信念更新与本地审计每步 1 次，全局审计在 LOCA-Bench 每 32 步、其余基准每 8 步；恢复最多使用 4 个近期无进展转移。
