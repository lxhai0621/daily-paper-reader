## 摘要
智能体记忆面临异构的访问需求：单跳问题可能只需要一条证据，而多跳问题则必须组合来自多个来源的证据。预定义的记忆工作流无法适应这些变化的需求。近期的自适应方法在记忆组件及其组合上进行搜索或学习，但设计空间本身仍是预定义的。我们提出 MemCodex，一种自演化的分层记忆系统，它将经验组织为可执行的记忆程序，用于摘要、关系知识、可复用技能和潜在记忆。开放式程序演化通过重写每一层的构建、索引、检索和路由方式，在层程序的开放设计空间中进行搜索，从而同时适配层内实现与跨层组合。在查询时，读取从粗到细遍历该层级结构，一旦找到足够证据便停止，并在需要时下探至原始历史。我们进一步开发了 MemArena，一个统一运行时，将异构数据和记忆系统置于统一接口之后。相对于最强的自适应记忆基线，MemCodex 将平均任务成功率提升了 10.1%，同时使用的上下文 token 减少了 3.4 倍，并实现了 2.1 倍的推理加速。

## Abstract
Agent memory faces heterogeneous access needs: a single-hop question may require one piece of evidence, whereas a multi-hop question must combine evidence from multiple sources. Predefined memory workflows cannot adapt to these varying needs. Recent adaptive methods search or learn over memory components and their compositions, but the design space itself remains predefined. We introduce MemCodex, a self-evolving hierarchical memory system that organizes experience into executable memory programs for summaries, relational knowledge, reusable skills, and latent memory. Open-ended program evolution searches the open design space of layer programs by rewriting how each layer is constructed, indexed, retrieved, and routed, thereby adapting both within-layer implementations and cross-layer composition. At query time, reads traverse the hierarchy from coarse to fine and stop once sufficient evidence is found, descending to the original history when needed. We further develop MemArena, a unified runtime that places heterogeneous data and memory systems behind a common interface. MemCodex improves average task success by 10.1% relative to the strongest adaptive-memory baseline, while using 3.4x fewer context tokens and achieving 2.1x faster inference.

## 2. 方法论

### 2.1 核心思想

- 将智能体记忆建模为架构 \(g=(\lambda,\psi)\)：
  - \(\psi\)：各层可执行记忆程序；
  - \(\lambda\)：层掩码，控制派生层是否启用；
  - 原始层 raw 始终启用。
- 文本层从粗到细为：**skill → graph → summary → raw**，另有 **kv memory** 作为潜在记忆。
- 每层暴露固定五方法接口：
  - 写路径：`admit` 过滤候选，`index` 维护有界活跃集，`propose` 向上一层提出派生项；
  - 读路径：`score` 排序候选，`route` 决定继续、缩小或下探。
- 关键约束：原始层 append-only；每个派生项保留精确源 turn 集合 `src(x)`，保证即使经过有损摘要，也能回溯原始证据。

### 2.2 查询自适应读

- 读操作从粗到细遍历活跃层，初始搜索范围 \(F=V\)。
- 对每层：
  - 选取与当前范围有交集的活跃项；
  - `score` 返回 top 候选 \(x^\star\) 与置信度 \(c\)；
  - `route` 返回三种动作之一：
    - `Stop`：停止读取并组装上下文；
    - `Narrow`：将范围限制到 \(F \cap src(x^\star)\)；
    - `Descend`：保持范围继续向细层遍历。
- 若到 raw 层，则取 top-\(k\) 的原始 turn 进入上下文。
- 两种证据通道：
  - **内容通道 \(C_{txt}\)**：将派生项文本放入上下文；
  - **路由通道 \(C_{route}\)**：检索命中后转向其源 turn。
- 论文强调路由通道能恢复摘要遗漏的证据，例如摘要说“Caroline 计划搬家”，但路由到源 turn 可找到“搬到 Paris”。

### 2.3 写路径与潜在记忆

- 写路径自底向上运行 `propose → admit → index`，每层 proposal 结合下层新入项与活跃项。
- skill 层的 `admit` 要求程序在演示会话上回放并复现记录结果。
- 初始架构 \(g_0\)：
  - `index` 使用 MemoryOS 的访问与近期热度；
  - `score` 使用余弦相似度；
  - `route` 使用逐层阈值决定 Stop 或 Narrow。
- **kv memory**：
  - 来自 Metis-27B 的 fast-weight 记忆块状态；
  - 只写、不可 score/route、不参与演化；
  - 对 open-weight 智能体通过 KV 接口注入记忆注意力；
  - API 模型无权重访问，只能使用 NL 接口，无潜在记忆。

### 2.4 程序演化

- 目标：在开放设计空间中搜索层程序及其组合。
- 每轮：
  - 从 archive 中采样 parent；
  - meta agent \(\rho\) 读取诊断、拒绝日志和层代码；
  - 子代只做**一个方法重写**或**一个层开关切换**，保证编辑可归因。
- 诊断 \(D(g)\)：分析失败轨迹、被拒绝或被驱逐项，将失败归因到第一个丢失 gold turn 的方法。
- 有效性检查 \(K\)：拒绝违反记忆约束的子代。
- 接受测试：
  - 仅当 token 不增、准确率不降，且满足“准确率提升且 McNemar 单侧 \(p<\alpha\)”或“token 下降”时接受；
  - 公式为  
    \[
    \text{Accept}(g\to g') \iff \Delta tok \le 0 \land \Delta acc \ge 0 \land ((\Delta acc>0 \land p<\alpha) \lor \Delta tok<0)
    \]
  - \(\alpha=0.05\)。
- Archive：
  - 保存被接受架构，形成树；
  - 被拒绝子代进入 parent 的拒绝日志；
  - parent 采样权重倾向于准确、少扩展、位于 accuracy-cost Pareto 前沿的节点。
- 最终 \(g^\star\) 取 evolve split 上准确率最高的归档架构。
