## 摘要
记忆增强的大型语言模型必须决定保留哪些记忆，而近期系统通过估计每个记忆对任务性能的影响来实现这一点。然而，这些估计完全依赖于被检索到的记忆。当一个记忆从未被检索时，存储层面的干预会产生相同的结果，使其效用无法被识别。这是一种检索层面的正值性违背，对于只检查记忆操作的诊断方法不可见。我们提出因果记忆策略（Causal Memory Policy, CMP），一个因果框架，通过对检索本身进行干预来恢复可识别性，预留固定数量的上下文槽位用于以已知倾向得分采样的记忆。CMP 在平衡分配设计下通过自归一化逆倾向得分加权来估计记忆效用。我们证明了记忆效用经由检索的因果分解、估计量的无偏性和精确方差，以及不可逆操作下的最优决策规则。实证上，在 LongMemEval 上 54% 的必需记忆无法被识别，在 LoCoMo 上为 67%，且这种失败在一个已部署的记忆系统中持续存在。CMP 将必需记忆与非必需记忆之间的区分能力从 0.54 AUC 提升到 0.66 AUC。最后，我们表明仅凭可识别的记忆效用不足以做出保留决策：逐查询效用在被估计的查询上达到 0.78 AUC，但保留策略可用的任何聚合方法都无法预测一个记忆在未见查询上的价值。代码见：https://anonymous.4open.science/r/cmp-release-D0C3/。

## Abstract
Memory-augmented large language models must decide which memories to retain, and recent systems do so by estimating each memory's effect on task performance. However, these estimates rely entirely on retrieved memories. When a memory is never retrieved, store-level interventions produce identical outcomes, leaving its utility unidentified. This is a retrieval-level positivity violation, invisible to diagnostics that examine only memory operations. We introduce Causal Memory Policy (CMP), a causal framework that restores identification by intervening on retrieval itself, reserving a fixed number of context slots for memories sampled with known propensities. CMP estimates memory utility by self-normalized inverse propensity weighting under a balanced assignment design. We prove the causal factorization of memory utility through retrieval, the unbiasedness and exact variance of the estimator, and the optimal decision rule under irreversible operations. Empirically, identification fails for 54% of required memories on LongMemEval and 67% on LoCoMo, and the failure persists in a deployed memory system. CMP improves discrimination between required and non-required memories from 0.54 to 0.66 AUC. Finally, we show that identified memory utility alone is insufficient for retention decisions: per-query utility reaches 0.78 AUC on the query for which it is estimated, yet no aggregation available to a retention policy predicts a memory's value on unseen queries. Code is available at: https://anonymous.4open.science/r/cmp-release-D0C3/.

# 论文结构化总结：Causal Memory Policy (CMP)

## 1. 论文的核心问题与整体含义

**研究背景**
- 记忆增强大语言模型（memory-augmented LLM）需维护外部记忆库以支持长程推理、个性化与知识积累，"保留/遗忘/重组什么"成为一等设计问题。
- 近期系统（如基于成功/失败计数、配对轨迹审计、候选集干预、保留预算等方法）都通过估计**每个记忆对任务性能的影响（记忆效用）**来决定去留。

**核心问题：检索层面的正值性违背（retrieval-level positivity violation）**
- 所有既有效用估计**完全依赖已被检索到的记忆**。若某条记忆从未被检索进上下文，则存储层面对它"存在/不存在"的干预会产生**完全相同的检索集**，从而产生相同的输出，其效用**无法被识别**。
- 根因在于：**检索中介了记忆状态对输出的全部影响**。记忆只有被检索进上下文才能影响答案，因此效用分解为两个因子：**被检索的概率**与**被检索后的条件贡献**。
- 这种失败会伪装成"记忆效用接近零"——退化对比的估计值收敛到 0 而非无定义，使得"真正零效用"与"从未被测试过"无法区分，从而可能导致**破坏性的错误遗忘**。
- 只检查记忆操作（store/forget/consolidate/noop）的探索诊断**看不到**这一失败，因为违背发生在检索变量上。
- 影响范围：仅影响**按估计效用排序**的记忆管理策略；基于新近性/频率的启发式策略因从不评估这些记忆而"侥幸"避开。

**整体含义**
- 作者将记忆效用重新定义为**检索中介的因果效应**，用结构因果模型（SCM）形式化，并指出可识别性由检索过程决定，而非由操作选择决定。

## 2. 方法论：核心思想与关键技术细节

### 2.1 因果形式化（SCM）
- 将记忆增强 LLM 建模为 SCM：$M=(U,V,F)$，外生变量 $U=\{Q,C\}$（查询、观测上下文），内生变量 $V=\{M,R,O,Y\}$（记忆状态、检索子集、操作、输出）。
- 结构方程：
  - 检索：$R_t=f_R(M_t,q_t)$
  - 生成：$Y_t=f_Y(R_t,q_t,\theta_{\text{LLM}})$
  - 操作选择：$O_t=f_O(M_t,q_t,c_t)$
  - 记忆转移：$M_{t+1}=f_M(M_t,O_t,q_t)$
- 关键结构事实：$c_t$ 进入 $f_O$ 但不进入 $f_Y$，故**所有从记忆状态到输出的路径都经过 $R_t$**。
- 两个序贯中介：$O_t\to M_{t+1}\to R_{t+1}\to Y_{t+1}$。第一个中介说明"记忆效用"而非"操作选择"才是估计目标；第二个中介决定可识别性。
- 四大挑战：**C1** 查询诱导混杂；**C2** 经由中介的支持失败；**C3** 不可逆操作；**C4** 无真值 oracle。

### 2.2 检索中介分解与不可识别性
- **记忆效用**：$U_t(m)=E[Y_t\mid do(M_t=M^{+m}_t),q_t,c_t]-E[Y_t\mid do(M_t=M^{-m}_t),q_t,c_t]$。
- **命题 1（检索中介分解）**：$U(m\mid q,c)=P(m\in R\mid q,c)\cdot U_R(m\mid q,c)$，其中第一项为**可检索性**，第二项为**条件效用**（固定上下文大小下，纳入 vs. 排除 m 的期望输出差）。
- **假设 1（检索正值性）**：对所有 $m$ 与 $(q,c)$，$P(m\in R_t\mid q_t=q,c_t=c)>0$——这是 CMP 唯一需要的假设。
- **定理 1（支持失败下的不可识别性）**：若 $P(m\in R\mid q,c)=0$，则两干预臂诱导相同检索集与输出，$U(m\mid q,c)=0$，且 $U_R(m\mid q,c)$ **无法被任何仅随机化记忆状态、保持 $M_{-m}$ 固定的设计识别**，与样本量无关。

### 2.3 组件 (i)：随机化检索暴露
- 每个时间步 $B$ 个上下文槽：$R_t=\text{top-(}B-k)(M_t,q_t)\cup E_t$，其中 $E_t\subset P$，$|E_t|=k$。
- 剩余 $B-k$ 槽由确定性排序器填充，$k$ 槽从暴露池 $P$ 中**以已知倾向采样**。
- **平衡分配**：将 $Tk$ 个暴露槽尽可能均匀分给 $P$，每个记忆获得 $n_m\in\{\lfloor Tk/|P|\rfloor,\lceil Tk/|P|\rceil\}$ 次暴露，倾向 $e_m=n_m/T$ **精确已知**，从而由构造满足假设 1。
- 强调平衡分配的必要性：独立包含会使 $n_m\sim\text{Binomial}(T,k/|P|)$，导致大量记忆暴露不足。
- 极端情形：$k=0$ 即普通检索，$k=B$ 即完全移除排序器。
- **预算推论**：要达到每臂至少 $n_{\min}$ 次抽取，需 $T\ge n_{\min}\cdot|P|/k$——**预算随池大小线性增长，与全库大小无关**。

### 2.4 组件 (ii)：已知倾向下的效用估计
- 使用**自归一化（Hájek）逆倾向加权估计量**：
$$\hat U_R(m)=\frac{1}{n_m}\sum_{t\in T^+_m}Y_t-\frac{1}{T-n_m}\sum_{t\in T^-_m}Y_t$$
- 平衡分配下权重求和为常数，估计量退化为**两臂均值之差**，方差为 $\sigma^2_+/n_m+\sigma^2_-/(T-n_m)$（精确而非条件于实现臂大小）。
- **命题 2**：平衡暴露下 $\hat U_R(m)$ 无偏，方差精确。
- 自归一化消除倾向相关缩放，使不同记忆的估计可直接比较（未归一化估计会与可检索性相关，Hájek 估计无此相关）。
- **对比估计量**：
  - 观测（AIPW）比较器：用倾向模型 + 结果模型，双重稳健（命题 3）。
  - 存储层随机化比较器：独立扰动存储成员，无偏但缺乏支持（命题 4）。
  - 三者仅在于随机化的变量不同（无 / $M_t$ / $R_t$），从而**隔离设计效应与估计器效应**。
- **分歧诊断** $\Gamma(m)$：观测与存储层估计的标准化分歧，仅作诊断（原假设为复合假设）。

### 2.5 组件 (iii)：不可逆操作下的决策规则
- **定理 2（单侧弃权是 Bayes 最优）**：设不可逆比率 $\lambda=H/\tau\ge1$，$z=\hat U_R(m)/\hat\sigma(m)$，则
$$\text{forget}(m)\iff \hat U_R(m)<z^\star(\lambda)\hat\sigma(m)$$
其中 $z^\star(\lambda)$ 是严格增函数 $g_\lambda$ 的唯一根，满足 $z^\star(\lambda)<0$（$\lambda>1$）、$z^\star(1)=0$、$z^\star(\lambda)\to-\infty$（$\lambda\to\infty$）。
- **推论 2**：双侧规则 $|\hat U_R(m)|>\delta\hat\sigma(m)$ 被严格支配（会淘汰确信有用的记忆）。
- 支持失败时 $\hat\sigma\to\infty$，$z\to0$，规则自动弃权（退化为 noop），无需额外诊断。

### 2.6 算法流程（三阶段）
1. **Phase 1 预热**：在默认策略下按暴露设计收集交互数据 $(M_t,q_t,c_t,R_t,Z^{(t)},Y_t)$。
2. **Phase 2 模型拟合**：按公式 6 估计 $\hat U_R(m)$ 与 $\hat\sigma(m)$，拟合倾向/结果模型，计算 $\Gamma(m)$ 审计支持。
3. **Phase 3 在线执行**：在线维护估计，供下游策略消费（如公式 9 的决策规则）。
