## 摘要
现有的记忆系统摘要器通常针对忠实性等面向人类的标准进行优化，这与其真正目标——保留支持未来查询所需的证据——并不一致。我们表明，将摘要生成条件化于查询-答案对能够显著提升答案质量，并且这种效用感知行为可以跨查询迁移。受这些发现启发，我们提出 MemSuit，一个自蒸馏框架；其中，教师摘要器以观察到的查询-答案对为条件，生成效用感知的记忆条目，而学生模型学习仅从原始对话中复现这些条目。为防止附带擦除（即条件化于单个查询-答案对时会丢弃与其他可能查询相关的证据），教师将每个块分解为多个自包含条目，将不同的查询相关侧面保留为可独立检索的单元。为使检索器与教师条目紧凑、事实密集的风格对齐，我们进一步使用由教师条目监督的对比目标微调嵌入模型。在多种多样的对话查询类型上，MemSuit 始终优于最先进的基线，证实了将记忆建立在 downstream 效用之上的价值。

## Abstract
Existing summarizers for memory systems are typically optimized for human-facing criteria such as faithfulness, which misaligns with their true objective: preserving the evidence needed to support future queries. We show that conditioning summarization on query-answer pairs substantially improves answer quality, and that this utility-aware behavior is transferable across queries. Motivated by these findings, we propose MemSuit, a self-distillation framework in which a teacher summarizer, conditioned on observed query-answer pairs, produces utility-aware memory entries that a student learns to reproduce from the raw conversation alone. To prevent collateral erasure where conditioning on a single query-answer pair discards evidence relevant to other plausible queries, the teacher decomposes each block into multiple self-contained entries that preserve distinct query-relevant facets as independently retrievable units. To align the retriever with the compact, fact-dense style of teacher entries, we further fine-tune the embedding model with a contrastive objective supervised by teacher entries. Across a diverse suite of conversational query types, MemSuit consistently outperforms state-of-the-art baselines, confirming the value of grounding memory in downstream utility.

## 1. 核心问题与整体含义
- **研究动机**：LLM 智能体在长期交互中需要记忆系统存储历史、按需检索。现有记忆摘要器多按“面向人”的标准优化，如忠实性、覆盖率、连贯性，但这与记忆摘要的真实目标不一致：摘要最终服务于下游检索与问答，应保留未来查询所需证据。
- **核心诊断**：论文认为记忆摘要存在**目标错位**。传统摘要保留主题级要点，却常丢弃时间、开放域、多跳等查询依赖的细粒度事实，导致后续问答证据不足。
- **整体含义**：论文主张将记忆摘要“锚定于效用意图”，即以下游问答效用而非人类可读摘要质量为目标。作者先验证：若摘要器能看到查询-答案对，答案质量显著提升；且这种效用感知行为可跨查询迁移。

## 2. 方法论
- **核心思想**：提出 **MemSuit**，一种基于自蒸馏的效用导向记忆摘要框架。训练时教师摘要器可访问查询-答案对，生成效用感知记忆条目；学生摘要器仅看原始对话，学习复现教师行为，从而在部署时无查询条件下仍保留潜在有用证据。
- **三阶段流程**：
  1. **自适应条目分解**：教师对对话块 `b` 和观察到的 `(q,a)`，不压缩成单一摘要，而是联合分割并输出可变数量、自包含的记忆条目。至少一个条目锚定当前查询，其余条目总结其他语义区域，避免“附带擦除”——即条件化于单个查询时丢弃其他潜在查询所需证据。
  2. **效用感知自蒸馏**：将教师条目序列化为带分隔符的目标 `y_b,q`，学生仅以对话块 `b` 为条件，用 token 级交叉熵损失学习复现。公式为 `L_distill = -E[Σ log pθ(y_t | y_<t, b)]`。学生不仅学习保留什么内容，也学习如何分解条目以保持独立可检索性。
  3. **条目感知检索校准**：用 LLM 判官 `ψ` 从教师条目中识别支持答案的正例 `Pq`。以余弦相似度衡量查询-条目亲和度，使用 InfoNCE 对比损失，将查询拉近其支撑条目、推离无关块条目，使检索器适配教师生成的紧凑、事实密集条目。
- **训练与推理**：训练时教师离线生成条目与正例，学生和检索器分别优化；推理时无教师、无查询，学生按块生成条目，编码入存储，查询时 top-K 检索，固定 reader 作答。

## 6. 主要结论与发现
- MemSuit 在两个 backbone 上均取得最佳平均 F1/BLEU，Llama backbone 平均 F1 35.56，Qwen backbone 平均 F1 25.04；相对最强 baseline 平均提升约 4.60 F1、3.37 BLEU。
- **时间类查询提升最明显**，说明效用感知蒸馏能恢复 vanilla 摘要常丢失的细粒度时间证据。
- 消融显示自蒸馏与检索校准互补；自蒸馏对时间、开放域贡献更大，因为 vanilla 摘要直接缺失证据，单靠校准无法弥补。
- 自适应分解优于固定粒度；过细会碎片化证据、增加检索噪声，过粗会重新引入附带擦除。
- 检索校准显著提升 grounding evidence 的 Recall@1/5/10，尤其改善初始相似度低的正例尾部。
- 泛化方面：LoCoMo 训练后迁移到 LongMemEval，MemSuit 与最强 baseline SimpleMem 相当；域内训练后超过所有 baseline。
- 存储效率：MemSuit 在较有竞争力的 token 预算下取得最高 F1，且比 Mem0 等更紧凑。

## 7. 优点
- **目标重定义清晰**：将记忆摘要从人类可读性转向下游效用，问题诊断有说服力。
- **方法设计有针对性**：自适应条目分解直接缓解附带擦除；自蒸馏把训练时特权 QA 信息内化到无查询学生；检索校准解决摘要风格与嵌入模型不匹配。
- **训练监督复用充分**：教师条目同时用于学生蒸馏和检索对比学习，无需额外人工标注。
- **实验较全面**：多 backbone、多查询类型、消融、检索分析、跨数据集泛化、新模型鲁棒性、效率分析均有覆盖。
- **部署可行**：推理时无需查询-答案对，符合真实记忆系统“先存储、后查询”的设定。
