## 摘要
尽管基于大语言模型（LLM）的智能体通过将推理与外部环境交互交错进行，在长时程任务中展现出强大能力，但上下文的持续累积会迅速造成严重的记忆瓶颈。现有记忆压缩方法依赖任务特定优化或外部辅助模型，会引入显著的计算开销。此外，所得压缩表示往往丢失结构化关系，导致信息稀释、注意力崩溃以及决策一致性下降。为解决这些局限，我们提出自回归状态机（ARSM），一种轻量级免训练框架，通过结构化状态演化实现原位推理压缩。ARSM 引入两个关键组件：(i) 轨迹抽象机制，将交互历史重组为紧凑的假设-动作-结果（HAR）微链；(ii) 动态状态机，通过原子操作和压缩控制参数来调控分层记忆。这些组件统一在一个自回归、自压缩的生成空间中，其中每次模型输出同时执行外部动作和内部状态更新。我们在 Webshop、Multi-Objective Multi-Hop QA 和 SWE-Bench Lite 数据集上评估 ARSM。实验结果表明，ARSM 在保持任务性能的同时降低了 token 消耗，为面向长时程任务的可扩展自主智能体提供了一条实用且高性价比的路径。

## Abstract
While Large Language Model (LLM)-based agents demonstrate strong capabilities in long-horizon tasks by interleaving reasoning with external environment interactions, the continuous accumulation of context rapidly creates a critical memory bottleneck. Existing memory compression methods rely on task-specific optimization or external auxiliary models, introducing significant computational overhead. Furthermore, the resulting compressed representations tend to lose structured relationships, leading to information dilution, attention collapse, and degraded decision consistency.   To address these limitations, we propose Auto-Regressive State Machine (ARSM), a lightweight training-free framework that enables in-situ reasoning compression through structured state evolution. ARSM introduces two key components: (i) a trajectory abstraction mechanism that reorganizes interaction histories into compact Hypothesis-Action-Result (HAR) micro-chains; (ii) a dynamic state machine that regulates hierarchical memory through atomic operations and a compression-control parameter. These components are unified within an auto-regressive, self-compressive generation space, where each model output jointly performs external action execution and internal state updates.   We evaluate ARSM on Webshop, Multi-Objective Multi-Hop QA, and SWE-Bench Lite datasets. Experimental results show that ARSM maintains the task performance while simultaneously reducing token consumption, offering a practical, cost-effective route toward scalable autonomous agents for long-horizon tasks.

## 2. 方法论：核心思想与关键技术

- **总体思想**：
  - 每次模型输出同时产生两类内容：
    1. 可执行的外部动作；
    2. 用于更新内部记忆的结构化元数据。
  - 形成“双循环”架构：外部执行循环 + 内部状态演化循环。
  - 核心目标：减少携带的历史上下文，同时保留与当前任务相关的因果信息。

- **自回归自压缩生成空间**：
  - 将模型输出形式化为结构化空间 \(Z_t\)，解析为 \(\langle \tau_t, u_t \rangle\)。
  - \(\tau_t\)：提取出的因果元组，如反思、下一步目标等。
  - \(u_t \in \{0,1\}^{4\times1}\)：离散 one-hot 路由向量，对应四类状态转移：
    - Ongoing：继续子任务；
    - Milestone：完成子任务；
    - Failure：失败或死路；
    - Success：成功完成。

- **HAR 微链轨迹抽象**：
  - 传统轨迹包含 Reasoning、Action、Observation。
  - ARSM 将其重组为 **Hypothesis–Action–Result（HAR）微链**：
    \[
    \tau_t = (H_t, A_t, R_t)
    \]
  - \(H_t\)：假设与目标；\(A_t\)：工具调用动作；\(R_t\)：对原始观察的简洁蒸馏。
  - 目的：保留推理因果拓扑，过滤原始环境日志中的冗余噪声。

- **动态状态机**：
  - 内部状态定义为：
    \[
    S_t = [c_t, p_t, w_t, m_t, a_t]^T
    \]
    - \(c_t\)：控制层，全局任务清单与进度；
    - \(p_t\)：约束层中的陷阱记忆，避免重复失败；
    - \(w_t\)：循环警报，检测重复推理；
    - \(m_t\)：知识层，折叠已完成子任务为里程碑事实；
    - \(a_t\)：工作记忆层，保存当前活跃 HAR 因果路径。
  - 状态更新：
    \[
    S_t = \Delta_{Z_t}(S_{t-1}) = (T(\tau_t) \circledast S_{t-1}) u_t
    \]
  - \(T(\tau_t)\) 为转移算子矩阵，由原子操作构成：
    - \(\delta\)：推进任务清单；
    - \(\phi\)：折叠活跃路径为里程碑知识；
    - \(\ell\)：从失败中提取教训；
    - \(\mu\)：更新循环权重与警报；
    - \(\pi\)：剪枝无效活跃路径；
    - \(\chi\)：检查循环风险；
    - \(\oplus\)、\(\cup\) 等用于扩展、写入等。

- **压缩控制参数 \(\rho \in [0,1]\)**：
  - 动态窗口大小：
    \[
    W(\rho)=
    \begin{cases}
    L_{\max} & \rho=0\\
    \max(V_{\min}, \min(L_{\max}, V_{\min}+\lfloor (V_r-V_{\min})\cdot \frac{1-\rho}{\rho}\rfloor)) & \rho>0
    \end{cases}
    \]
  - \(\rho\) 越小保留越多历史；\(\rho\) 越大压缩越激进。
  - 控制对象包括：最近原始轮次窗口、活跃推理路径窗口、陷阱窗口、里程碑窗口、在线状态条目预算、输出截断预算等。

- **稀疏化上下文管理**：
  - 上下文分为三块：
    1. Structured System State：压缩状态，保持目标对齐；
    2. Episodic Raw Trajectory：近期高保真交互，支持执行追踪；
    3. Operational Directives：输出格式与操作指令。

## 6. 主要结论与发现

- ARSM 在多个任务上 **同时降低 token 消耗并保持或提升任务性能**。
- WebShop：
  - 在不同骨干模型上提升 reward；
  - 总 token 降低最高约 66%–67%。
- Multi-Objective Multi-Hop QA：
  - \(\Sigma EM\) 与 \(\Sigma F1\) 显著提升；
  - 峰值 token 降低约 79%–80%。
- SWE-Bench Lite：
  - 提供可控的性能—效率权衡；
  - \(\rho\) 越大，token 越少，但过高压缩可能损害 Pass@1；
  - 总 token 降低最高可达约 82%。
- 路由行为：
  - ARSM 并非只做追加式记忆；
  - 会主动触发 MILESTONE、FAILURE、SUCCESS 等状态转移。
- 消融结论：
  - HAR 抽象主要提升任务性能；
  - 状态机主要降低记忆成本；
  - 两者结合取得最佳性能—效率平衡。
- 总体结论：结构化状态演化是替代无限扩展交互历史的可行方向，为长时程自主智能体提供低成本、可扩展路径。

## 7. 优点

- **免训练、自包含、即插即用**：
  - 不需要微调、RL、外部压缩模型或额外检索模块。
  - 可直接与多种 LLM 骨干配合。
- **结构化压缩而非简单截断**：
  - HAR 微链保留因果拓扑；
  - 动态状态机维护任务进度、失败教训、里程碑和活跃路径。
- **双循环设计清晰**：
  - 外部执行与内部状态更新同步进行；
  - 每次输出同时服务行动与记忆更新。
- **可控压缩**：
  - \(\rho\) 提供连续调节空间，便于按任务需求权衡保真度与推理成本。
- **实验覆盖较广**：
  - 跨三类任务、多个模型家族和规模；
  - 包含组件消融、路由分析、轨迹级评估与案例研究。
- **效率收益显著**：
  - 多个设置中 token 降低幅度大，且性能未普遍崩溃。

## 8. 不足与局限

- **依赖骨干模型能力**：
  - 需要模型可靠生成结构化反思、陷阱、目标等元数据。
  - 小模型可能因指令遵循不足产生格式错误，需要额外恢复轮次。
- **压缩—性能权衡明显**：
  - 过高 \(\rho\) 会丢弃必要上下文，导致 Pass@1 下降。
  - SWE-Bench Lite 中，ARSM 部分设置仍低于 SWE-Pruner 或 Mini SWE-Agent。
- **对比公平性有限**：
  - 多数基线使用额外训练、RL、RAG 或辅助模型，与 ARSM 制度不同。
  - 部分基线结果缺失或无法完成评估，难以严格横向比较。
- **评估偏差风险**：
  - 轨迹级评估依赖 LLM 评估器，可能存在主观性或模型偏好。
  - 仅使用三个 benchmark，任务覆盖仍有限。
- **资源与开销报告不完整**：
  - 未报告总 GPU 小时、推理延迟、状态管理额外开销。
  - 免训练不等于零成本，结构化生成与状态解析可能增加推理负担。
- **状态机设计复杂**：
  - 原子算子、窗口、阈值和 \(\rho\) 相关超参数较多，迁移到新任务可能需要调参。
- **长期稳定性与安全性未深入讨论**：
  - 对极端长时程、错误累积、状态污染、失败恢复等风险缺少系统分析。
- **预印本结果需复现验证**：
