## 摘要
长期记忆通过跨任务保留经验与技能，并使其能够在后续长时程决策中被检索、复用与修订，从而支撑大语言模型智能体的自演化。然而，现有记忆管理方法仍局限于判别式检索，且难以应对可复用经验所具有的稀疏、层次化与高度冗余的结构：只有一小部分依赖任务的轨迹与记忆值得被保留、检索或修订。此外，稀疏、延迟且间接的任务级反馈，以及记忆生命周期中普遍存在的弱监督，使这些操作的学习更加困难。更进一步，持续的记忆演化还带来一种架构层面的张力，即寻址不变性问题：已存储的经验会被不断修订，而供学习型检索策略使用的寻址接口却必须保持稳定。为解决上述问题，我们提出 GenMem，将记忆管理重新表述为生成式符号寻址。其核心机制是符号标识符（SID），即取自笛卡尔积地址空间的多层级离散词元元组，它用不到一百个离散符号对百万规模的稀疏记忆空间进行因子化表示。记忆智能体不再生成不断变化的原始内容，而是学习生成 SID；记忆演化则在固定地址上重写其载荷，而不改变地址本身。在架构上，GenMem 在多智能体执行框架中耦合了 MemRetriever 与 MemEvolver，并通过 GRPO 以密集的过程奖励与结果奖励进行双通道优化训练。在离线记忆演化设定下，实验涵盖 ALFWorld、WebShop、多跳问答、医学推理与深度研究等任务，将 GenMem 与强记忆增强基线进行了对比评估……

## Abstract
Long-term memory supports the self-evolution of LLM agents by retaining experience and skills across tasks and enabling their retrieval, reuse, and revision in subsequent long-horizon decision-making. Yet existing memory management approaches remain limited to discriminative retrieval and to address the sparse, hierarchical, and highly redundant structure of reusable experience: only a small, task-dependent subset of trajectories and memories warrants retention, retrieval, or revision. Learning these operations is further complicated by sparse, delayed, and indirect task-level feedback, with weak supervision across the memory lifecycle. Moreover, continual memory evolution introduces an architectural tension as addressing invariance: stored experience is perpetually revised, yet the addressing interface consumed by learned retrieval policies must remain stable. To address, we present GenMem, which reformulates memory management as generative symbolic addressing. Its core mechanism is the Symbolic Identifier (SID), a multi-level discrete token tuple drawn from a Cartesian-product address space that factorizes a million-scale sparse memory space using fewer than one hundred discrete symbols. Instead of generating ever-changing raw content, the memory agent learns to generate SIDs, while memory evolution rewrites the payload at a fixed address without shifting the address itself. Architecturally, GenMem couples a MemRetriever and a MemEvolver within a multi-agent harness, trained via GRPO with dense process and outcome rewards with two-channels optimization. Under offline memory evolution, experiments spanning ALFWorld, WebShop, multi-hop QA, medical reasoning, and deep research evaluate GenMem against strong memory-augmented baselines...

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：长期记忆使 LLM 智能体能够跨任务保留可复用经验与技能，支撑长时程决策与自演化。但这类"经验记忆"与百科知识不同：它是**行动导向、依赖上下文、持续演化**的。核心问题因此从"哪条记忆最像查询"转变为"哪段经验最能推进当前策略"，且该问题必须在经验本身不断变化时仍可回答。
- **现有范式局限**：主流记忆增强智能体仍锚定在**稠密检索 / 判别式打分**范式上，寻址与内容表示耦合。
- **挑战❶ 稀疏性（Sparsity）**：经验在记忆全生命周期（获取、组织、检索、演化）中高度冗余。论文在附录 B.1 中拆解为四个维度：
  - 价值稀疏（仅少数轨迹含可泛化策略或新失败模式）；
  - 结构稀疏（经验嵌入近似落在低维流形上，共享任务类别/子技能/工具模式）；
  - 访问稀疏（语义相似 ≠ 执行效用高，任一上下文只有极小记忆子集有用）；
  - 演化稀疏（只有被频繁查询反复使用的条目才值得精修）。
  - 叠加问题：监督来自**延迟、间接、稀疏**的任务级结果奖励，难以对单条记忆操作做信用分配。
- **挑战❷ 地址漂移（Address Variance）**：当检索依赖由当前记忆内容导出的表示时，每次内容修订都可能悄然改变"哪些查询能命中该条目"，即便该条目的功能角色未变。论文将此要求称为**寻址不变性（addressing invariance）**——"内容可以改，地址必须稳"。
- **动机类比**：LoRA（低秩）、MoE（稀疏激活）、Engram（条件化知识存储）均利用高维空间中的隐藏规律；可复用经验同样集中在稀疏、层级化的区域，因此需要**选择性寻址**，且该寻址在内容演化时保持稳定。
- **整体含义**：GenMem 把记忆管理从"判别式检索"重构为**生成式符号寻址**，用统一接口同时承担"读"（检索）与"写"（演化定位）。

## 2. 方法论

### 2.1 核心思想
- 用**符号标识符（SID）**作为记忆地址：`z_i = (s_i^1, …, s_i^L) ∈ Z`，其中 `Z = [N1] × … × [N_L]`（笛卡尔积地址空间），每级 `s_i^ℓ ∈ [N_ℓ]` 是一个离散符号。
- **容量与词表**：`K_addr = ∏ N_ℓ`（可能地址数），`V_SID = Σ N_ℓ`（符号总数）。默认配置 `(48,16,8,8)`：**80 个符号表达 49,152 个地址**。
- **地址与载荷解耦**：`(x_i, z_i) --Evolve--> (x'_i, z_i)`。SID 标识的是"记忆槽位"而非某个内容版本；在线修订只重写载荷，不重算/重分配地址。

### 2.2 SID 构造（离线、免梯度冷启动）
1. **经验获取**：由多智能体框架 StackPlanner 对每个训练查询生成多条轨迹；LLM 抽取器对比成功/失败/未验证轨迹，蒸馏可复用流程与失败教训（保留不确定性），得到种子摘要集 `X_seed`。
2. **前缀引导编码**：`e_i = f_enc(p_enc ⊕ x_i) ∈ R^d`，编码器冻结；前缀强调可复用策略、适用条件、验证与失败恢复。
3. **RQ-KMeans 残差量化**（式 3/13/14）：
   - 第 ℓ 级对残差做 K-Means，得码本 `C^(ℓ) = {c_j^(ℓ)}`；
   - 分配：`s_i^ℓ = argmin_j ‖r_i^(ℓ) − c_j^(ℓ)‖²`；
   - 更新：`r_i^(ℓ+1) = r_i^(ℓ) − c_{s_i^ℓ}^(ℓ)`；
   - 逐级拟合，**码本构造后固定**。共享前缀组织功能相近的经验，后级符号提供更细区分。
4. **同 SID 合并**：落到同一 SID 的多条经验被 LLM 合并为单条记忆条目（压缩统计见附录 D.2：138,243 条 → 16,416 条摘要，约 9.1× 文本压缩；每条摘要平均合并 4.52 条原始经验）。

### 2.3 生成式读—写闭环（式 4）
- **Retrieve**：`(z_r, x̃_r) = MemRetriever(q, M)` —— 生成检索 SID，取回经验并**改写为任务适配支持**。
- **Execute**：`(ŷ, τ) = StackPlanner(q, x̃_r)`。
- **Evolve**：`M' = Update(M; MemEvolver(τ, M))`，MemEvolver 返回 `(o, z_e, x̃_e)`，`o ∈ {insert, revise}`；`revise` 通过"载荷不变 / 合并 / 空载荷"分别实现保留、整合、删除。
- **更新规则**（式 26）：`M_{t+1}[z] = x̃_{e,t}` 若 `z = z_{e,t}`，否则保持原值——即**只改被寻址载荷，绝不重分配已有 SID**。

### 2.4 四阶段训练流程
1. **SID 对齐预训练**：五个文本↔SID 映射（正向 `q→z`、`τ→z`、`x→z`；反向 `z→x`、`z→d`）。损失 `L_SID(c,z) = −Σ_ℓ log p_θ(s^ℓ | c, s^{1:ℓ−1})`，`L_pre = Σ λ·L_映射`（式 5–6）。建立符号地址与经验的双向关联。
2. **记忆操作中训练**：构造 ReAct 风格轨迹，分别训练 MemRetriever（推理→生成检索 SID→查看→改写）与 MemEvolver（分析轨迹→提取可迁移教训→生成更新 SID→修订/新增）；用拒绝采样过滤格式与任务正确性，再由更强教师模型蒸馏推理链与角色输出，用标准下一词预测微调。
3. **联合策略后训练（GRPO，式 7–9）**：
   - 过程奖励 `R_process = R_format + R_strategy + R_SID`（格式合法性、SID 与真值一致性、LLM 裁判评估策略有用性）；
   - 结果奖励 `R_out = r_task(ŷ_mem, y*) − r_task(ŷ_no-mem, y*) + α·I[两者皆对]`（**对比式**，度量相对效用而非绝对准确率；仅当有记忆与无记忆都成功时给部分信用奖励）；
   - GRPO 目标含 token 级重要性比 `ρ_{i,t}`、裁剪、KL 惩罚项 `β·D_KL`；优势在 **proxy 与 audit 两个通道**分别归一化（"双通道优化"）。
4. **在线记忆自演化**：模型参数、编码器、SID 码本全部冻结；三者构成闭环处理新查询流：检索→执行→演化写入；`insert` 占空槽、`revise` 更新已有条目，**目标 SID 由 MemEvolver 生成，而非对更新后载荷重新编码量化**。适应完全发生在外部记忆层，无需梯度更新。
