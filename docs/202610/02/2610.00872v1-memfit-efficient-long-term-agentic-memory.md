## 摘要
面向大语言模型（LLM）的长期记忆系统因能够跨应用扩展推理能力而日益流行。当前记忆系统依赖 LLM 智能体来组织和整合记忆，导致写入操作成本高昂且效率低下。为解决这一局限，我们提出 MemFit，一种面向对话智能体的长期记忆系统，可降低记忆操作的成本和延迟。与依赖昂贵 LLM 调用来构建记忆、或通过压缩丢弃表层细节的现有系统不同，MemFit 将每一轮对话逐字存储在仅追加存储中，插入近乎瞬时且无需 LLM，并用片段摘要对轮次进行索引，而非替换它们。此外，MemFit 采用一种无需 LLM 的多路径检索策略，在文本和多模态设置下，对经说明文字增强的片段结合词汇与语义信号，并使用交叉编码器重排序。在三个广泛使用的基准 LoCoMo、MemGallery 和 LongMemEval-S 上的实证结果表明，MemFit 在实现最先进性能的同时，将记忆构建时间和成本降低数倍，为持久化的智能体记忆提供了可扩展且高效的解决方案。

## Abstract
Long-term memory systems for large language models (LLMs) have gained popularity for extending reasoning capabilities across applications. Current memory systems rely on LLM agents to organize and consolidate memory, resulting in costly, inefficient write operations. To address this limitation, we propose MemFit, a long-term memory system for conversational agents that reduces the cost and latency of memory operations. Unlike existing systems that rely on expensive LLM calls for memory construction or discard surface-level details through compression, MemFit stores each turn verbatim in an append-only store with near-instantaneous, LLM-free insertion, indexing turns with segment summaries rather than replacing them. Additionally, MemFit uses an LLM-free, multi-path retrieval strategy that combines lexical and semantic signals with cross-encoder reranking over caption- augmented episodes in both textual and multimodal settings. Empirical results on three widely used benchmarks, LoCoMo, MemGallery, and LongMemEval-S, show that MemFit achieves state-of-the-art performance while reducing memory construction time and cost several-fold, providing a scalable and efficient solution for persistent agentic memory.

## 1. 核心问题与整体含义

- **研究动机**：LLM 受固定上下文窗口限制，长对话中易出现“context rot”，因此需要外部长期记忆系统。现有系统多依赖 LLM 智能体在写入时整理、压缩、合并或删除记忆，导致写入成本高、延迟大。
- **核心问题**：能否在不依赖频繁 LLM 调用的情况下，实现高效存储与精准检索的长期智能体记忆？
- **整体含义**：MemFit 将 LLM 移出写入路径与检索搜索本身，采用“原样追加存储 + 摘要索引 + 免 LLM 多路径检索”，在性能、成本与多模态扩展之间取得更好平衡。

## 2. 方法论

### 核心思想
- **写入路径几乎免 LLM**：每轮对话逐字存储为 episode，插入仅需一次编码与两个索引追加。
- **摘要只做索引，不替代原文**：片段摘要用于定位对话区间，原始轮次仍可单独检索。
- **检索路径免 LLM**：融合词法、语义、摘要溯源、伪相关反馈与交叉编码器重排。
- **多模态文本图像融合**：将图像 ID 与 caption 作为结构化文本追加到 episode 文本中，使视觉内容可通过同一文本检索空间召回。

### 存储与摘要层
- 每个 utterance 形成一个 episode：  
  `e_i = (x_i, z_i, g_i, m_i)`  
  其中 `x_i` 是带时间与说话人标注的文本，`z_i` 是冻结句编码器的 L2 归一化嵌入，`g_i` 是全局序号，`m_i` 是元数据。
- 多模态轮次将 `[Image ID: caption]` 追加到 `x_i`。
- 两个索引：
  - **BM25 词法索引**：匹配姓名、日期、稀有名词等需逐字出现的内容。
  - **稠密语义索引**：嵌入矩阵 `Z`，通过 `Z z_q` 计算余弦相似度，匹配 paraphrase。
- 摘要层：
  - 用 TextTiling 基于 episode 嵌入自动分段，无需 LLM。
  - 对每个至少 3 个 episode 的片段，取最多 14 个均匀抽样 excerpt，调用一次 LLM 生成两句、≤200 token 的摘要。
  - 摘要记录成员 episode ID 作为 provenance，拥有自己的嵌入，并可被同一混合评分检索。
- **无合并、重写、删除**：事实更新时，旧陈述与纠正都保留并带日期，检索时按时间返回，让读者在知道问题后再做取舍。

### 检索四阶段
1. **混合候选生成**  
   - 词法路径：BM25。  
   - 语义路径：余弦相似度。  
   - 各取 top `nscan=60` 形成候选并集。  
   - 分数 min-max 归一化后凸组合：  
     `s_i = α · d_sem(z_q, z_i) + (1−α) · c_lex(q, x_i)`，默认 `α=0.7`。  
   - 元数据加成：说话人 `+0.10`、月份 `+0.08`、年份 `+0.05`。
2. **加性候选扩展**  
   - 摘要层用同一混合分数检索，最高分摘要通过 provenance 拉入其成员 episode。  
   - 伪相关反馈：取 top-2 episode 中 12 个最稀有词重跑候选生成，面向多跳问题。  
   - 扩展只增加候选，不淘汰已有候选。
3. **重排与 pack 组装**  
   - 交叉编码器对 top-50 一阶段候选与所有扩展候选重排。  
   - 摘要与 episode 分数分别标准化，避免文本分布差异影响排序。  
   - 取 top `k=10`，每个 episode 带同会话内 `w=1` 的邻居，恢复上下文。
4. **答案抽取**  
   - 将候选按时间排序，日期解析为绝对日期。  
   - 单次 LLM 调用生成答案。  
   - 多模态模式下，读者为 MLLM，并传入排序 episode 的图像与查询图像。

## 3. 实验设计

- **数据集 / Benchmark**：
  - **LoCoMo**：多会话长期对话，10 个对话、5,882 轮；评估 1,540 个非对抗问题，含 multi-hop、temporal、open-domain、single-hop 四类。
  - **MemGallery**：多模态长期记忆基准，20 个场景、240 会话、3,962 轮，1,003 轮含图像；1,711 个问题，分 9 类，归为记忆抽取/适应、记忆推理、知识管理三维度。
  - **LongMemEval-S**：500 个问题，每个问题对应约 47.7 个会话、约 115k token
