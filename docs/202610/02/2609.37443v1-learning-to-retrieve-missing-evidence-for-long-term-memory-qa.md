## 摘要
长期记忆使语言模型能够在未来对话中使用过去的交互。然而，回答问题所需的证据可能分散在相隔较远的对话轮次中，而问题本身又缺少定位这些证据所需的线索。检索到的事实可以揭示这些线索，从而促使我们基于已找到的证据做出检索决策。我们提出 MERA（缺失证据检索增强，Missing-Evidence Retrieval Augmentation），它将可全局搜索的记忆与针对特定问题的证据状态分离开来。经核实的证据指导后续检索，同时不限制对全局记忆的访问。我们通过强化学习训练一个轻量级规划器，奖励那些能够找回先前缺失证据的查询。MERA 在 Qwen3-30B 和 GPT-4o-mini 骨干模型上均取得较强的答案准确率。使用 Qwen3-30B 进行证据处理和答案生成时，训练后的 0.6B 规划器在 LoCoMo 上达到 77.40% 的准确率，在 LongMemEval-S 上达到 71.29%，分别超过未经检索依据训练的 30B 规划器 4.10% 和 3.96%。在 LoCoMo 上，后续检索轮次将累计证据召回率从 55.5% 提升到 80.5%。

## Abstract
Long-term memory enables language models to use past interactions in future conversations. However, evidence needed to answer a question may be scattered across distant turns, while the question itself omits clues needed to locate it. Retrieved facts can reveal these clues, motivating retrieval decisions conditioned on evidence already found. We introduce MERA (Missing-Evidence Retrieval Augmentation), which separates globally searchable memory from a question-specific evidence state. Verified evidence guides subsequent retrieval without restricting access to the global memory. We train a lightweight planner through reinforcement learning, rewarding queries that recover previously missing evidence. MERA achieves strong answer accuracy across Qwen3-30B and GPT-4o-mini backbones. With Qwen3-30B for evidence processing and answer generation, the trained 0.6B planner achieves 77.40% accuracy on LoCoMo and 71.29% on LongMemEval-S, exceeding a 30B planner without retrieval-grounded training by 4.10% and 3.96%, respectively. On LoCoMo, later retrieval rounds increase cumulative evidence recall from 55.5% to 80.5%.

## 一、核心问题与研究动机

- **背景**：长期记忆让语言模型能在未来对话中复用过去交互。近期记忆系统已能较好地解决"存什么、如何组织、如何维护"的问题（如 Mem0、A-MEM、MemoryOS、LightMem）。
- **核心痛点**：在长对话历史问答中，回答所需证据往往**稀疏且分散在相距很远的轮次**，而问题本身常常**缺失定位证据所需的实体、事件或时间线索**。因此，仅按问题检索"单条相关记忆"仍会漏掉关键证据。
- **关键转变**：挑战不仅是"哪些记忆相关"，而是"在已找到的证据基础上，下一步应该检索什么"。已恢复的证据本身可以提供原问题中不存在的检索锚点。
- **现有方法局限**：
  - 持久记忆方法侧重维护可复用记忆，较少关注"针对特定问题的已核实证据状态"。
  - IRCoT 用累积段落与推理调整查询，但缺乏显式验证步骤来区分"已确立证据"与"其他中间内容"。
  - 图遍历类方法（GraphReader、Think-on-Graph、HippoRAG）的后续访问依赖预构图连通性，可能把关键证据排除在可达范围之外。
- **论文目标**：提出 MERA（Missing-Evidence Retrieval Augmentation），把**全局可搜索记忆**与**问题特定的证据状态**分离，让已核实证据引导检索，同时不限制对全局记忆的访问。

## 二、方法论

### 2.1 核心思想

MERA 将长期记忆问答建模为**序列化证据获取**过程：每一轮检索决策都取决于"已经确立了什么"与"问题仍缺什么"。系统包含三个层面：

1. **离线记忆构建**：把对话轮次分解为自包含的原子事实，嵌入并索引，同时保留父轮次标识符。
2. **在线证据引导检索**：轻量规划器基于演化中的证据状态生成检索意图；检索器在全局原子事实索引上执行；验证器筛选有用证据并更新状态。
3. **检索接地的规划器训练**：用强化学习（GRPO）训练轻量规划器，奖励能找回"先前缺失的黄金证据"的查询。

### 2.2 关键技术细节

**（1）可追溯记忆与证据状态**

- 每个对话轮次提取自包含原子事实，附带关键词、主题标签、说话人、时间戳、轮次 ID；代词替换为显式实体，保留主-谓-宾方向性。
- **父子轮次事实聚合（Parent-turn Fact Aggregation）**：原子事实作为匹配单元（细粒度），父轮次事实记录作为验证与推理单元（粗粒度）。多意图结果按父轮次合并去重，验证器收到的是该轮次全部抽取事实 + 说话人 + 时间元数据，而非原始对话文本。
- 证据状态表示为：

  $$G_t = (V_t, L_t, X_t, D_t, \Psi_t), \quad s_t = (q, G_t, Q_t, S_t, E_t)$$

  其中 $V_t$ 为类型化节点（人物、组织、地点、事件、日期、数量、状态），$L_t$ 为有向标注关系，$X_t$ 为活跃检索锚点，$D_t$ 为已穷尽/失效方向，$\Psi_t$ 为指向来源轮次的溯源链接；$Q_t$ 为历史查询，$S_t$ 为已查看候选，$E_t$ 为已接受证据。
- **时间归一化**：区分"轮次时间"与"事件时间"；精确相对表达按轮次时间解析，模糊表达保留锚定区间；年龄、金额、计数、时长均显式计算并保留原始陈述与溯源。

**（2）证据状态引导的主动检索**

- 每轮规划器输出一组结构化检索意图：

  $$a_t = \{I_\ell^t\}_{\ell=1}^{m_t}, \quad I_\ell^t = (d_\ell^t, k_\ell^t, c_\ell^t)$$

  分别描述期望事实、显著实体/概念、粗略主题标签。
- 检索器把意图字段拼接为查询文本，在全局原子事实索引上检索，**排除已查看证据**；候选访问不要求与 $G_t$ 中节点相邻，因此可检索到图中尚未出现的实体。
- 验证器仅接受有助于回答问题的候选，并更新状态：

  $$G_{t+1} = \text{Merge}(G_t, \Delta G_t), \quad E_{t+1} = E_t \cup E_t, \quad Q_{t+1} = Q_t \cup a_t$$

- 终止条件：证据充分、搜索穷尽、连续多轮无有效意图/候选/图更新、或达到轮次预算 $T_{\max}$。最终图与已接受事实记录（含来源标识）交给答案模型。

**（3）检索接地的策略优化（GRPO）**

- **动机**：查询生成没有唯一正确字符串；不同措辞可能检索到相同证据，看似合理的查询可能只重复旧命中。因此**按检索结果而非查询形式评估动作**。
- 定义：$E^*$ 为黄金父轮次，$F_t$ 为第 $t$ 轮前已找到的黄金证据，$U_t = E^* \setminus F_t$ 为剩余缺失证据，$R(o_t)$ 为规划器输出 $o_t$ 检索到的父轮次。则：

  $$x_t = \frac{|R(o_t) \cap U_t|}{|U_t|}, \quad p_t = \frac{|F_t|}{|E^*|}, \quad R_{\text{ret}}(o_t) = x_t \left[1 + p_t(1 - x_t)\right]$$

  - $x_t$：本轮找回的缺失黄金证据比例；
  - 已找到证据不再获得额外奖励；
  - 进度项 $p_t(1-x_t)$ 使轨迹后期部分恢复获得更高奖励。
- **训练数据构造**：LoCoMo 用官方数据生成工具合成问题；LongMemEval 用训练分区对话 + 额外生成问题。训练状态覆盖初始检索、互补检索、后期补全；**过滤掉所有 rollout 均失败或均成功的状态**，只保留策略选择能改变结果的状态。
- **GRPO 细节**：对同一证据状态采样一组 $G$ 个输出，在相同记忆上执行并计算奖励，用组内均值/标准差归一化为相对优势 $A_i = (r_i - \bar{r})/(\sigma_r + \epsilon)$；采用 token 级裁剪代理目标，并加 KL 正则与可选熵项：

  $$J(\theta) = J_{\text{clip}}(\theta) - \beta D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}}) + \eta H(\pi_\theta)$$

- 仅更新规划器；记忆索引、证据模型、答案模型均保持固定。
- 辅助惩罚：关键词数量惩罚（抑制过宽意图）与响应长度惩罚。
