## 摘要
持久性文本记忆使语言模型能够在长程交互中携带信息，但学习该记住什么本质上是一个信用分配问题。一次记忆重写可能要在许多步之后才变得有用，而观察到的效用中很大一部分可能继承自重写之前已存储的信息。我们提出记忆增益策略优化（Memory Gain Policy Optimization, MGPO），通过将每次记忆重写归功于其对当前和未来下游效用的边际贡献，来分离其增量价值。这将延迟的记忆效用转化为直接的学习信号，以优化哪些信息应当被持久保留。我们在文档级信息抽取上研究 MGPO，其中结构化监督使单个记忆更新的效果可直接度量。相对于优化前的初始记忆策略，MGPO 在改进抽取的同时将平均记忆长度减少近 80%。学习到的记忆策略还支持跨领域复用和迁移，并可在无需进一步训练的情况下用于下游模型。这些结果表明，有效的记忆学习不仅取决于保留有用信息，还取决于识别哪些记忆更新能创造持久的增量价值。

## Abstract
Persistent textual memory allows language models to carry information across long interactions, but learning what to remember is fundamentally a credit-assignment problem. A memory rewrite may only become useful many steps later, while much of the observed utility may be inherited from information already stored before the rewrite. We introduce Memory Gain Policy Optimization (MGPO), which isolates the incremental value of each memory rewrite by crediting it for its marginal contribution to current and future downstream utility. This turns delayed memory utility into a direct learning signal for optimizing what information should persist. We study MGPO on document-level information extraction, where structured supervision makes the effects of individual memory updates directly measurable. MGPO improves extraction while reducing average memory length by nearly 80% relative to the initial memory policy before optimization. The learned memory policy also supports reuse and transfer across domains, downstream models without further training. These results show that effective memory learning depends not only on preserving useful information, but on identifying which memory updates create lasting incremental value.

## 1. 核心问题与整体含义

- **研究背景**：持久性文本记忆使语言模型能够在长程交互中携带信息，但记忆容量有限，模型必须选择性保留、修订或丢弃内容。现有方法包括检索式记忆、显式记忆管理、以及学习式记忆策略，但大多未解决一个核心学习问题：**一次记忆改写是否真正创造了下游价值**。
- **核心问题**：记忆学习本质上是长时程信用分配问题。
  - 一次改写可能多步之后才显现价值，延迟收益难以归因。
  - 即使某记忆状态对下游任务有用，其效用也可能主要**继承自改写前已存在的信息**（inherited utility），而非最新改写本身的贡献。
  - 因此，记忆状态的效用不能直接反映单次改写的边际贡献。
- **整体含义**：论文提出 **Memory Gain Policy Optimization（MGPO）**，通过反事实比较相邻记忆状态，隔离每次改写的增量价值，将延迟记忆收益转化为直接学习信号，从而学习“该记住什么”。
- **主要贡献**：
  - 识别“继承效用”是持久记忆学习中的核心挑战。
  - 提出 MGPO，为每次改写分配长时程反事实信用，同时保持原始下游目标不变。
  - 学到紧凑、可选择性记忆，提升文档级信息抽取，并支持跨 reader、跨领域、跨任务复用与迁移。

## 2. 方法论

### 2.1 核心思想

- 将记忆写入过程与答案生成**解耦**：仅训练记忆 writer，下游 reader 固定。
- 对同一 reader、同一目标，比较**改写前记忆**与**改写后记忆**的效用差异，得到该改写的边际贡献。
- 将单次改写对当前及未来所有目标的边际贡献累加，形成 **Memory Gain**，作为策略优化信号。

### 2.2 关键技术细节

- **流式记忆写入**：
  - 输入按块到达 \(c_1,\dots,c_N\)，记忆有界 \(|m_t| \le B\)。
  - writer \(\pi_\theta\) 生成更新记忆：\(m_t \sim \pi_\theta(\cdot \mid m_{t-1}, c_t)\)，\(m_0=\varnothing\)。
  - 固定 reader \(E\) 基于 \(m_t\) 与 \(c_j\) 生成答案 \(\hat{y}_{t,j}(\xi)=E(m_t,c_j;\xi)\)。
- **记忆状态效用**：
  - \(F_{t,j}=\mathbb{E}_\xi[U(\hat{y}_{t,j}(\xi),y_j)]\)，实践中用单次蒙特卡洛采样估计。
- **改写级信用**：
  - 反事实差分：\(\Delta_{t,j}=F_{t,j}-F_{t-1,j}\)。
  - Memory Gain：\(MG_t=\sum_{j=t}^{N}\Delta_{t,j}\)，衡量改写 \(t\) 在当前及未来目标上的总边际效用。
- **长时程返回**：
  - \(G_t=\sum_{k=t}^{N}MG_k\)，同时包含后续改写的贡献。
- **反事实矩阵**：
  - \(F_{t,j}\) 构成上三角矩阵，对角线 \(F_{j,j}\) 对应事实流式轨迹；非对角线为反事实评估，仅训练时需要。
- **势函数与继承效用**：
  - 定义 \(\Phi_t=\sum_{j=t}^{N}F_{t-1,j}\)，\(\Phi_{N+1}=0\)。
  - 可得 \(MG_t=r^{fact}_t+\Phi_{t+1}-\Phi_t\)，即 Memory Gain 是事实奖励的**势函数塑形**形式。
  - 返回分解：\(G_t=G^{fact}_t-\Phi_t\)。
- **策略梯度保持**：
  - 令 \(\psi_t=\nabla_\theta\log\pi_\theta(m_t\mid m_{t-1},c_t)\)。
  - 由于 \(\Phi_t\) 由改写前记忆决定，与当前动作条件独立，\(\mathbb{E}[\psi_t\Phi_t]=0\)。
  - 因此 \(\nabla_\theta J_{MG}=\nabla_\theta J_{fact}\)：MGPO 保持原目标期望梯度，但改变有限样本信用分配，\(\Phi_t\) 充当动作无关控制变量，可降低方差。
- **策略优化目标**：
  - 位置特定 EMA \(b(t)\) 与全局 EMA 尺度 \(\sigma^2\) 归一化优势：\(A_t=(G_t-b(t))/\sqrt{\sigma^2+\epsilon}\)。
  - 使用 PPO 式 token 级裁剪目标，并加入 KL 正则项约束 writer 不偏离参考策略。
- **任务实例化**：
  - 在文档级信息抽取中，将文档级 micro-F1 线性化为加性代理，按块分配监督目标。
  - 用固定权重 \(w\) 计算每个反事实单元效用 \(F_{t,j}=\sum_a \lambda_a \langle w^{(a)}, q^{(a)}_{t,j}\rangle\)，使信用可加、可比较。

### 2.3 算法流程（文字说明）

1. 采样一个文档 minibatch，切分为流式块与对应目标。
2. 用旧策略进行流式 rollout，生成记忆轨迹 \(m_1,\dots,m_N\)。
3. 对 \(0\le s\le j\le N\) 计算反事实效用矩阵 \(F_{s,j}\)。
4. 对每个改写 \(t\) 计算 \(MG_t\) 与返回 \(G_t\)。
5. 用位置 EMA 与全局尺度归一化得到优势 \(A_t\)。
6. 用 PPO 裁剪目标与 KL 正则更新 writer 参数。
7. 更新位置 EMA 与全局方差 EMA，重复直至收敛。
