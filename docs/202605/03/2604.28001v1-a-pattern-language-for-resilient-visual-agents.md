## 摘要
将多模态基础模型集成到企业生态系统中提出了一个根本性的软件架构挑战。架构师必须平衡相互竞争的质量属性：视觉语言动作（VLA）模型的高延迟和非确定性，与企业控制回路所需的严格确定性和实时性能。在本研究中，我们为视觉智能体提出了一种架构模式语言，将快速、确定性的反射与慢速、概率性的监督分离开来。它由四种架构设计模式组成：(1) 混合示能集成，(2) 自适应视觉锚定，(3) 视觉层级综合，以及 (4) 语义场景图。

## Abstract
Integrating multimodal foundation models into enterprise ecosystems presents a fundamental software architecture challenge. Architects must balance competing quality attributes: the high latency and non-determinism of vision language action (VLA) models versus the strict determinism and real-time performance required by enterprise control loops. In this study, we propose an architectural pattern language for visual agents that separates fast, deterministic reflexes from slow, probabilistic supervision. It consists of four architectural design patterns: (1) Hybrid Affordance Integration, (2) Adaptive Visual Anchoring, (3) Visual Hierarchy Synthesis, and (4) Semantic Scene Graph.

### 2. 论文提出的方法论
核心思想是**解耦快速确定性反射（System 1）与慢速概率性认知监督（System 2）**。论文定义了四种核心架构模式：

1.  **混合示能集成模式 (Hybrid Affordance Integration)**：
    *   **技术细节**：建立多模态感知融合层。并行运行轻量级局部模型（如 UI 对象检测器和 OCR），通过几何融合将输出投影到共享坐标平面。若两者冲突，则降低置信度并触发主动验证（如悬停），避免“感知幻觉”。
2.  **自适应视觉锚定模式 (Adaptive Visual Anchoring)**：
    *   **技术细节**：建立“回退路由”机制。System 1 负责毫秒级的本地缓存匹配（模板或特征嵌入）；当匹配置信度低于阈值（如 $\tau < 0.9$）时，触发 System 2（VLA 监督者）进行语义定位并更新缓存。
3.  **视觉层级综合模式 (Visual Hierarchy Synthesis)**：
    *   **技术细节**：将扁平的感知输出（坐标列表）转化为层级化的 UI 表示。利用格式塔原理（如包含、对齐）推断树状结构，实现“相对寻址”，使智能体对全局布局偏移具有鲁棒性。
4.  **语义场景图模式 (Semantic Scene Graph)**：
    *   **技术细节**：构建静态、可查询的世界模型。节点代表语义实体，边代表功能和空间关系。在执行高风险操作前，通过遍历图来验证前提条件，增强可解释性和安全性。
