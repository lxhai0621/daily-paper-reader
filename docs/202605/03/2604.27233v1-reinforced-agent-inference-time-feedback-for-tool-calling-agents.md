## 摘要
工具调用智能体通常根据工具选择、参数准确性和范围识别进行评估，但大语言模型（LLM）的轨迹评估本质上仍是事后的。由于与活跃的执行循环脱节，此类评估识别出的错误通常通过提示词微调或重新训练来解决，从根本上无法实时纠正智能体的行为。为了弥补这一差距，我们将评估移至推理时的执行循环中：一个专门的审查智能体在执行前评估临时的工具调用，将范式从后期恢复转变为主动评估和错误缓解。在实践中，这种架构在主执行智能体和次要审查智能体之间建立了明确的关注点分离。与任何多智能体系统一样，审查者在纠正错误的同时也可能引入新错误，但据我们所知，此前尚无研究系统地衡量这种权衡。为了量化这种权衡，我们引入了“益处-害处”（Helpfulness-Harmfulness）指标：益处衡量反馈纠正基础智能体错误的百分比；害处衡量反馈导致正确响应退化的百分比。这些指标通过揭示给定模型或提示词是否提供净正向价值，直接为审查者的设计提供参考。我们在 BFCL（单轮）和 Tau2-Bench（多轮有状态场景）上评估了我们的方法，在无关检测上提升了 5.5%，在多轮任务上提升了 7.1%。我们的指标表明，审查者模型的选择至关重要：推理模型 o3-mini 实现了 3:1 的收益风险比，而 GPT-4o 为 2.1:1。通过 GEPA 进行的自动提示词优化额外带来了 1.5-2.8% 的提升。总之，这些结果展示了分离执行与审查的核心优势：审查者可以通过模型选择和提示词优化进行系统性改进，而无需重新训练基础智能体。

## Abstract
Tool-calling agents are evaluated on tool selection, parameter accuracy, and scope recognition, yet LLM trajectory assessments remain inherently post-hoc. Disconnected from the active execution loop, such assessments identify errors that are usually addressed through prompt-tuning or retraining, and fundamentally cannot course-correct the agent in real time. To close this gap, we move evaluation into the execution loop at inference time: a specialized reviewer agent evaluates provisional tool calls prior to execution, shifting the paradigm from post-hoc recovery to proactive evaluation and error mitigation.   In practice, this architecture establishes a clear separation of concerns between the primary execution agent and a secondary review agent. As with any multi-agent system, the reviewer can introduce new errors while correcting others, yet no prior work to our knowledge has systematically measured this tradeoff. To quantify this tradeoff, we introduce Helpfulness-Harmfulness metrics: helpfulness measures the percentage of base agent errors that feedback corrects; harmfulness measures the percentage of correct responses that feedback degrades. These metrics directly inform reviewer design by revealing whether a given model or prompt provides net positive value.   We evaluate our approach on BFCL (single-turn) and Tau2-Bench (multi-turn stateful scenarios), achieving +5.5% on irrelevance detection and +7.1% on multi-turn tasks. Our metrics reveal that reviewer model choice is critical: the reasoning model o3-mini achieves a 3:1 benefit-to-risk ratio versus 2.1:1 for GPT-4o. Automated prompt optimization via GEPA provides an additional +1.5-2.8%. Together, these results demonstrate a core advantage of separating execution and review: the reviewer can be systematically improved through model selection and prompt optimization, without retraining the base agent.

### 1. 核心问题与研究动机
*   **核心问题**：现有的工具调用智能体（Tool-calling Agents）在选择工具、构造参数及识别任务范围时经常出错。
*   **研究背景**：目前的评估和改进方法大多是“事后”的（post-hoc），即在错误发生后通过提示词微调或重新训练来解决。
*   **痛点**：在实时执行循环中，一旦智能体执行了错误操作（如误删数据），事后纠错往往面临“状态恢复难题”（State Recovery Problem），且维护复杂轨迹的上下文成本极高。
*   **整体含义**：论文提出将评估环节前置到执行循环中，通过一个独立的“评审智能体”在工具调用执行前进行实时审核和纠偏。

### 2. 方法论
*   **核心思想**：采用“双智能体架构”，实现执行与评审的关注点分离（Separation of Concerns）。主智能体负责生成工具调用，评审智能体负责在执行前拦截并评估。
*   **关键协作机制**：
    *   **渐进式反馈（Progressive Feedback, $rN$）**：评审者发现错误后提供反馈，主智能体据此修正，最多循环 $N$ 次。
    *   **N 选一选择器（Best-of-N Selection, $sN$）**：主智能体生成 $N$ 个候选方案，评审者直接选出最佳方案。
    *   **N 选一评分器（Best-of-N Grading, $gN$）**：评审者对 $N$ 个候选方案进行打分并给出理由，选择得分最高者。
*   **量化指标（Helpfulness-Harmfulness）**：
    *   **益处（Helpfulness）**：反馈纠正了原先错误响应的比例。
    *   **害处（Harmfulness）**：反馈导致原先正确响应变错误的比例。
    *   **收益风险比（Benefit-to-Risk Ratio）**：益处与害处的比值。
*   **自动化提示词优化（APO）**：利用 GEPA（遗传-帕累托提示词演化）算法，通过观察评审者的判断失误，自动迭代和优化评审者的提示词。

### 3. 实验设计
*   **数据集/场景**：
    *   **BFCL (Berkeley Function-Calling Leaderboard)**：评估单轮、无状态的工具调用能力（包括简单、多重、并行及无关检测）。
    *   **$\tau^2$-Bench**：评估多轮、有状态的复杂场景（涵盖航空、零售、电信三个领域），需遵循特定领域策略。
*   **对比基准（Benchmark）**：以 GPT-4o 作为基础执行智能体（Baseline）。
*   **对比方法**：对比了不同评审模型（GPT-4o, o3-mini, GPT-5 mini）以及不同的协作机制（$rN, sN, gN$）。

### 4. 资源与算力
*   **算力说明**：论文未明确提及具体的 GPU 型号或训练时长。
*   **资源消耗**：由于该方法基于推理时反馈，主要消耗在于 API 调用。论文详细分析了延迟（Latency）开销：在单轮任务（BFCL）中，延迟增加了约 6.2 倍；在多轮任务（$\tau^2$-Bench）中，由于评审开销被多轮对话摊薄，延迟增加了约 2.4 倍。

### 5. 实验数量与充分性
*   **实验规模**：
    *   在 BFCL 上进行了上万次调用测试（Baseline $n=10,923$）。
    *   在 $\tau^2$-Bench 上进行了 834 个完整剧集的测试。
*   **充分性评价**：实验设计较为充分。不仅涵盖了单轮和多轮任务，还进行了消融实验（对比不同评审模型和提示词版本），并引入了自动优化算法（GEPA）来验证性能上限。通过“益处-害处”指标客观地揭示了引入评审者带来的正负面影响。

### 6. 主要结论与发现
*   **性能提升**：在 BFCL 无关检测上提升了 **5.5%**，在 $\tau^2$-Bench 多轮任务上平均提升了 **7.1%**。
*   **模型选择至关重要**：推理模型（如 o3-mini）作为评审者表现远优于标准模型，其收益风险比达到 **3:1**，而 GPT-4o 仅为 2.1:1。
*   **机制优劣**：渐进式反馈（Progressive Feedback）在处理复杂错误和无关检测方面优于“N 选一”方案。
*   **自动化优化的威力**：通过 GEPA 优化的提示词比人工编写的提示词在相关性任务上提升了 1.5%，无关检测提升了 2.8%。

### 7. 优点
*   **无需重训**：提供了一种即插即用的方案，无需重新训练基础模型即可提升性能。
*   **主动防御**：在执行前拦截错误，有效解决了破坏性操作后的状态恢复难题。
*   **量化严谨**：新提出的“益处-害处”指标为多智能体系统的评估提供了科学的度量衡。
*   **模块化强**：评审者可以独立于主智能体进行升级、优化或蒸馏。

### 8. 不足与局限
*   **延迟开销**：推理时的多次调用显著增加了响应时间，可能不适用于对实时性要求极高的场景。
*   **模型局限**：实验主要集中在 OpenAI 的闭源模型上，尚未在开源模型（如 Llama, Mistral）上验证泛化性。
*   **提示词敏感**：评审者容易出现“过度怀疑”（Over-skepticism）倾向，将正确的工具调用误判为不完整，需要精细的提示词工程或自动化优化来缓解。
*   **领域适配**：BFCL 优化的提示词直接迁移到 $\tau^2$-Bench 效果不佳，说明评审策略仍具有较强的领域依赖性。
