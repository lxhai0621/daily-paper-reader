## 摘要
长程智能体推理要求大语言模型在包含思考、工具调用、观察和部分结论的长时间交互历史中行动。挑战不仅在于这些历史会变得很长，还在于当前决策所需的信息可能分散在遥远的步骤中，并且只有在后期才变得相关。现有方法通过截断交互历史、将其压缩为较短的替代品，或检索选定部分进行重用来解决这一困难，但它们没有明确建模对过去交互的访问应如何适应智能体不断变化的状态。相反，我们将长程推理视为一个状态自适应记忆问题。为此，我们提出了状态自适应记忆（SAM），一个独立的框架，它将持续进行的交互整合为紧凑的记忆线索，同时保留原始轨迹页面用于意图驱动的回忆。这些线索并不被视为历史的替代品；相反，它们作为轻量级句柄，使智能体能够根据当前需求重建时间上遥远的信息，而无需重新训练基础模型。我们进一步通过专家引导的监督和强化学习优化记忆模块，使其与轨迹级别的实用性对齐。在BrowseComp、BrowseComp-ZH、WideSearch和HLE上，SAM在不同智能体骨干网络上持续优于强基线。我们的结果表明，显式记忆建模为长程智能体推理提供了一个简单而有效的基础。

## Abstract
Long-horizon agentic reasoning requires large language models to act over long interaction histories containing thoughts, tool calls, observations, and partial conclusions. The challenge is not merely that these histories grow long, but that information needed for the current decision may be scattered across distant steps and only become relevant later. Existing approaches address this difficulty by truncating the interaction history, compressing it into shorter surrogates, or retrieving selected parts of it for reuse, but they do not explicitly model how access to past interaction should adapt to the agent's evolving state. We instead cast long-horizon reasoning as a problem of state-adaptive memory. To this end, we propose State-Adaptive Memory~(SAM), a standalone framework that consolidates ongoing interaction into compact memory cues while preserving raw trajectory pages for intent-driven recall. These cues are not treated as replacements for history; rather, they serve as lightweight handles that allow the agent to reconstruct temporally distant information according to its current needs, without retraining the underlying backbone. We further optimize the memory module through expert-guided supervision and reinforcement learning, aligning it with trajectory-level utility. Across BrowseComp, BrowseComp-ZH, WideSearch, and HLE, SAM consistently outperforms strong baselines over diverse agent backbones. Our results suggest that explicit memory modeling provides a simple and effective foundation for long-horizon agentic reasoning.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：大语言模型（LLM）被越来越多地用作与外部环境进行长程交互的智能体。在长程推理任务中，智能体需要根据不断增长的交互历史（包含思考、工具调用、观察结果和部分结论）来持续收集证据、追踪进度并选择后续动作。
- **核心挑战**：交互历史不仅会变得很长，更关键的是当前决策所需的信息可能分散在遥远的历史步骤中，其重要性往往只在任务后期才显现。现有方法（如截断历史、压缩为摘要或检索部分内容）并未显式建模智能体状态如何动态地决定对过去信息的访问需求。
- **核心论点**：长程推理本质上是一个“状态自适应记忆”问题。智能体在任何时刻都需要一个连贯的视图，了解“已确立了什么”、“哪些已解决”、“接下来该追求什么”，但这些信息在原始轨迹中分散且隐式。因此，目标不是保留整个过去，而是让正确的过去信息在智能体当前状态需要时变得可恢复。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想：状态自适应记忆（SAM）
将交互历史重构为一个可导航的记忆空间，由两个耦合视图组成：
- **紧凑的记忆线索（Cues）**：作为轻量级句柄，保留在上下文中，指向原始页面。
- **原始轨迹页面（Pages）**：保存详细交互记录，存储在外部页面存储中。

### 关键技术细节

#### （1）基于页面的情节整合（Page-based Episodic Consolidation）
- 将轨迹按照令牌预算（默认32K tokens）划分为连续页面 `p_k`，每个页面保持推理、动作和反馈的局部连贯性。
- 记忆模型 `M_sum` 为每个页面生成紧凑记忆线索 `m_k`（内容如：建立了什么、排除了什么、未解决什么、日后可能重要的信息）。
- 原始页面从活动上下文中移除，线索保留在记忆库 `M_t` 中，原始页面存储在外部页面存储 `P_t` 中。
- 关键：线索不是不可逆压缩，而是作为页面句柄，必要时可恢复原始内容。

#### （2）智能体引导的线索选择（Agent-guided Cue Selection）
- 智能体观察任务、当前实时上下文和记忆库中的线索。
- 若需要额外过去信息，智能体发出回忆请求，包含意图 `q_t`，并从 `M_t` 中选择少量候选线索 `R_t`。
- 选择不由手工设计的检索分数决定，而是由智能体基于当前状态自主判断哪些早期页面值得重新访问。

#### （3）意图驱动的情节回忆（Intent-driven Episodic Recall）
- 根据选中的线索找到对应页面，记忆模型 `M_rec` 在回忆意图 `q_t` 条件下，顺序浏览这些页面，提取最相关信息，生成聚焦摘要 `ρ_t`。
- 注入到活动上下文中，形成最终上下文 `eC_t = [x; Clive_t; M_t; ρ_t]`（短程连续性 + 长程引导 + 重建的细节）。
- 回忆是状态条件重建，而非简单重放存储历史。

#### （4）优化过程（Optimization Process of SAM）
- **专家引导监督微调（SFT）**：使用前沿模型（Claude-4.5-Opus, GPT-5.4）作为专家，在域内查询上生成正确轨迹，提供整合和回忆的配对目标。在Qwen3.5-9B上微调，损失包括整合损失和回忆损失。
- **OAT-GRPO（Oracle-Anchored Tree GRPO）**：针对记忆模型的在线强化学习，超越标准GRPO：
  - **树结构结果奖励**：每次智能体调用记忆时，分支为b个样本（不同回忆输出），分支后由冻结推理器继续，递归扩展直到叶子节点得到二元结果。每个记忆动作节点的结果值为其子树中所有叶子结果的平均值。兄弟动作形成本地基线，实现记忆动作层面的GRPO。
  - **Oracle锚定的可恢复性奖励**：用三个前沿模型（GPT-5.4, GLM-4.7, DeepSeek-V4-Flash）的输出来近似目标空间，GPT-5.4作为评估者给候选人打分（0-10，重缩放至[0,1]），衡量相关性、覆盖度和一致性。
  - **组合奖励**：`R(a) = α*R_out(a) + (1-α)*(R_rec(a) - b_rec)`，α=0.3。在每对父上下文c内，兄弟动作形成组，计算优势并应用裁剪替代目标。

## 6. 主要结论与发现

1. **SAM是所有骨干上最强的上下文管理方法**：在四个基准的平均得分上，SAM远超最佳启发式基线（heuristic baseline），在BrowseComp和BrowseComp-ZH上领先幅度最大，说明其优势正好出现在启发式策略最弱的场景。
2. **同一个SAM模块跨基准和骨干泛化**：单次训练的Qwen3.5-9B记忆模型在所有骨干-基准组合上取得最佳成绩，启发式基线在不同基准上排名波动，证明SAM改进源自记忆机制本身，而非基准特化或骨干特化。
3. **SFT和OAT-GRPO两阶段互补**：移除任一阶段导致性能一致下降。
4. **意图驱动回忆是关键**：替代回忆方式（全局摘要、最近页面、原始内容）均不如全SAM，表明写时压缩不是主要增益来源，读时状态自适应重建才是。
5. **SAM在长程交互中扩大优势**：随着交互轮数增加（>80轮），SAM与摘要基线差距更明显。
6. **SAM对页面大小鲁棒**：在32K-64K最优化，但即便92K仍优于无管理基线（仅128K在BrowseComp上略差）。
7. **失败案例揭示边界**：当智能体过早锁定错误框架并基于该框架发起回忆查询时，SAM忠实地传递了错误前提下的信息，无法救助。这提示未来方向：联合优化智能体的回忆目标公式。

## 7. 优点

- **新颖的问题公式化**：将长程上下文管理重新定义为状态自适应记忆问题，区别于简单的截断或压缩。
- **分离智能体策略与记忆机制**：记忆模块独立于骨干，无需重新训练骨干即可跨模型迁移。
- **双视图设计（线索-页面）**：线索提供轻量级持久句柄，保留原始页面用于意图驱动重建，不同于不可逆压缩。
- **优化的完整性**：从专家监督SFT到OAT-GRPO，解决了延迟信用分配和稀疏奖励问题，尤其是树结构结果奖励和Oracle锚定可恢复性奖励的设计。
- **丰富的实验验证**：覆盖四个不同难度的长程基准，多个骨干，消融实验全面（训练阶段、回忆机制、页面大小、长程行为）。
- **开源性**：提供代码和训练检查点，可复现。
