## 摘要
自演化多智能体系统（MAS）已成为LLM智能体通过持续经验改进的有前景路径，其基础是持久化记忆。然而，现有设计几乎全部采用跨智能体共享的集中式存储库，这带来了通信与协调开销、隐私问题，并削弱了智能体多样性。我们提出DecentMem，一个去中心化记忆框架，其中每个智能体维护自己的双池记忆——一个由整合过去轨迹组成的利用池，以及一个由LLM生成的针对未见上下文的候选探索池。这两个池基于来自LLM作为评判者的阶段性反馈进行在线重新加权。理论上，我们证明了该设计保证了解决方案空间的全局可达性，并实现了$O(\log T)$的累积遗憾，匹配随机赌博机下限（常数项内）。在实践中，跨越三个MAS框架（AutoGen、DyLAN、AgentNet）、三个Qwen3骨干网络（4B/8B/14B）、两个Gemma4骨干网络（E2B/E4B）以及涵盖数学、代码、问答和具身任务的五个基准测试，DecentMem相比最强的集中式记忆基线平均准确率提升高达23.8%，相比无记忆基线提升高达52.5%，同时令牌使用量减少高达49%。

## Abstract
Self-evolving multi-agent systems (MAS) have emerged as a promising route to LLM agents that continually improve from experience, with persistent memory at their foundation. However, existing designs almost exclusively adopt a centralized repository shared across agents, incurring communication and coordination overhead, raising privacy concerns, and collapsing agent diversity. We propose DecentMem, a decentralized memory framework in which each agent maintains its own dual-pool memory -- an exploitation pool of consolidated past trajectories and an exploration pool of LLM-generated candidates for unseen contexts. The two pools are reweighted online based on stage-wise feedback from an LLM-as-a-judge. Theoretically, we prove that this design guarantees global reachability of the solution space and achieves $O(\log T)$ cumulative regret, matching the stochastic bandit lower bound up to constants. In practice, across three MAS frameworks (AutoGen, DyLAN, AgentNet), three Qwen3 backbones (4B/8B/14B), two Gemma4 backbones (E2B/E4B) and five benchmarks spanning math, code, QA, and embodied tasks, DecentMem improves average accuracy by up to 23.8% over the strongest centralized memory baseline and by up to 52.5% over the no-memory baseline, while reducing token usage by up to 49%.

- **研究动机**：现有基于 LLM 的多智能体系统（MAS）通过持久化记忆实现跨任务经验积累与自我进化。但主流设计几乎全部采用**集中式共享内存**——所有智能体读写同一个全局存储库（如 MetaGPT 的全局消息池、G-Memory 的层次化共享图），导致三大缺陷：① 智能体行为趋同，角色互补的专业化能力丧失（多样性崩溃）；② 通信与协调开销大；③ 隐私泄露风险高。
- **核心问题**：集中式记忆是否是 MAS 的默认最优设计方案？本文质疑这一默认假设，并提出去中心化记忆作为更优替代。
- **整体含义**：提出 DecentMem，首个**去中心化双池记忆框架**，每个智能体独立维护“利用池”和“探索池”，通过 LLM 评判者在线调整两池权重，既保留专业化多样性，又实现全局性搜索，在理论上保证了 O(log T) 的累积遗憾（最优 regret），并在多种框架、骨干模型和任务上显著优于集中式基线。

## 2. 方法论

- **核心思想**：将 MAS 的自我演化建模为每个智能体在其局部解空间图上的随机游走，利用池（E-pool）实现基于相似性的局部步进（利用历史成功轨迹），探索池（X-pool）通过 LLM 先验注入新的概率质量（探索未访问区域）。两池在线路由被建模为随机赌博机问题，使用 LLM 作为评判者对每个阶段的轨迹进行质量打分，并据此更新两池权重。

- **关键技术细节**：
  - **双池结构**：每个智能体 \( a_m \) 维护私有记忆 \( \mathcal{M}_m = \mathcal{M}_{m,\text{E-pool}} \cup \mathcal{M}_{m,\text{X-pool}} \)。E-pool 存储过去任务的完整协作轨迹（包括动作、推理过程和协调历史），X-pool 存储当前任务中 LLM 生成的候选记忆。
  - **在线路由**：在每个阶段，智能体以概率 \( \alpha = w_{\text{E-pool}} / (w_{\text{E-pool}} + w_{\text{X-pool}}) \) 选择 E-pool 进行相似性检索，否则选择 X-pool 生成新记忆。权重初始各为 1.0。
  - **反馈与更新**：执行后，LLM 评判者对每个阶段的质量打分（正确性、协调质量、中间连贯性、最终整合）。若阶段质量提升（\( \Delta t = 1 \)），则被使用的池权重增加，否则衰减。具体更新规则见公式 (6)(7)。
  - **整合**：任务完成后，所有 X-pool 记忆合并到 E-pool，并清空 X-pool。

- **理论分析**：
  - **全局可达性**：当 X-pool 始终活跃（\( w_{\text{X-pool}} > 0 \)），过渡矩阵 \( M_{m,\ell} = \alpha_{m,\ell} T_m + (1-\alpha_{m,\ell}) h_m \mathbf{1}^\top \) 严格正，对应马尔可夫链不可约且非周期，保证每个智能体在其子空间内全局可达（定理 1）。
  - **对数遗憾界**：将路由视为随机赌博机，期望收益函数严格凹且唯一最优 \( \alpha^* \in (0.5,1) \)。利用随机近似理论证明 \( \mathbb{E}[R(T)] = O(\log T) \)，匹配 \( \Omega(\log T) \) 下界，因此是阶最优的（定理 2）。

## 6. 主要结论与发现

- DecentMem **始终优于所有基线**：平均准确率比最强集中式基线（G-Memory）高 8.6%，比无记忆基线高 26.1%。最大提升出现在最小型骨干（Qwen3-4B+AgentNet）上，高达 52.5%。
- **去中心化优势随协调随机性增大而扩大**：从 AutoGen（+2.7%/1.7%）到 DyLAN（+9.2%/3.9%）到 AgentNet（+23.1%/6.8%）机制越随机，增益越大，验证了集中式记忆在随机协作中更易导致多样性崩溃。
- **自演化更快**：在 MBPP-Plus 上，DecentMem 比所有基线更快达到更高准确率，在 DyLAN 上收敛速度快约 2.5 倍。
- **更高效**：相比 G-Memory，令牌消耗平均减少 43%（在 BBH 上降低 32%~49%），同时准确率更高。
