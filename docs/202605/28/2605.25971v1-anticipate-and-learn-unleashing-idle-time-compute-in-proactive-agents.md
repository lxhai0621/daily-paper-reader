## 摘要
尽管AI代理在推理和工具使用方面展现出卓越能力，但它们本质上仍是被动的：仅在用户明确提示后才进行计算响应。这种范式忽略了一个关键机会：交互之间的空闲时间很大程度上被浪费，使得代理无法为未来的用户需求做好准备。为弥合这一差距，我们引入了ProAct，一种利用空闲时间计算来预测并满足未来用户可能需求的主动式代理架构。通过分析不断演变的对话历史及持久记忆，ProAct预测即将到来的需求并迭代获取信息，使代理能够在用户发起查询前解决知识缺口并准备证据。为严格评估主动能力，我们还引入了ProActEval，一个涵盖40个领域200个场景的综合基准，包含可预测的需求链和多样的用户认知概况。实证结果表明，与被动基线相比，ProAct具有显著优势。在ProActEval上，ProAct通过减少14.8%的必要交互轮次加速任务完成，降低11.7%的用户努力，并减少28.1%的幻觉率。此外，MemBench评估确认ProAct达到了最先进的反思精度，彰显其持续稳健的性能。

## Abstract
While AI agents demonstrate remarkable capabilities in reasoning and tool use, they remain fundamentally reactive: they compute responses only after explicit user prompts. This paradigm ignores a critical opportunity: the idle time between interactions is largely wasted, leaving agents unable to prepare for future user needs. To bridge this gap, we introduce ProAct, a proactive agent architecture that leverages idle-time compute to anticipate and fulfill likely upcoming user needs. By analyzing evolving dialogue history together with persistent memory, ProAct predicts upcoming needs and iteratively acquires information, allowing the agent to resolve knowledge gaps and prepare evidence before the user initiates a query.To rigorously evaluate proactive capabilities, we also introduce ProActEval, a comprehensive benchmark comprising 200 scenarios across 40 domains, featuring predictable need chains and diverse user cognitive profiles. Empirical results demonstrate significant advantages over reactive baselines. ProAct accelerates task completion by reducing required turns by 14.8%, decreases user effort by 11.7%, and cuts hallucination rates by 28.1% on ProActEval. Furthermore, MemBench evaluations confirm that ProAct achieves state-of-the-art reflective accuracy, underscoring its sustained and robust performance.

- **核心问题**：当前 AI 代理（如 ChatGPT、各类对话系统）本质上是**被动**的，仅在收到用户明确提示后才开始计算。交互之间的空闲时间完全被浪费，导致代理无法为用户的潜在未来需求预先做准备。
- **研究动机**：借鉴心理学中的“主动应对”（proactive coping）概念——即在需求完全显现之前就预期并积累资源。作者认为智能代理应利用空闲时间主动学习和准备，以提升后续交互效率和质量。
- **整体含义**：提出一种全新的人机协作范式——**主动代理**，将计算从请求时刻转移到离线空闲时段，从而使代理能够前瞻性地填补知识空白、准备证据，减少用户重复提问和等待时间。

### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心架构：ProAct**
  - 由两个紧密耦合的模块组成：**未来状态预测（Future-State Prediction）** 和 **空闲时间获取（Idle-Time Acquisition）**。
  - 结合**持久记忆**（用户画像、事实摘要、对话历史、已获制品），构成闭环：前台交互 → 更新记忆 → 预测未来需求 → 评估价值并获取证据 → 生成制品 → 决策推送/存储 → 更新记忆。
- **关键公式与过程**

  - **价值评分**：`S(z) = w_r r_z + w_g g_z + w_v v_z + w_τ τ_z`，其中 `r_z` 为用户相关性，`g_z` 为知识差距，`v_z` 为增量价值，`τ_z` 为时效性。仅 `S(z) ≥ θ_val` 的候选才触发在线搜索。
  - **获取与交付**：对入选候选进行迭代检索、证据提取、生成知识制品（含出处），然后通过效用感知推送门决定是立即推送、排队等待还是静默存储。推送条件：`PushScore = Value − Cost + 50 > 阈值`。
- **算法流程**（文字描述）：
  1. 每轮对话结束 → 更新记忆。
  2. 空闲窗口开始 → 预测模块生成候选需求（本地场景推断 + 相关扩展 + 记忆空白填充）。
  3. 过滤低置信度候选 → 去重 → 价值评分。
  4. 对高价值候选执行记忆感知的信息获取（先检内存、再局部搜索、最后分解子问题迭代检索）。
  5. 生成知识制品并记录出处。
  6. 根据推送评分决定交付模式。

### 3. 实验设计：数据集 / 场景、基准、对比方法
- **自有基准：ProActEval**
  - 包含 **200 个场景**，覆盖 **40 个领域**（如金融、医疗、教育、家政等）。
  - 每个场景包含一个虚构的事实清单（约 30 个原子事实）和一个有序的用户需求图（约 12 个需求，含可预测标记）。
  - 用户模拟器根据需求图与代理交互；代理不能看到需求图或评估元数据。
- **额外基准：MemBench**
  - 用于评估反思记忆精度（从对话历史推断用户偏好和情绪），测试规模为 10k 和 100k token。
- **对比方法**：
  - **Reactive**（无任何主动模块）
  - **Undirected Idle**（启用空闲获取但无预测方向）
  - **Directed Idle（ProAct）**（完整架构）
  - **ProactiveAgent**（基于 Lu et al. 2024 的决策协议改编，GPT-4o 骨干）
- **评估指标**：T80/T100（达到 80%/100% 必须需求覆盖所需的轮数）、User Effort（用户主动提问轮数）、Fact Accuracy、Hallucination Rate、Total Coverage、Must-Have Coverage、Anticipation Recall、Active Tokens。

### 5. 实验数量与充分性
- **主要实验组**：

### 6. 论文的主要结论与发现
- **ProAct 显著优于被动基线**：在 ProActEval 上，轮次减少 14.8%，用户努力降低 11.7%，幻觉率下降 28.1%。
- **预测方向是关键**：Undirected Idle（无预测方向）几乎无提升（T100 仅 -0.9%），而 Directed Idle 通过定向获取实现了 -14.1% 的进一步改善。Anticipation Recall 从 0 提升至 0.428。
- **ProAct 在 MemBench 上达到最高反思精度**：10k 时 84.3%，100k 时 86.3%，超越所有之前方法。
- **空闲计算需注意边际收益递减**：增大搜索预算 k 会提高 Anticipation Recall 但不会单调降低 T100/User Effort，且主动 token 成本持续上升。因此空闲计算是一个操作点权衡，而非越大越好。
- **与 ProactiveAgent 对比**：ProAct 的主动外推覆盖了 703/1572 个可预测需求（远高于后者的 32/1572），证明不仅需要主动行为，还需要覆盖正确的未来需求。
