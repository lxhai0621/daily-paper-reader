## 摘要
大语言模型（LLMs）往往由于模糊的人类查询与机器激活所需的结构化逻辑之间的分布不匹配，而无法利用其潜在的推理能力。现有的对齐方法要么通过单独微调每个模型而产生高昂的 $O(N)$ 成本，要么依赖于无法解决查询级结构复杂性的静态提示。在本文中，我们提出了 ReQueR（Reinforcement Query Refinement），这是一个将推理激发视为推理阶段对齐任务的模块化框架。我们通过强化学习训练一个专门的精炼器（Refiner）策略，将原始查询重写为显式的逻辑分解，并将冻结的 LLMs 视为环境。基于教育心理学中经典的“最近发展区”（Zone of Proximal Development）理论，我们引入了自适应求解器层级（Adaptive Solver Hierarchy），这是一种通过动态对齐环境难度与精炼器不断进化的能力来稳定训练的课程机制。ReQueR 在不同的架构和基准测试中获得了一致的 1.7%--7.2% 的绝对提升，平均优于强基准模型 2.1%。至关重要的是，它为“一对多”的推理阶段推理激发提供了一种极具前景的范式，使得在少量模型上训练的单个精炼器能够有效地解锁各种未见模型的推理能力。代码可在 https://github.com/newera-xiao/ReQueR 获取。

## Abstract
Large Language Models (LLMs) often fail to utilize their latent reasoning capabilities due to a distributional mismatch between ambiguous human inquiries and the structured logic required for machine activation. Existing alignment methods either incur prohibitive $O(N)$ costs by fine-tuning each model individually or rely on static prompts that fail to resolve query-level structural complexity. In this paper, we propose ReQueR (\textbf{Re}inforcement \textbf{Que}ry \textbf{R}efinement), a modular framework that treats reasoning elicitation as an inference-time alignment task. We train a specialized Refiner policy via Reinforcement Learning to rewrite raw queries into explicit logical decompositions, treating frozen LLMs as the environment. Rooted in the classical Zone of Proximal Development from educational psychology, we introduce the Adaptive Solver Hierarchy, a curriculum mechanism that stabilizes training by dynamically aligning environmental difficulty with the Refiner's evolving competence. ReQueR yields consistent absolute gains of 1.7\%--7.2\% across diverse architectures and benchmarks, outperforming strong baselines by 2.1\% on average. Crucially, it provides a promising paradigm for one-to-many inference-time reasoning elicitation, enabling a single Refiner trained on a small set of models to effectively unlock reasoning in diverse unseen models. Code is available at https://github.com/newera-xiao/ReQueR.

### 论文总结：One Refiner to Unlock Them All

#### 1. 核心问题与整体含义（研究动机和背景）
论文指出，大语言模型（LLMs）虽然拥有强大的潜在推理能力，但往往因为人类查询的**模糊性**与机器激活所需的**结构化逻辑**之间存在“分布不匹配”而无法充分发挥。
*   **现有挑战**：传统的对齐方法（如 SFT 或 RLVR）需要对每个模型进行独立微调，复杂度为 $O(N)$，且不适用于闭源模型；而静态提示词工程（Prompt Engineering）又难以处理复杂的查询重写。
*   **核心目标**：提出一种**推理阶段（Inference-time）**的对齐范式，通过训练一个通用的“精炼器”（Refiner），将原始查询转化为能激发模型推理潜能的结构化逻辑，实现“一个精炼器解锁多个模型”的 $O(1)$ 扩展能力。

#### 2. 方法论：核心思想与关键技术
论文提出了 **ReQueR (Reinforcement Query Refinement)** 框架，其核心是将查询精炼视为一个强化学习任务：
*   **Refiner 策略**：训练一个轻量级模型（如 Qwen3-4B）作为 Refiner，将原始输入 $x$ 重写为逻辑显式、去噪后的 $x'$。
*   **自适应求解器层级 (ASH)**：借鉴教育心理学的“最近发展区（ZPD）”理论。训练时，Refiner 面对的是一组能力不同的冻结求解器（Solvers）。ASH 会根据 Refiner 当前的表现动态调整 Solver 的难度：如果 Refiner 连续失败，则换用更强的 Solver 提供反馈；如果任务变得太简单，则换用较弱的 Solver 以施加“结构化压力”。
*   **奖励函数设计**：
    *   **准确性奖励 ($R_{acc}$)**：基于 Solver 最终答案的正确性。
    *   **泄漏惩罚 ($R_{leak}$)**：为防止 Refiner 直接在重写中泄露答案（Reward Hacking），引入基于**困惑度（Perplexity, PPL）**的约束。如果重写后答案的预测难度大幅下降，则判定为泄露并扣分。
*   **训练流程**：先进行少量的监督热身（SFT），随后使用 **GRPO（组相对策略优化）** 算法进行大规模在线强化学习。

#### 3. 实验设计
*   **数据集**：
    *   **训练**：GSM8K、MATH、OpenHermes-2.5。
    *   **评估**：涵盖数学推理（GSM-Symbolic, MATH-500, OlympiadBench, Omni-MATH, AMC23）和通用推理（MMLU-Pro, GPQA-Diamond）。
*   **Benchmark 与对比方法**：
    *   对比了 **Zero-shot CoT**、**Re2**（重读）、**RaR**（重述）、**TextGrad**（基于梯度的提示优化）和 **GEPA**（基于遗传算法的进化）。
*   **模型覆盖**：Refiner 为 Qwen3-4B；测试了包括 Llama-3.1/3.2 (3B-70B)、Qwen2.5/3 (0.6B-72B)、Mixtral-8x7B 和 DeepSeek-MoE 等多种架构。

*   **算力设备**：实验使用了由 **8 台 NVIDIA H100 GPU** 组成的集群。
*   **分配方式**：4 张显卡用于 Actor/Refiner 的梯度更新，另外 4 张用于并行推理（Solvers 和 PPL 计算）。
*   **训练细节**：强化学习阶段训练了 6 个 Epoch，Batch Size 为 64。

#### 5. 实验数量与充分性
论文的实验设计非常充分且具有说服力：
*   **跨模型迁移实验**：验证了在小模型上训练的 Refiner 能有效提升从未见过的超大规模模型（如 70B, 72B）的性能。
*   **消融实验**：分别验证了 SFT 热身、RL 阶段、ASH 机制以及泄漏惩罚对最终效果的贡献。
*   **定性分析**：总结了 Refiner 自动习得的 7 种精炼策略（如符号参数化、上下文去噪、逻辑歧义消除等）。
*   **鲁棒性测试**：在不同难度、不同领域的基准测试上均表现出一致的增益，证明了方法的普适性。

#### 6. 主要结论与发现
*   **性能提升**：ReQueR 在各基准上实现了 1.7% 至 7.2% 的绝对增益，平均超越最强基准 2.1%。
*   **一对多泛化**：单个 Refiner 展现了极强的跨架构迁移能力，能够“向下”兼容小模型，“向上”激发大模型。
*   **效率优化**：虽然增加了精炼步骤，但由于精炼后的查询逻辑更清晰，Solver 生成的推理链条长度反而缩短了 4.8%--17.3%，部分抵消了推理延迟。
*   **ASH 的必要性**：动态调整环境难度是防止奖励稀疏和模型过拟合的关键。

#### 7. 优点
*   **范式创新**：将对齐压力从模型参数转移到输入端，实现了 $O(1)$ 的对齐效率。
*   **动态课程学习**：ASH 机制巧妙解决了强化学习中常见的奖励稀疏问题。
*   **防作弊机制**：利用 PPL 变化检测答案泄露，比传统的 LLM 裁判更高效且客观。
*   **即插即用**：无需修改下游模型参数，非常适合闭源 API 或频繁更换模型的 Agent 系统。

#### 8. 不足与局限
*   **推理延迟**：尽管 Solver 生成变快，但 Refiner 本身仍需一次额外的生成过程，增加了首字延迟。
*   **误差传递**：如果 Refiner 在重写时产生幻觉或逻辑错误，会直接误导下游 Solver。
*   **任务限制**：目前主要集中在有客观标准答案的推理任务（Verifiable Rewards），对于开放式创作或主观评价任务的适用性尚待研究。
*   **能力上限**：Refiner 只能激发模型“固有”的潜能，无法让模型学会其预训练阶段完全未掌握的知识。
