## 摘要
百万级 Token 规模的长文本理解（LTU）需要在推理保真度与计算效率之间取得平衡。前沿的长上下文大语言模型（LLM）可以端到端地处理数百万 Token 的上下文，但面临着高 Token 消耗和注意力稀释的问题。与此同时，专门的 LTU 智能体通常通过图构建或索引等与任务无关的抽象方式来牺牲保真度。我们发现了 LTU 的一个关键洞察：相对于全文，与查询相关的信息通常是稀疏的，因此有效的推理应依赖于查询充分的子集，而非整个上下文。为此，我们提出了 SCOUT，这是一种 LTU 的新范式，从被动处理转向主动信息觅食。它将文档视为一个可探索的环境，并基于一个紧凑的、有出处依据的认知状态进行回答。在状态级差距诊断的引导下，SCOUT 在由粗到细的探索与锚定状态更新之间自适应地交替，从而将其认知状态逐步收缩至满足查询充分性。实验表明，SCOUT 在达到最先进专有模型性能的同时，将 Token 消耗降低了高达 8 倍。此外，随着上下文长度的增加，SCOUT 依然保持稳定，显著缓解了实际应用中的性价比权衡问题。

## Abstract
Long-Text Understanding (LTU) at million-token scale requires balancing reasoning fidelity with computational efficiency. Frontier long-context LLMs can process millions of token contexts end-to-end, but they suffer from high token consumption and attention dilution. In parallel, specialized LTU agents often sacrifice fidelity through task-agnostic abstractions like graph construction or indexing. We identify a key insight for LTU: query-relevant information is typically sparse relative to the full document, so effective reasoning should rely on a query-sufficient subset rather than the entire context. To address this, we propose SCOUT, a new paradigm for LTU that shifts from passive processing to active information foraging. It treats the document as an explorable environment and answers from a compact, provenance-grounded epistemic state. Guided by state-level gap diagnosis, SCOUT adaptively alternates between coarse-to-fine exploration and anchored state updates that progressively contract its epistemic state toward query sufficiency. Experiments show that SCOUT matches state-of-the-art proprietary models while reducing token consumption by up to 8x. Moreover, SCOUT remains stable as context length scales, substantially alleviating the practical cost-performance trade-off.

论文针对**百万级 Token 规模的长文本理解（LTU）**提出了挑战。当前主流方法面临“长文本三难困境”（LTU Trilemma）：难以同时满足**极端可扩展性**（处理百万级输入）、**高保真度**（不丢失细节）和**推理效率**（低 Token 成本）。
*   **研究动机**：现有模型要么暴力输入全文（导致注意力稀释且极其昂贵），要么采用任务无关的预处理（如 RAG 或图索引，容易在构建阶段丢失查询相关的关键细节）。
*   **核心洞察**：论文基于“信息稀疏性假设”，即回答特定问题所需的信息仅占全文极小比例。因此，应将长文本视为可探索的“环境”，让智能体通过“主动觅食”而非“被动接收”来获取信息。

#### 2. 方法论：核心思想与技术细节
SCOUT（Strategic Context Observation for Understanding Text）引入了一种全新的主动信息觅食范式：
*   **状态解耦（State Decoupling）**：这是 SCOUT 的核心。它将智能体的状态分为两部分：
    1.  **交互历史 ($H_t$)**：记录探索过程（做了什么、看到了什么），仅用于引导后续搜索，不参与最终推理，从而避免噪声干扰。
    2.  **认知状态 ($E_t$)**：仅存储与查询相关的、经过验证的知识单元。每个单元都包含**原子事实**和**出处锚点**（Provenance Anchor，如行号或偏移量），确保高保真度和可追溯性。
*   **动作空间设计**：
    *   **觅食动作 ($A_{forage}$)**：包括 `Grep`（关键词搜索）、`Scan`（结构化扫描）、`Read`（局部精读）等。
    *   **状态管理动作 ($A_{state}$)**：包括 `Update`（将新发现存入认知状态）和 `Evaluate`（诊断当前认知状态与回答问题所需信息之间的差距）。
*   **差距诊断驱动的收敛**：通过 `Evaluate` 动作不断识别“还缺少什么信息”，引导智能体精准地在百万级文本中定位缺失证据，直到认知状态足以回答问题。

#### 6. 主要结论与发现
*   **高效性**：SCOUT 在性能匹配甚至超越 Gemini-3-Pro 等顶尖模型的同时，**Token 消耗降低了高达 8 倍**。
*   **稳定性**：随着上下文长度从 64K 扩展到 1M+，SCOUT 的精度和成本几乎保持恒定，而传统 LLM 的成本呈指数级增长且精度大幅下滑。
*   **开源模型赋能**：通过 SCOUT 框架和针对性的强化学习（DAPO），较弱的开源模型（如 Qwen2.5-72B）在长文本任务上的表现能显著提升，甚至逼近闭源模型。

#### 7. 优点
*   **范式突破**：成功将长文本理解从“计算密集型”转变为“搜索-推理型”，解决了注意力稀释问题。
*   **可解释性与可靠性**：认知状态中的出处锚点强制模型基于原文证据推理，极大地降低了长文本中的幻觉风险。
*   **极佳的性价比**：为企业处理超大规模文档提供了一种低成本、高精度的可行方案。

#### 8. 不足与局限
*   **端到端延迟**：由于需要多轮交互，SCOUT 的**墙钟时间（Wall-clock latency）**高于单次推理的传统模型。
*   **跨查询复用**：目前 SCOUT 针对每个查询独立探索，如果对同一文档有多个查询，无法复用已建立的认知状态（索引类方法在此场景下更有优势）。
*   **信息密集型任务**：在信息极度密集的场景（如整本书的全文总结）中，主动觅食的优势可能不如在信息稀疏场景中明显。
