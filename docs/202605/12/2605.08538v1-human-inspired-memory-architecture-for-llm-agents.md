## 摘要
当前的 LLM 智能体在长交互周期内缺乏管理持久记忆的原则性机制。我们提出了一种基于生物学原理的记忆架构，包含六种认知机制：(1) 睡眠阶段巩固，(2) 基于干扰的遗忘，(3) 记忆印迹成熟，(4) 检索时的再巩固，(5) 实体知识图谱，以及 (6) 混合多线索检索。每种机制都针对原始记忆累积的特定失效模式。我们引入了一种合成校准方法，在不接触基准数据的情况下推导所有流水线阈值，从而消除了评估泄漏的一个常见来源。我们在两个基准测试上进行了评估。首先是一个 VSCode 问题追踪数据集（1.3 万个问题，12 万个事件），其中基于去重的巩固实现了 97.2% 的保留精度，同时减少了 58% 的存储空间（比基准线高出 21.8 个百分点）。其次是 LongMemEval 个人聊天基准测试，我们在此进行了首次流式 M 级评估（475 个会话，约 54 万个唯一轮次）。在 20 万 token 的上下文预算下，我们的流水线与原始检索准确率相当（70.1% 对 71.2%，95% 置信区间重叠），同时提供了一条可调节的准确率/存储大小运行曲线。在 S 级规模（50 个会话）下，基于去重的巩固使偏好召回率提升了 13.3 个百分点。

## Abstract
Current LLM agents lack principled mechanisms for managing persistent memory across long interaction horizons. We present a biologically-grounded memory architecture comprising six cognitive mechanisms: (1) sleep-phase consolidation, (2) interference-based forgetting, (3) engram maturation, (4) reconsolidation upon retrieval, (5) entity knowledge graphs, and (6) hybrid multi-cue retrieval. Each mechanism addresses a specific failure mode of naive memory accumulation. We introduce a synthetic calibration methodology that derives all pipeline thresholds without benchmark data exposure, eliminating a common source of evaluation leakage. We evaluate on two benchmarks. First, a VSCode issue-tracking dataset (13K issues, 120K events) where deduplication-based consolidation achieves 97.2% retention precision with 58% store reduction (+21.8 pp over baseline). Second, the LongMemEval personal-chat benchmark where we conduct the first streaming M-tier evaluation (475 sessions, ~540K unique turns). At a 200K-token context budget, our pipeline matches raw retrieval accuracy (70.1% vs. 71.2%, overlapping 95% CI) while exposing a tunable accuracy/store-size operating curve. At S-tier scale (50 sessions), dedup-based consolidation yields a +13.3 pp improvement in preference recall.

#### 1. 核心问题与研究动机
*   **核心问题**：当前的 LLM 智能体在长周期交互中缺乏有效的持久化、自适应记忆管理机制。
*   **研究背景**：
    *   **无状态智能体**：每次交互独立，丢失上下文。
    *   **长上下文窗口**：虽然容量增加，但成本随之飙升，且缺乏优先级排序和遗忘机制。
    *   **传统 RAG (向量数据库)**：将所有信息等同对待，缺乏巩固、遗忘和随时间演进的能力。
*   **动机**：借鉴人类神经科学原理，构建一个能够自动巩固重要信息、过滤冗余、并随时间演进的记忆系统，以支持企业级长时交互任务。

#### 2. 方法论：核心思想与关键技术
该架构模拟了人类大脑的六种认知机制，将记忆分为短期（热缓存）、中期（情节存储）和长期（知识图谱）三层：
*   **睡眠阶段巩固 (Consolidation)**：离线批处理机制，通过重要性评分（基于新颖性、频率、实体显著性等）对记忆进行去重、合并和提升。
*   **基于干扰的遗忘 (Forgetting)**：结合 Ebbinghaus 遗忘曲线（指数衰减）和检索干扰理论，主动删除低价值或高干扰的记忆，并实施“优雅降级”（从全文到摘要再到墓碑记录）。
*   **记忆印迹成熟 (Maturation)**：新记忆最初处于“沉默”状态，通过 Sigmoid 函数随时间增加激活强度，确保只有稳定的知识进入长期语义层。
*   **检索时的再巩固 (Reconsolidation)**：检索到的记忆进入不稳定状态，允许根据新信息进行更新或修正矛盾。
*   **实体知识图谱与混合检索**：结合向量相似度（情节检索）和图遍历（语义检索），实现多线索召回。
*   **合成校准 (Synthetic Calibration)**：**关键创新点**。利用 LLM 生成的合成语料库预先设定所有系统阈值（如相似度、重要性权重），完全不接触测试基准数据，从而消除评估泄露风险。

#### 5. 实验数量与充分性
*   **实验规模**：进行了 9 种配置的消融研究，并使用了 10,000 次重采样的 Bootstrap 方法计算 95% 置信区间（CI）。
*   **充分性**：实验覆盖了从短周期（S-tier）到极长周期（M-tier）的跨度，且在 VSCode 真实工业数据上进行了验证。
*   **客观性**：通过合成校准方法避免了参数微调带来的偏差，评估过程具有较高的客观性和统计严谨性。

#### 6. 主要结论与发现
*   **存储效率与精度**：在 VSCode 任务中，该架构在减少 58% 存储空间的同时，实现了 97.2% 的保留精度（比基准高 21.8%）。
*   **性能持平与优化**：在 LongMemEval M 级测试中，在 20 万 token 预算下，该流水线达到了与原始 RAG 相当的准确率（70.1% vs 71.2%），并提供了可调的准确率/存储平衡曲线。

*   **巩固策略**：实验证明“去重”比“摘要合并”更有效，后者容易丢失事实细节。

#### 7. 优点
*   **理论扎实**：将神经科学理论（如互补学习系统、印迹成熟）成功转化为可落地的工程架构。
*   **防泄露设计**：合成校准方法为 LLM 系统的参数调优提供了更公平的范式。
*   **流式评估**：比传统的静态批处理评估更贴近智能体的实际使用场景。
*   **自调节能力**：记忆库大小能自动稳定在一定范围内，不随输入量无限增长。

*   **机制隔离不足**：由于基准测试设计的限制（如缺乏跨会话矛盾），“成熟”和“再巩固”两种机制的独立贡献在实验中未能被充分区分。
