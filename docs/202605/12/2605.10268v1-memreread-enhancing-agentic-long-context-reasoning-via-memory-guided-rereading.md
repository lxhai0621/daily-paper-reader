## 摘要
为了在不产生标准注意力机制二次复杂度的情况下处理长上下文推理任务，基于智能体记忆的方法应运而生，这些方法通常在处理文档块时维护一个动态更新的记忆。为了减轻这种“边读边记”范式中潜在的证据丢失，最近的研究集成了检索模块，允许智能体召回在记忆覆盖过程中先前丢弃的信息。然而，基于检索的召回既受限于记忆形成过程中的证据丢失，也受限于无效查询引起的干扰。为了克服这些局限性，我们提出了 MemReread。MemReread 基于流式阅读，规避了中间检索。当最终记忆不足时，它会触发问题分解和重读，从而恢复被过早丢弃的间接事实。这种设计在支持非线性推理的同时，保留了文档理解中固有的逻辑流。为了进一步增强实用性，我们引入了一个强化学习框架，该框架在增强长度外推能力的同时，根据任务复杂度动态确定重读次数，从而灵活控制计算开销。大量实验表明，MemReread 在长上下文推理任务上始终优于基准框架，同时保持了相对于上下文长度的线性时间复杂度。

## Abstract
To tackle long-context reasoning tasks without the quadratic complexity of standard attention mechanisms, approaches based on agent memory have emerged, which typically maintain a dynamically updated memory when linearly processing document chunks. To mitigate the potential loss of latent evidence in this memorize-while-reading paradigm, recent works have integrated retrieval modules that allow agents to recall information previously discarded during memory overwriting. However, retrieval-based recall suffers from both evidence loss during memory formation and interference induced by invalid queries. To overcome these limitations, we propose MemReread. Built upon streaming reading, MemReread circumvents intermediate retrieval. It triggers question decomposition and rereading when the final memory is insufficient, enabling the recovery of indirect facts that were prematurely discarded. This design supports non-linear reasoning while preserving the inherent logical flow of document comprehension. To further enhance practicality, we introduce a reinforcement learning framework that enhances length extrapolation capability while dynamically determining the number of rereading passes based on task complexity, thereby flexibly controlling computational overhead. Extensive experiments demonstrate that MemReread consistently outperforms baseline frameworks on long-context reasoning tasks, while maintaining linear time complexity with respect to context length.

这篇论文介绍了一种名为 **MemReread** 的新型长文本推理框架，旨在解决大语言模型（LLM）智能体在处理超长上下文时面临的信息丢失和检索干扰问题。以下是对该论文的结构化总结：

### 1. 核心问题与研究动机
*   **研究背景**：标准注意力机制具有二次复杂度，难以处理超长文本。现有的“流式记忆智能体”（Streaming Memory Agents）通过分块处理和动态更新记忆来实现线性复杂度，但存在两大缺陷：
    *   **永久性潜在证据丢失**：某些事实在阅读早期看似无关（潜在证据），只有结合后期出现的“桥接事实”才显现其重要性。在单次流式阅读中，这些早期事实往往被记忆覆盖机制永久丢弃。
    *   **无效查询的干扰**：现有的检索增强型智能体在阅读过程中不断生成查询，但无法区分缺失信息是已被覆盖还是尚未读到，导致产生大量无效检索，引入噪声并稀释关键信号。
*   **核心问题**：如何在保持线性计算复杂度的前提下，有效恢复长文本中被丢弃的关键证据并减少推理干扰？

### 2. 方法论：MemReread 框架
MemReread 的核心思想是将“阅读”与“推理”解耦，通过**记忆引导的重读机制**取代中间检索。
*   **工作流程（四个阶段）**：
    1.  **阅读（Read）**：采用流式阅读范式，将文档分块处理，维护一个固定大小的记忆缓冲区，生成最终记忆。
    2.  **分解（Decompose）**：智能体判断最终记忆是否足以回答问题。若不足，则根据现有记忆分解出最高优先级的子问题。
    3.  **集成（Integrate）**：针对子问题进行定向重读（Rereading），获取子答案后，仅将“问题-答案对”更新至根记忆中，丢弃中间子记忆以节省空间。
    4.  **回答（Answer）**：重复上述过程直到记忆充足，最后基于最终记忆生成答案。
*   **关键技术：重读自适应 GRPO（ReA-GRPO）**：
    *   这是一种强化学习策略，旨在优化重读次数。
    *   **逻辑**：对于回答正确的样本，奖励重读次数较少的路径（鼓励简洁）；对于回答错误的样本，奖励重读次数较多的路径（鼓励深入探索）。这使得模型能根据任务复杂度动态调整计算开销。

### 3. 实验设计
*   **数据集**：
    *   **诊断任务**：自研 Global Reasoning Task（包含统计和变量跟踪），专门模拟非线性推理场景。
    *   **主流基准**：HotpotQA（分布内）、2WikiMultiHopQA（分布外/OOD）、RULER-QA、LongBench-E-QA、LongBench-v2。
*   **对比方法（Baselines）**：
    *   **MemAgent**：纯流式记忆智能体。
    *   **ReMemR1**：检索增强型流式记忆智能体。
    *   **原生 LLM**：如 Qwen3-4B/7B 及其 CoT 版本。
    *   **其他**：CDT（上下文去噪微调）、InfMem（块检索方法）。

*   **算力消耗**：

    *   **评估**：使用 4 张 A800。
*   **配置**：分块大小设为 5K tokens，最大重读次数 $p_c$ 通常设为 3。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 8K 到 1M tokens 的多种长度测试，并在 1.7B、4B、7B 乃至 1000B+（通过 API）等多个模型参数规模上进行了验证。
*   **充分性**：
    *   进行了**消融实验**，验证了重读次数 $p_c$ 对性能的影响。
    *   对比了不同强化学习算法（Vanilla vs GRPO vs ReA-GRPO）的有效性。
    *   进行了**零样本（Zero-shot）扩展性测试**，验证了方法在 GPT-4、Gemini 等闭源模型上的通用性。
    *   实验设计考虑了统计显著性（Paired t-test），结果具有客观性。

### 6. 主要结论与发现
*   **性能领先**：MemReread 在所有基准测试中均优于 MemAgent 和 ReMemR1，尤其在分布外（OOD）任务上提升显著（4B 模型在 2Wiki 上提升达 12.1%）。
*   **线性复杂度**：尽管引入了重读，但时间复杂度仍为 $O(p_c n)$（$p_c$ 为常数上限），空间复杂度保持恒定，优于随长度线性增加存储开销的检索方法。
*   **任务自适应**：通过 ReA-GRPO 训练后，模型能对简单任务（如 RULER）自动减少重读，对复杂任务增加重读，实现了精度与效率的平衡。

### 7. 优点与亮点
*   **非线性推理能力**：通过“分解-重读”机制，有效解决了流式处理中“先验知识缺失”导致的证据丢失问题。
*   **低干扰性**：摒弃了频繁的中间检索，避免了无效查询带来的噪声污染。
*   **工程可行性**：空间开销极低，不需要存储海量的历史块向量或原始文本，适合资源受限的场景。
*   **通用性强**：不仅适用于微调模型，在零样本场景下对多种开源和闭源模型均有提升。

### 8. 不足与局限
*   **推理延迟**：重读机制不可避免地增加了推理时间（约为 MemAgent 的 3-4 倍），在对实时性要求极高的场景下存在限制。
*   **依赖基础模型能力**：失败案例分析显示，若基础模型本身的逻辑推理或信息集成能力（Integration）较弱，重读也无法挽回错误。
*   **任务覆盖面**：目前主要集中在 QA 和推理任务，尚未在代码理解、长文本摘要或长文本生成等其他领域进行广泛验证。
