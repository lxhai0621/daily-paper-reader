## 摘要
多模态虚假信息越来越多地利用视觉说服力，通过重新利用或篡改的图像来增强误导性文本。我们推出了 RW-Post，这是一个针对真实世界多模态事实核查的帖子对齐文本-图像基准测试，具有可审计的标注：每个实例都将原始社交媒体帖子与推理轨迹以及明确链接的证据项相关联，这些证据项是通过大语言模型（LLM）辅助的提取与审计流水线从人工事实核查文章中获取的。RW-Post 支持在闭卷、证据受限和开放网络模式下的受控评估，从而能够对视觉接地（visual grounding）和证据利用进行系统性诊断。我们提供了 AgentFact 作为参考验证基准，并在统一协议下对强大的开源大型视觉语言模型（LVLM）进行了基准测试。实验表明仍有巨大的提升空间：当前模型在忠实的证据接地方面表现挣扎，而证据受限的评估则提高了准确性和忠实度。代码和数据集将在 https://github.com/xudanni0927/AgentFact 发布。

## Abstract
Multimodal misinformation increasingly leverages visual persuasion, where repurposed or manipulated images strengthen misleading text. We introduce \textbf{RW-Post}, a post-aligned \textbf{text--image benchmark} for real-world multimodal fact-checking with \emph{auditable} annotations: each instance links the original social-media post with reasoning traces and explicitly linked evidence items derived from human fact-check articles via an LLM-assisted extraction-and-auditing pipeline. RW-Post supports controlled evaluation across closed-book, evidence-bounded, and open-web regimes, enabling systematic diagnosis of visual grounding and evidence utilization. We provide \textbf{AgentFact} as a reference verification baseline and benchmark strong open-source LVLMs under unified protocols. Experiments show substantial headroom: current models struggle with faithful evidence grounding, while evidence-bounded evaluation improves both accuracy and faithfulness. Code and dataset will be released at https://github.com/xudanni0927/AgentFact.

### 1. 核心问题与整体含义（研究动机和背景）
随着生成式 AI 的发展，多模态虚假信息（文字+图像/视频）在社交媒体上泛滥。现有的多模态事实核查研究存在以下痛点：
*   **缺乏原始语境**：许多数据集仅包含孤立的断言，丢失了社交媒体帖子中的关键上下文。
*   **缺乏可审计性**：现有系统往往只给出真假判断，缺乏从证据到推理过程的明确链接。
*   **证据利用浅层化**：模型往往依赖内部知识或简单的检索，无法实现深度、忠实于来源的证据接地（Grounding）。
**研究目标**：构建一个包含真实社交媒体帖子、结构化推理轨迹和显式证据链接的基准测试集（RW-Post），并提出一个参考验证框架（AgentFact）。

### 2. 论文提出的方法论
#### A. RW-Post 基准构建
*   **数据来源**：从 Snopes 采集了 13,000 篇事实核查文章，经过严格过滤（如去除过短/过长文章、小图、带水印图）。
*   **LLM 辅助提取流水线**：利用 GPT-4o 将 HTML 文章转换为“带标签 URL 的文本”格式，提取出：
    1.  **原始帖子**（文字+图像）。
    2.  **推理轨迹**（逻辑步骤与关键点）。
    3.  **显式证据链接**（每个推理点对应具体的证据 ID 和 URL）。
*   **三种评估模式**：
    1.  **闭卷（Closed-book）**：仅提供帖子内容。
    2.  **证据受限（Evidence-bounded）**：提供帖子及数据集中标注的“金标准”证据。
    3.  **开放网络（Open-web）**：允许模型通过搜索引擎自行检索证据。

#### B. AgentFact 验证框架
这是一个基于多智能体协作的模块化流水线，包含五个核心智能体：
1.  **策略规划智能体 (Agent-SP)**：制定核查计划和搜索列表。
2.  **文本检索与验证智能体 (Agent-TR)**：执行搜索并评估来源可靠性。
3.  **图像检索与分析智能体 (Agent-IR)**：通过反向搜索检测视觉篡改、图文不符（Miscaption）及 Deepfake。
4.  **推理智能体 (Agent-R)**：结合证据执行分步推理。
5.  **解释生成智能体 (Agent-EG)**：生成带有证据引用的最终报告。

### 6. 论文的主要结论与发现
*   **证据是关键**：引入外部证据能显著提升所有模型的表现（如 GPT-4o-mini 的 Weighted-F1 从 25.4 提升至 85.1）。
*   **视觉接地困难**：令人意外的是，在提供证据的情况下，加入图像（T+E vs T+I+E）反而可能导致性能下降，表明现有 LVLM 难以有效整合视觉信号与复杂文本证据。
*   **开源模型差距大**：开源 LVLM 在证据利用和格式遵循率（FSR）上远落后于闭源模型（如 GPT-4o-mini）。
*   **证伪比证实难**：模型在处理“False”类别的召回率普遍低于“True”，且在处理“证据不足（Unproven）”的情况时表现不稳定。

### 7. 优点
*   **可审计性强**：RW-Post 不仅提供标签，还提供了“推理-证据”的显式对齐，这在现有数据集中非常罕见。
*   **真实场景对齐**：保留了原始社交媒体帖子的上下文，比单纯的断言核查更贴近现实。
*   **评估维度全面**：通过三种模式（闭卷/受限/开放）系统地诊断了模型在不同环节的瓶颈。

### 8. 不足与局限
*   **人工评估样本量较小**：仅对 40 个样本进行了深度人工评估，可能存在一定的统计偏差。
*   **数据源单一**：主要依赖 Snopes 网站，可能存在特定的编辑风格偏见。
*   **视觉分析局限**：目前的 AgentFact 在处理视频证据方面仍有提升空间，且对复杂视觉语义的理解仍显薄弱（如 Case Study 所示的“弱上下文接地”问题）。
*   **语言限制**：目前主要集中在英文环境。
