## 摘要
多智能体辩论（MAD）系统日益依赖共享内存来支持长程推理，但这种便利性也带来了一个关键漏洞：单个损坏的条目可能会污染下游的内存增强推理，而仅靠辩论本身无法过滤此类错误。现有的保护措施通过启发式方法或基于大语言模型（LLM）的验证来过滤条目，但它们依赖于具有相同失败模式的 AI 判断，并忽视了 MAD 中的跨智能体动态。我们通过将 MAD 中的内存更新建模为一个零信任内存博弈来填补这一空白，在该博弈中，不假设任何智能体是诚实的，博弈的均衡状态作为最优内存信任的指标。在该均衡的指导下，我们提出了 EquiMem，这是一种推理时校准机制，它根据共享内存状态对每次更新进行算法量化，使用智能体现有的检索查询和遍历路径作为证据，而不是征求任何 LLM 的判断。EquiMem 实现了针对嵌入式和基于图的内存的校准，在不同的基准测试、MAD 框架和内存架构中，它始终优于现有的保护措施，在对抗性智能体下保持鲁棒，且推理开销微乎其微。

## Abstract
Multi-agent debate (MAD) systems increasingly rely on shared memory to support long-horizon reasoning, but this convenience opens a critical vulnerability: a single corrupted entry can contaminate the downstream memory-augmented reasoning, and debate alone fails to filter such errors. Existing safeguards filter entries via heuristics or LLM-based validation, yet they rely on AI judgments that share the same failure modes and overlook the cross-agent dynamics of MAD. We address this gap by formulating memory updating in MAD as a zero-trust memory game, in which no agent is assumed honest and the game's equilibrium serves as an indicator of optimal memory trust. Guided by this equilibrium, we propose EquiMem, an inference-time calibration mechanism that quantifies each update algorithmically against the shared memory state, using agents' existing retrieval queries and traversal paths as evidence rather than soliciting any LLM judgment. EquiMem instantiates calibration for both embedding- and graph-based memory, and across diverse benchmarks, MAD frameworks, and memory architectures, it consistently outperforms existing safeguards, remains robust under adversarial agents, and incurs negligible inference overhead.

### 1. 核心问题与整体含义（研究动机和背景）
在多智能体辩论（Multi-Agent Debate, MAD）系统中，**共享内存**是支持长程推理和复杂任务协作的关键。然而，现有的共享内存机制存在一个致命漏洞：**“单点污染”**。如果某个智能体在辩论中产生错误信息并存入内存，这些错误会迅速传播并误导后续所有智能体的推理。

目前的解决方法（如基于 LLM 的审计或启发式过滤）存在两个缺陷：
*   **循环论证风险**：使用 LLM 来判断 LLM 生成内容的正确性，往往会陷入相同的幻觉或失效模式。
*   **忽视动态性**：忽略了多智能体之间在辩论过程中的博弈关系和证据链条。

**EquiMem 的核心目标**是：在不依赖额外 LLM 判断的前提下，通过博弈论均衡算法校准内存条目的可信度，确保共享内存的纯净性。

### 2. 论文提出的方法论
EquiMem 将内存更新过程建模为一个**零信任博弈（Zero-Trust Memory Game）**。

*   **核心思想**：不假设任何智能体是诚实的。将内存条目的“可信度”转化为博弈论中的均衡状态。通过分析智能体在检索内存时的查询路径和遍历行为，将其作为“证据”来量化新条目的质量。
*   **关键技术细节**：
    *   **三种校准指标**：
        1.  **冲突检测 ($\rho_{detect}$)**：衡量新条目与现有内存知识的逻辑一致性。
        2.  **对齐度 ($\rho_{align}$)**：衡量新条目在内存图谱中的结构支撑程度。
        3.  **效用度 ($\rho_{utility}$)**：衡量该条目对解决当前任务目标的实际贡献。
    *   **算法流程**：
        1.  **观察**：记录智能体在推理时的检索查询和内存访问路径。
        2.  **计算均衡**：基于上述指标，通过算法（而非 LLM 询问）计算每个待存入条目的权重。
        3.  **校准更新**：只有达到均衡阈值的条目才会被允许更新或强化到共享内存中。
    *   **架构兼容性**：该方法同时支持**嵌入式内存（Embedding-based）**和**图内存（Graph-based）**。

*   **无需额外 LLM**：避免了“用 AI 监督 AI”带来的幻觉传递问题，降低了推理延迟和成本。
