## 摘要
知识图谱问答（KGQA）旨在通过在知识图谱（KG）上进行推理来回答用户问题。最近的 KGQA 方法主要遵循检索增强生成范式，利用来自 KG 的结构化知识来增强大语言模型（LLM）。然而，训练有效的模型以从 KG 中检索与问题相关的证据通常需要高质量的中间监督信号（如与问题相关的路径或子图），而获取这些信号既耗时又耗费资源。我们提出了 PathISE，这是一个从答案级标签中学习高质量中间监督的新型框架。PathISE 引入了一个基于 Transformer 的轻量级估计器，用于估计关系路径的信息量，从而构建伪路径级监督。随后，该监督被蒸馏到 LLM 路径生成器中，其生成的路径在 KG 中进行落地，为归纳式答案推理提供简洁的证据。在三个 KGQA 基准测试上的广泛实验表明，PathISE 达到了具有竞争力的或最先进的 KGQA 性能，并提供了可重用的监督信号，能够增强现有的 KGQA 模型，且无需依赖昂贵的 LLM 精炼监督信号。我们的源代码可在 https://anonymous.4open.science/r/PathISE-2F87 获取。

## Abstract
Knowledge Graph Question Answering (KGQA) aims to answer user questions by reasoning over Knowledge Graphs (KGs). Recent KGQA methods mainly follow the retrieval-augmented generation paradigm to ground Large Language Models~(LLMs) with structured knowledge from KGs. However, training effective models to retrieve question-relevant evidence from KGs typically requires high-quality intermediate supervision signals, such as question-relevant paths or subgraphs, which are time- and resource-intensive to obtain. We propose PathISE, a novel framework for learning high-quality intermediate supervision from answer-level labels. PathISE introduces a lightweight transformer-based estimator that estimates the informativeness of relation paths to construct pseudo path-level supervision. This supervision is then distilled into an LLM path generator, whose generated paths are grounded in the KG to provide compact evidence for inductive answer reasoning. ExtensiveISE experiments on three KGQA benchmarks show that PathISE achieves competitive or state-of-the-art KGQA performance, and provides reusable supervision signals that can enhance existing KGQA models, without relying on costly LLM-refined supervision signals. Our source code is available at https://anonymous.4open.science/r/PathISE-2F87.

#### 1. 核心问题与整体含义（研究动机和背景）
知识图谱问答（KGQA）的核心挑战在于如何从庞大的知识图谱中检索出与问题相关的推理路径。现有的检索增强生成（RAG）方法通常依赖**中间监督信号**（如推理路径或子图）来训练检索器。然而，高质量的路径标注成本极高。
*   **弱监督的缺陷**：传统方法常将所有连接问题实体与答案的路径视为正样本，但这引入了大量“伪路径”（Spurious Paths），即虽然能到达答案但逻辑无关的路径，导致模型学到噪声。
*   **LLM精炼的局限**：利用大模型（LLM）筛选路径虽然准确，但在大规模数据集上调用成本昂贵且难以扩展。
**PathISE** 的提出旨在通过**多示例学习（MIL）**框架，仅利用现有的“答案级标签”自动估计路径的信息量，从而低成本地生成高质量的伪路径监督信号。

#### 2. 方法论：核心思想与关键技术
PathISE 框架分为三个主要阶段：

*   **阶段 I：基于 MIL 的信息路径估计**
    *   **核心思想**：将连接到同一答案的所有候选路径视为一个“正包”（Positive Bag）。根据 MIL 假设，正包中至少包含一条真正有信息的路径。
    *   **技术细节**：使用轻量级 Transformer 编码器同时对问题和关系路径进行编码。通过**注意力机制（Attention-based MIL Aggregator）**为包内路径分配权重。模型通过二分类任务（预测该包是否包含正确答案）进行训练，训练完成后，注意力得分（Attention Score）即代表路径的“信息量”。
*   **阶段 II：伪监督蒸馏**
    *   将 MIL 估计器筛选出的高分路径作为“伪监督”信号，通过 KL 散度损失函数蒸馏到一个基于 LLM 的**关系路径生成器**（如 LLaMA-3.1-8B）中。
*   **阶段 III：KG 落地的归纳推理**
    *   在推理阶段，生成器产生关系路径，在 KG 中进行实际落地（Grounding）获取实体证据，最后由 LLM 结合这些简洁的结构化证据进行归纳推理并给出答案。

#### 6. 主要结论与发现
*   **性能领先**：PathISE 在 WebQSP 和 CWQ 上显著优于所有弱监督方法，并达到了与昂贵的 LLM 精炼方法相当甚至更好的水平。
*   **监督信号可迁移**：PathISE 产生的伪监督信号是模型无关的，将其应用于其他 KGQA 模型（如 RoG）时，能带来显著的性能提升（F1 提升达 8.4%）。
*   **效率优势**：相比于需要多次 LLM 迭代的 Agent 类方法，PathISE 的推理速度更快，Token 消耗更低。
*   **降噪能力**：MIL 估计器能有效识别并抑制“伪路径”，使路径生成器更专注于符合逻辑的推理链。

#### 7. 优点（亮点）
*   **低成本高效率**：巧妙利用 MIL 框架解决了 KGQA 中间标注缺失的问题，无需昂贵的 LLM 标注。
*   **轻量级设计**：估计器采用简单的 Transformer 结构，易于训练和部署。
*   **归纳推理范式**：通过“路径落地”将复杂的图结构转化为简洁的文本证据，降低了 LLM 推理的幻觉风险。
*   **通用性强**：提出的监督学习框架可以作为通用插件增强现有的检索器或生成器。

#### 8. 不足与局限
*   **对 KG 完整性的依赖**：如果 KG 本身缺失关键边，MIL 估计器无法从不存在的路径中学习，也无法处理实体链接失败的情况。
*   **路径生成瓶颈**：错误分析显示，路径生成失败仍是导致最终回答错误的主要原因（尤其在复杂问题中）。
*   **MIL 估计误差**：在候选路径空间极大且噪声极高时，MIL 估计器仍可能给某些伪路径分配高分。
*   **应用限制**：目前主要针对关系路径（Relation Path），对于需要复杂逻辑算子（如交集、差集）的逻辑查询支持尚不明确。
