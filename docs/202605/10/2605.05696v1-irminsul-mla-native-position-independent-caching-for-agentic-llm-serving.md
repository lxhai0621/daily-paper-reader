## 摘要
智能体（Agentic）LLM 工作负载在每一轮对话中都会将完全相同的 token 置于偏移后的位置，导致前缀缓存（prefix caches）在第一个差异字节处失效。运营商报告称，即使内容未变，缓存命中率的下降也会导致从轻微减速到严重的 10-16 秒首字延迟（TTFT）峰值。先前的位置无关缓存系统在完整的 $d_K$ 维键（key）上修正 RoPE，这是由 GQA 带来的架构成本，而非缓存本身。多头潜在注意力（MLA）已在 DeepSeek-V2/V3/R1、Kimi-K2/Moonlight、GLM-5 和 Mistral Large 3 中大规模部署，它将每一行 KV 分解为位置无关的 $c_{KV}$ 和一个可闭式修正的 64 维 $k_r$；这种结构使得内容寻址缓存成为一种自然的适配，而非针对 GQA 的权宜之计。我们提出了 Irminsul，它通过对 CDC 分块段进行内容哈希键控以及针对 $k_r$ 的 $δ$ 旋转规则，扩展了 SGLang 的基数缓存（radix cache）。我们在三个原生的 MLA-MoE 部署——DeepSeek-V2-Lite (16B/2.4B)、Kimi Moonlight-16B-A3B 和 JoyAI-Flash (48B/3B) 上进行了评估，三者均保持了输出一致性，并在其中两个端点上测量了恢复情况；在智能体流量中，Irminsul 在精确前缀匹配之外额外恢复了高达约 83% 的 prompt token，同时每次缓存命中可节省 63% 的预填充（prefill）能耗。我们认为，内容寻址缓存应当作为推理栈中的一等原语，而非对前缀匹配的补丁。

## Abstract
Agentic LLM workloads put bit-identical tokens at shifted positions every turn, voiding prefix caches at the first byte of divergence. Operators report cache-hit regressions ranging from moderate slowdowns to severe TTFT spikes of 10-16s on unchanged content. Prior position-independent caching systems correct RoPE on the full $d_K$-dimensional key, an architectural cost imposed by GQA, not by caching itself. Multi-Head Latent Attention, deployed at scale in DeepSeek-V2/V3/R1, Kimi-K2/Moonlight, GLM-5, and Mistral Large 3, factors each KV row into a position-free $c_{KV}$ and a 64-dim $k_r$ correctable in closed form; this structure motivates content-addressed caching as a natural fit rather than a GQA workaround. We present Irminsul, which extends SGLang's radix cache with content-hash keying over CDC-chunked segments and a $δ$-rotation rule for $k_r$. We evaluate three native MLA-MoE deployments - DeepSeek-V2-Lite (16B/2.4B), Kimi Moonlight-16B-A3B, and JoyAI-Flash (48B/3B) - with output-consistency on all three and recovery measured on the two endpoints; Irminsul recovers up to ~83% of prompt tokens above exact-prefix on agentic traffic while delivering 63% prefill energy savings per cache hit. We argue that content-addressed caching belongs in the serving stack as a first-class primitive, not a retrofit over prefix matching.

### 1. 核心问题与研究动机
*   **核心问题**：在智能体工作负载（如 RAG、工具调用、多步推理）中，Prompt 经常被动态组装。即使 Token 内容完全一致，它们在序列中的**绝对位置**也经常发生偏移（Position Shift）。
*   **传统局限**：目前主流的推理框架（如 SGLang, vLLM）使用**前缀缓存（Prefix Caching）**。一旦 Prompt 开头插入了一个新 Token，后续所有相同的 Token 都会因为位置改变而导致哈希不匹配，从而引发缓存失效，导致首字延迟（TTFT）大幅增加和算力浪费。
*   **研究背景**：先前的“位置无关缓存（PIC）”方案主要针对 GQA 架构，需要对整个 $d_K$ 维度的 Key 进行复杂的旋转修正，计算成本高。而新兴的 **MLA（多头潜在注意力）** 架构（如 DeepSeek-V2/V3 使用）在数学结构上天然适合做位置无关缓存。

### 2. 方法论：Irminsul 核心技术
*   **核心思想**：利用 MLA 将 KV 向量分解为**位置无关项**（512 维的 $c_{KV}$）和**位置相关项**（64 维的 $k_r$）的特性。
*   **关键技术细节**：
    1.  **内容寻址分块（CDC）**：放弃固定长度分块，采用基于 Gear-hash 的内容定义分块（CDC）。通过滚动哈希识别 Token 序列中的特征边界，确保无论 Token 偏移到哪里，都能切分出相同的块。
    2.  **$\delta$-旋转规则**：对于缓存命中的块，直接复用 $c_{KV}$；对于带 RoPE 旋转的 $k_r$，根据新旧位置的差值 $\delta = p_{new} - p_{old}$ 进行闭式旋转修正。由于 $k_r$ 仅占 KV 行的 11%，修正开销极低。
    3.  **首块切除（First-Chunk Carve-out）**：针对“注意力汇聚（Attention Sink）”现象，研究发现 Sink 效应主要集中在序列起始位置。Irminsul 对位置 0 附近的 Token 进行重新计算，而对后续块进行位置无关复用，从而保证模型输出精度。
    4.  **算法流程**：接收 Prompt -> 前缀匹配 -> 对剩余部分进行 CDC 分块 -> 内容哈希检索 -> 命中则执行 $\delta$-旋转并拼接 -> 未命中则执行预填充并存入注册表。

### 6. 主要结论与发现
*   **高恢复率**：在智能体元数据变动的场景下，Irminsul 比传统前缀缓存多恢复了 **77% - 83%** 的 Token。
*   **显著节能**：相比完全重新计算，每次缓存命中可节省 **63%** 的预填充阶段能耗。
*   **架构敏感性**：实验证明 PIC 在纯 Softmax 架构（GQA/MLA）上非常有效，但在混合 SSM/线性注意力架构上几乎没有节能效果（因为其递归状态无法按 Token 索引）。
*   **精度保持**：$\delta$-旋转带来的相对误差极小（$4.7 \times 10^{-3}$），在所有测试任务中，模型输出的 KL 散度和 F1 分数均保持在安全范围内。

### 7. 优点与亮点
*   **架构原生性**：不同于以往将 PIC 视为 GQA 补丁的研究，本文指出 MLA 架构是 PIC 的“天作之合”，将修正开销从 $O(d_K N)$ 降至 $O(64 N)$。
*   **系统级集成**：提出了 S2（通过协作预防偏移）和 S1（检测并恢复）两种策略，具有很强的工程落地指导意义。
*   **深入的理论分析**：对 Attention Sink 的位置特性进行了量化研究，证明了“首块切除”策略的有效性。

### 8. 不足与局限
*   **模型依赖**：该方法高度依赖 MLA 架构，对于目前仍占据主流的 GQA 架构模型（如 Llama 3, Qwen 2.5），虽然理论可行但收益不如 MLA 显著。
*   **MHA 局限性**：研究发现 MHA 的 Attention Sink 具有局部集中特性，Irminsul 的首块切除策略在 MHA 上可能不足以完全消除误差。
*   **未来架构挑战**：论文提到 DeepSeek-V4 的 HCA（重度压缩注意力）可能会破坏 Token 级的内容哈希，需要进一步适配。
