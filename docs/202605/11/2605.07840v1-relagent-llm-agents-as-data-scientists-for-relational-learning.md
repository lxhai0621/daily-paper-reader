## 摘要
关系学习是一个具有挑战性的问题，它催生了广泛的方法，包括基于图的模型（如图神经网络、图 Transformer）、表格方法（如表格基础模型）以及基于序列的方法（如大语言模型），每种方法都有其自身的优势和局限性。我们提出了 RelAgent，一种用于关系学习的基于 LLM 的自主数据科学家，它分为两个阶段运行。在搜索阶段，LLM 智能体使用数据库、验证和评估工作区工具来构建 SQL 特征程序并选择预测模型。在推理阶段，生成的程序在无需进一步调用 LLM 的情况下执行。最终的预测器由 SQL 查询和经典模型组成，能够实现快速、确定性且具有内在可解释性的预测：特征是人类可读的查询，且预测仅取决于生成的由查询定义的特征映射，从而能够使用标准数据库系统进行可扩展部署。

## Abstract
Relational learning is a challenging problem that has motivated a wide range of approaches, including graph-based models (e.g., graph neural networks, graph transformers), tabular methods (e.g., tabular foundation models), and sequence-based approaches (e.g., large language models), each with its own advantages and limitations. We propose RelAgent, an LLM-based autonomous data scientist for relational learning, which operates in two phases. In the search phase, an LLM agent uses database, validation, and evaluation workspace tools to construct SQL feature programs and select a predictive model. In the inference phase, the resulting program is executed without further LLM calls. The final predictor consists of SQL queries and a classical model, enabling fast, deterministic, and intrinsically interpretable predictions: features are human-readable queries, and predictions depend only on the resulting query-defined feature map, enabling scalable deployment using standard database systems.

#### 1. 核心问题与整体含义
关系数据库是存储结构化数据的标准范式，但在其上进行预测建模（关系学习）极具挑战。传统方法要么依赖繁重的人工特征工程，要么使用黑盒模型（如 GNN 或关系基础模型），在可解释性、跨模式迁移能力或推理效率上存在权衡。论文的研究动机是利用大语言模型（LLM）的推理能力，自动化“特征工程 + 模型选择”的流程，同时确保最终预测器是透明且高效的。

#### 2. 方法论
RelAgent 提出了一个将关系学习视为“在查询特征和预测模型空间中进行自主搜索”的框架，分为两个阶段：
*   **搜索阶段（Search Phase）：** LLM 智能体作为“数据科学家”，通过三个工具接口与数据库交互：
    1.  **数据库探索：** 使用只读 SQL 检查模式、行数和数据分布。
    2.  **程序验证：** 智能体提出一个由多个 SQL 查询组成的“特征程序”和一个预测模型配置（如 XGBoost、LightGBM 及其超参数）。系统在验证集上执行并返回性能指标和错误诊断。
    3.  **评估工作区（Evaluation Workspace）：** 这是一个持久化数据库，记录了所有历史尝试的预测结果和诊断信息。智能体可以查询该工作区，进行跨实验的错误分析（如“哪些样本在修改特征后预测更准了”）。
*   **推理阶段（Inference Phase）：** 一旦搜索完成，LLM 退出流程。最终产出是一个纯 SQL 特征程序和一个训练好的经典机器学习模型。推理时直接在数据库执行 SQL 并输入模型，无需 LLM 调用，保证了确定性、高速度和内在可解释性。

#### 3. 实验设计
*   **数据集与场景：** 涵盖了三个主流关系学习基准：**RelBenchV1**、**RelBenchV2** 和 **4DBInfer**。涉及电商、社交网络、医疗、学术和体育等多个领域，包含实体分类和回归任务（如流失预测、参与度估计、LTV 预测等）。
*   **对比方法：**
    *   **监督表格模型：** LightGBM、AutoGluon、DS+TabPFN。
    *   **关系深度学习：** GraphSAGE、RelGNN、RelGT（基于图的方法）。
    *   **关系基础模型：** Griffin、Relational Transformer、KumoRFM-v1/v2（SOTA 闭源模型）。
    *   **LLM 特征工程方法：** FeatLLM、ReFuGe。

#### 4. 资源与算力
*   **LLM 后端：** 主要使用 **GPT-5.2** 作为核心智能体。
*   **对比后端：** 为了测试鲁棒性，还使用了 **DeepSeek-V4-Pro** 和 **Qwen3-32B**。
*   **硬件算力：** 对于本地部署的 Qwen3-32B，使用了 **2 张 NVIDIA RTX 6000 Ada (48GB)** GPU。
*   **运行时间：** 单个任务的搜索过程平均耗时 35-45 分钟（GPT-5.2/DeepSeek），Qwen3 约 98 分钟。

#### 5. 实验数量与充分性
*   **实验规模：** 在 32 个不同的关系学习任务上进行了评估。
*   **重复性：** 每个任务运行 5 次独立的搜索过程，并进行跨轮次的模型选择。
*   **消融实验：** 针对迭代反馈循环、评估工作区、语义信息（模式匿名化）、预测器选型以及不同 LLM 后端做了详尽的消融研究。
*   **充分性评价：** 实验设计非常客观且充分，不仅对比了最新的闭源 SOTA 模型，还通过合成实验（如定向三角形检测）验证了 SQL 特征在表达逻辑模式上的优越性。

#### 6. 主要结论与发现
*   **性能卓越：** RelAgent 在多个基准测试中达到了 SOTA 或接近 SOTA 的水平。在 RelBenchV1 上排名第一（平均秩次 3.17），优于所有开源模型，仅次于闭源的 KumoRFM-v2。
*   **搜索价值：** 消融实验显示，如果没有迭代反馈，性能会大幅下降（AUROC 从 78.38 降至 66.86），证明了“智能体搜索”而非“单次生成”是成功的关键。
*   **联合优化：** 智能体能够同时优化 SQL 特征和下游模型配置（如在回归任务中自动选择 L1 损失和对数变换），这种联合搜索带来了显著增益。

#### 7. 优点
*   **内在可解释性：** 预测依据是人类可读的 SQL 查询，而非不可解释的图嵌入或注意力权重。
*   **推理零成本（LLM 层面）：** 推理阶段不需要 LLM，解决了 LLM 在生产环境中延迟高、成本贵的问题。
*   **表达能力强：** SQL 可以表达复杂的关联逻辑（如多路自连接），这是标准 GNN 难以捕捉的。
*   **无缝集成：** 最终产物可以直接部署在任何标准 SQL 数据库（如 DuckDB, Snowflake）中。

#### 8. 不足与局限
*   **搜索成本：** 虽然推理便宜，但搜索阶段需要多次调用 LLM API，对于超大规模模式或极多任务，搜索成本较高。
*   **搜索深度限制：** 在有限的步数内，智能体可能难以发现极深的多表连接（Deep Joins）或非常复杂的高阶关系模式。
*   **非结构化数据处理：** 目前主要侧重于结构化关系和统计特征，对长文本字段或多模态属性的深度挖掘能力有限。
*   **验证集依赖：** 搜索过程高度依赖验证集的质量，存在对验证集过拟合的潜在风险。
