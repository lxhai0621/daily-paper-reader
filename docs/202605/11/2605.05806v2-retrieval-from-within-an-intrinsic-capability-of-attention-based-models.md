## 摘要
检索增强生成（RAG）通常将检索和生成视为独立的系统。我们探讨了基于注意力的编码器-解码器是否可以直接从其自身的内部表示中进行检索。我们引入了 INTRA（通过注意力的内在检索），这是一个解码器注意力查询对预编码的证据块进行评分，并将其直接重用为生成上下文的框架。通过这种构建方式，INTRA 统一了检索和生成，消除了 RAG 流水线中典型的检索器-生成器不匹配问题。该设计还通过在不同查询中重用预计算的编码器状态，分摊了上下文编码的开销。在问答基准测试中，INTRA 在证据召回率和端到端回答质量方面均优于强大的工程化检索流水线。我们的结果表明，基于注意力的模型已经具备了一种可以被激发出来的检索机制，而无需作为外部模块添加。

## Abstract
Retrieval-augmented generation (RAG) typically treats retrieval and generation as separate systems. We ask whether an attention-based encoder-decoder can instead retrieve directly from its own internal representations. We introduce INTRA (INTrinsic Retrieval via Attention), a framework where decoder attention queries score pre-encoded evidence chunks that are then directly reused as context for generation. By construction, INTRA unifies retrieval and generation, eliminating the retriever-generator mismatch typical of RAG pipelines. This design also amortizes context encoding by reusing precomputed encoder states across queries. On question-answering benchmarks, INTRA outperforms strong engineered retrieval pipelines on both evidence recall and end-to-end answer quality. Our results demonstrate that attention-based models already possess a retrieval mechanism that can be elicited, rather than added as an external module.

### 1. 核心问题与整体含义（研究动机和背景）
传统的检索增强生成（RAG）通常采用“模块化”设计，将检索器（Retriever）和生成器（Generator）视为两个独立的系统。这种分离导致了两个主要问题：
*   **表示空间不匹配**：检索器使用的向量空间（如双编码器）与生成器处理文本的内部表示空间不一致。
*   **计算冗余**：在标准 RAG 中，检索到的文本需要被生成器重新编码，造成了大量的计算开销。

本研究的核心问题是：**基于注意力的模型是否具备内在的检索能力？** 作者提出，注意力机制本质上就是一种查询驱动的信息选择过程，因此可以利用模型自身的内部表示直接进行检索，从而实现检索与生成的深度统一。

### 2. 论文提出的方法论：INTRA 框架
作者提出了 **INTRA (INTrinsic Retrieval via Attention)** 框架，其核心思想是利用编码器-解码器模型的交叉注意力（Cross-Attention）信号来驱动检索。

*   **核心思想**：将解码器的查询状态（Query states）作为检索向量，与预先编码好的证据块（Encoded chunks）进行匹配评分。
*   **关键技术细节**：
    *   **检索标记（Retrieval Tokens）**：在解码器输入中加入少量可学习的特殊标记，专门用于生成检索查询。
    *   **Reverse-QWK (Reversed Query-Key Projection)**：这是本文的技术亮点。为了避免为每一层解码器存储不同的 Key 表示，作者将 Key 侧的缩放和投影矩阵转移到 Query 侧。这样，整个语料库只需要存储一份归一化后的编码器表示，所有层和头都可以共享同一个索引进行高效检索。
    *   **MaxSim 评分**：借鉴 ColBERT 的后期交互（Late Interaction）机制，通过计算 Query Token 与 Chunk Token 之间的最大相似度之和来对证据块进行排名。
    *   **两阶段推理**：首先进行一次“检索前向传播”获取评分并选出 Top-k 证据块；然后直接复用这些块的编码器状态进行“生成前向传播”。

### 5. 实验数量与充分性
*   **实验规模**：在 4 个主流数据集上进行了详尽的测试，报告了证据召回率（Recall@k）和端到端问答指标（EM, F1）。

### 6. 主要结论与发现
*   **性能优越**：INTRA 在多跳问答任务上显著优于所有工程化的 RAG 流水线，证明了“内部检索”在处理复杂证据组合时的强大能力。
*   **效率提升**：由于直接复用预编码的表示，INTRA 避免了生成时的重新编码过程。实验显示，随着检索块数量增加，INTRA 的首字延迟（TTFT）远低于标准 RAG。
*   **模型对齐**：当检索器和生成器共享同一个解码器逻辑时，检索到的证据与生成器的“胃口”最匹配，Gap Closure 指标最高。

### 7. 优点
*   **架构优雅**：消除了检索器和生成器之间的表示鸿沟，将 RAG 从“拼凑系统”转向“原生统一系统”。
*   **技术创新**：Reverse-QWK 巧妙地解决了 Transformer 层间表示不一致的问题，使得大规模向量检索在显存/内存上变得可行。
*   **冷启动能力**：证明了预训练模型即使不经过大规模检索训练，也蕴含着极强的检索潜力。

### 8. 不足与局限
*   **架构限制**：该方法依赖于编码器-解码器（Enc-Dec）架构的交叉注意力，目前无法直接应用于主流的纯解码器（Decoder-only）模型（如 Llama, GPT 系列）。
*   **存储成本**：虽然计算更省，但存储 Token 级别的隐藏层表示（Embedding）比存储压缩后的向量索引或原始文本要占用更多空间。
*   **语料库动态性**：实验主要针对固定语料库，对于频繁更新的动态网页检索场景，维护大规模内部表示索引的成本尚待评估。
*   **任务范围**：主要集中在短文本问答，对于长文本生成或摘要任务的效果有待进一步验证。
