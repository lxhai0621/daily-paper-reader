## 摘要
大语言模型（LLMs）已成为现代人工智能的核心基础，但其生命周期仍受限于训练与部署之间的严格分离，部署后学习过程实际上便已停止。这种局限性与自然智能形成了鲜明对比，后者通过与环境的交互不断进行自适应。在本文中，我们将部署时学习（DTL）形式化为 LLM 生命周期的第三阶段，使 LLM 智能体能够在不修改模型参数的情况下，在部署期间从经验中改进。我们提出了 CASCADE（部署期间基于案例的持续自适应），这是一个通用且有原则的框架，为 LLM 智能体配备了显式的、不断演化的情景记忆。CASCADE 将经验重用建模为上下文老虎机（contextual bandit）问题，实现了有原则的探索-利用权衡，并在长期交互中建立了无悔（no-regret）保证。这种设计允许智能体积累、选择和优化与任务相关的案例，将过去的经验转化为可操作的知识。在涵盖医疗诊断、法律分析、代码生成、网络搜索、工具使用和具身交互的 16 个多样化任务中，CASCADE 的宏平均成功率比零样本提示（zero-shot prompting）提高了 20.9%，同时始终优于基于梯度和基于记忆的基准方法。通过将部署重新定义为一个自适应学习过程，本研究为持续改进的人工智能系统奠定了基础。

## Abstract
Large language models (LLMs) have become a central foundation of modern artificial intelligence, yet their lifecycle remains constrained by a rigid separation between training and deployment, after which learning effectively ceases. This limitation contrasts with natural intelligence, which continually adapts through interaction with its environment. In this paper, we formalise deployment-time learning (DTL) as the third stage in the LLM lifecycle that enables LLM agents to improve from experience during deployment without modifying model parameters. We present CASCADE (CASe-based Continual Adaptation during DEployment), a general and principled framework that equips LLM agents with an explicit, evolving episodic memory. CASCADE formulates experience reuse as a contextual bandit problem, enabling principled exploration-exploitation trade-offs and establishing no-regret guarantees over long-term interactions. This design allows agents to accumulate, select, and refine task-relevant cases, transforming past experience into actionable knowledge. Across 16 diverse tasks spanning medical diagnosis, legal analysis, code generation, web search, tool use, and embodied interaction, CASCADE improves macro-averaged success rate by 20.9% over zero-shot prompting while consistently outperforming gradient-based and memory-based baselines. By reframing deployment as an adaptive learning process, this work establishes a foundation for continually improving AI systems.

*   **核心问题**：传统大语言模型（LLM）的生命周期被严格划分为训练和部署两个阶段。一旦部署，模型的参数便不再更新，导致其无法从实时的环境交互和反馈中持续学习。
*   **研究动机**：
    *   **自然智能的对比**：人类智能通过持续的交互和经验积累不断进化，而 LLM 在部署后是静态的。
    *   **现有方法的局限**：基于梯度的在线微调（如 RLFT）在 LLM 规模下计算成本极高，且对于闭源 API 模型在方法论上不可行。
    *   **部署时学习（DTL）**：作者提出将 DTL 作为 LLM 生命周期的第三阶段（继预训练、微调之后），使智能体在不修改参数的情况下，通过管理“经验”来实现性能的持续提升。

### 2. 方法论：CASCADE 框架
*   **核心思想**：结合**基于案例的推理（CBR）**与**上下文多臂老虎机（Contextual Bandit）**算法。CASCADE 不更新 LLM 参数，而是通过演化一个显式的“情景记忆库”（Case Bank）来改变模型的行为。
*   **关键技术细节**：
    *   **4R 循环**：检索（Retrieve）、重用（Reuse）、修订（Revise）、保留（Retain）。
    *   **上下文老虎机建模**：将案例检索视为一个探索与利用（Exploration-Exploitation）的权衡问题。
    *   **Neural-LinLogUCB 算法**：这是 CASCADE 的核心算法，用于优化检索策略。它解耦了表示学习（使用深度 Transformer 编码器）和不确定性估计（使用浅层线性头），通过二元反馈（成功/失败）来最小化“检索悔值”（Retrieval Regret）。
    *   **无悔保证（No-regret Guarantees）**：论文在理论上证明了该方法具有子线性的悔值界限，即随着交互增加，智能体的平均性能会趋于最优。

### 3. 实验设计
*   **数据集与场景**：涵盖 16 个多样化任务，分为三类：
    1.  **单轮任务（12个）**：医疗诊断（DDXPlus）、用药推荐（MIMIC-IV-MR）、法律判决预测（MUD/CMDL）、金融意图路由、AIOps 根因分析、代码生成（SPIDER/BIRD）等。
    2.  **具身智能模拟任务**：ALFWorld（家庭环境）、ScienceWorld（科学实验）。
    3.  **复杂现实多轮任务**：基于 Web 的深度搜索（2Wiki）、基于电子健康记录（EHR）的复杂表格推理（MIMIC-III）。
*   **对比方法（Baselines）**：
    *   **非学习类**：Zero-shot Prompting。
    *   **基于记忆的学习类**：ICRL（在向强化学习）、ICRLPlus、NP-CBR（不带自适应检索的基准 CBR）。
    *   **基于梯度的学习类**：REINFORCE + LoRA（在线强化学习结合参数微调）。

### 4. 资源与算力
*   **CASCADE 需求**：极低。仅需**单张消费级 GPU**（如 NVIDIA RTX 3090），显存占用小于 **4GB**。因为它只需训练一个轻量级的检索编码器，而无需微调 LLM。
*   **对比方法需求**：REINFORCE + LoRA 需要多张高端 GPU（如 4x A40 或 2x A100）进行反向传播。
*   **底层模型**：实验使用了 Qwen3 系列（4B, 8B, 14B, 32B）以及黑盒 API 模型 Gemini-2.0-flash。

### 5. 实验数量与充分性
*   **实验规模**：在 16 个不同领域的任务上进行了广泛测试，每项实验均基于 5 个随机种子取平均值。
*   **消融实验**：非常充分。包括：
    *   不同上下文老虎机算法（LinLogUCB, NeuralLinUCB 等）的对比。
    *   探索系数 $\alpha$ 的敏感度分析。
    *   不同模型规模（4B 到 32B）的泛化性测试。
    *   检索案例数量（Top-k）对性能的影响。
    *   人机协同（Human-in-the-loop）场景下的性能表现。
*   **客观性**：通过在开源模型和黑盒 API 模型上同时验证，证明了方法的普适性和公平性。

### 6. 主要结论与发现
*   **性能提升**：CASCADE 相比 Zero-shot 宏平均成功率提升了 **20.9%**。
*   **超越梯度方法**：在 12 个单轮任务中的 9 个任务上，CASCADE 优于基于梯度的 REINFORCE+LoRA，且计算资源消耗极低。
*   **小模型逆袭**：配备 CASCADE 的小规模模型（如 8B）在某些任务上能超过更大规模（如 32B）的 Zero-shot 模型。
*   **黑盒适用性**：成功在 Gemini-2.0-flash 等黑盒 API 上实现持续改进，这是梯度方法无法做到的。

### 7. 优点与亮点
*   **理论与实践结合**：不仅提出了框架，还提供了严谨的无悔学习理论证明。
*   **极高的资源效率**：将学习重心从昂贵的参数更新转移到轻量级的经验管理，适合边缘部署。
*   **即插即用**：可以作为现有智能体框架（如 ReAct）的插件，显著增强其长期适应能力。
*   **可解释性**：显式的案例库让智能体的决策依据（参考了哪些过去经验）清晰可见。

### 8. 不足与局限
*   **冷启动依赖**：如果底层 LLM 的初始能力极差（Zero-shot 成功率为 0），CASCADE 将难以收集到成功的案例进行保留，导致学习停滞。
*   **长期记忆管理**：论文虽提到案例库会增长，但未深入探讨在极长交互周期下的记忆清理、遗忘机制或案例冲突解决。
*   **负面经验利用**：目前主要保留成功案例，对于如何从失败案例中提取结构化教训（Learning from failure）的探索相对较少。
*   **任务分布偏移**：虽然在 ALFWorld 的 unseen 任务上表现良好，但在极端任务偏移下的鲁棒性仍需更多验证。
