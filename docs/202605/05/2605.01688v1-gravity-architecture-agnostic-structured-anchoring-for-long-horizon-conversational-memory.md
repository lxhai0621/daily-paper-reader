## 摘要
长程对话智能体依赖于具有日益复杂的检索机制的记忆系统。然而，检索到的片段通常以非结构化文本的形式输入给语言模型，缺乏复杂推理所必需的关系、时间和主题结构。为了弥补这一推理差距，我们引入了 GRAVITY（通过注入拓扑记忆实现的生成时关系锚定），这是一种即插即用的结构化记忆模块。GRAVITY 从原始对话话语中提取三种互补的知识表示：基于关系图的实体概况、链接到因果追踪的时间事件元组，以及跨会话的主题摘要。在生成时，它将这些表示作为结构化锚定上下文注入到宿主系统的提示词中。该方法有效地将分散的证据合成为连贯且与查询相关的上下文，而无需对宿主模型进行任何架构修改。在 LongMemEval 和 LoCoMo 基准测试中对五种不同记忆系统进行的广泛评估证明了我们方法的有效性。平均而言，GRAVITY 将 LLM 评判准确率提高了 7.5%--10.1%。性能提升与基线强度呈负相关：最弱的宿主提升了 12.2%，而最强的宿主仍有 3.8%--5.7% 的提升。这些发现表明，结构化上下文锚定是一种广泛有效、架构无关的长程对话记忆增强范式。

## Abstract
Long-horizon conversational agents rely on memory systems with increasingly sophisticated retrieval mechanisms. However, retrieved fragments are typically fed to the language model as unstructured text, lacking the relational, temporal, and thematic structures essential for complex reasoning. To bridge this reasoning gap, we introduce GRAVITY (\textbf{G}eneration-time \textbf{R}elational \textbf{A}nchoring \textbf{V}ia \textbf{I}njected \textbf{T}opological Memor\textbf{Y}), a plug-and-play structured memory module. GRAVITY extracts three complementary knowledge representations from raw conversational utterances: entity profiles grounded in relational graphs, temporal event tuples linked into causal traces, and cross-session topic summaries. At generation time, it injects these representations into the host system's prompt as structured anchoring contexts. This approach effectively synthesizes scattered evidence into a coherent, query-relevant context without requiring any architectural modifications to the host model. Extensive evaluations across five diverse memory systems on the LongMemEval and LoCoMo benchmarks demonstrate the efficacy of our approach. On average, GRAVITY improves LLM-judge accuracy by 7.5--10.1%. Gains are inversely correlated with baseline strength: the weakest host improves by 12.2% while the strongest still gains 3.8--5.7%. These findings establish structured context anchoring as a broadly effective, architecture-agnostic augmentation paradigm for long-horizon conversational memory.

### 论文总结：GRAVITY —— 架构无关的长程对话记忆结构化锚定

#### 1. 核心问题与整体含义（研究动机和背景）
长程对话智能体（Long-horizon conversational agents）需要处理跨越数百个会话的长期记忆。现有的记忆系统（如基于向量检索的 RAG）主要关注如何检索相关的文本片段，但存在**“推理鸿沟”**：检索到的片段通常是零散、非结构化的，缺乏实体间的关系、事件的时间顺序以及跨会话的主题逻辑。即使检索是完美的（Oracle 设定），模型也难以从碎片化信息中还原复杂的背景。本文提出了 **GRAVITY**，旨在通过在生成阶段注入结构化的“锚点”上下文，弥补检索与生成之间的结构化信息缺失。

#### 2. 方法论：核心思想与技术细节
GRAVITY 采用一种**即插即用（Plug-and-play）**的模块化设计，无需修改宿主记忆系统的内部架构。其核心流程分为两个阶段：

*   **构建阶段（Build Phase - 离线）：** 从原始对话中提取三种维度的结构化锚点：
    1.  **实体锚点（Entity Anchors）：** 构建动态实体档案，包含属性、与其他实体的关系、状态变迁及共现信息。
    2.  **事件锚点（Event Anchors）：** 提取 4W1O（Who, What, When, Where, Outcome）元组，并根据参与者或主题将事件链接成“时间追踪链（Temporal Traces）”。
    3.  **主题锚点（Topic Anchors）：** 识别跨会话的语义主题，生成包含叙事摘要、关键事实和时间跨度的主题概览。
*   **推理阶段（Inference Phase - 在线）：**
    1.  **锚点检索与重排序：** 基于查询（Query）的嵌入向量对候选锚点进行重排序，并引入时间保护机制以确保时间相关的事件不被过滤。
    2.  **查询扩展：** 利用锚点内容生成扩展查询，帮助宿主系统检索更广泛的原始记忆。
    3.  **上下文注入：** 将选定的结构化锚点格式化为特定区块，注入到宿主系统的 Prompt 中，引导 LLM 进行推理。

#### 3. 实验设计
*   **数据集：** 
    *   **LoCoMo：** 包含 1,540 个 QA 对，涵盖多跳推理、事实召回、时间推理和开放域推理。
    *   **LongMemEval：** 包含 500 个问题，涉及信息提取、跨会话推理、知识更新等 7 个任务类型。
*   **基准模型（Host Systems）：** 选取了 5 种代表不同架构的 SOTA 记忆系统：**LightMem**（压缩型）、**A-Mem**（原子笔记型）、**Mem0**（向量+图混合型）、**LiCoMemory**（层次认知图型）和 **ZEP**（时间知识图谱型）。
*   **对比方法：** 比较了各系统在“原生状态”与“挂载 GRAVITY”后的表现，并设置了“非结构化摘要（+Sum）”作为消融对比。

#### 4. 资源与算力
*   **模型调用：** 默认使用 **GPT-4o-mini** 作为提取器、生成器和 LLM 评判员。
*   **本地算力：** 在成本优化实验中，使用了本地部署的 **Qwen-3-8B** 模型，运行在单张 **NVIDIA H20 GPU** 上（使用 vLLM 加速）。
*   **耗时：** 构建阶段平均每场对话耗时约 360-550 秒（取决于并行程度）；推理阶段增加的延迟通常在 0.3-1.0 秒之间。

#### 5. 实验数量与充分性
实验设计非常详尽且具有高度的客观性：
*   **跨架构验证：** 在 5 种完全不同的记忆架构上均验证了有效性。
*   **消融实验：** 验证了实体/事件/主题三个模块的互补性，以及重排序和查询扩展的作用。
*   **Oracle 实验：** 通过控制变量证明了性能提升源于“结构化组织”而非单纯的“证据存在”。
*   **成本分析：** 探讨了并行提取、三合一提取（Triple Extraction）等降低 Token 消耗的策略。
*   **错误分析：** 深入分析了 50 个失败案例，总结出过度总结、时间槽错误等局限性。

#### 6. 主要结论与发现
*   **普遍增益：** GRAVITY 使各系统的准确率平均提升了 **7.5%--10.1%**。
*   **负相关规律：** 提升幅度与宿主系统的基线强度呈负相关（R²=0.75）。这意味着 GRAVITY 能有效修补弱系统的结构化缺陷，而强系统由于自身已具备部分结构化能力，增益相对较小。
*   **结构胜过内容：** 实验证明，结构化的 Schema（实体/事件/主题）比同等长度的非结构化文本摘要效果显著更好（在 LoCoMo 上高出 4.4%）。

#### 7. 优点
*   **架构无关性：** 真正的即插即用，不需要访问或修改宿主系统的索引、嵌入或存储逻辑。
*   **多维覆盖：** 同时解决了关系、时间和主题三个维度的结构化缺失问题。
*   **可移植性：** 锚点知识库可以一次构建，在不同的 LLM 或记忆系统间通用。

#### 8. 不足与局限
*   **提取偏差：** 依赖于构建阶段 LLM 的提取质量。如果提取时丢失了细节或产生了幻觉，会误导生成阶段。
*   **过度总结风险：** 结构化锚点有时会为了简洁而忽略长尾细节，导致模型在处理极细粒度问题时表现下降。
*   **成本开销：** 虽然比部分系统低，但离线构建阶段仍需多次 LLM 调用，对于超大规模对话库存在一定的 Token 成本。
