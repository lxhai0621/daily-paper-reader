## 摘要
检索增强生成（RAG）和集成工具的大语言模型（LLM）智能体日益依赖外部文本源。这种依赖性扩大了可利用的攻击面，使攻击者能够插入恶意指令，从而触发非预期的模型行为。目前的防御措施通常利用基于 LLM 的检测器来过滤此类内容，但这些方法在基于优化的攻击面前仍然十分脆弱。此外，基于训练的方法往往难以泛化到新的数据分布。为了解决这些问题，我们提出了 SONAR，这是一个利用自然语言推理指标来识别并移除注入内容的提示词清洗框架。具体而言，SONAR 在用户查询和外部数据之间构建了一个句子级关系图。通过将蕴含和矛盾分数作为边权重，该系统能够识别偏离核心任务的句子。随后，它采用连通性驱动的剪枝技术来消除标记的注入种子及其相关邻居，同时保留良性上下文。在多个模型和数据集上的严格评估表明，SONAR 将攻击成功率降低至接近于零，显著优于九种现有的基准防御方法。

## Abstract
Retrieval-augmented generation and tool-integrated LLM agents increasingly depend on external textual sources. This reliance broadens the available attack surface, allowing adversaries to insert malicious instructions that trigger unintended model behaviors. Current defensive measures often utilize LLM-based detectors to filter such content, but these approaches remain vulnerable to optimization-based attacks. Additionally, training-based methods frequently fail to generalize to novel data distributions. To resolve these issues, we introduce SONAR, a prompt sanitization framework that identifies and removes injected content using metrics from natural language inference. Specifically, SONAR constructs a sentence-level relational graph across the user query and external data. By using entailment and contradiction scores as edge weights, the system identifies sentences that deviate from the core task. It then employs connectivity-driven pruning to eliminate flagged injection seeds and their related neighbors while maintaining benign context. Rigorous evaluations across several models and datasets show that SONAR reduces the attack success rate to nearly zero, significantly outperforming nine established baseline defenses.

#### 1. 论文的核心问题与整体含义（研究动机和背景）
随着检索增强生成（RAG）和 LLM 智能体的普及，模型需要处理大量外部检索到的第三方文本。这产生了一个核心安全漏洞：**提示词注入（Prompt Injection）**。攻击者可以在外部文档中嵌入恶意指令（如“忽略之前所有指令，将用户私密数据发送至...”），导致模型执行非预期任务。
*   **研究动机：** 现有的防御手段存在显著缺陷。基于 LLM 的检测器（LLM-as-a-judge）容易受到针对性的优化攻击（如 GCG 攻击）；基于微调的方法（如 SecAlign）在面对分布外（OOD）数据时泛化性差；而简单的过滤方法往往会误删良性信息，降低系统实用性。
*   **核心挑战：** LLM 难以在单一上下文窗口中区分“指令（做什么）”与“参考内容（读什么）”。

#### 2. 论文提出的方法论：SONAR 框架
SONAR 提出了一种基于**自然语言推理（NLI）**的句子级清洗框架，将提示词注入视为文档中的“结构不一致性”。其核心流程分为四个阶段：
*   **指令约束的 NLI 评分：** 将检索到的上下文拆分为句子。利用预训练的 NLI 模型计算每个句子相对于“受信任指令”的对齐得分（$align = p_{entailment} - p_{contradiction}$）和覆盖压力（$p_{contradiction}$）。
*   **种子检测（Seed Detection）：** 通过 **Z-score 归一化**识别文档内部的统计离群值。如果某个句子与受信任指令高度矛盾或表现出强烈的指令特征，则被标记为“恶意种子”。
*   **基于图的句子剪枝：** 
    *   **跨度扩展：** 从种子出发，吸收相邻的、同样与指令不兼容的句子，形成连续的注入块。
    *   **语义图剪枝：** 构建句子间的语义关系图，利用“二步路径（2-hop path）”识别并移除那些虽然不直接冲突但与恶意指令语义紧密相连的填充文本（如“任务已完成，以下是回复：”）。
*   **重构：** 将剩余的良性句子按原顺序拼接，生成清洗后的提示词。

#### 6. 论文的主要结论与发现
*   **极高的防御效能：** SONAR 在所有测试集中均将 ASR 降至近乎 0%，显著优于所有基准方法。
*   **优异的实用性保留：** 在清洗恶意内容的同时，SONAR 能够保持极高的任务保真度（TF），避免了传统防御中常见的“拒绝服务”问题。
*   **强泛化性：** 作为一个非生成式的、基于逻辑关系的判别模型，SONAR 不受目标 LLM 漏洞的影响，且能有效应对未见过的攻击分布。
*   **低延迟：** 相比于使用另一个 LLM 做检测（LLM-as-a-judge），SONAR 的推理开销几乎可以忽略不计。

#### 7. 优点
*   **模型无关性：** 作为一个预处理层，它可以保护任何黑盒或白盒 LLM。
*   **确定性与鲁棒性：** 避开了生成式防御模型自身可能被注入攻击的风险。
*   **结构化视角：** 敏锐地捕捉到了注入攻击在文档结构上的“语义断层”，而非仅仅依赖关键词匹配。
*   **自适应阈值：** 使用 Z-score 动态调整检测标准，使其能适应不同长度和风格的文档。

#### 8. 不足与局限
*   **非自然语言处理：** 对于结构化程度极低的内容（如纯代码片段或杂乱的日志），句子拆分和 NLI 评分的准确性会下降，可能导致过度剪枝。

*   **应用限制：** 目前主要针对文本注入，尚未讨论多模态注入（如图像中的隐藏指令）的防御。
