## 摘要
技能库使大语言模型智能体能够重用过去交互中的经验，但大多数现有库将技能存储为孤立的条目，并仅通过语义相似性进行检索。这给组合性任务带来了两个关键挑战。首先，智能体不仅必须识别相关技能，还必须识别它们如何相互依赖和构建。其次，这还导致库维护困难，因为系统缺乏结构性线索来决定何时合并、拆分或移除技能。我们提出了 SKILLGRAPH，这是一个将可重用技能表示为有向图节点的框架，其中类型化边编码了前提、增强和共现关系。给定一个新任务，SKILLGRAPH 不仅检索单个技能，还检索一个有序的技能子图，该子图可以指导多步决策。该图根据智能体轨迹和强化学习反馈不断更新，从而使技能库和智能体策略能够共同提升。在 ALFWorld、WebShop 和七个搜索增强问答任务上的实验表明，SKILLGRAPH 在与记忆增强强化学习方法的对比中实现了最先进的性能，在需要组合多种技能的复杂任务上提升尤为显著。

## Abstract
Skill libraries enable large language model agents to reuse experience from past interactions, but most existing libraries store skills as isolated entries and retrieve them only by semantic similarity. This leads to two key challenges for compositional tasks. Firstly, an agent must identify not only relevant skills but also how they depend on and build upon each other. Secondly, it also makes library maintenance difficult, since the system lacks structural cues for deciding when skills should be merged, split, or removed. We propose SKILLGRAPH, a framework that represents reusable skills as nodes in a directed graph, with typed edges encoding prerequisite, enhancement, and co-occurrence relations. Given a new task, SKILLGRAPH retrieves not just individual skills, but an ordered skill subgraph that can guide multi-step decision making. The graph is continuously updated from agent trajectories and reinforcement learning feedback, allowing both the skill library and the agent policy to improve together. Experiments on ALFWorld, WebShop, and seven search-augmented QA tasks show that SKILLGRAPH achieves state-of-the-art performance against memory-augmented RL methods, with especially large gains on complex tasks that require composing multiple skills.

*   **核心问题**：现有的 LLM 智能体技能库大多是“扁平化”的，即将技能视为孤立的条目，仅通过语义相似性进行检索。
*   **研究动机**：
    *   **缺乏组合性**：复杂任务通常需要按特定顺序执行一系列技能（如“加热并放置”），扁平化检索无法提供技能间的依赖关系或执行顺序。
    *   **维护困难**：缺乏结构化线索，导致系统难以决定何时合并冗余技能、拆分宽泛技能或删除过时技能。
    *   **学习效率低**：智能体难以从过去的成功或失败中提取结构化的可重用知识。

### 2. 方法论：SKILLGRAPH 框架
SKILLGRAPH 将技能组织为有向图 $G=(V, E)$，节点为技能，边为类型化关系。
*   **核心思想**：通过构建、检索和演化结构化技能图谱，实现技能库与智能体策略的协同进化。
*   **关键技术细节**：
    1.  **图构建（Construction）**：从轨迹中蒸馏出“通用技能”和“任务特定技能”。定义三种边：**前提（Prerequisite）**、**增强（Enhance）**和**共现（Co-occur）**。
    2.  **图感知检索（Graph-Aware Retrieval）**：
        *   **种子选择**：根据任务类型选择初始节点。
        *   **图扩展**：通过广度优先搜索（BFS）进行后向扩展（找前提）和束搜索（Beam Search）进行前向扩展（找后续）。
        *   **拓扑排序**：将检索到的技能按依赖关系排序，形成有序的 Prompt 引导。
    3.  **图演化（Evolution）**：
        *   **节点级适配**：根据成功率和使用频率执行插入、合并、拆分和弃用操作。
        *   **边级适配**：通过强化学习反馈调整边权重，进行路径强化、共现发现和权重衰减/剪枝。
        *   **渐进式解锁**：根据技能等级（Level）实施课程学习，只有掌握了基础技能才解锁高级技能。
    4.  **策略优化**：使用 **GRPO（组相对策略优化）** 算法，利用轨迹奖励更新策略模型。

### 6. 主要结论与发现
*   **性能领先**：SKILLGRAPH 在所有基准测试中均达到 SOTA。使用 7B 开源模型在 ALFWorld 和 WebShop 上的表现显著超过了 GPT-4o 和 Gemini-2.5-Pro。
*   **组合任务优势**：在需要严格执行顺序的任务（如 ALFWorld 的 Clean/Heat 任务）中，图感知检索带来的提升最为巨大。
*   **泛化能力**：在 NQ 和 HotpotQA 上训练的模型能有效迁移到其他 5 个未见过的 QA 任务。
*   **效率提升**：相比扁平化检索，图检索能提供更短且更有针对性的 Prompt，降低了推理成本并减少了干扰。

### 7. 优点
*   **结构化创新**：首次将技能库从简单的 Key-Value 存储提升为具有显式依赖关系的演化图谱。
*   **闭环进化**：实现了“更丰富的轨迹 -> 更好的图谱 -> 更好的检索 -> 更强的策略”的闭环。
*   **课程学习机制**：通过拓扑等级的渐进式解锁，降低了强化学习在复杂任务中的探索难度。

### 8. 不足与局限
*   **教师模型依赖**：图演化（拆分、合并、蒸馏）高度依赖于强大的教师模型（如 o3），这增加了训练阶段的 API 调用成本。
*   **推理延迟**：虽然 Prompt 变短了，但检索阶段涉及多次图遍历和排序，可能增加系统复杂性。
*   **跨环境迁移**：目前的实验主要在单一环境内演化，尚未深入探讨一个环境学到的技能图谱如何直接“嫁接”到完全不同的新环境中。
