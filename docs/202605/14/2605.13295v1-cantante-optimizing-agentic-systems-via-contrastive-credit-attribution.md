## 摘要
基于大语言模型（LLM）的多智能体系统在软件工程、预测建模和检索增强生成等复杂现实任务中表现出强大的性能。然而，自动化配置这些系统仍然是一个结构性挑战，因为评分仅在系统层面可用，而控制智能体行为的参数却是局部的。我们认为，优化这些系统本质上是一个信用分配问题。因此，我们提出了 CANTANTE，这是一个通过对比同一查询下多个联合配置的运行结果，将系统级奖励分解为每个智能体更新信号的框架。我们将其应用于提示词优化，将智能体提示词视为可学习的系统参数。我们在编程（MBPP）、数学推理（GSM8K）和多跳问答（HotpotQA）任务上，将 CANTANTE 与 GEPA 和 MIPROv2 进行了对比评估。在这些基准测试中，CANTANTE 在所有评估的优化器中获得了最佳平均排名，并始终优于未优化的提示词。与最强的基准模型相比，它在 MBPP 上提高了 18.9 个百分点，在 GSM8K 上提高了 12.5 个百分点，同时推理成本更低。在 HotpotQA 上，它的表现与最强基准模型保持在一个标准差范围内。至关重要的是，我们的信用相关性分析证实，归因器产生了有意义的单智能体信号，而非仅仅重复全局系统评分。

## Abstract
LLM-based multi-agent systems have demonstrated strong performance across complex real-world tasks, such as software engineering, predictive modeling, and retrieval-augmented generation. Yet automating their configuration remains a structural challenge, as scores are available only at the system level, whereas the parameters governing agent behavior are local. We argue that optimizing these systems is fundamentally a credit-assignment problem. We therefore introduce CANTANTE, a framework that decomposes system-level rewards into per-agent update signals by contrasting rollouts of multiple joint configurations on the same query. We instantiate it for prompt optimization, treating agent prompts as learnable system parameters. We evaluate CANTANTE against GEPA and MIPROv2 on programming (MBPP), mathematical reasoning (GSM8K), and multi-hop question answering (HotpotQA). Across these benchmarks, CANTANTE achieves the best average rank among all evaluated optimizers and consistently outperforms unoptimized prompts. It improves over the strongest baseline by +18.9 percentage points on MBPP and +12.5 percentage points on GSM8K, while incurring a lower inference cost. It remains within one standard deviation of the strongest baseline on HotpotQA. Crucially, our credit correlation analysis confirms that the attributer produces meaningful per-agent signals rather than echoing the global system score.

### 1. 核心问题与整体含义（研究动机和背景）
论文关注的核心问题是**大语言模型多智能体系统（MAS）的自动化配置优化**。
*   **研究动机**：虽然 MAS 在复杂任务中表现优异，但其配置（如各智能体的提示词、角色分配等）通常依赖繁琐的人工调优。
*   **核心挑战（信用分配难题）**：MAS 优化存在“结构性失配”——评估反馈是**全局性**的（整个工作流输出的一个标量分数），而需要优化的参数是**局部性**的（单个智能体的提示词）。例如，如果代码运行错误，很难直接判断是“计划者”的逻辑错了，还是“编写者”的代码写错了。
*   **整体含义**：论文将 MAS 优化定义为一个**信用分配问题（Credit Assignment Problem）**，旨在将全局奖励分解为针对每个智能体的特定更新信号。

### 2. 核心方法论：CANTANTE 框架
CANTANTE（Contrastive Attribution for Tuning of Multi-Agent Systems）通过**对比组内归因**使 MAS 变得可学习。

*   **核心思想**：通过在同一个查询（Query）下对比多个不同配置组合的运行轨迹（Rollouts），利用一个“归因 LLM”来识别每个智能体对最终结果的贡献。
*   **关键技术流程**：
    1.  **候选生成**：每个智能体的局部优化器（如 CAPO）提出 $K$ 个候选参数（提示词）。
    2.  **联合评估**：将这些候选参数组合成 $K$ 个系统配置，在任务数据集上运行，获得全局得分和执行轨迹（Trace）。
    3.  **对比归因**：归因器（一个高能力的 LLM）接收同一查询下的多组轨迹和得分，通过对比分析，为每个智能体在每组运行中分配一个信用值 $c \in [-1, +1]$。
    4.  **局部更新**：将分配到的信用值反馈给各智能体的局部优化器，进行下一轮迭代。
*   **优势**：即使不同配置的全局得分相同，归因器也可以通过分析中间推理轨迹的质量差异来提供细粒度的反馈信号，避免优化停滞。

### 6. 主要结论与发现
*   **性能领先**：CANTANTE 在所有基准测试中获得了最佳平均排名。在 MBPP 上比最强基准提升 **18.9%**，在 GSM8K 上提升 **12.5%**。
*   **推理效率**：在提升准确率的同时，CANTANTE 优化出的提示词在 MBPP 和 GSM8K 上的推理 Token 消耗反而比初始提示词更低，实现了“更强且更快”。
*   **稳定性**：相比基准方法，CANTANTE 在不同种子间的方差更小，表现出更稳定的优化轨迹。
*   **归因有效性**：分析显示，验证者（Validator）和阅读者（Reader）等关键节点获得的信用信号与系统表现相关性最高，符合直觉。

### 7. 优点
*   **解耦设计**：归因机制与具体的局部优化算法解耦，具有极强的通用性。
*   **解决冷启动**：通过对比机制，在低数据量（如仅 75 个样本）下依然能提取有效的学习信号。
*   **诊断功能**：信用相关性分析可以作为 MAS 拓扑设计的诊断工具，识别哪些智能体是性能瓶颈。

### 8. 不足与局限
*   **拓扑固定**：目前仅优化参数（提示词），不涉及工作流拓扑结构（节点和边）的动态调整。
*   **归因器依赖**：优化的上限受限于归因器 LLM 的能力。如果归因器不如任务智能体聪明，可能会提供错误的指导。
*   **可扩展性风险**：随着智能体数量增加，归因器需要处理的轨迹长度会呈指数增长，可能超出 LLM 的上下文窗口或导致信息过载。
*   **额外开销**：引入归因 LLM 会消耗额外的优化预算（Token）。
