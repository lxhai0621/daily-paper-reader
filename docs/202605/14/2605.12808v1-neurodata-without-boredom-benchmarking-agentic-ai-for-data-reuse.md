## 摘要
神经科学数据在实验室、格式和实验范式之间高度碎片化，重用通常需要大量的体力劳动。数据重用和整合的一个持久障碍是需要解读定制且多样化的数据格式选择。尽管已经提出了通用的数据格式，但该领域仍面临一个根本性的矛盾：足够灵活以适应各种实验的格式往往描述性不足，无法自解释；而描述性足够强的格式则需要详细的文档和整理工作，很少有实验室能够维持。智能体 AI（Agentic AI）是解决这一问题的理想选择：大语言模型（LLMs）阅读代码和文本的速度更快，并且能够持续关注人类往往会略过的底层细节。为了衡量智能体 AI 在此任务上的表现，我们选择了八篇近期研究大规模小鼠神经群体记录的论文，这些论文均共享了数据和代码，涵盖了多种记录模态、行为范式和数据集格式（例如 NWB、专用 API 以及通用的 Python 或 MATLAB 文件）。我们为智能体提供了数据、代码和论文，并提示它们加载、理解并重新格式化数据，以完成一个常见的下游任务：训练一个从神经活动到任务或行为变量的解码器。科学家常用的通用编程智能体在每个子任务上表现良好，但很少能串联出一个完全无误的端到端解决方案。我们刻画了智能体所犯错误的类型以及引发这些错误的数据集属性，并提出了智能体 AI 时代的数据共享最佳实践。我们进一步发现，作为评判者的智能体在捕捉错误方面并不可靠，尤其是在没有基准参考的情况下，因此交互式的、人在回路（human-in-the-loop）的编程仍然是必要的。

## Abstract
Neuroscience data are highly fragmented across labs, formats, and experimental paradigms, and reuse often requires substantial manual effort. A persistent roadblock to data reuse and integration is the need to decipher bespoke and diverse data formatting choices. Common data formats have been proposed in response, but the field continues to struggle with a fundamental tension: formats flexible enough to accommodate diverse experiments are rarely descriptive enough to be self-explanatory, and sufficiently descriptive formats demand detailed documentation and curation effort that few labs can sustain. Agentic AI is a natural candidate to solve this problem: LLMs read code and text faster and with sustained attention to the low-level details humans tend to skim over. To measure how well agentic AI performs on this task, we selected eight recent papers studying large-scale mouse neural population recordings that shared both data and code, spanning diverse recording modalities, behavioral paradigms, and dataset formats (e.g., NWB, specialized APIs, and general-purpose Python or MATLAB files). We provided agents with the data, code, and paper, and prompted them to load, understand, and reformat the data for a common downstream task: training a decoder from neural activity to task or behavioral variables. General-purpose coding agents commonly used by scientists performed well on each sub-task, but rarely strung together a fully error-free end-to-end solution. We characterize the types of mistakes agents made and the dataset properties that elicited them, and propose data-sharing best practices for the agentic-AI era. We further find that agents-as-judges are unreliable at catching errors, especially without ground-truth references, so interactive, human-in-the-loop coding remains necessary.

*   **研究背景**：神经科学实验数据具有极高的异构性（涵盖电生理、钙成像、多种行为范式等），且格式碎片化严重。尽管有 NWB 等标准格式，但由于实验设计的复杂性，数据字段的语义往往仍需查阅论文和原始代码才能理解。
*   **核心问题**：数据重用（Data Reuse）目前高度依赖人工，耗时且枯燥。本研究旨在评估当前的编程智能体（Agentic AI）能否通过阅读论文、理解代码和检查原始数据，自动完成数据的清洗、对齐和标准化重构。

### 2. 论文提出的方法论
*   **核心思想**：将数据重用任务转化为一个受控的编程智能体基准测试。要求智能体在给定参考资料的情况下，将异构的原始数据转换为统一的、可用于下游机器学习解码任务的格式。
*   **关键流程**：
    1.  **输入提供**：为智能体提供论文 PDF、方法论摘要、作者发布的原始分析代码、原始数据集以及预装了神经科学专用库（如 `PyNWB`, `AllenSDK`）的容器环境。
    2.  **结构化提示（Prompting）**：设计了包含 14 个步骤的详细工作流，强制智能体执行“创建笔记 -> 探索代码 -> 检查一致性 -> 制定计划 -> 小样验证 -> 全量转换 -> 自我审查”的流程。
    3.  **统一输出结构**：要求智能体输出一个包含神经活动矩阵、输入/输出变量、元数据的特定 Python 字典结构。
    4.  **下游验证**：使用研究者提供的统一线性解码器代码，在转换后的数据上训练，以验证数据的科学有效性。

### 3. 实验设计
*   **数据集与场景**：选取了 8 篇近期发表的大规模小鼠神经群体记录论文。
    *   **多样性**：涵盖了 NWB 格式、专用 API（如 IBL, Allen）以及自定义的 Matlab/Python 文件。
    *   **任务类型**：包括虚拟现实导航、视觉决策、自由运动行为等。
*   **Benchmark 设置**：
    *   **监督组（4个）**：由人类专家编写参考转换代码，作为金标准。
    *   **无监督组（4个）**：无专家代码，通过智能体间的一致性和论文描述进行评估。
*   **对比方法**：评估了两个主流的编程智能体：**Claude Code (Opus 4.6)** 和 **Codex (GPT 5.4)**。

### 4. 资源与算力
*   **硬件配置**：每个实验运行分配 1 个 GPU（显存 ≥ 24 GB），系统内存 ≥ 320 GB。
*   **时间限制**：每个任务的运行上限为 24 小时。
*   **模型调用**：使用了 Harbor 智能体评估框架进行自动化部署和调用。

### 5. 实验数量与充分性
*   **实验规模**：共 8 个数据集，每个智能体针对每个数据集重复运行 3 次，总计 48 组端到端实验。
*   **评估深度**：
    *   **结果评估**：对比神经元数量、试次数量、解码准确率等硬指标。
    *   **过程评估**：由人类专家根据 169 个子问题（涵盖加载、处理、对齐、效率等）进行盲审评分。
*   **充分性评价**：实验设计较为客观、公平。通过多次重复实验揭示了智能体表现的随机性，并引入了“智能体作为评审员（Agent-as-judge）”的对比实验，验证了自动评估的局限性。

### 6. 主要结论与发现
*   **子任务强，端到端弱**：智能体在单个步骤（如写加载代码）上表现出色，但很难在长链条任务中保持完全无误，端到端成功率极低。
*   **错误类型深层化**：大部分失败并非因为代码无法运行，而是源于**科学解释错误**（如：错误理解变量的正负号含义、使用了不恰当的过滤阈值、时间对齐时忽略了丢帧补偿）。
*   **AI 评审不可靠**：在没有专家参考答案的情况下，AI 智能体无法准确识别自己或他人代码中的细微科学错误，其评估准确率仅略高于随机。
*   **API 偏好**：尽管预装了专用 API，智能体往往倾向于直接处理原始文件（如 `.npy` 或 `.mat`），而非使用更规范但复杂的官方 SDK。

### 7. 优点
*   **高度真实性**：不同于以往的合成代码基准，本研究直接挑战了科研中最真实、最杂乱的数据重用场景。
*   **多维度评估**：结合了下游任务性能（结果）和专家代码审查（过程），能够捕捉到那些“虽然能跑通但科学上错误”的隐蔽问题。
*   **实践指导性**：为未来的数据共享提供了具体建议，强调了“可执行参考代码”对 AI 辅助科研的重要性。

### 8. 不足与局限
*   **样本量较小**：仅测试了 8 个数据集，且全部集中在小鼠神经科学领域，结论的普适性有待在其他学科验证。
*   **模型局限**：仅测试了两个特定版本的模型，未涵盖更多开源模型或最新迭代版本。
*   **人工依赖**：过程评估（Rubric-based scoring）仍高度依赖专家手动评分，难以实现完全自动化的基准测试。
