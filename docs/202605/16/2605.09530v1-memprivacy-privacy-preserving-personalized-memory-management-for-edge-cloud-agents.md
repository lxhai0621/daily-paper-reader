## 摘要
随着基于大语言模型（LLM）的智能体越来越多地部署在边云环境中，个性化记忆已成为实现长期适应和以用户为中心交互的关键驱动力。然而，云辅助的记忆管理会暴露敏感的用户信息，而现有的隐私保护方法通常依赖于激进的掩码处理，这会移除与任务相关的语义，从而降低记忆效用和个性化质量。为了应对这一挑战，我们提出了 MemPrivacy，它在边缘设备上识别隐私敏感片段，将其替换为语义结构化的类型感知占位符以进行云端记忆处理，并在需要时在本地恢复原始值。通过将隐私保护与语义破坏解耦，MemPrivacy 在最大限度减少敏感数据暴露的同时，保留了有效记忆形成和检索所需的信息。我们还构建了用于系统评估的 MemPrivacy-Bench，这是一个涵盖 200 个用户和超过 5.2 万个隐私实例的数据集，并引入了四级隐私分类法以实现可配置的保护策略。实验表明，MemPrivacy 在隐私信息提取方面表现强劲，大幅超越了 GPT-5.2 和 Gemini-3.1-Pro 等强大的通用模型，同时还降低了推理延迟。在多个广泛使用的记忆系统中，MemPrivacy 将效用损失限制在 1.6% 以内，优于基准掩码策略。总的来说，MemPrivacy 在隐私保护和边云智能体的个性化记忆效用之间实现了有效的平衡，实现了安全、实用且对用户透明的部署。

## Abstract
As LLM-powered agents are increasingly deployed in edge-cloud environments, personalized memory has become a key enabler of long-term adaptation and user-centric interaction. However, cloud-assisted memory management exposes sensitive user information, while existing privacy protection methods typically rely on aggressive masking that removes task-relevant semantics and consequently degrades memory utility and personalization quality. To address this challenge, We propose MemPrivacy, which identifies privacy-sensitive spans on edge devices, replaces them with semantically structured type-aware placeholders for cloud-side memory processing, and restores the original values locally when needed. By decoupling privacy protection from semantic destruction, MemPrivacy minimizes sensitive data exposure while retaining the information required for effective memory formation and retrieval. We also construct MemPrivacy-Bench for systematic evaluation, a dataset covering 200 users and over 52k privacy instances, and introduce a four-level privacy taxonomy for configurable protection policies. Experiments show that MemPrivacy achieves strong performance in privacy information extraction, substantially surpassing strong general-purpose models such as GPT-5.2 and Gemini-3.1-Pro, while also reducing inference latency. Across multiple widely used memory systems, MemPrivacy limits utility loss to within 1.6%, outperforming baseline masking strategies. Overall, MemPrivacy offers an effective balance between privacy protection and personalized memory utility for edge-cloud agents, enabling secure, practical, and user-transparent deployment.

*   **研究背景**：随着大语言模型（LLM）驱动的智能体（Agents）在边云协同环境中的普及，个性化记忆（Personalized Memory）成为提升用户体验的关键。
*   **核心矛盾**：
    *   **隐私泄露**：云端存储和处理用户记忆会暴露敏感的个人身份信息（PII），如健康、财务、凭证等。
    *   **效用损失**：现有的隐私保护手段（如全掩码或脱敏）往往会破坏文本的语义结构，导致智能体无法准确检索记忆或进行逻辑推理，从而严重降低个性化服务的质量。
*   **研究目标**：在最小化敏感数据暴露的同时，保留云端智能体进行记忆形成、检索和推理所需的语义信息。

### 2. 方法论：MemPrivacy 框架
MemPrivacy 采用**本地可逆伪名化（Local Reversible Pseudonymization）**的核心思想，分为三个阶段：
*   **阶段 1：上行脱敏（Uplink Desensitization）**
    *   在边缘设备上运行轻量化模型，识别隐私片段（Spans）。
    *   **四级隐私分类法（PL1-PL4）**：将信息分为 PL1（偏好/公开）、PL2（可识别 PII）、PL3（高敏感 PII）、PL4（凭证/机密）。
    *   **类型感知占位符**：将敏感词替换为带语义标签的占位符（如 `<Email_1>`），并在本地安全数据库中存储“占位符-原始值”的映射。
*   **阶段 2：云端处理（Cloud Processing）**
    *   云端智能体接收带有占位符的文本。由于占位符保留了语义角色（知道这是一个邮箱，但不知道具体是谁的），云端仍能进行有效的记忆存储和逻辑推理。
*   **阶段 3：下行还原（Downlink Restoration）**
    *   云端返回包含占位符的响应，边缘设备通过本地数据库查找并替换回原始值，实现对用户透明的个性化交互。
*   **训练技术**：模型训练分为两阶段：首先在 26k 实例上进行**监督微调（SFT）**，随后使用**组相对策略优化（GRPO）**进行强化学习，以提升隐私提取的精确度。

### 3. 实验设计
*   **数据集与场景**：
    *   **MemPrivacy-Bench**：自建基准，涵盖 200 个用户、5.2 万个隐私实例，包含 7 大类、23 小类对话场景。
    *   **PersonaMem-v2**：用于测试模型的分布外（OOD）泛化能力。
*   **对比方法**：

*   **测试床（Testbeds）**：在 LangMem、Mem0 和 Memobase 三种主流记忆系统上验证效用保持情况。

### 4. 资源与算力
*   **硬件环境**：实验在一台配备 **8 张 NVIDIA A800-80GB GPU** 的节点上完成。
*   **训练细节**：

*   **推理效率**：轻量化模型（0.6B-4B）在 A800 上处理单条消息的延迟通常在 **1-2 秒**内，远快于大型推理模型。

### 5. 实验数量与充分性
*   **实验规模**：
    *   对比了超过 10 种主流 LLM 的隐私提取能力。
    *   在 3 种不同的记忆系统架构上进行了端到端效用测试。
    *   进行了不同隐私比例（0%-100%）的鲁棒性分析。
*   **充分性评价**：实验设计较为充分。不仅关注了隐私提取的 F1 分数，还通过 BLEU、ROUGE 和 LLM-as-a-Judge 等多维指标评估了下游任务的效用。引入 OOD 数据集（PersonaMem-v2）增强了结果的说服力。

### 6. 主要结论与发现
*   **提取性能强**：MemPrivacy 专用模型（即使是 0.6B 版本）在隐私提取任务上显著优于 GPT-5.2 和 Gemini-3.1-Pro。
*   **效用损失极低**：在完全保护 PL2-PL4 信息的情况下，记忆系统的准确性下降控制在 **1.6%** 以内，而传统的不可逆掩码会导致性能下降超过 20%-40%。
*   **隐私-效用平衡**：通过类型感知占位符，云端模型能够理解“谁在对谁做什么”，从而在不接触原始数据的情况下维持逻辑连贯性。

### 7. 优点与亮点
*   **闭环设计**：通过“本地脱敏-云端推理-本地还原”实现了端到端的隐私隔离。
*   **语义保留**：不同于简单的脱敏，类型感知占位符解决了隐私保护与语义理解之间的长期冲突。
*   **高质量基准**：MemPrivacy-Bench 填补了智能体记忆领域缺乏细粒度隐私评估数据的空白。
*   **轻量化部署**：模型规模小（最低 0.6B），适合在手机、PC 等边缘设备上实机运行。

### 8. 不足与局限
*   **合成数据偏差**：MemPrivacy-Bench 主要基于 PersonaHub 合成，可能与真实世界中极其复杂、隐晦的隐私表达存在差异。
*   **上下文重识别风险**：虽然隐藏了具体值，但如果上下文信息过于独特，理论上仍存在通过背景知识进行重识别（Re-identification）的极低风险。
*   **多模态缺失**：目前研究仅限于文本，尚未涉及语音、图像等智能体常见的其他模态隐私保护。
