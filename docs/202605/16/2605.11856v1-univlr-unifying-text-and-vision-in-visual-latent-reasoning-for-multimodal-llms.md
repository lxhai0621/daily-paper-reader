## 摘要
多模态大语言模型（MLLMs）正日益被期望具备结合图像进行思考的能力，然而现有的视觉潜空间推理方法仍依赖于显式的文本思维链（CoT）与视觉潜空间标记（visual latent tokens）的交织。这种交织设计限制了效率，并使推理过程在独立的文本和视觉通道中保持碎片化。我们提出了 UniVLR，这是一个统一的视觉潜空间推理框架，它将文本推理和辅助视觉证据视为一个共享的视觉工作空间。UniVLR 不再将文本 CoT 保留为独立的推理路径，而是将推理轨迹与辅助图像共同渲染，并学习将这种统一表示压缩为紧凑的视觉潜空间标记。在推理阶段，模型仅通过视觉潜空间进行推理并直接解码最终答案，从而避免了外部工具调用和冗长的文本推理。在真实世界感知和视觉推理任务上的实验表明，UniVLR 在使用显著更少的生成推理标记的情况下，性能优于先前的视觉潜空间推理方法，这为 MLLMs 中的视觉思考提供了一种更统一、更高效的范式。

## Abstract
Multimodal large language models are increasingly expected to perform thinking with images, yet existing visual latent reasoning methods still rely on explicit textual chain-of-thought interleaved with visual latent tokens. This interleaved design limits efficiency and keeps reasoning fragmented across separate text and vision channels. We propose UniVLR, a unified visual latent reasoning framework that treats textual reasoning and auxiliary visual evidence as a shared visual workspace. Instead of preserving text CoT as an independent inference-time path, UniVLR renders reasoning traces together with auxiliary images and learns to compress this unified representation into compact visual latent tokens. At inference time, the model reasons only through visual latents and directly decodes the final answer, avoiding both external tool calls and verbose text reasoning. Experiments on real-world perception and visual reasoning tasks show that UniVLR outperforms prior visual latent reasoning methods while using substantially fewer generated reasoning tokens, suggesting a more unified and efficient paradigm for visual thinking in MLLMs.

在处理复杂的视觉感知任务（如几何解题、图表分析）时，多模态大模型（MLLM）通常需要“结合图像思考”。现有的视觉潜空间推理方法虽然尝试在连续向量空间中进行推理，但大多采用**交替设计**：即显式的文本思维链（CoT）与视觉潜变量标记（Latent Tokens）交替生成。
*   **研究动机**：这种交替设计存在两个缺陷：一是**效率低下**，仍需生成大量冗长的文本 Token；二是**推理碎片化**，模型往往依赖附近的文本而忽视了早期的辅助图像证据，导致视觉信息整合不足。
*   **核心目标**：提出一种统一的范式，将文本推理轨迹和辅助视觉证据融合在同一个视觉空间内，实现更高效、更连贯的“视觉思维”。

#### 2. 方法论：核心思想与技术细节
UniVLR 的核心思想是**将文本推理过程“视觉化”**，将其与辅助图像共同渲染在同一块画布上，并训练模型通过视觉潜变量来表征这一统一的推理过程。

*   **统一视觉画布渲染（Unified Visual Canvas Rendering）**：
    *   定义渲染函数 $\Phi(R, U)$，将文本推理步骤 $R$ 和辅助图像 $U$（如裁剪图、标注图）组合成一张统一的视觉画布。
    *   利用视觉编码器提取特征，并通过**长宽比感知的 2D 池化**将其压缩为固定长度 $K$ 的目标潜变量序列。
*   **两阶段潜空间对齐（Two-stage Alignment）**：
    *   **阶段 I：视觉潜空间接地（Grounding）**：使用辅助图像作为对齐目标，让模型学会生成具有语义意义的连续视觉标记。
    *   **阶段 II：文本-视觉统一对齐**：将渲染后的“文本+图像”画布作为目标，训练模型将整个推理逻辑压缩进视觉潜变量中。
*   **推理流程**：
    *   在推理时，模型不再生成中间文本，而是直接生成 $K$ 个视觉潜变量（连续向量），随后直接解码出最终答案。这种方式避免了外部工具调用和冗长的文本输出。

#### 7. 优点（亮点）
*   **范式创新**：打破了“文本思维链”的固有思维，利用 MLLM 强大的 OCR 和布局理解能力，将文本推理转化为视觉信号。

#### 8. 不足与局限
*   **可解释性挑战**：虽然潜变量高效，但它不像文本 CoT 那样直观，人类难以直接“阅读”模型的中间思考过程。

*   **固定预算限制**：目前使用固定的潜变量数量（如 K=12），而不同难度的任务可能需要动态调整推理步数。
