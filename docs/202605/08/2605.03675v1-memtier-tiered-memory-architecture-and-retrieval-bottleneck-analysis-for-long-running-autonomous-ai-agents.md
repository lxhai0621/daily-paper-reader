## 摘要
长期运行的自主 AI 智能体面临着一个已被广泛记录的记忆一致性问题：由于现有扁平文件记忆系统中的四种复合故障模式，在 72 小时的运行窗口内，工具执行成功率下降了 14 个百分点。我们提出了 MEMTIER，这是一种用于 OpenClaw 智能体运行时的三元记忆架构，它引入了结构化的情境 JSONL 存储、五信号加权检索引擎、注意力归因的认知权重更新循环、将情境事实提升到语义层的异步整合守护进程，以及用于调整检索权重的基于 PPO 的策略框架（基础设施已验证；性能提升待定）。在包含 500 个问题的完整 LongMemEval-S 基准测试（Wu 等人，2025）中，MEMTIER 在消费级 6GB GPU 上使用 Qwen2.5-7B 实现了 Acc=0.382 和 F1=0.412，相比全上下文基线（0.050 -> 0.382，即 5% -> 38%）提升了 33 个百分点。通过 DeepSeek-V4-Flash 事实预填充，单会话召回率达到 0.686-0.714，在这些类别上超过了论文中 RAG BM25 GPT-4o 的基线（0.560）。时间推理能力提升至 0.323，多会话综合能力提升至 0.173，证明了结构化语义预填充从定性上改变了轻量级检索所能达到的效果。所有阶段均在配备 6GB GPU 的消费级笔记本电脑上本地运行。

## Abstract
Long-running autonomous AI agents suffer from a well-documented memory coherence problem: tool-execution success rates degrade 14 percentage points over 72-hour operation windows due to four compounding failure modes in existing flat-file memory systems. We present MEMTIER, a tripartite memory architecture for the OpenClaw agent runtime that introduces a structured episodic JSONL store, a five-signal weighted retrieval engine, an attention-attributed cognitive weight update loop, an asynchronous consolidation daemon promoting episodic facts to a semantic tier, and a PPO-based policy framework for adapting retrieval weights (infrastructure validated; performance gains pending camera-ready). On the full 500-question LongMemEval-S benchmark (Wu et al., 2025), MEMTIER achieves Acc=0.382, F1=0.412 with Qwen2.5-7B on a consumer 6GB GPU - a +33 percentage point improvement over the full-context baseline (0.050 -> 0.382, i.e., 5% -> 38%). With DeepSeek-V4-Flash fact pre-population, single-session recall reaches 0.686-0.714, exceeding the paper's RAG BM25 GPT-4o baseline (0.560) on those categories. Temporal reasoning rises to 0.323 and multi-session synthesis to 0.173, demonstrating that structured semantic pre-population qualitatively changes what lightweight retrieval can achieve. All phases run locally on a consumer laptop with a 6GB GPU.

### 2. 方法论：MEMTIER 架构
MEMTIER 采用三元记忆架构，通过五个阶段实现：
*   **结构化情节存储 (Phase 1a)**：使用 JSONL 格式存储情节记忆，包含时间戳、项目隔离标签和**认知权重 (Cognitive Weight, CW)**。
*   **五信号加权检索引擎 (Phase 1b)**：检索评分综合了五个维度：
    1.  **BM25**：词法匹配得分。
    2.  **时间衰减**：指数级衰减，优先考虑近期记忆。
    3.  **认知权重**：基于历史表现的质量评分。
    4.  **层级提升 (Tier Boost)**：语义层记忆获得额外权重。
    5.  **两阶段范围限定**：先确定相关会话，再在会话内检索。
*   **注意力归因循环 (Phase 1c)**：根据工具执行结果更新记忆条目的 CW。成功则增加权重，失败则减少。
*   **异步整合守护进程 (Phase 2a)**：利用 LLM（如 DeepSeek）将情节记忆中的事实提取并蒸馏到“语义层”，实现跨智能体知识共享。
*   **基于 PPO 的策略框架 (Phase 2b)**：使用强化学习（近端策略优化）动态调整检索信号的权重向量 $w$。

### 6. 主要结论与发现
*   **性能提升**：在 LongMemEval-S 上，MEMTIER 将 7B 模型的准确率从 5% 提升至 **38.2%**，在单会话召回上甚至超过了 GPT-4o 的 RAG 基线。
*   **三层不变性发现**：研究发现，当使用 BM25 检索架构时，无论是更换更强大的生成模型，还是通过 PPO 微调权重，性能都会遇到瓶颈。这证明了**检索架构本身（而非模型大小或权重）是当前长程记忆的主要瓶颈**。

### 7. 优点
*   **轻量化与实用性**：证明了在消费级硬件上也能实现高性能的长程记忆管理。
*   **闭环学习**：引入认知权重和 RL 优化，使记忆系统具有“自我进化”的能力。
*   **架构洞察**：提出了“三层不变性”，为未来研究指明了方向（即需要从词法检索转向更深层的稠密检索或混合检索）。

### 8. 不足与局限
*   **检索瓶颈**：线性组合的 BM25 评分容易掩盖 RL 带来的边际收益。

*   **多会话综合能力仍弱**：虽然有提升，但在需要跨多个会话综合信息的任务上（0.180），性能仍有待加强。
