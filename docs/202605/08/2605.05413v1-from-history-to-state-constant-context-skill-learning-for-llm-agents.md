## 摘要
大语言模型（LLM）智能体越来越多地被用于操作浏览器、文件、代码和工具，使得个人助手成为一个自然的部署目标。然而，个人智能体面临着隐私-成本-能力的张力：云端模型能很好地执行多步工作流，但会将敏感的中间上下文暴露给外部 API；而本地模型虽然保护了隐私，但可靠性较低。此外，这两种设置都需要为冗长的技能提示词和不断增长的历史记录重复付费。我们提出了恒定上下文技能学习（constant-context skill learning），这是一种针对循环智能体工作流的“上下文到权重”（context-to-weights）框架：可重用的程序在轻量级的任务族模块中学习，而推理仅以当前观测和紧凑的状态块为条件。一个确定性追踪器根据任务进度渲染该状态块，并提供对齐的子目标奖励，因此每个模块都可以通过步级有监督微调（SFT）进行训练，并通过在线强化学习（RL）进行优化。在 ALFWorld、WebShop 和 SciWorld 任务中，我们的智能体在 Qwen3-4B、Qwen3-8B 和 Llama-3.1-8B 上均取得了强劲表现。使用 Qwen3-8B 时，SFT+RL 在 ALFWorld 上的未见任务成功率达到 89.6%，在 WebShop 上达到 76.8%，在 SciWorld 上的未见任务成功率达到 66.4%。它们达到或超过了已发表的强力智能体训练结果，同时相对于受控的 ReAct 提示词基线，每轮提示词 Token 减少了 2 到 7 倍，这表明程序性上下文可以从提示词转移到权重中。

## Abstract
Large language model (LLM) agents are increasingly used to operate browsers, files, code and tools, making personal assistants a natural deployment target. Yet personal agents face a privacy-cost-capability tension: cloud models execute multi-step workflows well but expose sensitive intermediate context to external APIs, while local models preserve privacy but remain less reliable. Both settings also pay repeatedly for long skill prompts and growing histories. We propose constant-context skill learning, a context-to-weights framework for recurring agent workflows: reusable procedures are learned in lightweight task-family modules, while inference conditions only on the current observation and a compact state block. A deterministic tracker renders this state block from task progress and supplies aligned subgoal rewards, so each module can be trained with step-level SFT and refined through online RL. Across ALFWorld, WebShop, and SciWorld, our agents achieve strong performance across Qwen3-4B, Qwen3-8B and Llama-3.1-8B. With Qwen3-8B, SFT+RL reaches 89.6\% unseen success on ALFWorld, 76.8\% success on WebShop, and 66.4\% unseen success on SciWorld. They match or exceed strong published agent-training results while reducing prompt tokens per turn by 2--7$\times$ relative to controlled ReAct prompting baselines, showing that procedural context can be moved from prompts into weights.

这篇论文提出了一种名为“恒定上下文技能学习”（Constant-Context Skill Learning）的框架，旨在解决大语言模型（LLM）智能体在实际应用中面临的效率与性能瓶颈。以下是对该论文的深度结构化总结：

### 1. 核心问题与研究动机
*   **核心问题**：当前的 LLM 智能体（如个人助手）在处理多步任务时，通常依赖于将冗长的技能说明和不断增长的执行历史放入提示词（Prompt）中。这导致了三个主要问题：
    *   **隐私风险**：将敏感的中间上下文发送到云端 API 会泄露隐私。
    *   **高昂成本**：Token 数量随步骤增加而激增，导致推理成本和延迟上升。
    *   **能力局限**：本地小模型在处理长上下文和复杂逻辑时可靠性较低。
*   **研究动机**：对于重复性的工作流（如购物、文件管理），智能体不应每次都重新阅读操作手册，而应将这些“程序性知识”内化到模型权重中，从而实现高效、隐私且低成本的本地部署。

### 2. 方法论：从历史到状态（Context-to-Weights）
该框架的核心思想是将“程序性上下文”从提示词转移到轻量级的模型权重中，其流程分为三个阶段：
*   **确定性状态追踪器（Deterministic Tracker）**：
    *   不使用 LLM 进行总结，而是利用简单的环境规则编写追踪器。
    *   它将原始交互历史压缩为一个紧凑的**状态块（State Block）**，包含当前子目标、已获取实体、已检查位置等关键变量。
*   **步级有监督微调（SFT）**：
    *   针对特定的任务族（Task Family），使用专家轨迹进行训练。
    *   模型输入仅包含：当前观察、上一步动作、以及追踪器生成的紧凑状态块。这使得输入长度不随任务步数增长。
*   **子目标引导的强化学习（RL）**：
    *   使用 **GRPO** 风格的算法进行在线优化。
    *   **关键技术**：利用追踪器状态自动生成“子目标奖励”，无需在 RL 过程中调用昂贵的 LLM 作为裁判。奖励函数结合了环境得分、进度奖励（如完成子目标）和错误惩罚（如无效动作）。

*   **数据集/场景**：

    *   **SciWorld**：复杂的科学实验任务，具有长时程和多步骤特点。
*   **基准测试（Benchmark）**：

*   **实验规模**：涵盖了 3 个主流基准测试，使用了 3 种不同规模和家族的底座模型，并区分了“已见（Seen）”和“未见（Unseen）”任务场景。
*   **消融实验**：非常充分。作者分别验证了状态块、SFT、RL 奖励设计以及专家轨迹数量对性能的影响。

### 6. 主要结论与发现
*   **性能卓越**：在 Qwen3-8B 上，SFT+RL 在 ALFWorld 未见任务上达到 89.6% 的成功率，在 SciWorld 上达到 66.4%，匹配或超过了现有的 SOTA 训练方法。

### 7. 优点
*   **推理效率极高**：恒定的上下文长度解决了 LLM 智能体随步骤增加而变慢、变贵的痛点。
*   **模块化设计**：通过 LoRA 适配器为不同任务族训练独立模块，避免了灾难性遗忘，且易于扩展新技能。

### 8. 不足与局限
*   **人工设计成本**：状态追踪器和奖励规则需要针对每个任务族进行预定义。虽然文中使用了 GPT-5.5 辅助生成规则，但仍需人工校验。
*   **模态限制**：目前仅在文本模式（Text-mode）环境下验证，尚未扩展到 GUI 或多模态视觉智能体。
*   **零样本迁移**：由于技能被固化在特定模块中，该方法不支持对全新任务族的零样本（Zero-shot）迁移，必须先进行微调。
