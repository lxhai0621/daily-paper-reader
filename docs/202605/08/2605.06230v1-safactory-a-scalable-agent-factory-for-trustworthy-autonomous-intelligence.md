## 摘要
随着大模型从对话助手演变为自主智能体，长程决策、工具使用以及真实环境交互带来的挑战日益增多。现有的智能体基础设施在评估、数据管理和智能体演化方面仍然处于碎片化状态，导致难以系统地发现风险并在持续的闭环中改进模型。在本报告中，我们提出了 Safactory，这是一个面向可信自主智能的可扩展智能体工厂。Safactory 集成了三个紧密耦合的平台：用于轨迹生成的并行模拟平台、用于轨迹存储和经验提取的可信数据平台，以及用于异步强化学习和同策略蒸馏的自主演化平台。据我们所知，Safactory 是第一个为下一代可信自主智能提出统一演化流水线的框架。

## Abstract
As large models evolve from conversational assistants into autonomous agents, challenges increasingly arise from long-horizon decision making, tool use, and real environment interaction. Existing agenticinfrastructure remain fragmented across evaluation, data management, and agent evolution, making it difficult to discover risks systematically and improve models in a continuous closed loop. In this report, we present \textbf{Safactory}, a scalable agent factory for trustworthy autonomous intelligence. Safactory integrates three tightly coupled platforms: a \textbf{Parallel Simulation Platform} for trajectory generation, a \textbf{Trustworthy Data Platform} for trajectory storage and experience extraction, and an \textbf{Autonomous Evolution Platform} for asynchronous reinforcement learning and on-policy distillation. As far as we know, Safactory is the first framework to propose a unified evolutionary pipeline for next-generation trustworthy autonomous intelligence.

### 2. 论文提出的方法论
Safactory 由三个紧密耦合的平台组成：
*   **并行仿真平台 (Parallel Simulation Platform)**：
    *   **核心思想**：通过预热环境池和异步调度实现大规模并发轨迹生成。
    *   **关键技术**：引入了类似 Git 的“回溯沙箱”机制，能够对环境状态进行版本管理。当智能体触发风险或失败时，系统可回滚到特定锚点并尝试不同的决策分支，极大提高了评估效率和覆盖度。
*   **可信数据平台 (Trustworthy Data Platform)**：
    *   **核心思想**：意图驱动的智能数据引擎（DataElf）。
    *   **关键技术**：支持自然语言驱动的任务编排，内置 30 多种工具集（涵盖安全审计、科学数据处理、轨迹分析等）。通过“黑盒”沙箱执行，确保数据“可用不可见”，并能自主演化出新的数据处理算子。
*   **自主演化平台 (Autonomous Evolution Platform)**：
    *   **核心思想**：支持大规模异步强化学习和同策略蒸馏（On-policy Distillation, OPD）。
    *   **关键技术**：采用 Bridge 模块解耦采样与训练，通过版本控制和组一致性约束解决异步训练中的策略滞后问题。

### 3. 实验设计
*   **实验场景与数据集**：
    *   **QA Gym**：基于 OpenRT 框架进行多轮红队攻击测试。

    *   **Android Gym**：基于 AndroidWorld，评估移动端 UI 交互与环境注入攻击。
    *   **Embodied Gym**：基于 ALFRED 和 Habitat，测试具身智能在 3D 环境中的任务完成度。
    *   **OpenClaw Gym**：针对工具调用和多步决策场景。
    *   **Minecraft Gym**：测试视觉感知与长程规划。
*   **Benchmark 与对比方法**：
    *   **模型对比**：涵盖了 Claude-4.6-Thinking、Qwen3.5-Plus、Kimi-K2.5、GLM-5、DeepSeek-V3.2 等主流大模型。
    *   **工具对比**：DataElf 在数据评分任务中对比了 IFD、DEITA、Ask-LLM 等；在安全审计中对比了 LlamaGuard、WildGuard 等。

### 4. 资源与算力
*   **算力底座**：论文明确提到使用了 **DeepLink** 计算技术，基于 **昇腾（Ascend）Atlas** 系列芯片构建了国产化软硬件协同系统。
*   **具体配置**：在 5.4 节的实验中，使用了 **8 张 GPU**（7 张用于 Rollout 采样，1 张用于训练），针对 Qwen3-VL-2B 模型进行 GRPO 算法优化。
*   **优化效果**：通过内核同页合并（KSM）等技术，内存占用减少 80% 以上，并行规模提升 6 倍。

### 5. 实验数量与充分性
*   **实验规模**：报告展示了跨越 6 个不同领域（桌面、移动、具身、工具等）的综合评估，并开源了包含 10,496 条轨迹、15.8 万个交互步骤的 **SATraj-OS** 数据集。
*   **充分性**：实验不仅涵盖了模型能力的横向对比，还包含了针对数据评分、安全审计、异步训练效率的专项消融实验。
*   **客观性**：通过引入“成功率 vs 安全率”的双维度坐标图，客观揭示了当前模型在“完成任务”与“安全合规”之间的权衡关系。

### 6. 主要结论与发现
*   **能力不等于安全**：在 OpenClaw 等场景中发现，模型能力的提升并不自然导致安全性的提高，许多高能力模型依然存在严重的合规风险。
*   **具身智能瓶颈**：当前多模态模型在具身环境（Embodied Gym）中普遍表现较差，成功率与安全性均处于低位，远未达到实用水平。
*   **异步架构优势**：Safactory 的异步架构相比传统同步框架（如 slime-native），在相同时间内生成的轨迹数量提升了 2.49 倍，显著提高了 GPU 资源利用率。
*   **经验蒸馏有效性**：通过轨迹分析工具提取的经验（Skills）注入，能将 Kimi-K2.5 在特定场景下的安全率从 32% 提升至 71%。

### 7. 优点
*   **系统性强**：首次提出了覆盖智能体全生命周期的统一进化流水线，而非单一的评估工具。
*   **工程创新**：引入“回溯沙箱”和“异步 Bridge”机制，解决了智能体训练中环境模拟慢、数据利用率低的痛点。
*   **国产化适配**：深度适配国产算力生态（DeepLink + 昇腾），具有重要的战略意义。

### 8. 不足与局限
*   **环境真实性**：虽然涵盖了多个 Gym，但与极端复杂的真实人类社会交互相比，模拟环境仍存在简化。
*   **自动评测难题**：在长程任务中，如何精准、自动地判定智能体的“意图安全性”和“操作后果”依然是一个开放性挑战。
*   **信用分配（Credit Assignment）**：在极长路径的强化学习中，如何将最终的失败准确归因到中间某一步的错误操作，仍需更精细的算法研究。
