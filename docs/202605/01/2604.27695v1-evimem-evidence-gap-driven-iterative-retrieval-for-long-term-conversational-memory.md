## 摘要
长期对话记忆需要检索分散在多个会话中的证据，然而单次检索在处理时间相关和多跳问题时往往会失败。现有的迭代方法通过生成的内容或文档级信号来优化查询，但没有一种方法能明确诊断证据鸿沟（即累积检索集中缺失的内容），导致查询优化缺乏针对性。我们提出了 EviMem，它结合了 IRIS（通过不足信号进行迭代检索）和 LaceMem（对话证据记忆的分层架构）。IRIS 是一个闭环框架，通过充分性评估检测证据鸿沟，诊断缺失内容并驱动有针对性的查询优化；LaceMem 是一种由粗到精的记忆层次结构，支持细粒度的鸿沟诊断。在 LoCoMo 数据集上，EviMem 在时间相关问题（从 73.3% 提升至 81.6%）和多跳问题（从 65.9% 提升至 85.2%）上的评判准确率均优于 MIRIX，且延迟降低了 4.5 倍。代码：https://github.com/AIGeeksGroup/EviMem。

## Abstract
Long-term conversational memory requires retrieving evidence scattered across multiple sessions, yet single-pass retrieval fails on temporal and multi-hop questions. Existing iterative methods refine queries via generated content or document-level signals, but none explicitly diagnoses the evidence gap, namely what is missing from the accumulated retrieval set, leaving query refinement untargeted. We present EviMem, combining IRIS (Iterative Retrieval via Insufficiency Signals), a closed-loop framework that detects evidence gaps through sufficiency evaluation, diagnoses what is missing, and drives targeted query refinement, with LaceMem (Layered Architecture for Conversational Evidence Memory), a coarse-to-fine memory hierarchy supporting fine-grained gap diagnosis. On LoCoMo, EviMem improves Judge Accuracy over MIRIX on temporal (73.3% to 81.6%) and multi-hop (65.9% to 85.2%) questions at 4.5x lower latency. Code: https://github.com/AIGeeksGroup/EviMem.

#### 1. 核心问题与整体含义（研究动机和背景）
在长期对话场景中，LLM 代理需要处理跨越多个会话（Sessions）的复杂交互。现有的检索增强生成（RAG）系统在处理**时序推理**（如“某人何时改变了计划？”）和**多跳合成**（如“某团队凭借哪支舞曲夺冠？”）时表现不佳。
*   **研究动机**：传统的检索是“开环”的单次过程，查询在看到证据前就已确定，无法根据检索结果调整。
*   **现有局限**：现有的迭代检索方法（如 FLARE、Self-RAG）虽有改进，但大多关注生成内容的置信度或单篇文档的质量，**缺乏对整个检索证据集“充分性”的显式诊断**。这导致查询优化盲目，难以应对证据分散且无表面相似性的长期对话记忆任务。

#### 2. 方法论：核心思想与关键技术
论文提出了 **EviMem** 框架，由两个相互协作的部分组成：

*   **IRIS (基于不足信号的迭代检索)**：一个闭环检索框架。
    *   **双路径检索**：每轮迭代同时运行“锚点路径”（原始问题）和“优化路径”（基于诊断的查询），防止语义漂移。
    *   **充分性评估（核心）**：LLM 将累积证据分为三个等级：**EXACT**（直接答案）、**INFERRABLE**（可推断）、**PARTIAL**（部分相关但不足）。
    *   **证据鸿沟诊断**：如果证据不足，LLM 会生成缺失信息的自然语言描述，直接驱动下一轮查询优化。
    *   **实体跟踪**：监控每个实体的证据覆盖率，防止多实体问题中某些关键事实被遗漏。
*   **LaceMem (分层对话证据记忆架构)**：
    *   **索引层 (Index)**：将对话转为原子语义元组（主-谓-宾-时间），支持精确搜索。
    *   **边缘层 (Edge)**：通过同源和语义相似性建立图连接，支持多跳扩展。
    *   **原始层 (Raw)**：保留原始对话文本，确保生成的答案有据可查。

#### 7. 优点
*   **闭环反馈**：将“证据充分性”作为显式信号，解决了 RAG 系统中常见的检索不足或检索漂移问题。
*   **分层记忆设计**：LaceMem 兼顾了结构化元组的精确性和原始文本的上下文完整性。
*   **高性价比**：通过轻量级模型进行中间诊断，在提升准确性的同时大幅降低了多智能体系统的推理开销。

#### 8. 不足与局限
*   **离线构建**：目前的 LaceMem 记忆层是基于完整的对话快照构建的。虽然架构支持增量更新，但论文尚未在**实时流式对话**（Online Streaming）环境中验证其动态索引的性能。

*   **检索深度限制**：虽然通过迭代实现了多跳，但最大迭代次数（k=3）可能仍无法处理极深（如 5 跳以上）的复杂逻辑链。
