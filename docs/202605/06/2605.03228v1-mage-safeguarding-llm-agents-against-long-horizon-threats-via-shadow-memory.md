## 摘要
随着基于大语言模型（LLM）的智能体越来越多地被部署用于执行复杂的现实任务，它们面临着一类日益增长的攻击，这些攻击利用扩展的用户-智能体-环境交互来实现单轮对话设置中难以实现的恶意目标。这种长程威胁对 LLM 智能体在关键领域的安全部署构成了重大风险。在本文中，我们提出了 MAGE（Memory As Guardrail Enforcement），这是一个旨在应对各种长程威胁的新型防御框架。受系统安全中“影子栈”抽象的启发，MAGE 维护了一个专门的、以安全为中心的智能体记忆，用于提取并保留智能体整个执行轨迹中的安全关键上下文，并利用该影子记忆在待执行操作实施前主动评估其风险。广泛的评估表明，MAGE 在检测准确率方面显著优于现有的针对各种长程威胁的防御措施，实现了对大多数攻击的早期检测，且对智能体效用的开销微乎其微。据我们所知，MAGE 是第一个使用智能体记忆方法来检测和缓解长程威胁的框架，为这一关键挑战建立了新的范式，并为未来的研究开辟了充满前景的方向。

## Abstract
As large language model (LLM)-powered agents are increasingly deployed to perform complex, real-world tasks, they face a growing class of attacks that exploit extended user-agent-environment interactions to pursue malicious objectives improbable in single-turn settings. Such long-horizon threats pose significant risks to the safe deployment of LLM agents in critical domains. In this paper, we present MAGE (Memory As Guardrail Enforcement), a novel defensive framework designed to counter a wide range of long-horizon threats. Inspired by the "shadow stack" abstraction in systems security, MAGE maintains a dedicated, safety-focused agentic memory that distills and retains safety-critical context across the agent's full execution trajectory, leveraging this shadow memory to proactively assess the risk of pending actions prior to their execution. Extensive evaluation demonstrates that MAGE substantially outperforms existing defenses across diverse long-horizon threats in detection accuracy, achieves early-stage detection for the majority of attacks, and introduces only negligible overhead to agent utility. To our best knowledge, MAGE represents the first framework to detect and mitigate long-horizon threats using an agentic memory approach, establishing a new paradigm for this critical challenge and opening promising directions for future research.

### 2. 论文提出的方法论
*   **核心思想**：借鉴系统安全中的“影子栈”（Shadow Stack）概念，为智能体建立一个并行的**影子记忆（Shadow Memory）**。该记忆不参与任务逻辑，专门用于提炼和保留与安全相关的上下文。
*   **关键技术细节**：
    *   **双组件架构**：
        1.  **记忆管理器 ($M$)**：负责将当前轮次的交互（动作、观察、指令）提炼并更新到影子记忆中。
        2.  **裁判 ($J$)**：在动作执行前，结合影子记忆评估该动作的风险。
    *   **影子记忆内容**：显式记录用户意图、关键事实、安全红旗（Red Flags）以及与已知攻击模式的匹配情况。
*   **算法流程（分步强化学习）**：
    *   采用 **分步 GRPO（Turn-wise Group Relative Policy Optimization）** 算法进行联合优化。
    *   **奖励设计**：包括裁判准确性奖励、影子记忆的跨时序折扣奖励（考虑当前记忆对未来判断的影响）、格式惩罚以及长度惩罚（保持记忆简洁）。

### 3. 实验设计
*   **场景与数据集**：

*   **充分性评估**：实验设计非常充分且客观。
    *   **消融实验**：验证了影子记忆组件、用户意图参考、攻击模式参考、奖励超参数（$\gamma, \lambda$）的影响。
    *   **自适应攻击测试**：模拟了攻击者已知晓 MAGE 存在并试图通过指令污染影子记忆或误导裁判的极端情况。

### 6. 主要结论与发现
*   **防御效能**：MAGE 显著降低了攻击成功率（ASR）。例如，在 STAC 攻击下，将 ASR 从 100% 降至 8.3%；在 PI2 攻击下实现 0% 的 ASR。
*   **效用保持**：在保持高安全性的同时，良性任务的成功率（BU）几乎不受影响（通常保持在 90% 以上或与无防御状态持平）。
*   **早期检测**：大多数攻击在第一轮或恶意动作即将发生时即被拦截，平均检测延迟接近 0。
*   **低开销**：相比于重复提示词等方法，MAGE 通过压缩记忆减少了 Token 消耗，且由于使用 4B 小模型，推理成本极低。

### 7. 优点
*   **即插即用**：无需修改被保护智能体的核心推理逻辑或进行微调。
*   **可解释性**：裁判在拒绝动作时会基于影子记忆提供人类可读的理由。
*   **鲁棒性**：通过强化学习训练，影子记忆能够识别并忽略试图污染记忆的自适应攻击指令。
*   **高效性**：影子记忆的 $O(T)$ 复杂度优于全轨迹检查的 $O(T^2)$ 复杂度。

### 8. 不足与局限
*   **攻击覆盖面**：目前主要针对工具链和提示词注入，尚未广泛测试内存中毒（Memory Poisoning）或目标漂移（Goal Drifting）等所有潜在威胁。
*   **固定模式限制**：影子记忆目前的提取模式（Schema）是预设的，可能无法灵活应对未来出现的全新攻击类别。
*   **单智能体局限**：研究集中在单智能体系统，在多智能体协同（Multi-agent systems）环境下的防御有效性尚待验证。
*   **模型依赖**：防御效果仍受限于影子记忆骨干模型（如 Qwen3-4B）的理解能力。
