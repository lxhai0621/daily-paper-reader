## 摘要
大语言模型（LLM）智能体需要长期用户记忆来实现一致的个性化，但有限的上下文窗口阻碍了在长时交互中追踪演化的偏好。现有的记忆系统主要依赖于静态的、手工设计的更新规则；虽然基于强化学习（RL）的智能体可以学习记忆更新，但稀疏的结果奖励提供了微弱的监督，导致长时程优化不稳定。借鉴记忆图式理论以及前额叶区域与海马体区域之间的功能划分，我们提出了 MemCoE，这是一个受认知启发的两阶段优化框架，用于学习记忆应如何组织以及更新哪些信息。在第一阶段，我们提出了记忆指南归纳（Memory Guideline Induction），通过解释为文本梯度的对比反馈来优化全局指南；在第二阶段，指南对齐的记忆策略优化（Guideline-Aligned Memory Policy Optimization）利用归纳出的指南来定义结构化的过程奖励，并进行多轮强化学习以学习遵循指南的记忆演化策略。我们在三个个性化记忆基准测试上进行了评估，涵盖了显式/隐式偏好以及不同的规模和噪声，并观察到相比强基线模型有持续的改进，且具有良好的鲁棒性、迁移性和效率。

## Abstract
Large language model (LLM) agents require long-term user memory for consistent personalization, but limited context windows hinder tracking evolving preferences over long interactions. Existing memory systems mainly rely on static, hand-crafted update rules; although reinforcement learning (RL)-based agents learn memory updates, sparse outcome rewards provide weak supervision, resulting in unstable long-horizon optimization. Drawing on memory schema theory and the functional division between prefrontal regions and hippocampus regions, we introduce MemCoE, a cognition-inspired two-stage optimization framework that learns how memory should be organized and what information to update. In the first stage, we propose Memory Guideline Induction to optimize a global guideline via contrastive feedback interpreted as textual gradients; in the second stage, Guideline-Aligned Memory Policy Optimization uses the induced guideline to define structured process rewards and performs multi-turn RL to learn a guideline-following memory evolution policy. We evaluate on three personalization memory benchmarks, covering explicit/implicit preference and different sizes and noise, and observe consistent improvements over strong baselines with favorable robustness, transferability, and efficiency.

    *   **认知科学启发**：借鉴人类记忆的“图式理论（Schema Theory）”，即大脑前额叶负责动态选择和配置组织模式（Schema），而海马体负责填充具体的细节。论文旨在构建一个类似的系统，将“如何组织记忆”与“记忆什么内容”进行解耦。

#### 2. 方法论
论文提出了 **MemCoE** 框架，分为两个优化阶段：
*   **第一阶段：记忆准则归纳 (Memory Guideline Induction, MGI)**
    *   **核心思想**：学习“如何”组织记忆。将记忆更新指令（Prompt）视为一个可优化的全局文本参数。
    *   **关键技术**：
        1.  **对比反馈作为文本梯度**：通过对比正确和错误的记忆更新轨迹，生成自然语言形式的“文本梯度”。
        2.  **批次梯度聚合**：在 mini-batch 级别聚合这些梯度，以消除单条数据的噪声，诱导出通用的、领域无关的记忆组织准则。
*   **第二阶段：准则对齐的记忆策略优化 (Guideline-Aligned Memory Policy Optimization, GMPO)**
    *   **核心思想**：学习“什么”信息值得更新。
    *   **关键技术**：
        1.  **准则对齐奖励**：利用第一阶段生成的准则来定义“过程奖励”（模型是否遵循了规定的格式和逻辑），结合最终回答的“结果奖励”。
        2.  **多轮强化学习**：使用 **GRPO (Group Relative Policy Optimization)** 算法，在多轮对话轨迹上端到端训练记忆演化策略，使模型学会根据准则筛选、保留或遗忘信息。

#### 6. 主要结论与发现
*   **性能领先**：MemCoE 在所有基准测试中均显著优于强基线模型，尤其在处理长时程（128K）和高噪声环境时表现稳健。
*   **解耦的有效性**：先诱导组织准则再优化更新策略的两阶段设计，比直接进行端到端 RL 更稳定且高效。

*   **效率优势**：相比于频繁调用 LLM 进行提取和合并的传统记忆库，MemCoE 通过内化更新行为，在保持高精度的同时具有更快的推理速度。

#### 7. 优点（亮点）
*   **理论支撑**：将认知心理学的记忆图式理论成功转化为可工程化的两阶段优化流程。
*   **解决稀疏奖励问题**：通过第一阶段诱导的准则提供“过程奖励”，有效缓解了 RL 在长程任务中监督信号微弱的问题。
*   **鲁棒性**：实验证明该方法对噪声数据和超长上下文具有极强的抵抗力。

#### 8. 不足与局限
*   **评分器依赖**：第二阶段的奖励计算依赖于另一个 LLM 作为评分器，评分器的可靠性可能影响训练效果。

*   **多目标平衡**：目前尚未显式解决记忆“稳定性”与“塑性”（即保留旧信息与接受新信息的平衡）之间的冲突。
