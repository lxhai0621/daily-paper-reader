## 摘要
科学阅读是一个主动的过程，经常需要查阅外部资源，但手动关键词搜索会中断阅读流并带来高认知负荷。现有的主动信息检索系统通常面临上下文歧义的问题，因为它们仅依赖于屏幕上的文本，而忽略了读者的特定背景和意图。在本演示中，我们提出了 H-MAPS（分层记忆增强型主动搜索助手），这是一款通过利用三层分层记忆来解决这种歧义的主动文献探索助手。H-MAPS 由隐式阅读行为触发，将用户的潜在信息需求转化为明确的自然语言问题，并完全在本地设备上执行神经检索以确保隐私。我们通过一个场景演示了 H-MAPS，在该场景中，两名分别专注于自然语言处理（NLP）和人机交互（HCI）的研究人员阅读同一篇论文。作为响应，系统生成了针对特定个人资料的问题，并检索了为每位用户量身定制的不同文献。

## Abstract
Scientific reading is an active process that frequently requires consulting external resources, but manual keyword searching interrupts the reading flow and imposes a high cognitive load. Existing proactive information retrieval systems often suffer from context ambiguity, as they rely solely on on-screen text and ignore the reader's specific background and intent. In this demonstration, we present H-MAPS (Hierarchical Memory-Augmented Proactive Search Assistant), a proactive literature exploration assistant that resolves this ambiguity by leveraging a three-layered hierarchical memory. Triggered by implicit reading behaviors, H-MAPS articulates the user's latent information needs into explicit natural language questions and performs neural retrieval entirely on the local device to ensure privacy. We demonstrate H-MAPS using a scenario where two researchers, specializing in NLP and HCI, read the same paper. In response, the system generates profile-specific questions and retrieves distinct literature tailored to each user.

### 2. 方法论
H-MAPS 的核心思想是利用**分层记忆（Hierarchical Memory）**来消除上下文歧义，其架构包含五个关键组件：
*   **屏幕感知（Screen Sensing）**：使用 OCR 技术（Tesseract）以约 1Hz 的频率捕获屏幕文本，并使用轻量级本地模型（Phi-3.5-mini）进行脱敏处理。
*   **三层分层记忆结构**：
    1.  **局部上下文 ($M_{loc}$)**：过去几分钟阅读内容的微摘要。
    2.  **会话上下文 ($M_{ses}$)**：当前阅读论文的逻辑流和已积累知识的运行摘要。
    3.  **推断画像 ($m_{prof}$)**：描述用户长期研究兴趣的自然语言文本，随会话动态更新。
*   **行为驱动触发器**：
    *   **持续关注**：检测到用户停止滚动（表明正在深度思考），触发探索性搜索（如相关工作、替代方法）。
    *   **内容回访**：检测到用户向上滚动（表明正在查阅旧概念），触发澄清性搜索（如定义、之前内容的总结）。
*   **问题构建（Question Generation）**：利用本地 LLM 将潜在需求转化为显式的自然语言问题。这一步将用户的任务从“构建查询”转变为“验证问题是否符合意图”，降低了认知负担。
*   **本地检索（Local Search）**：
    *   使用在 LitSearch 数据集上微调过的 `e5-small-v2` 模型进行向量化。
    *   在本地 1400 万篇 S2ORC 论文索引（FAISS）中进行检索，确保隐私不外泄。

### 3. 实验设计
*   **演示场景**：设定了两名具有不同背景的研究员（NLP 专家和 HCI 专家）阅读同一篇关于 `Self-RAG` 的论文。

### 6. 主要结论与发现
*   **个性化能力**：H-MAPS 能够成功根据用户画像将相同的视觉输入转化为完全不同的检索建议（例如，为 NLP 读者检索延迟优化论文，为 HCI 读者检索透明度设计论文）。
*   **可解释性**：通过生成显式的自然语言问题，系统为推荐结果提供了清晰的理由，方便用户快速判断相关性。
*   **本地化可行性**：证明了在个人电脑上托管千万级论文索引并进行实时主动检索的技术可行性。

### 7. 优点
*   **隐私保护**：全流程本地化处理（OCR、LLM 摘要、向量检索），无需上传敏感阅读内容。
*   **分层记忆机制**：巧妙地结合了短期关注、中期会话和长期兴趣，解决了主动搜索中的“冷启动”和“上下文缺失”问题。
*   **行为感知**：通过滚动行为区分“深度阅读”和“回顾查阅”，使干预时机更具智能化。

### 8. 不足与局限
*   **系统延迟**：12.2 秒的延迟对于实时交互仍显略慢，可能导致建议滞后于读者的阅读进度。

*   **存储压力**：约 70GB 的本地存储占用对普通用户设备仍有一定要求。
*   **评估局限**：缺乏真实世界的大规模用户测试，启发式触发规则（如 Jaccard 相似度）在复杂布局下的鲁棒性有待验证。
