## 摘要
在线流式视频理解要求模型实时处理连续的视觉输入并响应用户查询，其中无限的数据流和不可预测的查询时机使记忆管理成为核心挑战。现有方法通常通过视觉相似性启发式方法压缩视觉标记，或通过键值缓存（KV-cache）级别的检索来增强压缩。然而，压缩决策很少包含语义信号，且检索通常在压缩完成后才添加，导致这两个阶段难以协调。我们提出了 SAVEMem，这是一个无需训练的双阶段框架，它将语义感知引入记忆生成，并使检索范围能够针对每个查询进行自适应。在第一阶段，SAVEMem 在恒定的记忆预算下在线构建三层流式记忆。一个固定的伪问题库提供了轻量级的语义先验，使得长期保留由语义显著性而非仅由视觉相似性决定。在第二阶段，SAVEMem 对该记忆执行查询感知检索。一个基于锚点条件的近期门控根据查询目标是当前还是遥远的过去，将检索范围从短期调整到中期和长期记忆。在此范围内，查询与记忆标记之间的后期交互选择候选帧进行回答。在无需训练的情况下应用于 Qwen2.5-VL，SAVEMem 将 OVO-Bench 的总分从 52.27 提高到 62.69，并在 StreamingBench 和 ODV-Bench 上取得了一致的提升，同时在 128 帧时比骨干模型减少了 48% 的峰值 GPU 显存。

## Abstract
Online streaming video understanding requires models to process continuous visual inputs and respond to user queries in real time, where the unbounded stream and unpredictable query timing turn memory management into a central challenge. Existing methods typically compress visual tokens via visual similarity heuristics, or augment compression with KV-cache-level retrieval. However, compression decisions rarely incorporate semantic signals, and retrieval is often added after compression is finalized, making the two stages hard to coordinate. We present SAVEMem, a training-free dual-stage framework that brings semantic awareness into memory generation and lets the retrieval scope adapt per query. In Stage~1, SAVEMem builds a three-tier streaming memory online under a constant memory budget. A fixed pseudo-question bank provides a lightweight semantic prior, so that long-term retention is shaped by semantic salience rather than visual similarity alone. In Stage~2, SAVEMem performs query-aware retrieval over this memory. An anchor-conditioned recency gate adapts the retrieval scope from short-term to mid- and long-term memory based on whether the query targets the present or the distant past. Within this scope, late interaction between query and memory tokens selects candidate frames for answering. Applied to Qwen2.5-VL without training, SAVEMem improves the OVO-Bench overall score from 52.27 to 62.69 and yields consistent gains on StreamingBench and ODV-Bench, while reducing peak GPU memory by 48\% at 128 frames over the backbone.

*   **研究背景**：
    *   **内存限制**：视频流理论上是无限的，但硬件显存有限，必须进行压缩。
    *   **现有缺陷**：目前的压缩方法多依赖“视觉相似性”启发式算法（如合并相似帧），忽略了语义重要性；且检索机制通常在压缩完成后才独立添加，导致压缩与检索阶段缺乏协同。
    *   **感知-记忆权衡**：模型往往难以在关注“当前发生的事”和“追溯遥远的过去”之间取得平衡。

### 2. 方法论
SAVEMem 是一个**无需训练（Training-free）**的双阶段框架，核心思想是将语义感知引入记忆生成，并实现查询自适应的检索。

*   **第一阶段：语义记忆生成（查询无关）**
    *   **三层记忆结构**：构建短期（Short-term, FIFO缓冲）、中期（Mid-term）和长期（Long-term）记忆。
    *   **伪问题库（Pseudo-question Bank）**：预设一组通用问题（如“场景中有哪些物体？”、“发生了什么动作？”），通过计算视觉标记与这些问题的相似度（MaxSim），为每个标记赋予“语义显著性”得分。
    *   **选择性遗忘**：
        *   **时间语义剪枝**：在移入中期记忆时，保留语义得分高或处于场景边界的标记。
        *   **空间语义选择**：在移入长期记忆时，根据语义得分对空间标记进行排序和筛选，确保在有限预算下保留最具信息量的视觉特征。
*   **第二阶段：自适应记忆检索（查询感知）**
    *   **锚点条件近期门控（Recency Gate）**：利用短期记忆作为锚点，通过指数移动平均（EMA）校准查询与当前场景的亲和力。如果查询针对当前，则直接跳过历史检索；否则，扩大检索范围至中长期记忆。
    *   **后期交互（Late Interaction）**：采用类似 ColBERT 的机制，计算用户查询标记与视觉记忆标记之间的细粒度相似度，筛选出最相关的候选帧输入大模型。

*   **性能提升**：在 OVO-Bench 上，SAVEMem 将 Qwen2.5-VL-7B 的总分从 52.27 提升至 **62.69**，超越了许多需要专门训练的流式模型。

*   **显存高效**：通过三层级联压缩和选择性遗忘，实现了恒定的内存预算，适合长视频流处理。
*   **架构优雅**：将压缩和检索统一在同一个 MaxSim 相似度度量下，实现了逻辑上的高度一致性。

### 8. 不足与局限
*   **复杂推理瓶颈**：在需要极高时间覆盖率的任务（如精确计数或复杂因果推理）中，由于内存预算限制，仍存在信息丢失的风险。
*   **伪问题库的通用性**：目前使用的是一组固定的通用问题，对于某些极度专业化的领域（如医学视频），可能需要手动调整伪问题库。
*   **缺乏联合优化**：由于是无需训练的方法，压缩阶段和检索阶段无法通过反向传播进行端到端的联合优化。
