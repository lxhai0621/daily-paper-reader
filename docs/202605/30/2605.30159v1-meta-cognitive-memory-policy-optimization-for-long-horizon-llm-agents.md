## 摘要
记忆增强的LLM智能体通过递归地将交互轨迹总结为紧凑记忆来处理复杂的长周期任务。然而，现有方法通常使用基于结果的强化学习来训练这些记忆策略，未能定位中间记忆质量下降的位置。随着交互的展开，模糊的递归摘要逐渐丢弃任务相关信息并引入语义噪声。这加剧了信念偏差，模糊了智能体对潜在任务状态的估计，最终破坏长周期推理。因此，我们认为记忆优化不应仅关注轨迹层面的成功，而应关注中间摘要所诱导的信念清晰度。为此，我们引入信念熵（Belief Entropy），一种自监督代理指标，用于衡量模型在当前记忆下对潜在任务状态的不确定性。基于此代理指标，我们提出元认知记忆策略优化（MMPO）。MMPO并非仅依赖稀疏的基于结果的信号，而是通过明确惩罚引发高认知不确定性的摘要，提供细粒度的、针对记忆的监督。实验表明，MMPO在各种长周期任务上持续优于现有方法，即使扩展到175万token的上下文，仍能保持97.1%的性能。

## Abstract
Memory-augmented LLM agents tackle complex long-horizon tasks by recursively summarizing interaction trajectories into compact memory. However, existing approaches typically train these memory policies using outcome-based reinforcement learning, failing to localize where intermediate memory quality degrades. As interactions unfold, ambiguous recursive summaries progressively discard task-relevant information and introduce semantic noise. This exacerbates belief deviation, obscuring the agent's estimate of the latent task state and ultimately derailing long-horizon reasoning. We therefore argue that memory optimization should focus not merely on trajectory-level success, but on the clarity of the belief induced by intermediate summaries. To this end, we introduce Belief Entropy, a self-supervised proxy that probes how uncertain the model remains about the latent task state given its current memory. Based on this proxy, we propose Metacognitive Memory Policy Optimization (MMPO). Instead of relying only on sparse outcome-based signals, MMPO provides fine-grained, memory-specific supervision via explicitly penalizing summaries that induce high epistemic uncertainty. Experiments show that MMPO consistently outperforms existing methods on diverse long-horizon tasks, maintaining 97.1% performance even when scaled to 1.75M-token contexts.

- **核心问题**：递归摘要过程中累积的语义噪声会诱导**信念偏差（belief deviation）**，即智能体内部对潜在任务状态的估计逐渐偏离真实状态，最终破坏长周期推理性能。现有方法缺乏对中间摘要质量的明确准则。
- **研究意义**：本文提出记忆优化应聚焦于**摘要诱导信念的清晰度**，而非仅轨迹级成功。这为长周期 LLM 智能体的记忆训练提供了新的理论视角和实用方法。

## 2. 论文提出的方法论
### 2.1 核心思想
- 将长周期智能体任务建模为部分可观测马尔可夫决策过程（POMDP），智能体的决策依赖于由压缩记忆诱导的信念状态 \( b_t^M(s) = P(s_t | m_t) \)。
- 理想的中间摘要应最小化条件熵 \( H(s_t | m_t) \)，即保持信念的清晰度。但潜在状态 \( s_t \) 不可观测。
- **信念熵（Belief Entropy, BE）**：设计一个元认知探针（anchor question），使模型对锚问题的响应熵作为信念不确定性的代理信号：
  \[
  H_{BE}(m_t) = H(y | m_t, q)
  \]
  其中 \( q \) 为双探针问题：“基于当前记忆，当前任务进度如何？还需要什么信息？” 实际采用 token 级预测熵的均值来估计。

### 2.2 关键技术细节
- **子轨迹密集奖励**：每步内存摘要 \( m_t \) 产生一个密集奖励：
  \[
  R_k^{(i)} = \alpha \cdot \sigma(-H_{BE}(m_k^{(i)})) + r_{\text{final}}^{(i)}
  \]
  结合归一化的信念熵奖励和最终任务奖励，平衡局部清晰度与全局成功。
- **回合级优势估计**：对每组 \( G \) 条采样轨迹，计算每一步子轨迹的组相对优势：
  \[
  \hat{A}_k^{(i)} = \frac{R_k^{(i)} - \text{mean}(R_k)}{\text{std}(R_k)}
  \]
  然后聚合得到每个摘要步骤 \( t \) 的回合级优势：
  \[
  A_t^{(i)} = \frac{1}{T-t+1} \sum_{k=t}^T \hat{A}_k^{(i)}
  \]
- **优化目标**：基于 PPO 的剪裁代理目标，并结合 KL 散度惩罚项：
  \[
  J_{\text{MMPO}}(\theta) = \mathbb{E}\left[ \sum_{t=1}^T \sum_{j=1}^L \min\left( \rho_{t,j}(\theta) A_t^{(i)}, \text{clip}(\rho_{t,j}(\theta), 1-\epsilon, 1+\epsilon) A_t^{(i)} \right) \right] - \beta D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}})
  \]

### 2.3 算法流程
1. 每次迭代采样 \( G \) 条完整轨迹。
2. 对每条轨迹每步生成摘要 \( m_t \) 并计算 \( H_{BE}(m_t) \)。
3. 获取终端奖励 \( r_{\text{final}} \)。
4. 构造子轨迹奖励 \( R_k \) 并计算组相对优势。
5. 聚合回合级优势 \( A_t \)。
6. 根据 PPO 目标更新策略参数。
