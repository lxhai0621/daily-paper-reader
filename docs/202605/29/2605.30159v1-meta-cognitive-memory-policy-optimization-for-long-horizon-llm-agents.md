## 摘要
记忆增强型LLM智能体通过递归地将交互轨迹总结为紧凑记忆来处理复杂的长时域任务。然而，现有方法通常使用基于结果的强化学习来训练这些记忆策略，未能定位中间记忆质量下降的位置。随着交互的展开，模糊的递归总结逐渐丢弃任务相关信息并引入语义噪声。这加剧了信念偏差，掩盖了智能体对潜在任务状态的估计，最终导致长时域推理偏离正轨。因此，我们认为记忆优化不应仅关注轨迹层面的成功，还应关注中间总结所引发的信念清晰度。为此，我们引入信念熵（Belief Entropy），这是一种自监督代理指标，用于探测量模型在当前记忆下对潜在任务状态的不确定性程度。基于这一指标，我们提出了元认知记忆策略优化（MMPO）。MMPO不依赖稀疏的基于结果的信号，而是通过明确惩罚引发高认知不确定性的总结，提供细粒度的、针对记忆的监督。实验表明，MMPO在各种长时域任务上持续优于现有方法，即使在扩展到175万token上下文时仍能保持97.1%的性能。

## Abstract
Memory-augmented LLM agents tackle complex long-horizon tasks by recursively summarizing interaction trajectories into compact memory. However, existing approaches typically train these memory policies using outcome-based reinforcement learning, failing to localize where intermediate memory quality degrades. As interactions unfold, ambiguous recursive summaries progressively discard task-relevant information and introduce semantic noise. This exacerbates belief deviation, obscuring the agent's estimate of the latent task state and ultimately derailing long-horizon reasoning. We therefore argue that memory optimization should focus not merely on trajectory-level success, but on the clarity of the belief induced by intermediate summaries. To this end, we introduce Belief Entropy, a self-supervised proxy that probes how uncertain the model remains about the latent task state given its current memory. Based on this proxy, we propose Metacognitive Memory Policy Optimization (MMPO). Instead of relying only on sparse outcome-based signals, MMPO provides fine-grained, memory-specific supervision via explicitly penalizing summaries that induce high epistemic uncertainty. Experiments show that MMPO consistently outperforms existing methods on diverse long-horizon tasks, maintaining 97.1% performance even when scaled to 1.75M-token contexts.

## 2. 方法论

### 核心思想
- 将长时域智能体任务建模为部分可观测马尔可夫决策过程（POMDP）。记忆摘要 `m_t` 替代全历史 `h_t` 作为决策上下文，诱导出“摘要信念” `b_t(s) = P(s|m_t)`。
- 信念保存原则：可靠的中间摘要应保持对潜在任务状态的准确估计，即最小化条件熵 `H(s_t | m_t)`。
- **信念熵**（Belief Entropy, BE）：利用元认知锚问题（anchor question）将不可观测的信念不确定性转化为可观测的响应不确定性。锚问题设计为“基于当前记忆，任务进度如何？还需什么信息？”。BE 定义为模型对锚问题响应的 token 级预测熵的均值。
- **MMPO 框架**：在基于结果的 RL 基础上，用 BE 为每个中间记忆状态提供密集的过程奖励，从而做出细粒度的信用分配。

1. **子轨迹密集奖励**：对每条轨迹，在每一步 `k` 计算奖励 `R_k = α·σ(−H_BE(m_k)) + r_final`，其中 `σ` 为 sigmoid 归一化，`r_final` 为最终任务结果（如 F1）。这样将 BE 信号与结果信号结合。

## 7. 优点

- **理论动机明确**：从 POMDP 框架出发，将记忆质量形式化为信念保存，并推导出条件熵最小化目标，逻辑严密。
- **自监督信号**：信念熵无需人工标注，通过锚问题自动生成，可扩展性强。
- **密集过程监督**：克服了仅最终结果 RL 的信用分配问题，为每个中间记忆提供细粒度奖励。
- **实验设计全面**：覆盖多种任务、长度、框架、消融，并与多种替代信号对比，论证充分。
- **开源友好**：训练流程清晰（Algorithm 1），易于复现。

## 8. 不足与局限

- **信念熵的近似性**：BE 只是对真实信念不确定性 `H(s_t|m_t)` 的近似，其有效性依赖于锚问题的设计和模型生成能力。若锚问题不能充分暴露状态不确定性，则奖励信号可能不准确。
- **计算开销**：训练时每步需额外一次前向传播计算 BE，带来约 12% 开销；推理时可省略，但若作为可选置信度信号仍增加 5% 开销。
- **未保证事实正确性**：优化记忆清晰度不一定保证最终输出的事实准确性，仍可能因错误记忆或过度自信导致失败。
- **应用限制**：在需要处理敏感信息的场景中，记忆智能体可能泄露或保留不应保留的信息，缺乏隐私控制讨论。
- **实验覆盖尚可增强**：未测试更大规模（如 70B+）模型；未报告训练稳定性（如方差）和超参数敏感性；未在更多长时域交互任务（如机器人控制、游戏）上验证。
- **理论与实践的差距**：POMDP 假设任务状态是离散的，而实际 LLM 状态空间可能无限且非稳态，理论形式化与实际实现之间可能存在鸿沟。
