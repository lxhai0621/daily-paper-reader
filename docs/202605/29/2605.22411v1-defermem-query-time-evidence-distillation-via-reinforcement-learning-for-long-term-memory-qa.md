## 摘要
大型语言模型（LLM）智能体在长期记忆问答方面仍然存在困难，因为支持答案的证据常常分散在长对话历史中，并被大量无关内容所掩盖。现有的记忆系统通常在未知未来查询之前处理记忆，然后基于相似性而非对回答问题的效用性来检索生成的单元。这种工作流程使得下游的回答者需要去噪检索到的候选并重建特定于查询的证据。我们提出DeferMem，一种长期记忆框架，将该问题解耦为高召回候选检索和查询条件证据蒸馏。DeferMem使用轻量级的段链接结构来组织原始历史，并在查询时检索广泛的候选。然后，它应用一个用DistillPO训练的记忆蒸馏器，DistillPO是我们的强化学习算法，用于将高召回但高度噪音的候选蒸馏为一组忠实、自包含且查询条件的证据。DistillPO将检索后证据蒸馏形式化为一个结构化动作，包括消息选择和证据重写。它通过分解和门控奖励管道以及结构对齐的优势分配来优化该动作，从有效性到质量检查门控奖励组件，同时早期暴露任务级正确性反馈并将每个奖励分配给其负责的输出跨度。在LoCoMo和LongMemEval-S上，DeferMem在QA准确性和记忆系统效率方面超越了强基线，实现了最高的QA准确性、最快的运行时间以及零商业API令牌成本用于记忆操作。

## Abstract
Large language model (LLM) agents still struggle with long-term memory question answering, where answer-supporting evidence is often scattered across long conversational histories and buried in substantial irrelevant content. Existing memory systems typically process memory before future queries are known, then retrieve the resulting units based on similarity rather than their utility for answering the query. This workflow leaves downstream answerers to denoise retrieved candidates and reconstruct query-specific evidence. We present DeferMem, a long-term memory framework that decouples this problem into high-recall candidate retrieval and query-conditioned evidence distillation. DeferMem uses a lightweight segment-link structure to organize raw history and retrieve broad candidates at query time. It then applies a memory distiller trained with DistillPO, our reinforcement learning algorithm for distilling the high-recall but highly noisy candidates into a set of faithful, self-contained, and query-conditioned evidence. DistillPO formulates post-retrieval evidence distillation as a structured action comprising message selection and evidence rewriting. It optimizes this action with a decomposed-and-gated reward pipeline and structure-aligned advantage assignment, gating reward components from validity to quality checks while exposing task-level correctness feedback early and assigning each reward to its responsible output span. On LoCoMo and LongMemEval-S, DeferMem surpasses strong baselines in QA accuracy and memory-system efficiency, achieving the highest QA accuracy with the fastest runtime and zero commercial-API token cost for memory operations.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：DeferMem 将证据蒸馏延迟到查询时进行。先通过轻量级 segment-link 结构组织原始历史，实现高召回候选检索；再用基于强化学习的蒸馏器将噪声候选转化为忠实、自包含、查询条件化的证据。
- **关键技术细节**：
  - **Segment-Link 结构**：对每个会话的消息进行语义分割（通过局部注意力 + 语义相似性确定边界），再将相关片段链接成“段链接”。查询时通过 top-k 消息命中，扩展至其所在段和链接段，得到高召回但高噪声候选集。
  - **DistillPO 强化学习算法**：
    - 将证据蒸馏形式化为结构化动作：`o = (U, Z)`，其中 `U` 是选中的消息 ID 集合，`Z` 是重写后的证据陈述集合。
    - 基于 DAPO 的策略优化目标，结合：
      - **分解门控奖励管道**：8 个可验证的奖励组件（格式有效性、选择 ID 有效性、证据覆盖度、选择简洁性、选择-证据对齐、忠实性与自包含性、答案正确性、证据归因失败）。采用 leaky hierarchical gating 策略：基础有效性通过后才考虑高级奖励，但答案相关奖励在格式有效后立即暴露，防止过度优化低级目标。
      - **结构对齐优势分配**：将选择跨度（useful_msg）和证据跨度（distilled_info）的奖励分别归一化，计算各自组内优势，将梯度仅作用于对应 token 范围，提高学习效率。
      - **全奖励锚完成**：每个训练组中加入一个由强 LLM 生成且经验证通过所有奖励的锚完成，稳定组相对优化。
- **公式/算法流程**（文字说明）：训练时，对于每个查询，从旧策略采样 G 个完成，计算各自的奖励，通过分门控得到选择奖励和证据奖励，分别组内归一化得到优势，然后按标准 DAPO 损失进行梯度更新。锚完成作为组内一员参与优势计算和损失。

## 7. 优点

- **创新性**：明确将长期记忆问题解耦为高召回检索 + 查询时证据蒸馏，区别于现有写入时压缩/选择性检索。
- **方法设计细致**：DistillPO 结构化动作匹配记忆蒸馏本质，分解门控奖励减少信用分配模糊，结构对齐优势提升学习效率。
- **效率突出**：无商业 API token 消耗，运行速度比次优方法 LightMem 快 3-9 倍，同时准确率更高，实现了 accuracy–efficiency 前沿。
- **实验严谨**：多维度消融、超参数分析、错误分析、扩展性测试，充分验证各个模块必要性。
- **跨数据集泛化**：单独在 LoCoMo 或 LongMemEval 训练的单源变体也能在另一个数据集取得较好结果，表明蒸馏行为可迁移。

## 8. 不足与局限

- **训练数据量小**：仅使用 199 + 130 个 QA 对，且仅覆盖两个数据集，可能限制蒸馏器在更广泛对话场景下的泛化能力。
- **训练阶段依赖商业 LLM**：蒸馏器训练时需使用强 LLM（GPT-5.2）生成锚完成和部分奖励计算，虽然后续部署无 API 成本，但训练开销仍涉及商业 API 调用。
- **奖励函数仍有时滞**：多个 LLM 裁判调用用于计算 r5、r6、r7，可能引入裁判噪声和额外成本延迟。
- **未与更大模型或更多算力训练对比**：蒸馏器基于 8B 模型，未尝试更大规模 backbone，也未报告训练时间细节。
- **应用限制**：当前方法主要针对文本对话，图像仅使用描述文本；未来可能需要支持多模态真实信号。
- **长期记忆基准本身**：现有基准并非专为训练可学记忆系统设计，缺乏标准化的训练-测试划分和硬负例，可能限制进一步优化。
