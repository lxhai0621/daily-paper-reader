## 摘要
强化学习（RL）已成为大语言模型（LLM）智能体后训练的核心范式，但其轨迹级奖励信号仅能为长程交互提供粗粒度的监督。同策略自蒸馏（OPSD）通过引入来自增强了特权上下文的教师分支的密集 Token 级指导，对 RL 进行了补充。然而，将 OPSD 迁移到多轮智能体中存在问题：复合的多轮不稳定性使监督变得不稳定，而基于技能条件的特权指导需要非对称处理，因为教师的负向拒绝可能源于不完善的技能检索或利用。我们提出了 SDAR（自蒸馏智能体强化学习），它将 OPSD 视为门控辅助目标，同时保持 RL 作为主要的优化骨干。SDAR 将分离的 Token 级信号映射到 Sigmoid 门控中，加强了对教师认可的正差距 Token 的蒸馏，并软性地衰减了教师的负向拒绝。在 ALFWorld、WebShop 和 Search-QA 数据集上，针对 Qwen2.5 和 Qwen3 系列模型，SDAR 相比 GRPO 取得了显著提升（ALFWorld 提升 9.4%，Search-QA 提升 7.0%，WebShop-Acc 提升 10.2%），避免了原生 GRPO+OPSD 的不稳定性，并在不同模型规模下始终优于混合 RL-OPSD 基准。

## Abstract
Reinforcement learning (RL) has emerged as a central paradigm for post-training LLM agents, yet its trajectory-level reward signal provides only coarse supervision for long-horizon interaction. On-Policy Self-Distillation (OPSD) complements RL by introducing dense token-level guidance from a teacher branch augmented with privileged context. However, transferring OPSD to multi-turn agents proves problematic: compounding multi-turn instability destabilizes supervision, while skill-conditioned privileged guidance requires asymmetric treatment for negative teacher rejections may arise from imperfect skills retrieval or utilization. We introduce SDAR (Self-Distilled Agentic Reinforcement Learning), which treats OPSD as a gated auxiliary objective while keeping RL as the primary optimization backbone. SDAR maps detached token-level signals into a sigmoid gate, strengthening distillation on teacher-endorsed positive-gap tokens and softly attenuating negative teacher rejections. Across the Qwen2.5 and Qwen3 families on ALFWorld, WebShop, and Search-QA, SDAR substantially improves over GRPO (+9.4% on ALFWorld, +7.0% on Search-QA, +10.2% on WebShop-Acc), avoids the instability of naive GRPO+OPSD, and consistently outperforms hybrid RL--OPSD baselines across model scales.

### 论文总结：Self-Distilled Agentic Reinforcement Learning (SDAR)

#### 1. 核心问题与整体含义
论文针对大语言模型（LLM）智能体在后训练阶段面临的两个核心挑战：
*   **强化学习（RL）的稀疏性**：传统的 RL（如 GRPO）通常依赖轨迹级的奖励信号，对于长程、多轮交互任务来说，监督信号过于粗糙，难以指导具体的 Token 生成。
*   **自蒸馏（OPSD）在多轮场景下的不稳定性**：虽然引入特权上下文（如参考答案或技能）的自蒸馏可以提供密集的 Token 级指导，但在多轮交互中，学生模型的微小偏差会随轮次累积，导致教师信号变得不可靠。此外，教师分支依赖检索到的技能，若检索质量不佳，教师给出的“负向反馈”（即降低某个 Token 的概率）可能是错误的。

**SDAR 的核心意义**在于提出了一种稳健的框架，将 RL 作为优化主干，并引入一种**自适应门控的 Token 级自蒸馏**作为辅助目标，解决了多轮交互中的监督不稳定性问题。

#### 2. 方法论
SDAR 的核心思想是“让每个 Token 自主决定受监督的强度”，具体包含以下关键点：
*   **混合目标函数**：总体损失由 GRPO 策略损失和 SDAR 蒸馏损失加权组成：$L(\theta) = L_{GRPO}(\theta) + \lambda_{SDAR} \cdot L_{SDAR}(\theta)$。
*   **特权上下文（Skills Retrieval）**：在训练期间，教师分支可以访问检索到的“技能库”（包含任务相关的子目标分解或动作模板），而学生分支仅访问原始 Prompt。
*   **Token 级 Sigmoid 门控机制**：
    *   计算教师与学生在当前 Token 上的对数概率差距（Gap）：$\Delta_t = \log \pi_T(y_t | s^+_t) - \log \pi_\theta(y_t | s_t)$。
    *   使用 Sigmoid 函数将其映射为门控权重 $g_t = \sigma(\beta \Delta_t)$。
    *   **非对称信任逻辑**：当 $\Delta_t > 0$（教师更认可该 Token）时，门控激活度高，强化蒸馏；当 $\Delta_t < 0$（教师不认可）时，门控软性衰减，降低该信号的影响，以防教师因检索质量差而误导学生。
*   **分离梯度（Stop-gradient）**：门控权重 $g_t$ 在计算时不传递梯度，确保其仅作为置信度权重，维持训练稳定性。

#### 3. 实验设计
*   **数据集/场景**：

    2.  **WebShop**：真实的电商网站交互环境，测试智能体的购物决策能力。
    3.  **Search-QA**：搜索增强问答，包含 NQ、HotpotQA 等 7 个单跳和多跳问答数据集。
*   **基准模型**：Qwen2.5-3B/7B-Instruct，以及最新的 Qwen3-1.7B-Instruct。
*   **对比方法**：
    *   基础 RL 方法：GRPO。
    *   纯蒸馏方法：OPSD。
    *   技能增强方法：Skill-Prompt, Skill-GRPO。
    *   混合 RL+蒸馏方法：Skill-SD, RLSD, GRPO+OPSD（原生组合）。

*   **硬件**：使用了 **8 张 NVIDIA H800 GPU**。
*   **训练配置**：训练步数为 150 步，Batch Size 根据任务不同（16 或 128 个任务），每个 Prompt 采样 8 条轨迹。

#### 5. 实验数量与充分性
实验设计非常充分且客观：
*   **跨模型规模**：从 1.7B 到 7B 均有测试，验证了方法在小模型上的鲁棒性。
*   **跨领域基准**：涵盖了具身、电商、问答三大主流智能体场景。
*   **深度消融实验**：对比了不同的门控策略（熵门控、Gap 门控、Soft-OR）、不同的超参数（$\beta, \lambda$）以及不同的损失函数类型（Forward KL, Reverse KL, JSD）。
*   **鲁棒性分析**：专门测试了在不同检索质量（甚至随机检索）下的表现，证明了门控机制的过滤能力。

#### 6. 主要结论与发现
*   **性能显著提升**：在 7B 模型上，SDAR 相比 GRPO 在 ALFWorld 上提升了 9.4%，在 WebShop 成功率上提升了 10.2%。
*   **解决不稳定性**：原生的 GRPO+OPSD 在小模型（Qwen3-1.7B）上会出现性能崩溃，而 SDAR 保持了稳定的增长。
*   **知识内化**：SDAR 训练的模型在推理时**不需要**外部技能输入，其表现甚至超过了那些在推理时显式使用技能的基准方法（如 Skill-GRPO*），说明特权知识已成功迁移至模型参数中。
*   **非对称信任的必要性**：实验证实，教师与学生的 Gap 平均值为负，说明盲目跟随教师会损害性能，SDAR 的门控机制是成功的关键。

#### 7. 优点
*   **自适应性强**：无需人工设计复杂的课程学习时间表，通过 Token 级门控实现了自动的“由易到难”学习。
*   **训练稳定**：通过 Sigmoid 限制了辅助梯度的上限，防止了蒸馏信号在多轮漂移时干扰 RL 主干。
*   **推理高效**：实现了“训练时用技能，推理时去技能”，降低了部署成本。

#### 8. 不足与局限
*   **对技能库的依赖**：虽然 SDAR 对检索质量有鲁棒性，但其上限仍受限于技能库（SkillBank）的覆盖范围和质量。
*   **计算开销**：相比纯 RL，SDAR 需要在训练时额外进行一次教师分支的前向计算（带特权上下文），增加了训练时的显存和计算开销。
*   **应用限制**：目前主要在文本/代码类智能体任务上验证，对于视觉等多模态智能体场景的适用性尚待进一步探索。
