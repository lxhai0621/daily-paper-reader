## 摘要
当语言先验主导了微弱或模糊的视觉证据时，多模态大模型（LVLMs）经常会产生幻觉。现有的对比解码方法通过比较原始图像的预测与外部扰动视觉输入的预测来缓解这一问题，但此类参考可能会引入流形外伪影，并需要昂贵的额外前向传递。我们提出了 SIRA，这是一种无需训练的内部对比解码框架，它利用多模态 Transformer 的阶段性信息流，在同一个 LVLM 内部构建反事实参考。SIRA 并非从输入中移除视觉信息，而是首先让图像和文本 token 通过共享前缀进行交互，形成一个对齐的多模态状态，从而保留提示词解释、解码历史、位置结构和早期视觉锚定。然后，它在随后的 Transformer 层中分叉出一个反事实分支，在该分支中屏蔽了对图像 token 位置的注意力。该分支保留了共享的多模态上下文，但缺乏对细粒度视觉证据的持续访问，从而为 token 级对比提供了一个由语言先验主导的内部参考。在解码过程中，SIRA 抑制了那些在没有后期视觉访问的情况下依然表现强劲的 token，并倾向于那些优势取决于完整视觉路径的预测。在 POPE、CHAIR 和 AMBER 数据集上使用 Qwen2.5-VL 和 LLaVA-v1.5 进行的实验表明，SIRA 在减少幻觉的同时保持了描述覆盖范围，且开销低于双通对比解码。SIRA 不需要训练、外部验证器或扰动输入，适用于具有白盒推理访问权限的开源权重 LVLM。

## Abstract
Large vision-language models (LVLMs) often hallucinate when language priors dominate weak or ambiguous visual evidence. Existing contrastive decoding methods mitigate this problem by comparing predictions from the original image with those from externally perturbed visual inputs, but such references can introduce off-manifold artifacts and require costly extra forward passes. We propose SIRA, a training-free internal contrastive decoding framework that constructs a counterfactual reference inside the same LVLM by exploiting the staged information flow of multimodal transformers. Instead of removing visual information from the input, SIRA first lets image and text tokens interact through a shared prefix, forming an aligned multimodal state that preserves prompt interpretation, decoding history, positional structure, and early visual grounding. It then forks a counterfactual branch in later transformer layers, where attention to image-token positions is masked. This branch retains the shared multimodal context but lacks continued access to fine-grained visual evidence, yielding a language-prior-dominated internal reference for token-level contrast. During decoding, SIRA suppresses tokens that remain strong without late visual access and favors predictions whose advantage depends on the full visual pathway. Experiments on POPE, CHAIR, and AMBER with Qwen2.5-VL and LLaVA-v1.5 show that SIRA consistently reduces hallucinations while preserving descriptive coverage and incurring lower overhead than two-pass contrastive decoding. SIRA requires no training, external verifier, or perturbed input, and applies to open-weight LVLMs with white-box inference access.

大型视觉语言模型（LVLM）在生成描述时，往往会受到语言先验（Language Priors）的干扰，产生与图像内容不符的“幻觉”。现有的缓解方法（如对比解码）通常依赖于**外部手段**，即通过对输入图像进行模糊、遮盖等扰动来构建一个“弱视觉”参考分支，再与原始分支对比。
**研究动机：**
*   **开销大：** 外部扰动通常需要两次完整的前向传递，计算成本翻倍。
*   **伪影干扰：** 图像层面的扰动可能引入模型未见过的异常分布（off-manifold artifacts），导致对比信号不纯。
*   **内部机制利用不足：** 论文认为 Transformer 内部的信息流是分阶段的，早期层负责多模态对齐，后期层负责决策。因此，可以在模型内部直接构建参考分支。

### 2. 方法论：SIRA 核心思想与技术细节
SIRA（Shared-Prefix Internal Reconstruction of Attribution）提出了一种**无需训练、无需外部工具**的内部对比解码框架。

*   **核心思想：** 在同一个模型推理路径中，通过“共享前缀”和“后期屏蔽”来分离视觉贡献和语言先验。
*   **关键技术细节：**
    1.  **共享前缀（Shared-Prefix）：** 在 Transformer 的前 $b$ 层（早期层），图像和文本 token 正常交互。这保证了两个分支拥有相同的提示词理解、解码历史和初步的视觉锚定。
    2.  **后期分叉（Late Branching）：** 从第 $b$ 层开始，模型分叉为两个分支。
        *   **完整分支（Full Branch）：** 继续正常的视觉-文本交互。
        *   **反事实分支（Counterfactual Branch）：** 通过修改注意力掩码（Attention Mask），**屏蔽掉所有对图像 token 位置的访问**。该分支此后仅能依赖语言上下文进行预测。
    3.  **内部对比解码（Internal Contrastive Decoding）：** 在输出层，计算两个分支的 Logits 差异。
        *   公式逻辑：最终 Logits = 完整分支 Logits + $\alpha \times$ (完整分支 Logits - 反事实分支 Logits)。
        *   **作用：** 抑制那些在“没有视觉访问”时依然高概率出现的 token（即语言先验），放大那些高度依赖后期视觉证据的 token。

### 6. 主要结论与发现
*   **性能领先：** SIRA 在所有测试的幻觉基准上均取得了 SOTA（最优）结果，一致优于现有的对比解码方法。
*   **保持覆盖率：** 与一些通过“缩短句子”或“变得保守”来减少幻觉的方法不同，SIRA 在降低幻觉的同时，甚至提升了描述的覆盖率（Cover）。

*   **内部参考更优：** 相比于外部图像扰动，模型内部生成的反事实参考能更精准地隔离出视觉归因。

### 7. 优点：亮点总结
*   **纯净性：** 避免了外部图像处理带来的伪影，对比信号直接源于模型内部的信息流控制。
*   **高效性：** 共享了大部分计算前缀，仅在后期层进行双路计算，比传统的双路前向方法更省算力。
*   **即插即用：** 无需任何微调或额外数据，直接应用于现有的开源权重模型。
*   **理论支撑：** 结合了对 Transformer 内部多模态融合机制的深入理解，而非盲目尝试。

### 8. 不足与局限
*   **白盒依赖：** SIRA 需要访问模型的内部隐藏状态、注意力掩码和 KV Cache，因此无法应用于闭源 API（如 GPT-4o 或 Gemini）。
*   **额外开销：** 虽然比双路方法快，但相比标准解码仍有约 50% 的额外计算开销。
*   **属性幻觉：** 案例分析显示，SIRA 虽然能很好地解决“物体是否存在”的幻觉，但在处理复杂的“属性归因”（如光影导致的颜色误判）时仍有提升空间。
