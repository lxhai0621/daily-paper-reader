## 摘要
在现代测试时计算和智能体范式下，语言模型处理的序列越来越长。Transformer 架构的高效文本生成日益受到键值（KV）缓存内存占用和带宽的限制。为了解决这一限制，我们引入了自剪枝键值注意力（SP-KV），这是一种旨在预测未来 KV 效用以减小长期 KV 缓存大小的机制。该策略以细粒度运行：一个轻量级的效用预测器为每个键值对评分；虽然最近的 KV 始终通过局部窗口可用，但较旧的键值对只有在其预测效用超过给定阈值时才会被写入缓存并用于全局注意力。LLM 和效用预测器完全通过下一标记预测损失进行端到端联合训练，并由预训练的 LLM 检查点适配而来。SP-KV 并非强制执行固定的压缩率，而是执行动态稀疏化：该机制根据输入进行调整，通常能将 KV 缓存大小减少 3 到 10 倍，且较长的序列通常具有更高的可压缩性。这显著改善了内存使用和解码速度，且验证损失和在广泛下游任务上的性能几乎没有下降。除了作为一种有效的 KV 缓存缩减机制外，我们的方法还揭示了结构化的层特定和头特定稀疏模式，可用于指导混合局部-全局注意力架构的设计。

## Abstract
Under modern test-time compute and agentic paradigms, language models process ever-longer sequences. Efficient text generation with transformer architectures is increasingly constrained by the Key-Value cache memory footprint and bandwidth. To address this limitation, we introduce Self-Pruned Key-Value Attention (SP-KV), a mechanism designed to predict future KV utility in order to reduce the size of the long-term KV cache. This strategy operates at a fine granularity: a lightweight utility predictor scores each key-value pair, and while recent KVs are always available via a local window, older pairs are written in the cache and used in global attention only if their predicted utility surpasses a given threshold. The LLM and the utility predictor are trained jointly end-to-end exclusively through next-token prediction loss, and are adapted from pretrained LLM checkpoints.   Rather than enforcing a fixed compression ratio, SP-KV performs dynamic sparsification: the mechanism adapts to the input and typically reduces the KV cache size by a factor of $3$ to $10\times$, longer sequences often being more compressible. This leads to vast improvements in memory usage and decoding speed, with little to no degradation of validation loss nor performance on a broad set of downstream tasks. Beyond serving as an effective KV-cache reduction mechanism, our method reveals structured layer- and head-specific sparsity patterns that we can use to guide the design of hybrid local-global attention architectures.

论文的核心动机在于：**并非所有历史标记对未来的预测都同等重要**。SP-KV 旨在通过学习一种“选择性写入”机制，在 KV 对生成时即预测其未来效用，从而只保留最有价值的信息，从根本上压缩缓存体积并提升推理效率。

#### 2. 方法论
SP-KV 的核心思想是引入一个轻量级的**效用预测器（Utility Predictor）**，动态决定哪些 KV 对值得存入长期内存。

*   **核心组件**：在每个注意力头中集成一个小型 2 层 MLP。对于每个新生成的标记，预测器输出一个效用分数 $u \in (0, 1)$。
*   **双层存储机制**：
    *   **局部窗口（Local Window）**：始终保留最近的 $w$ 个标记（默认 128），确保捕捉局部时序特征。
    *   **全局缓存（Global Cache）**：对于超出窗口的旧标记，只有当其效用分数 $u$ 超过阈值 $\tau$ 时，才会被写入并参与全局注意力计算。
*   **训练策略**：
    *   **第一阶段（软门控训练）**：为了保持梯度可微，将 $\log u$ 作为偏置项加入注意力分数中。模型在持续预训练（CPT）过程中，仅通过“下一标记预测”损失函数自动学习识别重要标记，无需额外标注。
    *   **第二阶段（阈值感知硬门控 TAHG）**：在训练后期，将门控逐渐切换为二值化的硬阈值模式，以消除训练与推理之间的分布差异。
*   **硬件优化**：基于 FlashAttention-3 实现了定制内核，支持块跳过（Block-skipping）优化，显著提升了稀疏模式下的吞吐量。

*   **数据集**：主要使用 DCLM 预训练混合数据，涵盖代码、书籍及自然语言，特别增加了长序列比例。
*   **模型规模**：涵盖了从 48M 到 8.1B 参数的多个量级，用于验证扩展定律（Scaling Laws）。
*   **Benchmark**：
    *   **短文本任务**：MMLU, GSM8k, ARC, HumanEval 等 16 个标准评测。
    *   **长文本任务**：RULER 基准测试（包含 Needle In A Haystack 等 13 个子任务），支持高达 32k 的上下文。
*   **对比方法**：包括 Vanilla Attention（全注意力）、H2O、StreamingLLM、KVZap、ExpectedAttention 等主流 KV 压缩方案。

*   **硬件**：实验统一使用 **NVIDIA H100 80GB GPU**。

*   **效率提升**：在 8.1B 模型上，SP-KV 实现了约 2.1x 至 4.6x 的解码加速（Batch Size 为 16 时）。

论文进行了极其详尽的实验验证：
*   **扩展性分析**：通过 11 种不同计算规模的模型拟合了幂律曲线，证明 SP-KV 在不同算力下均能保持与全注意力模型相当的性能。
*   **消融实验**：深入探讨了预测器架构（线性 vs MLP）、局部窗口大小、学习率、辅助损失函数以及推理阈值 $\tau$ 对性能的影响。
*   **架构探针**：利用 SP-KV 学习到的稀疏模式，指导设计了更优的“局部-全局”混合注意力架构。
*   **客观性**：对比实验涵盖了多种 SOTA 压缩方法，并使用了统一的评估协议（如 LongPPL 验证集），实验设计较为客观公平。

#### 6. 主要结论与发现
*   **高效压缩**：SP-KV 通常能实现 **3 到 10 倍** 的 KV 缓存压缩率，且序列越长，压缩潜力越大。
*   **性能保持**：在 8.1B 模型上，实现约 66% 稀疏度的同时，下游任务平均性能下降仅为 0.2%，RULER 长文本任务下降仅 1.2%。
*   **任务敏感性**：不同任务对 KV 缓存的需求差异巨大。例如，大海捞针（NIAH）任务仅需保留 5-7% 的 KV 对即可达到完美精度。
*   **架构启示**：发现模型底层和顶层通常需要更多的全局注意力，而中间层则表现出极高的稀疏性。

#### 7. 优点
*   **动态自适应**：不同于固定比例的压缩，SP-KV 能根据输入内容动态决定保留多少信息。
*   **端到端适配**：通过联合训练，模型权重能适应稀疏的注意力模式，克服了事后剪枝（Post-hoc pruning）导致的性能骤降。
*   **硬件友好**：提供了针对 Hopper 架构优化的内核实现，将理论上的稀疏性转化为实际的推理加速。

#### 8. 不足与局限
*   **语料偏差**：实验主要集中在以英文为主的语料库上，在多语言或极端专业领域（如复杂数学证明）的泛化能力有待进一步验证。
*   **训练成本**：虽然只需 20 TPP 的持续预训练，但相比于完全无需训练的剪枝方法，仍存在一定的计算开销。
*   **后训练影响**：论文主要讨论了预训练阶段，SP-KV 在经过大规模指令微调（SFT）和强化学习（RLHF）后的表现尚未深入探讨。
