## 摘要
大语言模型（LLM）多智能体系统通常依赖于僵化的编排方式，要么采用扁平的单次查询路由，要么采用手工设计的任务分解，导致分解深度、执行者选择和推理预算无法在单一目标下进行联合优化。我们提出了 Uno-Orchestra，这是一种统一的编排策略，它能够选择性地分解任务，并将每个子任务分派给一个可接受的（模型，原语）对，这两个决策都是通过基于真实执行者交互的精选强化学习（RL）轨迹共同学习得到的。在涵盖数学、代码、知识、长上下文和智能体工具使用的 13 个基准测试集上，Uno-Orchestra 与 22 个基准模型相比，达到了 77.0% 的宏观 pass@1，比最强的工作流基准高出约 16%，同时单次查询成本降低了约一个数量级，推进了选择性委派的准确率-效率前沿。

## Abstract
Large language model (LLM) multi-agent systems typically rely on rigid orchestration, committing either to flat per-query routing or to hand-engineered task decomposition, so decomposition depth, worker choice, and inference budget are not jointly optimized under one objective. We introduce Uno-Orchestra, a unified orchestration policy that selectively decomposes a task and dispatches each subtask to an admissible (model, primitive) pair, with both decisions learned together from curated RL trajectories grounded in real worker interactions. Against 22 baselines on a 13-benchmark suite spanning math, code, knowledge, long-context, and agentic tool-use, Uno-Orchestra reaches 77.0% macro pass@1, roughly 16% above the strongest workflow baseline, at roughly an order of magnitude lower per-query cost, advancing the accuracy-efficiency frontier of selective delegation.

# 论文总结：Uno-Orchestra: Parsimonious Agent Routing via Selective Delegation

## 1. 核心问题与整体含义
论文针对当前大语言模型（LLM）多智能体系统中的**编排（Orchestration）效率与灵活性**问题展开研究。现有的系统通常在两种极端间摇摆：要么是扁平的“单次路由”（将整个任务交给一个专家模型），要么是僵化的“手工分解”（预设复杂的任务流）。这导致系统无法根据任务难度动态调整分解深度，也无法在单一目标下联合优化模型选择和推理成本。

**Uno-Orchestra** 的核心动机是实现“**选择性委派（Selective Delegation）**”：即让一个统一的策略模型自主决定“是否需要分解任务”、“如何分解”以及“将子任务路由给哪个（模型, 原语）对”，从而在保证准确率的同时极大地降低推理成本。

## 2. 方法论
Uno-Orchestra 将编排任务建模为一个多轮决策过程，由一个单一的因果语言模型（Causal-LM）作为控制器。

*   **核心思想**：将任务分解（Decomposition）和路由分派（Dispatch）折叠进同一个模型骨干中。模型在同一个输出序列中生成任务计划（DAG图）和具体的路由决策。
*   **动作空间**：定义为 `(模型, 原语)` 对。原语（Primitive）涵盖了模型内部认知操作（如直接回答、思维链）、多步技能调用（如文档阅读）和外部工具调用（如代码执行）。
*   **关键技术：两阶段训练流程**：
    1.  **第一阶段：验证器门控课程学习（SFT）**。从 38 个公共数据集中提取任务，利用强老师模型生成轨迹，并仅保留通过验证器（Verifier）检查的 61,201 条高质量轨迹进行有监督微调。
    2.  **第二阶段：智能体自适应强化学习（Agentic-GRPO）**。针对多轮交互场景改进了 GRPO 算法。通过引入“轮次级信用分配（Turn-level Credit Assignment）”和“过程奖励（Process-level Rewards）”，解决了长程任务中的信用分配难题，使模型学会在必要时进行修复或重新规划。
*   **奖励函数**：联合优化准确率（验证器信号）和成本（归一化后的 Token 成本），通过超参数 $\alpha$ 平衡两者。

## 3. 实验设计
*   **数据集与场景**：涵盖 5 大能力维度的 13 个基准测试，包括数学（MATH-500, AIME）、代码（HumanEval, MBPP, LiveCodeBench, SWE-bench）、知识（MMLU, GPQA）、阅读理解（DROP, MRCR）和智能体工具使用（GAIA, Terminal-Bench, ToolBench）。
*   **对比方法**：共对比了 22 个基准模型，分为五类：
    1.  静态/直接推理（如 Claude 3.5 Opus 直接回答）。
    2.  单轮路由器（如 RouterDC, xRouter）。
    3.  多轮/强化学习路由器（如 Router-R1, AutoMix）。
    4.  智能体工作流系统（如 AgentOrchestra, AOrchestra）。
    5.  Uno-Orchestra 的不同消融版本。

## 4. 资源与算力
*   **硬件环境**：使用了单台配备 **8 张 NVIDIA A100 80GB GPU** 的服务器。
*   **训练时长**：
    *   **SFT 阶段**：约 6 小时。
    *   **RL 阶段（Agentic-GRPO）**：约 25 小时。
*   **模型骨干**：主要实验基于 **Qwen2.5-7B-Instruct**。
*   **推理成本计算**：基于公开的 API 价格清单（如 Gemini, GPT-4, Claude 等）进行统一核算。

## 5. 实验数量与充分性
*   **实验规模**：在 13 个不同领域的基准测试上进行了广泛评估，实验覆盖面广。
*   **消融实验**：非常充分。作者对比了从 Base 到 SFT、再到不同 RL 变体（GRPO, Tree-GRPO, Agentic-GRPO）的性能演进；测试了不同规模的路由器骨干（4B vs 7B）；并验证了在“弱模型池”（仅使用开源模型）下的表现。
*   **客观性**：在 RL 训练中采用了“匿名模型标签”协议，防止路由器通过识别模型品牌（如 GPT-4）走捷径，强制其通过交互反馈学习模型能力，保证了实验的公平性。

## 6. 主要结论与发现
*   **性能领先**：Uno-Orchestra 达到了 **77.0% 的宏观 pass@1**，比最强的工作流基准（AgentOrchestra）高出约 16%。
*   **成本极低**：在达到最高准确率的同时，其单次查询成本比复杂的工作流系统**降低了约一个数量级**。
*   **选择性委派的有效性**：模型学会了对简单问题直接回答（零编排成本），仅对复杂任务进行多轮分解。
*   **泛化能力**：在分布外（Out-of-domain）的任务上，Uno-Orchestra 的领先优势反而进一步扩大，证明其学习的是通用的编排逻辑而非简单的记忆。

## 7. 优点
*   **架构优雅**：将分解与路由统一在单个因果模型中，消除了多个模块间冗余的上下文传递。
*   **效率极高**：通过强化学习直接优化成本函数，实现了准确率与效率的帕累托最优。
*   **信用分配创新**：提出的 Agentic-GRPO 解决了多轮智能体任务中奖励稀疏和归因困难的问题。
*   **实战导向**：训练轨迹基于真实的沙盒执行结果，而非模拟的路径。

## 8. 不足与局限
*   **验证器依赖**：系统高度依赖自动验证器（Verifier）提供奖励信号，对于缺乏明确客观标准（如开放式写作）的任务，该方法难以直接应用。
*   **API 波动风险**：由于依赖第三方商业模型作为执行者，模型能力的更新或 API 的变动可能会影响路由策略的稳定性。
*   **静态模型池**：实验中假设模型池是预设且固定的，对于动态增加新模型时的冷启动处理虽有提及，但仍需更深入的研究。
