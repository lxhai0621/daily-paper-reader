## 摘要
高级图表问答既需要对微小视觉元素的精确感知，也需要跨多个子图的多步推理。尽管现有的多模态大语言模型（MLLMs）在理解单张图表方面表现出色，但在处理跨多个子图的多步推理时往往面临困难。我们提出了 HierVA，这是一个用于图表推理的层级化视觉智能体框架，它在图文联合空间中迭代地构建和更新工作上下文。高层管理器负责生成计划并维护仅包含关键信息的紧凑上下文，而专门的工作器则执行推理、收集证据并返回结果。特别地，该智能体维护独立的视觉和文本上下文，并使用放大工具来限制视觉上下文的范围。在 CharXiv 推理子集上的实验表明，该方法相比强多模态基线模型有持续的提升，消融研究验证了层级化架构、限定范围的视觉上下文以及提炼后的上下文共同带来了互补的增益。

## Abstract
Advanced chart question answering requires both precise perception of small visual elements and multi-step reasoning across several subplots. While existing MLLMs are strong at understanding single plots, they often struggle with multi-step reasoning across multiple subplots. We propose HierVA, a hierarchical visual agent framework for chart reasoning that iteratively constructs and updates a working context in a joint image--text space. A high-level manager generates plans and maintains a compact context containing only key information, while specialized workers perform reasoning, gather evidence, and return results. In particular, the agent maintains separate visual and textual contexts, using a zoom-in tool to restrict the visual context. Experiments on the CharXiv reasoning subset demonstrate consistent improvements over strong multimodal baselines, and ablation studies verify that hierarchical architecture, scoped visual context, and distilled context contribute complementary gains.

#### 1. 核心问题与整体含义（研究动机和背景）

*   **感知精度不足**：关键证据（如坐标轴刻度、图例）在全局视图中往往微小且拥挤。
*   **上下文单调增长（Monotonic Context Growth）**：现有的“带图思考”模式通过不断追加局部裁剪图和中间推理文本来获取细节，导致上下文窗口迅速膨胀，引入大量无关噪声，使模型容易“遗忘”或被干扰。
*   **多步推理复杂性**：跨子图的比较、聚合和极值查找需要严密的逻辑管理。

#### 2. 方法论：核心思想与关键技术

    *   **自适应缩放 (Adaptive Zoom)**：管理者通过调用缩放工具获取高分辨率局部图，并将其作为执行者的输入。
    *   **上下文提炼与封装 (Distillation & Encapsulation)**：执行者的详细推理过程对管理者不可见，仅返回单句总结或图像句柄，防止全局上下文过载。
    *   **即时技能路由 (Just-in-Time Skill Routing)**：维护一个技能库（如 ReadValue, CompareValues），管理者根据任务动态将技能说明注入执行者的系统提示词中，而非全部堆叠在全局提示词里。

*   **架构优雅**：通过“抽象屏障”解决了多模态推理中常见的上下文冗余问题。
*   **无需训练**：作为一种插件式的编排方案，易于迁移到不同的 MLLM 基座上。
*   **精细化控制**：引入了类似操作系统管理内存的机制来管理图文上下文，具有很强的逻辑严密性。

#### 8. 不足与局限
*   **感知依赖**：如果基座模型本身无法识别微小的刻度或标签，层级编排也无法挽回底层感知的失败。

*   **任务拆分风险**：对于某些需要全局统筹、无法轻易拆分为独立子任务的问题，层级化分解可能会导致逻辑断裂。
*   **覆盖范围**：实验主要集中在英文科学图表，尚未验证在多语言或极端排版文档中的表现。
