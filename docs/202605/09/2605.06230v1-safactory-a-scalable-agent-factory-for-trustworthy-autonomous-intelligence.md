## 摘要
随着大模型从对话助手演变为自主智能体，长程决策、工具使用以及真实环境交互带来的挑战日益凸显。现有的智能体基础设施在评估、数据管理和智能体演化方面仍然处于碎片化状态，导致难以系统地发现风险并在持续的闭环中改进模型。在本报告中，我们提出了 Safactory，这是一个面向可信自主智能的可扩展智能体工厂。Safactory 集成了三个紧密耦合的平台：用于轨迹生成的并行仿真平台、用于轨迹存储和经验提取的可信数据平台，以及用于异步强化学习和同策略蒸馏的自主演化平台。据我们所知，Safactory 是首个为下一代可信自主智能提出统一演化流水线的框架。

## Abstract
As large models evolve from conversational assistants into autonomous agents, challenges increasingly arise from long-horizon decision making, tool use, and real environment interaction. Existing agenticinfrastructure remain fragmented across evaluation, data management, and agent evolution, making it difficult to discover risks systematically and improve models in a continuous closed loop. In this report, we present \textbf{Safactory}, a scalable agent factory for trustworthy autonomous intelligence. Safactory integrates three tightly coupled platforms: a \textbf{Parallel Simulation Platform} for trajectory generation, a \textbf{Trustworthy Data Platform} for trajectory storage and experience extraction, and an \textbf{Autonomous Evolution Platform} for asynchronous reinforcement learning and on-policy distillation. As far as we know, Safactory is the first framework to propose a unified evolutionary pipeline for next-generation trustworthy autonomous intelligence.

### 2. 方法论：核心思想与关键技术
Safactory 由三大紧密耦合的平台组成：
*   **并行仿真平台 (Parallel Simulation Platform)**：
    *   **核心思想**：解决长程任务评估效率低和覆盖不足的问题。
    *   **关键技术**：采用预热环境池和异步调度实现高并发；引入**“回溯沙箱” (Backtracking Sandbox)** 机制，类似 Git 的版本管理，允许智能体在触发风险点时快速回滚并探索不同决策分支，提高风险探测的覆盖率。
*   **可信数据平台 (Trustworthy Data Platform - DataElf)**：
    *   **核心思想**：将原始日志转化为高价值资产。
    *   **关键技术**：**DataElf 引擎**支持自然语言驱动的数据任务编排；内置 23 种安全审计检查器（涵盖 13 类风险）；提供数据价值评估工具（如 DataElf Scorer），通过多维度评分和聚类选择，用不到 1/5 的数据量超越全量数据微调效果。
*   **自主演化平台 (Autonomous Evolution Platform)**：
    *   **核心思想**：支持大规模异步强化学习（RL）。
    *   **关键技术**：通过 **Bridge 模块**解耦采样与训练，解决策略版本滞后问题；支持**同策略蒸馏 (On-policy Distillation, OPD)**，利用教师模型信号约束学生模型的更新，增强训练稳定性。

### 3. 实验设计
*   **实验场景与数据集**：
    *   **QA Gym**：基于 OpenRT 框架进行多轮红队对抗。
    *   **OS Gym**：基于 OSWorld 和 RiOSWorld，评估桌面操作系统下的任务成功率与安全性。
    *   **Android Gym**：基于 AndroidWorld 和 GhostEI-Bench，测试移动端抗环境注入攻击能力。
    *   **Embodied Gym**：基于 Habitat 和 ALFRED，评估具身智能在 3D 环境中的表现。
    *   **OpenClaw Gym**：评估工具调用和多步决策能力。
    *   **Minecraft Gym**：评估视觉感知与长程规划。
*   **对比方法**：涵盖了 Claude-4.6-Thinking、Qwen3.5-Plus、Kimi-K2.5、GLM-5、DeepSeek-V3.2 等主流闭源和开源模型。
*   **基准测试 (Benchmark)**：使用了 AlpacaEval 2.0、MT-Bench、GSM8K 等通用指标，以及针对安全性的 Recall（召回率）对比（如对比 LlamaGuard、WildGuard 等）。

### 4. 资源与算力
*   **算力底座**：论文明确提到基于**昇腾 (Ascend) Atlas 800 A3** 系列超级节点和**鲲鹏 (Kunpeng)** 国内芯片。
*   **具体配置**：在 5.4 节的消融实验中，使用了 **8 张 GPU**（7 张用于 Rollout 采样，1 张用于训练更新）。
*   **技术优化**：通过 DeepLink 计算技术，实现了分布式分层存储和内核同页合并（KSM），单实例性能提升 50% 以上，内存占用减少 80%。

### 5. 实验数量与充分性
*   **实验规模**：报告展示了跨越 6 个不同领域（桌面、移动、具身、工具、QA、游戏）的广泛实验。
*   **数据量**：开源了 **SATraj-OS** 数据集，包含 10,496 条 GUI 交互轨迹和 15.8 万个交互步骤。
*   **充分性**：实验不仅对比了模型性能，还深入探讨了“能力与安全”的权衡关系（如 OS 场景中能力越强风险越高，而 Android 场景中能力与安全正相关）。安全审计实验对比了 4 种基准方法，覆盖 13 类风险，实验设计较为客观、全面。

### 6. 主要结论与发现
*   **安全性的“冰山模型”**：智能体风险多隐藏在长程交互和工具调用中，静态测试无法触达。
*   **能力不等于安全**：在 OpenClaw 等复杂工具场景下，模型能力的提升并未自然带来安全性的改善，甚至可能加剧风险。
*   **经验蒸馏的有效性**：通过轨迹分析工具提取的轻量化经验（Skills），在不改变模型参数的情况下，将 Kimi-K2.5 在 RiOSWorld 上的安全性从 32.17% 提升至 71.08%。
*   **异步架构优势**：Safactory 的异步 RL 架构比传统同步架构（如 slime-native）具有更高的资源利用率，轨迹生成吞吐量提升了 2.49 倍。

### 7. 优点
*   **系统性强**：首个将评估、数据、训练全流程打通的智能体工厂框架，而非单一的算法改进。
*   **工程创新**：引入“回溯沙箱”和“意图驱动数据引擎”，极大地降低了智能体开发和测试的门槛。
*   **生态适配**：深度适配国产软硬件生态（DeepLink + 昇腾），具有重要的实践参考价值。

### 8. 不足与局限
*   **评估指标局限**：长程任务的自动评分（Judging）依然困难，部分场景仍依赖预设的启发式规则。
*   **信用分配挑战**：在极其复杂的长程交互中，强化学习的信用分配（Credit Assignment）问题仍未完全解决。
*   **环境真实性**：虽然涵盖了多种 Gym，但与真实人类社会极其复杂的随机交互环境相比，仿真环境仍存在简化。
