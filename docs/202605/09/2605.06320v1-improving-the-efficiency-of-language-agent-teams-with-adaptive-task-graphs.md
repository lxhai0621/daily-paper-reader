## 摘要
大语言模型（LLMs）越来越多地以团队形式部署，但现有的协调方法往往处于两个极端。高度结构化的方法依赖于预先分配的固定角色、流水线或任务分解。相比之下，完全非结构化的团队虽然具备适应性和探索能力，但存在效率低下的问题，如错误传播、智能体间冲突以及资源浪费（以时间、Token 或文件操作衡量）。我们提出了用于任务演化的语言智能体团队（LATTE），这是一个受分布式系统启发的 LLM 团队协调框架，其中处理器必须在部分可观测性和通信限制下运行。在 LATTE 中，智能体团队协作构建并维护一个共享的、不断演化的协调图，该图编码了子任务依赖关系、单个智能体分配以及子任务进度的当前状态。该协议在保持一致性的同时，赋予智能体动态分配工作、调整协调并发现新任务的能力。在多项协作任务和多种基础模型中，我们证明了 LATTE 如何在减少 Token 使用量、实际运行时间、通信和协调失败（例如文件冲突和冗余输出）的同时，达到或超过包括 MetaGPT、去中心化团队、自顶向下的领导者-执行者层级结构以及静态分解在内的标准设计的准确性。

## Abstract
Large language models (LLMs) are increasingly deployed in teams, yet existing coordination approaches often occupy two extremes. Highly structured methods rely on fixed roles, pipelines, or task decompositions assigned a priori. In contrast, fully unstructured teams enable adaptability and exploration but suffer from inefficiencies such as error propagation, inter-agent conflicts, and wasted resources (measured in time, tokens, or file operations). We introduce Language Agent Teams for Task Evolution (LATTE), a framework for coordinating LLM teams inspired by distributed systems, where processors must operate under partial observability and communication constraints. In LATTE, a team of agents collaboratively construct and maintain a shared, evolving coordination graph which encodes sub-task dependencies, individual agent assignment, and the current state of sub-task progress. This protocol maintains consistency while empowering agents to dynamically allocate work, adapt coordination, and discover new tasks. Across multiple collaborative tasks and a variety of base models, we demonstrate how LATTE reduces token usage, wall-clock time, communication, and coordination failures (e.g. file conflicts and redundant outputs) while matching or exceeding the accuracy of standard designs including MetaGPT, decentralized teams, top-down Leader-Worker hierarchies, and static decompositions.

### 1. 核心问题与整体含义（研究动机和背景）
随着 LLM 智能体被广泛应用于复杂任务，如何协调多个智能体成为核心挑战。目前的协调模式存在两个极端：
*   **高度结构化（如 MetaGPT）：** 依赖预设的固定角色和流水线，缺乏灵活性，难以应对执行过程中新发现的子任务或错误。
*   **完全非结构化（如去中心化团队）：** 智能体自主协作但效率低下，容易产生错误传播、资源浪费（Token 和时间）以及严重的协作冲突（如重复修改同一文件）。

**LATTE 的目标**是在保持灵活性的同时引入必要的结构，通过动态演化的任务图来平衡一致性与适应性。

### 2. 方法论：核心思想与技术细节
LATTE 受分布式系统启发，将团队协作建模为对**共享动态协调图（DAG）**的维护过程。
*   **核心思想：** 任务图的节点代表子任务，边代表依赖关系。团队由一名**领导者（Lead）**和多名**执行者（Worker）**组成。
*   **混合协调模型：** 
    *   **领导者：** 拥有全局视野，负责维护图的一致性，执行具有全局影响的操作（如分配任务、验证结果、处理掉队者）。
    *   **执行者：** 拥有局部视野，负责执行具体子任务，并能根据执行情况提议修改图结构（如发现新子任务）。
*   **图变动算子（Mutation Operators）：** 定义了 7 种具有明确前置/后置条件的显式操作：
    1.  `DISCOVER`：添加新子任务。
    2.  `ASSIGN`：领导者指派任务。
    3.  `CLAIM`：执行者主动申领任务（类似分布式计算中的工作窃取）。
    4.  `COMPLETE`：标记任务完成。
    5.  `RELEASE`：释放长时间未完成的任务（应对掉队者）。
    6.  `CLOSE`：强制关闭任务。
    7.  `VERIFY`：插入验证节点进行质量控制。
*   **概率论动机：** 论文将任务图的演化视为一种近似后验推理过程，通过“提议-评估”机制（类似 Metropolis-Hastings 采样）来优化任务分解。

### 6. 主要结论与发现
*   **效率最优：** LATTE 在准确率-效率帕累托前沿上表现最佳。其 Token 成本仅为次优方法（静态图）的一半左右。

*   **应对掉队者：** 通过 `RELEASE` 机制，LATTE 有效解决了智能体“卡死”问题，将 95 分位任务完成时间缩短了 2.3 倍。
*   **自适应性：** 实验证明 LLM 团队能够自主利用 `VERIFY` 等算子，在遇到高不确定性任务时自动增加质量检查。

### 7. 优点
*   **透明度与可解释性：** 任务图将原本黑盒的智能体协作过程显性化，便于审计和诊断。
*   **动态扩展：** 允许在执行过程中发现新任务，克服了预规划（Pre-planning）无法应对未知情况的缺陷。
*   **上下文管理：** 通过任务图限制了每个智能体接收的信息范围，有效缓解了长上下文导致的推理疲劳。

### 8. 不足与局限
*   **规划开销：** 对于非常简单或极短的任务，初始化任务图的开销可能超过其带来的效率收益。
*   **领域局限：** 实验主要集中在代码和数据处理等具有清晰子任务边界的领域，在更开放、无结构的创意写作等任务上的表现尚待验证。
*   **团队规模：** 实验固定在 5 人团队，尚未测试在超大规模（如数百个智能体）团队中的扩展性。
