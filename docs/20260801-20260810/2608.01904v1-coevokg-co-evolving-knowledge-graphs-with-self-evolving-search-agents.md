## 摘要
大型语言模型可以通过强化学习来改进搜索代理，然而现有的自博弈代理在生成任务时会反复丢弃成功搜索过程中获得的知识。我们提出了CoEvoKG，一个将知识图谱同时作为可验证训练任务来源和代理进化的持久证据记忆的框架。CoEvoKG联合训练任务生成器和搜索代理：生成器根据从知识图谱中采样的实体链创建多跳问题，代理则从答案正确性的奖励和搜索轨迹（其实体路径由图谱证据支持）中学习。当搜索成功时，CoEvoKG会验证并对检索到的证据去重，然后将其写回相应的图节点和边。未来的轮次会利用这个增强后的图谱进行任务生成和奖励计算，从而在模型自我进化与知识积累之间形成闭环。在六个问答基准（NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA和Bamboogle）上，使用三个骨干模型的实验表明，在Qwen2.5-3B-Instruct、Qwen2.5-7B-Instruct和Llama-3.1-8B-Instruct上，CoEvoKG相对于相应基础模型的宏平均准确率分别提高了+11.2、+10.1和+11.6个百分点。在匹配的训练预算下，CoEvoKG在三个骨干上相比竞争性的自博弈基线和用于搜索代理的强化学习基线，进一步提高了+2.6到+3.7个宏平均分。代码可在https://github.com/lazzy1225/CoEvoKG获取。

## Abstract
Large language models can improve with reinforcement learning for search agents, yet existing self play agents repeatedly generate tasks while discarding the knowledge gained during successful searches. We introduce CoEvoKG, a framework that turns a   knowledge graph into both a source of verifiable training tasks and a persistent evidence memory for agent evolution. CoEvoKG jointly trains a task generator and a search agent: the generator creates multihop questions from entity chains sampled   from the knowledge graph, while the agent learns from rewards for answer correctness and search trajectories whose entity paths are supported by graph evidence. When a search succeeds, CoEvoKG verifies and deduplicates the retrieved evidence, then   writes it back to the corresponding graph nodes and edges. Future rounds reuse this enriched graph for task generation and reward computation, closing the loop between model self evolution and knowledge accumulation. Experiments on six QA benchmarks   (NQ, TriviaQA, PopQA, HotpotQA, 2WikiMultiHopQA, and Bamboogle) with three backbone models show that CoEvoKG improves macro average accuracy over the corresponding base models by +11.2, +10.1, and +11.6 points on Qwen2.5-3B-Instruct,   Qwen2.5-7B-Instruct, and Llama-3.1-8B-Instruct, respectively. Under matched training budgets, CoEvoKG further improves over competitive self play baselines and RL baselines for search agents by +2.6 to +3.7 macro average points across the three   backbones. Code is available at https://github.com/lazzy1225/CoEvoKG.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：现有基于强化学习（RL）的搜索代理训练方法存在两个主要障碍：
  - **固定任务池的局限**：现有 agentic RL 方法（如 Search-R1）在固定人工编写的 QA 数据上训练，奖励验证虽然可控，但训练分布受限；扩展到更难的多跳任务成本高昂，而完全无约束的问题生成又容易产出模糊、不可回答或琐碎的问题。
  - **自进化不回馈知识**：自博弈方法（如 Search Self-Play, SSP）虽能自生成任务，但循环不稳定（任务过易/过难/不可验证），且**成功搜索后检索到的证据被直接丢弃**，没有作为可复用知识保留下来，导致模型无法持续积累知识。
- **整体思路**：CoEvoKG 将**知识图谱（KG）实体链**同时扮演两个角色：
  1. 结构化、可验证的多跳任务来源；
  2. 由求解器验证证据不断丰富的外部持久记忆。
  
  通过在"任务生成 → 求解搜索 → 证据写回"之间形成闭环，实现模型自进化与知识积累的协同演进。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 整体框架

CoEvoKG 联合训练两个策略：
- **生成器（Proposer）πp**：从知识图谱的实体链 c 中生成问题 q 和答案 a（选链上某实体），即 (q,a) ~ πp(·|c)
- **求解器（Solver）πs**：通过多轮搜索工具 T 回答问题，生成轨迹 τ 和最终答案 y，即 (τ,y) ~ πs(·|q,T)

联合优化目标：
- 求解器：max Ec~G, (q,a)~πp, (τ,y)~πs [Rs(q,a,c,τ,y)]
- 生成器：max Ec~G, (q,a)~πp [Rp(q,a,c;πs)]

其中 G 为动态演化的图记忆池，随训练不断被证据写回增广。

### 2.2 核心组件一：基于 KG 链的任务生成

- **证据链池构建**：基于 Wikipedia 的 KILT 知识源（以锚文本超链接关联文章），离线随机游走生成 2–3 跳实体链，边带自然语言关系标签（如"directed by"），节点保留文章段落作为证据。
- **链式生成器**：条件于实体链，选择任意链上实体作为答案，生成满足条件的问题：(i) 不逐字提及链上实体；(ii) 需要至少两跳；(iii) 答案唯一且简洁。
- **质量门控（Quality Gate）**：生成候选须通过硬性过滤（无答案泄漏）+ LLM 验证器评分（链忠实性、真正多跳、单一答案焦点、清晰度），公式 Q(q,a,c) = 1[no_leak] · Verify(q,a,c)。
- **种子回退**：生成失败时用人工 QA 种子替代，保持批次完整（种子回退率从约 0.40 降至约 0.25）。

### 2.3 核心组件二：路径支持与难度奖励

**求解器奖励**（答案正确性 + 路径支持）：
- Rs = Rans(1 + β·Spath)，其中 β=0.2，Spath 仅对正确答案生效（防幸运猜测）
- **路径支持分数 Spath** 计算流程：
  - 从求解器的推理步骤、查询和检索段落中提取实体路径 ĉτ
  - 对相邻实体对 (u,v) 计算关系一致性分数 M(u,v) = max(Mdirect, Mbridge)，基于实体的共现、相互提及、关系序列位置及一跳桥接
  - Spath = 几何平均，任何一跳缺乏支持都会使分数急剧下降，要求整条路径可追溯（Spath ≥ τpath）

**生成器难度奖励**：
- Rdiff = exp(-(ps - p⋆(t))² / 2σ²)，其中 ps 为求解器在 G 条采样轨迹中的成功率
- 目标成功率 p⋆(t) 从高到低退火（p⋆s → p⋆e），鼓励生成落在求解器当前能力边界附近的问题，既不太易也不可解性过低

### 2.4 核心组件三：验证图记忆（证据写回）

- 对同时满足 Rans=1 且 Spath ≥ τpath 的轨迹，将检索到的证据写回原生成链的对应节点和关系
- **去重机制**：按实体序列小写化哈希，新序列新增为链；重复序列仅合并新证据段落
- 写回后图池 Gt → Gt+1 变得更密集，后续轮次中生成器基于更丰富的上下文生成，验证器也有更多证据可用

### 2.5 优化算法

- 基于 veRL + SGLang 后端，异步多轮 rollout
- **求解器**：GRPO（组相对优势），每组采样 G=8 条轨迹
- **生成器**：REINFORCE++（累计折扣回报 + 全局批归一化），难度奖励在终止 token 接收
- 两策略均采用带低方差 KL 惩罚的 PPO 风格代理目标
- 每轮顺序：生成器采样 → 质量门 → 求解器 rollout → 更新两策略 → 证据写回

1. **闭环设计新颖**：将知识图谱同时作为任务源和证据记忆，真正实现从求解成功中积累知识并反哺训练，克服了现有自博弈方法"用完即弃"的根本缺陷
2. **奖励设计精细**：
