## 摘要
大型语言模型（LLM）智能体必须在长时间交互中保留可复用信息、控制有界的活动上下文，并恢复早期证据。现有方法通常分别优化长期记忆（LTM）和短期记忆（STM），而统一策略往往主要依靠轨迹级反馈进行训练，这为个体记忆决策提供的信用信号较弱。我们提出可验证记忆（VerMem），该框架将LTM、活动上下文和情节历史表示为不同状态，并通过单一记忆操作策略加以控制。七个原子操作使策略能够添加、修改或软删除LTM条目；将LTM检索到活动上下文；过滤或总结活动上下文；以及恢复选定的情节片段。VerMem通过监督微调初始化，并采用三阶段强化学习课程进行训练。局部验证器对可执行的记忆转换进行评分，全局验证器在任务完成后评估证据连贯性和终端记忆一致性。这些分数通过层次化信用分配与程序化计算的任务、证据召回、效率和约束信号相结合。验证器仅在训练期间使用。在五个基准和两个LLM骨干上，VerMem在绝大多数报告指标上取得最佳结果，并持续优于强记忆基线。在三个交互基准上受控在线令牌预算下，它也在比较方法中实现了最强的效率-性能前沿。代码可于 https://github.com/Sun-SYSU-24/VerMem 获取。

## Abstract
Large language model (LLM) agents must retain reusable information, control a bounded active context, and recover earlier evidence during long-horizon interaction. Existing methods commonly optimize long-term memory (LTM) and short-term memory (STM) separately, while unified policies are often trained primarily with trajectory-level feedback, which provides weak credit for individual memory decisions. We present Verifiable Memory (VerMem), a framework that represents LTM, active context, and episodic history as distinct states and controls them with one memory operation policy. Seven atomic operations let the policy add, revise, or soft-delete LTM entries; retrieve LTM into the active context; filter or summarize the active context; and restore selected episodic fragments. VerMem is initialized by supervised fine-tuning and trained with a three-stage reinforcement-learning curriculum. The local verifier scores executable memory transitions, and a global verifier assesses evidence coherence and terminal-memory consistency after task completion. These scores are combined with programmatically computed task, evidence-recall, efficiency, and constraint signals through hierarchical credit assignment. The verifiers are used only during training. Across five benchmarks and two LLM backbones, VerMem achieves the best result on the vast majority of reported metrics and consistently outperforms strong memory baselines. Under controlled online-token budgets on three interactive benchmarks, it also achieves the strongest efficiency--performance frontier among the compared methods. Code is available at https://github.com/Sun-SYSU-24/VerMem.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：LLM 智能体在长时程多步交互中，不仅要进行单步生成，还要**保留和适时使用任务相关信息**。现有工作通常将智能体记忆分为**长期记忆（LTM，持久知识）**和**短期记忆（STM，活动上下文）**，但往往分别优化其中一侧：
  - STM 方向侧重压缩和组织当前上下文；
  - LTM 方向侧重构建外部持久存储；
  - 少数统一策略（如 AgeMem）虽将 LTM/STM 操作纳入一个策略，但只用**轨迹级/结果级反馈**训练，对单个原子记忆操作缺乏精细信用分配。

- **三个核心挑战**：
  1. **异构记忆协调**：LTM 和 STM 作用状态和时间尺度不同，在统一决策过程中既要共享目标又要维持功能边界；
  2. **历史上下文恢复**：早期观察、工具输出或中间结论可能随子目标切换再次变得重要，需要在不引入大量无关历史的前提下恢复相关片段；
  3. **多粒度信用分配**：记忆操作的效用往往是延迟的，一个正确的写入可能要到后续检索才体现价值，而错误的过滤可能数步之后才导致失败，需要操作级和轨迹级兼顾的信用信号。

- **整体含义**：现有方法未能联合使用**操作级验证**和**轨迹级验证**来训练统一记忆策略。VerMem 正是针对这一缺口，提出“局部+全局验证器”引导的分层信用分配框架，使记忆管理策略可学习、可训练、可迁移。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想

- VerMem 把**长期记忆 Mt**、**活动上下文 Ct** 和**同任务情节历史 Ht** 作为三个分离概念状态，由**一个统一的记忆操作策略**同时控制三类操作：
  - LTM 维护：添加、修订、软删除；
  - STM 控制：检索、过滤、总结；
  - 历史上下文恢复：选择性恢复 Ht 中的早期片段。
- 训练采用**SFT 热启动 + 三阶段强化学习课程**，结合**局部验证器（操作级）**和**全局验证器（轨迹级）**进行分层信用分配。
- 两个验证器**仅在训练时使用**，推理阶段不引入额外验证调用。

### 2.2 状态与问题形式化

- 概念状态：`st = (q, Mt, Ct, Ht)`；
- 策略可见序列化：`xt = g(st)`，受 8192 token 限制，避免无界拼接 Ht；
- 记忆命令：`ut = (vt, ξt)`，其中 `vt ∈ V ∪ {∅}`，`V` 包含七种原子操作；
- 记忆转换：`˜st = Tm(st, ut)`；
- 任务/环境转换：`st+1 = Te(˜st, bt, zt+1)`，与记忆转换明确分离；
- 训练课程：`θSFT → θA（LTM）→ θB（STM）→ θC（联合）`。

### 2.3 原子记忆工具

- **LTM 工具**（3 个）：
  - `Add`：向 Mt 添加新条目；
  - `Update`：创建修订版而非覆盖；
  - `Delete`：软删除但保留历史记录。
- **STM 工具**（4 个）：
  - `Retrieve`：从 Mt 检索到 Ct；
  - `Filter`：从 Ct 移除低价值内容；
  - `SelectEpisode`：从 Ht 恢复同任务相关片段到 Ct；
  - `Summarize`：将 Ct 中内容替换为忠实摘要。
- 另有**空操作 ∅**，不改变 Mt/Ct，但仍作为可训练决策计入决策步数。

### 2.4 训练流程

- **SFT 热启动**：
  - 数据集 `DSFT = {(xi, v*, ξ*)}`，共 32,000 训练状态 + 4,000 开发状态；
  - 每个目标操作类型平衡（各 4,000）；
  - 由边界模板 + 冻结 DeepSeek-V3.2 教师生成候选，经七项确定性过滤筛选。
- **三阶段 RL**：
  - Phase A：仅 `VLTM ∪ {∅}`，关注 LTM 维护；
  - Phase B：仅 `VSTM ∪ {∅}`，在干扰项下训练 STM 和历史恢复；
  - Phase C：完整 `V ∪ {∅}`，在完整多步任务中联合训练；
  - 相邻阶段仅转移策略参数，记忆状态独立初始化。
- **状态化轨迹采集**：每个任务从相同初始状态采样 K=8 条轨迹组成候选组，用于归一化信用。

### 2.5 分层信用分配公式要点

- **局部优势**：
  - 由局部验证器对**可执行命令**给出相关性、证据支撑、局部进展、信息保真度四维评分；
  - 按操作类型归一化：`Alocal = (rlocal − μlocal_v) / (σlocal_v + ε)`;
  - 被拒绝的命令不送局部验证器，`Alocal = 0`。
- **全局优势**：
  - 轨迹结束后由复合全局分支给出：`rglobal = 1/4 (rtask + revid + rstate + reff)`；
  - 其中 `revid = 1/2 (rsup + vcoh)`，`rstate = vstate`；
  - 全局验证器仅提供 `vcoh`（证据连贯性）和 `vstate`（终端记忆一致性），其余为程序化计算；
  - 在同一任务候选组内归一化：`Aglobal = (rglobal − μglobal_q) / (σglobal_q + ε)`。
- **总信用**：
  `A_hier = λlocal·Alocal + λglobal·Aglobal − λconstraint·c`，文中设 `λlocal=λglobal=λconstraint=1`。

### 2.6 优化目标

- 采用 GRPO 风格的候选组归一化 + PPO clip：
  - token 级概率比 `ρt,k,j(θ)`；
  - 带 KL 正则 `βKL · dKL`；
  - 损失只作用于序列化记忆命令的 token，任务求解器输出、环境观测和填充 token 均不参与；
  - 同一命令内所有 token 共享 `A_hier`，但 `ρ` 和 `dKL` 逐 token 计算。

### 2.7 奖励与约束设计

- **三通道分离**：
  1. 局部语义奖励（仅可执行命令）；
  2. 复合全局轨迹奖励（任务正确性、支撑事实召回、全局验证器、效率）；
  3. 硬约束惩罚（无效工具、非法引用、越权删除、上下文溢出等）。
- 效率项：`reff = I[rtask ≥ δ]·(1 − Conline)`，δ=0.5，防止低成本的失败轨迹获得效率奖励。
- 约束成本 `ct,k` 直接分配到对应决策，不进入局部语义分。

    - 训练域只有 HotpotQA，跨域迁移证据虽好，但领域覆盖面有限；

    - 消融实验中“+LT 增益最大”等结论依赖单一训练域；
    - Qwen-Max 作为 judge 可能引入与 Qwen 骨干的潜在偏好偏差。

## 6. 主要结论与发现（续）

- **跨任务迁移**：仅在 HotpotQA 训练即可提升 ALFWorld、SciWorld、PDDL、BabyAI，且增益在多个任务上接近甚至超过了在这些任务上直接训练的基线。例如，Qwen2.5-7B 下，VerMem 在 ALFWorld 的 Success Rate 与 PDDL 的 Progress Rate 上明显领先于 Base 和 AgeMem，说明统一的记忆操作策略具备跨环境可泛化的能力。
- **效率与质量的统一**：在 1,000–5,000 token 的在线预算扫描中，VerMem 始终优于 Base 和 AgeMem，`TN@S*`（达到 40% 宏观平均成功率所需 token）显著更低，`SR@B*`（预算 2,500 时的成功率）更高。这表明 VerMem 不仅提升最终表现，还减少了达到目标所需的上下文预算，对长时程交互更友好。
- **组件的累积增益**：从 Base 逐步加入 LTM 工具、STM 工具、局部/全局验证器，每一步都带来稳定提升；其中 `+LT` 的增益最大，说明**LTM 正确维护**是整体收益的核心；`+noV → +V` 的进一步提升则验证了分层验证器信用的必要性。
- **本地与全局验证器的互补**：单独使用局部验证器或全局验证器均能改善性能，但两者结合的效果最好，支持“操作级信用 + 轨迹级信用”互补设计的合理性；没有验证器的 `VerMem-noVerify` 在多数任务上明显下降，证明损失函数中的语义验证信号不是可有可无的。
- **奖励分解的影响**：奖励消融显示，仅用最终答案正确性（Answer-Only）会损害效率和质量指标（如更高的 `TN`、更低的 `MQ`），而全回报（All-Returns）更有利于训练出平衡的记忆策略。
- **鲁棒性**：跨三个种子（42/43/44）的标准差较小，主指标排名基本稳定；在 Qwen3-4B 上性能甚至高于 Qwen2.5-7B，说明方法不依赖特定骨干。

## 7. 局限性与未来工作

- **训练域单一**：所有 SFT 和 RL 数据来自 HotpotQA（多跳问答），虽然验证了零样本迁移，但缺乏在更多样化的长期任务（如多智能体协作、持续学习、开放式对话）上的训练验证；某些任务的收益可能受训练域分布影响。
- **验证器依赖**：局部和全局验证器由冻结大模型担任，在训练阶段引入额外推理成本；论文未详细报告验证器的误差率、一致性，以及在更弱模型上训练时验证信号质量是否会下降。
- **记忆操作为离散模板**：当前动作空间是有限的七种原子操作加空操作，且参数（如更新内容、检索查询）由策略生成；未来可以扩展到更细粒度的记忆编辑（如字段级修改）、基于语义相似度的检索，以及可学习的记忆衰减机制。
- **未上升到元认知**：VerMem 虽然能够控制记忆操作，但缺乏对“我为什么需要记住这一段”的显式建模，也没有对自身记忆的不确定性做估计；未来可引入元认知信号（如记忆置信度、信息熵）来指导策略。
- **效率评估场景有限**：token 预算曲线只在三个模拟交互基准上计算，未覆盖真实 API 成本、验证器开销和训练算力；完整资源报缺少 GPU 明细。

## 8. 总体评价与启示

- **方法定位**：VerMem 是首个同时使用局部（操作级）和全局（轨迹级）验证器来训练统一 LTM/STM 记忆策略的工作，填补了“记忆操作缺少细粒度信用分配”的空白。其核心贡献不在于新的网络结构，而在于**训练信号的设计**——用验证器将不可微的语义目标转化为可训练的强化学习奖励。
- **实验设计亮点**：
  - 训练/评估严格分离，强有力地展示了策略的跨域泛化；
  - 同时报告性能与 token 效率，契合长时程智能体实际部署中的成本考量；
  - 多组对照和消融（动作空间、信用分配、奖励分解、种子鲁棒性）使得结论较为稳健；
  - 内部对照 `noVerify` 直接证明了验证器信用的价值，而非仅靠与外部方法比较。
- **可复现性**：超参数、数据构造流程、候选轨迹采样细节交代较清晰，但训练资源和验证器的具体模型版本（除 DeepSeek-V3.2 外）未完整披露，复现成本可能较高。
- **启发**：对记忆策略的研究可以不再纠结于“更聪明的存储结构”，而是关注“如何让策略知道哪些记忆操作值得做”；分层验证器提供了一种通用范式，未来可以应用到其他具有延迟反馈的智能体动作（如工具调用、人机对话中的澄清策略）。

## 9. 个人思考

- **为什么 HotpotQA 训练能迁移到 ALFWorld 等任务**：可能因为记忆操作的核心模式（何时添加、何时检索、何时过滤、何时总结）在语言层面是跨任务共享的；HotpotQA 的多跳结构迫使模型学会“证据的收集 → 维持 → 复用”，与具身任务中的中间状态跟踪存在结构同构性。这启发我们，结构化的语言任务可能比想象中更适合作为“记忆策略预训练”的语料。
- **分层信用分配的本质是“软教师”**：局部验证器像过程监督，全局验证器像结果监督，两者结合相当于提供了过程+结果的稠密奖励，缓解了强化学习中的稀疏回报问题。但验证器本身如果带有偏见，策略也会继承该偏见（如 Qwen-Max 作为 judge 可能偏爱 Qwen 风格的回答），未来可考虑多验证器投票。
- **对实践者的建议**：在当前记忆管理方法未成熟的情况下，先从“LTM 的三个操作 + 简单的检索过滤”开始，比直接上复杂图记忆或向量库更可能取得收益；VerMem 的“课程式”训练（先学单类工具，再学联合操作）也提示我们，向模型注入记忆能力应遵循由简到繁的顺序。
- **潜在改进方向**：用更小的验证器替代冻结大模型；将验证器本身作为可学习的价值函数进行联合训练；或者将记忆操作策略从离散命令扩展到“改写上下文”的连续生成，以更细粒度地控制信息流。
