## 摘要
跨会话持久化的LLM智能体会积累存储的记忆，这些记忆的有效性因内容类型而异，然而现有的记忆架构将所有记忆视为同等持久，并系统性地用过时事实污染检索到的上下文。我们表明，每个记忆的、按类型条件化的时间衰减（这是西部灌丛鸦情景记忆的一个特性）可以在外部LLM智能体记忆存储中作为自动分类系数π_i来操作化，从而产生ScrubJay-MEM：每个记忆被编码为联合绑定的What--Where--When元组，具有估计的易腐性π_i和效用视界τ_i，通过查询自适应评分检索，并在每次更新时以O(1)次LLM调用进行追溯修订。我们引入了时间泛化测试（TGT），一个具有保留时间间隔和泛化差距（GenGap）指标的基准。在TGT上，ScrubJay-MEM是唯一具有显著正GenGap（+0.108）的基于检索的系统；在MemoryAgentBench EventQA-64k上，在LLM骨干下，它比Mem0的F1提高了+2.66，比Qwen3-Embedding-4B提高了+3.09。一次衰减消融使GenGap降低了5.7倍，证明类型条件化衰减是结果所必需的。在更强的骨干下收益变窄，在事实整合任务上收益反转，将贡献限定为对易腐事实的时间推理。

## Abstract
LLM agents that persist across sessions accumulate stored memories whose validity varies enormously by content type, yet existing memory architectures treat all memories as equally persistent and systematically contaminate retrieved context with outdated facts. We show that per-memory, type-conditioned temporal decay, a property of western scrub jay episodic memory, can be operationalized as an auto-classified coefficient $π_i$ in an external LLM-agent memory store, yielding ScrubJay-MEM: each memory is encoded as a jointly-bound What--Where--When tuple with an estimated perishability $π_i$ and utility horizon $τ_i$, retrieved by query-adaptive scoring, and revised retroactively at $O(1)$ LLM calls per update. We introduce the Temporal Generalization Test (TGT), a benchmark with held-out retention intervals and a Generalization Gap (GenGap) metric. On TGT, ScrubJay-MEM is the only retrieval-based system with substantially positive GenGap ($+0.108$); on MemoryAgentBench EventQA-64k it improves F1 by $+2.66$ over Mem0 and $+3.09$ over Qwen3-Embedding-4B under a llm backbone. A decay ablation collapses GenGap by $5.7\times$, establishing type-conditioned decay as necessary for the result. Gains narrow under stronger backbones and reverse on fact-consolidation tasks, scoping the contribution to temporal reasoning over perishable facts.

## 1. 核心问题与整体含义（研究动机与背景）

论文聚焦于一个在LLM智能体长期部署中日益严重的问题：**记忆时效性缺失**。

### 背景与动机
- **问题根源**：跨会话持久化的LLM智能体会积累大量记忆，而不同记忆的有效期差异极大——用户的职业可能数年内不变，会议室地点到下午就过时，当前分支名称甚至撑不过午餐时间。
- **现有方案的根本缺陷**：主流记忆架构（MemGPT、Mem0、A-MEM等）将所有记忆视作同等持久，检索时缺乏有效的时间衰减机制。这意味着随着记忆库增长，过时事实对检索上下文的污染会系统性加剧。
- **朴素修复方案的失败**：对所有记忆使用统一衰减率不可行——统一衰减要么过度折扣稳定知识，要么过度保留短暂事实；二元短期/长期划分也覆盖不了真实的连续衰减谱系，论文观察到实际存在至少四种可区分的衰减速率。
- **认知神经科学启发**：西部灌丛鸦在食物缓存恢复中展现出精确的"什么–哪里–何时"（What–Where–When, WWW）情景记忆能力，并**按食物类型区分衰减率**（蠕虫易腐而花生耐久），还能根据环境信号回溯修正缓存记忆。这为设计具有类型条件衰减的记忆系统提供了生物学模板。
- **核心论证**：解决时间记忆问题的关键是实现**逐记忆（per-memory）、类型条件化（type-conditioned）、可回溯修订（retroactively revisable）** 的衰减机制——这三个属性是现有智能体记忆系统所不具备的。

## 2. 方法论：ScrubJay-MEM 架构

ScrubJay-MEM是一个五部分构成的记忆系统，将灌丛鸦的四种认知机制转化为可计算的计算组件。

### 2.1 情景记忆单元（Episodic Memory Unit, EMU）
每条记忆 $m_i$ 存储为集成四元组：
- $w^{\text{WHAT}}_i \in \mathbb{R}^{d_1}$：语义内容嵌入
- $w^{\text{WHERE}}_i \in \mathbb{R}^{d_2}$：任务/上下文嵌入
- $(t_i, \tau_i)$：创建时间戳 + 估计效用期
- $\pi_i \in (0,1]$：易腐性系数（π≈1为短暂事实，π≈0为稳定知识）

四条信息通过**确定性门控融合**绑定为单个向量：$h_i = 0.55 w^{\text{WHAT}}_i + 0.35 w^{\text{WHERE}}_i + 0.10 \sigma(w^{\text{WHAT}}_i \odot w^{\text{WHERE}}_i)$，并加入对数刻度的时序位置偏移。

### 2.2 类型条件的易腐性效用函数
核心公式为：$U(m_i, t_q) = V_i \cdot \exp\left(-\pi_i \cdot \frac{t_q - t_i}{\tau_i}\right)$

关键特性是衰减率按记忆类型区分，论文定义了四种类型：稳定知识（π≈0.05–0.15，周至月）、程序性/技能（π≈0.2–0.4，天至周）、任务特定推理（π≈0.5–0.7，小时至天）、短暂交互（π≈0.8–1.0，分钟至小时）。(π, τ) 在存储时由LLM提示分类器自动估计（含关键词启发式回退）。

### 2.3 集成WWW检索+超图传播
检索评分结合四个信号：语义相似度（What）、上下文相似度（Where）、时态效用（When）、图邻域传播（Graph），权重 $[\alpha_q, \beta_q, \gamma_q, \delta_q]$ 通过**查询自适应加权**（关键词触发偏置 + softmax）动态调节，如含"latest/recent/today"的查询自动上调When权重。记忆库组织为带三类边（语义、上下文、时间共现）的**超图**，通过一跳消息传递实现图奖励传播。

### 2.4 回溯上下文整合（Retroactive Contextual Integration, RCI）
当新信息改变了旧记忆的语义优先级时，RCI以 **O(1)次 LLM调用** 完成参数更新：先计算新信息与记忆的阈值亲和度，再对V（加性）、π（加性裁剪）、τ（乘性更新）轻量更新。论文给出**命题1**：单次更新的所有参数变化有界，WHAT嵌入以收缩因子 $(1-\eta_w\alpha_{in})$ 向新证据几何收敛。

### 2.5 前瞻记忆缓冲（Prospective Memory Buffer, PMB）
任务执行前预加载最可能需要的K条记忆，实现两级检索（先缓冲后全库），达到 **O(K + (1-P_hit)·N)** 的期望亚线性检索成本（命题2）。

### 2.6 其他组件
- **未来导向编码**：存储时附加"何时会有用"的LLM注释，引导嵌入朝向未来检索场景
- **价值加权记忆整合**：会话末尾按效用阈值剪枝，但保留低效用高连接的枢纽节点

|----------|----------|

### 结论要点
1. **类型条件衰减是时间泛化的必要机制**——对所有其他指标影响甚微（≤1.3个百分点），唯独GenGap移动+8.9个百分点
2. **统一衰减率无效**——naive recency（B5，GenGap −0.046）甚至劣于无时间模型（B3，−0.022），直接反驳单一全局衰减率的猜想
3. **ScrubJay-MEM的核心贡献范围**：面向易腐事实的时间推理，在资源受限（小骨干模型）的实际部署场景增益最大
4. **与RAG-prompt方法互补**：ScrubJay-MEM以架构成本编码时间有效性而非逐查询的推理成本，占据不同的帕累托前沿点

### 方法局限
- **v1系统大量使用参数自由的替代方案**：融合权重（0.55/0.35/0.10）、图边权重和自适应加权头均为启发式，论文坦言训练版MLP变体留待未来
- **任务适用性有明显边界**：在事实整合（fact-consolidation）任务上，类型条件衰减**主动有害**——抑制了整合步骤所需的过期事实可见性
- **π误分类风险**：如果LLM分类器将医疗/财务/安全关键信息误标为"短暂"，生产部署可能静默丢失敏感内容；论文在伦理部分建议以显式保留策略门控敏感类别的删除

### 偏差风险
- **分类类别与基准共享π范围**：TGT 的四种易腐性类别与架构内部分类法共享 π 范围，存在类别原语共享的潜在泄漏担忧；论文通过去衰减消融控制这一因素
- **自我偏好以外的评判偏差**：虽然跨家族评判器缓解了自偏好，但评判器本身的小模型能力（3B）可能限制对复杂答案的判断精度

### 应用限制总结
ScrubJay-MEM 的贡献应准确界定为：**面向易腐事实的时间推理检索器**——是平面检索器在事实整合任务上的补充，而非替代；是提示级时间推理在资源受限场景下的替代方案，而非对更强骨干模型的普遍增益。
