## 摘要
长文档视觉问答（LongDocVQA）要求多模态大语言模型（MLLMs）定位、整合并推理分布在多页文档中的异构元素。现有方法，包括端到端MLLMs、检索增强生成（RAG）流程和文档智能体，通常缺乏显式机制来表征和验证在推理过程中基础证据如何逐步组合，从而限制了答案的准确性和可追踪性。在本文中，我们将LongDocVQA视为显式证据图推理问题，而非隐式答案预测。为此，我们提出DocTrace，一种层次化框架，逐步执行证据定位、结构化文档解析和证据图推理，以实现显式的证据来源追溯。为有效学习这些能力，我们开发了一个两阶段训练框架：联合监督微调（SFT）首先初始化证据定位和图推理能力，随后采用任务特定的组相对策略优化（GRPO）并配以专门奖励，进一步优化这些能力。在MMLongBench-Doc、LongDocURL和SlideVQA上的大量实验表明，DocTrace持续优于现有的开源基线和专有MLLMs。与Qwen3-VL-8B-Instruct骨干相比，DocTrace在三个基准上分别实现了14.4、11.3和11.7个百分点的绝对提升。除了具有竞争力的性能外，DocTrace构建了具有显式节点级来源的可追踪证据图，为长文档理解提供了透明且可验证的推理。

## Abstract
Long Document Visual Question Answering (LongDocVQA) requires Multimodal Large Language Models (MLLMs) to locate, integrate, and reason over heterogeneous document elements distributed across multiple pages. Existing approaches, including end-to-end MLLMs, retrieval-augmented generation (RAG) pipelines, and document agents, often lack explicit mechanisms to represent and verify how grounded evidence is progressively composed during reasoning, limiting both answer accuracy and traceability. In this paper, we cast LongDocVQA as an explicit evidence graph reasoning problem rather than implicit answer prediction. To this end, we propose DocTrace, a hierarchical framework that progressively performs evidence localization, structured document parsing, and evidence graph reasoning to enable explicit evidence provenance. To effectively learn these capabilities, we develop a two-stage training framework: joint Supervised Fine-Tuning (SFT) first initializes evidence localization and graph reasoning abilities, followed by task-specific Group Relative Policy Optimization (GRPO) with dedicated rewards to further optimize these capabilities. Extensive experiments on MMLongBench-Doc, LongDocURL, and SlideVQA demonstrate that DocTrace consistently outperforms both existing open-source baselines and proprietary MLLMs. Compared with the Qwen3-VL-8B-Instruct backbone, DocTrace achieves absolute improvements of 14.4, 11.3, and 11.7 points on the three benchmarks, respectively. Beyond competitive performance, DocTrace constructs traceable evidence graphs with explicit node-level provenance, enabling transparent and verifiable reasoning for long document understanding.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务定义**：长文档视觉问答（LongDocVQA）要求多模态大语言模型（MLLMs）在跨越多页的、富含视觉信息的文档中（如文本、表格、图表、图示等异构元素）定位、整合并推理证据。
- **核心挑战**：LongDocVQA的本质困难在于**多跳推理**——从单页获得的中间结论必须与跨页分布的证据结合，才能得出最终答案。在高风险应用（如金融审计、医疗分析）中，仅仅给出正确的答案并不足够，用户还必须能够检查每个结论是如何从有根据的证据中推导出来的。

- **现有方法的不足**：
  - **端到端MLLMs**：在隐层表征中隐式聚合证据，难以检查各部分证据对预测的贡献；
  - **RAG方法**：将检索到的证据视为无序上下文，未建模证据在推理中的组合方式；
  - **智能体框架**：交互轨迹面向行动（action-oriented），没有显式表示证据间的依赖关系。
  - 三类方法共同的问题是**证据组合始终是隐式的**，使推理过程难以验证、监督和改进。

- **核心认识**：人类专家解决长文档推理时遵循层次化的从粗到细工作流——**证据定位 → 结构化证据解析 → 证据组合**，并显式建模证据如何支持中间结论、中间结论如何联合生成最终答案。受此启发，作者提出应将证据组合作为显式的推理对象，而非隐藏在隐层的潜在表征中。

## 2. 方法论：核心思想、技术细节与流程

### 2.1 总体框架

DocTrace将LongDocVQA重新定义为**显式证据图推理问题**，通过三个层次化阶段进行：

**Stage 1：证据定位（Evidence Localization）**
- 对所有文档页面进行统一降采样，以低分辨率文档图像和问题Q作为输入，预测相关证据页的索引集合：`P_evid = f_loc(D_low, Q)`；
- 仅将预测的证据页传递至后续阶段，大幅缩小推理空间。

**Stage 2：结构化文档解析（Structured Document Parsing）**
- 使用文档解析模型（PaddleOCR-VL-1.5）以原生分辨率处理定位的证据页，提取细粒度的布局元素；
- 每个元素表示为 `b_i = (t_i, x_i, c_i)`，其中 `t_i` 为语义类型（文本/表格/图示/图表），`x_i` 为边界框，`c_i` 为提取内容；
- 这些元素构成证据池 `B = {b_1, b_2, ..., b_M}`，作为后续图推理的原子证据单元。

**Stage 3：证据图推理（Evidence Graph Reasoning）**
- 在结构化证据池基础上显式构建证据图 `G = (V, E)`：
  - 每个节点对应一个有根据的证据块或中间推理结果；
  - 每条有向边表示推理依赖关系；
- 推理过程建模为 `P(A, G | B, Q) = P(G | B, Q) · P(A | G, Q)`：先构建证据图，再依据图生成最终答案；
- 由此每个推理步骤都明确基于文档证据，天然提供节点级证据溯源。

### 2.2 训练范式（两阶段）

**（a）训练数据构造**
- 针对现有基准仅提供问题-答案对、缺乏中间监督的问题，自动构建包含证据页和证据图的结构化监督；
- 将训练样本划分为四类代表场景：(1) 单页可回答；(2) 多页可回答；(3) 无关不可回答；(4) 细节缺失不可回答；
- 使用Gemini 3.1 Pro生成带证据的页面和证据图，再由GPT-5.5独立验证证据充分性和逻辑一致性，过滤后才进入监督语料。

**（b）联合SFT（Joint SFT）**
- 多任务联合优化证据定位与证据图推理：在低分辨率页面中预测证据页索引；在高分辨率页面+布局元素中学习生成证据图和最终答案。

**（c）任务特定GRPO对齐（Task-specific GRPO）**
- **定位奖励（Localization Reward）**：采用距离感知的软Fβ奖励，对接近真实页面的预测给予部分分数，同时偏向高召回；
- **图忠实度奖励（Graph Faithfulness Reward）**：`R_graph = w_h·R_hit + w_c·R_comp + w_s·R_struct + w_t·R_topo`，分别评估证据锚定、图完整性、结构有效性、依赖拓扑一致性；
- **答案正确性奖励（Answer Correctness Reward）**：`R_answer = α·R_exact + (1-α)·R_llm`，对确定性答案用精确匹配，灵活化答案用LLM验证语义等价；对不可回答问题奖励弃答、惩罚幻觉。

6. **Stage 1是主要瓶颈**：多页问题性能差距主要由证据定位覆盖率不足导致（单页78.3 vs 多页46.5），而非推理本身。

## 7. 优点

- **问题重建（Problem Reformulation）**：将LongDocVQA从“隐式答案预测”重定义为“显式证据图推理”，概念上具有原创性，直接回应可验证性需求；
- **层次化从粗到细的推理设计**：低分辨率全面扫描→高分辨率针对性解析，在效率和精度之间取得良好平衡（端到端推理时间从15.04秒降至7.33秒，prefill tokens减少2.3×）；
- **完整的训练体系**：SFT用于初始化、GRPO用于对齐，通过距离感知软奖励、图结构约束、反事实评估等精细设计，使训练信号与最终目标高度一致；
- **数据构造自动化**：利用Gemini生成+GTP交叉验证，解决了中间监督缺失的难题；
- **透明可验证性**：提供节点级证据来源，使推理可审计，对高风险应用场景意义重大；
- **严谨的因果评估**：通过反事实掩蔽（对照安慰剂控制）验证证据的必要性和特异性，在长文档VQA领域较为少见；
- **深入的错误定位分析**：区分训练/推理各阶段的贡献和瓶颈，为后续工作指明方向。

## 8. 不足与局限

- **训练数据依赖自动构建**：证据图和中间标注由闭源模型生成，虽然经过交叉验证，但本质上受限于教师模型的能力水平，可能存在系统性偏差或错误传播风险；
- **证据定位是主要瓶颈**：多页问题仅有46.5%的证据覆盖率，Page F1不足75%，Stage 1准确限制整体性能上限，且用512px低分辨率扫描可能遗漏细粒度跨页证据；
- **因果评估的局限性**：作者自认反事实评估只证明证据的行为重要性（输入扰动导致输出变化），并不能证明模型内部“真正”遵循显式证据图进行推理；
- **基准覆盖范围有限**：三个基准（MMLongBench-Doc、LongDocURL、SlideVQA）虽具代表性，但均偏重特定领域（学术论文、幻灯片）——对金融报告、医疗病历等高风险场景的泛化性尚未验证；
- **上下文窗口限制**：论文本身承认在128K上下文下，1568px分辨率在80页以上文档即溢出，Stage 1低分辨率和Stage 3高分辨率的协同虽然缓解了问题，但本质上仍是当前架构承受力的妥协方案；
- **数据构造的隐私与版权风险**：混合使用公开基准和自行收集的arXiv论文/技术报告来构建训练语料，在真实业务场景（如客户机密文档）中，训练数据的敏感性问题未予讨论；
- **不可回答问题处理的不稳定性**：Stage 1 GRPO曾导致不可回答问题精度暂时下降（66.0%←68.0%），表明答案性判断（answerability）与证据召回之间存在固有张力。
