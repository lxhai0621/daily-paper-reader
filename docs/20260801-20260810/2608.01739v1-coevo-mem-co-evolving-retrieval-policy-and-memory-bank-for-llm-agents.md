## 摘要
随着记忆在任务和会话间不断累积，长期LLM智能体的性能同时依赖于查询特定的检索和持续的记忆精炼。然而，现有方法通常要么优化记忆访问（通过迭代查询改写或自适应检索策略），要么优化记忆演化（如结构更新）。这种分离忽略了一个基本反馈回路：检索决定了哪些记忆获得使用信号，而更新后的记忆库会重塑未来的检索。我们提出CoEvo-Mem，一个用于协同进化检索策略和记忆库的闭环框架。对于每个查询，一个冻结的LLM生成路由特定的查询改写和路由先验，由轻量级残差路由器在线修正。检索到的上下文作为两个学习过程之间的耦合接口：任务结果将信用分配给路由决策，而轨迹条件反馈更新记忆值和图关系。这些更新改变了记忆在后续查询中的排序和选择方式，从而闭合反馈回路。为缓解耦合引起的非平稳性，CoEvo-Mem在固定记忆库更新路由器与固定检索策略演化记忆库之间交替进行。在七个多样化基准上，CoEvo-Mem取得了最先进的性能，展示了检索-记忆协同进化的重要性。

## Abstract
As memories accumulate across tasks and sessions, the performance of long-term LLM agents depends jointly on query-specific retrieval and continual memory refinement. However, existing methods typically optimize either memory access, through iterative query refinement or adaptive retrieval policies, or memory evolution such as structural update. This separation overlooks a fundamental feedback loop: retrieval determines which memories receive usage signals, while updated memory bank reshape future retrieval. We propose \textbf{CoEvo-Mem}, a closed-loop framework for co-evolving the retrieval policy and memory bank. For each query, a frozen LLM generates route-specific query rewrites and a routing prior, which a lightweight residual router corrects online. The retrieved context serves as the coupling interface between the two learning processes: task outcomes assign credit to routing decisions, while trajectory-conditioned feedback updates memory values and graph relations. These updates alter how memories are ranked and selected for subsequent queries, thereby closing the feedback loop. To mitigate coupling induced non-stationarity, CoEvo-Mem alternates between updating the router with the memory bank fixed and evolving the memory bank with the retrieval policy fixed. Across seven diverse benchmarks, \textbf{CoEvo-Mem} achieves state-of-the-art performance, demonstrating the importance of retrieval-memory coevolution.

## 1. 核心问题与研究动机

- **研究背景**：LLM智能体需要在长期交互中不断积累记忆，高效地存储、组织、检索和更新历史经验是长期记忆系统设计的核心挑战。现有工作大体分为两类方向：
  - **记忆访问（Memory-Access）方法**：通过RAG、查询改写、自适应检索来提升检索效果；
  - **记忆中心（Memory-Centric）方法**：通过价值更新、结构化组织或潜在记忆表示来改进记忆本身。
- **核心问题**：现有方法通常将检索策略与记忆演化分开独立优化，忽视了二者之间的**根本反馈回路**——检索决定了哪些记忆被暴露并接收任务反馈，而记忆库的更新又会重塑未来的检索结果。单独优化其中一个组件会导致另一个组件与新状态不匹配，难以实现系统性的持续改进。

## 2. 方法论：CoEvo-Mem框架

### 2.1 核心思想

CoEvo-Mem是一个**闭环（closed-loop）协同进化框架**，同时优化检索策略与记忆库，并保持回答LLM（answering LLM）完全冻结。检索到的上下文集合 \(A_t\) 是耦合两个学习过程的**接口**：任务结果通过它分配路由决策的信用，轨迹条件反馈更新记忆值与图关系。

### 2.2 关键模块与技术细节

1. **自路由查询改写器（SR-QR, Self-Routed Query Rewriter）**：
   - 冻结LLM分别生成**密集查询改写**（保留语义意图）和**稀疏查询改写**（强调实体与精确术语），以及初始的密集-稀疏路由先验 \(p_t^0\) 和置信度特征 \(\xi_t^0\)。
   - 若输出无效，则回退到原始查询与均匀先验，保证鲁棒性。

2. **先验引导的残差路由器（Prior-Guided Residual Router）**：
   - 可训练的查询编码器 \(\phi_\psi\) 与策略头 \(f_\omega\) 在线生成残差修正量 \(\Delta_t\)，叠加到冻结LLM先验上得到最终路由策略 \(\pi_t = \text{softmax}(\log \bar{p}_t^0 + \Delta_t)\)。
   - 策略头末层零初始化，确保初始策略与LLM先验完全一致。
   - 训练时通过**Beta分布采样**探索路由混合权重，用**REINFORCE（score-function）估计器**优化，并添加KL正则防止偏离先验。

3. **Q加权混合检索器（Q-Weighted Hybrid Retriever）**：
   - 融合密集语义相似度（embedding）与稀疏词法匹配（BM25），并加入**学习到的记忆效用值 \(Q_t(m)\)**，通过加权倒数排名融合（WRRF）得到综合分数。
   - 每个路由的改写数量进行归一化，防止某一路由因改写数量多而获得更大权重。

4. **时间图扩展（Temporal Graph Expansion）**：
   - 在初始候选池上选出top-k记忆后，扩展其时间邻居（前驱与后继），在扩展池上重新计算排名，使时间邻居在同一混合分数下竞争。

5. **类型化关系记忆图（Typed Relational Memory Graph）**：
   - 节点存储经验内容、描述、关键词、时间元数据、源轨迹和效用值。
   - 边类型包括 **Dense**（语义邻近）、**Sparse**（词法重叠）、**Time**（从早到晚的方向性延续）。
   - 图结构与检索通道形成严格对齐。

6. **轨迹条件的记忆更新（Trajectory-Conditioned Memory Update）**：
   - 用固定提示蒸馏训练轨迹为新记忆节点，记录奖励作为来源而非过滤条件。
   - 对暴露的记忆计算**TD式价值残差**：\(\delta_t(m) = R_t u_t(m) + \gamma \hat{Q}_t(m^{new}_t) - Q_t(m)\)，其中 \(u_t(m)\) 是任务归因分数。
   - 通过类型化路径（最多D条边）进行**关系信用传播**，将信用从暴露记忆传播到相关未暴露记忆，路径强度由关系衰减因子乘积决定。
   - 所有节点的更新均基于同一前更新快照同步完成，并投影到有效区间 \([Q_{\min}, Q_{\max}]\)。

7. **交替协同进化（Alternating Co-Evolution）**：
   - 为缓解耦合引起的非平稳性，采用**逐阶段交替更新**：Router阶段固定记忆图、只更新路由器；Memory阶段固定路由器、顺序演化记忆图。
   - 每个阶段完整遍历一次训练集，反复切换使每个组件始终面对对方的最新状态。
   - 若图初始为空，先附加一个Memory引导阶段。

## 6. 主要结论与发现

1. **检索-记忆协同进化有效**：在所有评估设置中，CoEvo-Mem均取得最高平均分，相比最强基线平均提升3.72个百分点，单项最高提升7.50个百分点（GPQA Diamond）；
2. **增益不是单一任务驱动**：最大提升出现在科学问答（+7.50）、工具使用（+6.33）、代码生成（+3.81）三类截然不同的任务上；
3. **SR-QR贡献显著**：移除后宏平均分数降低4.24个百分点，在固定记忆图的MC协议中将LoCoMo-MC和LongMemEval-MC错误率降低6.00和10.00个百分点；
4. **记忆演化作用明确**：移除后宏平均分降低4.80个百分点，对GPQA Diamond、LiveCodeBench和BFCL-thinking影响最大（分别下降10.00、7.62、5.94点）；
5. **交替训练优于同时或两阶段训练**：交替优化分别比Simultaneous和Two-Stage高1.92和3.33个百分点，证实了固定不活跃组件、逐阶段切换的有效性；
6. **训练收敛**：LoCoMo OpenQA训练和验证准确率分别达到87%和84%，交替协同进化的收益可泛化到留出问题。

## 7. 优点

- **问题洞察深刻**：清晰识别了检索与记忆演化之间被现有方法忽视的反馈回路，具有原创性；
- **方法论设计精巧**：残差路由器基于冻结LLM先验做在线修正，既保留LLM先验知识又允许任务奖励驱动自适应，避免了从头学习路由的高成本；
- **轻量高效**：唯一可训练参数仅为残差路由器（\(\psi, \omega\)），LLM全部冻结，训练开销低，且具备可迁移性（GPT-4骨干替代无需重训记忆系统）；
- **记忆图与检索通道严格对齐**：Dense/Sparse/Time三类边与三类检索通道精确对应，而非构建通用的辅助知识图，设计具有一致性；
- **工程严谨**：提供了完整的失败语义（无效输出保守处理）、同步更新快照机制、明确的评估协议和详细的实现契约，可复现性强；
- **实验覆盖全面**：多样化的任务类型、多次独立运行报告均值±标准差，消融设计规范，还包含跨骨干迁移实验。

- **可扩展性**：实验中只测试了单智能体单机环境，未涉及大规模多智能体并发读写、异步更新等复杂生产场景。
