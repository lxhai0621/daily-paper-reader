## 摘要
基于知识的视觉问答（KB-VQA）需要从外部来源检索实体知识，以回答基于视觉的问题。现有的检索增强系统存在两个关键局限性。首先，依赖单一检索模态造成了单源检索瓶颈，会遗漏仅能通过互补来源访问的 ground-truth 实体。其次，双塔逐点重排序器存在检索源盲重排序问题，因为它们忽略了检索来源和候选级检索先验，导致冗余的模态依赖。为了解决这些挑战，我们提出了 UniHEAR，一个用于异构源实体检索和重排序的统一轻量级框架。UniHEAR 为每个候选实体构建粗检索描述符，并引入检索引导的注意力模态门控，以根据该描述符调节模态注意力权重，并通过粗检索先验的熵加权源融合进行补充。一种结合对比学习与辅助模态保持损失的混合训练策略，在单一模型中统一了实体级和段落级检索。在 E-VQA 和 InfoSeek 上的大量实验表明，UniHEAR 实现了最先进的检索和 VQA 性能，在保持轻量级重排序架构的同时，相比最强基线将 Recall@1 提高了 6.7 和 1.2 个百分点。代码和模型可在 https://github.com/iven-luo/UniHEAR 获取。

## Abstract
Knowledge-Based Visual Question Answering (KB-VQA) requires retrieving entity knowledge from external sources to answer visually grounded questions. Existing retrieval-augmented systems suffer from two critical limitations. First, relying on a single retrieval modality creates a Single-Source Retrieval Bottleneck, missing ground-truth entities that are only accessible through complementary sources. Second, dual-tower pointwise rerankers suffer from Retrieval-Source-Blind Reranking, as they overlook retrieval origins and candidate-level retrieval priors, leading to redundant modality reliance. To address these challenges, we propose UniHEAR, a unified lightweight framework for heterogeneous-source entity retrieval and reranking. UniHEAR constructs a Coarse Retrieval Descriptor for each candidate entity, and introduces Retrieval-Guided Attentive Modality Gating to condition modality attention weights on this descriptor, complemented by Entropy-Weighted Source Fusion of coarse retrieval priors. A hybrid training strategy combining contrastive learning with an auxiliary modality-preserving loss unifies entity-level and section-level retrieval within a single model. Extensive experiments on E-VQA and InfoSeek demonstrate that UniHEAR achieves state-of-the-art retrieval and VQA performance, improving Recall@1 by 6.7 and 1.2 points over the strongest baselines while maintaining a lightweight reranking architecture. Code and model are available at https://github.com/iven-luo/UniHEAR.

## 1. 核心问题与整体含义

**研究动机**：KB-VQA（基于知识的视觉问答）要求模型从外部知识库（如 Wikipedia）检索实体知识来回答视觉问题。主流的 RAG（检索增强生成）采用"粗检索→精排→生成"三阶段流水线，但现有系统存在两个关键局限：

- **单源检索瓶颈（Single-Source Retrieval Bottleneck）**：粗检索只依赖单一模态（I2I 图像对图像、或 I2T 图像对文本）。I2I 侧重形态相似性，I2T 侧重语义一致性，两者候选集合重叠度低。在有限检索预算下，ground-truth 实体往往只被其中一种来源命中，导致召回上限被抑制。
- **检索源盲重排序（Retrieval-Source-Blind Reranking）**：现有的双塔逐点重排序器对所有候选赋予均匀的模态注意力，忽略了候选来自哪个检索源及其在粗检索中的置信度先验。这导致对已被粗检索利用过的模态产生冗余依赖，降低了重排序的判别力。

**整体含义**：本文指出系统化的解决思路是打通粗检索与精排之间的信息鸿沟，让大规模粗检索器产生的丰富先验信号（排名、相似度、分布统计量）显式地指导轻量级重排序器，并通过异构源互补覆盖来突破单源瓶颈。

## 2. 方法论

UniHEAR 是一个统一轻量级框架，核心思想是通过 **粗检索描述符（Coarse Retrieval Descriptor）** 作为桥梁，把粗检索的先验注入重排序过程。整体分三阶段：

**阶段一：异构源粗检索（Heterogeneous-Source Coarse-Grained Retrieval）**
- 同时对实体图像（I2I）和实体文本摘要（I2T）进行粗检索，构建两来源候选集 Cᵏᵥ、Cᵏₜ，取并集作为统一候选池。
- 对每个来源计算池级熵 Hₛ（公式 2，温度 τₕ 放大差异），衡量该来源 top-k 检索分布的集中度/可靠性。
- 为每个候选实体构造 **Coarse Retrieval Descriptor** D(e) ∈ R¹⁰（公式 3-4）：包含每源的归一化排名 rₛ、原始相似度 simᶜₛ、z 归一化相似度 zₛ、与 top-1 的相似度差距 δₛ、池级熵 Hₛ。缺失来源设为 0 并估算相似度。

**阶段二：检索引导的多模态实体重排序（Retrieval-Guided Multimodal Entity Reranking）**
- 基于 VISTA 编码器，对每个候选实体生成三种模态表示：多模态 Cᵢₜ、文本 Cₜ、视觉 Cᵢ。
- **RAMG（Retrieval-Guided Attentive Modality Gating，公式 5-9）**：将查询的多模态表示 Qᵢₜ 与三个模态表示做注意力，但注意力 logits 通过仿射调制参数 γ(D)、β(D) 进行条件调制，参数由粗检索描述符 D(e) 线性映射得到。初始化使 γ=1、β=0，即开始时退化为标准注意力，训练中逐步学习检索源感知的调制。最终加权融合得到段落级表示并取最大值作为实体重排序分数 simᵣ。
- **EWSF（Entropy-Weighted Source Fusion，公式 10-12）**：将粗检索分数以权重 rₛ/(Hₛ+ε) 重新纳入，Hₛ 越小（来源越可靠）权重越高，并对两来源相似度做尺度校准（池均值比 R）。最终分数 sim = simᵣ + sim꜀。

**训练目标（公式 13-17）**：
- 主对比损失 L_con 训练融合表示。
- 辅助损失 L_aux 保持跨模态对齐能力（用于下游段落重排），并使用二进制掩码 ωₘ 过滤不可靠的正样本视觉监督。
- 总损失 L = L_con + λL_aux。

**阶段三：多实体段落增强生成（公式 18-19）**
- 对 top-kₑ 个重排实体按排名分配递减数量的段落（第 i 个实体分 kₛ-i+1 个段落），段落分数组合实体级分数与段落级 IT2T 匹配。
- 将检索到的上下文与图像、问题一并输入 MLLM 生成答案。

- RAMG 的检索引导调制与 EWSF 的熵加权融合各自均带来持续增益，且两者互补；粗检索描述符中 z 归一化与熵信息是最关键的信号。

## 7. 优点

- **方法层面**：轻量高效，197M 参数较 BLIP-2 基座（1.2B-1.7B）少 6-9 倍，却取得更好效果；单一模型统一实体级与段落级检索，无需独立段落重排器；粗检索描述符作为可解释、低成本的信息桥接机制，设计精巧。
- **实验层面**：消融设计细致（逐组件、逐阶段、逐模态、逐超参数），公平性分析较到位（池规模对齐、同编码器基座对比），从检索、VQA、效率多维度评估。
- **分析层面**：通过 oracle 曲线量化单源瓶颈的潜在空间；案例分析直观展示成功与失败模式，有助于理解方法边界。

## 8. 不足与局限

- **EWSF 的无监督失效风险**：论文承认训练无关的熵加权融合在来源置信度极端失衡时会失效——如某来源出现高相似度集中时，可能压制另一来源的正确候选信号（附录 D 案例）。未采用学习式来源可靠性估计。
- **对注释质量的依赖**：InfoSeek 无 ground-truth 段落注释，使用 jina-reranker-v3 生成的弱标注文本可能引入偏差；辅助损失中的视觉模态掩码策略也仅做启发式判断。
- **VQA 结果的覆盖度有限**：在 InfoSeek 上，无生成微调的配置（Qwen2.5-VL）比一些有生成微调的方法（如 ReAG）低约 9.5 个点，虽然在与同规模、同设置模型对比中占优，但"最佳"结论依赖具体配置条件；未在更大参数规模的生成器上验证（如 70B 级模型）。
- **算力披露不完整**：未报告总训练 GPU 小时数、峰值显存、推理延迟的详细分解（仅给平均每样本耗时）。
- **超参数敏感性**：熵温度 τₕ、融合权重 η 对不同数据集的敏感度差异较大（E-VQA 在 η 变化下跨度达 34.5 点），默认值是对两个数据集的折中而非全局最优，泛化性有限。
- **知识库规模限制**：InfoSeek 只用了 100K 子集而非完整 6M 页，E-VQA 的 2M 知识库与真实全量维基百科仍有差距，对大规模场景的可扩展性评估不充分。
