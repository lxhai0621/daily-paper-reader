## 摘要
长时程智能体依赖记忆来复用经验，然而现有记忆系统通常假设可以通过固定表示直接消费证据。这会导致表示不匹配，即相关信息可用但未针对当前决策进行组织。为此，我们提出MemPrism，一种任务条件化的关系记忆框架，将持久经验存储与决策时的工作记忆分离。MemPrism将交互记录为事件流，并根据当前任务上下文动态构建关系视图。一个轻量级视图策略选择关系结构、证据范围、结果条件和粒度，而确定性组合器与渲染器将历史事实转换为临时的光学工作记忆视图，以供冻结的任务策略使用。在长时程具身和网络智能体基准上的实验表明，MemPrism持续提升任务性能，尤其是在轨迹变长时，同时减少了记忆令牌消耗。此外，学习到的视图策略无需额外适配即可跨不同VLM迁移，展示了任务条件化关系视图作为智能体通用记忆接口的有效性。

## Abstract
Long-horizon agents rely on memory to reuse experiences, yet existing memory systems often assume that evidence can be directly consumed through a fixed representation. This leads to representation mismatch, where relevant information is available but not organized for the current decision. To this end, we propose MemPrism, a task-conditioned relational memory framework that separates persistent experience storage from decision-time working memory. MemPrism records interactions as the event stream and dynamically constructs relational views according to the current task context. A lightweight view policy selects the relation structure, evidence range, outcome condition, and granularity, while a deterministic composer and render transform historical facts into a temporary optical working-memory view for a frozen task policy. Experiments on long-horizon embodied and web-agent benchmarks show that MemPrism consistently improves the task performance, especially as trajectories become longer, while reducing memory token consumption. Furthermore, the learned view policy transfers across different VLMs without additional adaptation, demonstrating the effectiveness of task-conditioned relational views as a general memory interface for agents.

## MemPrism：面向长时程智能体的任务条件化关系记忆视图

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：长时程智能体（long-horizon agents）依赖记忆来复用经验，但现有记忆系统普遍假设检索到的证据可以通过“固定表示”直接服务于当前决策，导致**表示不匹配（representation mismatch）**问题——相关信息虽已存储并检索到，却未以当前子任务所需的关系形式组织，因而无法有效支持决策。
- **与存储失败、检索失败的本质区别**：表示不匹配发生在“检索之后、决策之前”的读取接口处。即智能体掌握了正确证据，却因呈现方式不对而仍可能失败。
- **关键观察**：同一段历史事实，在不同任务下需要不同的组织方式。例如循环检测需要按动作-结果对齐、状态追踪需要把同一实体的变化按时间分组、故障分析需要连接动作与环境反馈、依赖分析需要关联轨迹中相距较远的相关事件。时间线、状态表、动作效果视图、依赖追踪可能源于同样的事实，却突出了不同类型的证据。
- **提出的原则**：持久记忆应保存稳定可复用的交互事实，工作记忆应为当前决策动态构建，而非依赖固定表示。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 核心思想

MemPrism 将**持久经验存储**与**决策时工作记忆**解耦：持久侧保存统一、可复用的事件流；决策时根据当前任务上下文，动态构建临时的、任务条件化的关系视图，供冻结的任务策略使用。

#### 总体架构：五个模块

| 模块 | 功能 |
|---|---|
| **Recorder（记录器）** | 持久事件记忆。将每次真实交互以原始和结构化形式存储为事件流，绝不写回摘要或历史视图。 |
| **Router（路由器）** | 决策条件化视图路由。根据当前观察、任务目标、近期事件特征和全局历史统计，从144个联合视图动作中选择一个。 |
| **Composer（组合器）** | 关系视图构建。按所选视图动作，从事件流中选择事件并构建关系结构。 |
| **Render（渲染器）** | 光学工作记忆。将关系结构确定性渲染为二维光学视图（临时工作记忆）。 |
| **Adapter（适配器）** | 仅训练阶段使用。通过两阶段学习训练Router。 |

#### 关键技术细节

- **事件流表示**：原始事件 $e_t = (o^-_t, u_t, y^+_t, r_t, m_t)$ 经事件提取器Φ和规则校验映射为结构化事件 $\tilde{e}_t = (t, e^{ent}_t, e^{act}_t, e^{out}_t, \Delta s_t, \xi_t)$。结果类型分为异常（exception）、状态更新（state_update）、无观察变化（no_observed_change）三类。
- **视图动作空间**：联合视图动作为四因子组合 $a^v_t = (\tau_t, w_t, c_t, \gamma_t)$：
  - 关系类型 $\tau$：TemporalTrace（时间追踪）、ActionEffect（动作效果）、EntityState（实体状态）、DependencyChain（依赖链）
  - 时间范围 $w$：recent_short（6条）、recent_long（10条）、all
  - 结果过滤 $c$：all、exception、state_update、no_observed_change
  - 粒度 $\gamma$：coarse、medium、fine
  - 总动作空间：4 × 3 × 4 × 3 = **144**，联合分布建模以保留因子间依赖关系。
- **视图语义**：TemporalTrace 按时间排序展示动作顺序与任务进度；ActionEffect 按"动作-实体"分组对齐重复尝试与结果；EntityState 按实体与状态键分组展示状态演化；DependencyChain 以最新事件为锚构建局部依赖链（非验证因果图）。
- **光学视图作为输出界面**：利用二维布局表达关系语义——空间邻近表示分组、行列对齐支持状态对比、箭头表达变化或依赖、高亮标记失败与任务相关证据。
- **Adapter 两阶段训练**：
  - **阶段一（SFT）**：视图教师根据决策状态和参考动作给出软分布 $q_T(a|t)$，Router 最小化 KL 散度 + 结构代价正则项 $L_{SFT} = KL(q_T \| \pi^v_\theta) + \lambda_C \sum_a \pi^v_\theta(a|z_t)\hat{C}_t(a)$。
  - **阶段二（GRPO）**：在在线环境中用分组 GRPO 精调。同一任务的轨迹共享归一化优势 $A_i = (R_i - \mu_g)/(\sigma_g + \epsilon)$，更新目标包含裁剪项、参考策略 KL 约束和熵奖励项。**仅更新 Router**，其余模块全部冻结。
- **推理流程**：当前观察→Router 选择视图动作→Composer 按范围/过滤/粒度选择事件并构建关系结构→Render 渲染光学视图→冻结任务 VLM 读取当前输入+视图输出环境动作→只有执行的动作和反馈追加到事件流，视图立即丢弃。

### 6. 主要结论与发现

1. **表示不匹配是真实瓶颈**：在相同证据窗口下，不同固定关系视图导致成功率从30.00%到35.71%不等，直接验证了"证据正确但组织不当"会导致失败。
2. **动态组织与光学呈现互补增益**：光学呈现独立贡献3.57个百分点，动态组织独立贡献5.00个百分点，两者组合效果最佳。
3. **自适应粒度是最关键的因素**：固定细粒度导致最大降幅（-7.84点），其次为固定视图类型（-4.99点），说明"以何种详细程度呈现历史"对决策影响最大。
4. **上下文条件化选择优于频率匹配**：频率匹配随机（30.71%）远低于上下文条件化的SFT（34.29%），证明增益来自按任务状态匹配视图而非简单使用频率。
5. **长轨迹下优势持续扩大**：在≤50步时，MemPrism 较 Full History 高9.3个百分点（40.7% vs 31.4%），而token消耗反而降低33.6%（797 vs 1,201 tokens）。Full History 在≤30步后趋于平台期，MemPrism 仍在增长。
6. **视图策略可跨VLM零样本迁移**：同一 planner 应用于4个不同VLM均带来SR提升（+2.26~+9.40个百分点）和token压缩（30.64%~48.15%），说明任务条件关系视图是一种通用的记忆接口。

### 7. 优点

- **问题定义新颖且有深度**：将"表示不匹配"从存储失败和检索失败中独立出来，定位为读取接口处的工作记忆决策问题，概念清晰、界定明确。
- **架构设计具有解耦性**：持久事件流与临时工作视图分离，避免固定摘要和重复压缩造成的不可逆失真；视图仅服务当前决策、永不回写。
- **训练目标聚焦**：两阶段"动作条件软监督 + 轨迹级分组GRPO"隔离了视图选择的效果，使性能提升可更直接归因于记忆表示接口，而非任务策略的协同变化。
- **光学视图不仅是压缩手段**：二维布局编码了关系语义（邻近=分组、箭头=依赖、高亮=失败），是将"表示"与"关系结构"统一的设计。
- **公平的基线接入协议**：所有外部基线使用官方实现、相同任务策略、相同提示槽位，对需额外训练的基线（CFG-SFT）和RL型方法（AgentOCR RL版、MemOCR）做了明确排除和说明，避免混淆。
- **广泛的分析视角**：除主实验结果外，还提供长程行为分析、跨VLM迁移验证、分辨率敏感性、视图选择分布统计等，增强了结论的可信度与可迁移性。
- **可复现性保障**：附录含详细训练配置、提示词模板、模型版本、哈希校验与运行清单说明。

### 8. 不足与局限

- **绝对性能仍偏低**：Mind2Web 总体动作准确率仅12.87%，虽优于基线但终端可用性有限；EB-ALFRED平均SR仅17.7%，距离实际部署仍有很大差距。

- **缺乏统计显著性报告**：主结果只报告单次成功率和点估计，未给出多次运行的均值和标准差（尽管附录提到存档Wilson区间和配对bootstrap区间，正文未展示）。
- **跨模型迁移仅报告零样本增益方向**：未讨论迁移效果的稳定性、不同VLM间的差异原因（如为什么MiniCPM-V-2.6上的增益最大），模型规模与增益幅度的关系也未分析。

### 9. 总结与综合评价

MemPrism 的核心贡献在于将长时程智能体的记忆问题从"存什么、怎么取"推进到"以什么关系形式呈现"，通过持久化事件流与决策时动态关系视图的分离，系统性地验证了"表示不匹配"是独立于存储失败和检索失败的真实瓶颈。其144维联合视图动作空间配合两阶段训练（软标签SFT + 轨迹级GRPO），在三个异构基准（文本家务、视觉具身、Web交互）上一致性地超越了包括图记忆、Zettelkasten、长期+工作记忆在内的主流基线，并在长轨迹场景下同时实现性能提升与token压缩，展现出作为通用记忆接口的潜力。机制消融清晰归因了动态组织、光学呈现与自适应粒度的各自贡献，跨VLM零样本迁移进一步佐证了该接口的通用性。

但该方法仍处于研究原型阶段：绝对性能距离实用部署有明显差距（Mind2Web约13%、EB-ALFRED约18%、Visual子集全部为0%），训练成本较高（8×H200、每基准约24–48小时），且缺乏统计显著性报告与大规模模型验证。未来工作可沿三条路径展开：一是将视图动作空间扩展为连续/可学习的关系表示，摆脱人工定义的离散因子；二是将Router与任务策略进行联合但受控的训练，探索表示接口与决策策略的协同进化；三是在更长交互跨度（数百步以上）和更复杂环境（多智能体、开放世界）中检验该机制的扩展性。总体而言，MemPrism 提出了一个有清晰问题意识、完整方法论、充分实验支撑的记忆表示新范式，对长时程具身智能体和交互式Web智能体的记忆系统设计具有重要参考价值。
