## 摘要
基于学习的记忆系统在自进化LLM智能体中面临两个紧密耦合的挑战。首先，轨迹索引的效用随交互历史增长，从而将有限的反馈分散到一个不断扩展的状态空间中。其次，由于轨迹级奖励是对共同检索到的记忆联合分配的，不相关的经验可能获得误导性的效用更新，并因此陷入记忆-奖励陷阱。为了解决这些挑战，我们引入了降阶记忆强化学习（RoMeRL），它使用一个由结果极性和记忆动态因子化的固定维度每任务记忆状态来表示不断增长的轨迹索引效用空间。RoMeRL通过一组固定的语义坐标来纳入新经验，这些坐标的内容随时间更新或替换，从而将反馈集中在一个有界的效用支持上。理论上，我们证明了这种降阶参数化增加了每个效用坐标接收的平均反馈，并在通用坐标转换模型下刻画了错误坐标的稳态占用。在ALFWorld和LifelongAgentBench上的实验表明，RoMeRL提高了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，并将LLM调用减少了21.1%。这些结果表明，降阶效用状态支持高效的自进化智能体记忆，同时限制了持续的奖励污染。代码可在以下网址获取：https://github.com/YOUNG-fnxm/RoMeRL

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. ### 1. 核心问题与研究动机

- **背景**：LLM 智能体本质上是无状态的，需要外部记忆系统来累积和复用历史经验。早期方法以手工工作流为主，随后发展为基于下游任务反馈的**学习型记忆系统**，通过更新记忆条目的效用值来实现"自我进化"，不修改底层 LLM 参数。
- **核心问题**：学习型记忆系统存在两个紧密耦合的挑战：
  - **反馈稀释**：每条新轨迹都会引入一个新的效用变量，使轨迹索引的效用空间随交互历史不断膨胀，而有限的反馈被分散到越来越大的状态空间中。
  - **记忆-奖励陷阱（Memory-Reward Trap, MRT）**：轨迹级奖励是共同分配给所有被检索记忆的，导致弱相关、过期或失败经验可能因出现在成功轨迹中而获得正向效用更新，即"因果归因偏差"。
- **根本困境**：单纯增加探索能提高反馈覆盖率，但也让更多弱相关记忆暴露于错误奖励信号中——**探索-污染两难**。这引出了论文的核心问题：*如何在扩展反馈覆盖的同时，不扩大面对错误奖励传播的效用支持？*

### 2. 方法论：RoMeRL

#### 核心思想
将轨迹索引的持续增长效用空间，替换为**固定维度的每任务语义状态**，按"结果极性 × 记忆动态"分解为 2×2 的坐标结构，将反馈集中到有界且稳定的效用支持上。

#### 关键技术细节

- **四个语义坐标**：
  - **PCC**（正合并坐标，Positive Consolidated）：保留全局最高效的成功轨迹，作为稳定可复现的参考。
  - **PAC**（正适应坐标，Positive Adaptive）：保留失败后首次成功的过渡轨迹，捕捉"失败→成功"的恢复模式。
  - **NCC**（负合并坐标，Negative Consolidated）：保留已积累正效用证据的失败经验（效用超过阈值时晋升至此），提供可复用的诊断性负面信息。
  - **NAC**（负适应坐标，Negative Adaptive）：保留最近一次失败轨迹，实时跟踪当前错误状态。
- **状态表示**：每个坐标存储一个代表记忆及其效用值，`Z_{g,t} = Φ(D_{g,t}) ∈ R^{2×2}`，新经验通过坐标内容的更新或替换（而非新增变量）纳入系统。
- **检索机制**：按语义相似度与学习效用的加权分数选择 Top-k 记忆进入上下文。
- **效用更新**：沿用标准 Q 学习更新公式；进入坐标的新代表继承原坐标效用作为热身起点，再通过后续反馈逐步调整。

#### 理论分析
- **定理1**（间隙-方差分解）：效用估计误差由统计方差和信用间隙（含基线项与归因偏差）两部分构成，更多反馈只能降低方差，无法消除信用间隙。
- **定理2**（反馈预算）：在保证全池估计误差不超过 ϵ 的条件下，所需反馈量随记忆数 Nt 线性增长，揭示轨迹索引方法固有的"维度成本"。
- **定理3**（反馈集中）：固定维度 d 的状态使每个坐标平均获得 kT/d 次反馈信号，将方差从 O(σ²Nt/kT) 降至 O(4σ²/kT)。
- **命题1**（错误坐标占用）：存在**清洁→错误**转移概率 γ 和**错误→清洁**转移概率 λ 时，稳态错误坐标占比不超过 γ/(γ+λ)，远低于全池水平，条件为 d·γ/(γ+λ) < Nt·ρ_full。
