## 摘要
代理式强化学习使大语言模型代理能够通过交互进行学习，但稀疏的轨迹级奖励仅揭示成功与否，却无法识别哪些中间决策应获得信用。仅训练阶段可用的特权技能能够提供更密集的监督：通过让同一冻结策略快照在基于任务匹配的程序技能条件下，对无技能轨迹中的固定token重新评分。然而，现有方法并未联合校准跨交互步骤的教师分数、将教师置信度与实际回报相关联，并将所得信号整合到原生奖励到优势的构建中。我们提出了基于自蒸馏奖励塑形的代理式强化学习（ADRS），一种为多轮语言代理构建与回报相关的token级信用框架。ADRS在每一步中对特权token分数进行中心化和归一化，通过基于组内置信度-回报关联的、与回报相关的教师价值优势（TVA）门控对其进行调制，并将门控后的token信号纳入原生强化学习信用构建中。这些组件共同决定了教师偏好什么、该偏好何时与回报相关，以及它如何进入原生强化学习信用路径，同时保持轨迹采样和推理过程无需技能。最后，在三个交互基准上的实验表明，ADRS在长视界任务上持续提升性能，且这些增益在多种强化学习骨干、数据缩减设置、未见任务和延长训练中均能保持。为便于匿名评审，我们的代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. ## 1. 论文的核心问题与整体含义

- **研究动机**：多轮语言智能体（LLM Agent）在交互式任务（如具身控制、网页导航、搜索问答）中，通常利用强化学习（RL）进行策略优化。然而，环境仅提供稀疏的轨迹级最终奖励（轨迹成功与否），无法告知哪些中间查询、动作或 token 决策值得获得信用，导致 token 级时间信用分配（Temporal Credit Assignment）困难。
- **关键缺口**：现有方法（如 GRPO、GiGPO）主要依赖稀疏结果信号构建优势；而基于特权技能/自蒸馏的监督方法（如 OPSD、SDAR 等）虽然提供了更密集的 token 级信号，但没有系统性地解决三个挑战：
  1. **分数校准**：教师 log-probability 在不同交互步骤之间的偏移和尺度差异大，不可直接跨步比较；
  2. **可靠性估计**：教师自信不一定与真实回报相关（教师偏爱语言上更"标准"但非决定成败的 token）；
  3. **信用整合**：教师信号若通过独立辅助目标引入，会绕过原生 RL 的 reward-to-advantage 路径，与组相对优势存在错位。
- **整体含义**：论文提出 **ADRS（Agentic Reinforcement Learning with Self-Distilled Reward Shaping）** 框架，将训练时才可用的"特权程序技能"转化为与回报相关联的 token 级训练奖励，从而在不改变 rollout 和推理阶段"无技能"设定前提下，提高长期任务的学习效率和最终性能。

## 2. 方法论：核心思想、关键技术与算法流程

- **核心思想**：ADRS 作为位于"轨迹收集"与"actor 优化"之间的信用构建层，利用训练时特权信息重新校准并注入 token 级信用，并使其进入原生 RL 的 reward-to-advantage 路径。整体训练流程为：
  1. 行为策略在无特权文本下采样多条轨迹；
  2. 冻结同一策略快照，对已采样的 token 分别在普通上下文和技能条件下重打分；
  3. 通过三个模块将配对分数转化为优势调制信号；
  4. 更新 actor，进入下一轮迭代。推理时完全不使用技能。
- **模块一：Within-Step Relative Privileged Scoring（分数校准）**：
  - 对每一步内的特权 token 分数做 **去均值（centering）** 和 **尺度归一化（scale normalization）**：
    \(b_s = \frac{1}{|\mathcal{V}_s|}\sum_{j\in \mathcal{V}_s} \ell^T_{s,j},\quad q_{s,j} = \ell^T_{s,j} - b_s,\quad \hat{q}_{s,j} = q_{s,j} / (\sigma_q + \epsilon)\)
  - 关键性质：同一步内 \(\sum_j \hat{q}_{s,j} = 0\)，即**零和结构**，保证同名教师信号不会改变轨迹级总分。
- **模块二：Return-Associated TVA Reliability Gate（可靠性估计）**：
  - 通过 **Teacher Value Advantage（TVA）** 计算组内（GRPO 的 prompt 级或 GiGPO 的 step 级）教师置信度与返回的协方差，得到标量门控值：
    \(d_g = \mu^+_g - \mu^-_g = \frac{\mathrm{Cov}_g(\alpha, R)}{\bar{\alpha}_g(1-\bar{\alpha}_g)}\)
  - 经 sigmoid 转换得到门控 \(m_u = \sigma(\tau \tilde{d}_{g(u)})\)，并作用于该单元所有 token。
  - 支持 L2（轨迹级）和 L3（step 级）两种粒度，以及 TVA-off（\(m=1\)）配置。
- **模块三：Teacher-Guided Per-Token Advantage Modulation（信用整合）**：
  - 教师奖励 \(r^T_{s,j} = \eta m_{s,j} \hat{q}_{s,j}\) 先加入基础 token 奖励形成 \(\tilde{r} = r^{base} + r^T\)。
  - **轨迹路径**：对 \(\tilde{r}\) 使用骨干算法（GRPO/GiGPO）计算组相对优势 \(A^{traj}\)。由于教师信号的 step 零和性，轨迹路径保持原始环境方向（不改变轨迹排序）。
  - **token 路径**：在 prompt 组内对 \(r^T\) 做标准化得到 \(Z^T_t\)，作为 token 级调制信号。
  - 最终优势为 \(A^{ADRS}_{i,k,t} = A^{traj}_{i,k} + \eta Z^T_{i,k,t}\)；若 \(\eta = 0\) 则恢复原生算法。
  - 提出三个命题分别刻画：TVA 的协方差含义、教师奖励的 stepwise 零和与链式表示、以及 ADRS 在行为策略点与采样 token 辅助更新的局部一阶梯度等价性。

## 6. 主要结论与发现

- ADRS 在 **Qwen2.5-3B** 上于 ALFWorld（94.5% success）、Search-QA（45.0% macro-average）、WebShop（87.5 score / 76.6 success）三个基准中均取得最佳结果，较最强基线分别提升 +10.1、+0.4、+2.5/+8.6 个百分点。
- 增益在 **模型家族和规模间保持稳健**（Qwen2.5-3B/7B、Qwen3-1.7B 均优于最强基线），且在 **300 步长训练** 中持续存在（ALFWorld 最佳即 97.7%）。
- **推理时无技能**即可复现领先结果，说明训练阶段特权技能已被成功内化为策略知识。
- 数据效率实验表明：使用 **60% 训练数据即可超过全量数据的 GRPO**；在 unseen split 上平均提高 11.9 个百分点。
- 机制诊断发现：ADRS 信号在训练中持续将信用集中在任务决定性 token（动作/对象）上，而对风格性 token 信号压缩（action/style 幅度比达 95.3），解释了长视界任务上性能提升的原因。
- TVA 门控带来了额外且稳定的提升（ALFWorld 上 +0.8 峰值，+2.4 last-3），且 300 步延展训练仍然保持优势。

## 7. 优点

- **问题定义清晰，三阶段分解有解释力**：将"有效奖励利用"分解为分数校准、可靠性估计、信用整合，每个挑战对应独立且可插拔的模块，逻辑严密且各有理论命题支撑。
- **方法设计优雅且有理论依据**：
  - Step 内零和性质无需改变轨迹级排序；
  - TVA 门控具有明确的组内协方差统计含义，避免"自信即有用"的朴素假设；
  - 将教师信号作为"pre-advantage reward shaping"与辅助目标对比，理论上证明了局部一阶梯度等价性，定位明确。
- **工程实用性高**：完全兼容现有 GRPO/GiGPO 骨干，无需额外更大的教师模型，不增加推理开销；训练成本可控。
