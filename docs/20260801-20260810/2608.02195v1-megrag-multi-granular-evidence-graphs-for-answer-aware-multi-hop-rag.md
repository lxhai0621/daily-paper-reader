## 摘要
多跳问答是检索增强生成（RAG）中的一个基本挑战，因为推导答案需要整合分散的证据。迭代式RAG（iRAG）被广泛用于应对这一挑战，但现有方法存在两个局限性。首先，大多数方法仍以单一粒度的证据支持每个推理步骤，难以在信息密度和上下文噪声之间取得平衡。其次，现有方法通常仅在聚合了跨中间步骤检索到的证据后才回答原始问题，因此冗余证据和中间检索错误可能会累积并降低最终答案的质量。为解决这些局限性，我们提出了MEGRAG，一个答案感知的框架，将多跳推理表示为路径结构化的多粒度证据图。在离线阶段，MEGRAG通过跨粒度索引将段落与其句子和抽取的三元组链接起来。在线阶段，它为当前查询检索段落并选择对齐的证据，从紧凑的三元组开始，并根据需要添加句子或段落上下文。MEGRAG利用生成的中间答案和先前推理来判断初始查询是否已解决。如果没有解决，它会识别缺失信息并制定有针对性的下一个查询；否则，它停止检索并返回答案。大量实验表明，与多种RAG基线相比，该方法持续取得了性能提升。

## Abstract
Multi-hop question answering is a fundamental challenge in retrieval-augmented generation (RAG), because deriving an answer requires integrating dispersed evidence. Iterative RAG (iRAG) is widely used for this challenge, but existing methods have two limitations. First, most methods still support each reasoning step with single-granularity evidence, making it difficult to balance information density and contextual noise. Second, existing methods often answer the original question only after aggregating evidence retrieved across intermediate steps, so redundant evidence and intermediate retrieval errors may accumulate and degrade the final answer. To address these limitations, we propose MEGRAG, an answer-aware framework that represents multi-hop reasoning as a path-structured multi-granular evidence graph. Offline, MEGRAG links passages to their sentences and extracted triples through a cross-granularity index. Online, it retrieves passages for the current query and selects aligned evidence, starting with compact triples and adding sentence or passage context as needed. MEGRAG uses the resulting intermediate answer and prior reasoning to decide whether the Initial Query has been resolved. If not, it identifies the missing information and formulates a focused next query; otherwise, it stops retrieval and returns the answer. Extensive experiments demonstrate consistent gains over a diverse set of RAG baselines.

## 1. 论文的核心问题与整体含义

**研究背景与动机：**
- 多跳问答（Multi-hop QA）要求模型将分散在多个文档中的信息逐步整合，是RAG面临的典型挑战。
- 迭代式RAG（iRAG）通过交替检索-推理-查询重构来应对多跳问题，但现有方法存在两大局限：
  1. **单粒度证据问题**：大多数方法以单一粒度（段落、句子或三元组）支撑每一步推理。细粒度证据（如三元组）信息密度高但缺乏上下文，粗粒度证据（如段落）上下文完整但包含噪声，难以兼顾信息密度与上下文噪声之间的平衡。
  2. **错误累积问题**：现有方法普遍在完成所有中间步骤的检索与证据聚合之后才回答原始问题。中间步骤的冗余证据和检索误差会沿推理链逐步累积，最终损害答案质量。

**核心主张：**
- 人类推理是选择性且目标导向的：只寻求足以支撑判断的证据，并利用中间结论来识别未知信息、引导后续探索。MEGRAG以此为基础，将多跳推理建模为**路径结构化的多粒度证据图**，即“答案感知”（answer-aware）的推理过程。

## 2. 论文提出的方法论

**核心思想：**
MEGRAG将多跳RAG分解为两个阶段：离线构建统一的多粒度证据空间，在线构建问题特定的路径结构化证据图。每个推理步骤都生成中间答案，并基于“初始查询是否已解决”来决定继续检索还是停止。

**关键技术细节：**

**（1）离线多粒度证据空间**
- 构建三种粒度的证据视图：段落级（EP）、句子级（ES）、三元组级（ET）。
- 建立跨粒度索引 I，将句子和三元组链接到其来源段落。
- 段落提供广泛上下文（如实体消歧、跨句推理）；句子保留局部约束（如别名、时间线索、否定、比较）；三元组提供由大语言模型抽取的紧凑关系事实。
- 检索时仅检索段落，通过索引对齐召回到句子和三元组，避免在全语料上独立检索细粒度单元。

**（2）在线路径结构化证据图构建**
- 图 G(i) = (V(i), E(i))，每个节点 vi = (qi, Zi, bi, hi, mi, yi, si) 包含当前查询、所选证据、中间答案、已解析路径、剩余信息需求、初始查询答案和停止决策。
- **候选收集**：基于当前查询 qi 做向量检索，取 top-NP 段落，再通过索引对齐获取对应的句子集和三元组集（受 NS 和 NT 预算约束）。
- **自适应证据选择**：沿三元组 → 三元组+句子 → 三元组+句子+段落的顺序评估证据充足性，取第一个被判定充分的粒度组合作为 Zi；未选中的证据不进入后续推理。
- **推理决策**：基于 Zi 生成中间答案 bi，更新已解析路径 hi。如果累积信息尚不能回答初始查询，记录缺失信息 mi、设 si=0 并生成聚焦的下一查询 qi+1 及目标条件化转换关系 ri；否则设 si=1，以 yi 作为最终答案并停止检索。
- **停止条件**：达到步骤预算 B 仍未解决时，用有序证据（Z1,...,ZB）调用最终解析器生成答案。每个节点最多有一个后继节点，因此图退化为一条有向路径。

**（3）图构建蒸馏**
- 教师模型（Qwen3-Max）在训练问题上执行完整推理，生成轨迹 ξ = {(x, qi, Hi, Ci, oi)}。
- 学生模型（Qwen3-8B）通过LoRA微调，以极大似然损失 LGCD 学习在每一步复现教师的完整决策，包括证据选择、中间答案、停止判断和下一查询生成。

## 6. 论文的主要结论与发现

1. **性能持续领先**：在全部12组主实验对比中（3数据集 × 2骨干），MEGRAG均取得最高F1和EM。在Qwen3-8B上，相对最强基线的F1提升为2WikiMultiHopQA +5.84、HotpotQA +2.90、MuSiQue +8.34；在纯提示词的Qwen3-Max上仍分别保持+1.92、+3.34、+5.21的F1优势，说明推理流程本身有效，不依赖蒸馏。

2. **自适应粒度选择优于任何固定粒度**：没有一种固定粒度在所有数据集上占优；MEGRAG通过自适应组合在三个数据集上分别超过各自最优固定粒度变体1.45、3.49和6.23的F1。

3. **强化历史信息对长链推理尤为重要**：移除结构化历史后，MuSiQue上F1下降5.81，表明中间答案、已解析路径和缺失信息等状态字段对较长的组合链推理至关重要。

4. **目标条件化转换关系具有实际作用**：在MuSiQue上移除ri导致F1下降1.61，随机替换后下降2.91，说明后续决策不仅依赖关系的存在，更依赖其语义内容。

5. **答案感知停止机制有效节省计算**：HotpotQA 89.3%的问题在第1步停止，节省71.88%的LLM调用和74.10%的token（F1仅损失1.46）；MuSiQue更频繁地继续检索，节省58.1%/59.5%的调用/token且F1还有+0.04的提升。

6. **蒸馏对小型模型很重要**：去除SFT后F1下降6.33~18.41点；但Qwen3-Max纯提示词设置依然保持优势，说明大规模模型不需要蒸馏也能执行该流程。

7. **跨基线泛化能力**：在Llama、DeepSeek、GPT、Gemini等骨架上均排名第一（24项对比全部领先），在替换检索器后仍保持优势；在不需要长检索链的单跳QA上（NQ、WebQ）也未出现性能回退。

## 7. 优点

- **方法设计层面**
  - **多粒度自适应证据选择**：以“充分性”而非固定粒度为标准，从紧凑的三元组开始按需扩展，有效兼顾信息密度与上下文完整性，是该领域的一个新颖视角。
  - **答案感知的迭代推理**：将“回答当前查询”与“解决初始查询”明确区分，每步生成中间答案并用剩余信息需求驱动停止或继续，直接回应了iRAG中的错误累积问题。
  - **离线/在线分离**：将可复用的语料组织与问题特定的推理分离——离线跨粒度索引只需构建一次，在线仅做轻量检索与决策，没有依赖语料级知识图谱遍历。
  - **路径状态明确化**：每个推理节点显式记录查询、证据、中间答案、解析路径、缺失信息和目标条件化转换关系，整个推理过程透明可追踪。
  - **可蒸馏性**：将图构建策略蒸馏为轻量级学生模型，降低部署成本，同时方法本身不以微调为前提（Qwen3-Max纯提示词同样有效）。

- **实验评估层面**
  - 评测维度丰富：除主实验结果外，还覆盖消融、停止效率、延迟-精度权衡、检索器/骨干鲁棒性、步数预算、单跳迁移等多个角度。
  - 对比方法覆盖面广：包含迭代式、结构感知式、多粒度式三大类基线，且对不同训练策略做了披露。
  - 统计检验意识：用配对自助法置信区间刻画结果的不确定性。
  - 成本意识：报告了与固定四步检索相比在LLM调用和token方面的实际节省，对应用具有参考价值。

## 8. 不足与局限

- **方法层面的固有局限**
  - 证据范围受限于段落检索结果：语料中未被检索到的信息无法恢复。
  - 自动抽取的三元组可能包含错误或省略限定词（如时态、否定、数量约束），从而影响中间推理质量。
  - 单一路径、无回溯：一旦某个中间状态出错，后续推理无法纠正（“不能从错误的中间状态回溯”）。
  - 本质上是一条路径而非通用图：每个节点最多一个后继，不是一般的图搜索或消息传递方法，难以处理需要多分支证据聚类的复杂问题。
  - 三元组优先的固定选择顺序（triple-first）是一种启发式，可能不适合所有问题类型。

- **实验与评估层面的局限**
  - 主评估限定在固定1,000题子集上，配对自助法只反映该子集内的采样不确定性，不能外推到独立抽样的不同子集。
  - 评估为英文事实验证类问答（factoid QA），未涵盖多语言、多模态或开放式生成场景。
  - 延迟数据排除了离线OpenIE、嵌入和索引的一次性构建成本，实际部署的总成本被低估。
  - 学生模型（Qwen3-8B）依赖教师模型（Qwen3-Max）生成的轨迹进行蒸馏，引入对特定教师模型的依赖性。
  - 基线比较采用各自原生的训练制度，Qwen3-8B下的主实验更接近完整系统对比而非控制变量的架构对比（作者已明确承认这一点）；部分Qwen3-Max对比（如2WikiMultiHopQA和HotpotQA的EM）未达到统计显著性，观察到的排名不应被过度解读。
