## 摘要
大语言模型（LLM）智能体必须保留并利用跨步骤信息，以便在长程任务中连贯行动。现有方法提高了记忆的可访问性，但行动相关信息仍可能因形成、组织、排序或呈现不当而无法指导当前决策。我们将这种访问后失败称为“记忆-行动差距”。我们提出MemArbiter，一种功能感知的记忆仲裁框架，以解决这一差距中由记忆管理引起的部分。MemArbiter将交互历史分解为原子项，将其组织成五个功能性记忆库，并结合库级需求、项级相关性、焦点-环境表示和时间呈现门控，动态控制记忆显著性。我们在ALFWorld上，在统一的每步记忆预算下，将MemArbiter与Flat Retrieval和Flat Recency进行对比评估。使用开放权重动作生成模型，MemArbiter在500和750 token预算下分别实现了82.8%和92.5%的成功率，比最强基线分别高出20.9和25.4个百分点。它还改善了失败后的恢复能力，并减少了失败动作重复和状态-动作循环。这些结果表明，功能感知的记忆仲裁能使可访问的信息更有效地指导行动。

## Abstract
Large language model (LLM) agents must retain and use cross-step information to act coherently in long-horizon tasks. Existing methods improve memory accessibility, yet action-relevant information may still fail to guide the current decision because it is poorly formed, organized, prioritized, or presented. We call this post-access failure the Memory-Action Gap. We propose MemArbiter, a function-aware memory arbitration framework that addresses the memory-management-induced component of this gap. MemArbiter decomposes interaction histories into atomic items, organizes them into five functional Memory Banks, and combines bank-level demand, item-level relevance, focal-ambient representations, and a temporal presentation gate to dynamically control memory salience. We evaluate MemArbiter on ALFWorld against Flat Retrieval and Flat Recency under unified per-step memory budgets. With an open-weight action-generation model, MemArbiter achieves success rates of 82.8% and 92.5% under 500- and 750-token budgets, outperforming the strongest baseline by 20.9 and 25.4 percentage points, respectively. It also improves post-failure recovery and reduces failed-action repetition and state-action recurrence. These results show that function-aware memory arbitration enables accessible information to guide actions more effectively.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：长程LLM智能体在跨步骤决策时，即使相关信息已被记忆系统保留并访问，仍可能因信息"形成、组织、排序或呈现"不当而无法有效指导当前动作，导致决策失败。论文将这一现象定义为 **Memory-Action Gap（记忆-行动差距）**。
- **研究背景**：
  - 现有研究主要聚焦于提升记忆的**可访问性**（如上下文扩展、检索管理、压缩、经验维护等），但忽略了"可访问≠可用的决策影响力"。
  - 长程任务中，历史信息以不同方式影响决策（目标、状态、约束、经验、事实等），但现有记忆机制多将记忆视为**同质化文本块**，无法区分其决策功能，导致整合管理效果不佳。
  - 该差距区别于"遗忘"（信息未保留）和"检索失败"（信息无法定位），而是信息已进入记忆管理流程却未能引导动作选择。
- **整体含义**：论文提出记忆管理不仅是"存得下、找得到"的问题，更是一个贯穿"记忆形成→功能组织→优先级动态调整→提示呈现"的**端到端仲裁问题**，功能感知的记忆管理对长程智能体决策至关重要。

## 2. 方法论（MemArbiter 框架）

- **核心思想**：将记忆按照决策功能差异化组织，动态控制记忆在提示中的显著性与呈现形式，使可访问信息在正确时间以合适形式发挥决策影响力。

- **五步核心流程**（以决策步骤 t 为单位）：
  1. **状态解析**：解析目标、当前观察、上一步动作与结果、交互轨迹，提取当前子目标、任务进度、相关实体与未解决的信息需求，构成决策上下文 $c_t$。
  2. **候选写入与记忆库更新**：将交互信息分解为**原子记忆项**，经有效性检查、去重、冲突消解后，由候选写入器 $W_b(c_t)$ 按更新策略 $U_b$ 写入对应记忆库。
  3. **双频带表示**：每个记忆项生成两种呈现粒度——**焦点形式**（保留完整内容）与**环境形式**（由确定性模板生成的简洁提示），两者可随决策需求切换，无需重新提取或分类。
  4. **决策相关性信号**：
     - **库级需求** $d_{b,t}$：估计当前步骤对某类功能记忆的总体需求（如目标完成度、状态新近性、约束适用性、异常结果触发等）。
     - **项级相关性** $\eta_{i,t}$：评估单个记忆项对当前决策的贡献（如子目标对齐度、信息需求匹配度、错误恢复效用等）。
  5. **时间呈现门控**：依据公式 $z_{i,t} = G_{b(i)}(z_{i,t-1}, d_{b(i),t}, \eta_{i,t}, h_{i,t-1})$ 为每个记忆项分配状态（焦点 F / 环境 A / 隐藏 H）。考虑上一状态（连续性）、库级需求、项级相关性、相关性历史（区分趋势与波动），并采用角色特定的转换规则（如目标与约束受保护不被常规时间衰减驱逐，任务状态始终为最新快照等）。
  6. **提示组装**：按记忆库分区、焦点在前、环境在后、组内按相关性排序，构成结构化记忆提示 $P_t$，与当前观察共同用于下一动作生成。

- **五个功能记忆库**：Goal（目标）、Task State（任务状态）、Constraint（约束）、Episodic（情景）、Reference（参考）。

## 3. 实验设计

- **基准环境**：ALFWorld（文本交互式具身家务任务基准），使用其 **eval_out_of_distribution 划分中的全部 134 个未见过任务**，每回合上限 50 步。
- **对比基线**：
  - **Flat Recency**：无序存储观察与动作，保留最近的记录。
  - **Flat Retrieval**：基于 BM25 检索，查询由目标 + 上一动作 + 最新观察拼接而成。
  - **消融变体**：w/o Functional Banks（无功能记忆库）、w/o Dynamic Signals（无动态信号）、w/o Temporal Gate（无时间门控），均在 500-token 预算下评估。
- **评估指标**：累计成功率 SR@k（k 步内完成任务的比例），SR@50 为主要指标；另有失败恢复、动作重复、状态-动作循环、记忆提示中情景记忆占比变化等机制诊断指标。
- **统一约束**：所有方法使用相同的每步记忆呈现预算（500 和 750 token）与统一的 token 计数（o200k_base）。
- **跨模型验证**：将动作生成模型换为专有模型 GPT-5.4（记忆写入与状态解析仍用 Qwen3.6），500-token 预算下验证泛化性。

- **消融实验**：3 个消融变体 × 500-token 设置，分别验证功能记忆库、动态信号与时间门控的贡献。

- **机制诊断实验**：失败后一步恢复率、失败动作重复、相邻动作重复、状态-动作循环、情景记忆占比变化等，含 500/750 两种预算下的对比。

## 6. 主要结论与发现

- **性能显著提升**：500-token 预算下 MemArbiter 成功率 82.84%（超最强基线 20.90 pp）；750-token 下达 92.54%（超最强基线 25.38 pp）。增加预算对 MemArbiter 增益明显，而对扁平基线增益有限。
- **跨任务类型一致改善**：6 类任务中 5 类占优（500-token），预算提升后全部 6 类占优；在 Pick Two（需协调多个中间状态）任务上增益最大（从基线 0% 提升至 58.82%/70.59%）。
- **更高效利用长轨迹**：SR@k 曲线显示 MemArbiter 在相同步数限制下完成更多任务，非因采取更多动作而是更有效地利用交互步骤。
- **跨模型一致性**：GPT-5.4 作为动作生成模型时仍有 12.69 pp 优势，表明方法不依赖特定生成模型。
- **消融发现**：去掉动态信号损失最大（SR@50 下降 17.17 pp），功能记忆库次之（下降 15.68 pp），时间门控贡献在长轨迹中体现（SR@15 略降 2.98 pp，但 SR@50 提升显著）。
- **失败恢复机制**：失败后一步恢复率提升 18.2~34.8 pp，失败动作重复率降低 20.4~31.4 pp；情景记忆在失败后的提示占比上升（如 500-token 下 29.4%→32.7%），与更好的恢复行为相关。

## 7. 优点

- **问题定义精准**：明确区分"记忆可访问性"与"决策影响力"，提出 Memory-Action Gap 这一新概念，填补了长程智能体记忆研究中"访问后失败"的空白。
- **功能感知设计**：将记忆按决策功能划分为五类记忆库，克服了同质化记忆管理的瓶颈，并利用各角色的时间特性（持久性、更新频率、激活模式）设计差异化管理。
- **双频带表示与门控机制**：焦点/环境两级粒度 + 有状态的呈现门控（考虑连续性、信号、历史），兼顾动态适应性与呈现稳定性，避免独立决策导致的频繁切换。
- **预算约束下的公平比较**：对记忆提示 token 预算进行统一测量和限制，确保性能差异来自记忆管理质量而非上下文长度。
- **多维度验证体系**：不仅报告成功率，还从失败恢复、重复行为、机制相关性等角度分析"为什么有效"，实验证据链完整。

## 8. 不足与局限

- **单一环境评估**：仅在 ALFWorld（文本家务）上验证，是否适用于网页导航、多模态、开放域任务尚未验证，泛化性存疑。
- **缺乏与先进记忆方法对比**：未与 HiAgent、MemAct、AgeMem 等近期工作同台比较，仅对比两类扁平基线，难以定位其在 SOTA 中的相对水平。
- **预先设计的角色体系**：五个记忆库和相关信号为人工预先定义，虽透明可审计，但需人工适配新领域，是否具备跨域自适应能力未验证。
- **因果性证据有限**：失败后情景记忆占比上升与恢复行为改善仅表明相关性，未通过受控干预证明"提升某条记忆确实导致更优动作"。
- **统计充分性不足**：每个任务仅运行一次，未报告多次运行的均值和方差；未提供误差棒或显著性检验。
- **基线较弱**：Flat Recency 和 Flat Retrieval 为简单方法，对"扁平组织导致失败"的论证是强对比，但未能检验 MemArbiter 与"扁平组织+更复杂的提示工程"或"可学习记忆管理"方法的优劣。
- **未报告效率指标**：缺少记忆管理本身的延迟、token 开销、额外计算成本等工程可用性数据。
