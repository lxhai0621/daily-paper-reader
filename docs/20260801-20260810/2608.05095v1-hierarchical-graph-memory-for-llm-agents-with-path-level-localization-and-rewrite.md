## 摘要
长期推理的智能体需要一种能够随着新事实和外部反馈的持续到来而高效且有效地更新的记忆。近年来，图记忆已被采用，以提供多跳检索和推理的结构化组织。然而，现有方法将所有记忆存储在一个平面图中，积累的历史记忆可能引入不相关的上下文，并增加检索过程中证据选择的成本。此外，它们通常独立地更新记忆单元，需要重复的单元级重写以覆盖相关变化。为了解决这些问题，我们提出了HiGram，一个具有路径级定位和重写的演化层次化图记忆框架。具体来说，我们首先提出了一种层次化图记忆，它将记忆组织成由上层节点和记忆单元组成的从粗到细的架构，从而减少检索过程中不相关信息量。我们进一步提出了基于微图的路径级定位，它利用查询和更新条件化的微图来识别支持子图和证据路径，然后再进行重写。最后，我们提出了一种协同重写方法，该方法联合修订单元内记忆和单元间依赖关系，使有效依赖结构能够在局部证据路径中更新。在长期对话问答和冲突感知记忆评估的基准实验表明，我们的方法在答案质量和令牌效率上相比基线有显著提升。此外，我们的方法在动态、静态和条件冲突下提高了答案准确性和查询有效的证据选择。

## Abstract
Agents for long term reasoning require a memory that can be efficiently and effectively updated over time, as new facts and external feedback continue to arrive. Recently, graph memory has been adopted to offer structural organization for multi-hop retrieval and reasoning. However, existing methods store all memories in a flat graph, and accumulated historical memories can introduce irrelevant contexts and increase the cost of evidence selection during retrieval. Moreover, they typically update memory units independently, requiring repeated unit-wise rewrite to cover related changes. To address these issues, we propose HiGram, an evolving hierarchical graph memory framework with path-level localization and rewriting. Specifically, we first propose a hierarchical graph memory, which organizes the memory into coarse-to-fine architecture composed of upper-level nodes and MemoryUnits, thereby reducing the amount of irrelevant information during retrieval. We further propose MicroGraph-based path-level localization, which leverages query and update conditioned MicroGraphs to identify support subgraph and evidence path before rewrite. Finally, we propose a coordinated rewriting method that jointly revises intra-unit memory and inter-unit dependencies, enable valid dependency structures updating in the localized evidence path. Experiments on benchmarks for long-term conversational question answering and conflict-aware memory evaluation demonstrate that our method demonstrate substantial improvements over baselines in answer quality and token efficiency. Besides, our method improves answer accuracy and query-valid evidence selection under dynamic, static, and conditional conflicts.

## 1. 论文的核心问题与整体含义

- **研究动机**：长期推理智能体（LLM Agent）需要一种能够随新事实、修正信息与外部反馈持续到达而**高效且有效地更新**的记忆机制。现有记忆系统虽然已具备存储、检索和压缩历史对话的能力，但面对持续演化的记忆，系统不仅要检索相关历史信息，还必须**保持记忆结构的合理性**，确保后续推理能访问可靠证据。
- **核心问题**：现有图记忆方法存在两方面关键缺陷：
  1. **组织结构缺陷**：所有记忆存储在**平面图（flat graph）**中，缺乏从粗到细（coarse-to-fine）的显式组织。随着历史记忆不断积累，检索平面结构会引入大量**不相关上下文**，增加证据选择的成本。
  2. **更新方式缺陷**：现有方法通常**独立更新记忆单元**，而答案往往由**相互连接的证据路径**而非孤立事实支持。单元级独立更新会遗漏相关证据，使过期依赖残留在后续推理中，且需要**重复的单元级重写**才能覆盖所有相关变化，导致token消耗不可接受、更新效率低下。
- **核心洞察**：现有方法存在记忆组织/更新的粒度与推理所用证据结构粒度之间的**不匹配**。记忆系统应当先定位查询相关子图，再基于更新识别受影响的证据路径，并在有界区域内联合修订记忆状态及其依赖关系。

## 2. 论文提出的方法论

### 2.1 总体框架

HiGram包含三个主要阶段（如图1所示）：
1. **层次化记忆组织**——构建粗到细的记忆架构
2. **基于MicroGraph的路径级定位**——缩小搜索空间并识别受影响路径
3. **协同重写**——在局部区域内更新记忆状态和依赖关系

### 2.2 层次化记忆组织（Hierarchical Memory Organization）

- 记忆表示为层次化图记忆 `G_t = (V_t, E_t)`，节点集为：
  - **上层节点**：包括主体节点（subject nodes）、客体类别节点（object-category nodes）、上下文节点（context nodes），作为抽象层提供粗粒度访问
  - **MemoryUnits**：存储细粒度事实信息，记录主体、关系、客体、客体类别、交易时间、上下文、置信度、当前状态等
- 边集包括：主体-单元连接、客体类别-单元连接、上下文-单元连接，以及**依赖边**（连接MemoryUnit之间的显式证据依赖）
- MemoryUnit状态包括：**active**（参与当前检索）、**superseded/outdated/pending**（保留历史断言但不参与定位）
- 相比直接在全部历史事实上搜索的平面图记忆，该设计可先定位相关区域再访问对应MemoryUnits，减少不必要的定位开销。

### 2.3 基于MicroGraph的路径级定位

- **MicroGraph构建**：一个MicroGraph `B_t,j` 由一对主体节点和客体类别节点定义，代表全局图中的局部区域。选择这两个属性是因为它们在时间更新中保持稳定，能在详细证据路径选择前提供高效访问。
- **锚点提取**：根据查询 `q_t` 和可用的更新文本 `u_t`，构造临时MemoryUnits `M_temp_t`，再通过锚点提取器获取主体节点和客体类别节点作为锚点 `A_t`。
- **候选MicroGraph选择**：选出与锚点有交集匹配的候选MicroGraph，按相关性得分排序，取Top-K_g个作为局部记忆区域，其关联的MemoryUnits及连接构成**支持子图（support subgraph）** `G_S,t`。
- **路径级定位**：在支持子图内枚举连接的MemoryUnit路径（最多K_p条候选路径），通过评分函数 `φ_H(P, M_temp_t)` 评估候选路径与临时MemoryUnits的**一致性**，包括属性匹配、依赖一致性、时间有效性和上下文兼容性，选出受影响的**证据路径** `P_t`。

### 2.4 协同重写（Coordinated Rewriting）

- **目标**：不是覆写历史记忆，而是在局部证据路径内维护一致的证据结构。
- **单元内重写（Intra-unit Rewriting）**：将临时MemoryUnits与证据路径中的MemoryUnits匹配；新记忆则作为active单元提交，更新现有记忆则根据时间与上下文一致性修订状态和有效时间信息。
- **单元间重写（Inter-unit Rewriting）**：识别直接依赖受影响单元的其他MemoryUnits（依赖边从支持单元指向依赖单元），检查依赖是否在更新证据下仍有效——保持仍一致的依赖，将不再有效的依赖单元标记为outdated并排除出当前证据视图；更新后单元的依赖**不会自动继承**，仅在有效证据支持时保留，防止无依据的推导结论。

## 6. 论文的主要结论与发现

- **答案质量与token效率双提升**：HiGram在LoCoMo上取得了GPT-5.4和GPT-4o下的最佳平均F1、BLEU和LLM-J。token使用仅为GPT-5.4下全上下文方案的7.2%、GPT-4o下ReadAgent的15.8%，同时保持了比紧凑记忆系统更优的答案质量。
- **冲突场景优势显著**：在MemConflict上取得全面最优性能，在静态冲突上同时领先AA和CRS，在动态冲突上获得最佳UOCS（更新顺序一致性），在条件冲突上取得最佳AA。
