## 摘要
记忆系统在提升智能体性能方面已显示出潜力，但其在小语言模型中的潜力在很大程度上仍未得到探索，因为小语言模型难以自行生成足够多的成功轨迹。我们提出了代理记忆蒸馏（AMD），一种无需训练的新框架，通过层级记忆将结构化知识从大型教师智能体迁移到小型学生智能体。AMD从成功的教师轨迹中构建三种互补的记忆类型：工作流记忆编码任务级策略，子任务记忆在中间粒度提供具体行为示例，函数记忆捕获每个函数的调用约定和常见陷阱。工作流记忆和子任务记忆在每个任务开始时主动注入，而函数记忆则在工具调用出错时被动检索。我们在三个工具使用基准上评估了AMD，使用四个学生模型（4B-8B参数）以GPT-5-mini为教师，在AppWorld、BFCL V3和ToolSandbox上分别实现了27.2个百分点、11.2个百分点和3.4个百分点的平均准确率提升，同时始终优于现有的基于记忆的基线。进一步分析表明，子任务记忆贡献最大，教师有效性既取决于教师能力也取决于学生兼容性，且4B大小的学生从AMD中受益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

# 代理记忆蒸馏：利用层级教师记忆赋能小型LLM智能体——论文总结

## 1. 核心问题与整体含义

- **研究动机**：大型语言模型（LLM）智能体的记忆系统已被证明能显著提升性能，但这一潜力在小语言模型（SLM）上尚未得到有效发挥。小型智能体自身任务成功率低，难以生成足够的成功轨迹，导致自生成的记忆库中成功经验稀缺，限制了记忆机制的实际收益。
- **关键挑战**：即使将强教师模型（如 GPT-5-mini）的高质量经验直接注入学生模型，由于教师与学生之间的**能力差距（capability gap）**，学生难以理解和运用抽象的教师记忆，改进幅度微弱。
- **整体含义**：本文提出一种**无需训练**的教师-学生记忆迁移框架——**Agent Memory Distillation (AMD)**，通过**层次化记忆结构**（任务级、子任务级、函数级）将教师知识转化为小模型易于理解和应用的形式，从而显著提升小型智能体的工具调用能力。

## 2. 方法论

### 2.1 核心思想

AMD 从教师智能体在成功轨迹中提炼三类互补的记忆，分别对应不同任务粒度，主动或反应式地注入学生智能体，以弥合教师与学生之间的能力缺口。

### 2.2 三类层次化记忆

| 记忆类型 | 粒度 | 内容 | 注入方式 |
|---------|------|------|---------|
| **Workflow Memory（工作流记忆）** | 任务级 | 整体任务完成策略：涉及的应用/工具、关键前置条件、决策规则、验证线索和常见失败模式；使用类型化占位符（如 `<ID>`、`<EMAIL>`）抽象具体值 | **主动注入**：任务开始前，以任务指令为查询，检索 top-k 条目加入系统提示 |
| **Subtask Memory（子任务记忆）** | 中间粒度 | 教师行为中语义连贯的片段，包含具体可执行代码块、对应观测、简短标签和描述 | **主动注入**：学生先分解任务为子任务标签，每个标签独立检索，去重后注入系统提示 |
| **Function Memory（函数记忆）** | 函数级 | 单个工具调用的具体示例（函数名 + 调用上下文 + 返回观测），可选附加 API 文档 schema | **反应式检索**：仅在工具调用出错时，根据失败函数名查询并追加到错误上下文 |

### 2.3 记忆构建流程

由教师模型 `πT` 在成功轨迹集 `D_T^+` 上构建：
- 每条轨迹生成一条工作流记忆（自然语言洞察）；
- 轨迹按语义边界分割为若干子任务片段（由教师 LLM 配合规则提示完成）；
- 提取每个函数调用作为函数记忆条目。
所有记忆条目使用 `text-embedding-3-small` 编码为稠密向量，检索基于余弦相似度。

### 2.4 推理算法（文字描述）

1. 任务开始时，用任务指令检索工作流记忆，注入系统提示；
2. 学生分解任务为子任务标签（最多6个），每个标签检索子任务记忆，去重后注入；
3. 执行循环中，若前一轮观测检测到错误，提取失败函数名，查询函数记忆并作为提示块附加；
4. 学生基于当前消息历史和函数提示生成下一个动作；循环直到任务完成或达到最大步数（40步）。
目标函数为：最大化学生使用记忆后的期望任务奖励，即 `max_M E_s[R(πS(s; M))]`。

## 6. 主要结论与发现

- AMD 能**显著提升小模型智能体性能**，并让部分学生达到或超越教师水平。
- **子任务记忆贡献最大**（尤其 AppWorld 上，WF+ST 相比 WF 提升可达 +25%p），为复杂长程任务提供关键的具体行为示例。
- 教师有效性**不仅取决于教师准确率，还受教师-学生兼容性影响**（如 GPT-5-mini 对 Qwen3-4B 的迁移效果优于更强大的 GPT-5.5，尽管后者准确率高得多）。
- **4B 规模学生受益最大**：绝对准确率随模型规模增大而上升，但相对增益在 4B 处达到峰值（+34.52%p）。
- 检索数量 k=1 已接近最优，更多记忆反而干扰小模型；**记忆表示形式应分层适配**：高维规划用自然语言，低维执行用具体代码。

## 8. 不足与局限

- **评估范围局限**：仅覆盖文本、结构化工具使用（Python API 或 JSON 函数调用）基准，未涉及多模态环境或开放式代码生成。
