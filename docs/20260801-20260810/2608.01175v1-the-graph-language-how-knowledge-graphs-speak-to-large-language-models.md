## 摘要
大语言模型（LLMs）擅长推理，但受益于知识图谱（KGs）提供的基础支撑。然而，整合这些范式具有挑战性。我们提出了GRALAN，它通过保留图结构的关联标记，使知识图谱能够直接在大语言模型的语义空间中表达。GRALAN的可训练语言中介为任何冻结的LLM生成结构化标记，为知识密集型应用奠定了基础。我们通过将问答任务重新构建为对问题聚焦子图的实体分类，展示了其有效性。实验表明，GRALAN显著优于现有方法，特别是在复杂多跳推理任务上，为KG-LLM集成建立了一种保持结构保真度同时利用LLM推理能力的新范式。

## Abstract
Large Language Models (LLMs) excel at reasoning but benefit from grounding provided by Knowledge Graphs (KGs). However, integrating these paradigms is challenging. We introduce GRALAN, which enables KGs to speak directly in the LLM's semantic space through relational tokens that preserve graph structure. GRALAN-s trainable language mediator generates structured tokens for any frozen LLM, creating a foundation for knowledge-intensive applications. We demonstrate its effectiveness in question-answering by re-framing the task as entity classification over question-focused subgraphs. Experiments show that GRALAN significantly outperforms existing methods, particularly on complex multi-hop reasoning tasks, establishing a new paradigm for KG-LLM integration that maintains structural fidelity while leveraging LLMs' reasoning capabilities.

# GRALAN 论文要点总结

## 1. 论文核心问题与研究动机

- **知识图谱与大语言模型的语义鸿沟**：知识图谱（KG）以实体和关系三元组形式存储结构化事实，擅长精确、可追溯的符号推理；大语言模型（LLM）擅长自然语言理解与泛化推理，但缺乏结构化知识支撑，容易产生幻觉和事实性错误。
- **现有整合方法的两难**：
  - 将 KG 展平（flattening）或序列化为文本，会丢失图结构的高阶关系信息；
  - 对 LLM 进行全量微调或联合预训练，计算成本高且存在灾难性遗忘风险；
  - 参数高效方法（如 LoRA、prompt tuning）和多跳推理方法（如 ToG）在复杂异构图推理上仍不够理想。
- **核心研究问题**：能否让 KG 直接在 LLM 的语义空间中“说话”，从而在不损伤图结构的前提下，将 LLM 作为冻结的通用推理引擎，实现结构保真与语言推理能力的有机结合？

## 2. 方法论

### 核心思想
- 提出 **GRALAN（The Graph Language）**，将 KG-LLM 整合从“结构变换”转向“语义对齐”。
- 通过一个可训练的 **Graph Language Mediator**，将图结构编码为**关系令牌（relational tokens）**，这些令牌不与 LLM 词汇表绑定，而是位于 LLM 的嵌入空间中，从而让冻结的 LLM 能直接“理解”图结构。
- 问答任务被重构为**实体分类**：在一个**问题聚焦子图**上预测哪个实体是正确答案，而非生成任意文本，从而避免词汇表限制，并支持随知识图谱大小线性扩展。

### 三个主要模块

1. **任务聚焦子图提取器（Task-Focused Subgraph Extractor）**
   - 两阶段流程：
     - **问题分析**：用 LLM 或实体识别将自然语言问题映射到种子实体集合 `E_seed` 和相关关系集合 `P_rel`。
     - **问题聚焦 BFS**：从种子实体出发，按关系与问题关系的相似度 `sim(r, P_rel)` 给边赋予优先级，并设定相关性阈值 `θ`，剪枝掉低相关边（如“part-of”“base salary”），得到紧凑的子图 `G_sub`。
   - 相比传统 BFS，该算法显著减少噪声，提高后续模块的效率与精度。

2. **图语言中介（Graph Language Mediator）**
   - **图编码器**：使用 RGCN/RGAT 在子图上做消息传递，得到实体嵌入 `H`、关系嵌入 `R`；再通过注意力加权池化得到全局子图嵌入 `z_graph`。
   - **问题编码**：用 LLM 自带的 tokenizer 和 embedding 得到问题嵌入 `E_Q`。
   - **语义对齐**：
     - 关系感知的节点交互：对由关系 `r` 连接的节点对 `(i, j)`，计算基于问题上下文的注意力分数；
     - 问题空间投影：通过交叉注意力将图表示投影到问题语义空间，融合全局上下文，得到增强节点表示 `h_final`。
   - **LLM 输入组装**：选取 top-K 与问题最相关的节点嵌入，并与全局子图嵌入、问题嵌入拼接，加上特殊分隔符 [GRAPH]、[NODES]、[QUESTION]、[ANSWER]，构成 `X_LLM`。
   - 这个输入序列绕过了 LLM 的原始 token embedding，直接输入图对齐的嵌入。

3. **LLM 推理器（LLM-Based Reasoning）**
   - LLM 保持**完全冻结**，处理 `X_LLM` 后产生隐藏状态。
   - 提取 [ANSWER] 位置的隐藏状态，通过一个可训练的分类层（或双线性分类）映射到子图实体空间，得到每个实体的概率：
     - `P(v | X) = softmax(W_cls h_answer)`
   - 最终答案为概率最高的实体；支持通过阈值 τ 输出多个答案。

### 训练目标
- 联合优化分类损失与 LLM 损失，并加入正则项：
  - `L_total = λ_cls L_cls + (1−λ_cls) L_LLM + α L_reg`
  - 其中 `L_reg` 包含 L2 正则和 KL 散度（用于约束分类概率与 LLM 输出概率的一致性）。
- 好处：兼顾图结构监督和 LLM 语义理解，且不需要微调 LLM。

## 6. 主要结论

1. **GRALAN 在几乎所有基准上显著优于基线**：
   - 在 PQL-2h 上比 G-Retriever/JAKET 提升约 7.6 个百分点；在 PQL-3h 上比 JAKET 提升 19 个百分点。
   - 在 MetaQA 2-hop/3-hop 达到 100% 准确率，超过所有对比方法。
   - 在 ZeroShotRE 和 ComplexWebQuestions 上，以 FLAN-T5-XXL 超过了使用 GPT-4 的 ToG（分别 +1.15% 和 +2.63%）。
2. **多项选择问答**：GRALAN 平均准确率 85.26%，超过 LoRA+Q-KGR（85.21%），尤其在 ARC 和 Riddle 上取得新高。
3. **消融结果**：
   - 子图选择阈值 θ ≈ 0.7 最佳；
   - BFS 深度 3 为最优，过深会引入噪声；
   - 混合预测策略（HYB）优于纯 LLM 或纯分类；
   - 损失权重 λ_cls 在 0.5–0.7 之间最佳；
   - 更大的 LLM 效果更好，但小模型中 GRALAN 依然稳健。
4. **总括**：将 KG-LLM 整合从“适配”转向“对齐”，是一种可行且高效的新范式，兼具结构保真、参数效率和可解释性。

## 7. 优点

- **结构保真**：直接用 GNN 编码子图，而非展成文本，保留多跳关系和高阶拓扑。
- **参数高效**：LLM 完全冻结，只训练轻量的图编码器、中介层和分类层，避免灾难性遗忘，降低训练成本。
- **新颖的问题重构**：将 QA 转化为子图实体分类，绕开 LLM 词汇表限制，可自然扩展到大型 KG。
- **关系感知的交叉注意力**：实现符号图结构与神经网络语义空间的深度交互，而非简单拼接。
- **可解释性**：问题聚焦 BFS 与 top-K 节点选择提供了清晰的理由路径。
- **灵活性**：框架不依赖特定 LLM 或 GNN 结构，可推广到推荐、知识发现、多模态等任务。
- **实验设计较扎实**：覆盖开放问答和多项选择，既有传统基准又有 LLM 对比，还有多维消融。
