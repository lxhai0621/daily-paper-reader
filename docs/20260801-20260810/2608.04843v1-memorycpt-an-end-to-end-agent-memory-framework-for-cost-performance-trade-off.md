## 摘要
长程LLM智能体需要记忆系统，能够从大规模交互历史中恢复有用证据，而无需将过多上下文传递给下游模型。现有记忆流水线通常依赖手工设计的启发式规则和重复的LLM调用，这可能导致冗余上下文和高推理成本。我们提出MemoryCPT，一种端到端可训练的智能体记忆流水线，涵盖离线记忆构建和在线查询条件上下文生成。MemoryCPT包含两个阶段：查询无关蒸馏（QAD），利用显式推理轨迹将模块化记忆构建流水线蒸馏为紧凑模型；以及查询感知检索与摘要（QAR），将互惠排名融合（RRF）与基于LoRA的摘要器相结合，该摘要器通过群组相对策略优化（GRPO）在成本感知奖励下训练。我们进一步引入单位成本质量（QPC）来量化每单位推理成本下的答案质量。在LoCoMo和LongMemEval上的实验表明，与评估的基线相比，MemoryCPT改善了成本-性能权衡，同时消融和敏感性分析刻画了其各组件的贡献以及关键设计选择的影响。

## Abstract
Long-horizon LLM agents require memory systems that recover useful evidence from large interaction histories without passing excessive context to downstream models. Existing memory pipelines often rely on hand-crafted heuristics and repeated LLM calls, which can introduce redundant context and high inference cost. We propose MemoryCPT, an end-to-end trainable agent memory pipeline that spans offline memory construction and online query-conditioned context generation. MemoryCPT consists of two stages: Query-agnostic Distillation (QAD), which distills a modular memory-construction pipeline into a compact model using explicit reasoning traces; and Query-aware Retrieval and Summarization (QAR), which combines reciprocal rank fusion (RRF) with a LoRA-based summarizer trained via Group Relative Policy Optimization (GRPO) under a cost-aware reward. We further introduce Quality per Cost (QPC) to quantify answer quality per unit inference cost. Experiments on LoCoMo and LongMemEval show that MemoryCPT improves the cost-performance trade-off over the evaluated baselines, while ablation and sensitivity analyses characterize the contributions of its components and the effects of key design choices.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：长时程LLM智能体需要在长期交互中维持持久记忆（多会话对话、任务日志、演化中的个人知识），但现有记忆管线普遍存在两个瓶颈：
  - **上下文冗余**：直接向LLM输入完整历史不可行——长上下文成本高、速度慢、噪声大（"Lost in the Middle"问题）。
  - **现有记忆管线依赖手工启发式与多次LLM调用**：如基于提示词的压缩、结构化记忆分块、混合检索排序等，属于训练无关（training-free）方法，缺乏对中间记忆操作的内化，且检索时往往过度保守，导致推理成本高、收益不成比例。
- **核心矛盾**：答案质量与推理成本之间存在根本张力——检索更多记忆提升召回但增加下游QA模型的token消耗；激进压缩降低成本但可能丢弃关键证据。
- **论文主张**：提出一个**端到端可训练**的智能体记忆管线，将测试时的记忆操作蒸馏进模型参数中，显式地优化成本-性能权衡，而非仅追求原始准确率。

## 2. 论文提出的方法论

### 核心思想
MemoryCPT 是一个两阶段的端到端可训练记忆管线，将完整的记忆过程拆解为**离线构建**（查询无关）与**在线提取**（查询感知）两部分，将下游QA模型保持冻结，仅训练记忆处理模块。

### 阶段一：Query-agnostic Distillation（QAD，查询无关蒸馏）
- **目标**：将教师的模块化记忆构建能力蒸馏进紧凑的学生模型。
- **模块化教师管线**（参考 Ma et al. 2026）包含四个角色：
  - **BatchSegmenter**：切分会话边界；
  - **EpisodeGenerator**：生成情景记忆（episodic records）；
  - **EpisodeMerger**：合并相关情景；
  - **SemanticExtractor**：提取持久语义知识（semantic memory）。
- **推理轨迹监督**：教师输出采用"<think>推理轨迹</think> + 结构化JSON输出"的格式，学生模型（Qwen2.5-7B-Instruct 或 Llama-3.2-3B + LoRA-A适配器）通过标准因果语言建模目标学习，不仅学习"做什么"还学习"为什么"。
- **训练目标**：最小化 `L_QAD = -E[Σ log p_θ(z_t | z_{<t}, x)]`，其中 z = 推理轨迹 ⊕ 结构化输出。
- **合并策略**：为减少推理开销，将相邻的教师调用（如合并决策与内容生成）折叠为单次学生预测。

### 阶段二：Query-aware Retrieval and Summarization（QAR，查询感知检索与摘要）
- **RRF检索（粗选）**：对情景记忆和语义记忆分别使用稠密检索（嵌入）与稀疏检索（BM25），通过互惠排名融合（RRF）合并排序结果，获取Top-k候选记忆，限制摘要器的注意力范围。
- **上下文赌博机形式化**：
  - 状态：`s_q = (q, M_RRF^q)`（查询+RRF粗选候选集）；
  - 动作：摘要 token 序列 `m_q ~ π_φ(·|s_q)`（由 base A + LoRA-B 生成）；
  - 无转移动力学（单步赌博机）。
- **GRPO训练**：使用群组相对策略优化（Group Relative Policy Optimization）优化LoRA-B，最大化奖励并施加KL散度约束。
- **成本建模**：训练时代理成本 = 摘要输出token成本 + QA输入token成本 + QA输出token成本，并按参考成本 `C_ref` 裁剪归一化至 [0,1]。
- **奖励设计**：`R = α·F1(ŷ, y*) + (1-α)·(1 - Ĉ(q,m_q))`，默认 α=0.8。F1提供密集、连续、局部可计算的反馈。

### 端到端流程
两阶段训练：先QAD训练LoRA-A并合并进基础模型得到 base A；再在 base A 上以GRPO训练LoRA-B。推理时仅包含三步：RRF检索 → LoRA-B生成查询感知摘要 → 冻结的Qwen3-14B最终问答。

## 3. 实验设计

### 数据集

- **LongMemEval**（Wu et al. 2025）：原为纯测试基准，作者构建分层切分（150训练/98验证/105测试），覆盖其6个记忆类别，平均上下文9.37K tokens。

### 对比基线
1. **No-Memory**：Qwen3-14B直接读取截断的原始对话。
2. **LightMem**：训练无关的轻量记忆管线。
3. **MemoryOS**：层级化记忆块+结构化读写操作。
4. **BudgetMem**：基于预算感知的训练型记忆管线（因架构限制使用Qwen-2.5-72B API）。
5. **Memory-R1**：基于强化学习的记忆管理智能体。

### 统一评估协议
- 所有方法使用相同的下游QA模型（Qwen3-14B, temperature=0）、相同的评测提示模板、相同的判定模型（Qwen2.5-72B-Instruct）和统一的定价表。
- 评估指标：token-level F1、LLM-as-Judge准确率、平均推理成本（USD/查询×10⁴）、**QPC = F1/Cost**。

## 6. 论文的主要结论与发现

1. **端到端记忆训练可同时提升质量与效率**：在LoCoMo上（Qwen-2.5-7B为基础），相比BudgetMem，MemoryCPT将F1从0.373提升到0.479（相对提升约28%），推理成本从24.11降至3.46（约7倍下降），QPC提升超过9倍。
2. **现有记忆管线的成本-质量瓶颈明确**：LightMem、MemoryOS、BudgetMem虽提升F1但推理成本大幅增长（如MemoryOS在LongMemEval上成本达396.31）；Memory-R1虽控制成本但质量较低。
3. **QAD是质量放大器**：删除QAD后F1从0.479降至0.370，尽管成本略降，但QPC下降。
4. **QAR是成本控制的关键**：删除QAR后成本从3.46升至11.10，QPC从0.138降至0.038，表明查询感知压缩对控制下游成本至关重要。
5. **Fine Summary在保持语义正确性的同时大幅提升成本效率**：删除FS后Judge分数基本不变（甚至略升），但成本从3.46升至8.35，QPC从0.138降至0.053——论文诚实指出并非在每个质量指标上都是最优。
6. **α=0.8是最优权衡点**：QPC(QA)在两端数据集上均在α=0.8处达到峰值（LoCoMo: 59.5, LongMemEval: 56.5）。α→1.0时摘要过长而F1增益有限；α过小时过度压缩导致F1骤降。
7. **检索深度k存在拐点**：k=8/20已恢复约96%的峰值F1（仅42%-44%候选成本），k=20/50为最优，k=32/80时因噪声引入而质量下降。

## 7. 优点

- **端到端可训练的完整记忆管线**：从离线构建到在线检索与摘要的全流程可训练，突破了传统训练无关管线的局限。
- **两阶段分离设计的巧思**：离线/在线分离隔离了记忆构建与查询特定提取，既缩小了RL动作空间，又将昂贵的构建成本摊销到多次查询上。
- **显式推理轨迹蒸馏**：不是仅以最终摘要监督学生，而是保留教师在每个记忆操作背后的推理过程（rationale-then-output），学习目标更精细、更可学习。
- **成本感知的GRPO奖励设计**：使用加权和替代直接优化F1/Cost比例，避免了该比例的不稳定性；F1作为密集、连续的训练信号优于LLM judge。
- **创新的QPC评估指标**：首次在智能体记忆文献中系统化定义"单位成本质量"，使不同系统可在统一公平的条件下比较成本-性能权衡。
- **多维度实验验证**：主实验、消融、超参敏感性、细粒度分类分析、成本摊销分析相互印证，证据链完整。
- **全面的成本追踪协议**：统一价格表、统一QA模型、统一判定模型，区分输入输出token价格，明确区分离线摊销成本与在线成本。

## 8. 不足与局限

- **评估领域的局限**：仅在对话记忆QA基准（LoCoMo、LongMemEval）上验证，未覆盖更广泛的智能体记忆场景（如工具使用记录、代码交互历史、多模态交互等）。论文也承认未来需向更广泛的记忆源扩展。
- **LLM-as-Judge 与 F1 指标本身存在偏差风险**：F1对开放式回答可能不敏感，LLM judge虽有"宽大处理"指令但仍可能带有系统性偏好。
- **训练数据规模较小**：LoCoMo仅使用8段对话训练，314个测试问题规模有限；统计显著性检验未见报告。
- **只测试了特定模型规模**：记忆操作模型仅7B和3B，教师为DeepSeek-v3，未验证更强或更弱学生模型的泛化性。较小的基础模型（Llama-3.2-3B）在LongMemEval上表现明显较差（F1仅0.181），表明方法对模型容量的依赖性。
- **实时/流式环境验证缺失**：所有评估基于离线存储的完整对话日志，未涉及动态增长的持续性记忆中在线更新的场景。
- **消融实验观察**：w/o FS变体的Judge分数略高于完整模型（0.759 vs 0.755），说明质量与成本之间的权衡可能存在微妙的帕累托边界，论文凭QPC指标选择完整模型，但若用户只关心质量，可能会选不同的配置。
- **训练时间的工程细节不够透明**：未报告训练时长（GPU小时数）、收敛曲线和训练稳定性信息，影响实际部署的成本估计。
- **统一QA模型下的泛化问题**：所有方法共用Qwen3-14B作为QA后端，未验证在其他下游模型上的表现是否与当前结论一致。
