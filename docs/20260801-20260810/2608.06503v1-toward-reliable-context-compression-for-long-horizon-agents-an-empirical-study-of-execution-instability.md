## 摘要
循环上下文压缩控制长时程智能体中的上下文增长，但其行为影响仍知之甚少。在这项初步实证研究中，我们表明压缩可能削弱近期交互的影响，增加阻塞动作、重复探索和跨运行的不稳定性。受这些观察的启发，我们引入了TRACE，一个验证器引导的框架，通过从相同环境状态出发的配对闭环延续来评估单个压缩事件，并利用摘要偏好优化自然语言压缩提示，同时保持所有模型冻结。在AppWorld上的初步结果显示，在任务性能、多运行可靠性和上下文-执行效率方面优于现有压缩基线。这些发现为边界局部评估作为可靠智能体上下文压缩的有前景方向提供了早期证据。

## Abstract
Recurrent context compression controls context growth in long-horizon agents, but its behavioral effects remain poorly understood. In this preliminary empirical study, we show that compression can weaken the influence of recent interactions, increasing blocked actions, repeated exploration, and instability across runs. Motivated by these observations, we introduce TRACE, a verifier-guided framework that evaluates individual compaction events through paired closed-loop continuations from the same environment state and uses summary preferences to optimize a natural-language compression prompt while keeping all models frozen. Initial results on AppWorld show improvements over existing compression baselines in task performance, multi-run reliability, and context--execution efficiency. These findings provide early evidence for boundary-local evaluation as a promising direction for reliable agent context compression.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：随着大语言模型（LLM）在长时程交互任务中的广泛应用（如工具调用、浏览器操作、办公自动化等），上下文随交互不断增长，导致推理成本升高、有效信息定位困难。因此，上下文压缩成为规模化部署长时程智能体的关键需求。
- **已有方法的隐含假设**：现有压缩方法（如 ReSum、SUPO、ACON）假设“只要压缩后的检查点保留了任务相关内容，就可以替代原始交互历史”。作者指出这一假设忽略了历史轨迹的**方向性（directed role）**——原始的动作-观察序列不仅记录事实，还锚定当前执行位置、已完成步骤和终止条件。
- **核心研究问题**：循环上下文压缩（recurrent context compression）在行为层面对冻结的（frozen）下游智能体究竟产生何种影响？压缩是否会导致智能体“丢失当前位置”、重复探索或无法终止？
- **总体含义**：压缩质量不能仅用终端任务结果或文本保真度来衡量，而应关注压缩事件是否破坏了智能体对当前执行状态的识别。论文提出边界局部（boundary-local）评估框架 TRACE，并给出初步实证证据。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：在每次压缩发生的“边界”处，从相同的环境状态出发，对比压缩前（PRE）与压缩后（POST）的闭环续篇差异，从而将压缩引起的执行退化与智能体自身变异性分离。利用这种边界局部偏好信号，只优化压缩器的自然语言模板，所有模型参数保持冻结。
- **问题形式化**：
  - 给定上下文预算 \(B\)，若拼接后的上下文超过预算，则进行压缩：\(z_{t+1} = C(\bar{z}_{t+1}; B)\)，否则保留原始上下文。
  - 定义短视执行负担 \(G(\tau) = \sum_{j=1}^{K} z_j(\tau)\)，其中 \(z_j\) 表示第 \(j\) 个动作是否为“阻塞/错误”或“重复调用”。
  - 压缩引起的额外负担为 \(\Delta G_b(s) = \mathbb{E}[G(\tau_b^+(s))] - \mathbb{E}[G(\tau_b^-)]\)，验证器分数 \(Q_b(s) = -\Delta G_b(s)\)，分数越高表示该候选摘要引入的执行退化越少。
- **技术细节**：
  - **训练边界选择**：在训练集上使用基础压缩器收集边界，筛选出出现阻塞动作的边界，并按 AppWorld 原生错误类型分层采样 12 个边界。
  - **候选摘要生成**：冻结的基础压缩器从同一输入生成 3 个候选摘要；每个候选独立生成 POST 续篇，PRE 续篇复用，从而仅由 POST 行为区分候选。
  - **偏好构造**：每个边界保留最高分和最低分摘要，形成 12 个对比对，交给冻结的 proposal 模型（LLM）分析。
  - **Proposer 输入限制**：只提供压缩器输入、摘要好坏对以及下游系统提示；不提供后续动作、观测、错误信息或验证器分解，避免模板过度拟合具体失败案例。
  - **系统提示审计**：为防止优化出的压缩规则与下游系统提示矛盾，提案者需先对照系统提示审计现有策略，再基于对比对提出修改。
  - **端到端选择**：由 proposer 生成 5 个完整模板，每个模板在开发集上运行两次，选择 Pass 2（两次都成功）最高的模板作为最终模板，再在测试集上评估。
- **关键特点**：优化目标不是终端任务成功率，而是压缩边界处的执行负担差；终端结果仅在开发集模板选择阶段使用，不参与逐条摘要偏好。

## 3. 实验设计：数据集、基准与对比方法

## 6. 主要结论与发现

- **压缩导致行为不稳定**：随着上下文预算缩小，平均通过率下降，且多运行可靠性（Pass 2 vs Pass@2 的差距）明显恶化。Summary 压缩仅在 2K 极紧预算下优于 FIFO，在 4K/8K/16K 下 FIFO 并不逊色。
- **核心机制是“执行状态错位”而非单纯信息丢失**：
  - 压缩后的摘要条件在终止判断上明显更差（2K 时仅 44.6% 正确终止 vs FIFO 77.2%），且更容易输出多余内容。
  - 对近期交互的“行为影响力”存在梯度：原始更新保留 > 压缩摘要 > 完全省略，说明压缩削弱了近期交互对后续决策的锚定作用。
  - 压缩后立即出现更多阻塞/错误动作（第一动作边际效应 +0.108），随后出现更多重复探索/重取行为。
- **TRACE 在压缩基线中取得最优性能**：
  - 在 AppWorld test-normal 上，TRACE 平均 Acc 77.1、Pass 2 67.3、Pass@2 86.9，显著优于最佳压缩基线 Prompting-O（71.4 / 59.5 / 83.3），且距无压缩（85.7 / 77.4 / 94.0）更近。
  - 在 Hard 任务上优势最大：Acc 63.5 vs Prompting-O 60.3。
- **效率改进**：TRACE 保持接近全上下文的平均步数，同时大幅降低峰值 token 量（Hard 任务上峰值 token 约为全上下文的不到一半）。
- **跨模型迁移**：MiniMax-M3 优化出的模板直接迁移到 Kimi-K2.7-Code，整体 Acc 84.5、Pass 2 79.2，超过无压缩（82.7 / 73.8），且在 Medium 任务上三项指标全部超过无压缩，证明了压缩策略可跨模型迁移的初步潜力。

## 7. 优点：方法与实验设计亮点

- **问题视角新颖**：提出“执行状态错位”这一概念，将压缩质量评估从文本保真度转向对下游行为的可执行性影响，更贴合长时程智能体的实际需求。
- **验证器设计巧妙**：
  - 使用配对闭环续篇（PRE/POST）从同一环境状态出发，可有效控制智能体内在随机性和执行错误，隔离压缩的因果效应。
  - 通过“阻塞动作 + 重复调用”这种可观测、可量化的信号，避免终端结果归因困难。
- **优化信号纯净**：只向 proposer 提供摘要偏好，不暴露 rollout 细节，减少了对单一失败案例的过拟合；同时要求 proposer 对照系统提示审计，防止压缩规则与环境契约矛盾。
- **保持模型冻结**：只优化压缩提示，所有模型、工具、解码方式均不动，降低了部署成本，且展示出跨模型迁移能力。
- **实验协议规范**：所有基线共享相同的冻结智能体协议，保证压缩表示是唯一变量；冻结提示模板并记录哈希，提高可复现性。
- **效率分析**：同时报告准确率与步骤/峰值 token，揭示 FIFO 以牺牲执行步数换取 token 压缩的权衡，而 TRACE 能在两者间取得更优平衡。

## 8. 不足与局限

- **单一基准**：仅 AppWorld 一个环境，且该环境允许重新查询状态，结论不一定适用于信息不可恢复或知识密集类任务。
- **验证器信号有限**：目前只考虑阻塞和重复动作两类可观测事件，无法捕获“静默状态损坏”（如摘要中保留了错误但未引发错误的变量值），可能低估压缩的实际危害。
- **缺乏消融实验**：没有分别验证“边界局部验证器”相对“轨迹级反馈”的增益、配对 PRE 控制的作用、候选摘要数量等超参数影响，因果归因不够完整。
- **模型覆盖有限**：跨模型迁移只测试了一个目标模型（Kimi-K2.7-Code），且优化模型和目标模型均为同一

…家的模型，因此跨模型迁移结论的普适性有限。

- **统计严谨性不足**：所有指标均以点估计形式报告，未给出多次运行的方差或置信区间；Pass 2 仅基于两次运行，随机波动可能影响最终模板选择的可靠性。
- **成本与效率衡量维度单一**：主要报告峰值输入 tokens 与步数，未系统报告总 token 消耗、延迟或推理成本；对压缩带来的实际经济收益缺乏量化。
- **未讨论压缩对智能体学习/适应性指标的影响**：本工作聚焦冻结智能体的执行行为，未考察压缩策略在在线学习或策略更新场景下的长期影响。
