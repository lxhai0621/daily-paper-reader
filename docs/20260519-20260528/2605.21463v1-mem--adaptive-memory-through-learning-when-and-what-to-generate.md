## 摘要
我们提出Mem-$\pi$，一个面向大型语言模型（LLM）智能体的自适应记忆框架，其中有用的指导信息按需生成，而非从外部记忆存储中检索。现有的记忆增强智能体通常依赖从情节记忆库或技能库中基于相似性的检索，返回的静态条目常常与当前上下文不一致。与之相反，Mem-$\pi$使用一个独立的、拥有自身参数的专用语言或视觉-语言模型（与下游智能体分离），为复杂任务生成上下文特定的指导信息。基于当前智能体上下文，该模型联合决定何时生成指导以及生成何种指导。我们采用一种决策-内容解耦的强化学习（RL）目标对其进行训练，使其能够在生成无益时选择放弃，否则生成简洁而有用的指导。在涵盖网页导航、终端工具使用和基于文本的具身交互等多种智能体基准测试中，Mem-$\pi$始终优于基于检索的和先前RL优化的记忆基线，在网页导航任务上实现了超过30%的相对改进。

## Abstract
We present Mem-$π$, a framework for adaptive memory in large language model (LLM) agents, where useful guidance is generated on demand rather than retrieved from external memory stores. Existing memory-augmented agents typically rely on similarity-based retrieval from episodic memory banks or skill libraries, returning static entries that often misalign with the current context. In contrast, Mem-$π$ uses a dedicated language or vision-language model with its own parameters, separate from the downstream agent, to generate context-specific guidance for complex tasks. Conditioned on the current agent context, the model jointly decides when to produce guidance and what guidance to produce. We train it with a decision-content decoupled reinforcement learning (RL) objective, enabling it to abstain when generation would not help and otherwise produce concise, useful guidance. Across diverse agentic benchmarks spanning web navigation, terminal-based tool use, and text-based embodied interaction, Mem-$π$ consistently outperforms retrieval-based and prior RL-optimized memory baselines, achieving over 30% relative improvement on web navigation tasks.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有记忆增强的LLM智能体主要依赖检索式记忆（如情景记忆库、技能库），返回静态条目。这些条目常与当前上下文不匹配，包含无关或过时信息，无法动态适应任务需求。此外，检索式记忆的管理开销大（合并、遗忘），且无法融合多条经验为单一提示。
- **动机**：认知科学表明人类记忆不是字面重放，而是基于当前上下文和先前知识的动态重构过程。这启发将记忆建模为生成式策略，按需生成指导，而非固定检索。
- **整体含义**：Mem-π将记忆从静态存储转变为参数化生成策略，学习“何时生成”（放弃 vs. 生成）和“生成什么”（上下文相关的指导），从而提升智能体在复杂任务中的决策能力。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：使用一个独立于下游智能体的专用语言/视觉-语言模型（记为πmem），其参数编码可复用的经验，在推理时根据当前上下文（任务指令+环境观察）生成指导。指导被注入到智能体的输入中。
- **两阶段训练**：
  - **经验蒸馏（Stage 1）**：在离线经验库（由JEF-Hinter从先前轨迹中提取）上进行监督学习，将场景与指导的对映射参数化，使模型能生成上下文相关的指导。
  - **适应蒸馏（Stage 2）**：通过强化学习（基于GRPO）优化πmem，以下游智能体的任务成功奖励作为信号。引入放弃机制，模型可输出`[GENERATE]`或`[ABSTAIN]`决策。
- **关键技术：决策-内容解耦策略优化**
  - **结构化反事实采样**：每个任务采样一组固定分支：1个放弃（不生成）+ G-1个生成分支，保证组内可比较。
  - **优势分解**：计算放弃分支与生成分支平均奖励的差值Δ作为决策优势；生成分支内部通过组标准化得到内容优势。
  - **Token级信用分配**：决策token仅接收决策优势，内容token仅在Δ<0（即生成优于放弃）时接收内容优势，避免无效梯度。
  - **长度正则器**：对生成的指导施加长度惩罚，鼓励简洁。
- **公式**：最终目标为带有per-token优势的GRPO目标（式7），替代原始标量优势。
