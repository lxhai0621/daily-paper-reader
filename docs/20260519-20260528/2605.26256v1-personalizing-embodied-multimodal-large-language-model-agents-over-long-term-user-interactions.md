## 摘要
基于多模态大语言模型（MLLM）的具身智能体在解决物理环境中的复杂任务方面展现出巨大潜力。然而，个性化辅助不仅仅需要遵循通用指令或识别物体类别。在真实场景中，目标往往仅通过先前的交互隐含地指定，要求智能体利用随时间积累的个性化上下文。在这项工作中，我们提出POLAR，一种用于长期用户交互中个性化具身智能体的多模态记忆增强框架。POLAR将先前的交互组织成一个多模态知识图谱，该图谱捕获用于个性化上下文和视觉概念的语义记忆，以及用于具身经验（如智能体轨迹）的情景记忆。为了执行具身任务，POLAR检索相关记忆以解释当前请求并指导任务执行。我们在多种MLLM主干和不同评估场景下评估POLAR，以研究记忆在长期个性化中的作用。结果表明，所提出的记忆机制通过更有效地利用先前交互中积累的信息，持续提升性能。当智能体需要在多次交互中进行推理、执行多跳推理或随时间跟踪用户特定上下文的更新时，性能提升尤为显著。

## Abstract
Multimodal large language model (MLLM)-based embodied agents have shown strong potential for solving complex tasks in physical environments. However, personalized assistance requires more than following generic instruction or recognizing object categories. In real-world scenarios, the intended target is often specified only implicitly through prior interactions, requiring agents to leverage personalized context accumulated over time. In this work, we propose POLAR, a multiomodal memory-augmented framework for personalized embodied agents over long-term user interactions. POLAR organizes prior interactions into a multimodal knowledge graph that captures semantic memory for personalized context and visual concepts, and episodic memory for embodied experiences such as agent trajectories. To execute embodied tasks, POLAR retrieves relevant memories to interpret the current request and guide task execution. We evaluate POLAR across multiple MLLM backbones and diverse evaluation scenarios to study the role of memory in long-term personalization. Results show that the proposed memory mechanism consistently improves performance by enabling more effective use of information accumulated over prior interactions. The gains are especially pronounced when the agents are required to reason across multiple interactions, perform multi-hop inference, or tracking updates in user-specific context over time.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：真实场景中，用户对具身智能体的请求往往不显式指定目标对象，而是通过长期的多轮交互隐含地提供个性化上下文（例如，用户说“把我的鞋拿来”，但家里有多双鞋，需要根据先前对话推断是哪一双）。现有的基于多模态大语言模型（MLLM）的具身代理在解决此类任务时存在两大缺陷：
  1. 依赖通用指令或类别级识别，无法区分同一类别中的具体实例；
  2. 直接将原始交互日志作为上下文输入时，MLLM 在长上下文中表现退化，且无法有效利用随时间演化的信息。
- **研究背景**：个性化具身代理需要同时具备**记忆管理**（将交互组织为可用知识）和**个性化推理**（从记忆中检索并应用于当前任务）的能力。当前工作多假设目标参考显式给出，或仅依赖单次指令，忽略了长期交互中的隐式上下文。
- **整体贡献**：提出 **POLAR**（Personalized Embodied Agent with Multimodal Memory）框架，通过构建多模态记忆知识图，将语义记忆（用户特定属性和关联）与情景记忆（代理历史轨迹）结构化存储，在任务执行时检索相关记忆以定位目标实例并规划路径。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：将长期交互转化为**任务相关的结构化记忆**，而非原始日志或简单摘要。记忆组织为**多模态知识图**，包含三类节点：
  - **对象节点**：唯一对象 ID；
  - **语义记忆节点**：以精简文本语句存储关于对象的个性化属性（每次交互提取一组属性，如“用户通常把钥匙放在门厅桌子”），避免信息纠缠；
  - **情景记忆节点**：压缩代理轨迹，记录成功/失败、搜索重点（如哪些房间无目标）、有用过渡，支持未来规划。
- **记忆构建（Memorization）**：
  - 对每次交互，生成语义记忆（多语句）和情景记忆（精简文本）；
  - 通过对象 ID 或视觉相似度将新记忆连接到已有对象节点，或创建新节点；
  - 支持时间戳和去重：若新语义与已有节点高度相似，则连接而非重复。
- **利用阶段（Utilization）**：
  - 给定当前指令 \( I \)，使用 BGE-M3 编码器计算语义相似度，检索 top-5 语义记忆节点；
  - 沿图连接找到对应对象节点，收集关联的指令与情景记忆；
  - 对候选对象集合进行推理，确定意图目标，并利用情景记忆引导规划。
- **动作空间**：分层设计

  - **低层规划**：基于当前视觉观测（前、左、右视图）执行 MOVE_FORWARD、TURN_LEFT、TURN_RIGHT、STOP 等原生动作。

### 3. 实验设计：数据集、场景、基准方法
- **数据集与场景**：

  - 使用 GPT-5 生成个性化上下文（明确指令 + 评估指令），要求代理从先验交互中推断隐含目标；
  - 设计三个评估场景：

    3. **时间场景**（Temporal）：上下文随时间变化（偏好变化或所指对象变化）。

  - **no-prior**：仅使用当前指令和视觉观测；

  - **成功率 (SR)**：代理最终位置与目标距离 < 2m；
  - **SPL**（Success weighted by Path Length）：考虑路径效率；
  - **类别匹配 (CM)**：到达正确类别但错误实例的假阳性率（越低越好）。
