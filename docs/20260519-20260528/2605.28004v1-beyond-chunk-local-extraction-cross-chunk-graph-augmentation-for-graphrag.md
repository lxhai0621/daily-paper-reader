## 摘要
GraphRAG通过将语料组织为显式知识图谱来扩展检索增强生成，从而实现基于图的检索以支持复杂问答。然而，现有框架仅在单个块内提取实体和关系，导致跨块关系——即证据跨越多个段落的关系——系统地缺失于索引中。由于块组合的组合爆炸，基于LLM的穷举恢复此类关系在实践中不可行。我们提出CrossAug，一种GNN引导的跨块图增强方法，在查询时检索之前的离线步骤中，用跨块关系结构丰富GraphRAG索引。CrossAug通过自监督图破坏获取训练监督，使用拓扑感知的GNN对子图进行缺失性评分，并仅对选定的高分区域应用基于证据的LLM补全。在四个多跳和长文档QA基准测试中，基于三种LLM的GraphRAG框架上的实验表明，CrossAug持续提升性能，证实了跨块图增强对基于检索的问答的益处。我们的代码开源于https://github.com/DonFinliani/CrossAug。

## Abstract
GraphRAG extends retrieval-augmented generation by organizing corpora as explicit knowledge graphs, enabling graph-based retrieval for complex question answering. However, existing frameworks extract entities and relations within individual chunks, leaving cross-chunk relations -- those whose evidence spans multiple passages -- systematically absent from the index. Exhaustive LLM-based recovery of such relations is impractical due to the combinatorial explosion of chunk combinations. We present CrossAug, a GNN-guided CROSS-Chunk Graph AUGmentation method that enriches GraphRAG indices with cross-chunk relational structure as an offline step before query-time retrieval. CrossAug derives training supervision through self-supervised graph corruption, uses a topology-aware GNN to score subgraphs for missingness, and applies evidence-grounded LLM completion only to selected high-scoring regions. Experiments on three LLM-based GraphRAG frameworks across four multi-hop and long-document QA benchmarks demonstrate that CrossAug consistently improves performance, confirming the benefit of cross-chunk graph augmentation for retrieval-based question answering. Our code is available at https://github.com/DonFinliani/CrossAug.

# 论文详细总结：Beyond Chunk-Local Extraction: Cross-Chunk Graph Augmentation for GraphRAG

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有 GraphRAG 框架在构建图索引时，仅在单个文本块（chunk）内提取实体和关系，导致跨块关系——那些证据分布在多个段落中的关系——系统性缺失。例如，别名解析、因果链等关键关系需要联合阅读多个块才能恢复，而块局部提取器无法访问跨块信息，使得下游检索和问答在需要跨块证据的复杂问题上表现不佳。
- **背景**：尽管社区总结等方法能处理语料级查询，但无法精确恢复具体的跨块关系事实。手工标注所有缺失关系因块组合爆炸而不切实际。现有研究大多聚焦于如何更好地利用已构造的图进行检索、排序或推理，而非解决构造阶段的图不完整问题。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：引入图神经网络（GNN）作为结构性引导，通过结合语义节点特征与关系图结构，识别局部提取失败的典型模式，从而定位最可能需要 LLM 补全的区域；然后仅对选定的高缺失性子图调用 LLM 进行证据引导的补全，离线丰富图索引，不改变查询时流程。
- **关键模块**：
  1. **自监督图损坏模块**：
     - 从基础图中采样以实体为中心的子图，通过掩码事实边（mask fact edges）和删除实体节点（delete entity nodes）构造损坏视图，与完整视图配对，形成自监督训练数据（损坏为正样本，完整为负样本）。
  2. **拓扑感知 GNN 评分模块**：
     - 使用关系型 GNN（两层消息传递，使用边类型特异性变换）编码子图，通过全局均值池化和最大池化得到图表示，再经 MLP 和 Sigmoid 输出缺失性分数 m(S)。
     - 训练目标为二元交叉熵（BCE Loss）；推理时仅选择分数超过阈值 θ 且与已选子图节点重叠度低的子图，直到达到 LLM 调用预算 B。
  3. **GNN 引导的 LLM 补全模块**：
     - 为选中的子图组装上下文（根实体、实体列表、已知三元组、证据段落），要求 LLM 提出新实体和关系，且必须附带支持块 ID（citation grounding），丢弃无有效引用的三元组。
     - 验证后的三元组插入基础图索引，保证结构一致。

## 6. 主要结论与发现

- CrossAug 通过 GNN 引导的离线图增强，系统性地弥补了 GraphRAG 图索引中因块局部提取造成的跨块关系缺失，在不改变查询时流程的前提下持续提升多跳和长文档 QA 性能。
- 性能提升主要来源于：块顺序优化（提高有用证据排名）、块集合变化（引入黄金块或支撑桥梁块）、隐藏事实直接作为紧凑证据输入 QA 提示。
- 增强是框架无关的，适用于多种基于 LLM 抽取的 GraphRAG。
- 通过预设预算和阈值，额外成本可控（通常为基础流水线 15% 以内的时间开销），且增益在较小预算下已开始显现。

## 7. 优点

1. **创新性方法设计**：将跨块关系发现重新形式化为子图级缺失性检测，用 GNN 做廉价全局筛选，LLM 做精细化补全，避免穷举组合爆炸。
2. **自监督训练**：无需人工标注缺失关系，利用图本身构造损坏样本生成训练信号，实用性强。
3. **证据接地**：LLM 补全要求附带支持块 ID，并后置验证，减少幻觉。
4. **框架通用性**：仅依赖最小图接口（实体节点、关系边、证据溯源），可应用于多种 GraphRAG 实现。
5. **充分而系统的实验**：涵盖多种框架、数据集、消融、超参数分析、质量验证、细粒度检索效果拆解，全面且可信。

## 8. 不足与局限

1. **额外索引成本**：尽管可控，但 LLM 补全带来显著 prompt 开销（每条包含子图、多段落证据、已知三元组），对大语料仍可能高昂。论文讨论了成本但未提供极端大语料的缩放实验。
2. **仅限 LLM 抽取的 GraphRAG**：方法适用于显式三元组抽取的框架，不适用于仅依靠语义链接/共现的轻量级框架（如 LinearRAG），适用范围存在边界。
3. **三元组质量仍有误差**：自动评估显示约 80-84% 正确率，残留错误可能传播至下游问答，高风险场景需人工审计。
4. **未测试多种 LLM**：仅使用 Qwen3-32B 作为主干，未验证不同大小或系列 LLM 下的泛化性。
5. **缺乏统计显著性检验**：主要结果仅报告数值，未提供置信区间或 p 值，无法确认差异是否统计显著。
6. **长文档基准有限**：仅 LiteraryQA 为长文档，而且采样前 50 本书，未覆盖更多样化长篇类型（如学术论文、法律文件）。
7. **GNN 设计细节略显简化**：仅两层消息传递，未探索更深或更复杂 GNN 架构对缺失性检测的影响；特征仅使用原始嵌入投影，未融合其他结构或位置信息。
