## 摘要
长期记忆对于持久性LLM智能体至关重要，但现有架构将历史交互存储为非结构化的平面文本。这种无约束的存储导致了来源-角色崩溃，即智能体遭受源监控错误的关键失效模式。为了在架构层面解决这一认知脆弱性，我们提出了MemIR，一种类型化记忆中间表示，将源监控作为结构约束进行可操作化。MemIR将长期记忆写入基础原子，将原始证据、检索线索和事实主张分离，事实授权仅限支持的主张原子。然后，它应用多路径原子投影和来源范围利用，将异构检索命中转换为以主张为中心的候选束和用于答案生成的标准化事实接口。在LoCoMo和BEAM-100K上的实验表明，MemIR持续优于现有记忆基线，特别是在需要源跟踪、时间定位和碎片证据聚合的任务上。

## Abstract
Long-term memory is essential for persistent LLM agents, yet prevailing architectures store historical interactions as unstructured, flat text. This unconstrained storage induces provenance-role collapse, a critical failure mode where agents suffer from source-monitoring errors. To resolve this cognitive vulnerability at the architectural level, we propose MemIR, a typed Memory Intermediate Representation that operationalizes source monitoring as a structural constraint. MemIR writes long-term memory into grounded atoms that separate raw evidence, retrieval cues, and truth-bearing claims, with factual authorization restricted to supported claim atoms. It then applies multi-route atomic projection and provenance-scoped utilization to transform heterogeneous retrieval hits into claim-centered candidate bundles and a normalized fact interface for answer generation. Experiments on LoCoMo and BEAM-100K demonstrate that MemIR consistently outperforms existing memory baselines, especially on tasks requiring source tracking, temporal grounding, and aggregation of fragmented evidence.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：长期 LLM 智能体需要持久记忆来在多次交互中保持连贯行为，但现有记忆架构通常将历史交互存储为**非结构化的平面文本**（如摘要、对话片段）。这种扁平化存储丢失了记忆片段的**来源（provenance）**和**认知角色（role）**，导致**来源-角色崩溃（provenance-role collapse）**——智能体无法区分“观察到的原始证据”与“推断出的内容”，也无法跟踪指代关系和事实的时效性，从而产生源监控错误（source-monitoring errors）。
- **整体含义**：要实现可靠的长时记忆，不能仅依赖检索的命中率，而必须在架构层面引入**结构化的源监控机制**，将证据、线索和事实主张明确分离并授权，从而让智能体能够基于可溯源的事实进行推理，避免幻觉和错误聚合。

## 2. 论文提出的方法论：核心思想与关键技术

- **核心思想**：将认知科学中的**源监控理论（Source Monitoring）**操作化为结构约束，提出一种**类型化记忆中间表示——MemIR**。MemIR 把长时记忆组织为**记忆原子（memory atoms）**，原子类型区分原始证据、检索线索和事实主张，只有受支持的主张原子才可作为事实性记忆。检索时通过多路原子投影将异构命中映射到主张原子，再通过来源范围利用构造标准化的**事实接口**供下游生成使用。
- **关键技术细节**：

  1. **系统写作记忆原子（Systematic Writing of Memory Atoms）**：
     - 将交互历史离散化为**页面原子（P）**和**片段原子（S）**（保持局部上下文边界和逐字证据）。
     - 从片段中提取**句柄原子（H）**（指代参照）、**时间原子（T）**（时间锚定）、**枢纽原子（V）**（语义锚定），这些线索原子必须由片段支持（`∅≠ sup(x) ⊆ S`）。
     - 对每个页面，LLM 生成**主张原子（A）**，它们是唯一的事实承载单元，且必须有支持它的片段原子（`∅≠ sup(x) ⊆ S`）。
     - 构建**检索视图（R）**，定义跨原子访问关系（如片段到主张、句柄到涉及的主张等），不创建新内容。

  2. **多路原子投影（Multi-Route Atomic Projection）**：
     - 使用**稀疏检索（BM25）**和**密集检索（BGE-M3）**分别在检索视图和主张/片段原子进行检索。
     - 通过**倒数排名融合（RRF）**合并多路检索分数：`s_ret(x|q) = Σ_d 1[x∈TopK_d] / (k + rank_d(x|q))`。
     - 应用**类型约束投影**：只将检索命中映射到与其关联的主张原子（通过关联集 Ωa 包含支持片段、句柄、枢纽），无主张关联的命中丢弃。
     - 将映射到同一主张的命中聚合成**候选束**：`b_a = ⟨a, ρ_a, E_a⟩`，其中 `ρ_a = Σ_{h∈H_a} s_ret(o(h)|q)`，`E_a` 为来源闭包（包含所有关联原子）。

  3. **来源范围利用（Provenance-Scoped Utilization）**：
     - 先按聚合检索分数保留 top-M 候选束，再用**交叉编码器**重新评分，得到 top-K 束。
     - 通过**LLM 选择器**从 top-K 中选取至多 X 个互补束，并赋予角色（`direct` 或 `support`）。
     - 将选中束转换为**归一化事实接口**：`f_i = ⟨z(a_i), E_i, τ_i, r_i⟩`，包含事实文本、来源闭包、时间线索和角色。
     - 该接口作为下游答案模型的唯一输入，若证据不足则输出“insufficient evidence”。
