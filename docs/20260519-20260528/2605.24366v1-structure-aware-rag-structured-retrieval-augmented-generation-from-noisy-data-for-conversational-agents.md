## 摘要
大型语言模型（LLMs）已广泛用于对话应用。然而，它们对参数化知识的依赖限制了在需要动态或领域特定信息的现实场景中的可靠性。检索增强生成（RAG）通过在生成过程中融入外部知识解决了这一局限，但现有的基于文本和基于图的RAG方法通常难以应对噪声或不相关的上下文。在这项工作中，我们提出了结构感知检索增强生成（SA-RAG），它使用表格作为中间结构化表示，提供紧凑且可控的接口，在减少噪声的同时保留关键信息。我们引入了一个质量感知的表格元数据生成框架，该框架对元数据归一化和有效性进行建模，提升了元数据质量和下游性能。此外，我们探索了免训练和基于训练的表格生成方法。生成验证和直接偏好优化进一步提高了表格质量，同时保持了语义和结构一致性。在两个噪声真实世界数据集上的实验表明，SA-RAG显著优于现有的RAG基线。我们的代码可在公共仓库中获取。

## Abstract
Large Language Models (LLMs) have been widely adopted in conversational applications. However, their reliance on parametric knowledge limits reliability in real-world scenarios that require dynamic or domain-specific information. Retrieval-Augmented Generation (RAG) addresses this limitation by incorporating external knowledge during generation, but existing text-based and graph-based RAG methods often struggle with noisy or irrelevant contexts. In this work, we propose Structure-aware Retrieval Augmented Generation (SA-RAG), which uses tables as an intermediate structured representation to provide a compact and controllable interface that reduces noise while preserving essential information. We introduce a quality-aware table metadata generation framework that models metadata normalization and effectiveness, improving metadata quality and downstream performance. Furthermore, we explore both training-free and training-based table generation methods. Generation validation and direct preference optimization further improve table quality while maintaining semantic and structural consistency. Experiments on two noisy real-world datasets show that SA-RAG significantly outperforms existing RAG baselines. Our code is publicly available at a public repository.

## 2. 方法论
- **核心思想**：从原始噪声对话中自动诱导出高质量表格（含元数据及对齐的值），然后基于这些表格进行检索与生成。包含三个紧密耦合的阶段：
  1. **质量感知元数据生成（Quality-aware Metadata Generation）**  
     - 对每条对话，用LLM提取候选列名及附加信息（类型、语义）。  
     - 通过归一化函数 \( \mathcal{N} \) 将同义、粒度不一致的列名映射为标准形式。  
     - 迭代优化：定义质量目标函数 \( \mathcal{L}(\mathcal{M}) = \sum_{i,j} R(\tilde{m}_{ij}, \mathcal{M}) + S(\mathcal{M}) \)，其中 \( R \) 衡量列对信息的覆盖程度，\( S \) 衡量结构化规范程度。  
     - 每次新列候选加入前计算增量 \( \Delta \)，仅当收益为正且不超最大列数时才执行 **KEEP / EXPANDABLE / NEW / OTHER** 等元操作。  
  2. **表生成策略（Table Generation Strategy）**  
     - **免训练方法**：LLM直接生成单元格值 → 语义与结构验证（\( p_{ij} = I_{\text{sem}}(\tilde{v}_{ij}, d_i) \cdot I_{\text{struct}}(\tilde{v}_{ij}, m_j) \)），失败则置为NULL。  
     - **训练方法（DPO）**：构建偏好对（正例：人工标注的高质量表；负例：受控扰动表）。优化DPO损失函数，使模型在保持语义忠实性和元数据一致性的同时生成更可靠的表。  
  3. **结构感知检索与生成**  
     - 将查询和每条表行编码为稠密向量，余弦相似度检索Top-K。  
     - 从检索到的表中迭代抽取值-关系-信息三元组，累积形成结构化证据集 \( K_q \)。  
     - 最终响应 \( \hat{a} = \text{ResponseGenerator}(q, \mathcal{T}_q, K_q) \) 条件生成。

## 8. 不足与局限
- **额外预处理开销**：相比纯文本RAG，需要先诱导元数据、生成并验证表格，增加了数据准备阶段的算力与时间，尽管离线可接受，但在超大规模语料上可能成本显著。  
- **数据领域局限**：仅测试了技术支持和客服对话，表格诱导方法对其他类型（如开放域闲聊、医疗问答）的适用性未验证。

- **实验细节缺失**：未报告训练超参数、推理时的检索深度、LLM-as-judge的一致性和偏差分析，也未进行人类评估与自动指标的相关性验证。  
- **与干净数据对比缺失**：未展示SA-RAG在低噪声设置下是否仍优于基线，无法排除复杂方法在简单场景下过度设计的风险。
