## 摘要
现有智能体记忆系统普遍遵循我们称之为“记忆作为工具”的范式，其中单个查询触发扁平段落列表的一次性检索，存在被动调用、推理-检索解耦以及检索到的片段与智能体导航需求之间的结构不匹配等问题。我们提出MemCog，一种“记忆作为认知”系统，将记忆访问视为推理过程的一个组成部分。MemCog将用户知识组织为带有关联链接图的可导航记忆存储，提供跨维度导航接口以实现多步推理驱动的遍历，并采用主动推理协议，驱动智能体从对话上下文自发启动记忆探索。此外，我们构建了ProactiveMemBench，这是第一个用于评估主动记忆触发的基准测试。实验表明，MemCog在被动QA基准测试中取得了最先进的结果（LoCoMo上92.98，LongMemEval上95.8），同时在ProactiveMemBench上显著优于基线，证明了“记忆作为认知”的优势。

## Abstract
Existing agent memory systems universally follow what we term a Memory-as-Tool paradigm where a single query triggers one-shot retrieval of flat passage lists, suffering from passive invocation, reasoning-retrieval decoupling, and structural mismatch between retrieved fragments and the agent's navigational needs. We propose MemCog, a Memory-as-Cognition system that makes memory access an integral part of the reasoning process. MemCog organizes user knowledge as Navigable Memory Store with associative link graphs, exposes Cross-Dimensional Navigation Interface for multi-step reasoning-driven traversal, and employs Proactive Reasoning Protocol that drives agents to spontaneously initiate memory exploration from conversational context. We additionally construct ProactiveMemBench, the first benchmark for evaluating proactive memory triggering. Experiments show that MemCog achieves state-of-the-art on passive QA benchmarks (92.98 on LoCoMo, 95.8 on LongMemEval) while substantially outperforming baselines on ProactiveMemBench, demonstrating the advantage of Memory-as-Cognition.

## 1. 核心问题与整体含义

- **背景**：现有对话智能体的长期记忆系统普遍遵循 **“记忆作为工具”**（Memory-as-Tool）范式，即单个查询触发一次扁平段落列表的检索，智能体仅在检索完成后才进行推理。
- **核心问题**：该范式存在三大根本局限：
    - **调用瓶颈**：记忆系统仅当智能体显式调用工具时才被激活，无法主动从对话上下文中自发触发记忆检索。
    - **推理-检索解耦**：检索是一次性的，智能体的推理能力无法干预检索过程；当初始结果不足时，无法动态规划进一步探索。
    - **结构不匹配**：即使记忆有层次组织，返回的 top-k 碎片缺乏结构导航信息，智能体无法从当前结果推断下一步最佳检索路径。
- **论文含义**：提出 **“记忆作为认知”**（Memory-as-Cognition）范式，将记忆访问从被动的预处理步骤转变为智能体推理过程的有机组成部分，从而消除上述局限。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：通过**主动推理协议**驱动智能体自发探索，配合**可导航记忆存储**和**跨维度导航接口**，使检索与推理在多步循环中深度融合。
- **三大组件**：
    1. **可导航记忆存储（Navigable Memory Store）**：
        - 三级粒度：**维度**（顶层类别，如个人偏好、工作）、**页面**（每个维度内的主题单元）、**段落**（页面内的详细信息块，含摘要、结构化事实、关联页面链接等）。
        - **跨维关联链接**：包括四种类型（相关、时间后继、因果、对比），形成覆盖图，为智能体提供显式的导航线路提示。
        - 构建与更新：初始从对话历史提取事实并聚类构建；每次对话后增量更新（匹配旧页面、创建新页面、建立链接、冲突检测与置信度更新）。
    2. **跨维度导航接口（Cross-Dimensional Navigation Interface）**：
        - 提供多粒度动作：`list_dimensions()`（列出所有维度）、`browse_dimension(dim)`（浏览某维度的页面列表）、`read_page(page_id)`（读取页面完整内容及所有链接）、`follow_link(link)`（沿链接导航到目标页面）。
        - 每次动作返回的内容不仅包含请求的信息，还包含**结构上下文**（可用链接、兄弟页面、维度位置），支持智能体自主决策下一步。
    3. **主动推理协议（Proactive Reasoning Protocol）**：
        - 通过系统提示定义两种记忆使用模式：
            - **主动关联**：当对话上下文涉及人物、地点、主题等可能连接存储知识时，智能体自发启动导航；对话可能受益于历史上下文；用户陈述与存储信息矛盾时。
            - **被动响应**：用户明确询问过去信息时。
        - 强调渐进式导航、自然整合、选择性呈现（评判相关性、时效性、敏感性、冗余性）。
- **主动记忆基准构造**：提出 **ProactiveMemBench**，采用六步 LLM 驱动流程（生成角色-生成记忆单元-关联评分-跨会话分组-生成对话-生成评估问题），覆盖 5 个主题领域，500 个测试实例，包含时间、实体、情感、行为模式、多跳五种触发类型。

- **结论**：MemCog 验证了 **Memory-as-Cognition** 范式的有效性，将记忆从被动工具提升为集成推理的认知组件。

## 7. 优点

- **范式创新**：首次明确并解决 Memory-as-Tool 的三个根本限制，提出完整的 Memory-as-Cognition 替代方案。
- **方法设计**：主动推理协议与可导航存储的协同设计巧妙：协议驱动探索，存储提供持续探索的结构线索，形成正反馈循环。
- **多步导航接口**：将检索转化为可推理的多步动作序列，使智能体能根据中间结果动态调整路径，避免一次性检索的盲目性。
- **新基准贡献**：构建 ProactiveMemBench，填补主动记忆评估空白，并提供详细构造方法和人类验证，推动领域研究。
