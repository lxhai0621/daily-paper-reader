## 摘要
长期LLM智能体需要能够追踪变化的事实并在会话间提供相关证据的持久记忆。现有记忆系统通常将观测结果存储为孤立记录、摘要或索引片段，这使得证据聚合、事实修订和记忆维护变得困难。我们提出Infini Memory，一种可维护的基于文本的持久记忆架构，将智能体记忆视为主题结构化文档。每个主题文档作为一个语义单元，用于收集相关证据、保留元数据并随时间修订事实。新观测结果首先存入缓冲区，并定期整合为连贯的文本上下文。在推理时，一种智能体检索过程允许LLM通过迭代工具调用而非单次检索步骤来读取记忆。在MemoryAgentBench上，Infini Memory取得了64.7%的总体得分。消融实验表明，主题结构维护和迭代证据检查改善了长期记忆使用的互补方面。

## Abstract
Long-term LLM agents need persistent memory that can track changing facts and provide relevant evidence across sessions. Existing memory systems often store observations as isolated records, summaries, or indexed fragments, which makes evidence aggregation, fact revision, and memory maintenance difficult. We propose Infini Memory, a maintainable text-based persistent memory architecture that treats agent memory as topic-structured documents. Each topic document serves as a semantic unit for collecting related evidence, preserving metadata, and revising facts over time. New observations are first staged in a buffer and periodically consolidated into coherent textual contexts. At inference time, an agentic retrieval procedure lets the LLM read memory through iterative tool calls rather than a single retrieval step. On MemoryAgentBench, Infini Memory achieves 64.7% overall score. Ablations show that topic-structured maintenance and iterative evidence inspection improve complementary aspects of long-term memory use.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将外部记忆表示为一组**主题文档**，每个文档是一个语义单元，收集相关证据、保留元数据、支持事实修订。
- 新观测先进入短期**缓冲区 (CURRENT)**，避免频繁重写主题库；达到阈值后触发合并，经重写、主题路由、更新操作整合到主题库。
- 推理时采用**智能体检索**：LLM 通过工具调用（全局搜索、文档内搜索、目录浏览、行范围读取）进行多步搜索、验证、扩展上下文，直到收集足够证据。

### 关键技术细节
1. **主题文档格式**：
   - 元数据：doc_id, summary, token_count, created_time, update_log, aux
   - 内容：分层标题 + 条目，每个条目带解析签名 `<seq=..., time=..., source=...>`
   - 好处：条目级元数据随修订移动，保留时间/来源线索；文档摘要可随维护刷新。

2. **缓冲写入与合并流程**：
   - 缓冲区写入仅追加，不扫描主题库。
   - 合并触发条件：缓冲区 token 数 ≥ τ_tok 或存活时间 ≥ τ_time。
   - 合并步骤：
     1. 重写 CURRENT 为 REWRITE_CURRENT（去重、调和矛盾、分组）。
     2. 规划器决定每个块更新已有主题文档还是创建新文档。
     3. 应用更新/创建，清除 CURRENT。
     4. 定期拆分过长文档（≥5000 tokens）和合并过小文档（<1000 tokens）。

3. **智能体检索**：

   - 最终证据包含文档级、标题级或行范围；还包括 CURRENT 中的未合并条目。

## 6. 论文的主要结论与发现

- Infini Memory-A 在 MemoryAgentBench 上总体得分 **64.7%**，比最强基线 HippoRAG-v2（45.5%）高出 19.2 个百分点，在全部四个能力上均领先。
- 混合变体 Infini Memory-H 得分 61.3%，智能体检索额外提升 3.4 百分点，**选择性遗忘**提升最大（+7.0%），得益于显式时间/来源线索。
- 消融发现：
  - 去掉结构维护后准确率从 76.0% 降至 69.3%（-6.7 点），知识更新和多会话问题损失最明显。
  - 检索策略：单次摘要选择仅 41.7%，加 BM25 升至 76.0%，智能体检索至 79.3%。
  - 拆分阈值：5000 tokens 最佳；过低（1000）导致碎片但可通过混合检索恢复；过高（≥7000）因文档混合不同主题导致精度显著下降。
- **结论**: 持久智能体记忆质量既取决于记忆维护方式，也取决于证据检索方式，两者互补，缺一不可。
