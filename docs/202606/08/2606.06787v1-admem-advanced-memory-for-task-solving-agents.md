## 摘要
大型语言模型（LLMs）作为工具使用代理展现出潜力，但在需要记忆、组织和重用知识的长期任务中仍然受限。先前的记忆方法旨在解决这一情况，但主要侧重于存储事实信息。最近关于程序性记忆的工作改善了任务重用，但往往简化为重放过去的成功经验，而没有处理失败案例或在线可扩展性问题。我们引入了一个统一且自动化的记忆框架，该框架在结合短期和长期存储的双层设计中整合了语义、情景和程序性记忆。一个包含参与者、记忆和评论代理的多代理架构实现了自动记忆生成、奖励标注和自适应检索。通过基于奖励的评估、合并和剪枝来管理长期记忆，确保了可扩展性和持续改进。跨多种环境的实验表明，与现有基线相比，我们的方法提高了长期多轮任务的鲁棒性和成功率。这项研究强调了全面、自适应的记忆对于推进基于LLM的代理的重要性。

## Abstract
Large Language Models (LLMs) show promise as tool-using agents but remain limited in long-horizon tasks that require remembering, organizing, and reusing knowledge. Prior memory approaches aim to resolve the situation, but mainly focus on storing factual information. Recent work on procedural memory improves task reuse, yet often reduces to replaying past successes without addressing failure cases or online scalability. We introduce a unified and automatic memory framework that integrates semantic, episodic, and procedural memory in a bi-level design combining short-term and long-term stores. A multi-agent architecture with actor, memory, and critic agents enables automatic memory generation, reward annotation, and adaptive retrieval. Long-term memory is managed through reward-based evaluation, merging, and pruning, ensuring scalability and continual improvement. Experiments across various environments show that our approach improves robustness and success on long multi-turn tasks compared to existing baselines. This work highlights the importance of comprehensive, adaptive memory for advancing LLM-based agents.

## 2. 方法论

### 核心思想
- 提出 **AdMem** 框架，整合三种记忆类型：
  - **语义记忆 (MS)**：存储关于环境和任务的事实与通用知识。
  - **情景记忆 (ME)**：存储过去交互事件的摘要。
  - **程序记忆 (MP)**：存储从过去行动中提取的决策指导，包括成功与失败的反思。
- 采用 **双层记忆架构**：
  - **短期记忆 (STM)**：每个任务内维护，包含当前子目标、计划、上下文压缩（类似程序执行栈）。
  - **长期记忆 (LTM)**：跨任务持久化，通过检索、评估、合并、剪枝进行管理。
- **多智能体架构**：
  - **Actor 代理**：与环境和用户交互，执行任务，利用短期和长期记忆。
  - **Critic 代理**：负责生成程序记忆条目。它接收 Actor 的行动及其预期结果、实际观察，通过比较生成奖励 `r_t ∈ {0,1}` 和反思文本。
  - **Memory 代理**：管理长期记忆存储，实现检索与维护。

### 关键技术细节
- **短期上下文管理（栈结构）**：Actor 维护当前活动的子目标栈，超出栈范围的回合被压缩为摘要，实现上下文聚焦。
- **程序记忆生成流程**：
  - Actor 在行动时设置预期结果 `ˆo_{t+1}`。
  - Critic 接收半成品记忆（上下文、行动、预期、检索到的记忆），待相关观察全部返回后，生成奖励和反思。
  - 工具支持：计划新任务、添加子目标、结束子目标、思考、行动等。
- **长期记忆检索与更新**：
  - 语义/情景记忆使用密集检索（相似度匹配）。
  - 程序记忆检索结合上下文相似度和记忆有效性参数 `v_m`（表示建议有效性的概率）。
  - 更新机制：假设奖励是由多个检索到的记忆条目独立贡献的二进制随机过程 `r_t = l^{(1)}_t ∨ l^{(2)}_t ∨ ... ∨ l^{(n)}_t ∨ l_t`，其中 `l^{(i)}_t ∼ Bernoulli(v_{m^{(i)}} · ψ(c_t)^T ψ(c^{(i)}))`。通过 EM 算法更新 `v_m` 估计，初始设为 1（乐观面对不确定性）。
- **长期记忆管理**：基于检索频率进行剪枝（低于阈值 ε 删除），合并经常同时检索的条目。

### 算法流程
- **Actor 代理**（算法1）：每轮接收观察，报告给 Critic 和 Memory 代理，检索程序记忆，基于上下文和检索记忆选择行动，设定预期，更新短时记忆，将半成品记忆发送给 Critic。
- **Critic 代理**（算法2）：维护半成品记忆队列，当收到相关观察时，生成奖励和反思，将新程序记忆条目及检索记忆得分反馈给 Memory 代理。

## 6. 主要结论与发现

- AdMem 在 **大多数领域** 上显著提升了任务完成率和平均进度，尤其是在需要跨任务经验迁移的场景（如 AlfWorld: 63.4% vs ReAct 49.3%；PDDL: 76.7% vs 33.3%）。
- 短期规划（栈式上下文压缩）本身能提升单任务表现，但无法在任务间共享知识。
- 长期记忆单独加入时可能带来初期性能下降（信息混淆），但与短期规划结合后能有效避免损害，并在多轮 epoch 中持续改进（Jericho 上 AdMem 从 45% 提升到第三轮的 60%）。
- 表明自适应记忆系统对于 LLM 代理在长期、重复性任务中的自我进化至关重要。

## 7. 优点

- **统一记忆框架**：首次在 LLM 代理中完整整合语义、情景和程序记忆，并且通过多智能体协调自动生成和更新。
- **双层记忆管理**：短期栈式管理实现了上下文高效压缩；长期记忆利用基于奖励的评估和 EM 算法进行动态排序、合并与剪枝，实现可扩展学习。
- **实用化设计**：Critic 代理基于行动预期与实际结果对比生成奖惩，无需外部奖励信号，适合人工交互场景。
- **实验验证充分**：在多个类型环境测试，消融实验清晰揭示各组件贡献，并展示了多轮 epoch 的持续改进能力。
- **机制可解释**：记忆条目可审计、可追溯，记忆有效性参数更新基于概率模型，具有理论依据。

## 8. 不足与局限

- **单一模型验证**：所有实验仅使用 Claude Haiku 4.5，未评估其他 LLM（如 GPT-4, LLaMA 等）下的表现，限制了结论通用性。
- **消融实验不够广泛**：仅在一个领域（Jericho）进行了完整的组件消融和 epoch 测试，其他领域下的组件贡献未知。
- **计算开销**：虽然并行缓解延迟，但每步 LLM 调用次数增加（最多 3 倍），在延迟敏感或成本受限场景可能不适用。
- **奖励信号局限性**：Critic 使用二元奖励（0/1），对于复杂多步任务的细粒度信用分配可能不足；依赖期望与实际比较，若 Actor 设定不准确的预期会导致奖励信号有偏。

- **长期记忆更新机制简略**：EM 算法假设独立的记忆贡献，忽略记忆间交互；剪枝阈值 ε 需要手动设定，未讨论自适应调节方法。
