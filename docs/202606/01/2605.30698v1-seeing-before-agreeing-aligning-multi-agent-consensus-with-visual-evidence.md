## 摘要
视觉-语言模型（VLM）在视觉问答（VQA）上取得了强劲性能。为了减轻个体幻觉和盲点，通过多智能体协作汇聚不同视角已成为一种有前景的范式。虽然该方法在文本问答中取得了巨大成功，但其在多模态领域的潜力尚未被充分探索。现有的多智能体VQA方法主要采用以文本为中心的协议，专注于文本讨论而忽略了对齐视觉信息。在这项工作中，我们揭示了一个关键洞见：答案级别的共识不足以实现可靠的多智能体VQA，对齐的视觉证据——即智能体所依赖的图像区域的共享支持——对于值得信赖的共识至关重要。为了利用这一洞见，我们提出了EAGLE（证据对齐的接地多智能体推理），一种即插即用的以证据为中心的框架，用于协调多个VLM智能体。EAGLE显式暴露每个智能体的接地区域作为视觉证据，使证据之间能够相互验证，并利用证据一致性指导最终决策。在六个VQA基准上的实验表明，EAGLE在跨领域实现了最佳平均性能，同时保持了轻量级、可解释性和部署实用性。

## Abstract
Vision-language models (VLMs) have achieved strong performance on visual question answering (VQA). To mitigate individual hallucinations and blind spots, aggregating diverse perspectives via multi-agent collaboration has emerged as a promising paradigm. While this approach has shown great success in textual QA, its potential in the multimodal domain remains under-explored. Existing multi-agent VQA methods predominantly adapt text-centric protocols, focusing on textual discussions while ignoring the alignment of visual information. In this work, we reveal a key insight: answer-level agreement is insufficient for reliable multi-agent VQA; \textit{aligned visual evidence} -- shared support from the image regions agents rely on -- is essential for trustworthy consensus. To leverage this insight, we propose EAGLE (\textbf{E}vidence-\textbf{A}ligned \textbf{G}rounded mu\textbf{L}ti-agent r\textbf{E}asoning), a training-free evidence-centered framework for coordinating multiple VLM agents. EAGLE explicitly exposes each agent's grounding regions as visual evidence, enables mutual verification over the evidence, and uses evidence consistency to guide final decision-making. Experiments on six VQA benchmarks show that EAGLE achieves best average performance across domains while remaining lightweight, interpretable, and practical for deployment.

## 1. 核心问题与整体含义

**研究动机**：视觉语言模型（VLM）在视觉问答（VQA）中取得显著进展，但仍易产生幻觉、依赖语言先验或数据集偏差。虽然多智能体协作在文本问答中成功缓解了单模型缺陷，但在多模态领域（VQA）中，现有方法仍沿用以文本为中心的交互机制，仅交换语言级理由，而忽略了关键视觉证据的对齐。这导致智能体可能在答案层面达成一致，但其预测所依赖的视觉区域却不一致，从而形成虚假的、不可靠的共识。

**核心问题**：在多智能体VQA中，答案级一致不足以构建可信共识；必须确保各智能体所依赖的视觉证据（即grounding区域）也对齐。论文通过预先实验（pilot study）验证了这一现象：当答案一致但证据分散时准确率显著下降；只有答案和证据同时一致才能获得高可靠性。

**整体含义**：提出了一种新的多智能体协作原则——“先见后议”（Seeing Before Agreeing），即智能体必须在对齐视觉证据之后才达成共识，而非仅靠文本一致。基于此，设计了无需训练的以证据为中心的框架EAGLE，使多智能体VQA更可靠、可解释且高效。

## 2. 方法论

### 核心思想
EAGLE通过显式暴露每个VLM智能体的grounding区域（边界框）和原子视觉声明（visual claim），将视觉证据作为跨智能体对齐的基础，利用证据一致性来指导答案的接受、修正和仲裁，而非仅依赖答案投票。

### 关键技术细节
EAGLE包含五个顺序模块，无需额外训练：

- **Evidence Routing（证据路由）**：使用LLM根据问题类型将证据焦点分类为LOCAL（单物体）、RELATION（多物体空间关系）、GLOBAL（场景级）或PRECISION（细粒度读取/OCR）。为每个智能体分配任务特定的grounding指令，使产生的边界框和声明更可比较。

- **Grounded Answer（接地答案）**：各智能体独立输出答案、理由、边界框和原子视觉声明，形式化表示为 \(o_i^{(1)} = (y_i^{(1)}, r_i^{(1)}, b_i^{(1)}, c_i^{(1)})\)。

- **Evidence Diagnosis（证据诊断）**：联合评估答案一致性（UNANIMOUS / MAJORITY / DIVERGENT）和证据一致性（ALIGNED / PARTIAL / DISPERSED）。证据一致性通过两个信号判定：
  - **空间对齐**：计算智能体对之间边界框集的相互覆盖率，要求所有对的IoU > 阈值 \(\tau_{\text{iou}}\)（实验中设为0.4）。
  - **声明对齐**：用LLM判断两智能体的视觉声明是否表述兼容的视觉证据。
  只有同时满足空间和声明对齐，才认为一个智能体对证据对齐；仅当所有对都对齐时，当前轮次视为证据对齐。

- **Evidence-Gated Early Exit（证据门控早退）**：若当前轮次同时达成答案一致（UNANIMOUS）和证据对齐（ALIGNED），则直接采纳并退出；否则进入修正或最终仲裁。

- **Grounded Revision（接地修正）**：引导智能体以自身历史输出、其他智能体的输出和诊断信号为参考，重新审视图像，修正其预测。每个智能体再次输出完整的结构化结果。

- **Evidence-Guided Arbitration（证据引导仲裁）**：在达到最大轮次后仍未达成证据对齐一致时，按票数降序检查每个候选答案，选择第一个支持组内部证据对齐的答案；若无这样的组，则回退到最高票答案（平局时由最强单智能体预测打破）。

### 算法流程（文字描述）
1. 对每个问题，通过Evidence Routing获取证据焦点 \(f\)。
2. 第一轮：各智能体调用Grounded Answer生成初始输出。
3. 对当前轮次运行Evidence Diagnosis，判断是否满足早退条件（答案一致且证据对齐）。若满足，输出共同答案；否则进入下一步。
4. 若未达最大轮次，调用Grounded Revision使智能体修正预测，然后返回步骤3。
5. 若已达最大轮次，调用Evidence-Guided Arbitration决定最终答案。

## 3. 实验设计

## 6. 主要结论与发现

1. **答案级一致不可靠**：预实验显示，答案一致但证据分散时准确率（77.65%）显著低于答案一致且证据对齐时（85.98%）；证据和答案均不一致时准确率仅52.78%。
2. **视觉证据对齐是关键**：EAGLE通过显式暴露和比较grounding区域，使多智能体达成以证据为基础的可信共识，显著优于仅依赖文本讨论的现有方法。
3. **性能最优且高效**：在6个基准上EAGLE平均准确率72.69%，超过最强基线DART（70.15%），且VLM调用次数最少（4.087），无外部工具依赖。
4. **组件有效性**：消融实验表明每个模块（路由、grounding、仲裁、早退、修正上下文）均贡献正收益，去除后性能下降。
5. **一次修正足够**：参数实验显示一轮grounded revision即可获得可靠共识，更多轮次可能导致过修正。

## 7. 优点

1. **无需训练**：完全基于推理时的协调，易于部署和扩展至新VLM。
2. **以视觉证据为中心**：首次将多智能体VQA的共识建立在显式的grounding区域和视觉声明上，提升了可靠性和可解释性。
3. **证据门控早退**：在证据对齐一致时提前退出，减少不必要的计算开销，提升了效率。
4. **轻量级与实用**：使用轻量LLM（LLaMA-3.2-1B）进行路由和诊断，且无需外部视觉工具（对比DART），降低了部署复杂度。
5. **强大的泛化能力**：在覆盖不同难度与类型的6个基准上均达到最佳或次佳性能，验证了框架的通用性。
6. **诊断透明**：通过答案一致性和证据一致性的明确分类，为智能体修正提供了结构化信号，而非模糊的语言反馈。

## 8. 不足与局限

1. **实验范围有限**：仅评估了静态图像上的英文VQA基准，未涉及多语言、视频理解、具身感知、文档智能等更广泛的多模态场景。
2. **证据表示相对简单**：当前仅使用边界框和简短视觉声明，未来可引入更丰富的证据形式（如时间证据、层次场景结构、跨模态证据链）。
