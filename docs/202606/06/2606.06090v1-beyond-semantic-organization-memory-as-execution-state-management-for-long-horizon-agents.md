## 摘要
基于LLM的智能体越来越多地处理具有相互依赖决策的长时程任务，其中每个动作都会重塑未来约束，中间错误可能级联放大。现有的RAG和智能体记忆系统按语义相似性组织历史记录，在决策时检索内容相关条目。我们认为这种设计与执行状态依赖不匹配：它会分割决策轨迹，将有效和错误痕迹混合在一起，阻碍连贯的状态重建和错误隔离。我们提出MAGE（记忆作为智能体引导的探索），一种主动的执行状态管理器，将交互存储在层次化状态树中。智能体从活跃的根到当前路径派生其状态，结合子目标摘要、近期痕迹和来自先前分支的提示。四个耦合操作维护树：Grow记录新痕迹，Compress总结已完成子目标，Maintain验证摘要，Revise恢复目标边界并在新分支上继续。这种设计在保持状态完整性的同时限制上下文增长，并将缺陷片段从活跃路径中隔离。在MemoryArena上的实验表明，MAGE将平均任务成功率提高了7.8-20.4个百分点，同时将令牌消耗减少了55.1%。

## Abstract
LLM-based agents increasingly tackle long-horizon tasks with interdependent decisions, where each action reshapes future constraints and intermediate errors can cascade. Existing RAG and agent memory systems organize histories by semantic similarity, retrieving content-relevant entries at decision time. We argue that this design mismatches execution-state dependencies: it fragments decision trajectories and mixes valid and erroneous traces, hindering coherent state reconstruction and error isolation. We propose MAGE (Memory as Agent-Guided Exploration), an active execution-state manager that stores interactions in a hierarchical state tree. The agent derives its state from the active root-to-current path, combining subgoal summaries, recent traces, and hints from prior branches. Four coupled operations maintain the tree: Grow records new traces, Compress summarizes completed subgoals, Maintain validates summaries, and Revise restores a target boundary and resumes on a new branch. This design bounds context growth while preserving state integrity and isolating flawed segments from the active path. Experiments on MemoryArena show that MAGE improves the average task success rate by 7.8--20.4 pp over baselines, while reducing token consumption by 55.1%.

# 论文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：现有 LLM 智能体记忆系统普遍采用语义相似性（如 RAG、实体-关系图、层级存储）来组织和检索历史信息，这与长时程智能体任务中执行状态依赖（action-conditioned MDP）的本质不匹配。这种设计导致两个主要问题：
  1. **状态碎片化**：语义检索切断了决策链，使智能体无法重建完整的执行状态，从而做出基于不完整信息的错误决策。
  2. **错误隔离困难**：有效与错误轨迹混合在同一个记忆池中，且缺乏结构化的回滚边界，错误易级联传播。
- **研究意义**：重新定义记忆的角色——从被动的事实归档转为主动的执行状态管理器，为构建可靠且高效的长时程智能体提供了新思路。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程
- **核心思想**：将记忆建模为一棵**两层层次化状态树**，智能体只从**当前活跃的根到叶子路径**中提取完整执行状态（而非检索语义相似条目），并通过四个耦合操作维护树的更新与错误隔离。
- **关键技术细节**：
  - **状态树结构**：
    - 底层：记录每一个动作-观察对，保留细粒度执行顺序。
    - 顶层：存储已完成子目标的摘要节点，每个摘要覆盖一段连续的底层节点。
  - **执行状态 S 的组成**（从当前路径生成）：
    - `C`（压缩状态）：根到当前顶层摘要节点路径上的摘要内容。
    - `R`（原始状态）：最后一次压缩后累积的底层动作-观察片段。
    - `H`（执行提示）：当前节点的兄弟分支替代方案及诊断反馈。
  - **四个操作（算法流程）**：
    - **Grow**：当智能体执行新动作后，追加到底层树中；若已有相同内容的子节点则合并，否则建新节点。
    - **Compress**：在子目标完成或原始状态超过阈值时，将一段连续的底层节点压缩为顶层摘要，并清空 `R`。
    - **Maintain**：每次压缩后用 LLM 验证摘要和底层轨迹是否满足任务要求，若失败则记录诊断信息并返回失败信号。
    - **Revise**：当检测到错误时，将状态指针回滚到目标子目标边界，丢弃该分支，然后在新分支上继续执行，已正确完成的先前分支不受影响。
- **关键创新**：错误隔离是通过保留有效前缀、错误分支被排除在活跃路径之外实现的；上下文增长有界得益于边界感知压缩。

## 6. 论文的主要结论与发现
- MAGE 在 MemoryArena 上平均任务成功率比最好基线高出 **7.8–20.4 个百分点**，同时令牌消耗比 Long Context 降低 **55.1%**。
- 语义检索系统在状态依赖强的任务（如 Web Shopping）上不如全历史法，而在依赖稀疏的（如 Formal Reasoning）上可与全历史法持平。
- 消融实验表明：缺少 Compress 会显著增加 token 消耗并降低性能；缺少 Maintain 或 Revise 会导致错误写入或无法修复，最终损害成功率。
- 记忆结构组织应当以执行路径为核心，而非语义相似性。

## 8. 不足与局限
- **实验覆盖**：虽然跨域验证，但 MemoryArena 中的任务具有明确的子目标边界，MAGE 的 Compress/Revise 依赖于这些自然边界；在连续性任务（如对话、持续规划）中如何定义子目标尚需探讨。

- **应用限制**：当前设计假设错误可通过子目标边界隔离并分支重做；在不可逆动作（如支付、发货）或实时交互环境中需要额外的安全机制。
