## 摘要
长时域对话智能体需要通过与不断演变的事件、任务和目标进行交互。这类历史记录天然具有时间顺序，然而许多现有记忆系统主要根据主题相似性组织信息，可能忽略事件发生的顺序。我们提出了分段树记忆（Segment Tree Memory，简称SegTreeMem），一种将对话历史表示为按时间顺序排列的话语分段树的记忆架构。SegTreeMem通过在线最右前沿更新规则增量插入新话语，在形成层次化记忆分段的同时保留时间顺序。在检索时，SegTreeMem通过树传播相关性分数，将局部语义匹配与层次化时间上下文相结合。在三个长时域记忆基准测试和两个LLM骨干网络上，SegTreeMem在答案质量上优于平面检索、图结构记忆和树结构记忆基线。额外的时间顺序排列分析表明，性能提升依赖于在记忆构建过程中保留时间顺序，支持了时间顺序是智能体记忆关键结构的论断。

## Abstract
Long-horizon conversational agents need to interact with users through evolving events, tasks, and goals. Such histories are naturally temporal, yet many existing memory systems organize information primarily by topical similarity and may ignore the order in which events occur. We introduce Segment Tree Memory, or SegTreeMem, a memory architecture that represents conversation history as a temporally ordered Segment Tree over utterances. SegTreeMem incrementally inserts new utterances through an online rightmost-frontier update rule, preserving chronological order while forming hierarchical memory segments. For retrieval, SegTreeMem propagates relevance scores through the tree to combine local semantic matching with hierarchical temporal context. Across three long-horizon memory benchmarks and two LLM backbones, SegTreeMem improves answer quality over flat retrieval, graph-structured memory, and tree-structured memory baselines. Additional temporal-order permutation analysis shows that the performance gain depends on preserving temporal order during memory construction, supporting the claim that temporal order is a key structure for agentic memory.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
使用**线段树（Segment Tree）**作为记忆架构的基本数据结构。每个节点对应一个连续的话语区间，内部节点递归划分其区间为有序、不重叠的子区间。这天然保留了时间顺序，并支持层次化抽象。

### 关键技术细节

#### 2.1 对话线段树（Conversation Segment Tree）
- 根节点覆盖整个对话历史。
- 内部节点：区间为其子节点区间的并集，子节点按左右顺序排列，区间连续且不相交。
- 叶子节点：对应单个话语。
- 每个节点携带一个LLM生成的摘要（annotation）。

#### 2.2 在线构建：右前沿插入（Rightmost Frontier Update）
- 当新话语到来时，仅需检查**右前沿**（所有右端点为t的节点）作为候选插入位置。
- 使用**兼容性模型**选择最合适的非叶子前沿节点，将新话语作为右子节点插入；若无兼容节点，则创建新根。
- 三种兼容性模型：**余弦相似度**、**逐点LLM打分**、**批量LLM打分**。
- 更新仅影响O(log|Mt|)个节点，支持实时交互。

#### 2.3 检索：结构感知的分数传播（Structure-Aware Score Propagation）
- 先计算每个节点与查询的局部相关性分数，归一化为初始分布。
- 通过**传播矩阵**（基于树结构的转移矩阵）进行多跳传播：支持**自上而下**（父→子）和**自下而上**（子→父）两种策略。
- 最终分数为初始分数与传播分数的加权组合，衰减因子α控制传播强度，传播步数H限制范围。
- 选择top-K节点作为检索证据。

**方法局限：**
- **长程主题重现**：分隔遥远但主题相同的话语在树中结构距离远，有限传播无法连接，这是纯时间树的固有局限。

- **传播策略固定**：所有查询使用相同传播方向和参数，未实现查询自适应选择。
- **缺乏增量维护**：没有子树重平衡、压缩或去重机制，长期部署可能不高效。

**偏差风险：**
- 主要实验使用gpt-5.4-mini和text-embedding-3-small，可能偏向OpenAI生态。
- 数据集规模相对较小（总查询数约4000），统计显著性有限。

**应用限制：**
- 需要LLM进行节点摘要，成本较高（即使余弦构建也需要LLM摘要每个内部节点）。
- 对于非常长的对话（上千话语），树深度可能增加，传播效果可能减弱。
