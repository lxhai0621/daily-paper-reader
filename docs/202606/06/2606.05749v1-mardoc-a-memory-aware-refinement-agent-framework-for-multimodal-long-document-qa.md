## 摘要
迭代式检索-推理智能体近期在多模态长文档问答中展现出潜力。然而，现有系统大多维护一个不断增长的单一上下文，混合了检索痕迹、观察结果和中间推理过程。随着交互的累积，关键证据变得分散且稀释，使得多跳推理充满噪声。我们提出MARDoc，一种记忆感知精炼智能体框架，将长文档问答解耦为三个专用智能体：用于多粒度多模态检索的探索者、将交互痕迹提炼为结构化证据与推理记忆的精炼者，以及用于检查证据充分性并提供针对性反馈的反思者。在迭代过程中，智能体依赖动态更新的结构化记忆，而非完整的累积交互历史。该设计在保留答案关键事实及其逻辑依赖关系的同时，减少了上下文噪声。在MMLongBench-Doc和DocBench上的实验表明，MARDoc取得了优异的结果，超越了同基线模型，并展示了结构化记忆在智能体文档问答中的有效性。

## Abstract
Iterative retrieval-reasoning agents have recently shown promise for multimodal long-document question answering. However, most existing systems maintain a single growing context that mixes retrieval traces, observations, and intermediate reasoning. As interactions accumulate, key evidence becomes scattered and diluted, making multi-hop reasoning noisy. We propose MARDoc, a Memory-Aware Refinement Agent framework that decouples long-document QA into three specialized agents: an Explorer for multi-granularity multimodal retrieval, a Refiner for distilling interaction traces into structured evidence and reasoning memories, and a Reflector for checking evidence sufficiency and providing targeted feedback. Across iterations, the agents rely on a dynamically updated structured memory rather than a full accumulated interaction history. This design reduces context noise while preserving answer-critical facts and their logical dependencies. Experiments on MMLongBench-Doc and DocBench show that MARDoc achieves strong results, outperforming same-backbone baselines and demonstrating the effectiveness of structured memory for agentic document QA.

#### 1. 核心问题与整体含义（研究动机和背景）

- **问题**：多模态长文档问答（DocQA）中，现有迭代检索‑推理智能体（如 DocAgent、DocDancer）维护一个不断增长的单一上下文，混合了检索痕迹、观察结果和中间推理过程。随着交互轮次增加，关键证据变得分散且被稀释，导致多跳推理噪声大、错误累积。
- **背景**：实际应用（如金融报告分析、科学文献理解）需要模型跨页面、跨模态对齐信息，但现有方法受限于上下文窗口或检索碎片化。近期智能体方法虽引入规划与工具调用，仍受“单调上下文流”范式困扰，缺乏对证据的凝练与记忆机制。
- **动机**：设计一个能动态维护结构化记忆、替代完整交互历史的多智能体框架，以减少噪声、保留关键事实与逻辑依赖，从而提升多模态长文档问答的准确性。

#### 2. 方法论：核心思想、关键技术细节

- **核心思想**：将长文档问答解耦为三个专用智能体（Explorer、Refiner、Reflector），通过动态更新的结构化记忆（Structed Memory）而非完整交互历史进行通信，实现“探索‑精炼‑反思”迭代循环。
- **关键技术细节**：
    - **文档处理**：使用 MinerU2.5 解析文档，生成包含文本、布局、表格、图像等细粒度语义节点的结构化大纲；并用 Qwen3-VL 为视觉元素生成描述，增强可检索性。
    - **Explorer（探索者）**：基于 ReAct 框架，接收用户查询、大纲、当前记忆和反思指令，调用多粒度工具集（搜索、获取段落/章节/图片/表格等）进行检索，生成推理链并输出候选答案。
    - **Refiner（精炼者）**：在每轮探索后，将原始交互痕迹（推理链）蒸馏为两部分结构化记忆：
        - **证据记忆（$M_E$）**：记录与问题最相关的事实信息及其来源（如“图表显示 26% 的 Rep/Lean Rep 群体支持对华贸易”）。
        - **推理记忆（$M_R$）**：提取清晰的推理路径，每个节点标注依赖的证据，形成证据链。
    - **Reflector（反思者）**：检查当前记忆是否足以回答问题。若充分，直接输出最终答案；若不充分或存在错误，生成针对性反馈指令（如“缺少 Rep/Lean Rep 总人数”），指导下一轮探索。
- **公式/算法流程**：
    - 第 t 轮：Explorer 输出推理链 $T_t = M_{Exp}(Q, O, M_{t-1}, R_{t-1})$；
    - Refiner 更新记忆：$(M_E, M_R) = M_{Ref}(Q, T_t, M_{t-1})$；
    - Reflector 评估：若充分则输出答案 $A = M_{Ref}(M_t, Q)$，否则生成反馈 $R_t = M_{Ref}(M_t, Q)$。
    - 记忆 $M_t$ 覆盖旧记忆，避免上下文无限累积。

#### 6. 主要结论与发现

- MARDoc 在 MMLongBench-Doc 上使用 Qwen3-30B 达到 57.1% ACC，超越 DocAgent 使用 Claude 3.5 Sonnet 的结果（57.3%），且以更小骨干模型取得竞争力。
- 结构化记忆显著优于单调上下文流：消除噪声、保持关键证据与逻辑依赖，尤其利于多跳推理。
- Refiner 的两个记忆组件互补：$M_E$ 确保事实忠诚度，$M_R$ 维护推理连贯性，两者结合有效缓解幻觉并提升多跳准确率。
- Reflector 的反馈指令对提升单跳与多跳问题至关重要；无指令时模型更倾向预测“不可回答”。
- 细粒度文档表示（MinerU2.5）和多样化工具有助于提升检索质量。
- 额外计算代价（约 22.5k token / 15.9 秒）可换取显著的准确率提升（7.8 个百分点）。

#### 7. 优点

- **创新性**：提出“记忆‑感知精炼”范式，用结构化的证据记忆与推理记忆替代累积的上下文流，从根本上缓解上下文稀释问题。
- **系统化设计**：三个智能体分工明确（探索、精炼、反思），通过记忆接口通信，实现稳定迭代。
- **实验扎实**：在多个基准上与多种基线公平对比，消融实验逐一验证组件贡献，分析细致（如按证据页数、问题类型、迭代次数）。
- **实用性强**：采用 training‑free 方式，直接使用现有 MLLM 和提示工程即可部署，计算成本可接受。

#### 8. 不足与局限

- **缺乏微调**：仅基于提示工程，未进行任务特定微调，可能限制上限。未来可通过训练进一步优化。
- **模型泛化性**：实验仅基于 Qwen3-VL 模型家族，未验证在其他架构（如 LLaVA、InternVL）上的表现。
- **延迟与效率**：迭代循环涉及多轮工具调用和 LLM 推理，导致延迟高于单次方法（平均 65.3s vs DocAgent 的 49.4s），实际部署需考虑实时性。

- **可能偏差**：评估依赖 GPT-4o 提取答案（MMLongBench-Doc）或评价（DocBench），可能引入评估者自身偏差；数据集规模有限（135 和 229 个文档），结论可能不适用于所有长文档场景。
