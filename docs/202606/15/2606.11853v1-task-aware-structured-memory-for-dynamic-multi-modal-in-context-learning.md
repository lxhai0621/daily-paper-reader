## 摘要
多模态大语言模型依赖上下文学习进行快速任务适应，但其可扩展性严重受限于有限的上下文窗口以及在长多模态序列中不断增长的关键值缓存成本。现有的记忆压缩方法通常依赖于刚性标记移除或样本相关的重要性估计，这会引入偏差、破坏语义结构（尤其是视觉表示），并产生无法适应新查询的静态记忆。我们提出了TASM（任务感知结构化记忆），这是一个无需训练的框架，通过任务感知、结构保持和动态可访问的记忆构建来解决这些限制。TASM采用任务向量引导压缩，用捕捉演示间共享相关性的任务级方向替代样本特定信号。为保留底层流形，它通过二分图匹配实现语义感知的标记合并，在无破坏性剪枝的情况下聚合标记。最后，TASM将记忆结构化为包含紧凑核心记忆和潜在库的层次结构，支持查询自适应的动态检索。评估证实，TASM在重度压缩下仍保持高性能，有效平衡了效率与适应性。

## Abstract
Multi-modal large language models (MLLMs) depend on in-context learning (ICL) for rapid task adaptation, but their scalability is severely limited by finite context windows and the growing cost of key-value (KV) caches in long multi-modal sequences. Existing memory compression approaches typically rely on rigid token removal or sample-dependent importance estimation, which introduces bias, disrupts semantic structure, particularly for visual representations, and yields static memories that cannot adapt to new queries. We introduce TASM (Task-Aware Structured Memory), a training-free framework that addresses these limitations through task-aware, structure-preserving, and dynamically accessible memory construction. TASM employs task-vector guided compression to replace sample-specific signals with a task-level direction that captures shared relevance across demonstrations. To preserve the underlying manifold, it applies semantics-aware token merging via bipartite graph matching, aggregating tokens without destructive pruning. Finally, TASM structures memory into a hierarchy comprising a compact Core Memory and a Latent Bank, facilitating query-adaptive dynamic retrieval. Evaluations confirm TASM maintains high performance under heavy compression, effectively balancing efficiency with adaptability.

## 1. 核心问题与整体含义（研究动机与背景）
多模态大语言模型（MLLMs）依赖上下文学习（ICL）进行快速任务适应，但面临严重的可扩展性瓶颈：有限的上下文窗口以及长序列中KV缓存的高昂内存与计算成本。现有记忆压缩方法存在三大结构性缺陷：
- **样本特定偏差**：基于答案注意力分数的剪枝过度拟合演示样本，忽略了查询所需的关键上下文。
- **拓扑破坏**：硬剪枝（如Top-K）破坏视觉标记的2D空间结构，损害定位等任务。
- **静态记忆僵化**：压缩后的缓存无法根据新查询动态恢复被丢弃的信息。

本文提出TASM（Task-Aware Structured Memory），一个**无需训练**的框架，通过任务感知、结构保持和动态可访问的记忆构建来解决上述问题。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
将KV缓存视为任务的结构化表示，而非静态缓冲。压缩由任务本身的变换方向（任务向量）引导，而非个体样本内容。

### 关键技术细节
1. **任务向量引导压缩**：
   - 从少量演示（问题-答案对）中提取全局任务向量 \(\tau_l = (\mu_{A,l} - \mu_{Q,l}) / \|\mu_{A,l} - \mu_{Q,l}\|_2\)，表示“问题→答案”的变换方向。
   - 重要性分数 \(s^{\text{task}}_{i,l} = \text{ReLU}(\mathbf{k}_{i,l}^\top \tau_l / \|\mathbf{k}_{i,l}\|) + \gamma \|\mathbf{v}_{i,l}\|_2 / \max_j \|\mathbf{v}_{j,l}\|_2\)，结合任务对齐度与值范数。
   - 层自适应门控 \(\lambda(l)\) 在浅层侧重局部注意力，深层侧重任务向量。

2. **语义感知令牌合并**：
   - 将高分数令牌作为“汇点”（Sinks），低分数令牌作为“源点”（Sources），构建二分图。
   - 边权重包含余弦相似度和空间约束（\(\Delta_{\text{win}}=3\) 窗口），防止跨空间合并。
   - 通过加权质心聚合源令牌到汇点，保留信息密度与2D拓扑结构。

3. **查询自适应动态检索**：
   - 层次记忆：GPU驻留的紧凑**核心记忆**（Core Memory）与CPU卸载的**潜在库**（Latent Bank）。
   - 基于JS散度 \(D_{\text{JS}}(P_t \| P_{\text{ref}})\) 监测注意力分布变化，当超过阈值 \(\delta\) 时触发检索，从潜在库获取Top-k相关令牌。
   - 有效缓存动态扩展：\(C_t = M_{\text{core}} \cup K_{\text{retrieved}}\)。

### 算法流程（文字描述）
1. 初始化：用少量演示提取任务向量 \(\tau\)（每层）。
2. 每步推理：计算当前查询注意力分布，若JS散度 > \(\delta\) 则从潜在库检索。
3. 计算重要性分数 \(S\)（任务分数与注意力的加权）。
4. 选择Top-B令牌作为汇点，其余作为源点。
5. 二分图匹配合并源令牌到汇点，更新核心记忆。
6. 未合并的令牌加入潜在库。

## 6. 主要结论与发现
- TASM在**78.6%压缩比**下（ImageNet-100：16,264→3,485 tokens），性能**匹配甚至超越**全上下文MLoC。
- 在时间推理任务（YouCook2）上，TASM超越全上下文（109.5 vs 108.8），而EMLoC下降（102.0）。
- 在空间定位（ScreenSpot）上，TASM优于EMLoC（19.5 vs 18.3）。
- 在V-NIAH挑战中（200张图像），TASM准确率45.5%，是EMLoC（18.9%）的2.4倍。
- **任务向量可零样本迁移**：在一个类别集上提取的向量可直接用于另一类别集（性能仅下降0.8%）。
- **语义感知令牌合并**保留空间结构，硬剪枝破坏流形。
- 动态检索仅在3.4%的步骤触发，高效实现了自适应上下文扩展。

## 7. 优点
- **无需训练**：可直接应用于现有MLLM（如Qwen2-VL、LLaVA、InternVL），无需微调。
- **结构保留**：通过合并而非剪枝，保持视觉拓扑，特别适用于空间/时间敏感任务。
- **动态自适应**：基于JS散度的检索只在需要时激活，兼顾效率与准确率。
- **高效可扩展**：在32k上下文中仅用11.5GB显存、43.8 tok/s，而全上下文OOM。
- **鲁棒泛化**：在动态高分辨率模型（InternVL3）上几乎无性能损失，优于现有剪枝方法。

## 8. 不足与局限
- **冷启动成本**：需要少量演示（约4个）提取任务向量，虽然样本效率高，但仍需预处理。
- **超参数敏感性**：JS散度阈值\(\delta\)和任务向量权重\(\alpha\)需根据任务调整，论文虽给出默认值但未提供自动调节策略。
- **计算开销**：预填充阶段因二分图匹配略有增加（相比硬剪枝+35ms @32k），但解码阶段几乎无影响。
- **模型规模验证**：主要基于7B模型，未在更大模型（如70B+）上实验，可扩展性需进一步确认。
- **潜在偏差**：任务向量提取依赖于演示数据的质量和代表性，若演示分布与测试分布差异大，可能影响压缩质量。
