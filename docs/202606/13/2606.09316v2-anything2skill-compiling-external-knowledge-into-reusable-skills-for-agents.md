## 摘要
检索增强生成（RAG）使智能体能够在推理时访问外部知识，但它主要检索碎片化的陈述性证据，使得智能体不得不反复从段落、手册、示例、日志或轨迹中推断任务流程。这引出一个基本问题：能否将从外部知识库中提取的技能安装到智能体中，使其快速逼近领域专业知识？在本文中，我们提出 Anything2Skill，一个基于类别引导的框架，将异构外部知识编译为智能体的可复用、可检索且可执行的技能。给定知识记录语料库，\textsc{Anything2Skill} 首先将每条记录分解为证据窗口，并在技能树先验下执行规划与扩展的技能提取。提取的候选技能随后被转换为结构化的技能合约，指定调用条件、禁忌操作、动作步骤、工作流阶段、约束、输出规范、支持证据和置信度分数。为了构建可部署的程序性记忆，Anything2Skill 通过类别感知编译、注册表级协调、生命周期追踪、版本化更新和可见的技能树投影，将提取的技能管理在持久化 SkillBank 中。推理时，智能体同时从原始知识库检索任务特定段落，并从 SkillBank 检索相关程序性技能，使 RAG 提供陈述性证据，而编译的技能提供可复用的程序性指导。在 qsv 和 GitHub-CLI 上的实验表明，Anything2Skill 结合 RAG 分别实现了 98.85% 和 94.10% 的成功率，大幅优于仅使用 RAG 的智能体。这些结果表明，将潜在的程序性知识编译为显式技能是将检索增强智能体从知识访问扩展到能力复用的有效途径。

## Abstract
Retrieval-augmented generation (RAG) enables agents to access external knowledge at inference time, but it primarily retrieves fragmented declarative evidence, leaving agents to repeatedly infer task procedures from passages, manuals, examples, logs, or trajectories. This raises a fundamental question: can skills extracted from external knowledge bases be installed into an agent, enabling it to rapidly approximate domain expertise? In this paper, we propose Anything2Skill, a taxonomy-guided framework that compiles heterogeneous external knowledge into reusable, retrievable, and executable skills for agents. Given a corpus of knowledge records, \textsc{Anything2Skill} first decomposes each record into evidence windows and performs plan-and-expand skill extraction under a skill-tree prior. The extracted candidates are then converted into structured skill contracts that specify invocation conditions, contraindications, action moves, workflow steps, constraints, output specifications, supporting evidence, and confidence scores. To construct a deployable procedural memory, Anything2Skill manages the extracted skills in a persistent SkillBank through taxonomy-aware compilation, registry-level reconciliation, lifecycle tracking, versioned updates, and visible skill-tree projection. At inference time, agents retrieve both task-specific passages from the original knowledge base and relevant procedural skills from the SkillBank, allowing RAG to provide declarative evidence while compiled skills provide reusable procedural guidance. Experiments on qsv and GitHub-CLI show that Anything2Skill combined with RAG achieves 98.85\% and 94.10\% success rates, respectively, substantially outperforming RAG-only agents. These results suggest that compiling latent procedural knowledge into explicit skills is an effective way to extend retrieval-augmented agents from knowledge access toward capability reuse.

- **核心问题**：现有检索增强生成（RAG）仅能检索碎片化的**陈述性知识**（如文档段落、事实描述），无法直接提供**程序性知识**（即如何完成任务的流程、步骤、约束等）。智能体必须反复从外部证据中手动推断任务过程，导致效率低下且容易出错。
- **研究背景**：大语言模型（LLM）作为智能体时，需要外部的、可更新的知识支持。RAG 虽解决了知识获取的广度，但缺乏对“如何做”的封装。近期工作（如 ReAct、Toolformer、Voyager 等）显示了显式技能、记忆、工具的重要性，但大多数技能来源于手工定义、环境交互或执行代码，**忽略了外部知识库中已存在的大量潜在程序性知识**。
- **整体含义**：本文提出从异构知识（文档、手册、日志、对话、轨迹等）中**自动提取并编译为可复用、可检索、可执行的技能**，从而将 RAG 从“知识访问”扩展到“能力复用”，让智能体能够快速逼近领域专家。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
- **Anything2Skill**：一个基于**技能树先验（Skill-Tree Prior）** 的框架，将异构知识记录分解为证据窗口，通过“规划-扩展”策略提取技能候选，并转化为结构化**技能合约**，最终编译到持久化 **SkillBank** 中。推理时，智能体同时检索原始知识库（RAG 提供陈述性证据）和 SkillBank（提供程序性指导），实现互补。

### 关键技术细节（流程描述）

1. **证据窗口构建**：每条输入知识记录被分解为严格的证据窗口，每个窗口包含文本段、标题上下文、字符范围、锚点信息、元数据（源路径、标题路径等），确保每个技能可追溯。

2. **技能提取（Plan-and-Expand）**：
   - **规划阶段**：LLM 根据窗口和技能树先验，识别候选技能，包括轻量目标、初步资产类型、调用线索、禁忌、预期产物等。
   - **扩展阶段**：对每个候选独立扩展为结构化技能草案，若窗口不支持则返回空（防止幻觉）。
   - **过程性有效性过滤器**：只保留至少含一个过程性组件（工作流步骤、动作、约束）且可映射到技能树类型的候选。

3. **结构化技能合约**：每个技能 `s` 包含：
   - 名称、描述、规范化资产类型、技能树节点、粒度级别、上下文元数据（领域、族、任务类型、方法类型、阶段）
   - 调用条件、禁忌条件、动作/干预步骤、工作流步骤、约束与注意、输出合约
   - 支持证据集（支持、约束、冲突、案例变体等）
   - 置信度分数

4. **SkillBank 管理**（三步）：
   - **文档级编译**：将同一文档内共享身份键（资产类型、粒度、节点、名称等）的草案分组，通过编译器生成规范技能，保证资产类型、粒度、节点不变，且只引用组内证据。
   - **注册表级协调**：新技能与已有 SkillBank 通过混合检索（稠密+BM25+类别兼容性）找到邻居，由管理模型预测生命周期动作（创建、增强、修订、合并、拆分、不变、丢弃），约束类型兼容性。维护版本历史。
   - **可见技能树投影**：将激活技能按层级组织，选择父节点，进行同级去重合并（基于相同关键属性），生成层次化投影。

- **编译技能显著提升智能体性能**：仅使用 Skills 在 qsv 上成功率从 81.60% 提升至 91.95%（+10.35pp），在 GitHub-CLI 上从 64.70% 提升至 82.30%（+17.60pp），无需任务时文档检索。
