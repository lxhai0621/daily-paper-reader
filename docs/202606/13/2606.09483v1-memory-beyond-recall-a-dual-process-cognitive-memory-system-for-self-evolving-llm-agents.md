## 摘要
对于LLM智能体而言，长期记忆不仅仅是在正确的时间检索正确的段落。当前的记忆系统将信念修正、因果耦合和跨领域抽象压缩到单一的检索界面中，该界面针对表面回忆进行了调优，因此难以处理需要推理用户如何演变的隐式个性化。我们提出DCPM，它沿着认知能力层级重新组织智能体记忆，从原始输入和原子事实开始，经过历时信念轨迹和身份，上升到领域图式、潜在意图和跨领域模式。该层级由继承双过程理论架构分离的两个过程驱动：一个同步的白天写入器（系统1），它将信念修正记录为双重链接的取代链；以及一个异步的夜间引擎（系统2），它归纳图式和意图，并扫描跨领域冲突，抽象为更高级别的核心图式。在LongMemEval、PersonaMem和PersonaMem-v2上，启用系统2在基准测试奖励隐式跨会话推理的任务中贡献最大（在PersonaMem-v2上最高提升+5.20），而在跨度回忆任务中贡献最小，这与架构预测一致。

## Abstract
Long-term memory for an LLM agent is more than retrieving the right passage at the right time. Current memory systems collapse belief revision, causal coupling, and cross-domain abstraction into a single retrieval surface tuned for surface recall, and consequently struggle on implicit personalisation that requires reasoning over how a user has evolved. We propose DCPM, which reorganises agent memory along a cognitive capability hierarchy ascending from raw inputs and atomic facts, through diachronic belief trajectories and identity, to domain schemas, latent intentions and cross-domain patterns. The hierarchy is driven by two processes inheriting the architectural split of dual-process theory: a synchronous daytime writer (System1) that records belief revisions as doubly linked supersedes chains, and an asynchronous nighttime engine (System2) that induces schemas and intentions and sweeps for cross-domain collisions abstracted into higher-level core schemas. On LongMemEval, PersonaMem and PersonaMem-v2, enabling System2 contributes most where the benchmark rewards implicit cross-session inference (up to +5.20 on PersonaMem-v2) and least on span recall, matching the architectural prediction.

## 1. 核心问题与整体含义（研究动机和背景）

- 现有LLM智能体的长期记忆系统被简化为检索问题：它们将**信念修正**（用户如何改变看法）、**因果耦合**（信念变化的原因）、**跨领域抽象**（不同生活领域的行为模式）等认知功能混入单一检索表面，只优化了对显式事实的“表面回忆”。
- 结果：智能体无法处理**隐式个性化**任务——例如，需要推理用户偏好如何随时间演变、为何改变，或在不同领域间发现潜在模式。一个与用户对话数周的智能体仍会错误回答基本个性化查询。
- 作者提出：**记忆应被视为认知过程而非存储问题**，并借鉴**双过程理论**（Kahneman, 2011）和**心理理论**（Theory-of-Mind），按认知能力层级（从原始输入→事实→身份→图式→意图→跨域核心图式）组织智能体记忆。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：基于认知能力层级，将记忆系统拆分为两个进程：
  - **System 1（同步白天写入器）**：在线实时处理，记录信念演化轨迹。
  - **System 2（异步夜间引擎）**：离线运行，诱导高层次认知结构。
- **关键技术细节**：
  - **System 1**：当用户或应用发出 `add_memory` 请求时立即执行：（1）原始持久化（零损失）；（2）提取身份项与原子事实（含类型、主题、显著性、时间戳）；（3）调和（Reconcile）步骤：对每个新项，与向量库中top-k最近项比较，决定 ADD / SUPERSEDE / UPDATE / 丢弃；（4）批量嵌入并更新向量库，对 SUPERSEDE 操作写入双向指针 `n_new.SUPERSEDES = n_old` 和 `n_old.SUPERSEDED_BY = n_new`，形成**双重链接取代链**，保留历史中间状态。
  - **System 2**：在空闲或夜间运行，分三阶段：（1）预处理（无LLM）：对新事实进行两阶段DBSCAN聚类；（2）LLM诱导：对每个簇调用一个具有四个工具（创建图式、创建意图、添加证据、添加边）的智能体，构建图结构；（3）跨域扫描器：对每个图式提取行为抽象描述，分别嵌入行为-认知空间（E_beh）和语义空间（E_sem），检测跨域碰撞（E_beh高相似但E_sem低相似），对碰撞簇诱导生成**核心图式**。
  - **读取路径**：查询嵌入通过向量相似性命中事实/身份库，遍历取代链，并通过证据链接检索图式/意图/核心图式节点。**全程不调用LLM**，延迟仅由向量搜索和指针遍历决定。

- **双过程假设成立**：启用System 2在隐式跨会话推理任务（PersonaMem-v2）上提升最大（+5.20），在表面回忆（LongMemEval）上提升很小（+0.33～+0.44），在显式偏好回忆（PersonaMem）居中（+1.31～+2.41）。
- DCPM full 在PersonaMem-v2上达到最强结果（kimi-2.5: 59.30%），超过长上下文基线（58.46%）。
- 消融显示：**核心图式（跨域碰撞）贡献约4.1个点**，图式/意图贡献约1.1个点，取代链贡献约2.9个点。
- 取代链对知识更新子集正确回答的预测力强：78%正确答案涉及至少一个取代指针，而仅31%错误答案涉及。
- 节点分布以事实为主（42.8%），核心图式仅占1.3%但贡献了大部分System 2增益，说明其编码了高杠杆认知结构。

## 7. 优点

- **理论驱动**：明确基于双过程理论和心理理论设计记忆系统，具有认知科学基础，架构可解释。
- **认知能力层级**：超越简单存储，引入信念演化链条、图式、意图和跨域抽象，符合人类记忆的层次性。
- **双过程分离**：System 1在线低延迟写入，System 2离线深度处理，兼顾实时性与认知深度。
- **读取路径零LLM**：检索时不调用LLM，避免推理延迟与成本，适合部署。
- **可溯源**：所有抽象节点保留指向支持事实的证据链接，增强可解释性。
- **跨域冲突检测**：通过行为-语义双空间碰撞发现隐性模式，是重要的创新点。

## 8. 不足与局限

- **实验覆盖有限**：仅评估英文聊天助手场景，未测试跨语言、具身智能体、多用户或用户身份不确定等设置。
- **离线成本**：System 2的LLM调用次数随模式库规模增长，虽然论文指出实践范围可控，但理论上限可能较高；双空间碰撞扫描二次复杂度在领域数增多时成为瓶颈。
- **阈值手动调整**：碰撞阈值 θ_beh、θ_sem 通过 held-out 调优，非自动学习，可能基准敏感性高。
- **单领域用户获益有限**：如果用户历史集中在单一领域，跨域核心图式作用小。
- **自然语言节点**：图式、意图、核心图式以自然语言形式存储，继承LLM输出的冗长与不一致，无法进行代数操作（如偏好向量集合交）。
- **隐私与伦理风险**：系统可能推断用户未明确披露的认知模式，尤其在跨域综合后可能产生侵犯性推断。论文建议了用户审查与分层同意，但未在实验中验证。
- **未提供算力消耗**：缺失GPU型号、训练时长等细节，不利于可重复性分析。
