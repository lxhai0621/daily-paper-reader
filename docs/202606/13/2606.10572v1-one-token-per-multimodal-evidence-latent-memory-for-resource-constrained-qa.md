## 摘要
外部记忆有效地将基于大型语言模型（LLM）和视觉语言模型（VLM）的问答（QA）与相关的多模态证据结合起来。然而，现有的记忆范式以原始文本和图像形式表示每个记忆项，因此基于检索的系统必须将检索到的文本或图像传递给生成LLM/VLM，导致高额的标记消耗和存储压力，使得资源受限的应用难以承受。我们提出潜在记忆（Latent Memory），这是一种潜在空间记忆范式，它用一个小型压缩器LLM/VLM生成的单个高维潜在标记取代每个原始文本或图像证据项。潜在记忆不是在生成时检索原始证据，而是在统一的潜在表示空间中操作：将查询嵌入到该空间中以检索相关的潜在标记，并将检索到的潜在标记直接提示给预训练的LLM或VLM以生成答案。为了使每个潜在标记同时具有信息性，可用于重建、检索和生成，我们以统一端到端的方式训练压缩器，采用重建、对比和蒸馏目标。潜在记忆在七个纯文本QA基准（如HotpotQA）和多模态QA基准上进行了评估，与先进的RAG基线相比，它实现了具有竞争力的QA性能，同时消耗的生成器标记减少了3到10倍。在WebQA上，它还能提供最强的图像基础QA性能。代码可在https://github.com/zz1358m/Latent-Memory-Master获取。

## Abstract
External memory effectively grounds large language models (LLMs) and vision-language models (VLMs)-based question answering (QA) in relevant multimodal evidence. However, existing memory paradigms represent each memory item in raw text and image forms, so retrieval-based systems must pass the retrieved text or images to the generation LLMs/VLMs, resulting in high token consumption and storage pressure, making it unaffordable for resource-constrained applications. We propose Latent Memory, a latent-space memory paradigm that replaces each raw text or image evidence item with a single high-dimensional latent token produced by a small compressor LLM/VLM. Rather than retrieving raw evidence for generation, Latent Memory operates in a unified latent representation space: the query is embedded into this space to retrieve relevant latent tokens, and the retrieved latent tokens are directly prompted to a pretrained LLM or VLM for answer generation. To make each latent token simultaneously informative for reconstruction, retrieval, and generation, we train the compressor with reconstruction, contrastive, and distillation objectives in a unified end-to-end manner. Latent Memory is evaluated on seven text-only QA benchmarks (e.g., HotpotQA) and multimodal QA benchmarks, where it achieves competitive QA performance compared to advanced RAG baselines while consuming 3x to 10x fewer generator tokens. It can also deliver the strongest image-grounded QA performance on WebQA. Code is available at https://github.com/zz1358m/Latent-Memory-Master.

### 论文提出的方法论

- **核心思想**：提出 Latent Memory，将每个多模态证据项（文本或图像）压缩成单个高维潜在 token，存储于“记忆库”中。在问答时，将查询也压缩为潜在表示，在统一潜在空间中检索最相关的潜在 token，然后直接将这些潜在 token 作为连续输入喂给冻结的生成器（LLM/VLM）进行答案生成，无需恢复原始证据。

- **关键技术细节**：
  1. **记忆压缩**：使用一个小型压缩器 LLM/VLM（如 LLaMA-3.2‑1B 或 LLaVA-7B）对每个证据项编码，取特殊标记 `[MEM]` 的最终隐藏状态作为潜在 token \( z_i \)。所有潜在 token 构成 Latent Memory \( M \)。
  2. **检索**：将潜在 token 通过 MLP 映射到低维检索空间（512维），查询也编码为同一空间的向量；通过内积相似度检索 top‑k 潜在 token。
  3. **条件生成**：检索到的潜在 token 经另一个 MLP 映射到生成器的隐藏维度，直接作为连续输入嵌入放入生成器 prompt 中。
  4. **训练目标**（联合优化）：
     - **重构损失** \( L_{\text{Recon}} \)：文本证据用自回归解码器重建原句子；图像证据用 MLP 重建 CLIP 图像嵌入（便于后续用扩散模型生成图像）。

     - **蒸馏损失** \( L_{\text{Distill}} \)：让基于潜在 token 的生成分布与基于原始证据的生成分布（教师）之间的 KL 散度最小化。

1. **效率‑性能平衡**：Latent Memory 在 **减少生成 token 3‑10 倍** 的同时，达到与先进 RAG 基线相当甚至更优的 QA 性能（尤其是图像问答）。

5. **泛化能力**：HotpotQA 训练的压缩器可直接迁移到多种域外文本和多模态任务，无需微调。

### 优点

1. **极高 token 效率**：显著降低生成器输入长度，尤其对于图像证据（从数百视觉 token 降至 1 个潜在 token）。
2. **存储压缩**：对图像证据，单潜在 token（4096 维 bf16）比原始图像文件小 26 倍以上（如 WebQA） 。
3. **统一表示**：潜在 token 同时用于检索和生成，避免分离优化带来的不一致。
4. **生成器无关**：生成器保持冻结，无灾难遗忘风险，且可迁移到同类生成器。
5. **可解释性**：通过重构损失部分恢复原始证据（文本或图像标题），提供可读性。

### 不足与局限

1. **证据独立性假设**：假设每个证据可独立压缩为孤立 token，无法处理依赖全局结构的信息（如表格的行列关系、视频时序、文档布局）。论文指出这是未来方向。
2. **文本存储开销**：对于短文本片段，潜在 token 的存储（4KB）反而比原始文本（0.23KB）大；但其主要优势仍在生成 token 节省和图像压缩。
3. **训练依赖正例证据**：对比学习需标注哪些证据支持问题，尽管训练时不需答案标签，但仍需检索正例标注。
4. **实验范围**：当前仅聚焦于外部证据驱动的 QA，未涉及代理记忆（agentic memory）或对话历史等自生成记忆。
5. **模态限制**：仅支持文本和图片，不支持表格、视频、音频等复杂模态。
6. **推理额外开销**：压缩器需额外前向编码查询，但论文通过时间复杂性分析说明仍比全上下文或 RAG 更快（尤其在大量证据时）。
