## 摘要
检索增强生成在扩展到大规模、异构文档集合时会退化，此时密集相似度失去区分能力，top-k检索越来越多地返回语义相似但上下文不正确的片段。我们将这种失败模式称为向量搜索稀释。即使使用混合密集+稀疏检索，我们在已部署的怀俄明州交通部语料库中直接观察到这一点：从54个文档扩展到1,128个文档（88,907个片段）时，准确率从75%降至40%以下。为了解决这种稀释，我们提出了MASDR-RAG（用于RAG的多智能体限定领域检索），并在200个经过专家验证的查询上进行了评估，涵盖五个LLM骨干网络、六个语料库和两个索引栈。我们的结果表明，使用组织元数据进行领域限定是关键修复方法，显著将P@10从0.77提高到0.86（p < 0.05）。此外，我们对多智能体编排的研究揭示出高度配置依赖性——产生了我们所谓的精度-忠实度悖论。基于这些不同的结果，我们的实际建议很简单：先限定范围，然后执行一次综合调用，将完整的多智能体编排保留给真正多领域的语料库，并与原生工具调用的骨干网络配对。代码和数据将在接收后公开。

## Abstract
Retrieval-augmented generation degrades when scaled to large, heterogeneous document collections, where dense similarity loses discriminative power, and top-k retrieval increasingly returns semantically similar but contextually incorrect chunks. We refer to this failure mode as vector search dilution. Even when using hybrid dense+sparse retrieval, we observed this firsthand in a deployed Wyoming Department of Transportation corpus, where scaling from 54 to 1,128 documents (88,907 chunks) reduced accuracy from 75% to below 40%. To address this dilution, we propose MASDR-RAG ( Multi-Agent Scoped Domain Retrieval for RAG) and evaluate it on 200 expert-validated queries across five LLM backbones, six corpora, and two index stacks. Our results indicate that domain scoping using organizational metadata is the key fix, significantly improving P@10 from 0.77 to 0.86 ($p < 0.05$). Furthermore, our investigation of multi-agent orchestration revealed that a high degree of configuration dependence results --creating what we call the precision-faithfulness paradox. Based on these varied outcomes, our practical recommendation is simple: scope first, then perform a single synthesis call, reserving full multi-agent orchestration for genuinely multi-domain corpora paired with native-tool-call backbones. Code and Data will be made public upon acceptance.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：利用**组织元数据**对检索空间进行领域限定，将搜索限制在文档图中的预定义元数据过滤器中（如 `source_type`、`document_series`、`article category`），从而将有效搜索空间减少 85–98%。
- **关键技术细节**：
  - **向量搜索稀释的形式化定义**：
    \[
    \delta(q, k^\star) = 1 - \frac{P_{\text{global}}(q)}{P_{\text{scoped}}(q)}
    \]
    其中 \( P_{\text{global}} \) 是在全局检索下目标类别块在 top-m 中的比例，\( P_{\text{scoped}} \) 是在限定类别内检索的比例（≈1）。\( \delta = 0 \) 表示无稀释，\( \delta \to 1 \) 表示严重稀释。
  - **架构 MASDR-RAG**：包含三个组件：
    1. 领域限定检索代理：每个代理通过 Neo4j 元数据过滤只搜索对应 `document_series` 的块。
    2. 混合路由（Hybrid Router）：先用快速正则表达式匹配，若不成功则使用零样本 LLM 分类器。
    3. 多智能体编排：通过函数调用分派给九个领域代理，最多进行 5 轮工具调用。
  - **轻量变体 HYBRID-ROUTED**：仅使用一次路由 LLM 调用 + 一次综合调用，最多两次 LLM 调用。
- **算法流程**（文字说明）：
  1. 用户查询输入 → `Hybrid Router`（正则 → LLM 分类器）确定目标领域。
  2. 分派到对应领域代理，每个代理在 Neo4j 图中执行 `document_series` 过滤后的近似最近邻搜索（ANN）和 BM25 全文搜索，合并结果（向量优先）。
  3. 合成器 LLM（Qwen-7B / Llama-8B / Gemini）基于 top-k 片段生成最终答案。
  4. 多智能体变体可在多个代理间迭代至多 5 轮；HYBRID-ROUTED 仅单轮路由 + 单轮合成。

## 6. 论文的主要结论与发现
1. **向量搜索稀释确实存在**：在小类别中更严重（如 Design Manual δ=0.53），与大类别的块数对数负相关（Spearman ρ=-0.60，p=0.12，在复现中更强）。
2. **领域限定是提升检索精度的核心手段**：将 P@10 从 0.77 提升至 0.86（p<0.05），且效果跨骨干、跨索引一致。
3. **多智能体编排导致精度-忠实度悖论**：MASDR-RAG 提升了检索精度但降低了 Faithfulness（在 Gemini 栈上从 0.61 降至 0.35，p<0.01），该悖论仅在商业骨干（Claude、GPT-5-mini、Gemini）上出现，在开源骨干（Qwen、DeepSeek）上消失。
4. **悖论根源不是路由噪声、重排序、检索器类型或索引实现**，而是由于上下文碎片化——多轮合成时来自多个片段的密集、准重复段落使合成器难以正确整合。
5. **HYBRID-ROUTED 解决了悖论**：在保持 P@10 提升的同时，Faithfulness 无显著下降，且成本远低于多智能体（在 Llama-8B 上减少 5.9 倍 token，2.2 倍延迟）。
6. **推荐原则**：先限定领域，再单次综合；只有在真正多领域语料库且使用原生工具调用骨干（如 Qwen、DeepSeek）时才采用多智能体编排。

## 8. 不足与局限
- **LLM 裁判偏差**：RAGAS 风格指标假设单一上下文窗口，可能不公平地惩罚多智能体输出。作者承认这导致 MASDR-RAG 的 Faithfulness 下降被称为“上界”，但方向性趋势仍稳健。
- **骨干规模限制**：开源实验仅限 7B–8B 模型，缺乏 ≥70B 参数的验证，因此无法判断悖论在更大模型上的表现。
- **元数据依赖**：路由范围需要手工定义的 `document_series` 或 `section` 元数据，若语料库缺乏此类组织信息则方法不可直接适用。
- **统计显著性：** 原始 WYDOT 的稀释 Spearman 相关系数 p=0.12（n=8 类别）未达显著阈值，虽然跨 DOT 复制中达到显著（ρ=-0.68 到 -0.95），但原文分析中对此有透明说明。
- **未讨论数据偏见**：未分析 WYDOT 语料库可能存在的领域分布偏差（如 Crash 报告占比 34.8% 但文档仅 1.9%）。
- **仅覆盖单一知识图谱设置**：未在非图结构（如纯向量数据库）上验证，虽然 FAISS 替代实验支持索引无关性。
