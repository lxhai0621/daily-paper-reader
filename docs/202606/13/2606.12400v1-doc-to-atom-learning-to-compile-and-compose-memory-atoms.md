## 摘要
长输入序列是大语言模型在文档理解和多步推理中的核心，然而注意力的二次方成本使得推理既内存密集又缓慢。上下文蒸馏通过将上下文信息压缩到模型参数中缓解了这一问题，最近的工作如Doc-to-LoRA将上下文蒸馏摊销为一次前向传播，为每个文档生成一个LoRA适配器。然而，为所有查询生成单个整体适配器会导致无关查询干扰、有限的组合性召回以及对长文档推理的可扩展性差。为了解决这些挑战，我们提出了Doc-to-Atom（Doc2Atom），一种组合式参数记忆框架，将每个文档分解为语义类型化的知识原子。每个原子被编译为一个独立的微LoRA适配器和一个来源检索键。在推理时，一个轻量级查询路由器选择并组装仅相关的原子到一个查询特定的适配器中，然后注入到冻结的基础模型中。整个系统通过一个多目标蒸馏框架进行端到端训练。在六个不同的问答基准上的实验表明，Doc2Atom优于Doc-to-LoRA基线，同时降低了文档内部化的内存成本。

## Abstract
Long input sequences are central to document understanding and multi-step reasoning in Large Language Models, yet the quadratic cost of attention makes inference both memory-intensive and slow. Context distillation mitigates this by compressing contextual information into model parameters, and recent work such as Doc-to-LoRA amortizes context distillation into a single forward pass that generates one LoRA adapter per document. However, producing a single monolithic adapter for all queries leads to irrelevant-query interference, limited compositional recall, and poor scalability to long-document reasoning. To address these challenges, we propose Doc-to-Atom (Doc2Atom), a compositional parametric memory framework that decomposes each document into semantically typed knowledge atoms. Each atom is compiled into an independent micro-LoRA adapter and a provenance retrieval key. At inference time, a lightweight query router selects and assembles only the relevant atoms into a query-specific adapter, which is then injected into a frozen base model. The entire system is trained end-to-end through a multi-objective distillation framework. Experiments on six diverse QA benchmarks demonstrate that Doc2Atom outperforms Doc-to-LoRA baselines while reducing the memory cost of document internalization.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：大语言模型在处理长输入序列时，注意力机制的二次方复杂度导致推理变得内存密集且缓慢。
- **现有方法局限**：上下文蒸馏将信息压缩到模型参数中，但 Doc-to-LoRA 等方法为每个文档生成一个整体的 LoRA 适配器，对所有查询统一应用，导致三个问题：(1) **无关查询干扰** —— 即使查询与文档无关，适配器仍会修改模型隐藏状态；(2) **组合召回有限** —— 固定秩的适配器无法针对不同查询选择性呈现证据；(3) **长文档可扩展性差** —— 相同参数预算需压缩越来越多内容。
- **论文目标**：提出 Doc-to-Atom (Doc2Atom)，将文档分解为语义类型化的知识原子，每个原子独立编译，查询时仅组装相关原子，实现选择性、可组合的参数记忆。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将文档分解为**最小、自包含的知识原子**（知识单元），每个原子带有语义类型（事实声明、实体属性、事件关系、过程步骤、证据片段）。
- 每个原子独立编译为：
  - 一个**微 LoRA 适配器**（低秩因子 A/B）
  - 一个**溯源检索键**
  - 可选的**紧凑 KV 原型**和**稀疏掩码**
- 推理时，**两阶段路由器**根据查询选择最相关的 K 个原子，通过路由权重加权求和组装成查询特定的复合 LoRA 适配器，注入冻结基模型的最后几层。

### 2.2 关键技术细节
- **数据原子化管道**：使用 LLM（MiniMax-M2.5）对文档进行原子分解，并为每个原子生成丰富元数据（内容、源跨度、检索文本、置信度、冲突组、关系等）。同时生成无关探针问题，用于训练路由器拒绝无关查询。
- **共享文本编码器**：重用冻结基模型的前 L_enc=4 层，对原子和查询进行编码，通过投影头得到 d=256 维嵌入，避免额外编码模型参数。
- **原子级记忆编译器**：输入原子嵌入，通过共享躯干 MLP 和四个并行头输出：
  - 溯源键头 → 检索锚向量 k_i ∈ R^dk
  - 微 LoRA 头 → 每个目标模块 m 和记忆层 ℓ 的 A(ℓ)_m,i ∈ R^{r×d_in} 和 B(ℓ)_m,i ∈ R^{d_out×r}，B 初始化为零
  - 微 KV 头 → 可选的紧凑键值原型
  - 稀疏掩码头 → 控制每个原子写入哪些层-模块组合的门控信号
- **两阶段路由器**：
  - 第一阶段：查询嵌入与所有原子的溯源键进行余弦最大内积搜索，召回 top-32。
  - 第二阶段：用冻结的交叉编码器对候选者进行重新排序，加入元数据偏置（原子置信度、是否可回答、冲突组、语义类型）。
  - 最终选择 top-K 原子（课程学习逐步增加 K），其分数经 softmax 归一化为稀疏路由权重 w_i。
- **记忆合成器与注入**：按层和模块，通过路由权重加权求和组合微 LoRA 因子 A_c = Σ w_i A_i, B_c = Σ w_i B_i，再乘以聚合后的稀疏门控。微 KV 按路由权重缩放后沿序列维度拼接为紧凑前缀。所有写入限制在最后 nL=4 个解码器层。
- **多目标训练框架**（教师-学生范式）：
  - **教师**：冻结基模型接收完整文档+查询，产生全上下文参考 logits。
  - **学生**：冻结基模型仅接收查询，注入组装后的 LoRA，产生 logits。
  - 总损失 L_total 包含：
    - 语言模型交叉熵 L_LM + 温度缩放的 KL 散度 L_distill
    - 路由监督：加权二值交叉熵 L_route（对干扰原子惩罚加重）
    - 无关查询抑制：对无关查询的组合 LoRA 因子施加 L2 范数惩罚 L_irrel
    - 知识保护：对组合 delta 施加 L2 约束或零空间投影 L_protect
    - 稀疏正则化：推动门控激活率接近目标密度 ρ
    - 组合一致性：强制多原子组合的 student logits 与强制使用 gold 原子的 forced logits 之间的对称 KL 散度
    - 额外：冲突组内 listwise 交叉熵 L_conflict、置信度对齐 L_confidence
  - 训练采用**四阶段课程学习**：逐步增加 top-K（1→4→8），逐步激活损失函数，最后阶段加强稀疏正则化。

## 6. 主要结论与发现

1. **Doc2Atom 在总体准确率上优于所有 D2L 基线**：在 Gemma-2-2B-It 上总体 F1 37.99 vs D2L atom 29.41 (提升 8.58)，在 Qwen3-4B 上 35.72 vs 29.30 (提升 6.42)。零样本 LongBench 上提升尤为显著（最高 6× F1）。
2. **原子化本身对 D2L 有益**：训练 D2L 在原子化文档上（D2L atom）比原始文档（D2L raw）总体提升 +0.86 (Gemma) 和 +0.45 (Qwen3)。
3. **无关查询拒绝大幅改善**：Doc2Atom 在大多数数据集上拒绝 F1 > 85%，而 D2L 基线普遍低于 40%，表明路由器学会了抑制无关查询。
4. **内存效率显著提升**：额外 GPU 内存降低 44% (Gemma) 至 85% (Qwen3)，因为 top-K 原子预算限制了激活存储。
5. **原子记忆与上下文访问互补**：在已有上下文中添加原子记忆仍能提升总体 F1 (+2.26，Table 5)，说明原子结构提供了额外信号。
6. **与 ICL 仍有差距**：虽然 Doc2Atom 缩小了差距，但总体 F1 仍低于 Base+ctx 约 10-16 个点，留待未来改进。

## 7. 优点

- **创新性**：首次提出将文档分解为可组合的原子级参数记忆，替代整体适配器，实现了细粒度的选择性检索和动态组装。
- **全面性**：多目标训练框架系统性地覆盖了语言建模、路由、拒答、知识保护、稀疏性、组合一致性等多个维度。
- **高效性**：通过原子分解和路由，推理时只需处理少量原子，大幅降低内存占用；离线编译步骤的额外延迟可接受。
- **鲁棒性**：对无关查询的拒绝能力远超基线，且泛化到未见过的 LongBench 子集。
- **可解释性**：原子带有语义类型、元数据和溯源跨度，提供了更透明的人机交互基础。
- **公平对比**：设计了 D2L atom 基线以隔离原子化影响，实验设置详细且公开超参数。

## 8. 不足与局限

- **固定语义分类**：使用预定义的 5 种原子类型和分解策略，对于不同任务/领域可能不灵活，需要更自适应的原子粒度。
- **模型规模限制**：实验限于 2B 和 4B 基模型，未扩展到更大模型（如 7B、70B 或更大），结论的泛化性需验证。
- **与 ICL 的差距**：虽然优于 Doc-to-LoRA，但离全上下文 ICL 仍有显著差距（约 10-16 F1 点），距离实用化还有距离。
- **更新延迟略高**：每次编译/内化步骤比 D2L 慢 3-7 倍（Gemma 0.31s→2.10s，Qwen3 0.51s→1.10s），尽管离线场景可接受，但高频更新时可能成瓶颈。
- **微 KV 能力未深入探索**：方法中提及可选的微 KV 原型，但实验中未单独消融其贡献，也未与其他前缀调优方法比较。
- **课程学习未消融**：四阶段课程设计的必要性未被实验验证，可能过度复杂。
- **冲突处理不足**：虽然定义了冲突组和相应损失，但实际示例中冲突组为空，冲突检测的有效性未充分展示。
- **数据标注依赖强**：离线原子分解和问题-原子标注依赖 LLM（MiniMax-M2.5），标注质量和一致性未深入分析，可能引入偏差。
- **单次文档内化**：每个文档独立编译，缺乏跨文档知识整合或持续学习能力。
