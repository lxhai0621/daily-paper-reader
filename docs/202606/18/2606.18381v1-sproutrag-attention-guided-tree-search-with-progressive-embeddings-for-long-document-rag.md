## 摘要
检索增强生成（RAG）系统需要在检索粒度与上下文连贯性之间取得平衡，现有方法通过LLM引导的分块、单级上下文扩展或层次化摘要来解决这一挑战。这些方法在不同程度上依赖于索引或检索过程中昂贵的LLM调用，将上下文聚合限制在单一粒度级别，或通过摘要引入信息损失。我们提出SproutRAG，一种注意力引导的层次化RAG框架，通过将句子级块组织成逐步增大但语义连贯的单元，利用学习到的句子间注意力构建二分块树，从而解决了这一权衡。与依赖外部LLM、固定上下文扩展或有损摘要的先前方法不同，SproutRAG学习哪些注意力头和层最能捕捉语义文档结构，实现了无需额外LLM调用或压缩摘要的多粒度检索。在检索时，SproutRAG使用层次化束搜索在多个粒度上检索候选，捕获超出平面检索的多句相关性。该框架通过联合目标进行端到端训练，同时改进嵌入和树结构。在涵盖科学、法律和开放领域的四个基准上的实验表明，SproutRAG相比最强基线平均提高了6.1%的信息效率（IE）。代码可在https://github.com/AmirAbaskohi/SproutRAG获取。

## Abstract
Retrieval-augmented generation (RAG) systems must balance retrieval granularity with contextual coherence, a challenge that existing methods address through LLM-guided chunking, single-level context expansion, or hierarchical summarization. These approaches variously depend on costly LLM calls during indexing or retrieval, limit context aggregation to a single granularity level, or introduce information loss through summarization. We present SproutRAG, an attention-guided hierarchical RAG framework that addresses this trade-off by organizing sentence-level chunks into progressively larger but semantically coherent units, using learned inter-sentence attention to construct a binary chunking tree. Unlike prior approaches that rely on external LLMs, fixed context expansion, or lossy summarization, SproutRAG learns which attention heads and layers best capture semantic document structure, enabling multi-granularity retrieval without additional LLM calls or compressed summaries. At retrieval time, SproutRAG uses hierarchical beam search to retrieve candidates at multiple granularities, capturing multi-sentence relevance beyond flat retrieval. The framework is trained end-to-end with a joint objective that improves both embeddings and tree structure. Experiments across four benchmarks spanning scientific, legal, and open-domain settings demonstrate that SproutRAG improves information efficiency (IE) by 6.1% on average over the strongest baseline. Code is available on https://github.com/AmirAbaskohi/SproutRAG.

- **现有方法的不足**：
  - 基于LLM的分块（Meta-Chunking, MoC）丢弃跨块依赖；

- **整体含义**：需要一种无需推理时LLM调用、不依赖有损摘要、能自然支持多粒度检索的文档结构学习框架。SproutRAG通过学习句子间注意力构建二分块树，实现高效、无LLM的层次化检索。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 使用小语言模型（SLLM）编码文档，获取句子嵌入和跨句注意力。
- **学习**哪些注意力头和层最能反映语义相关性，以加权聚合替代均匀平均（避免邻近偏差）。
- 自底向上构建**注意力引导的二分树**：叶子为句子，内部节点为语义相关的句子组，嵌入为子节点平均（渐进式嵌入）。
- 检索时使用**层次化束搜索**，从根开始扩展，保留top-b节点，收集所有访问节点中相似度超过阈值的候选（多粒度）。
- 联合训练：对比学习优化嵌入（检索损失）+ 注意力正则化（结构损失），确保树结构利于检索。

### 关键技术细节

- **注意力加权聚合**：
  ```
  A_ij = Σ_l Σ_h w_l,h * Attn(l,h)_ij
  w_l,h = exp(α_l,h) / Σ exp
  ```
  其中α_l,h为可学习标量，随机初始化，与SLLM共同微调。

- **对称化与树构建**：
  - 对称化：`M_ij = (A_ij + A_ji)/2`
  - 每一步合并`M`值最大的两个节点，父节点嵌入为子节点平均。
  - 单链接更新：父节点到其他节点的`M`值取子节点中最大值（保持长程语义）。

- **层次化束搜索**：
  - 从根开始，每步扩展当前束中节点的所有子节点，保留top-b最相似的。
  - 相似度：`cosine(e_q, e_v)`。
  - 候选集：所有访问节点中得分≥阈值δ的节点（包括叶子、内部节点、子树）。
  - 最后用重排序器选择top-k。

- **联合训练目标**：
  - `L_ret`：对比学习（query vs 正负passage，每passage由句子嵌入均值池化）。
  - `L_attn`：对正passage中共同支持查询的句子对，鼓励其对称注意力高（最大化log M_ij）。
  - 总损失：`L = L_ret + λ L_attn`，λ=0.1。

## 6. 论文的主要结论与发现

- **检索性能**：SproutRAG在所有四个基准上获得最高信息效率（IE），平均领先最强基线6.1%，同时保持最高精度。
- **端到端生成**：相比GraphRAG、ReflectiveRAG、REFRAG，SproutRAG在F1、ROUGE-L、METEOR、BERTScore上均更优；性能接近PageIndex，但在线token使用量（4.38K/query）和延迟（193ms）远低于PageIndex（24.6K Tok/Q, 2847ms）。
- **消融分析**：
  - 未训练版本性能最差，证明微调必要性。
  - 移除检索损失（`L_ret`）或注意力正则化（`L_attn`）均导致下降，两者互补。
  - 均匀注意力聚合、嵌入相似度树、仅叶子检索、贪心搜索均不如完整设计。
  - 默认beam width=5和λ=0.1最佳，超参数较稳定。
- **核心发现**：学习注意力聚合可消除邻近偏差；层次化检索（内部节点）能恢复跨句连贯信息，这是平面或成对方法做不到的。

## 7. 优点

- **无需推理时LLM调用**：索引时学到的注意力权重直接用于树构建和检索，检索只需SLLM编码查询和简单余弦相似度+束搜索，非常高效。
- **学习注意力聚合**：自动发现对文档结构最有用的头和层，避免手工设计或均匀平均的邻近偏差。
- **多粒度检索**：叶子保精度，内部节点保连贯性，束搜索自动平衡两者。
- **联合训练**：同时优化嵌入质量和树结构，端到端可微。
- **跨数据集迁移**：一次训练即可用于不同领域，无需重复微调。
- **效率优越**：在线token使用和延迟远低于LLM-heavy方法，同时性能接近。

## 8. 不足与局限

- **二叉树结构限制**：可能无法自然建模多个句子同时构成一个语义单元的情况；未来可扩展为多分支树。
- **需要一次性训练**：虽然跨数据集重用，但仍比零训练基线（如直接使用预训练SLLM）昂贵。
- **树固定不变**：检索时结构静态，无法根据查询动态重组；复杂多跳查询可能需要自适应遍历策略。
- **未探索更复杂的节点表示**：目前仅用平均池化，门控或注意力机制可能更好。
- **实验覆盖**：虽然数据集多样，但未在极长文档（如整本书）上测试；基准均为英文或中文但混合领域，未覆盖其他语言。
- **偏差风险**：训练数据来自CLaRa，可能影响在完全不同分布（如法律特定领域）上的泛化，但实验显示在LegalBench-RAG上仍表现良好。
