## 摘要
检索增强生成（RAG）已成为利用外部知识增强大语言模型（LLMs）的一种范式，然而现有的基于图的方法面临一个根本性局限：以实体为中心和以片段为中心的方法都基于锚定在原文本上的表征进行操作，缺乏真正的知识融合。虽然以实体为中心的方法连接逻辑相关的内容，以片段为中心的方法保留上下文，但两者都通过相似性搜索分别检索信息，从而丢失了从两者综合中产生的涌现理解。在本文中，我们提出HyGRAG，一种分层图RAG框架，通过解决三个核心挑战超越源文档：构建真正整合上下文和关系信息的摘要，利用这些综合表征在检索中获取涌现知识，以及高效更新动态语料库的分层结构。具体而言，我们在同时包含片段节点和实体节点的混合图上设计分层索引结构，然后迭代聚类并生成基于LLM的摘要。接着，我们设计上下文和关系感知的检索，该检索在所有抽象级别上进行搜索，同时通过社区成员关系进行扩展。此外，我们通过基于附加的算法实现动态知识更新，仅需局部重新摘要。实验结果表明，HyGRAG将多跳推理任务的平均准确率提高了9.7%，同时保持了合理的效率。

## Abstract
Retrieval-Augmented Generation (RAG) has emerged as a paradigm for enhancing large language models (LLMs) with external knowledge, yet existing graph-based methods face a fundamental limitation: entity-centric and chunk-centric approaches operate on representations anchored to original text without true knowledge fusion. While entity-centric methods connect logically related content and chunk-centric methods preserve context, both retrieve information separately through similarity search, missing emergent understanding from their synthesis. In this paper, we propose HyGRAG, a hierarchical graph RAG framework that transcends source documents by addressing three core challenges: constructing summaries that genuinely integrate contextual and relational information, leveraging these synthesized representations to access emergent knowledge during retrieval, and efficiently updating hierarchical structures for dynamic corpora. Specifically, we design hierarchical index structures over hybrid graphs with both chunk and entity nodes, then iteratively cluster them and generate LLM-based summaries. Then, we design context and relation-aware retrieval that searches across all abstraction levels while expanding through community membership. Moreover, we enable dynamic knowledge update through attachment-based algorithms with only local re-summarization. Experimental results show that HyGRAG improves the average accuracy of multi-hop reasoning tasks by 9.7%, while maintaining reasonable efficiency.

#### 1. 核心问题与整体含义（研究动机和背景）
- **背景**：检索增强生成（RAG）通过外部知识增强大语言模型（LLMs），而图RAG方法进一步利用图结构改善检索与推理。现有方法分为两类：
  - **实体中心方法**（如GraphRAG、HippoRAG）：提取实体和关系构建知识图谱，擅长多跳推理，但丢失原文上下文，在事实性问答上甚至不如简单稠密检索。
  - **块中心方法**（如RAPTOR、EraRAG）：保持文本块的上下文信息，通过聚类生成层级摘要，但无法捕获跨块间的显式关系，缺乏逻辑推理能力。
- **根本问题**：两类方法都仅锚定于原始文本的单一表征，缺乏对上下文与关系信息的真正融合。检索时分别通过相似性搜索获得各自结果，无法产生综合两者的**涌现理解**（emergent understanding）。
- **本文目标**：提出**HyGRAG**（Hierarchical Graph RAG），统一上下文与关系感知，构建超越原始文档的融合知识表征，并支持动态更新。

#### 2. 方法论
- **核心思想**：构建包含**块节点**和**实体节点**的混合图，通过迭代聚类和LLM摘要生成层次化索引；设计**双重感知检索**（上下文感知 + 关系感知），使模型能同时利用微观细节和宏观社区知识；通过**附加算法**实现动态更新，仅局部重摘要。
- **关键技术细节**（分四大模块）：
  1. **层次索引结构构建**
     - 文本分块（每块1200 token，重叠100 token），基于共享实体数（阈值>3）构建块-块边。
     - 用LLM提取知识图谱三元组，形成实体-实体边。
     - 通过实体-块隶属关系连接两类节点，得到混合图 \(G_{hybrid}\)。
     - 用Cleora生成结构感知嵌入，再通过超平面LSH聚类，控制社区大小（5~50），对每个社区用Llama3.1-8B-Instruct生成文本摘要，并用BGE-M3编码为向量。
     - 递归聚类到最大层数 \(L=4\)，形成层次树 \(T_{index} = \{L_0, L_1, \ldots, L_L\}\)。
  2. **上下文与关系感知检索**
     - **上下文感知**：从所有层级的社区、块、实体中分别检索 top-k 最相似节点。
     - **关系感知**：从检索到的社区中收集所有实体，加上上下文实体，提取与之相关的所有三元组，再按相关性过滤 top-k。
     - 最终输出四类信息：社区摘要、块文本、实体、关系三元组。
  3. **检索增强生成**
     - 将四类信息用结构化提示模板组织，输入LLM生成答案；可选推理增强（+Inference）。
  4. **动态知识更新**
     - 新文档分块并提取三元组，生成摘要嵌入，从底层向上搜索最相似社区，相似度>阈值 \(\tau_{attach}=0.65\) 则附加，否则升至上层。
     - 附加后仅更新该路径上所有祖先社区的摘要，无需全量重构。
- **算法流程**（文字说明）：
  - 离线索引：文档分块 → 构建混合图 → Cleora嵌入 → LSH聚类 → LLM生成社区摘要 → 递归至顶层。
  - 在线检索：查询编码 → 上下文感知检索（社区/块/实体） → 关系感知检索（扩展实体+过滤三元组） → 组合 → LLM生成。
  - 动态更新：新文档分段 → 提取三元组 → 生成摘要 → 附加到最相似社区 → 局部更新祖先摘要。
