## 摘要
多模态大语言模型（MLLMs）在许多视觉任务中展现出令人印象深刻的能力，但在面对复杂、开放世界场景时，往往难以实现事实性 grounding。尽管最近的多模态深度搜索智能体试图通过利用外部工具来解决这一问题，但视觉原生搜索范式仍未得到充分探索。现有方法主要依赖具有显式语义的简单图像和纯文本证据轨迹，限制了智能体执行多跳、跨模态推理和搜索的能力。为解决这些局限性，我们提出了 Visual-Seeker，一种通过主动视觉推理实现的视觉原生多模态深度搜索智能体。我们的智能体不将视觉视为静态输入，而是主动关注细粒度视觉细节，在搜索过程中动态收集视觉证据。为释放其视觉原生潜力，我们设计了一条主动视觉推理数据流水线，并合成了 5K 条高质量多模态轨迹用于模型训练。大量实验表明，我们在五个具有挑战性的多模态搜索基准上达到了最先进的性能，甚至超过了几个专有模型，验证了在真实网络环境中鲁棒的视觉原生推理和搜索能力。代码和数据可在 https://github.com/ZhengboZhang/Visual-Seeker 获取。

## Abstract
Multimodal large language models (MLLMs) have demonstrated impressive capabilities in many visual tasks, but they often struggle with factual grounding when confronted with complex, open-world scenarios. While recent multimodal deep search agents attempt to address this issue by utilizing external tools, the visual-native search paradigm remains underexplored. Existing methods primarily rely on simple images with explicit semantics and text-only evidence trajectories, limiting the agent's ability to perform multi-hop, cross-modal reasoning and search. To address these limitations, we propose Visual-Seeker, a visual-native multimodal deep search agent via active visual reasoning. Rather than treating vision as a static input, our agent actively attends to fine-grained visual details, dynamically harvests visual evidence throughout the search process. To unlock its visual-native potential, we design an active visual reasoning data pipeline and synthesize 5K high-quality multimodal trajectories for model training. Extensive experiments demonstrate the state-of-the-art performance across five challenging multimodal search benchmarks, even surpassing several proprietary models, validating robust visual-native reasoning and search in real-world web environments. The code and data can be accessed at: https://github.com/ZhengboZhang/Visual-Seeker.

## 2. 论文提出的方法论

### 核心思想
- 将视觉从“静态输入”转变为搜索过程中**主动收集证据**的核心模态；模型能够对复杂多实体图像进行细粒度感知，并在多跳搜索中主动调用视觉工具（如裁剪、图像搜索）收集和整合视觉证据。

### 关键技术细节
1. **Active Visual Reasoning 数据合成管道**（三阶段）：
   - **阶段一：细粒度种子实体选择**
     - 从 LiveVQA 数据集中提取多实体图像的视觉推理过程，用 MLLM 进行联合实体提取，输出结构化实体 `E_i = (name_i, description_i, type_i)`。
     - 三步过滤：
       1. 通用提及过滤（剔除无特定标识的名词短语）。
       2. 复杂实体-图像过滤（剔除实体语义易得的图像）。
       3. 实体消歧（利用 Wikipedia 消歧页面处理多义词）。
     - 获得约 2K 种子实体。
   - **阶段二：多跳轨迹合成**
     - 在离线 Wikipedia 知识图 G = (V, E) 上从种子节点开始随机游走。
     - 两种扩展策略生成非线性子图：
       - **回溯**：以概率 p_back 跳回历史访问节点，形成树状结构。
       - **循环约束**：从共享前缀的岔路节点分支出两条不相交路径，再汇聚，形成循环拓扑。
     - 基于子图实体关系，用 LLM 生成多跳文本问题。
   - **阶段三：视觉证据注入**
     - 针对每个 VQA 实例，用 LLM 生成搜索关键词，通过搜索引擎检索包含丰富视觉信息的候选图像。
     - 用 MLLM 提取图像中**无法从文本获得**的细粒度属性（如颜色、空间布局）。
     - 将模糊关键词作为问题、视觉属性作为答案合成两跳 QA，合并到原始 VQA 中，迫使模型在搜索中调用 `search_image` 工具并进行像素级推理。

2. **Visual-Seeker 智能体架构与训练**
   - **工具集**（5 个外部工具）：
     - `text_search`（SerperAPI 文本搜索）
     - `reverse_image_search`（反向图像搜索）
     - `search_image`（文本到图像检索，主动收集视觉证据）
     - `visit`（JinaAPI 捕获网页并使用 Qwen3-30B-A3B-Instruct 总结）
     - `image_crop`（按坐标裁剪图像，用于细粒度视觉推理）
   - **工作流**：ReAct 风格循环，每轮输出思考 + 工具调用参数，最多 15 轮。
   - **监督微调（SFT）**：
