## 摘要
多模态文档检索——从大规模语料库中选择最相关的多模态文档以回答自然语言查询——在检索增强生成（RAG）系统中发挥着至关重要的作用。现有最先进的方法使用多个token级嵌入来表示每个文档和查询，并通过晚期交互实现高效性。然而，这种多向量表示在检索过程中会带来大量内存开销，导致可扩展性差，阻碍实际部署。本文提出Stellar，一种可扩展的多模态文档检索框架，它将token级文档嵌入存储在磁盘上，仅将少量候选嵌入加载到内存中进行晚期交互。Stellar包含两个关键组件：(i) 基于词汇表示的过滤（LRF），通过微调多模态大语言模型（MLLM）作为稀疏编码器，生成高质量词汇表示，实现高效且有效的文档过滤，大幅缩小候选集；(ii) 高效的磁盘支持晚期交互（DLI），设计了一种基于平衡聚类算法的磁盘上token嵌入存储布局，并利用简单而有效的成本模型动态地将必要的token嵌入加载到内存中。在四个真实世界基准和一个新提出的数据集上的大量实验表明，Stellar在保持检索效果的同时，将内存开销和查询延迟相比现有方法降低了1-2个数量级。

## Abstract
Multimodal document retrieval--selecting the most relevant multimodal document from a large corpus to answer a natural language query--plays an essential role in Retrieval-Augmented Generation (RAG) systems. State-of-the-art methods represent each document and query with multiple token-level embeddings and use late interaction to achieve high effectiveness. However, such multi-vector representations incur substantial memory overhead during retrieval, leading to poor scalability and hindering real-world deployment. In this paper, we present Stellar, a scalable multimodal document retrieval framework that stores token-level document embeddings on disk and loads only a small set of candidate embeddings into memory for late interaction. Stellar comprises two key components: (i) Lexical Representation-based Filtering (LRF), which fine-tunes a Multimodal Large Language Model (MLLM) as a sparse encoder to produce high-quality lexical representations, enabling efficient and effective document filtering to significantly reduce the candidate set; (ii) Efficient Disk-backed Late Interaction (DLI), which designs an on-disk token embedding storage layout guided by a balanced clustering algorithm, and dynamically loads only the necessary token embeddings into memory using a simple yet effective cost model. Extensive experiments on four real-world benchmarks and a newly presented large-scale dataset demonstrate that Stellar reduces memory overhead and query latency by 1-2 orders of magnitude compared to existing methods without compromising retrieval effectiveness.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 改变“压缩嵌入以适配内存”的范式，转而将原始token嵌入存储在廉价磁盘，仅选择性加载少量候选嵌入到内存进行晚期交互。
- 采用“先高效过滤 + 后磁盘加载”两阶段策略：第一阶段用稀疏词汇表示快速筛选候选集；第二阶段用成本感知策略从磁盘加载token嵌入完成精确评分。

### 关键技术细节

#### (a) 词汇表示过滤 (LRF)
- 设计基于MLLM的孪生双编码器，利用预训练MLLM的语言建模头作为共享投影层，将文档和查询映射到词汇空间（维度|V|）。
- 对每个token的词汇向量应用ReLU去除负值，然后跨token做最大池化，得到稀疏向量（维度|V|，平均仅~200个非零项，稀疏度99.87%）。
- 使用对比学习（InfoNCE loss）和FLOPs正则化损失微调MLLM（LoRA低秩适配），确保稀疏且区分性强。
- 离线构建倒排索引；在线查询时只扫描查询非零维度对应的倒排列表，快速筛选top-k1候选文档（k1=100）。

#### (b) 磁盘支持晚期交互 (DLI)
- **集群存储布局**：使用平衡聚类算法(BCA)将语义相似的文档（基于稀疏嵌入）分入同一集群，每个集群的token嵌入连续存储在单个磁盘块中。算法通过初始k-means、递归拆分、小集群重分配保证块大小均衡（期望大小sexp=50，最小smin=3）。
- **两级内存索引**：文档级索引（doc_id -> 块ID、偏移、长度）和块级索引（块ID -> 文档列表、总向量数），轻量级。
- **成本感知加载策略**：对每个命中块，根据顺序读速率Rseq和随机读速率Rrand，比较全块加载（FBL）和特定向量加载（SVL）的预估时间，选择较低者。
- **评分融合**：将第一阶段稀疏得分与晚期交互稠密得分用z-score归一化后加权融合（α=0.3最佳），利用互补信号提升准确性。

### 公式与算法流程（文字说明）
- 稀疏得分：`score_spa(q,d) = sum_{j in I_q∩I_d} z_j(q)·z_j(d)`
- 稠密得分：`score_mul(q,d) = sum_{i=1}^n max_{j=1}^m (e_qi·e_dj)` (L2归一化后内积)
- 融合得分：`score_fus = α·Z(score_spa) + Z(score_mul)`

## 6. 主要结论与发现

1. **有效性**：Stellar在R@1上优于所有基线（包括ColPali），在R@10和M@10上持平或略优，得益于稀疏-稠密评分融合。

3. **LRF有效性**：稀疏词汇过滤在召回率上与稠密过滤相当甚至更好，但内存和延迟低得多（稠密过滤本身成为瓶颈）。
4. **DLI设计必要**：平衡聚类和成本感知加载策略显著减少I/O延迟；评分融合提升1-2%的R@1。

## 7. 优点

- **创新性**：首次将“存储到磁盘+选择性加载”范式引入多模态文档检索，从根本上解决内存瓶颈，而非压缩折中。
- **设计巧妙**：利用MLLM的预测头作为词汇投影层，结合对比学习和FLOPs正则化，产生高稀疏度（99.87%）且语义丰富的表示；平衡聚类算法兼顾语义局部性和I/O性能。
- **工程实用**：提出简单有效的成本模型，动态选择加载策略，无需复杂预测。
- **实验全面**：涵盖多个规模基准，包含消融、可扩展性、参数敏感性等，且公开代码和新数据集LargeDoc，促进后续研究。
