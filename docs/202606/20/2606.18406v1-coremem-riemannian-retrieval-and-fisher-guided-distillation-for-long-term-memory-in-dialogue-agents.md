## 摘要
个性化对话智能体需要持续的长期记忆，以在多次会话中保持连贯的交互。然而，在消费级硬件（例如8 GB显存的边缘设备）上部署这些能力引入了严重的记忆和计算瓶颈。现有系统通常依赖各向同性余弦相似度进行检索，并采用启发式规则进行上下文压缩。这些方法缺乏统一的理论基础，经常在高维检索中遭遇中心点问题，并在压缩过程中出现语法碎片化。为克服这些限制，我们提出CoreMem，一种资源高效的边缘-云记忆架构，从根本上由信息几何统一。首先，黎曼检索用局部自适应的费舍尔-拉奥度量替代余弦匹配，通过马氏距离有效惩罚中心记忆，并采用O(Ndr) Woodbury加速实现实时搜索。其次，费舍尔引导的离散令牌蒸馏（FDTD）引入了分层句子到令牌压缩机制。它从费舍尔信息迹中推导敏感性分数，提供了一种原则性的压缩-KL权衡，并辅以显式结构语法保护。在LOCOMO和LongMemEval-S基准上的评估表明，CoreMem实现了显著的精度提升，在开放域（+4.51个百分点）和时间（+4.17个百分点）推理上取得了实质性增益。广泛的性能分析证实，CoreMem能在严格的8 GB显存预算内无缝运行，成功弥合了资源受限的边缘设备与对理论基础的终身记忆智能体需求之间的鸿沟。

## Abstract
Personalized dialogue agents require continuous long-term memory to maintain coherent interactions across multiple sessions. However, deploying these capabilities on consumer-grade hardware (e.g., 8 GB VRAM edge devices) introduces severe memory and compute bottlenecks. Existing systems typically rely on isotropic cosine similarity for retrieval and heuristic rules for context compression. These approaches lack a unified theoretical foundation, frequently suffering from the hubness problem in high-dimensional retrieval and syntactic fragmentation during compression. To overcome these limitations, we propose CoreMem, a resource-efficient edge-cloud memory architecture fundamentally unified by information geometry. First, Riemannian retrieval replaces cosine matching with a locally adaptive Fisher-Rao metric, effectively penalizing hub memories via Mahalanobis distance with O(Ndr) Woodbury acceleration for real-time search. Second, Fisher-guided discrete token distillation (FDTD) introduces a hierarchical sentence-to-token compression mechanism. It derives sensitivity scores from Fisher information traces, providing a principled compression-KL tradeoff augmented with explicit structural syntax protection. Evaluated on the LOCOMO and LongMemEval-S benchmarks, CoreMem achieves strong accuracy improvements, yielding substantial gains in Open-domain (+4.51 pp) and Temporal (+4.17 pp) reasoning. Extensive profiling confirms that CoreMem operates seamlessly within a strict 8 GB VRAM budget, successfully bridging the gap between resource-constrained edge devices and the demand for theoretically grounded, lifelong memory agents.

### 方法论：核心思想、关键技术细节

- **核心思想**：以信息几何统一记忆检索与压缩，将嵌入视为统计流形上的点，检索使用局部自适应Fisher-Rao度量（Mahalanobis距离），压缩使用Fisher信息迹衡量token敏感性。
- **Riemannian检索**：
  - 替代余弦相似度，采用马氏距离：`score = q^T Σ^{-1} h`，其中Σ是局部协方差矩阵。
  - 协方差建模为低秩加对角：`Σ ≈ U_r M_r U_r^T + D`，其中`D = diag(σ² + λ)`，λ动态设为`10·mean(σ²)`以控制条件数。
  - 使用Woodbury恒等式加速求逆：复杂度从O(d³)降至O(N d r)，实现实时搜索。
  - 引入残差融合：`score = α·norm(cos) + (1-α)·norm(rie)`，平衡余弦和Riemannian度量的互补优势（α=0.5）。
- **Fisher引导离散令牌蒸馏（FDTD）**：
  - 对每个token，计算其对loss的Fisher信息迹：`S(x_i) = ||∇h_i L ⊙ h_i||₂`。
  - 理论保证：若模型局部L-Lipschitz连续，则按Fisher迹升序丢弃token时，生成KL散度有界于`O(L² Σ_{dropped} S(x_i))`。
  - 分层句子级压缩：先分句，对长句子（>8 token）保留首尾各3个token保护句法骨架，中间按Fisher迹丢弃；再用语法/关键字/数字/句首等结构掩码加权；最后按句子平均分贪心选择直至预算B。
- **边缘-云混合架构**：边缘设备运行小编码器（gte-Qwen2-1.5B或MiniLM-L6）和本地SLM（Qwen3-0.6B等）执行检索与压缩，仅传输压缩后的token给云端LLM（GPT-4o-mini），降低API成本约20-30%。

### 主要结论与发现

- **核心结论**：CoreMem-Fusion（α=0.5）在LOCOMO上总体Judge准确率最高（MiniLM-L6下0.540），特别是在开放域（+4.51 pp）和时间推理（+4.17 pp）上显著优于所有基线；在LongMemEval-S上取得0.4624 Judge准确率，时间推理+2.25 pp。
- **检索与压缩互补性**：纯Riemannian在开放域和时间上更强，余弦在多跳上略优；融合均衡两者。

- **边缘可行性**：严格适配8 GB VRAM，本地压缩降低云API token用量20-30%。

### 优点

- **理论统一**：将检索和压缩置于信息几何框架下，提供KL散度界等理论保证，避免了纯启发式的盲目性。
- **算法效率**：Woodbury加速使Riemannian检索实时可行（O(Ndr)）；Fisher信息迹计算仅需一次反向传播，且无需训练新模型。
- **边缘-云混合设计务实**：本地完成检索和压缩，仅传输关键信息，保护隐私并降低API成本。
- **全面的消融和压力测试**：验证了每种结构保护机制的必要性，以及不同预算和嵌入尺寸下的行为规律。
