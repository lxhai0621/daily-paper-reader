## 摘要
近年来，大型语言模型（LLM）智能体的进步为自动化数据科学带来了令人振奋的进展。然而，现有方法仍受到静态动作集和缺乏原则性长程上下文管理的根本限制，阻碍了其在多阶段、迭代的数据科学流程中跨任务积累可重用经验并可靠运行的能力。为解决这些挑战，我们提出了EvoDS，一个自进化的自主数据科学智能体，它通过基于智能体的强化学习学会扩展自身技能并自适应地管理长期上下文。具体而言，EvoDS引入了两大关键策略：(1) 自主技能获取（ASA）机制，使智能体能够合成、验证并重用可执行技能；(2) 自适应上下文压缩（ACC）策略，将上下文管理视为一个学习到的控制问题而非被动截断。这些策略在一个两阶段多智能体训练方案中进行协调，使得EvoDS能够随时间自主改进。理论上，我们证明EvoDS的分层设计降低了工具选择错误，且其优化目标与信息瓶颈原理一致，确保上下文的有效利用。实验上，EvoDS在四个不同基准测试上平均优于最先进的开源数据科学智能体28.9%，同时消除了令牌溢出错误。我们的代码和数据可在https://github.com/usail-hkust/EvoDS获取。

## Abstract
Recent progress in Large Language Model (LLM) agents has enabled promising advances in automated data science. However, existing approaches remain fundamentally limited by their static action sets and lack of principled long-horizon context management, hindering their ability to accumulate reusable experience across tasks and operate reliably in multi-stage, iterative data science pipelines. To address these challenges, we introduce EvoDS, a self-evolving autonomous data science agent that learns to expand its skills and adaptively managing long-term context through agentic reinforcement learning. Specifically, EvoDS introduces two key strategies: (1) Autonomous Skill Acquisition (ASA) mechanism, which enables agents to synthesize, validate, and reuse executable skills; and (2) Adaptive Context Compression (ACC) strategy, which treats context management as a learned control problem rather than passive truncation. These strategies are orchestrated within a two-stage multi-agent training scheme, enabling EvoDS to autonomously improve over time. Theoretically, we prove that EvoDS's hierarchical design reduces tool-selection error, and its optimization objective aligns with an information bottleneck principle, ensuring efficient context use. Empirically, EvoDS outperforms state-of-the-art open-source data science agents by an average of 28.9% across four diverse benchmarks while eliminating out-of-token failures. Our code and data are available at https://github.com/usail-hkust/EvoDS.

## 1. 核心问题与整体含义（研究动机和背景）

现有的大语言模型（LLM）数据科学智能体虽然能够通过推理、编码、工具调用等方式完成部分自动化数据科学流程，但仍存在两个根本性限制：
- **静态动作集**：智能体的工具和技能是预先固定、不可学习的，无法从过往任务中抽象出可复用的经验，导致重复试错，缺乏自我改进能力。
- **缺乏原则性长程上下文管理**：数据科学工作流天然需要多步迭代，执行上下文会快速膨胀，引发“中间迷失”现象，降低推理质量，甚至超出令牌预算。

因此，论文提出要使智能体能够**自主获取技能**并**自适应压缩上下文**，从而实现跨任务的经验积累和长程稳定执行。这是实现真正自主、可扩展数据科学的必要方向。

## 2. 方法论：核心思想、关键技术细节

EvoDS 是一个 **自进化自主数据科学智能体**，包含以下关键组件：

### 2.1 分层多智能体架构
- **Manager Agent（管理智能体）**：负责高层推理、任务分解、协调子智能体。维护全局记忆（整体任务目标）和局部记忆（子任务目标与上下文）。
- **五个子智能体**：Cleaner（数据清洗）、Featurizer（特征工程）、Modeler（建模）、Visualizer（可视化）、Debugger（调试）。每个子智能体维护自身领域内的局部技能集和局部记忆。
- 子智能体作为 Manager 的可调用工具，Manager 也可以直接执行代码/Shell 命令。

### 2.2 自主技能获取（Autonomous Skill Acquisition, ASA）
- **合成**：当子智能体现有技能不足以解决被分配的子任务时，利用底层 LLM 生成新的可执行技能（名称、描述、代码）。
- **验证**：在环境中执行新技能，仅保留成功产生有效输出的技能。
- **缓存**：验证通过的技能先存入库中，避免立即膨胀动作空间。
- **扩展**：采用使用频率驱动的策略，只有当某技能被反复合成（次数 ≥ 阈值 τ=3）时，才永久加入该子智能体的动作空间。

### 2.3 自适应上下文压缩（Adaptive Context Compression, ACC）
- **子智能体级**：子智能体执行完子任务后，不对原始输出，而是利用 LLM 基于全局目标蒸馏为简洁摘要（成功摘要关键结果，失败摘要错误原因），返回给 Manager。
- **Manager 级**：Manager 拥有一个专门的**摘要工具**，可根据当前推理状态和全局目标自主决定何时压缩历史上下文，而非等到超过长度限制才被动截断。每次压缩后更新 Manager 记忆。

### 2.4 两阶段智能体强化学习
- **阶段一：监督微调（SFT）**：使用高级 LLM（DeepSeek-V3.1）作为教师模型，收集主轨迹（Manager）和子轨迹（子智能体）进行行为初始化。主轨迹因上下文压缩被分段，每段视为独立训练样本。
- **阶段二：在线强化学习（RL）**：采用 GRPO 算法，对主轨迹和子轨迹分别定义奖励，并联合优化。
  - 子轨迹奖励：子任务成功 +0.1，失败 -0.1。
  - 主轨迹奖励（混合设计）：
    \[
    R_{\text{main}} = R_{\text{outcome}} + 0.2 \cdot R_{\text{sub}} - 0.1 \cdot P_{\text{context}} - 0.1 \cdot P_{\text{turn}}
    \]
    其中 \(R_{\text{outcome}}\) 是最终解决方案质量（0~1），\(R_{\text{sub}}\) 是子任务完成率，\(P_{\text{context}} = |C|/C_{\text{max}}\) 是上下文长度惩罚，\(P_{\text{turn}} = T/T_{\text{max}}\) 是交互步数惩罚。
  - 由于主轨迹被分段，最终奖励广播给所有段。
  - 所有智能体共享同一 LLM 骨干（参数），通过角色提示和不同动作空间区分。

理论分析：
- 定理5.1：分层智能体框架的工具选择误差上界严格低于扁平框架（证明见附录）。

## 6. 主要结论与发现

1. **性能提升显著**：EvoDS 在四个基准上平均超越最强开源基线 DataMind-14B 28.9%（绝对提升 9.5%），超越所有基于 DeepSeek-V3.1 和 GPT-4o 的基线，仅次于 o4-mini + ReAct。表明精心设计的智能体框架和训练策略能大幅缩小开源与闭源模型的差距。
2. **消除令牌溢出失败**：ACC 策略使得所有测试样本均未出现超出令牌预算的失败，而基线在长上下文任务中频繁溢出。

4. **分层架构优于扁平架构**：消融实验显示去除分层导致性能下降，理论分析支持分层降低工具选择误差上界。
5. **RL 联合优化优于单智能体 GRPO**：联合优化 Manager 与子智能体获得更高验证奖酬和更少上下文消耗。

## 8. 不足与局限

1. **模型骨干限制**：EvoDS 使用 Qwen3-8B 作为骨干，其固有科学知识有限，在 ScienceAgentBench 这类需要深度领域知识的任务上仍落后于最强闭源模型（o4-mini + ReAct），表明未来需融合外部知识库或使用更强的基础模型。
2. **实验场景局限性**：
   - MLE-Dojo 仅采样 10 个任务，统计稳定性可能不足。
   - 主要聚焦于表格数据（CSV），未涉及图像、文本等多模态数据科学任务。
3. **技能合成质量**：ASA 机制依赖 LLM 自身生成技能代码，可能存在错误或不安全的代码，虽然经过验证，但验证仅基于一次执行，无法保证鲁棒性。重复合成阈值 τ=3 的选择可能不通用。
4. **训练成本与可扩展性**：虽然使用 8B 模型，但 SFT 收集 36K 轨迹 + 300 步 RL 仍需 4 张 A800，对于资源有限的团队仍有一定门槛。
5. **失败模式分析**：虽然给出了失败类型分布，但未提出针对性解决方案；指令遵循错误占比最高（52%），表明模型在复杂指令理解上仍有改进空间。
6. **短期记忆局限**：上下文管理侧重于历史交互的压缩，未与长期知识库（如跨任务技能库的持久化存储）深度耦合，技能库仅在同一基准内跨任务复用。
