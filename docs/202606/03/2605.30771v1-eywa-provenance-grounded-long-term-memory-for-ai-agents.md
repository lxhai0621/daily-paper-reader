## 摘要
跨会话持久化的AI智能体需要可检索、审计、更新和擦除的记忆。现有记忆系统通常将源证据、提取的事实、检索上下文和回答策略压缩到一条不透明的提示路径中，导致故障难以诊断：错误答案可能源于证据缺失、提取不支持、状态过时、检索丢失或答案模型行为。我们提出Eywa，一种以“证据优先于信念”为构建原则的基于来源的记忆架构。Eywa在推导规范事实前存储不可变的源证据，通过类型化信号和来源支持验证提取的记忆，并通过确定性多路读取路径检索受限的记忆上下文，检索过程中零调用LLM。检索到的上下文与回答指令分开返回，使得同一记忆基底可跨前沿、预算及本地答案模型进行评估。在冻结的、以工件记录的检索配置下，Eywa在LoCoMo C1-C4划分上搭配Claude Sonnet 4.6写入和QA角色达到90.19%的裁判准确率。在LongMemEval-S上达到88.2%的检索充分性准确率。在BEAM（一个700个问题的技术记忆压力基准）上达到81.45%的平均Nugget分数和85.29%的pass@score >= 0.5。完整的每问题工件（包括问题、黄金答案、模型答案、检索上下文和标签）发布在https://eywa.to/research。

## Abstract
AI agents that persist across sessions need memory they can retrieve, audit, update, and erase. Existing memory systems often collapse source evidence, extracted facts, retrieved context, and answer policy into one opaque prompt path, making failures difficult to diagnose: a wrong answer may come from missing evidence, unsupported extraction, stale state, retrieval loss, or answer-model behavior. We present Eywa, a provenance-grounded memory architecture built around evidence before belief. Eywa stores immutable source evidence before deriving canonical facts, validates extracted memories against typed signals and source support, and retrieves bounded memory context through a deterministic multi-route read path with zero LLM calls inside retrieval. Retrieved context is returned separately from answer instructions, allowing the same memory substrate to be evaluated across frontier, budget, and local answer models. Under a frozen, artifact-recorded retrieval configuration, Eywa reaches 90.19% judge accuracy on the LoCoMo C1-C4 split with Claude Sonnet 4.6 write and QA roles. On LongMemEval-S, it reaches 88.2% retrieval-sufficiency accuracy. On BEAM, a 700-question technical-memory stress benchmark, it reaches 81.45% mean nugget score and 85.29% pass@score >= 0.5. Full per-question artifacts, including questions, gold answers, model answers, retrieved context, and labels, are published at https://eywa.to/research.

## 1. 核心问题与整体含义（研究动机和背景）

- **现有问题**：当前AI智能体的记忆系统将源证据、提取的事实、检索上下文和答案策略压缩到一条不透明的提示路径中。当记忆支持的答案错误时，错误来源难以定位——可能源于证据缺失、提取不合理、状态过时、检索失败或答案模型行为。
- **研究动机**：人类记忆不仅是事实档案，还支持自我连续性、社会协调和面向未来的行动。AI智能体需要功能上的连续性：必须保留重要的过去证据、更新过时的信念、检索相关上下文，并能解释某条记住的声明为何合理。
- **整体含义**：提出一种可审计、可追溯、可独立评估的长期记忆架构，将记忆视为基础设施而非提示装饰，使错误来自哪一层变得可检查。

## 2. 方法论

### 核心思想：证据优先于信念（evidence before belief）

- 原始对话证据在推导LLM可能的事实之前被不可变存储。提取的事实与源证据保持链接，支持审计、修复和删除。

### 关键技术细节

#### 写路径（Write Path）——两层架构
- **第0层（Tier 0）**：不可变捕获。每个用户轮次存储为不可变的证据行。信号检测器（无LLM）提取类型化锚点（日期、实体、资金值、版本号、标识符、URL等），成为确定性验证基底。
- **第1层（Tier 1）**：验证提取。LLM从证据窗口提取候选事实 $\hat{f}$，通过验证函数 $V$ 对齐：
  \[
  V(\hat{f}, E, S) = V_{\text{support}}(\hat{f}, E) \land V_{\text{hard}}(\hat{f}, S) \land V_{\text{subject}}(\hat{f}, E) \land V_{\text{act}}(\hat{f}, S)
  \]
  - $V_{\text{support}}$：与源文本的词汇和模糊重叠。
  - $V_{\text{hard}}$：硬锚点值的确定性校验（日期、资金值、引号字符串等）。
  - $V_{\text{subject}}$：检查声称的主体是否出现在支持窗口或已知实体中。
  - $V_{\text{act}}$：保留来自记忆活动信号的否定和不确定性。
- 验证通过后的事实成为规范事实，保留来源链接 $\ell(f) \to e$。

#### 提取即索引，而非记忆本身
- 权威记忆基底是不可变的证据存储。提取的规范事实只是可查询、可修订的索引，不代表替换源证据。

#### 记忆表示与来源图
- 证据记录 → 不可变根；信号 → 证据上的类型化注释；规范事实/观察 → 派生信念；来源元数据链接信念到证据。
- 实现：SQLite（权威存储）、LanceDB（向量索引）、SQLite FTS5（关键词索引）、图形关系（RustworkX）。

#### 提取模式
- **规范（Canonical）**：持久配置文件事实（如“Alice偏好暗模式”），带实体类型和生命周期跟踪。
- **观察（Observation）**：高召回率的事件级事实（如“Alice提到在2023年7月3日参加了骄傲游行”）。
- **混合（Hybrid）**：双臂同时运行，推荐高召回部署。
- **结构化技术提取**：面向实现细节、库版本、配置、指标等。

#### 读路径（Read Path）——确定性的多路检索（零LLM调用）

- **查询规划器**：基于规则的确定性引擎（无LLM），分析问题形状（精确/推理/计数/布尔/列表等）、时间线索和实体线索，分配通道权重。
- **检索通道**：
  - 向量（$R_v$）：余弦相似度。
  - 关键词（$R_k$）：BM25 + 查询扩展。
  - 时间（$R_t$）：按事实有效期过滤。
  - 实体/图（$R_g$）：从提取的查询实体出发遍历知识图。
  - 支持通道：生成立体救援（raw-episode rescue）、推理支持。
- **融合**：加权倒数排名融合（RRF）：
  \[
  \text{RRF}(f) = \sum_{c \in C} \frac{w_c}{k + \text{rank}_c(f)}
  \]
  默认 $k=20$。
- **后融合过滤器**：
  - **降级**：若查询目标为某人 $p$，则其他实体的候选得分乘以 $\delta_p = 0.05$。
  - **保留下限**：若某事实已排名较高且匹配角色和时间窗口，则其排名不能低于 $r_{\min}=25$。
- **上下文打包**：按排名顺序打包到配置的令牌预算$B$内，支持多样性或时间顺序模式。

#### 答案策略分离
- `ReadResult` 包含两个不同字段：`context`（检索的记忆证据）和 `answer_instructions`（策略文本）。
- 三种策略：严格（strict）、平衡（balanced）、高级（advanced）。同一检索结构可服务不同模型。

## 6. 主要结论与发现

1. **来源分离有效**：证据–信念分离使错误可诊断，且错误来源可定位（覆盖缺失/提取错误/检索丢失/上下文打包/答案模型行为/评判错误）。
2. **零LLM读路径可行**：确定性的多路检索在测试中速度约150–200毫秒（6,320事实、250情节），支撑频繁读场景。
3. **模型可分离**：同一记忆基底可用不同模型（前沿、预算、本地）消费；Qwen3 32B在Sonnet写入的记忆上从69%提升至79.68%，证明写路径质量对弱答案模型的帮助。
4. **特定类别仍是瓶颈**：开放域推理（C3）最难，反映答案模型推理能力而非记忆缺失。
5. **弃权感知评估的重要**：非对抗性问题应避免用弃权获得分数；报告弃权率和弃权感知指标有助于暴露答案模型弱点。
6. **生产适用性**：本地优先设计、开源方向，适合隐私敏感和成本敏感部署。

## 7. 优点
