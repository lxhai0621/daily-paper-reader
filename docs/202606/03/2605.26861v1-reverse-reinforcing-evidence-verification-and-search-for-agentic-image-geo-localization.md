## 摘要
图像地理定位旨在确定照片拍摄地点，该任务通常不仅需要识别可见地标。人类专家通常通过迭代工作流程解决：他们检查信息区域，形成位置假设，寻求外部证据，并在新线索出现时修正判断。现有方法仅部分捕捉了这一过程：直接预测方法完全绕过证据获取，而检索增强方法引入外部证据，但通常对中间决策（搜索何处、如何查询、如何过滤噪声结果）提供有限监督。我们提出REVERSE，一个强化证据搜索与验证之间交互以实现多轮智能推理的框架。REVERSE教授三个中间决策：看哪里、查询什么、信任什么证据。为此，我们构建了带有注释区域选择、搜索观察和地理信息证据标签的工具化轨迹，并引入了视觉基础、查询效用和证据区分的流程奖励。离线搜索缓存使检索观察在强化学习期间稳定可重用，从而实现对噪声搜索结果的密集监督。使用4B模型，REVERSE在Im2GPS3k和YFCC4k上优于强检索增强基线，并与大得多的模型相媲美。代码可在https://github.com/yonglleee/REVERSE获取。

## Abstract
Image geo-localization aims to determine where a photograph was taken, a task that often requires more than recognizing visible landmarks. Human experts typically solve it through an iterative workflow: they inspect informative regions, form location hypotheses, seek external evidence, and revise their judgments as new clues appear. Existing methods only partially capture this process: direct prediction methods bypass evidence acquisition altogether, while retrieval-augmented methods introduce external evidence but usually provide limited supervision on the intermediate decisions of where to search, how to query, and how to filter noisy results. We present REVERSE, a framework that reinforces the interplay between evidence search and verification to enable multi-turn agentic reasoning. REVERSE teaches three intermediate decisions: where to look, what to query, and what evidence to trust. To support this, we construct tool-grounded trajectories with annotated region selections, search observations, and geo-informative evidence labels, and introduce process rewards for visual grounding, query utility, and evidence discrimination. An offline search cache makes retrieval observations stable and reusable during reinforcement learning, enabling dense supervision over noisy search results. With a 4B model, REVERSE outperforms strong retrieval-augmented baselines and rivals substantially larger models on Im2GPS3k and YFCC4k. Code is available at https://github.com/yonglleee/REVERSE.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：图像地理定位（Image Geo-localization）要求从照片中推断拍摄地点，该任务不仅是识别显式地标，往往需要迭代的推理过程——专家会检查区域、形成假设、搜索外部证据、修正判断。现有方法存在两种局限：
    - 直接预测方法（如分类或 VLM 直接输出坐标）完全跳过证据获取；
    - 检索增强方法虽然引入外部证据，但对**中间决策**（在哪里搜索、如何查询、如何过滤噪声结果）缺乏显式监督，导致模型可能误用工具或无法区分有用证据。
- **研究动机**：希望让模型学会如人类专家一样的主动、多轮推理，而不仅仅是单次预测。
- **整体含义**：通过强化证据搜索与验证之间的交互，使智能体 (agent) 具备可学习的中间推理能力，从而提升地理定位的准确性和鲁棒性。

## 2. 论文提出的方法论

### 核心思想

将图像地理定位重新定义为**多轮工具化推理过程**，模型需要做出三个可观察的中间决策：
- **看哪里** (where to look) —— 通过缩放 (Zoom) 工具选取可能包含地理线索的区域；
- **查什么** (how to query) —— 通过图像搜索 (Image Search) 或文本搜索 (Text Search) 工具构造有效查询；
- **信什么** (what to trust) —— 通过 `<useful>` 标签对搜索结果进行证据判别，区分地理信息与干扰项。

### 关键技术细节

1. **智能体框架与工具**：模型配备三个工具：
    - 缩放工具：裁剪并放大指定区域；
    - 图像搜索工具：对裁剪区域进行反向图像搜索，返回网页列表；
    - 文本搜索工具：接受自然语言查询，返回网络摘要。
    模型在每个回合只能调用一个工具，最终输出 `<answer> 国家, 城市, 纬度, 经度 </answer>`。

2. **数据生成管道 (Data Generation Pipeline)**：
    - 使用 Kimi-K2.6 作为教师模型，在 MP-16 Pro 图像上生成多轮轨迹（包括缩放、搜索、`<useful>` 标签和最终答案）。
    - 进行质量过滤、证据标签再标注（判断每个搜索结果对目标图像是否具有地理信息）、边界框修正（将全图裁剪改为紧贴地理信息区域）。
    - 构建离线搜索缓存：将所有图像搜索和文本搜索的观察结果固化，通过 IoU 和 Jaccard 相似度匹配，方便 RL 训练时重用并保持噪声结构。

3. **三阶段训练流程**：
    - **Stage 1: SFT**：在 4M 张 MP-16 Pro 图像上进行监督微调，学习直接坐标预测，建立地理先验。
    - **Stage 2: Agentic Cold Start**：在 4,427 条教师轨迹上进行自回归微调，学习工具调用格式和基本证据选择。
    - **Stage 3: Agentic RL**：使用 GRPO 算法进行强化学习，采用易→全课程学习（先训练距离误差 ≤25km 的简单样本，再扩展至全难度），优化复合奖励。

4. **过程奖励 (Process Reward)**：复合奖励包含三项：
    - **地理奖励 r_geo**：基于 Haversine 距离映射到标准阈值（1,25,200,750,2500 km）得分。
    - **格式奖励 r_fmt**：确保应答包含 `<think>`、`<useful>`、`<answer>` 等正确标签。
    - **工具过程奖励 r_tool**：包括
        - 图像搜索执行奖励：基于 IoU 的连续奖励；
        - 文本搜索执行奖励：固定基础奖励；
        - 缩放执行惩罚：对退化边界框扣分；
        - **MCC 判别奖励**：使用 Matthews 相关系数 (MCC) 评估 `<useful>` 标签的准确性。MCC 在 [-1,1] 范围内，**对全部标记为有用等简单策略严格惩罚（得分为 0）**，迫使模型真正学习证据判别。

### 公式（文字说明）

- 轨迹定义：τ = (I, a₁, o₁, ..., a_T, o_T, ŷ)
- SFT 损失：L_geo = -∑ log p_θ(a_t | I)
- Cold Start 损失：L_SFT = -∑ log p_θ(a_t | I, a<t, o<t)
- GRPO 目标：L_GRPO(θ) = -E[ A(τ) log π_θ(τ|I) ] + β KL
- 复合奖励：R(τ) = α·r_geo + β·r_fmt + γ·r_tool
- MCC 计算：MCC = (TP·TN - FP·FN) / sqrt((TP+FP)(TP+FN)(TN+FP)(TN+FN))

## 3. 实验设计

- **数据集**：
    - **Im2GPS3k**：2,997 张全球采样地理标记图像，常用于基准测试。
    - **YFCC4k**：4,536 张图像，偏向日常场景，更少显著地标，难度更高。
- **基准测试指标**：在 1, 25, 200, 750, 2500 km 五个阈值上的准确率（未解析预测视为错误）。
- **对比方法**：
    - 分类方法：PlaNet, CPlaNet, ISNs, GeoToken
    - 检索方法：GeoCLIP, Img2Loc, PIGEON, G3
    - VLM 方法：Translocator, GeoDecoder, GeoBayes, SpotAgent, Geo-R
    - 零样本参考：未微调的 Qwen3-VL-4B/8B
- **主要结果**：
    - Im2GPS3k：REVERSE 在 25km 阈值达到 48.3%，优于所有检索增强基线（Geo-R 为 41.5%）；1km 达到 22.5%，优于 Geo-R 的 18.1%。相比 8B 未微调模型（37.2%@25km）提升显著。

## 6. 论文的主要结论与发现

- **工具使用必须训练**：直接给未微调模型装备工具会降低性能，而通过过程奖励训练后模型能学会选择性地使用工具。
- **过程奖励优于结果奖励**：仅用地理准确率奖励（Acc only）在 25km 只达到 42.2%，而完整过程奖励达到 45.4%，显示出中间步骤监督的重要性。
- **MCC 判别奖励关键**：删除 MCC 奖励后 25km 准确率下降 1.8 个百分点，且模型退化为全标记为有用。
- **小模型可媲美大模型**：4B 模型通过 REVERSE 训练超过未经训练的 8B 模型，并匹配更大模型（如 Geo-R）的性能。
- **图像搜索是主导工具**：单独图像搜索即达到较高精度，文本搜索提供补充，缩放工具在训练后使用频率降低，转向更高效的搜索路径。

## 7. 优点

1. **显式建模中间推理**：首次将“看哪里、查什么、信什么”三个决策纳入可优化目标，通过标签化和过程奖励提供密集监督。
2. **巧妙防止奖励作弊**：使用 MCC 作为证据判别奖励，MCC 在常数预测时为 0，彻底杜绝简单策略（如全标记为有用）。
3. **离线缓存设计**：使 RL 训练中检索结果稳定、可重复，同时保留真实噪声结构，降低 API 成本 90%+。
4. **课程学习策略**：先易后难，稳定工具使用行为后再泛化到困难样本。
5. **小模型高效**：以 4B 模型达到甚至超越 8B 未训练模型和部分大 VLM 方法，验证了训练方式比模型规模更重要。

## 8. 不足与局限

1. **依赖专有教师模型**：高质量轨迹来自 Kimi-K2.6，教师模型本身可能引入偏见，且无法完全开源。
2. **离线缓存静态性**：训练时使用的搜索快照是固定的，与真实动态网络有差异，模型可能对新出现的干扰项适应不足。
3. **YFCC 等模糊场景性能有限**：在缺乏明显视觉线索的场景（日常照片）中，工具辅助收益低，甚至不如传统检索方法（G3），说明该方法更依赖可检索的地标信息。
4. **未讨论域泄露风险**：论文指出图像搜索可能返回含 GPS 元数据的 Flickr 结果，但未验证泄漏影响，虽声称未观察到但可能仍存在。
5. **隐私与伦理风险**：准确地理定位能力可被滥用，识别用户隐私位置，论文仅提建议但未提供防护机制。
6. **实验覆盖中等**：仅在两个 benchmark 上评估，未在最新更大规模数据集（如 OpenStreetView-5M）或连续大规模场景测试，泛化性需更多验证。
7. **计算资源较大**：32 块 A800 GPU 的训练成本不低，对复制有门槛。
