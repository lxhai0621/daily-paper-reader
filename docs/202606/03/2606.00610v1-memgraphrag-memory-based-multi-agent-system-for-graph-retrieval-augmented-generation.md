## 摘要
检索增强生成（RAG）已成为通过利用外部知识减轻大语言模型（LLM）幻觉的重要方法。虽然对简单查询有效，但传统RAG在处理信息高度碎片化的大规模非结构化语料库时表现不佳。基于图的RAG（GraphRAG）通过引入知识图谱来捕获结构关系，从而为复杂推理提供更全面的检索。然而，现有的GraphRAG方法依赖孤立的片段级提取来构建图，缺乏对整个语料库的全局视角。因此，这些方法常常导致主题不一致、逻辑冲突和结构碎片化的图，从而降低检索性能。本文提出MemGraphRAG，一种新颖的框架，引入基于记忆的多智能体系统以确保高质量的图构建。具体来说，MemGraphRAG采用由共享记忆支持的协作智能体社群，在整个提取过程中提供统一的全局上下文。该机制允许智能体动态解决逻辑冲突并保持整个语料库的结构连通性。此外，我们针对所构建的图提出了一种记忆感知的分层检索算法。在多个基准上的大量实验表明，MemGraphRAG在相当效率下优于最先进的基线模型。我们的代码可在https://github.com/XMUDeepLIT/MemGraphRAG获取。

## Abstract
Retrieval-Augmented Generation (RAG) has become an essential method for mitigating hallucinations in Large Language Models (LLMs) by leveraging external knowledge. Although effective for simple queries, traditional RAG struggles with large-scale, unstructured corpora where information is highly fragmented. Graph-based RAG (GraphRAG) incorporates knowledge graphs to capture structural relationships, enabling more comprehensive retrieval for complex reasoning. However, existing GraphRAG methods rely on isolated, fragment-level extraction for graph construction, lacking a global perspective on the whole corpus. As a result, these methods frequently lead to thematically inconsistent, logically conflicting, and structurally fragmented graphs that degrade retrieval performance. In this paper, we propose MemGraphRAG, a novel framework that introduces a memory-based multi-agent system to ensure high-quality graph construction. Specifically, MemGraphRAG employs a collaborative society of agents supported by shared memory, which provides a unified global context throughout the extraction process. This mechanism allows agents to dynamically resolve logical conflicts and maintain structural connectivity throughout the corpus. Furthermore, we propose a memory-aware hierarchical retrieval algorithm tailored for the constructed graph. Extensive experiments on multiple benchmarks demonstrate that MemGraphRAG outperforms the state-of-the-art baseline models with comparable efficiency. Our code is available at https://github.com/XMUDeepLIT/MemGraphRAG.

# MemGraphRAG: 基于记忆的多智能体系统用于图检索增强生成（详细总结）

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：检索增强生成（RAG）能缓解大语言模型（LLM）的幻觉，但传统 RAG 在处理大规模、非结构化、信息碎片化的语料库时效果不佳。图检索增强生成（GraphRAG）通过引入知识图谱捕获结构关系，提升了复杂推理能力。
- **核心问题**：现有 GraphRAG 方法在构建知识图谱时采用“孤立片段级提取”（isolated local extraction），即针对每个文档块独立抽取三元组，**缺乏对整个语料库的全局视角**。这导致三个关键缺陷：
  1. **主题不相关**：提取到大量与主题无关的三元组，成为噪声。
  2. **逻辑不一致**：不同片段可能产生互相矛盾的事实（互斥冲突、时间冲突、粒度冲突）。
  3. **结构碎片化**：实体重复、子图不连通，削弱多跳推理能力。
- **研究动机**：设计一种能保持**全局一致性**的图构建方法，从而提升检索质量和生成准确性。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 提出 **MemGraphRAG**，将图构建重构为“全局记忆”（Global Memory）与“分层索引图”（Hierarchical Indexing Graph）的协同演化过程。
- 引入**多智能体系统**（Multi-Agent Group），由共享记忆提供全局上下文，实现动态协调、冲突解决和信息整合。

### 2.2 三大核心机制

#### （1）主题去噪：统一模式过滤（Unified Schema Filtering）
- **提取智能体**（\(A_{ext}\)）从每个文档块同时提取**候选模式**（schema）、**实例化事实**和**源段落**，存入三层全局记忆（\(M_{ont}\)、\(M_{fac}\)、\(M_{pas}\)）。
- 模式只有其出现频率 \( \text{Freq}(s) \geq \tau \) 时才提升为“稳定模式”，只有匹配稳定模式的事实才被激活并加入图。这过滤了低频噪声。

#### （2）一致性维护：全局判决（Global Adjudication）
- **冲突检测智能体**（\(A_{det}\)）监控 \(M_{fac}\)，对新激活的事实进行全局扫描（语义相似度+符号匹配），找出冲突集 \(F_{conf}\)。
- **冲突解决智能体**（\(A_{res}\)）从 \(M_{pas}\) 中检索原始证据，基于证据执行修正（丢弃错误事实、为时间事实添加时间戳、为粒度冲突细化谓词）。

#### （3）结构统一：记忆引导桥接（Memory-Guided Bridging）
- 将验证后的记忆投影为三层图：
  - \(G_{ont}\)（语义本体图）：类型-关系骨架。
  - \(G_{fac}\)（事实图）：多跳推理实体-关系图。
  - \(G_{pas}\)（源证据图）：链接事实到原始段落。
- 在 \(G_{fac}\) 中添加两种桥接边：
  - **类型桥接**：共享同一稳定模式的实体间添加边。
  - **相似度桥接**：嵌入相似度超过阈值 \(\delta\) 的实体对。

### 2.3 记忆引导的在线检索算法
**三阶段**：
1. **多层内存过滤**：对查询 \(q\) 并行从 \(M_{ont}\)、\(M_{fac}\)、\(M_{pas}\) 检索 top-K 候选，仅保留相似度 > \(\tau\) 的模式和事实。若无有效结构候选，则退化为标准 RAG。
2. **结构感知节点初始化**：为不同类型节点赋予初始 PageRank 权重：
   - 实体节点：取关联检索事实的平均相似度。
   - 类型节点：模式相关性 × 反度惩罚 \(1/\log(\deg+1)\)，抑制高连结点的干扰。
   - 段落节点：语义相似度 × 信息密度项（IDF 的聚合）。
3. **个性化 PageRank 传播**：在异构图上运行 PPR（阻尼系数 \(\lambda=0.5\)），收敛后选择 top-K 段落和实体作为 LLM 上下文。
