## 摘要
记忆仍然是长时域机器人操作的关键瓶颈，因为标准的视觉-语言-动作（VLA）策略在任务相关线索随时间变得遮挡或不可观察时经常失败。虽然现有的记忆增强方法利用历史上下文，但它们要么遭受严重的信息瓶颈，通过解耦的双系统产生高延迟，要么依赖于积累大量视觉冗余的非选择性缓冲区。为了解决这些限制，我们引入了EventVLA，一个基于稀疏视觉证据记忆概念的端到端框架，包含两个核心组件：用于保留初始和短期上下文的基础视觉锚点，以及一个动态关键帧证据记忆（KEM）模块。具体来说，KEM直接从VLA的潜在嵌入中预测未来的关键帧概率，以自主捕获和存储稀疏的、任务关键的视觉事件。这种前瞻驱动的机制使策略能够动态评估当前观察结果的未来因果效用，在视觉证据变得不可观察之前保留瞬时的视觉证据。此外，我们提出了RoboTwin-MeM，一个专门设计用于评估具有交互式视觉证据的非马尔可夫操作任务的诊断基准。广泛的评估表明，在17个需要记忆的模拟任务和4个真实世界双手任务中，EventVLA相比最先进的记忆增强VLA平均成功率提高了+40%。

## Abstract
Memory remains a critical bottleneck for long-horizon robotic manipulation, as standard Vision-Language-Action (VLA) policies often fail when task-relevant cues become occluded or unobservable over time. While existing memory-augmented methods utilize historical context, they either suffer from severe information bottlenecks, incur high latency via decoupled dual systems, or rely on unselective buffers that accumulate massive visual redundancies. To address these limitations, we introduce EventVLA, an end-to-end framework founded on the concept of sparse visual evidence memory that comprises two core components: foundational visual anchors to retain initial and short-term contexts, and a dynamic Keyframe Evidence Memory (KEM) module. Specifically, KEM directly predicts future keyframe probabilities from the VLA's latent embeddings to autonomously capture and store sparse, task-critical visual events. This foresight-driven mechanism empowers the policy to dynamically evaluate the future causal utility of current observations, preserving transient visual evidence before it becomes unobservable. Furthermore, we propose RoboTwin-MeM, a diagnostic benchmark specifically designed to evaluate non-Markovian manipulation tasks with interactive visual evidence. Extensive evaluations show that across 17 memory-requiring simulation tasks and 4 real-world bimanual tasks, EventVLA achieves an average success rate improvement of +40% over state-of-the-art memory-augmented VLAs.

## 2. 方法论

### 2.1 核心思想
EventVLA 是一个端到端框架，基于**稀疏视觉证据记忆**概念，将两种记忆组件无缝结合：
- **基础视觉锚点**（Heuristic Visual Anchors）：初始帧（场景全局布局） + 短期历史滑动窗口（局部运动线索）。规则驱动，固定。
- **动态关键帧证据记忆（KEM）模块**：数据驱动，通过从 VLA 潜在嵌入预测未来关键帧概率，主动捕获和存储瞬态的、交互产生的视觉事件（例如，短暂暴露的物体颜色、随机序列）。

### 2.2 关键技术细节
- **问题形式化**：动作生成依赖当前观测 \(o_t\)、语言指令 \(l\) 和外部稀疏记忆缓冲区 \(M_{t-1}\)（含锚点 \(A_t\) 和事件关键帧 \(E_t\)）。
- **KEM 模块设计**：
  - 在 VLA 自回归 Transformer 的最后一层隐藏状态 \(h_t\) 上添加轻量级 KEM 预测头。
  - 将隐藏状态投影为未来动作块内每个时间步的关键帧概率 \(\hat{p}_t \in [0,1]^H\)（\(H\) 为动作块大小）。
  - 当概率超过阈值 \(\tau_{\text{commit}}\) 时触发写事件，存储对应图像到事件缓冲区 \(E_t\)（FIFO 最大容量 \(N_{\max}\)）。
  - 使用 1D 非极大值抑制（NMS）和冷却期（cooldown）确保写入稀疏性。
- **训练策略**：
  - 使用 Qwen3-VL 自动标注管道从演示视频中提取关键帧时间戳，并生成时间平滑的软标签（raised cosine kernel）。

  - 教师-学生课程训练：教师强迫概率 \(\alpha\) 从 1 线性衰减到 0，逐步过渡到自主预测。

### 2.3 公式与算法流程（文字说明）
- 关键帧概率预测：\(\hat{p}_t = \sigma(\text{KEM}_{\text{mlp}}(h_t))\)

- 在线推理：对每个动作块，KEM 预测概率，经 NMS 和冷却期筛选后，将有效关键帧图像提交到事件缓冲区。

## 7. 优点

1. **端到端稀疏记忆**：非马尔可夫推理与动作生成在同一框架中完成，避免双系统延迟。
2. **前瞻性关键帧预测**：KEM 利用 VLA 自身隐藏状态预测未来关键帧，实现主动、数据驱动的记忆写入。
3. **自动标注管道**：利用 VLM 提取关键帧标签，免除人工标注负担，可扩展。
4. **诊断基准 RoboTwin-MeM**：专为严格非马尔可夫场景设计，参数化中间记忆需求，促进社区研究。
5. **实验覆盖全面**：从模拟到真实、从简单到复杂、从强马尔可夫到严格非马尔可夫，消融细致，对比基线多样。
6. **推理效率**：在模拟中达到约 0.94 Hz 的吞吐量，实际部署可行。

## 8. 不足与局限

1. **有界事件缓冲区**：在超长时域（>10 分钟）且事件密度高的任务中可能饱和，导致早期关键证据被 FIFO 淘汰。论文承认此局限，并提出未来可探索分层记忆或压缩表示。
2. **训练与推理硬件需求**：基于较大 VLM（4B 或更大），对计算资源有一定要求，文中未详细报告训练 GPU 数量和时间，复现门槛不够透明。
3. **真实实验规模有限**：仅 4 个任务，每个 20 次试验，虽然结果显著，但任务多样性（如物体种类、环境复杂度）仍可扩展。
4. **基准的特定性**：RoboTwin-MeM 任务设计基于 SAPIEN 物理引擎，场景相对受控，与现实世界完全非结构化环境仍有差距。
