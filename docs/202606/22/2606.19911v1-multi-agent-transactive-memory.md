## 摘要
具有多样化能力的LLM智能体在各类任务中的去中心化部署，激发了在异构智能体群体间进行知识共享的基础设施需求。正如搜索引擎索引人类生成的产物以支持人类解决问题，检索系统可以组织智能体生成的产物以供跨群体复用。我们将检索增强生成（证明了人类创作产物对单个智能体的价值）扩展至对支持智能体群体的智能体生成产物的检索。特别地，智能体轨迹编码了可复用的程序性知识，然而这些产物通常在一次使用后被丢弃或仅由生成智能体保留，迫使新实例化的智能体反复重新发现已有解决方案。我们提出多智能体交互记忆（MATM），一种在群体层面存储和检索智能体生成轨迹的框架，其中生产者智能体将轨迹贡献到共享存储库，消费者智能体检索它们以改进任务执行。我们聚焦于交互式环境（ALFWorld和WebArena），其中轨迹较长且编码了特别丰富的程序性结构。实验表明，从MATM中检索轨迹可提升下游任务性能，并在无需协调或联合训练的情况下减少交互步骤。这些结果将MATM定位为开放智能体生态系统中群体层面经验共享的设计模式。

## Abstract
The decentralized deployment of LLM agents with diverse capabilities across diverse tasks motivates infrastructure for knowledge sharing across heterogeneous agent populations. Just as search engines index human-generated artifacts to support human problem solving, retrieval systems can organize agent-generated artifacts for reuse across agent populations. We extend retrieval-augmented generation - which demonstrates the value of human-authored artifacts to individual agents - to retrieval of agent-generated artifacts supporting a population of agents. In particular, agent trajectories encode reusable procedural knowledge, yet these artifacts are typically discarded after a single use or retained only by the producing agent, forcing newly instantiated agents to repeatedly rediscover existing solutions. We propose Multi-Agent Transactive Memory (MATM), a framework for population-level storage and retrieval of agent-generated trajectories, where producer agents contribute trajectories to a shared repository and consumer agents retrieve them to improve task execution. We focus on interactive environments (ALFWorld and WebArena), where trajectories are long and encode especially rich procedural structure. Our experiments demonstrate that retrieving trajectories from MATM improves downstream task performance and reduces interaction steps without coordination or joint training. These results position MATM as a design pattern for population-level experience sharing in open agent ecosystems.

## 1. 论文的核心问题与整体含义（研究动机和背景）

*   **背景**：LLM 智能体在不同领域中被去中心化部署，其执行任务时产生的交互轨迹（action-observation trajectory）编码了丰富的可复用程序性知识（procedural knowledge）。然而，这些轨迹通常在一次使用后被丢弃，或仅由生成它的智能体私下保留，导致新实例化的智能体必须反复重新探索已有的解决方案。
*   **核心问题**：现有智能体记忆系统主要关注单智能体的私有记忆（如检索增强生成 RAG 从人类文档中检索），缺乏**群体级别的知识共享基础设施**。虽然多智能体协作或集中式训练方法存在，但需要协调或共同训练，不适合动态、异构、开放式的智能体生态系统。
*   **研究目标**：提出一种群体级别的经验共享框架，使不同智能体能够贡献和检索彼此产生的轨迹，以提升任务执行效果和效率，并支持持续增长。

## 2. 论文提出的方法论

*   **核心思想**：借鉴心理学的“交互记忆”（Transactive Memory）概念——人类群体通过将知识分布在个体之间，并使用共享机制定位和检索相关信息。MATM 将智能体群体产生的轨迹视为共享知识，构建一个存储库（repository），智能体可扮演生产者（producer）或消费者（consumer）角色，生产者贡献成功轨迹，消费者检索相关轨迹辅助推理。
*   **关键技术细节**：
    *   **索引与检索方案**：采用**状态条件的键值索引**。将轨迹分段（每段包含 l 步），以**当前任务描述加上最近 l 步历史**作为键（key），以**后续 l 步的轨迹**作为值（document）。这样消费者在推理过程中可以根据当前状态检索后续的指导片段，而不仅依赖初始任务指令。
    *   **生成式检索流水线（Retrieval-Planner）**：消费者智能体在每个交互步骤前使用一个“检索规划器”（RetrievalPlanner）决定是否调用检索，以避免过度检索稀释上下文。
    *   **学习排序轨迹（Learning to Rank Trajectories, LTRT）**：为提升检索质量，引入轻量级学习排序重排序器。特征共六类 44 维：生产者智能体元数据（如基准分数）、消费者智能体元数据、第一阶段检索分数、查询特征、轨迹特征、查询-轨迹交互特征。通过边际效用（marginal utility）标注每个候选片段（比无检索基线的得分增益），训练点式（FFN）、成对（LambdaMART, SVMRank）重排序模型。
*   **算法流程（文字说明）**：
    1. **预填充阶段**：用公开数据（如 seq2seq 模型轨迹、高级 LLM 轨迹）初始化索引 D0。
    2. **增量更新阶段**：将训练问题划分为多个批次；每批中为每个问题分配一个生产者智能体，先执行无检索基线得到轨迹和分数，随机抽样分支点，在分支点检索 top-K 候选轨迹，每个候选生成一条增强轨迹；将成功轨迹（超过阈值 θ）且满足质量要求的轨迹加入缓冲池，最终分段、嵌入、加入索引。同时记录每个候选的边际效用标签，形成 LTRT 训练数据集。
    *   所有操作仅在训练集上进行，测试集完全隔离。

## 6. 论文的主要结论与发现

1. **MATM 普遍提升效果和效率**：检索增强显著提高成功率和减少步数（ALFWorld SR +8%p，步数 -0.59；WebArena SR +2%p，步数 -1.73），RPP 由负转正。
2. **学习排序进一步改善**：SVMRank 在 ALFWorld、FFN 在 WebArena 中均超越单阶段检索（平均 SR 提升 9%p 以上），表明生产者元数据等特征对预测下游效用重要。
3. **收益分布广泛**：无论生产者能力强弱，消费者都能获益；能力差距与检索优势的相关系数小且不显著，说明不是简单的“强-弱迁移”。
4. **跨任务泛化**：即使只检索不同任务类型的轨迹，SR 也显著高于无检索基线（ALFWorld 59.9% vs 47.1%），表明轨迹包含通用交互模式。
5. **记忆规模正相关**：随索引增大，效果和效率持续改善（WebArena 成功率在 50% 大小处有波动，但整体趋势向上）。
