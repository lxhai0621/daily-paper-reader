## 摘要
现有记忆增强型LLM智能体仅将过去经验存储在提示空间中，以文本摘要或检索段落的形式存在，而整个执行过程中模型参数保持不变。这类智能体可以“查找”已见内容，但无法“从中学习”：其策略不因经验而改变，任何从上下文中丢弃的信息都会永久丢失。我们提出TMEM，一种自演化的参数化记忆框架，其中智能体不仅将历史压缩为显式记忆，还通过轻量级在线更新将提炼后的监督吸收到快速LoRA权重Δ_t中，从而在单个回合内真正改变其未来行为。我们将此形式化为具有快速权重执行动态的智能决策过程：动作从π_{θ_0+Δ_t}中采样，而提取动作产生用于更新Δ_t的监督，进而影响后续决策。这一观点使得提取策略可直接通过强化学习进行优化：训练θ_0不仅能改善任务动作，还能提升用于在线LoRA适应的数据质量。我们进一步提出基于SVD的LoRA子空间初始化，以加速在线收敛。在LoCoMo、LongMemEval-S、多目标搜索和CL-Bench上的实验表明，TMEM在不同模型规模下始终优于基于摘要和基于检索的基线方法。

## Abstract
Existing memory-augmented LLM agents store past experience exclusively in prompt space, as textual summaries or retrieved passages, while keeping model parameters frozen throughout a rollout. Such agents can \emph{look up} what they have seen but cannot \emph{learn from} it: their policy is unchanged by experience, and any information dropped from the context is permanently lost. We introduce \texttt{TMEM}, a self-evolving parametric memory framework in which the agent not only compresses history into explicit memory but also absorbs distilled supervision into fast LoRA weights $Δ_t$ via lightweight online updates, genuinely altering its future behavior within a single episode. We formalize this as an agentic decision process with fast-weight rollout dynamics: actions are sampled from $π_{θ_0+Δ_t}$, while extraction actions produce supervision that updates $Δ_t$ for subsequent decisions. This view makes the extraction policy directly optimizable by RL: training $θ_0$ improves not only task actions but also the quality of the data used for online LoRA adaptation. We further propose SVD-based initialization of the LoRA subspace to accelerate online convergence. Experiments on LoCoMo, LongMemEval-S, multi-objective search, and CL-Bench show that \texttt{TMEM} consistently outperforms summary-based and retrieval-based baselines across different model scales.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- TMEM 引入“快速参数化记忆”概念，通过将蒸馏后的经验吸收到可在线更新的 LoRA 权重 Δ_t 中，使智能体在单个回合内真正改变未来行为。
- 形式化为一个具有快速权重（fast-weight）执行动态的智能决策过程：动作从自适应策略 π_{θ_0+Δ_t} 中采样，其中提取动作产生用于更新 Δ_t 的监督数据。
- 将记忆提取视为策略动作的一部分，而非辅助预处理步骤，从而通过强化学习（RL）直接优化提取策略。

### 关键技术细节
1. **快速权重执行动态**：
   - 智能体维护工作上下文 h_t、显式文本记忆 m_t 和快速参数化记忆 Δ_t（LoRA 权重）。
   - 当上下文预算（L_max）达到时，触发记忆提取模式：使用专用提示 d 将当前会话蒸馏为结构化 QA 对形式的监督数据。
   - 通过轻量级在线 SFT 更新函数 T（使用 SGD，学习率 5×10^{-4}，5 个 epoch，batch size 16）将提取的监督写入 Δ_t，从而更新策略。
   - 后续动作从更新后的策略 π_{θ_0+Δ_{t+1}} 中采样，而非仅依赖压缩文本。

2. **SVD 初始化的参数记忆**：
   - 标准 LoRA 随机初始化，而 TMEM 对每个目标权重矩阵 W 进行 SVD 分解 W = UΣV^T，固定投影矩阵 A = Σ_r V_r^T（top-r 奇异向量和奇异值），仅在线更新系数矩阵 B。
   - 这样锚定在线更新到预训练权重的高能量方向，加速少步适应，减少每次触发的计算开销。
   - 理论保证（Theorem 1）：SVD 初始化的近似误差不大于随机高斯初始化。

3. **策略优化（带停止梯度的 RL）**：
   - 目标函数 J(θ_0) = E_{τ}[R(τ)]，其中 θ_0 在回合内固定但跨回合优化。
   - 使用停止梯度（stop-gradient）技术，通过 Δ_t 产生路径的梯度不反向传播，从而优化基模型 θ_0 以产生更好的任务动作和更好的提取动作。
   - 策略梯度估计对每个片段（segment）分别计算普通动作的梯度和边界动作（提取或最终响应）的梯度。

4. **与现有方法的统一**：设置 Δ_t ≡ 0 即恢复为纯显式记忆智能体，将现有上下文管理方法统一在单一框架下。

## 6. 论文的主要结论与发现

1. TMEM 在四个任务族上均一致优于摘要记忆和检索记忆基线，无论是否经过 RL 优化。
2. RL 优化进一步放大 TMEM 的优势：在 LoCoMo 和 LongMemEval-S 上，RL 后 TMEM 的增益（F1/EM 提升 5~6 分）明显大于摘要记忆（2~4 分）和检索记忆（3~4 分）。

4. QA 对形式的监督信号优于原始 next-token 预测和自由文本摘要，表明结构化知识蒸馏对参数记忆至关重要。

6. 上下文预算 L_max 存在最优值：过小导致过度压缩，过大则使提取质量下降。
7. TMEM 在效率上位于无记忆（最高GPU/时间）和摘要记忆（最快最省）之间，但优于检索记忆在 LongMemEval-S 上的时间开销。
