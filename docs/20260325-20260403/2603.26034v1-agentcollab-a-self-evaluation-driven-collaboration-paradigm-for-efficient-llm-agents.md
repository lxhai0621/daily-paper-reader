## 摘要
由大语言模型（LLMs）驱动的自主智能体通过长程推理和工具交互执行复杂任务，其中在执行效率和推理鲁棒性之间存在基本的权衡。不同能力-成本水平的模型具有互补优势：低成本模型能够实现快速执行，但在困难的推理环节可能表现不佳；而更强大的模型虽然计算成本更高，但能提供更稳健的推理。我们提出了 AgentCollab，这是一个自驱动的协作推理框架，在智能体执行过程中动态协调具有不同推理能力的模型。该框架不依赖外部路由模块，而是利用智能体自身的自反思信号来判断当前的推理轨迹是否取得了实质性进展，并仅在必要时将控制权升级到更强的推理层级。为了进一步稳定长程执行，我们引入了一种难度感知的累积升级策略，根据最近的失败信号分配额外的推理预算。在实验中，我们使用“小-大”两级模型设置实例化了该框架。在多种多步智能体基准测试上的实验表明，AgentCollab 持续改进了大语言模型智能体的准确率-效率帕累托前沿。

## Abstract
Autonomous agents powered by large language models (LLMs) perform complex tasks through long-horizon reasoning and tool interaction, where a fundamental trade-off arises between execution efficiency and reasoning robustness. Models at different capability-cost levels offer complementary advantages: lower-cost models enable fast execution but may struggle on difficult reasoning segments, while stronger models provide more robust reasoning at higher computational cost. We present AgentCollab, a self-driven collaborative inference framework that dynamically coordinates models with different reasoning capacities during agent execution. Instead of relying on external routing modules, the framework uses the agent's own self-reflection signal to determine whether the current reasoning trajectory is making meaningful progress, and escalates control to a stronger reasoning tier only when necessary. To further stabilize long-horizon execution, we introduce a difficulty-aware cumulative escalation strategy that allocates additional reasoning budget based on recent failure signals. In our experiments, we instantiate this framework using a two-level small-large model setting. Experiments on diverse multi-step agent benchmarks show that AgentCollab consistently improves the accuracy-efficiency Pareto frontier of LLM agents.

*   **研究背景**：
    *   **单模型局限**：小模型推理快但易在复杂环节出错，且一步出错会导致后续步数激增（轨迹漂移）；大模型推理稳健但全过程使用会导致极高的延迟。

*   **动机**：利用智能体自身的“自我反思”能力作为信号，动态协调大小模型协作，实现“小模型处理常规步骤，大模型攻克关键难点”。

### 2. 方法论：AgentCollab 框架
核心思想是**自驱动的协作推理**，无需外部路由模型，完全依靠智能体对当前进展的自我评估。
*   **模型升级机制（Model Escalation）**：
    1.  **预热阶段（Warm-up）**：由大模型（$M_L$）启动，负责全局规划和任务分解。
    2.  **常规阶段（Routine）**：移交给小模型（$M_S$）执行具体的工具调用和推理。
    3.  **自我评估（Self-evaluation）**：每一步推理后，模型生成一个结构化的进展评估（Rationale + Binary Value）。若 `value = FALSE`（停滞），则触发升级。
    4.  **干预与回退**：大模型接管控制权，在限定步数内修复轨迹，完成后控制权回退给小模型。
*   **难度感知的累积预算策略（Difficulty-aware Budget Allocation）**：
    *   为了防止频繁切换导致的计算开销（如 Prefill 状态丢失）并应对持续困难，引入累积机制。
    *   **公式逻辑**：干预步数 $B_l$ 随连续失败次数 $l$ 增加。采用线性增长 $f(B_0, l) = \min \{B_{max}, B_0 + kl\}$ 或 Sigmoid 曲线增长，确保在困难路段大模型有足够的“深度”来纠偏。

### 6. 主要结论与发现
*   **帕累托前沿优化**：AgentCollab 在所有任务中均显著提升了准确率-效率权衡。其准确率接近纯大模型，而推理速度接近纯小模型。
*   **纠偏能力**：小模型虽然单步快，但出错后会导致推理步数大幅增加；AgentCollab 通过大模型及时介入，缩短了总推理轨迹长度。
*   **动态预算优势**：动态累积策略减少了模型间的频繁切换（切换率从 49.6% 降至 45.1%），有利于 KV Cache 复用，提升了实际吞吐量。
*   **能力差距效应**：大小模型间的“能力鸿沟”越大，协作带来的收益越明显（如 7B+32B 的效果远好于 3B+7B）。

### 7. 优点
*   **即插即用**：无需训练额外的路由模型或策略网络，降低了部署门槛。
*   **轨迹级优化**：跳出了单轮路由的局限，从智能体长程交互的全局视角优化效率。
*   **自适应性强**：通过自我反思信号，能够根据任务难度动态分配算力。

### 8. 不足与局限
*   **同构依赖**：实验主要基于相同架构（Qwen 系列）的不同规模模型，尚未验证跨架构（如不同厂商模型）协作的效果。
*   **自我评估偏差**：框架高度依赖模型“自我评估”的准确性。实验发现，若小模型指令遵循能力较弱，可能产生“虚假进展”判断（False Positive），导致升级失效。
*   **闭源模型限制**：未在 GPT-4 或 Gemini 等闭源 API 模型上测试，因为 API 延迟不稳定，难以准确衡量效率增益。
